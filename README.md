# FiveWin Documentation

Welcome to the FiveWin documentation. This directory contains comprehensive guides and references for using the FiveWin framework to build Windows applications with Harbour.

## Documentation Structure

The documentation is organized into the following sections:

* **[Architecture](architecture.md)** - High-level overview of the framework's architecture and design principles
* **[Modules](modules/)** - Documentation organized by functional modules
  * **[Classes](modules/classes.md)** - Object-oriented components for building GUIs
  * **[Functions](modules/functions.md)** - Utility functions for common tasks
  * **[Windows API Wrappers](modules/winapi.md)** - Direct access to Windows system functionality
* **[Tutorials](tutorials/)** - Step-by-step guides for building applications
* **[API Reference](reference/)** - Detailed reference for all classes, methods, and functions

## Language Consistency

All documentation in this repository is being standardized to English to ensure consistency and broader accessibility.

If you're new to FiveWin, we recommend starting with the [Tutorials](tutorials/) section, which provides step-by-step guidance for building your first applications.

MCP Server — Computer Use

Source: mcp\mcp_server.prg

A Model Context Protocol (MCP) server for desktop automation, built with Harbour/FiveWin. Exposes screenshot capture and UI action execution tools over stdio for AI clients like Claude Code, OpenCode, and Cursor.

Architecture

┌─────────────────────┐      JSON-RPC 2.0       ┌──────────────────┐
│  Claude Code /      │  stdin ──────────────►   │  mcp_server.exe  │
│  OpenCode / Cursor  │  stdout ◄──────────────  │  (Harbour/FWH)   │
│  (the brain)        │                          │  (the muscles)   │
└─────────────────────┘                          └──────────────────┘
        │                                                │
        │  1. capture_screen → gets screenshot            │
        │  2. analyzes image (client has vision)          │
        │  3. execute_action → click/type/scroll          │
        │  4. repeat...                                   │
        ▼                                                ▼
   Decides what                                    Windows Desktop
   to do next                                      (GDI + Win32 API)

Quick Start

1. Build

cd C:\FWH\mcp
build.bat

2. Configure Claude Code

Create .mcp.json in your project root:

{
  "mcpServers": {
    "computer-use": {
      "command": "C:\\FWH\\mcp\\mcp_server.exe"
    }
  }
}

3. Use

Ask Claude Code to interact with your desktop:

Open Notepad and type "Hello World"

MCP Tools

ToolDescriptionParameters
capture_screen Captures full screen screenshot format: "base64" or "file" (required)
path: file path when format=file
execute_action Executes a UI action on the desktop action: click | right_click | double_click | type | scroll | key | hover | navigate | wait (required)
x: X coordinate 0-1000 (normalized)
y: Y coordinate 0-1000 (normalized)
text: text to type or URL to navigate
key: key combo (ctrl+c, alt+tab, enter, etc.)
direction: up | down | left | right (for scroll)
durationMs: duration for wait action (default 1000)
get_screen_size Returns screen dimensions in pixels None
get_action_history Returns history of executed actions last_n: number of recent actions (default 10)
reset_agent Resets agent state and clears history None
save_screenshot Captures and saves screenshot to file path: file path to save (required)

Coordinate System

All coordinates are normalized to 0-1000 relative to screen size, compatible with Gemini Computer Use format. 

Screen (1920×1080):
┌───────────────────────────────┐
│ (0,0)                   (1000,0) │
│                               │
│     x=500, y=500 = center    │
│                               │
│ (0,1000)              (1000,1000) │
└───────────────────────────────┘

Conversion to pixels:
  pixel_x = x × screen_width / 1000
  pixel_y = y × screen_height / 1000

Technical Details

  • Protocol: MCP 2024-11-05 (JSON-RPC 2.0 over stdio)
  • Transport: Newline-delimited JSON on stdin/stdout
  • Build: Harbour + MSVC 64-bit (/subsystem:console)
  • Win32 APIs: GetDC, BitBlt, CreateCompatibleBitmap, mouse_event, keybd_event
  • No external dependencies: Pure Harbour/FWH + Windows APIs

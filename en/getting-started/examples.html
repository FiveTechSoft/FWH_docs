Examples Index

FWH ships with 500+ example programs organized in the samples\ directory. Each subdirectory targets a specific area: getting started, UI controls, data access, printing, internet, AI, legacy utilities, and more. All examples can be compiled with build_new.bat <name> <variant>.

Building the Examples

All examples are compiled from the samples directory using the unified build script:

cd \fwteam\samples
build_new.bat <program> <variant>

// Examples:
build_new.bat tutor01 hb32       // Harbour + BCC32
build_new.bat tutor01 hm64       // Harbour + MSVC 64
build_new.bat xbrwedit hb32      // TXBrowse inline edit
build_new.bat qrcode2 hb32       // QR codes

Variants: hb32, hm32, hm64, hg32, hg64, hb64, xb32, xb64, xm64.

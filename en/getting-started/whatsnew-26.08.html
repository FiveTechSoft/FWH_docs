samples/test/testblur.prg — blur with JPG/PNG

samples/test/testblur.prg demonstrates the embedded C Blur( hBitmap, nRadius ) effect (box blur, 0–100). It previously loaded only BMP via PalBmpRead. It now loads common image files and shows a visible horizontal slider under the image.

  • Formats: BMP, JPG/JPEG, PNG (and other types supported by FW_ReadImage / FreeImage / GDI+ fallbacks)
  • UI: code-created DEFINE DIALOG with PIXEL TRUEPIXEL so the image and controls share the same pixel grid; without TRUEPIXEL, PIXEL controls can land outside the dialog template and disappear
  • Slider: horizontal TSlider under the bitmap (0–100); value shown next to the label “Blur:”
  • CLI: testblur.exe path\to\image.jpg skips the file dialog when the path exists
cd samples\test
build_new.bat testblur hb32
testblur.exe
:: or: testblur.exe C:\path\to\photo.jpg

Related: FW_ReadImage() / PalBmpDraw(), and sample samples\test\testblu2.prg (blur over an XBrowse background).

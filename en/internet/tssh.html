TSSH

Source: source/classes/tssh.prg | C backend: source/winapi/ssh.c

Hierarchy: TSSH (standalone class, no inheritance)

TSSH wraps the Windows 10+ OpenSSH client (ssh.exe and scp.exe) via CreateProcess with anonymous pipe capture. It supports remote command execution, SCP file transfer, key-based authentication, and host key scanning.

Requirements: OpenSSH Client installed (Windows Settings → Apps → Optional Features → OpenSSH Client). For password-based authentication, set up SSH keys or use an external tool like Plink.

Usage Examples

Connect and Execute Commands

oSSH := TSSH():New( "192.168.1.100", "root", 22, "~/.ssh/id_rsa" )

if oSSH:Connect()
   // Run a command
   cResult := oSSH:Exec( "uname -a" )
   MsgInfo( cResult )

   // List files
   cResult := oSSH:Exec( "ls -la /var/log" )
   MsgInfo( cResult )
endif

File Transfer

oSSH := TSSH():New( "myserver.com", "deploy", 22, "deploy_key.pem" )

// Upload
if oSSH:SendFile( "app.exe", "/opt/app/app.exe" )
   MsgInfo( "Upload successful" )
endif

// Download
if oSSH:GetFile( "/etc/hostname", "hostname.txt" )
   MsgInfo( "Downloaded: " + MemoRead( "hostname.txt" ) )
endif

Generate Key and Scan Host

oSSH := TSSH():New()

// Generate RSA key pair
oSSH:KeyGen( "mykey_rsa", "rsa", "deploy@myserver", 4096 )
// Creates: mykey_rsa (private) and mykey_rsa.pub (public)

// Scan host key (for known_hosts)
cHostKey := oSSH:KeyScan( "github.com" )
? cHostKey

Deploy Workflow

oSSH := TSSH():New( "prod-server", "admin", 22, "~/.ssh/prod_key" )

// Pull latest code
oSSH:Exec( "cd /opt/app && git pull origin master" )

// Rebuild
oSSH:Exec( "cd /opt/app && make clean && make" )

// Restart service
oSSH:Exec( "systemctl restart myapp" )

// Verify
cStatus := oSSH:Exec( "systemctl status myapp" )
MsgInfo( cStatus )

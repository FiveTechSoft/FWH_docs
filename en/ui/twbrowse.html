TWBrowse

Source: source/classes/wbrowse.prg

Inherits from: TControl

TWBrowse is FiveWin's original browse control for navigating database records and array data in a tabular format. It provides column headers, adjustable column sizing, keyboard navigation, inline editing, and integration with database objects, arrays, and ADO recordsets. TXBrowse is the modern successor, but TWBrowse remains in active use for simpler scenarios.

Example: 3-Column Browse Bound to DBF

#include "FiveWin.ch"

function Main()

   local oWnd, oBrw

   USE CUSTOMER NEW

   DEFINE WINDOW oWnd TITLE "Customers" SIZE 600, 400

   @ 10, 10 BROWSE oBrw ;
      HEADERS "Code", "Name", "City" ;
      SIZES 60, 200, 150 ;
      OF oWnd

   oBrw:SetOBJ( TDatabase():Open( nil, "CUSTOMER" ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TWBrowse supports three data binding modes: array (SetArray), database object (SetOBJ), and ADO recordset (SetADO).
  • For simple DBF browsing without an explicit TDatabase object, the browse automatically uses the current work area (cAlias).
  • The bLine code block allows custom row rendering. It receives the row object and the column value array as parameters.
  • Use bSkip to implement custom navigation logic for non-standard data sources.
  • For new projects, consider using TXBrowse which offers richer features including bitmap headers, footers, groups, and advanced styling.

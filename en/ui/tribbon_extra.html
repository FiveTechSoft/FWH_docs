TBackStage

Source: source/classes/tribbon.prg

Inherits from: TControl

TBackStage implements the Office-style backstage view -- a full-panel menu replacing the ribbon when activated (typically by clicking the File tab). It displays a vertical list of selectable options and action buttons with icons, gradients, and hover effects.

Key DATA Members

DATATypeDescription
aOptionsArrayArray of TBackStageOption objects
nMainWidthNumericWidth of the options panel (default 155)

Methods

MethodDescription
New( nTop, nLeft, nBottom, nRight, oWnd, nMainWidth )Create a backstage panel

TQuickAccess

Source: source/classes/tribbon.prg

Inherits from: TRibbonBar

Quick Access Toolbar sits above ribbon tabs with small icon buttons for frequent commands.

MethodDescription
New( oRibbon, nLeft )Create the toolbar
AddButton( cBmp, bAction, cTooltip )Add a button with bitmap and action
DelButton( oButton )Remove a button

Example: Backstage with Pages

#include "FiveWin.ch"
function Main()
   local oWnd, oRBar, oBack
   DEFINE WINDOW oWnd TITLE "Ribbon Demo" SIZE 800, 600
   DEFINE RIBBONBAR oRBar WINDOW oWnd PROMPT "Home", "Insert"
   oBack := TBackStage():New( 25, 0, 600, 800, oWnd, 180 )
   oBack:AddOption( "New", , , 1, , , , , "new.bmp" )
   oBack:AddOption( "Open", , , 1, , , , , "open.bmp" )
   oBack:AddOption( "Save", , , 2, , , , , "save.bmp" )
   oRBar:SetBackStage( oBack )
   ACTIVATE WINDOW oWnd CENTERED
return nil

Notes

  • TBackStage is created independently and attached via oRBar:SetBackStage().
  • Option types: BCKTYPE_SELECT (1) for page selection, BCKTYPE_BUTTON (2) for actions.
  • TQuickAccess is created via oRBar:QuickAccess() and populated with AddButton().

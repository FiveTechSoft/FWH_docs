TCalendar

Source: source/classes/tcalenda.prg

Inherits from: TControl

TCalendar wraps the Windows month calendar common control for date selection. It supports single and multi-select date ranges, week number display, day state highlighting, today indicator suppression, and extensive color customization of all calendar elements.

Command Syntax

@ nRow, nCol CALENDAR oCal VAR dDate OF oWnd SIZE nW, nH ON CHANGE bBlock

Example: Calendar with Change Callback

#include "FiveWin.ch"

function Main()

   local oWnd, oCal, dDate := Date()

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 400, 350

   @ 20, 20 CALENDAR oCal VAR dDate OF oWnd SIZE 350, 250 ;
      ON CHANGE MsgInfo( DToC( dDate ), "Date Selected" )

   oCal:lWeekNumbers := .T.
   oCal:SetColor( MCSC_TITLEBK, CLR_BLUE )
   oCal:SetColor( MCSC_TITLETEXT, CLR_WHITE )
   oCal:SetFirstDayOfWeek( 1 )  // Monday

   @ 300, 20 BUTTON "&OK" SIZE 60, 25 PIXEL OF oWnd ;
      ACTION ( MsgInfo( DToC( dDate ) ), oWnd:End() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TCalendar wraps the Win32 SysMonthCal32 common control. The control automatically adjusts its minimum size based on the font and number of visible months.
  • In multi-select mode (lMultiselect := .T.), use bSetGet2 to bind the end date variable and GetDateRange() to retrieve both start and end dates.
  • Day states allow individual days to be rendered in bold (grayed = GRAY, bold = BOLD). Use SetArrayDayState() to configure states per month.
  • The MCSC_* constants for color customization are: MCSC_BACKGROUND (0), MCSC_TEXT (1), MCSC_TITLEBK (2), MCSC_TITLETEXT (3), MCSC_MONTHBK (4), MCSC_TRAILINGTEXT (5).

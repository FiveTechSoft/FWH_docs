TCColumn

Source: source/classes/tccolumn.prg

Standalone class

TCColumn defines a single column within a TCBrowse control. Each column has a heading, data codeblock, picture clause, alignment, width, optional foreground/background colors, inline editing support, and bitmap display capability. Columns can be serialized for the Visual FiveWin IDE designer.

Key DATA Members

DATATypeDescription
cHeadingCharacterColumn header text displayed in the browse header row
bDataCodeblockCodeblock that returns the cell value for each row
cPictureCharacterPicture clause for formatting cell values
bClrForeCodeblockCodeblock returning foreground color per cell
bClrBackCodeblockCodeblock returning background color per cell
nAlignNumericText alignment: DT_LEFT (0), DT_CENTER (1), DT_RIGHT (2)
nWidthNumericColumn width in dialog units (auto-calculated if not specified)
lBitMapLogicalColumn displays bitmaps instead of text
lEditLogicalAllow in-place editing of cells
bValidCodeblockEdit validation codeblock (return .T. to accept)
cOrderCharacterIndex tag name for ordering
cMsgCharacterStatus bar message when editing this column
cErrorCharacterError message displayed when validation fails

Methods

MethodDescription
New( cHeading, bData, cPicture, bClrFore, bClrBack, uAlign, nWidth, lBitMap, lEdit, cMsg, bValid, cError, lNoLite, cOrder )Create a new TCColumn definition
Load( cInfo )Load column properties from a string (VisualFW designer)

Example: Column with Conditional Color

#include "FiveWin.ch"

function CreateColumns()

   local oCol1, oCol2

   // Simple column with default left alignment
   oCol1 := TCColumn():New( "Product", { || oData:Product } )

   // Column with picture, right-aligned, and conditional color:
   // negative values shown in red
   oCol2 := TCColumn():New( "Balance",;
      { || oData:Balance },;
      "999,999.99",;
      { || If( oData:Balance < 0, CLR_HRED, CLR_BLACK ) },;
      { || If( oData:Balance < 0, CLR_YELLOW, CLR_WHITE ) },;
      DT_RIGHT,;
      120 )

return nil

Notes

  • TCColumn is used exclusively with TCBrowse. For TXBrowse, use TXColumn instead.
  • The uAlign parameter accepts both numeric values (DT_LEFT, DT_CENTER, DT_RIGHT) and character strings ("LEFT", "CENTER", "RIGHT").
  • Color codeblocks (bClrFore, bClrBack) are evaluated per cell and can also accept dBASE-style color strings (e.g., "R/W" for red on white).
  • Column width is auto-calculated if nWidth is omitted, based on heading and data lengths.
  • When lEdit is .T., pressing Enter or clicking on the cell enters edit mode. The bValid codeblock validates the entered value.
  • The Save() and Load() methods support serialization for the Visual FiveWin IDE.

TCalViews: TDayView, TWeekView, TMonthView

Source: source/classes/tdayv.prg, source/classes/tweekv.prg, source/classes/tmonthv.prg

Each inherits from: TCalEx

TDayView, TWeekView, and TMonthView are the three sub-view classes used by TCalEx to render different calendar perspectives. Each view inherits from TCalEx and provides specialized rendering, navigation, and event handling for its specific time granularity. The active view is set via TCalEx methods SetDayView(), SetWeekView(), and SetMonthView().

TDayView - Day View

TDayView displays a single day with a time-slot grid. The grid is divided into rows representing time intervals (controlled by nInterval in TCalEx) between nStartHour and nEndHour. Each appointment or event appears as a colored block spanning its duration. Users can click on empty slots to create new events and drag existing events to reschedule.

Key DATA

DATATypeDescription
nRowCountNumericTotal number of time-slot rows in the grid
nRowHeightNumericHeight of each time-slot row in pixels

Methods

MethodDescription
New( oCalex )Create a TDayView bound to a TCalEx parent
GoNextDay()Navigate to the next day
GoPrevDay()Navigate to the previous day
SetDate( dDate )Set the view to a specific date

Example: Switch to Day View

// Assume oCal is a TCalEx instance
oCal:SetDayView( dDate(), 30 )  // 30-minute intervals

TWeekView - Week View

TWeekView displays a full week (7 days) with time-slot rows for each day. Each column represents one day of the week, and each row represents a time interval. Events are rendered as colored blocks spanning their time range within each day column. The view supports horizontal and vertical scrolling for weeks with many events.

Key DATA

DATATypeDescription
nDaysNumericNumber of days displayed (always 7)
nRowHeightNumericHeight of each time-slot row
nRowCountNumericTotal number of time-slot rows

Methods

MethodDescription
New( oCalex )Create a TWeekView bound to a TCalEx parent
GoNextWeek()Navigate to the next week
GoPrevWeek()Navigate to the previous week
SetDate( dDate )Set the view to a specific week containing dDate

Example: Switch to Week View

// Assume oCal is a TCalEx instance
oCal:SetWeekView( dDate(), 30 )  // Current week, 30-min intervals

TMonthView - Month View

TMonthView displays a full month in a traditional calendar grid layout. The grid has 7 columns (days of the week) and 5 or 6 rows (weeks in the month). Each cell shows the day number and can display event indicators. Double-clicking a cell typically switches to TDayView for the selected date via oCalex:SetDayView().

Key DATA

DATATypeDescription
nWksNumericNumber of weeks displayed (5 or 6, depending on the month)
nRowHeightNumericHeight of each week row
nColWidthNumericWidth of each day column
nInfoHeightNumericHeight reserved for event info in each cell

Methods

MethodDescription
New( oCalex )Create a TMonthView bound to a TCalEx parent
SetDate( dDate )Set the view to the month containing dDate
GoNextMonth()Navigate to the next month
GoPrevMonth()Navigate to the previous month
GetDateFromPos( nAtRow, nAtCol )Return the date at grid position (row, col)
GetPosFromDate( dDate )Return grid row and column for a given date

Example: Switch to Month View

// Assume oCal is a TCalEx instance
oCal:SetMonthView()  // Show current month

Notes

  • All three views are created internally by TCalEx and accessed through its oDayView, oWeekView, and oMonthView DATA members.
  • View navigation methods (GoNext/GoPrev) are automatically scoped to the active view. For example, oCal:GoNext() advances one day, week, or month depending on the active view.
  • Double-clicking a cell in TMonthView triggers oCalex:SetDayView(), drilling down from month to day granularity.
  • The nInterval setting from TCalEx controls the row granularity in day and week views. Common values are 30 (half-hour rows) or 60 (hour rows).
  • Event rendering and mouse interaction logic is shared between the views through inherited methods from TCalEx.

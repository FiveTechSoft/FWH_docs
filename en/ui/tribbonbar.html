TRibbonBar

Source: source/classes/tribbonbar.prg

Overview

TRibbonBar class — part of the FiveWin for Harbour/xHarbour framework.

Accelerators

TRibbonBar supports standard Windows-style & accelerators for tab switching. Place & before the desired letter in each prompt:

DEFINE RIBBONBAR oRBar WINDOW oWnd ;
   PROMPT "&Configuración", "&Ficheros", "&Informes", "&Ayudas" ;
   HEIGHT 133 TOPMARGIN 25

When lUseAcc is .F. (the default), pressing Alt+key switches to the matching tab. The underlined letter is rendered in the tab prompt. The keytip number boxes are not shown.

To enable the keytip overlay (numbered squares), set oRBar:lUseAcc := .T..

Claude Code

Claude Code is Anthropic's official CLI tool and AI coding agent that operates directly in your terminal. It reads your entire codebase, executes commands, edits files, and orchestrates complex multi-step development tasks — all from the command line.

FiveWin for Harbour integrates deeply with Claude Code via project-specific configuration (CLAUDE.md), persistent memory, specialized skills, and multi-agent workflows. This section documents all Claude Code capabilities and how they enhance FWH development.

What Is Claude Code?

  • Terminal-native — runs in PowerShell, cmd, bash, or any terminal
  • Full codebase awareness — reads and understands your entire project
  • Tool-using agent — edits files, runs builds, executes git, launches apps
  • Multi-agent orchestration — spawns parallel sub-agents for complex tasks
  • Persistent memory — remembers project facts, user preferences, conventions
  • Hooks system — automated behaviors triggered by events
  • MCP servers — extensible via Model Context Protocol

Key Features

CLAUDE.md

The project instruction file checked into the repo root. Contains build rules, compiler paths, library naming conventions, encoding requirements, and critical rules that Claude Code follows for every task. Also supports user-level ~/.claude/CLAUDE.md.

Memory System

Persistent file-based memory at .claude/projects/<project>/memory/. Stores user preferences, project conventions, feedback, and reference facts across sessions. Recalled automatically via MEMORY.md index.

Skills

Specialized instruction sets loaded on-demand. The FWH project includes:

  • dialog — Design Windows dialog boxes (.rc + PRG with REDEFINE)
  • systematic-debugging — Root-cause analysis workflow
  • test-driven-development — TDD workflow for Harbour/FiveWin
  • code-review — Correctness and simplification review
  • caveman — Token-efficient communication mode (75% reduction)
  • writing-plans / executing-plans — Plan-then-execute workflow
  • deep-research — Multi-source web research with citations

Multi-Agent Workflows

Orchestrate dozens of parallel sub-agents via JavaScript workflow scripts. Patterns include: adversarial verification, judge panels, fan-out search, pipeline stages, and loop-until-dry accumulation. The FWH project uses workflows for comprehensive code review and documentation generation.

Caveman Mode

Ultra-compressed communication: fragments, no articles, no pleasantries. Cuts token usage ~75% while keeping full technical accuracy. Three intensity levels (lite/full/ultra) plus Wenyan (classical Chinese) variants. Trigger: "caveman mode", "/caveman".

Hooks System

Event-driven automation via settings.json. Examples in FWH: UserPromptSubmit activates caveman mode, SessionStart persists caveman state, PostToolUse triggers build/test flows.

File, Text & Data Classes

FiveWin provides a rich set of classes for file I/O, text editing, INI configuration, Windows registry access, clipboard operations, C structure interop, and data dictionary management. These classes wrap low-level OS facilities into clean object-oriented interfaces.

classDiagram TFile <|-- TTxtFile TControl <|-- TTxtEdit class TFile { +cName +hFile +nLen +New(cFileName, nMode) +Create(cFileName, nMode) +Open() +Close() +GoTop() +GoBottom() +Seek(cStr) +PutStr(cStr) +cGetStr(nLen) } class TTxtFile { +cLine +nLine +nTLines +ReadLine() +Add(cLine) +DelLine() +Skip(nSkip) } class TIni { +cIniFile +New(cIniFile) +Get(cSection, cEntry, uDefault) +Set(cSection, cEntry, uValue) +Sections() +DelSection(cSection) +DelEntry(cSection, cEntry) } class TReg32 { +nHandle +nKey +New(nKey, cRegKey) +Create(nKey, cRegKey) +Get(cSubKey, uVar) +Set(cSubKey, uVar) +Close() } class TClipBoard { +nFormat +New(nFormat, oWnd) +SetText(cText) +GetText() +SetBitmap(oBitmap) +GetBitmap() }

TFile - Binary File Operations

TFile is the base class for binary file manipulation. It wraps Harbour's low-level FOpen/FCreate/FRead/FWrite functions into an object that tracks the file handle, length, and current position. TTxtFile inherits from TFile to add line-based access.

DATA Members

DATATypeDescription
cNameCharacterFile name (path) passed to constructor
hFileNumericOS file handle returned by FOpen/FCreate
nLenNumericTotal file length in bytes
nBufferLenNumericRead buffer size (default 2048)
nModeNumericOpen mode (FO_READWRITE, FC_NORMAL, etc.)

METHOD Reference

MethodDescription
New( cFileName, nMode )Opens existing file or creates new. If file exists, opens with nMode (default FO_READWRITE). If not, creates with FC_NORMAL.
Create( cFileName, nMode )Erases existing file then calls New() to create a fresh file.
Open()Returns .T. if file handle is valid (hFile > 0).
Close()Closes the file handle via FClose().
End()Alias for Close().
GoTop()Seeks to byte position 0 (beginning of file).
GoBottom()Seeks to end of file, updates nLen.
GoTo( nRecno )Seeks to absolute byte position nRecno.
Skip( nBytes )Moves file pointer forward/backward by nBytes relative to current position.
nRecNo()Returns current byte position in file.
lEoF()Returns .T. if current position >= nLen.
lBoF()Returns .T. if current position == 0.
nGetByte()Reads and returns one byte as numeric (Asc value), or -1 on failure.
nGetWord()Reads and returns a 16-bit word (2 bytes) via Bin2I(), or -1 on failure.
cGetStr( nLen )Reads nLen bytes and returns as string.
PutByte( nByte )Writes one byte at current position.
PutWord( nWord )Writes a 16-bit word at current position via I2Bin().
PutStr( cStr )Writes a string at current position via FWrite().
AppByte( nByte )Appends one byte at end of file, increments nLen.
AppWord( nWord )Appends a 16-bit word at end of file.
AppStr( cStr )Appends a string at end of file.
Count( cStr )Counts occurrences of cStr in the entire file (default CRLF).
Seek( cStr, nDirection, nCase )Searches for cStr from current position. nDirection: 0=forward, 1=backward. nCase: 0=nocase, 1=upper, 2=lower.
DelBytes( nLen )Deletes nLen bytes at current position.
InsBytes( nLen )Inserts nLen empty bytes at current position.

Example: Reading a Binary File

local oFile := TFile():New( "data.bin" )

if oFile:Open()
   oFile:GoTop()
   ? "File size:", oFile:nLen, "bytes"

   // Read header: 2-byte signature + 4-byte length
   local nSig  := oFile:nGetWord()
   local cData := oFile:cGetStr( 256 )

   ? "Signature:", nSig
   ? "First 256 bytes:", cData

   // Search for a pattern
   oFile:GoTop()
   if oFile:Seek( "MARKER" )
      ? "Found MARKER at position:", oFile:nRecNo()
   endif

   oFile:Close()
endif

Example: Creating and Writing a Binary File

local oFile := TFile():Create( "output.dat" )

oFile:PutWord( 0x4657 )           // 2-byte signature "FW"
oFile:PutStr( "Hello World" )     // string data
oFile:AppStr( CRLF + "Line 2" )  // append at end

? "Bytes written:", oFile:nLen
oFile:Close()

TTxtFile - Text File Line Access

TTxtFile inherits from TFile and adds line-by-line navigation. It counts CRLF line endings on open and provides Skip/GoTo/ReadLine methods that work with line numbers rather than byte offsets. Ideal for reading log files, CSV data, or configuration files.

DATA Members

DATATypeDescription
cLineCharacterContents of the current line after ReadLine()
nLineNumericCurrent line number (1-based)
nTLinesNumericTotal number of lines in the file
nMaxLineLengthNumericMaximum expected line length (default 1024)
nOffsetNumericByte offset of current line start

METHOD Reference

MethodDescription
New( cFileName, nMode )Opens file, counts lines (CRLF), reads first line.
ReadLine()Reads the current line into ::cLine from current byte offset.
ReadLn()Alias for ReadLine() (backward compatibility).
GoTo( nLine )Seeks to line number nLine and reads it.
GoTop()Goes to line 1, resets offset to 0, reads first line.
GoBottom()Goes to last line.
Skip( nSkip )Moves forward or backward by nSkip lines.
Advance()Moves to the next line (seeks next CRLF). Returns .F. at EOF.
Add( cLine )Appends a new line at the end of the file.
InsLine( cLine )Inserts a new line at current position.
DelLine()Deletes the current line.
RepLine( cLine )Replaces current line (DelLine + InsLine).
AppendLn( cLine )Appends a line with CRLF terminator.
RecCount()Returns total line count (same as nTLines).
RecNo()Returns current line number.
LastRec()Returns total line count.
Skipper( nRecs )TBrowse-compatible skipper method.
GetValue( cSection, cKeyword, xDefVal )Reads a value from INI-style sections in the text file.
SetValue( cSection, cKeyword, xValue )Writes a value to INI-style sections.

Example: Processing a Text File Line by Line

local oTxt := TTxtFile():New( "logfile.txt", FO_READ )

if oTxt:Open()
   ? "Total lines:", oTxt:RecCount()

   oTxt:GoTop()
   while ! oTxt:Eof()
      if "ERROR" $ Upper( oTxt:cLine )
         ? "Line", oTxt:nLine, ":", oTxt:cLine
      endif
      oTxt:Skip( 1 )
   end

   oTxt:Close()
endif

Example: Building a Text File

local oTxt := TTxtFile():New( "report.csv" )

oTxt:Add( "Name,Age,City" )
oTxt:Add( "John,30,New York" )
oTxt:Add( "Maria,25,Madrid" )
oTxt:Add( "Hans,40,Berlin" )

? "Written", oTxt:RecCount(), "lines"
oTxt:Close()

TTxtEdit - Multiline Text Editor Control

TTxtEdit is a full-featured text editor control with syntax highlighting, undo/redo, block selection, find/replace, line numbering, and clipboard support. It inherits from TControl and can be placed in any window or dialog. Used internally by FiveWin's code editor and is suitable for building IDE-like interfaces.

nClrTok1, nClrTok2, nClrTok3NumericColors for each token group
nClrNumberNumericColor for numeric literals
nClrStringNumericColor for string literals
nClrOperatorNumericColor for operators
nClrLineNumberNumericColor for line number gutter
nClrBBlock, nClrFBlockNumericBackground/foreground colors for selected block
lLineNumberLogicalShow line numbers in the gutter
nTabLenNumericTab stop width in characters
lReadOnlyLogicalIf .T., editing is disabled (default .F.)

METHOD Reference

Example: Code Editor with Syntax Highlighting

local oWnd, oEdit

DEFINE WINDOW oWnd TITLE "Code Editor"

oEdit := TTxtEdit():New( 0, 0, oWnd:nWidth(), oWnd:nHeight(), oWnd )
oEdit:lLineNumber := .T.
oEdit:nTabLen     := 3

// Harbour keywords for syntax highlighting
oEdit:cTokens1 := "function return local static if else endif do while end " + ;
                   "for next class endclass method data"
oEdit:nClrTok1 := CLR_BLUE

oEdit:cTokens2 := "nil .t. .f. .and. .or. .not."
oEdit:nClrTok2 := CLR_RED

oEdit:nClrString  := CLR_HGREEN
oEdit:nClrNumber  := CLR_MAGENTA
oEdit:nClrComment := RGB( 0, 128, 0 )

// Load a file
oEdit:aLines := HB_ATokens( MemoRead( "myapp.prg" ), CRLF )

ACTIVATE WINDOW oWnd

TIni - INI File Access

TIni provides read/write access to Windows-style INI files. It wraps the Windows API functions GetPrivateProfileString/WritePrivateProfileString. When no file is specified, it reads from/writes to WIN.INI. The lAutoSet flag (default .T.) automatically writes default values if a key is not found.

DATA Members

DATATypeDescription
cIniFileCharacterPath to the INI file. Empty string means WIN.INI.
lAutoSetLogicalIf .T. (default), writes default values when key not found on Get().

METHOD Reference

MethodDescription
New( cIniFile )Creates TIni object. Appends ".ini" extension if no dot in filename.
Get( cSection, cEntry, uDefault, uVar )Reads a value. Type is determined by uDefault: numeric returns integer, date returns CToD(), logical returns .T./.F. comparison, otherwise string.
Set( cSection, cEntry, uValue )Writes a value (converted to string via cValToChar).
Sections()Returns an array of all section names in the INI file.
DelSection( cSection )Deletes an entire section from the INI file.
DelEntry( cSection, cEntry )Deletes a single entry from a section.

Command Syntax

// FiveWin provides INI command wrappers:
INI oIni FILENAME "myapp.ini"

   GET cServer  SECTION "Database" ENTRY "Server"  DEFAULT "localhost" OF oIni
   GET nPort    SECTION "Database" ENTRY "Port"    DEFAULT 3306        OF oIni
   GET lDebug   SECTION "App"      ENTRY "Debug"   DEFAULT .F.         OF oIni

   SET SECTION "App" ENTRY "LastRun" TO DToC( Date() ) OF oIni

ENDINI

Example: Application Settings

function LoadSettings()
   local oIni := TIni():New( "myapp.ini" )
   local cServer, nPort, cUser

   cServer := oIni:Get( "Database", "Server", "localhost" )
   nPort   := oIni:Get( "Database", "Port",   3306 )
   cUser   := oIni:Get( "Database", "User",   "admin" )

   // List all sections
   local aSections := oIni:Sections()
   AEval( aSections, {|c| QOut( "Section:", c ) } )

return nil

function SaveSettings( cServer, nPort )
   local oIni := TIni():New( "myapp.ini" )

   oIni:Set( "Database", "Server", cServer )
   oIni:Set( "Database", "Port",   nPort )
   oIni:Set( "App",      "LastRun", DToC( Date() ) )

return nil

TReg32 - Windows Registry Access

TReg32 provides object-oriented access to the Windows Registry. It supports reading and writing string (REG_SZ), numeric (REG_DWORD), and binary (REG_BINARY) values under any registry hive. On 32-bit applications running on 64-bit Windows, it automatically adds KEY_WOW64_64KEY for correct registry view access.

HKEY Constants

ConstantValueDescription
HKEY_CLASSES_ROOT0x80000000File type associations and COM registrations
HKEY_CURRENT_USER0x80000001Current user preferences and settings
HKEY_LOCAL_MACHINE0x80000002Machine-wide configuration data
HKEY_USERS0x80000003All user profiles on the machine
HKEY_CURRENT_CONFIG0x80000005Current hardware profile

DATA Members

DATATypeDescription
cRegKeyCharacterRegistry key path (e.g. "Software\\MyApp")
nKeyNumericRoot HKEY constant
nHandleNumericHandle to the opened registry key
nErrorNumericLast error code (0 = ERROR_SUCCESS)
lErrorLogicalError flag

METHOD Reference

MethodDescription
New( nKey, cRegKey )Opens an existing registry key. Tries KEY_ALL_ACCESS first, falls back to KEY_READ.
Create( nKey, cRegKey )Creates a new registry key (or opens if it already exists).
Get( cSubKey, uVar )Reads a value. Returns string for REG_SZ, numeric for REG_DWORD.
GetBinary( cSubKey )Reads a binary value as raw string.
Set( cSubKey, uVar, nType )Writes a value. nType defaults to REG_SZ for strings, REG_DWORD for numerics.
Delete( cSubKey )Deletes a sub-key.
Close()Closes the registry key handle.

Example: Reading and Writing Registry Values

#define HKEY_CURRENT_USER  2147483649

function ReadAppSettings()
   local oReg, cValue := "", nValue := 0

   oReg := TReg32():New( HKEY_CURRENT_USER, "Software\MyCompany\MyApp" )

   if oReg:nError == 0
      oReg:Get( "InstallPath", @cValue )
      ? "Install path:", cValue

      oReg:Get( "RunCount", @nValue )
      ? "Run count:", nValue

      // Increment run counter
      oReg:Set( "RunCount", nValue + 1 )
   endif

   oReg:Close()
return nil

function CreateAppKey()
   local oReg

   oReg := TReg32():Create( HKEY_CURRENT_USER, "Software\MyCompany\MyApp" )
   oReg:Set( "Version", "26.05" )
   oReg:Set( "InstallDate", DToC( Date() ) )
   oReg:Set( "RunCount", 0 )
   oReg:Close()
return nil

TClipBoard - Clipboard Access

TClipBoard provides access to the Windows clipboard for reading and writing text, bitmaps, metafiles, and dropped files. It handles Unicode text automatically when FW_SetUnicode() is active, converting between UTF-8 and UTF-16 as needed.

Clipboard Format Constants

ConstantValueDescription
CF_TEXT1ANSI text
CF_BITMAP2Bitmap (HBITMAP)
CF_OEMTEXT7OEM text
CF_UNICODETEXT13Unicode text (UTF-16)
CF_ENHMETAFILE14Enhanced metafile
CF_HDROP15Dropped files list

DATA Members

DATATypeDescription
nFormatNumericDefault clipboard format (CF_TEXT)
oWndObjectOwner window for clipboard operations

METHOD Reference

MethodDescription
New( nFormat, oWnd )Creates clipboard object with given format. Default CF_TEXT.
Open()Opens the clipboard (required before read/write).
Close()Closes the clipboard.
Empty()Empties the clipboard contents.
Clear()Opens, empties, and closes in one step.
IsEmpty()Returns .T. if clipboard has no data in current format.
SetText( cText )Writes text. Auto-detects UTF-8 and converts to UTF-16 if needed.
GetText()Reads text from clipboard.
SetWideText( cText )Writes text explicitly as Unicode (CF_UNICODETEXT).
GetUnicodeText()Reads Unicode text from clipboard.
SetBitmap( oBitmap )Writes a bitmap to clipboard (accepts TBitmap object or hBitmap handle).
GetBitmap()Reads a bitmap from clipboard.
SetMetaFile( oMetaFile )Writes an enhanced metafile to clipboard.
GetMetaFile()Reads an enhanced metafile from clipboard.
GetFiles()Returns array of file paths from CF_HDROP (drag-and-drop).
SetData( uData )Low-level: sets raw clipboard data in current format.
GetData()Low-level: gets raw clipboard data in current format.

Example: Clipboard Text Operations

local oClip := TClipBoard():New()

// Write text to clipboard
oClip:SetText( "Hello from FiveWin!" )

// Read text from clipboard
local cText := oClip:GetText()
? "Clipboard contains:", cText

// Clear the clipboard
oClip:Clear()

Example: Clipboard Bitmap

local oClip := TClipBoard():New()
local oBmp

// Copy a bitmap to clipboard
DEFINE BITMAP oBmp FILENAME "logo.bmp"
oClip:SetBitmap( oBmp )
oBmp:End()

// Retrieve bitmap from clipboard
local hBmp := oClip:GetBitmap()
if hBmp != 0
   ? "Bitmap retrieved from clipboard"
endif

TStruct - C Structure Interop

TStruct allows defining and manipulating C language structures from Harbour/xHarbour code. Members are defined with name, type, and optional length. Once defined, members can be accessed as properties using Harbour's error handler mechanism. The internal buffer (cBuffer) is a binary string compatible with Windows API STRUCT parameters.

Supported Type Constants

TypeSize (bytes)Description
BYTE / CHAR18-bit value
WORD / _INT / BOOL216-bit value
LONG / DWORD / PTR / LPSTR432-bit value or pointer
LONGLONG864-bit value

DATA Members

DATATypeDescription
cBufferCharacterRaw binary buffer holding the structure data
aMembersArrayArray of { cName, nType, nLen, nOffset } for each member

METHOD Reference

MethodDescription
New()Creates an empty structure with blank buffer.
AddMember( cName, nType, nLen )Adds a named member. nLen auto-determined from nType if omitted.
SetMember( nMember, uData )Sets value of member by index.
GetMember( nMember )Gets value of member by index.
SizeOf()Returns total structure size in bytes (Len of cBuffer).

Example: Defining and Using a POINT Structure

#include "Struct.ch"

local oPoint := TStruct():New()
oPoint:AddMember( "x", LONG )
oPoint:AddMember( "y", LONG )

// Set via property access (uses OnError handler)
oPoint:x := 100
oPoint:y := 200

? "Point:", oPoint:x, oPoint:y
? "Size:", oPoint:SizeOf(), "bytes"    // 8 bytes

// Pass cBuffer to Windows API functions expecting LPPOINT
// GetCursorPos( oPoint:cBuffer )

Example: RECT Structure for API Calls

#include "Struct.ch"

local oRect := TStruct():New()
oRect:AddMember( "left",   LONG )
oRect:AddMember( "top",    LONG )
oRect:AddMember( "right",  LONG )
oRect:AddMember( "bottom", LONG )

oRect:left   := 10
oRect:top    := 20
oRect:right  := 300
oRect:bottom := 200

? "Width:", oRect:right - oRect:left     // 290
? "Height:", oRect:bottom - oRect:top    // 180

TDict - Application Data Dictionary

TDict is a data dictionary manager for FiveWin applications. It creates and manages a set of DBF tables (in a "system" folder by default) that describe your application's structure: scripts, databases, tables, browses, columns, forms, menus, help texts, and language translations. It provides methods to auto-build UI from metadata, load menus dynamically, and generate web-based browse/edit views.

DATA Members

DATATypeDescription
cPathCharacterPath to the dictionary folder (default "system")
lAutoBuildLogicalAuto-build tables if missing (default .T.)
lCheckFilesLogicalCheck file existence on startup (default .F.)
oScriptsObjectScripts table workarea
oApplicationObjectApplication settings workarea
oBrowsesObjectBrowse definitions workarea
oBrwColsObjectBrowse column definitions workarea
oFormsObjectForm definitions workarea
oLangsObjectLanguage translations workarea
oMenusObjectMenu definitions workarea
oHelpObjectHelp text workarea
oTablesObjectTable definitions workarea

METHOD Reference

MethodDescription
New( cPath )Creates/opens dictionary in cPath folder. Auto-creates all required DBF tables and indexes.
Activate()Activates the dictionary (opens all tables).
End()Closes all dictionary tables.
OpenDataBase( cDbName, lInternet )Opens a database registered in the dictionary.
CloseDataBase( cDbName )Closes a registered database.
OpenTable( cTblName )Opens a specific table from the dictionary.
CreateTable( cTblName )Creates a new table definition.
LoadMenu( cMenuName )Loads a menu definition from the dictionary.
BuildSubMenu()Builds sub-menus from dictionary data.
Report( cReportName )Generates a report from dictionary definitions.

LoadWebEdit( cParams )Generates HTML edit form from dictionary metadata.

Example: Using the Data Dictionary

local oDict := TDict():New( "c:\myapp\system" )

oDict:Activate()

// Open a registered database
oDict:OpenDataBase( "customers" )

// Load a menu from dictionary
oDict:LoadMenu( "MainMenu" )

// Generate a report
oDict:Report( "CustomerList" )

oDict:End()

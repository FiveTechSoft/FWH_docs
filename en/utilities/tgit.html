TGit

Source: source/classes/tgit.prg | C backend: source/winapi/git.c

Hierarchy: TGit (standalone class, no inheritance)

TGit wraps the git.exe command line via CreateProcess with anonymous pipe capture for stdout and stderr. No external libraries required — only git must be installed and in the system PATH.

Usage Examples

Repository Status

oGit := TGit():New( "C:\MyProject" )

if oGit:IsRepo()
   aStatus := oGit:Status()
   for each aFile in aStatus
      ? aFile[ 1 ], aFile[ 2 ]  // XY status, filename
   next
endif

Commit and Push

oGit := TGit():New()
oGit:AddAll()
oGit:Commit( "Fix: resolve login timeout issue" )
oGit:Push( "origin", "master" )

Branch Operations

oGit := TGit():New()

// List branches
aBranches := oGit:BranchList()
for each aBranch in aBranches
   ? If( aBranch[ 2 ], "* ", "  " ) + aBranch[ 1 ]
next

// Create and switch
oGit:BranchCreate( "feature/new-feature" )
oGit:BranchSwitch( "feature/new-feature" )

View History

oGit := TGit():New()
aLog := oGit:Log( 20 )  // Last 20 commits
for each aCommit in aLog
   ? aCommit[ 1 ]  // Hash
   ? aCommit[ 2 ]  // Author
   ? aCommit[ 3 ]  // Date
   ? aCommit[ 4 ]  // Message
next

Clone Repository

oGit := TGit():New()
oGit:Clone( "https://github.com/user/repo.git", "C:\Projects\repo" )

TClipBoard - Windows Clipboard

Source: source/classes/clipbrd.prg

TClipBoard wraps the Windows Clipboard API (OpenClipboard, GetClipboardData, SetClipboardData, CloseClipboard, etc.) into an object-oriented interface. It supports ANSI and Unicode text, bitmap images, metafiles, and file lists (from Explorer's copy/paste). The class automatically manages clipboard ownership and sequencing of open/empty/close.

DATA Members

DATATypeDescription
nFormatNumericDefault clipboard format for text operations (CF_TEXT)
oWndObjectOwner window for clipboard operations

Methods

MethodDescription
New( nFormat )Create clipboard object with optional format (default CF_TEXT)
SetText( c )Copy ANSI text to the clipboard
GetText()Retrieve ANSI text from the clipboard
SetWideText( c )Copy Unicode (wide) text to the clipboard
GetUnicodeText()Retrieve Unicode text from the clipboard
SetBitmap( oBmp )Copy a bitmap to the clipboard
GetBitmap()Retrieve a bitmap from the clipboard
SetMetaFile( o )Copy a metafile to the clipboard
GetMetaFile()Retrieve a metafile from the clipboard
GetFiles()Return an array of file names from a CF_HDROP clipboard (copied from Explorer)
Clear()Clear all clipboard contents
Open()Open the clipboard for multiple operations (must call Empty() and Close() afterwards)
Empty()Empty the clipboard contents (must be called after Open() before setting data)
Close()Close the clipboard (must be called after Open())

Example: Copy/Paste Text and Files

#include "FiveWin.ch"

function Main()

   local oClip := TClipBoard():New()

   // Copy text to clipboard
   oClip:SetText( "Hello from FiveWin!" )
   ? "Text copied to clipboard"

   // Paste text from clipboard
   ? "Clipboard content:", oClip:GetText()

   // Copy a file list (as if from Explorer)
   oClip:Open()
   oClip:Empty()
   // ... set CF_HDROP data via Windows API
   oClip:Close()

   // Read files copied from Explorer
   local aFiles := oClip:GetFiles()
   if ValType( aFiles ) == "A"
      AEval( aFiles, {|c| ? "File: " + c } )
   endif

return nil

Example: Copy a Bitmap

function CopyBitmap()

   local oClip := TClipBoard():New()
   local oBmp  := TBitmap():New( "logo.bmp" )

   oClip:SetBitmap( oBmp )
   MsgInfo( "Bitmap copied to clipboard" )

return nil

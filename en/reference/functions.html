Key FWH Functions

FiveWin provides hundreds of functions that extend Harbour with Windows API access, GUI utilities, and convenience helpers. This page documents the most commonly used ones.

Message Box Functions

MsgInfo()

MsgInfo( cMessage [, cTitle ] ) --> nil

Displays an information message box with an "i" icon and OK button. The default title is "Information". 

MsgInfo( "Record saved successfully" )
MsgInfo( "Total: " + LTrim( Str( nTotal ) ), "Calculation Result" )

MsgAlert()

MsgAlert( cMessage [, cTitle ] ) --> nil

Displays a warning message box with an exclamation icon. Default title: "Alert". 

MsgAlert( "File not found: " + cFile )

MsgStop()

MsgStop( cMessage [, cTitle ] ) --> nil

Displays an error/stop message box with a red X icon. Default title: "Stop". 

MsgStop( "Invalid data entered", "Validation Error" )

MsgYesNo()

MsgYesNo( cMessage [, cTitle ] ) --> lYes

Displays a Yes/No question dialog. Returns .T. if the user clicks Yes, .F. for No. 

if MsgYesNo( "Are you sure you want to delete this record?" )
   oDb:Delete()
endif

MsgNoYes()

MsgNoYes( cMessage [, cTitle ] ) --> lYes

Same as MsgYesNo() but with "No" as the default (focused) button.

MsgGet()

MsgGet( cTitle, cPrompt, @cValue [, cPicture ] ) --> lOk

Displays an input dialog with a GET field. Returns .T. if the user clicks OK. The value is returned by reference in cValue. 

local cName := Space( 40 )
if MsgGet( "Input", "Enter your name:", @cName )
   ? "Name:", Trim( cName )
endif

Alert()

Alert( cMessage [, aButtons ] ) --> nButton

Standard Harbour alert function, enhanced by FiveWin to display a GUI dialog instead of a console alert. Returns the number of the button clicked (1-based). 

local nChoice := Alert( "Choose an action", { "Save", "Discard", "Cancel" } )
do case
   case nChoice == 1 ; SaveData()
   case nChoice == 2 ; // discard
   case nChoice == 3 ; // cancel
endcase

Language & Localization

FWString()

FWString( cEnglishText ) --> cLocalizedText

Returns the localized version of a string based on the current language setting. FiveWin includes translations for Spanish, French, German, Portuguese, Italian, Dutch, Russian, and many other languages. 

? FWString( "Save" )   // "Guardar" (if Spanish)
? FWString( "Cancel" ) // "Annuler" (if French)

FWSetLanguage()

FWSetLanguage( cLang [, hCustomStrings ] ) --> cPrevLang

Set the application language. Built-in values include: "EN" (English), "ES" (Spanish), "FR" (French), "DE" (German), "PT" (Portuguese), "IT" (Italian), "NL" (Dutch), "RU" (Russian), "PL" (Polish), "CZ" (Czech), "SK" (Slovak), "HR" (Croatian), "HU" (Hungarian), "RO" (Romanian), "BG" (Bulgarian), "TR" (Turkish), "ZH" (Chinese), "JA" (Japanese), "KO" (Korean), "AR" (Arabic). 

FWSetLanguage( "ES" )  // Switch to Spanish

File & Directory Dialogs

cGetFile()

cGetFile( cFilter, cTitle [, nFilterIndex [, cInitDir [, lMulti [, nFlags ] ] ] ] ) --> cFile

Displays an Open File dialog. Returns the selected file path, or empty string if cancelled. 

local cFile

cFile := cGetFile( "DBF Files (*.dbf)|*.dbf|All Files (*.*)|*.*", ;
                   "Select Database" )

if ! Empty( cFile )
   ? "Selected:", cFile
endif

// Multiple file selection
cFile := cGetFile( "Images|*.jpg;*.png;*.bmp", "Select Images",,,  .T. )
// Returns files separated by CRLF

cPutFile()

cPutFile( cFilter, cTitle [, nFilterIndex [, cInitDir [, cDefFile ] ] ] ) --> cFile

Displays a Save File dialog. Returns the selected path, or empty string if cancelled. 

local cFile := cPutFile( "PDF Files (*.pdf)|*.pdf", "Save Report As" )
if ! Empty( cFile )
   SaveReport( cFile )
endif

cGetDir()

cGetDir( [cTitle [, cInitDir ] ] ) --> cDir

Displays a folder picker dialog. Returns the selected directory path. 

local cDir := cGetDir( "Select output folder" )
if ! Empty( cDir )
   SetErrorPath( cDir )
endif

Conversion Functions

cValToChar()

cValToChar( uValue ) --> cString

Converts any Harbour value to its character string representation. Works with numeric, date, logical, array, hash, nil, and object types. 

? cValToChar( 42 )           // "42"
? cValToChar( .T. )          // ".T."
? cValToChar( Date() )       // "03/24/2026"
? cValToChar( nil )          // "NIL"
? cValToChar( { 1, 2, 3 } ) // "{ 1, 2, 3 }"

nLoWord() / nHiWord()

nLoWord( nDWord ) --> nWord
nHiWord( nDWord ) --> nWord

Extract the low-order or high-order 16-bit word from a 32-bit value. Essential for processing Windows messages where wParam/lParam pack two values. 

// In a WM_SIZE handler:
local nWidth  := nLoWord( nLParam )
local nHeight := nHiWord( nLParam )

Date/Time Functions

FW_ADDMONTH()

FW_ADDMONTH( tDate, nMths ) --> tDateTime

Adds a number of months to a date or datetime value. Handles year boundaries and end-of-month adjustments automatically. 

? FW_ADDMONTH( CTOD( "01/15/2026" ), 3 )  // 04/15/2026
? FW_ADDMONTH( CTOD( "01/31/2026" ), 1 )  // 02/28/2026 (end-of-month adjusted)

FW_YMDLAPSED()

FW_YMDLAPSED( dFrom, dLast ) --> { nYears, nMonths, nDays }

Returns the elapsed time between two dates as an array of years, months, and days. Useful for calculating age or tenure in a human-readable format. 

local aLapsed := FW_YMDLAPSED( CTOD( "03/15/2020" ), Date() )
? "Years:", aLapsed[ 1 ], "Months:", aLapsed[ 2 ], "Days:", aLapsed[ 3 ]

FW_MTHSLAPSED()

FW_MTHSLAPSED( dDate1, dDate2 ) --> nMonths

Returns the number of complete calendar months between two dates. Unlike simple day-count division, this function respects calendar month boundaries. 

? FW_MTHSLAPSED( CTOD( "01/15/2026" ), CTOD( "04/20/2026" ) )  // 3

FW_AGE()

FW_AGE( dDob, dAsOn ) --> nAge

Calculates age in complete years from a date of birth, as of a given date. 

local nAge := FW_AGE( CTOD( "04/15/1980" ), Date() )
? "Age:", nAge

FW_NEXTBIRTHDAY()

FW_NEXTBIRTHDAY( dDob, dToday, lIncludeToday ) --> dDate

Returns the date of the next birthday from a date of birth, relative to a given date. If lIncludeToday is .T. and today is the birthday, returns today. 

local dNext := FW_NEXTBIRTHDAY( CTOD( "04/15/1980" ), Date() )
? "Next birthday:", dNext

FW_ADDTIME()

FW_ADDTIME( tDate, cTimeStr ) --> tDateTime

Adds a time duration string to a datetime value. The time string supports "HH:MM:SS" format and can span multiple days. 

local tStart := FW_ADDMONTH( Date(), 0 ) // today at midnight
local tEnd   := FW_ADDTIME( tStart, "02:30:00" )
? "Two and a half hours later:", tEnd

FW_DateToUnix()

FW_DateToUnix( tDateTime ) --> nMilliSecs

Converts a datetime value to Unix epoch milliseconds (milliseconds since 1970-01-01 00:00:00 UTC). Essential for API communication and timestamp arithmetic. 

local nMs := FW_DateToUnix( DateTime() )
? "Current epoch ms:", nMs

FW_UnixToDate()

FW_UnixToDate( nMilliSecs ) --> tDateTime

Converts Unix epoch milliseconds back to a datetime value. The inverse of FW_DateToUnix(). 

local tDate := FW_UnixToDate( 1713129600000 )
? "Date from epoch:", tDate

UTC_TIMESTAMP()

UTC_TIMESTAMP( dDateTime ) --> tDateTime

Converts a local datetime to Coordinated Universal Time (UTC). Applies the local timezone offset to produce the equivalent UTC datetime. 

local tUtc := UTC_TIMESTAMP( DateTime() )
? "UTC time:", tUtc

FW_UTCTOLOCAL()

FW_UTCTOLOCAL( tUtcTime ) --> tDateTime

Converts a UTC datetime back to local time. The inverse of UTC_TIMESTAMP(). 

local tLocal := FW_UTCTOLOCAL( tUtc )
? "Local time:", tLocal

FW_TIMEZONE()

FW_TIMEZONE() --> cTimezoneStr

Returns the local timezone offset as a formatted string, e.g. "+05:30" for India or "-05:00" for Eastern Standard Time. 

? "Timezone offset:", FW_TIMEZONE()  // e.g. "+05:30"

FW_SToT()

FW_SToT( cDateTime ) --> tDateTime

Converts a datetime string to a Harbour datetime value. Accepts various standard formats including "YYYY-MM-DD HH:MM:SS" and "MM/DD/YYYY HH:MM:SS". 

local t := FW_SToT( "2026-05-28 14:30:00" )
? "Parsed datetime:", t

FWVersion() --> cVersion

GetVersion() --> aVersion

hb_Compiler()

hb_Compiler() --> cCompiler

Returns the Harbour compiler version string.

IsExe64()

IsExe64() --> lIs64

Returns .T. if the current application is a 64-bit executable.

IsWinNT() / IsWin10() / IsWin11()

IsWinNT() --> lNT
IsWin10() --> lWin10

Detect the Windows version.

System Information Functions

ScreenWidth()

ScreenWidth() --> nPixels

Returns the full screen width in pixels. Useful for positioning windows and dialogs relative to the screen boundaries. 

local nW := ScreenWidth()
oWnd:SetSize( nW / 2, ScreenHeight() / 2 )

ScreenHeight()

ScreenHeight() --> nPixels

Returns the full screen height in pixels. Combines with ScreenWidth() for centering and sizing calculations.

ScreenScaling()

ScreenScaling() --> nScale

Returns the DPI scaling factor for the primary monitor. Returns 1.0 for 96 DPI (100%), 1.25 for 120 DPI (125%), 1.5 for 144 DPI (150%), etc. 

local nScale := ScreenScaling()
if nScale > 1.0
   MsgInfo( "High-DPI display detected: " + Str( nScale * 100, 3, 0 ) + "%" )
endif

IsWindows11()

IsWindows11() --> lBoolean

Returns .T. if the application is running on Windows 11. Checks the Windows build number (requires build 22000 or higher). 

if IsWindows11()
   // Apply Windows 11-specific styling
   oWnd:lWin11 := .T.
endif

IsWindows10()

IsWindows10() --> lBoolean

Returns .T. if the application is running on Windows 10.

IsWin64()

IsWin64() --> lBoolean

Returns .T. if running on a 64-bit version of Windows, regardless of whether the application itself is 32-bit or 64-bit. 

if IsWin64()
   ? "Running on 64-bit Windows"
endif

IsDarkTheme()

IsDarkTheme() --> lBoolean

Detects whether the Windows dark theme (personalization setting) is currently active. Useful for adapting application colors at runtime. 

if IsDarkTheme()
   SetAppColors( CLR_BLACK, CLR_WHITE )
else
   SetAppColors( CLR_WHITE, CLR_BLACK )
endif

FW_IsTouchScreen()

FW_IsTouchScreen() --> lBoolean

Returns .T. if the system has touch input capabilities. Useful for adapting UI to provide larger touch targets and gesture support. 

if FW_IsTouchScreen()
   oBtn:SetSize( 64, 48 )  // larger buttons for touch
endif

FW_IsMousePresent()

FW_IsMousePresent() --> lBoolean

Returns .T. if at least one mouse is connected to the system. Useful for touch-only devices where hover effects and right-click may not apply. 

if ! FW_IsMousePresent()
   // Enable touch-friendly navigation
   oWnd:SetTouchMode( .T. )
endif

GetCPUSpeed()

GetCPUSpeed() --> nMhz

Returns the approximate CPU speed in MHz. Uses Windows performance counters to estimate the processor clock frequency. 

? "CPU speed:", GetCPUSpeed(), "MHz"

FW_ActiveMonitors()

FW_ActiveMonitors() --> nCount

Returns the number of active monitors connected to the system. Useful for multi-monitor configuration and window placement. 

if FW_ActiveMonitors() > 1
   // Position window on secondary monitor
   oWnd:SetWindowPos(, 1920, 100, 800, 600 )
endif

cWinVersion()

cWinVersion() --> cVersion

Returns a human-readable Windows version string such as "Windows 11 Pro" or "Windows 10 Enterprise". Includes edition information when available. 

? "OS:", cWinVersion()

ScrResolution()

ScrResolution() --> { nWidth, nHeight }

Returns the screen resolution as an array of width and height in pixels. Similar to ScreenWidth()/ScreenHeight() but returns both in a single call. 

local aRes := ScrResolution()
oWnd:SetSize( aRes[ 1 ] * 0.75, aRes[ 2 ] * 0.75 )

WndCenterEx()

WndCenterEx( hWnd, hParent ) --> nil

Centers a window on the monitor where the parent window is currently displayed. Unlike the basic WndCenter(), this function correctly handles multi-monitor setups. 

WndCenterEx( hWnd, hParent )
// Centers the child window on the same monitor as its parent

Shell & Process Functions

ShellExecute()

ShellExecute( nHwnd, cOperation, cFile [, cParams [, cDir [, nShowCmd ] ] ] ) --> nResult

Execute or open a file using the Windows shell. Common operations: "open", "print", "explore", "runas". 

// Open a file with its default application
ShellExecute( 0, "open", "report.pdf" )

// Open a URL in the default browser
ShellExecute( 0, "open", "https://www.fivetechsoft.com" )

// Open Windows Explorer at a folder
ShellExecute( 0, "explore", "C:\data\" )

// Print a document
ShellExecute( 0, "print", "document.docx" )

// Run as administrator
ShellExecute( 0, "runas", "myapp.exe" )

WinExec()

WinExec( cCommandLine [, nShowCmd ] ) --> nResult

Execute a program. Simple alternative to ShellExecute for launching executables. 

WinExec( "notepad.exe C:\data\log.txt" )
WinExec( "calc.exe" )

File System Functions

lIsDir()

lIsDir( cDirName ) --> lBoolean

Checks whether the specified path is an existing directory. Returns .T. if the directory exists and is accessible. 

if ! lIsDir( "C:\data\backup" )
   lMkDir( "C:\data\backup" )
endif

lMkDir()

lMkDir( cPath ) --> lSuccess

Creates a directory. Returns .T. on success. Creates intermediate directories if needed (similar to mkdir -p). 

if lMkDir( "C:\data\reports\2026\may" )
   ? "Directory created successfully"
endif

cFilePath()

cFilePath( cPathMask ) --> cPath

Extracts the path portion from a full file path, excluding the filename. Includes the trailing backslash. 

? cFilePath( "C:\data\app\myfile.txt" )  // "C:\data\app\"

cFileNoPath()

cFileNoPath( cPathMask ) --> cFileName

Extracts the filename portion from a full file path, excluding the directory path. The inverse of cFilePath(). 

? cFileNoPath( "C:\data\app\myfile.txt" )  // "myfile.txt"

cFileNoExt()

cFileNoExt( cPathMask ) --> cName

Returns the filename without its extension. Removes everything after the last dot. 

? cFileNoExt( "C:\data\app\myfile.txt" )  // "C:\data\app\myfile"

cFileExt()

cFileExt( cPathMask ) --> cExt

Returns the file extension without the dot. The inverse of cFileNoExt(). 

? cFileExt( "myfile.txt" )  // "txt"
? cFileExt( "C:\data\app\myfile.dbf" )  // "dbf"

cNewFileName()

cNewFileName( cRootName, cExt ) --> cFileName

Generates a unique filename by appending a numeric suffix if the target file already exists. Useful for backup and export routines. 

local cName := cNewFileName( "backup", "zip" )
// Returns "backup.zip" or "backup_001.zip", "backup_002.zip", etc.

cTempFile()

cTempFile( cPath, cExtension ) --> cFileName

Creates a temporary file with a unique name in the specified directory. The file is created on disk but left empty for the caller to write. 

local cTmp := cTempFile( "C:\temp", "tmp" )
? "Temporary file:", cTmp

FSize()

FSize( cFile ) --> nFileSize

Returns the size of a file in bytes. Returns -1 if the file does not exist or cannot be accessed. 

local nBytes := FSize( "C:\data\largefile.dbf" )
? "File size:", nBytes, "bytes"
? "In KB:", nBytes / 1024

FDate()

FDate( cFile ) --> dFileDate

Returns the last-modified date of a file as a Harbour date value. 

local d := FDate( "C:\data\customer.dbf" )
? "Last modified:", d

FTime()

FTime( cFile ) --> cFileTime

Returns the last-modified time of a file as a character string in "HH:MM:SS" format. 

local cTime := FTime( "C:\data\customer.dbf" )
? "Last modified at:", cTime

ADrives()

ADrives( nType ) --> aDrives

Returns an array of available drive letters. The nType parameter filters by drive type: 0 = all drives, 1 = floppy drives, 2 = hard drives, 3 = network drives, 4 = CD/DVD drives, 5 = RAM drives. 

local aHD := ADrives( 2 )  // hard drives only
? "Fixed drives:"
AEval( aHD, { |c| QOut( c ) } )

FW_MEMOWRIT()

FW_MEMOWRIT( cFile, cText ) --> lSuccess

Writes text content to a file, overwriting any existing content. Returns .T. on success. A simplified wrapper around Harbour's MemoWrit(). 

if FW_MEMOWRIT( "C:\log\output.txt", "Process completed at " + Time() )
   ? "File written successfully"
endif

aFindFile()

aFindFile( cFileName, cPath ) --> aFiles

Recursively searches for files matching a pattern under the specified directory path. Returns an array of full file paths. 

local aPrgs := aFindFile( "*.prg", "C:\fwteam\source" )
? "Found " + LTrim( Str( Len( aPrgs ) ) ) + " PRG files"

Color Functions

GetSysColor()

GetSysColor( nIndex ) --> nRGBColor

Get a Windows system color. Common indices: COLOR_WINDOW (5), COLOR_WINDOWTEXT (8), COLOR_BTNFACE (15), COLOR_HIGHLIGHT (13), COLOR_HIGHLIGHTTEXT (14). 

local nBgColor := GetSysColor( 5 )  // Window background color

nRGB()

nRGB( nRed, nGreen, nBlue ) --> nRGBColor

Create an RGB color value from individual components (0-255 each).

local nRed   := nRGB( 255, 0, 0 )
local nGreen := nRGB( 0, 128, 0 )
local nBlue  := nRGB( 0, 0, 255 )
local nCustom := nRGB( 45, 52, 64 )  // dark gray-blue

Image & Drawing Functions

FW_ReadImage()

FW_ReadImage( oWnd, uSource, aResize ) --> aImageInfo

Loads an image from a file path, URL, resource identifier, or memory buffer. Returns an array: { hBitmap, hPalette, nWidth, nHeight, lAlpha, cName }. Supports BMP, PNG, JPG, GIF, and TIFF formats via GDI+. 

local aImg := FW_ReadImage( oWnd, "logo.png" )
if aImg[ 5 ]  // has alpha channel
   oBmp:SetBitmap( aImg[ 1 ] )
endif

FW_DrawImage()

FW_DrawImage( oWnd, hBmp, aRect, lTransp, nResize, nAlpha, lGray, cAlign )

Draws an image on a window or device context with optional resizing, alpha blending, grayscale conversion, and alignment (C = center, T = top, B = bottom, L = left, R = right). 

// Draw image centered and semi-transparent
FW_DrawImage( oWnd, hBmp, { 10, 10, 210, 210 }, .F., 0, 128, .F., "C" )

FW_SaveImage()

FW_SaveImage( uImage, cFile, nJpegQuality )

Saves an image (handle or image array) to a file. The output format is determined by the file extension: BMP, PNG, JPG, GIF, or TIFF. The nJpegQuality parameter (1-100) controls JPEG compression quality. 

FW_SaveImage( hBitmap, "thumbnail.jpg", 85 )

FW_SaveThumbNail()

FW_SaveThumbNail( cImage, cThumb, nWidth, nHeight ) --> lSuccess

Creates a thumbnail image from a source image file, saving it to the specified path. Maintains aspect ratio while fitting within the given dimensions. 

FW_SaveThumbNail( "photo.jpg", "thumb.jpg", 150, 150 )

FW_ImageToBLOB()

FW_ImageToBLOB( uImage, cType, nQuality ) --> cBuffer

Converts an image to a binary BLOB (memory buffer) suitable for storing in a database field. The cType parameter specifies the output format ("JPG", "PNG", "BMP", "GIF"). 

local cBlob := FW_ImageToBLOB( hBmp, "JPG", 80 )
oRs:Fields( "photo" ):Value := cBlob

FW_TextToBitmap()

FW_TextToBitmap( cText, oFont, nClrText, nClrBack ) --> hBitmap

Renders text to a bitmap handle using the specified font and colors. Useful for creating image-based labels, watermarks, or text overlays. 

local hBmp := FW_TextToBitmap( "Hello World", oFont, nRGB( 255,0,0 ), CLR_WHITE )

FW_BarCodeBmp()

FW_BarCodeBmp( cText, cType, nWidth, nHeight ) --> hBitmap

Generates a barcode bitmap from text data. Supported barcode types include "EAN13", "CODE128", "CODE39", "UPCA", "QR", and more. 

local hBmp := FW_BarCodeBmp( "123456789012", "EAN13", 200, 60 )
oImage:SetBitmap( hBmp )

FW_DrawShadow()

FW_DrawShadow( hDC, aRect, nSize, nAlpha )

Draws a drop shadow effect around a rectangle on the given device context. The nSize parameter controls shadow width and nAlpha (0-255) controls opacity. 

FW_DrawShadow( hDC, { 10, 10, 300, 200 }, 8, 80 )

DrawProgressBar()

DrawProgressBar( hDC, aRect, nValue, nTotal, aColors )

Draws a custom progress bar on the specified device context. The aColors array can specify bar and background colors. 

DrawProgressBar( hDC, { 10, 10, 310, 30 }, 65, 100, { CLR_GREEN, CLR_GRAY } )

FW_PieChart()

FW_PieChart( oWnd, aRect, aValues, aColors )

Draws a pie or donut chart on the specified window within the given rectangle. The aValues array holds numeric data and aColors provides segment colors. 

FW_PieChart( oWnd, { 10, 10, 310, 310 }, { 30, 50, 20 }, ;
             { CLR_RED, CLR_BLUE, CLR_GREEN } )

GradientFill()

GradientFill( hDC, nTop, nLeft, nBottom, nRight, aGradInfo, lVert )

Fills a rectangular area with a gradient. The aGradInfo parameter specifies color stops. Set lVert to .T. for vertical gradient or .F. for horizontal. 

GradientFill( hDC, 0, 0, 100, 300, { { CLR_BLUE, CLR_CYAN } }, .T. )

FW_SayText()

FW_SayText( oWnd, cText, aRect, cAlign, oFont, nClrText, nClrBack )

Draws text on a window or DC with alignment control. The cAlign parameter supports "C" (center), "L" (left), "R" (right), "T" (top), "B" (bottom), "W" (word-wrap), and combinations like "TL" or "CR". Supports basic RTF formatting. 

FW_SayText( oWnd, "Hello", { 10, 10, 200, 50 }, "CR", oFont, CLR_RED, CLR_WHITE )

CalcTextWH()

CalcTextWH( oWnd, cText, hFont ) --> { nWidth, nHeight }

Calculates the pixel dimensions of a text string when rendered with the given font. Useful for layout calculations before drawing. 

local aSize := CalcTextWH( oWnd, "Sample Text", oFont:Handle() )
? "Text width:", aSize[ 1 ], "Height:", aSize[ 2 ]

WebPageContents()

WebPageContents( cUrl, lText ) --> cResponse

Downloads the contents of a URL. When lText is .T., returns text-only content (stripping HTML tags). When .F., returns the raw HTML. Uses WinHTTP for the request. 

local cHtml := WebPageContents( "https://www.fivetechsoft.com", .F. )
local cText := WebPageContents( "https://www.fivetechsoft.com", .T. )

Network & Internet Functions

IsInternet()

IsInternet() --> lYesNo

Detects if there is internet access by resolving "microsoft.com" via DNS. Returns .T. if the hostname resolves to a valid IP address. 

if IsInternet()
   ? "Internet available"
else
   MsgAlert( "No internet connection detected" )
endif

LocalIP()

LocalIP() --> cIP

Returns the local computer's IP address by resolving its hostname. 

? "Local IP:", LocalIP()  // e.g. "192.168.1.10"

PublicIP()

PublicIP() --> cIP

Returns the public (internet-facing) IP address by querying an external web service. 

? "Public IP:", PublicIP()  // e.g. "203.0.113.45"

IsLocalIP()

IsLocalIP( cIP ) --> lLocal

Checks whether an IP address belongs to a private or local range. Recognizes class A (10.x.x.x), class B (172.16-31.x.x), class C (192.168.x.x), loopback (127.x.x.x), and link-local (169.254.x.x) addresses. 

? IsLocalIP( "192.168.1.1" )   // .T.
? IsLocalIP( "8.8.8.8" )       // .F.
? IsLocalIP( "127.0.0.1" )     // .T.

IsExternalIP()

IsExternalIP( cIP ) --> lExternal

Returns .T. if the IP address is a valid, non-local (public) address. Combines format validation with IsLocalIP(). 

? IsExternalIP( "8.8.8.8" )       // .T.
? IsExternalIP( "192.168.1.1" )   // .F.

Data Format & Conversion Functions

cValToStr()

cValToStr( uVal, cPic ) --> cString

Converts any Harbour value to a formatted string. The cPic parameter accepts date/time masks like "dd/mm/yyyy hh:mi:ss" and "dddd, mmmm dd, yyyy", making it more flexible than cValToChar(). 

? cValToStr( Date(), "dddd, mmmm dd, yyyy" )  // "Thursday, May 28, 2026"
? cValToStr( 1234.56, "999,999.99" )            // "  1,234.56"
? cValToStr( .T., "Yes/No" )                    // "Yes"

FW_TRANSFORM()

FW_DbfToArray()

FW_DbfToArray( cAlias, bFor, bWhile, nNext, nRecNo, lRest ) --> aData

Copies records from a DBF work area into a 2D array. Supports scope filtering via FOR/WHILE conditions, NEXT n, record number, or REST scope (SET FILTER-compatible). Returns an empty array if no records match.

Writes data from a 2D array into a DBF file. The cAlias parameter specifies the target alias and file. When lOverWrite is .T., replaces existing data; otherwise appends.

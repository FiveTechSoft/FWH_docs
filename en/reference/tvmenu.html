TVMenu

Source: source/classes/VMenu.prg

Inherits from: TControl

TVMenu is an ExplorerBar-style panel control that displays a list of TVItem objects. It supports a collapsible title header, open/close animation, multiple selection styles (SOLID, INSET, XBOX, BUMP, ETCHED, RAISED, UNDERLINE), gradient backgrounds, and theme-aware rendering. TVMenu is the parent container for TVItem objects, which are automatically added to the menu's aItems array when created.

Example

local oMenu, oItem

oMenu := TVMenu():New( 0, 0, 220, 380, oWnd, ;
         {|| MsgInfo("Action") }, ;
         RGB(55,65,80), RGB(245,246,248), ;
         oFont, .t., RGB(220,224,230), ;
         0, , "SOLID", 5, , 1, "FILLED" )

oMenu:SetTitle( "Explorer", 28, oFont, ;
                RGB(255,255,255), RGB(70,130,180), ;
                , 50, .f., , , , , , .t., 17 )

oItem := TVItem():New( oMenu, "Home" )
oItem:SetImage( hBmp )

oItem := TVItem():New( oMenu, "Documents" )
oItem:SetImage( hBmp2 )

TRDD / TRDDODBC

Source: source/classes/trdd.prg, source/classes/trddodbc.prg

TRDD is a standalone base class. TRDDODBC inherits from: TRDD

TRDD is a virtual RDD (Replaceable Database Driver) base class that delegates RDD operations to code blocks. TRDDODBC extends TRDD to provide an ODBC-backed RDD, allowing standard USE, SKIP, APPEND, SEEK, and field access commands against ODBC data sources. It registers as the "ODBC" RDD via RddRegister.

Example: USE Table via ODBC RDD

#include "FiveWin.ch"

function Main()

   local oRdd := TRDDODBC():New( "MyDSN", "user", "pass" )

   REQUEST ODBC

   USE customers VIA "ODBC" ALIAS CUST

   DO WHILE ! CUST->( Eof() )
      ? CUST->Name, CUST->City
      CUST->( Skip() )
   ENDDO

   CUST->( dbCloseArea() )
   oRdd:End()

return nil

Notes

  • TRDD is a code-block-driven virtual RDD. Override any b* block to customize behavior without subclassing.
  • TRDDODBC registers itself as RDD "ODBC" and uses TOdbc internally for database communication.
  • Work areas are managed via the aDbOdbc array (255 slots). Each open table creates a TDbOdbc instance.
  • Several VIRTUAL methods on TRDD (e.g., Pack, Recall, Lock, UnLock, FieldInfo, OrdCreate) return default nil and can be overridden in subclasses.

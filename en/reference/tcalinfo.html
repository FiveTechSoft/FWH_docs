TCalInfo

Source: source/classes/calinfo.prg

Inherits from: TControl

TCalInfo represents a calendar appointment or item displayed within a TCalex calendar control. It manages the visual appearance, temporal range, and selection state of individual calendar entries, supporting gradient-colored items across day, week, and month views.

Key DATA Members

DATATypeDescription
nStart / nEndNumericStart and end time offsets within the day (in minutes)
dStart / dEndDateStart and end dates for multi-day appointments
cTextCharacterDisplay text for the appointment item
cSubjectCharacterSubject or title of the appointment
aGradColorArrayGradient color array for the item background
aGradColorND / aGradColorAp / aGradColorBTArrayGradient colors for non-displayed, appointment, and business time states
lSelectedLogicalSelection state of the appointment
oCalexObjectParent TCalex calendar control

Methods

MethodDescription
New( oCalex, nStart, nEnd, dStart, dEnd, cText, cSubject )Create a new calendar item with temporal bounds and display text
BuildDates( nTop, nLeft, nW, nH )Compute the visual rectangle for the item within the calendar grid
Move()Reposition the item in response to calendar scrolling or resize
Paint()Paint the item in the default calendar view
PaintOnMonth()Paint the item within the month overview grid
PaintOnWeek()Paint the item within the week/day view
Show() / Hide()Show or hide the calendar item

Example: Create Appointment

#include "FiveWin.ch"

function Main()

   local oCalex, oAppt

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 800, 600

   oCalex := TCalex():New( oWnd )

   oAppt := TCalInfo():New( oCalex, ;
      540, 600, ;              // 9:00 AM to 10:00 AM
      dDate(), dDate(), ;      // Today only
      "Team Meeting", "Weekly sync" )

   oAppt:aGradColor := { CLR_BLUE, CLR_CYAN }
   oAppt:Show()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Time values (nStart, nEnd) are expressed in minutes from midnight (0 to 1439).
  • Multi-day appointments use dStart and dEnd date values spanning the event duration.
  • Gradient arrays contain two numeric color values for the start and end gradient stops.
  • The parent TCalex control dispatches paint calls to the appropriate view method (PaintOnMonth, PaintOnWeek, or Paint) based on the current display mode.

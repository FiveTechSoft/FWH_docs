TMenu

Source: source/classes/menu.prg

Standalone class (not control-based)

TMenu is the FiveWin menu system. It manages both popup menus and system menus, supporting modern Office themes (2007/2010/2013/2015), keyboard accelerators, and MDI menu merging. Menus can be created programmatically via commands or from dialog resources.

Menu Commands

Menus are most commonly defined using the MENU / MENUITEM command syntax: 

MENU oMenu
   MENUITEM "&File"
      MENU oSub
         MENUITEM "&Open"   ACTION oWnd:Open()
         MENUITEM "&Save"   ACTION oWnd:Save()
         SEPARATOR
         MENUITEM "E&xit"   ACTION oWnd:End()
      ENDMENU
   MENUITEM "&Help"
      MENU oSub
         MENUITEM "&About"  ACTION MsgInfo( "My App v1.0" )
      ENDMENU
ENDMENU

Example: Popup Menu

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu

   DEFINE WINDOW oWnd TITLE "TMenu Demo"

   // Create a popup context menu
   MENU oMenu POPUP
      MENUITEM "Cut"    ACTION MsgInfo( "Cut" )
      MENUITEM "Copy"   ACTION MsgInfo( "Copy" )
      MENUITEM "Paste"  ACTION MsgInfo( "Paste" )
      SEPARATOR
      MENUITEM "Delete" ACTION MsgInfo( "Delete" )
   ENDMENU

   // Assign to window as popup on right-click
   oWnd:bRClicked := { |nRow, nCol| oMenu:Activate( nRow, nCol, oWnd ) }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Popup menus are positioned at screen coordinates using Activate( nRow, nCol, oWnd ). The row and column values come from the bRClicked event block.
  • The l2007, l2010, l2013, and l2015 flags enable themed menu rendering. Only one should be active at a time.
  • Use oAccTable to define keyboard accelerators (shortcut keys) for menu items.
  • For MDI applications, AddMdi() handles automatic menu merging when child windows are activated.

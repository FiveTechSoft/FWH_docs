GPT2Model - Inferencia de GPT-2 preentrenado en FWH

Fuente: source/classes/gpt2model.prg (sobre FW_Tensor, source/function/fwtensor.c)

GPT2Model ejecuta GPT-2 preentrenado real enteramente en FWH/Harbour en la CPU. Carga los pesos reales de GPT-2 desde un model.safetensors de HuggingFace y corre el forward pass completo — embeddings de token + posición, pre-norm, atención causal multi-cabeza, MLP GELU, residuales, norm final y cabeza de salida con pesos atados — todo sobre el backend plano FW_Tensor. Es la Fase 3 de la hoja de ruta PyTorch-lite, verificada numéricamente contra una referencia ("The capital of France is" → " the", token 262).

Obtener los pesos

Descarga GPT-2 small del Hub de HuggingFace (no se distribuye con FWH): https://huggingface.co/gpt2/resolve/main/model.safetensors (~500 MB, 124M params) más tokenizer.json para HFTokenizer. Los pesos se leen un tensor a la vez con FWT_LoadSafe (sin cargar todo el archivo), así el pico de memoria son los pesos float32 (~500 MB), que caben en un proceso de 32 bits.

Métodos

MétodoDescripción
New( n_layer, n_head, n_embd, vocab, n_ctx )Configura la arquitectura. Por defecto GPT-2 small (12, 12, 768, 50257, 1024).
LoadSafetensors( cFile )Parsea la cabecera safetensors y carga cada tensor de pesos en FW_Tensors.
Forward( aTok )Ejecuta el forward para una secuencia de tokens (ids de gather base 1). Devuelve logits [seq, vocab].
Generate( aTok, nNew, nTemp, nTopK )Generación autorregresiva (greedy / temperatura / top-k). Devuelve la secuencia completa de ids base 1.

Los ids son base 1 para el gather (id base 0 de HuggingFace + 1); reconvierte con id - 1 antes de decodificar.

Ejemplo

oTok := HFTokenizer():New( "gpt2.tokenizer.json" )
oM   := GPT2Model():New()                       // por defecto GPT-2 small
oM:LoadSafetensors( "model.safetensors" )

aIds := oTok:Encode( "The capital of France is" )   // ids HF base 0
aTok := {} ; AEval( aIds, { |n| AAdd( aTok, n + 1 ) } )

aOut := oM:Generate( aTok, 8, 0.0001, 1 )            // greedy, 8 tokens
aHF  := {} ; AEval( aOut, { |n| AAdd( aHF, n - 1 ) } )
? oTok:Decode( aHF )    // "The capital of France is the capital of the French Republic, and"

Notas

  • Sólo inferencia (sin entrenamiento) — no necesita autograd.
  • La velocidad la limita el matmul ingenuo; un backend BLAS (Fase 2 de la hoja de ruta) haría rápidas las generaciones largas. Aún no hay KV cache, así que cada paso recomputa la ventana (O(n²)).
  • Para modelos mayores/cuantizados, la vía pragmática es bindear llama.cpp (Pista C de la hoja de ruta) en vez de escalar este camino desde cero.
  • Test/demo: samples/ai/gpt2test.prg.

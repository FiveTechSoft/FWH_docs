Red Neuronal Transformer

Fuente: source/classes/transformer.prg, source/function/matrixes.c, source/function/matrices.prg

FiveWin proporciona una implementación pura en Harbour/C de la arquitectura Transformer de solo codificador (encoder-only) para clasificación de secuencias y modelado de lenguaje. La implementación incluye autoatención multi-cabeza (multi-head self-attention), redes feed-forward, normalización de capas y optimizadores Adam/SGD. Todo el álgebra lineal intensiva se acelera mediante extensiones en C en matrixes.c.

Arquitectura

flowchart LR Input[Tokens de Entrada] --> Embed[Búsqueda de Embedding] Embed --> Pos[Codificación Posicional] Pos --> MHA[Atención Multi-Cabeza] MHA --> Add1[+ Residual] Add1 --> LN1[Normalización de Capa] LN1 --> FF[Feed Forward] FF --> Add2[+ Residual] Add2 --> LN2[Normalización de Capa] LN2 --> Pool[Pooling Promedio] Pool --> Proj[Proyección W_vocab] Proj --> SM[Softmax] SM --> Output[Probabilidades de Salida]

Clases

Transformer

La clase de nivel superior que orquesta los embeddings, la codificación posicional, las capas apiladas y la proyección de salida.

MétodoDescripción
New( num_layers, d_model, n_heads, vocab_size, max_seq_len, hEmbeddings, aVocab )Crea un Transformer con la arquitectura indicada. Inicializa todas las subcapas y los embeddings.
Forward( src_indices, pos_indices )Ejecuta una pasada hacia adelante: búsqueda de embedding, codificación posicional, N bloques transformer, pooling promedio y softmax sobre el vocabulario.
Backward( d_output, targets, src_indices, pos_indices )Retropropaga los gradientes a través de todas las capas y acumula los gradientes de los pesos.
zero_grad()Reinicia a cero todos los gradientes acumulados.

MultiHeadAttention

Calcula la atención por producto escalar escalado (scaled dot-product) sobre múltiples cabezas. Proyecta las entradas en los espacios Query, Key y Value mediante matrices aprendidas, calcula las puntuaciones de atención y concatena las salidas de las cabezas.

FeedForward

Un MLP de dos capas por posición con activación ReLU que opera sobre cada posición de forma independiente: FF(x) = W2 * ReLU(W1 * x + b1) + b2.

LayerNorm

Aplica normalización de capa a lo largo de la dimensión de características: y = (x - mean) / sqrt(var + eps) * gamma + beta.

Optimizer_Adam

Optimizador de Estimación Adaptativa de Momentos (Adaptive Moment Estimation). Mantiene estimaciones del primer (m) y segundo (v) momento con corrección de sesgo. Utiliza la función acelerada en C hb_AdamUpdate() para actualizaciones eficientes de parámetros.

Optimizer_SGD

Descenso de Gradiente Estocástico (Stochastic Gradient Descent) con momento opcional para escenarios de entrenamiento más simples.

Operaciones de Matrices (Extensiones en C)

El archivo matrixes.c proporciona álgebra lineal de alto rendimiento expuesta a Harbour como envoltorios HB_FUNC:

FunciónDescripción
hb_MatrixMultiply( A, B )Multiplicación estándar de matrices (MxN * NxP = MxP)
hb_Softmax( logits )Softmax por filas con estabilidad numérica (resta del máximo)
hb_ReLU( M )Unidad Lineal Rectificada: max(0, x) elemento a elemento
hb_AdamUpdate( W, dW, m, v, t, lr, beta1, beta2, eps )Paso de actualización de parámetros del optimizador Adam con corrección de sesgo
hb_MatrixTranspose( M )Transpone la matriz (intercambia filas y columnas)
hb_Matrix3DAdd( A, B )Suma elemento a elemento para tensores 3D (batch x seq x dim)
hb_Matrix3DAvg( X )Pooling promedio sobre la dimensión de secuencia
hb_Matrix3DExpand( M, n )Expande el gradiente 2D a 3D para la retropropagación a través de la secuencia

Clase FW_Matrix

La clase FW_Matrix en matrices.prg proporciona un envoltorio de alto nivel para la manipulación de matrices con sobrecarga de operadores de Harbour: 

oM1 := FW_Matrix():New( { { 1, 2 }, { 3, 4 } } )
oM2 := FW_Matrix():New( { { 5, 6 }, { 7, 8 } } )
oResult := oM1 * oM2   // sobrecarga de operadores mediante la palabra clave OPERATOR
oResult:View()         // mostrar en una rejilla TXBrowse

Flujo de Entrenamiento

Un bucle de entrenamiento típico sigue estos pasos:

  1. Pasada hacia adelante: llama a oTransformer:Forward( src_indices, pos_indices ) para obtener las distribuciones de probabilidad.
  2. Cálculo de la pérdida: calcula la pérdida de entropía cruzada entre las predicciones y los tokens objetivo.
  3. Pasada hacia atrás: llama a oTransformer:Backward( d_output, targets, src_indices, pos_indices ) para propagar los gradientes.
  4. Paso del optimizador: usa Optimizer_Adam:Step( oTransformer ) u Optimizer_SGD:Step( oTransformer ) para actualizar los pesos.
  5. Gradientes a cero: llama a oTransformer:zero_grad() antes de la siguiente iteración.

Ejemplo: Clasificación de Sentimiento

El ejemplo samples/ai/transf2.prg extiende el Transformer con una cabeza de clasificación para análisis de sentimiento binario (Positivo/Negativo): 

#include "FiveWin.ch"

CLASS CustomTransformer INHERIT Transformer
   DATA W_proj, b_class, dW_proj, db_class, last_probs

   METHOD New( num_layers, d_model, n_heads, vocab_size, max_seq_len, ;
               hEmbeddings, aVocab, num_classes )
   METHOD ForwardClassification( src_indices, pos_indices )
   METHOD BackwardClassification( d_loss, train_src, train_pos )
   METHOD UpdateWeights( learningRate )
ENDCLASS

METHOD New( ... ) CLASS CustomTransformer
   ::Super:New( num_layers, d_model, n_heads, vocab_size, max_seq_len, ;
                hEmbeddings, aVocab )
   ::W_proj   := hb_MatrixRandom( vocab_size, num_classes )
   ::b_class  := hb_MatrixZero( 1, num_classes )
   ::dW_proj  := hb_MatrixZero( vocab_size, num_classes )
   ::db_class := hb_MatrixZero( 1, num_classes )
RETURN Self

// Forward de clasificación: forward del padre + proyección W_proj + softmax
METHOD ForwardClassification( src_indices, pos_indices ) CLASS CustomTransformer
   LOCAL probs := ::Forward( src_indices, pos_indices )
   ::last_probs := probs
   LOCAL logits := hb_MatrixMultiply( probs, ::W_proj )
   // Añadir sesgo (bias)
   AEval( logits, { |row, i| row[ 1 ] += ::b_class[ 1 ][ 1 ] } )
   AEval( logits, { |row, i| row[ 2 ] += ::b_class[ 1 ][ 2 ] } )
RETURN hb_Softmax( logits )

// Bucle de entrenamiento
oTransformer := CustomTransformer():New( 1, 6, 2, 8, 5, NIL, vocab, 2 )
FOR e := 1 TO 50
   FOR i := 1 TO Len( trainSrc )
      pred := oTransformer:ForwardClassification( { trainSrc[ i ] }, ;
                                                   { trainPos[ i ] } )
      loss := CrossEntropyLoss( pred, { trainLabels[ i ] } )
      oTransformer:BackwardClassification( loss[ 2 ], ;
                                           { trainSrc[ i ] }, { trainPos[ i ] } )
      oTransformer:UpdateWeights( 0.01 )
   NEXT
NEXT

Entrena con frases como "buen dia" (Positivo) y "malo trabajo" (Negativo) usando un vocabulario de 8 tokens y 50 épocas de entrenamiento.

Notas

  • La codificación posicional sinusoidal se precalcula en la inicialización por eficiencia.
  • Las conexiones residuales usan hb_Matrix3DAdd (acelerada en C) para evitar la sobrecarga de los bucles de Harbour.
  • El Softmax en C resta el máximo de la fila antes de la exponenciación para evitar el desbordamiento de coma flotante.
  • Demos visuales de entrenamiento: samples/ai/transformer.prg (GUI) y samples/ai/transf1.prg (interactivo).

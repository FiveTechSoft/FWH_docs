Class Agent

Fuente: source/classes/agent.prg

source\classes\agent.prg

An autonomous AI coding agent for Harbour/FiveWin. Implements the same motor agentic que impulsa Agents Web: chat streaming, herramientas reales, tools dinámicas, skills y multi-agente vía hb_threadStart().

Métodos Principales

New( cKey, [cModel] ) → Agent

Constructor. Inicializa tools, skills, carga estado guardado. Modelo por defecto: deepseek-v4-pro.

Run( cPrompt ) → lastAssistantMessage

Bucle principal: observar → decidir → actuar. Máx nMaxSteps iteraciones (defecto 14). Devuelve la última respuesta de texto. Las tool calls intermedias se ejecutan y sus resultados se incorporan a la conversación.

Step() → cResponse

Envía la conversación actual a DeepSeek (POST api.deepseek.com/chat/completions), devuelve la respuesta bruta. Actualiza métricas de tokens. Es el RPC central del LLM.

BuildSystemPrompt()

Construye el system prompt: instrucciones base + skills activos + lista de user tools + objetivo/plan.

BuildToolsArray() → aTools

Devuelve el array completo de tools en formato OpenAI (integrado + usuario) para la petición LLM.

Skills

MethodDescription
CreateSkill(cName,cContent,[cDir])Escribe archivo skill en skills/name.md
ToggleSkill(cName,lOn)Activa/desactiva sin borrar el archivo

5 skills integrados: reviewer, summarizer, refactor, documenter, tester. Los skills inyectan instrucciones reutilizables en el system prompt. Moldean CÓMO piensa el agente, no QUÉ puede hacer (eso lo manejan las tools).

Multi-Agente

DispatchAgents( aTasks, cContract ) → aResults

Lanza hasta 4 sub-agentes en paralelo vía hb_threadStart(). Cada sub-agente:

  • Tiene su propia instancia Agent (mismo modelo, misma API key)
  • Accede a todas las tools excepto dispatch_agents y ask_user (sin recursión)
  • Tiene límite de pasos reducido (5)
  • Recibe el cContract antepuesto a su prompt para consistencia
Resultados recolectados vía hb_threadJoin(). Requiere Harbour MT VM (libhbvmmt).

SubAgentRun( cTask, cContract ) → cResult

Ejecución individual de sub-agente. Llamado por DispatchAgents() en su propio hilo.

Planificación

GeneratePlan( cGoal ) → aPlan

Pide al LLM que divida el objetivo en 3-6 pasos JSON. Devuelve un array de {title, state} donde el primer paso está "active" y el resto "pending".

ExecutePlan()

Ejecuta el plan secuencialmente: para cada paso "active", llama a Run() con la descripción, lo marca "done", activa el siguiente. Para cuando todos están completos.

Persistencia

MethodDescription
SaveState(cDir)Guarda user tools y skills activos en user_tools.json
LoadState(cDir)Restaura del disco al iniciar. También carga skills del directorio skills/.

Ejemplo Completo

PROCEDURE Main()
   LOCAL oAgent, cResult

   oAgent := Agent():New( "sk-xxxx" )

   // Registrar una tool personalizada
   oAgent:RegisterTool( "contar", ;
      "Cuenta lineas, palabras y caracteres de un archivo", ;
      "contar.py" )

   // Crear y activar un skill
   oAgent:CreateSkill( "prueba", ;
      "Responde siempre en español." + CRLF + ;
      "Verifica el disco antes de escribir código." + CRLF + ;
      "Escribe tests automáticamente." )
   oAgent:ToggleSkill( "prueba", .T. )

   // Generate and execute a plan
   oAgent:GeneratePlan( "Crea una app TODO en PHP+SQLite" )
   oAgent:ExecutePlan()

   // Or run directly
   cResult := oAgent:Run( "Explica qué hay en el disco" )
   ? cResult

   oAgent:UsageReport()
RETURN

Notas

  • Requiere Harbour MT VM para DispatchAgents(). Enlazar contra libhbvmmt.
  • API Key: configurar vía variable de entorno DEEPSEEK_API_KEY o constructor.
  • Streaming: streaming token a token vía SSE está planeado pero no implementado aún.
  • Contrato: el parámetro cContract en DispatchAgents() es crítico. Sin él, los sub-agentes paralelos divergen en convenciones de nombres. Proporciona siempre nombres exactos de tablas, columnas, funciones y rutas de archivos.
  • Ejemplo: samples\agenticai\agenticai2.prg — una app FiveWin GUI completa usando la Class Agent con panel de chat TWebView2.

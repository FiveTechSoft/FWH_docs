THFTask y TChatAgent - utilidades FWAI

Fuente: source/classes/thftask.prg, source/classes/tchatagent.prg

Dos clases utilitarias "FWAI" que llevan tareas de IA cotidianas a las apps FiveWin en pocas líneas — ver la hoja de ruta PyTorch-lite.

THFTask — tareas NLP de HuggingFace

Una clase fina sobre la Inference API de HuggingFace para las tareas NLP comunes. Cada método hace POST al endpoint del modelo y devuelve valores Harbour normales.

MétodoDevuelve
Classify( cText [,cModel] ){ {label,score}, ... } descendente
ZeroShot( cText, aLabels [,cModel] ){ {label,score}, ... } con tus propias etiquetas
NER( cText [,cModel] ){ {entity,word,score}, ... }
Summarize( cText [,cModel] )cadena resumen
Translate( cText [,cModel] )cadena traducción (en→es por defecto)
Sentiment( cText [,cModel] ){ label, score } (top)
 
oT := THFTask():New()                            // usa HF_API_KEY
aCls := oT:Classify( "win a free prize now" )    // -> { {"spam",0.91}, {"ham",0.09} }
? oT:Summarize( cInformeLargo )
? oT:Translate( "Hello world" )                  // "Hola mundo"
aEnt := oT:NER( "John lives in Madrid" )         // PER John, LOC Madrid
aZ   := oT:ZeroShot( "mi factura está mal", { "facturación", "soporte" } )

El transporte es inyectable vía ::bSender { |cUrl, cJson| -> cResponseJson } — déjalo NIL para usar libcurl, o ponlo para simular respuestas (el test samples/ai/thftasktest.prg verifica el parsing offline) o enrutar por otra capa HTTP / un servidor local.

TChatAgent — chat sobre los datos de tu app

Un agente mínimo con tool-calling: el LLM responde, o pide a la app que ejecute una consulta; la app devuelve filas y el bucle continúa hasta que el LLM responde. Agnóstico de backend vía dos codeblocks.

flowchart LR U[Pregunta usuario] --> A[TChatAgent] A -->|prompt| L[LLM bChat] L -->|TOOL consulta| A A -->|ejecuta consulta| T[bTool → filas] T --> A L -->|ANSWER texto| R[Respuesta]
MétodoDescripción
New( bChat, bTool [,cSystem] )bChat = { |cPrompt| -> cReply } (LLM, p.ej. TOLlama o una clase API); bTool = { |cQuery| -> cResultText } (tú ejecutas la consulta DBF/SQL).
Ask( cQuestion )Ejecuta el bucle y devuelve el texto de respuesta final.
 
oLlm   := TOLlama():New( "llama3" )
oAgent := TChatAgent():New( ;
   { |cPrompt| oLlm:Send( cPrompt ), oLlm:GetValue() }, ;     // backend LLM
   { |cQuery|  RunMyQuery( cQuery ) } )                       // tu tool de datos
? oAgent:Ask( "¿cuántas facturas vencidas hay este mes?" )

Se instruye al LLM a responder TOOL <consulta> o ANSWER <texto>; los resultados se reinyectan como RESULT: <filas> hasta que responde (o nMaxSteps). Combínalo con TSemanticIndex para que el agente recupere registros relevantes. Test: samples/ai/chatagenttest.prg.

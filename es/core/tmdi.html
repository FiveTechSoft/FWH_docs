TMDI* (Clases MDI)

Fuentes: source/classes/mdiframe.prg, mdiclien.prg, mdichild.prg

Las tres heredan de: TWindow

El sistema MDI (Multiple Document Interface) consta de tres clases coordinadas: TMDIFrame (la ventana de marco principal), TMDIClient (el área cliente que gestiona las ventanas hijas) y TMDIChild (las ventanas hijas de documento individuales). Juntas proporcionan la experiencia MDI clásica de Windows con mosaico, cascada, organización de iconos y fusión de menús.

Ejemplo: marco MDI con dos ventanas hijas

#include "FiveWin.ch"

function Main()

   local oWnd, oChild1, oChild2

   DEFINE MDIFRAME oWnd TITLE "MDI Demo"

   DEFINE MDICHILD oChild1 TITLE "Document 1" OF oWnd
   @ 10, 10 SAY "First document" OF oChild1

   DEFINE MDICHILD oChild2 TITLE "Document 2" OF oWnd
   @ 10, 10 SAY "Second document" OF oChild2

   ACTIVATE MDIFRAME oWnd MAXIMIZED

return nil

Notas

  • Use DEFINE MDIFRAME ... TITLE cTitle para crear el marco. El marco crea automáticamente un TMDIClient y añade un submenú "Window" para la gestión de las ventanas hijas si no se proporciona ninguno.
  • Use DEFINE MDICHILD oChild OF oWnd TITLE cTitle para crear ventanas hijas. Se registran automáticamente con el TMDIClient mediante Add().
  • TMDIFrame reenvía las operaciones de portapapeles (Copy, Cut, Paste, Undo, Redo, Find, SelectAll) al control activo de la ventana hija activa.
  • Fusión de menús: cuando el marco se crea con un menú, el parámetro nMenuInfo especifica qué posición de submenú se convierte en la lista de ventanas.
  • El indicador lChildAutoSize de TMDIFrame hace que las nuevas ventanas hijas se abran maximizadas.

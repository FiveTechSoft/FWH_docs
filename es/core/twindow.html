TWindow

Clase Base Clase Raíz source/classes/window.prg

TWindow es la clase raíz de toda la jerarquía de clases de FiveWin. Todo elemento visible en una aplicación FiveWin — diálogos, controles, marcos MDI, ventanas hijas MDI — hereda en última instancia de TWindow. Encapsula un HWND de Win32 y proporciona la API fundamental para la creación de ventanas, manejo de eventos, pintado, gestión de coordenadas, arrastrar y soltar, tooltips y más.

Jerarquía de Herencia

TWindow se sitúa en la cima de la jerarquía. Todas las clases principales de FiveWin derivan de ella directa o indirectamente:

classDiagram class TWindow { +hWnd +cCaption +oMenu +oMsgBar +aControls +Activate() +End() +Center() } TWindow <|-- TMDIFrame TWindow <|-- TMDIChild TWindow <|-- TDialog TWindow <|-- TControl TControl <|-- TButton TControl <|-- TGet TControl <|-- TXBrowse TControl <|-- TSay TControl <|-- TFolder TMDIFrame : +oWndClient TMDIChild : +oWndParent TDialog : +lModal TDialog : +lTruePixel

Métodos Principales

New() — Constructor

METHOD New( nTop, nLeft, nBottom, nRight, cTitle, nStyle, oMenu,
      oBrush, oIcon, oWnd, lVScroll, lHScroll, nClrFore, nClrBack,
      oCursor, cBorder, lSysMenu, lCaption, lMin, lMax, lPixel,
      nExStyle, cVarName, nHelpId, lUnicode, nWidth, nHeight )

Crea una nueva instancia de TWindow pero no la muestra. El handle de ventana hWnd aún no se ha creado; eso ocurre durante Activate().

Activate()

METHOD Activate( cShow, bLClicked, bRClicked, bMoved, bResized,
      bPainted, bKeyDown, bInit, bUp, bDown, bPgUp, bPgDown,
      bLeft, bRight, bPgLeft, bPgRight, bValid, bDropFiles,
      bLButtonUp, lCentered, oMonitor )

Crea la ventana Win32, la muestra y entra en el bucle de mensajes. El parámetro cShow puede ser "MAXIMIZED", "ICONIZED" o "NORMAL" (predeterminado). El método no retorna hasta que la ventana se cierra.

End()

Envía WM_CLOSE a la ventana. Si bValid está establecido, se evalúa primero; el cierre se cancela cuando bValid devuelve .F..

Comandos: DEFINE WINDOW / ACTIVATE WINDOW

FiveWin proporciona comandos del preprocesador que se traducen en llamadas a métodos de TWindow. Esta es la forma recomendada de crear ventanas:

DEFINE WINDOW

DEFINE WINDOW oWnd ;
   [ FROM nTop, nLeft TO nBottom, nRight ] ;
   [ TITLE cTitle ] ;
   [ STYLE nStyle ] ;
   [ MENU oMenu ] ;
   [ BRUSH oBrush ] ;
   [ ICON oIcon ] ;
   [ OF oParent ] ;
   [ VSCROLL ] [ HSCROLL ] ;
   [ COLOR nClrText, nClrBack ] ;
   [ CURSOR oCursor ] ;
   [ BORDER cBorder ] ;   // "NONE", "SINGLE"
   [ NOSYSMENU ] ;
   [ NOCAPTION ] ;
   [ NOMINIMIZE ] ;
   [ NOMAXIMIZE ] ;
   [ PIXEL ] ;
   [ HELPID nHelpId ] ;
   [ UNICODE ]

ACTIVATE WINDOW

ACTIVATE WINDOW oWnd ;
   [ MAXIMIZED | ICONIZED | NORMAL ] ;
   [ ON LEFT CLICK bLClicked ] ;
   [ ON RIGHT CLICK bRClicked ] ;
   [ ON MOVE bMoved ] ;
   [ ON RESIZE bResized ] ;
   [ ON PAINT bPainted ] ;
   [ ON KEYDOWN bKeyDown ] ;
   [ ON INIT bInit ] ;
   [ ON UP bUp ] [ ON DOWN bDown ] ;
   [ ON PAGEUP bPgUp ] [ ON PAGEDOWN bPgDown ] ;
   [ ON LEFT bLeft ] [ ON RIGHT bRight ] ;
   [ VALID bValid ] ;
   [ ON DROP bDropFiles ] ;
   [ CENTERED ]

Ciclo de Vida de la Ventana

flowchart LR A["DEFINE WINDOW
(TWindow:New)"] --> B["Build Menu,
Toolbar, StatusBar"] B --> C["ACTIVATE WINDOW
(TWindow:Activate)"] C --> D["Win32 CreateWindow"] D --> E["ON INIT
bInit block"] E --> F["Message Loop
(user interaction)"] F --> G{"User closes
or End()"} G -->|"bValid returns .T."| H["WM_CLOSE /
DestroyWindow"] G -->|"bValid returns .F."| F H --> I["Activate() returns"]

El punto clave es que Activate() es una llamada bloqueante que ejecuta el bucle de mensajes de Windows. El código colocado después de ACTIVATE WINDOW solo se ejecuta después de que la ventana se haya cerrado.

Ejemplo: Ventana Principal con Menú, Barra de Herramientas y Barra de Estado

#include "FiveWin.ch"

function Main()

   local oWnd, oBar, oFont

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14

   DEFINE WINDOW oWnd TITLE "My Application" ;
      COLOR CLR_BLACK, CLR_WHITE

   DEFINE BUTTONBAR oBar OF oWnd SIZE 56, 56 2007

   DEFINE BUTTON OF oBar RESOURCE "NEW"  ;
      ACTION MsgInfo( "New document" )    ;
      TOOLTIP "New"

   DEFINE BUTTON OF oBar RESOURCE "OPEN" ;
      ACTION MsgInfo( "Open file" )       ;
      TOOLTIP "Open"

   DEFINE BUTTON OF oBar RESOURCE "SAVE" ;
      ACTION MsgInfo( "Save file" )       ;
      TOOLTIP "Save"

   SET MESSAGE OF oWnd TO "Ready" ;
      CENTERED CLOCK DATE KEYBOARD

   MENU oMenu
      MENUITEM "&File"
      MENU
         MENUITEM "&New"    ACTION MsgInfo( "New" )    MESSAGE "Create new document"
         MENUITEM "&Open"   ACTION MsgInfo( "Open" )   MESSAGE "Open existing file"
         MENUITEM "&Save"   ACTION MsgInfo( "Save" )   MESSAGE "Save current file"
         SEPARATOR
         MENUITEM "E&xit"   ACTION oWnd:End()          MESSAGE "Exit application"
      ENDMENU
      MENUITEM "&Help"
      MENU
         MENUITEM "&About"  ACTION MsgAbout()
      ENDMENU
   ENDMENU

   oWnd:SetMenu( oMenu )
   oWnd:SetFont( oFont )

   ACTIVATE WINDOW oWnd MAXIMIZED ;
      ON INIT ( oWnd:SetFocus() ) ;
      VALID ( MsgYesNo( "Exit application?" ) )

   oFont:End()

return nil

Ejemplo: Aplicación MDI

MDI (Interfaz de Múltiples Documentos) permite que una ventana marco principal albergue múltiples ventanas hijas. FiveWin proporciona TMDIFrame y TMDIChild, ambas derivadas de TWindow:

#include "FiveWin.ch"

static oWnd

function Main()

   local oBar

   DEFINE WINDOW oWnd TITLE "MDI Application" MDI ;
      COLOR CLR_BLACK, GetSysColor( COLOR_APPWORKSPACE )

   DEFINE BUTTONBAR oBar OF oWnd SIZE 56, 56 2007

   DEFINE BUTTON OF oBar RESOURCE "NEW" ;
      ACTION NewChild() TOOLTIP "New Document"

   SET MESSAGE OF oWnd TO "Ready" CENTERED CLOCK DATE

   MENU oMenu
      MENUITEM "&File"
      MENU
         MENUITEM "&New Child"  ACTION NewChild()
         SEPARATOR
         MENUITEM "E&xit"       ACTION oWnd:End()
      ENDMENU
      MENUITEM "&Window"
      MENU
         MENUITEM "&Tile"       ACTION oWnd:Tile()
         MENUITEM "Ca&scade"    ACTION oWnd:Cascade()
         MENUITEM "Arrange &Icons" ACTION oWnd:IconArrange()
         SEPARATOR
         MENUITEM "Close &All"  ACTION oWnd:CloseAll()
      ENDMENU
   ENDMENU

   oWnd:SetMenu( oMenu )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

//--------------------------------------------------------------------//

static function NewChild()

   local oChild
   static nCount := 0

   nCount++

   DEFINE WINDOW oChild TITLE "Document " + LTrim( Str( nCount ) ) ;
      MDICHILD OF oWnd

   ACTIVATE WINDOW oChild

return nil

Consejos de Uso

  • Pintado con doble buffer — Envuelve el pintado personalizado dentro de DispBegin() / DispEnd() para eliminar el parpadeo.
  • Persistencia de posición de ventana — Guarda nTop, nLeft, nBottom, nRight en un archivo INI en bValid y restáuralos en New().
  • Fondos con gradiente — Establece aGradColors con un array de pares de colores: oWnd:SetGradient( { { 0.5, nRGB(40,40,50), nRGB(20,20,30) }, { 0.5, nRGB(20,20,30), nRGB(10,10,15) } } ).
  • Unicode — Pasa UNICODE en el comando DEFINE WINDOW, o llama a FW_SetUnicode( .T. ) globalmente, para usar las APIs Win32 de caracteres anchos.
  • aControls — Itera sobre los controles hijos con AEval( oWnd:aControls, {|o| o:Refresh() } ) o el método más nuevo ForEachControl().
  • Compatible con múltiples monitores — Pasa oMonitor a Activate() para abrir la ventana en un monitor específico en configuraciones multi-pantalla.

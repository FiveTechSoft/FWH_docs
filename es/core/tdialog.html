TDialog

Clase Base Hereda de TWindow source/classes/dialog.prg

TDialog es la clase utilizada para crear cuadros de diálogo modales y no modales en FiveWin. Hereda de TWindow y agrega comportamiento específico de diálogos: activación modal/no modal, creación basada en recursos, selección de sistema de coordenadas (texto, píxel, píxel real), fondos transparentes para controles, soporte de modo oscuro y un ciclo de vida estructurado con fases ON INIT / VALID.

Métodos Principales

New() — Constructor

METHOD New( nTop, nLeft, nBottom, nRight, cCaption, cResName,
      hResources, lVbx, nStyle, nClrText, nClrBack, oBrush, oWnd,
      lPixels, oIco, oFont, nHelpId, nWidth, nHeight, lTransparent,
      aGradColors, cVarName, lUnicode, lTruePixel, lResizable )

Crea un objeto TDialog. Si se proporciona cResName, la disposición del diálogo proviene de un recurso compilado. De lo contrario, las coordenadas definen el tamaño del diálogo. Cuando nWidth y nHeight son distintos de cero, anulan nBottom/nRight y fuerzan el modo píxel.

Define() — Constructor Alternativo

METHOD Define( nTop, nLeft, nBottom, nRight, cCaption, nStyle,
      lVbx, nClrText, nClrBack, oBrush )

Constructor mínimo utilizado principalmente por el diseñador visual. Crea el objeto con menos parámetros.

Activate()

METHOD Activate( bLClicked, bMoved, bPainted, lCentered,
      bValid, lModal, bInit, bRClicked, bWhen, lResize16,
      lCenterInWnd, lMdiChild, oMdiChild, bMdiSetup, oMonitor )

Crea el diálogo Win32 y entra en el bucle de mensajes. Para diálogos modales (predeterminado), esta llamada se bloquea hasta que se invoca End(). Para diálogos no modales (lModal := .F. o cláusula NOMODAL), retorna inmediatamente.

End()

METHOD End( nResult )

Cierra el diálogo. Si bValid está establecido, se evalúa primero; si devuelve .F., el diálogo permanece abierto. El parámetro opcional nResult establece ::nResult antes de cerrar.

cToChar()

METHOD cToChar( hActiveWnd )

Genera una representación de cadena de caracteres del diálogo y todos sus controles — utilizado por el diseñador visual para serializar un diálogo a código fuente.

SetDarkMode()

METHOD SetDarkMode( nClrText, nClrBack )

Habilita el estilo de modo oscuro para el diálogo y sus controles hijos.

Ciclo de Vida del Diálogo

Comprender el ciclo de vida del diálogo es fundamental para una inicialización y limpieza correctas:

flowchart TD A["DEFINE DIALOG
(TDialog:New)"] --> B["Add Controls
@ ... GET, SAY, BUTTON, etc."] B --> C["ACTIVATE DIALOG
(TDialog:Activate)"] C --> D["Win32 CreateDialog /
DialogBoxParam"] D --> E["Initiate()
Distribute child controls"] E --> F["ON INIT block
bInit evaluated"] F --> G["Message Loop
User interaction"] G --> H{"End() called
or close button"} H -->|"VALID returns .F."| G H -->|"VALID returns .T."| I["Destroy controls
DestroyWindow"] I --> J["Activate() returns
nResult available"]

Importante: los controles deben crearse entre DEFINE DIALOG y ACTIVATE DIALOG. El bloque ON INIT se dispara después de que la ventana del diálogo exista (tiene un hWnd válido), siendo el lugar adecuado para la inicialización que necesite el handle de ventana.

Sistemas de Coordenadas

Los diálogos de FiveWin soportan tres sistemas de coordenadas. Elegir el correcto es esencial para un diseño correcto en diferentes configuraciones de DPI:

SistemaCláusulaUnidadCuándo Usar
Coordenadas de texto(predeterminado)Celdas de caracteres: 1 fila ~ 16px, 1 col ~ 8px (a 96 DPI)Código legacy, diálogos simples. Coordenadas como @ 1, 2 posicionan controles en la cuadrícula de texto.
PIXELPIXELUnidades de diálogo (DLUs), no píxeles reales. Escaladas por la fuente del sistema.Compatibilidad con editores de recursos. Todavía no es 1:1 con los píxeles de pantalla.
TRUEPIXELTRUEPIXELPíxeles reales de pantalla (mapeo 1:1)Aplicaciones modernas. Control total sobre el posicionamiento exacto. Recomendado para código nuevo.

Comparación de Coordenadas

// Text coordinates (default) - relative to character grid
DEFINE DIALOG oDlg TITLE "Text Coords" ;
   FROM 2, 5 TO 20, 60

   @ 1, 1 SAY "Name:" OF oDlg
   @ 1, 6 GET oGet VAR cName OF oDlg SIZE 100, 11

ACTIVATE DIALOG oDlg CENTER

// TRUEPIXEL - exact screen pixels, recommended for new code
DEFINE DIALOG oDlg TITLE "True Pixels" ;
   SIZE 500, 400 TRUEPIXEL

   @ 20, 20 SAY "Name:" OF oDlg SIZE 60, 22 TRUEPIXEL
   @ 20, 90 GET oGet VAR cName OF oDlg SIZE 200, 24 TRUEPIXEL

ACTIVATE DIALOG oDlg CENTER

Consejo: En Windows 10/11 con pantallas de alto DPI, las coordenadas de texto y el modo PIXEL pueden producir resultados inesperados. Usa TRUEPIXEL para diseños con precisión de píxel. También puedes establecerlo globalmente con FW_SetTruePixel( .T. ) o a nivel de clase con TDialog():lClsTruePixel := .T..

Ejemplo: Diálogo Modal con GETs y Botones

#include "FiveWin.ch"

function EditCustomer( oWnd )

   local oDlg, oFont, oBtnOk, oBtnCancel
   local cName   := Space( 40 )
   local cEmail  := Space( 60 )
   local cPhone  := Space( 20 )
   local cCity   := Space( 30 )
   local nResult

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14

   DEFINE DIALOG oDlg TITLE "Edit Customer" ;
      SIZE 480, 340 TRUEPIXEL ;
      FONT oFont OF oWnd TRANSPARENT

   @ 20,  20 SAY "Name:"  OF oDlg SIZE 80, 22 TRUEPIXEL
   @ 20, 110 GET cName    OF oDlg SIZE 340, 24 TRUEPIXEL

   @ 55,  20 SAY "Email:" OF oDlg SIZE 80, 22 TRUEPIXEL
   @ 55, 110 GET cEmail   OF oDlg SIZE 340, 24 TRUEPIXEL

   @ 90,  20 SAY "Phone:" OF oDlg SIZE 80, 22 TRUEPIXEL
   @ 90, 110 GET cPhone   OF oDlg SIZE 200, 24 TRUEPIXEL

   @ 125, 20 SAY "City:"  OF oDlg SIZE 80, 22 TRUEPIXEL
   @ 125, 110 GET cCity   OF oDlg SIZE 200, 24 TRUEPIXEL

   @ 260, 250 BUTTON oBtnOk PROMPT "&OK" OF oDlg ;
      SIZE 100, 30 TRUEPIXEL ;
      ACTION ( oDlg:End( IDOK ) )

   @ 260, 360 BUTTON oBtnCancel PROMPT "&Cancel" OF oDlg ;
      SIZE 100, 30 TRUEPIXEL ;
      ACTION ( oDlg:End( IDCANCEL ) ) CANCEL

   ACTIVATE DIALOG oDlg CENTER ;
      VALID ( oDlg:nResult != IDOK .or. ;
              !Empty( cName ) .or. ;
              MsgAlert( "Name is required" ) == nil )

   nResult := oDlg:nResult

   oFont:End()

   if nResult == IDOK
      // Save the data...
      MsgInfo( "Saved: " + AllTrim( cName ) )
   endif

return nResult

Ejemplo: Diálogo No Modal

Un diálogo no modal no bloquea el código que lo invoca. El usuario puede interactuar tanto con el diálogo como con otras ventanas. Usa NOMODAL o NOWAIT:

#include "FiveWin.ch"

static oDlgFind   // keep reference alive!

function ShowFindDialog( oWnd )

   local cSearch := Space( 40 )

   if oDlgFind != nil .and. IsWindow( oDlgFind:hWnd )
      oDlgFind:SetFocus()
      return nil
   endif

   DEFINE DIALOG oDlgFind TITLE "Find" ;
      SIZE 400, 140 TRUEPIXEL ;
      OF oWnd STYLE nOR( DS_MODALFRAME, WS_POPUP, WS_CAPTION, WS_SYSMENU )

   @ 20, 20  SAY "Search:" OF oDlgFind SIZE 60, 22 TRUEPIXEL
   @ 20, 90  GET cSearch   OF oDlgFind SIZE 200, 24 TRUEPIXEL

   @ 20, 300 BUTTON "Find" OF oDlgFind SIZE 80, 26 TRUEPIXEL ;
      ACTION DoSearch( cSearch )

   @ 56, 300 BUTTON "Close" OF oDlgFind SIZE 80, 26 TRUEPIXEL ;
      ACTION oDlgFind:End()

   ACTIVATE DIALOG oDlgFind CENTER NOMODAL ;
      ON INIT ( oDlgFind:SetFocus() )

   // Code here runs IMMEDIATELY (dialog is modeless)

return nil

static function DoSearch( cSearch )
   MsgInfo( "Searching for: " + AllTrim( cSearch ) )
return nil

Diálogos Basados en Recursos

Los diálogos pueden cargarse desde recursos .RC compilados (integrados en el EXE o en una DLL de recursos). Esto es útil para editores visuales o al migrar desde aplicaciones C/C++:

#include "FiveWin.ch"

function ShowAbout()

   local oDlg

   DEFINE DIALOG oDlg RESOURCE "ABOUTDLG"

   REDEFINE BUTTON ID 101 OF oDlg ACTION oDlg:End()

   ACTIVATE DIALOG oDlg CENTER

return nil

Usa los comandos REDEFINE (en lugar de @) para vincular objetos FiveWin a controles ya definidos en la plantilla de recursos mediante sus IDs numéricos.

Fondos con Gradiente y Transparentes

Los fondos con gradiente requieren TRANSPARENT para que los controles hijos se pinten correctamente sobre el gradiente:

DEFINE DIALOG oDlg TITLE "Gradient Dialog" ;
   SIZE 500, 350 TRUEPIXEL TRANSPARENT ;
   GRADIENT { { 0.5, nRGB(30,60,120), nRGB(15,30,60) }, ;
              { 0.5, nRGB(15,30,60),  nRGB(5,10,20) } }

Consejos de Uso

  • Usa siempre CENTER a menos que tengas una razón específica para posicionar el diálogo manualmente. Las posiciones fijas en píxeles no funcionan en diferentes resoluciones de pantalla.
  • Mantén las referencias de diálogos no modales en variables static para evitar que el recolector de basura los destruya.
  • Usa ON INIT para código que necesite que la ventana del diálogo exista (establecer foco, poblar XBrowse, llamar a la API Win32). No dependas del código entre DEFINE y ACTIVATE para esto.
  • VALID se dispara en cada intento de cierre, incluyendo el botón X de la barra de título y la tecla Escape. Devuelve .T. para permitir el cierre, .F. para impedirlo.
  • Modo oscuro — Llama a oDlg:SetDarkMode( nClrText, nClrBack ) en el bloque ON INIT para un diálogo con tema oscuro.
  • Diálogos redimensionables — Usa la cláusula RESIZABLE. Combínala con el anclaje de controles (AdjClient(), AdjTop()) para redimensionar automáticamente los controles hijos.

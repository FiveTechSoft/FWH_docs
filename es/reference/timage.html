TImage

Fuente: source/classes/image.prg

Hereda de: TControl

TImage es un control de imagen ampliado que muestra mapas de bits, iconos y metarchivos dentro de una ventana o diálogo. Amplía TBitmap con capacidades adicionales: carga desde archivos, recursos, búferes de memoria y URLs; guardado de imágenes en varios formatos (BMP, PNG, JPG, GIF, TIFF); rotación; y un indicador de progreso integrado. TImage es el control recomendado para mostrar imágenes estáticas en aplicaciones FiveWin.

Miembros DATA Principales

DATATipoDescripción
nProgressNuméricoPorcentaje de progreso (0-100). Cuando se establece, se superpone una barra de progreso sobre la imagen.
nFormatNuméricoIdentificador del formato de imagen usado al guardar. Valores: 0=BMP, 1=JPG, 2=PNG, 3=GIF, 4=TIFF.
cBmpFileCarácterRuta del archivo origen de la imagen mostrada.
cBmpResCarácterNombre del recurso de la imagen mostrada (si se cargó desde recursos).
hBitmapNumérico (Handle)Handle del mapa de bits mostrado actualmente.
lStretchLógicoSi es .T., la imagen se estira para ajustarse a las dimensiones del control.
lAdjustLógicoSi es .T., el tamaño del control se ajusta para coincidir con las dimensiones de la imagen.
nAngleNuméricoÁngulo de rotación actual en grados.

Métodos Principales

MétodoDescripción
New( nRow, nCol, nW, nH, cRes, cFile, oWnd, lNoBorder, lStretch, lAdjust, oFont, bClrGrad, ... )Crea un nuevo control de imagen. Acepta un nombre de recurso (cRes) o una ruta de archivo (cFile). Los parámetros adicionales controlan el borde, el comportamiento de estiramiento y el color de degradado.
Define( cRes, cFile, oWnd )Constructor alternativo para crear el control tras la instanciación.
LoadImage( cRes, cFile )Carga una imagen desde un nombre de recurso o ruta de archivo, reemplazando la imagen actual.
SaveImage( cFile, nFmt, nQuality )Guarda la imagen actual en un archivo. nFmt especifica el formato (0=BMP, 1=JPG, 2=PNG, 3=GIF, 4=TIFF). nQuality se aplica a JPG (0-100).
LoadFromMemory( cBuf, nW, nH )Carga una imagen desde un búfer de memoria que contiene datos de mapa de bits en bruto.
LoadFromURL( cUrl )Descarga y muestra una imagen desde una URL. Los datos de la imagen se obtienen mediante una petición HTTP interna.
RotateImage( nAngle )Rota la imagen mostrada según el ángulo especificado en grados. Crea un nuevo mapa de bits rotado.
Progress( lOn )Muestra u oculta un indicador de progreso superpuesto sobre la imagen. Sin argumentos, alterna la visibilidad.
SetImage( hBmp )Reemplaza la imagen mostrada con un handle de mapa de bits. El mapa de bits anterior no se destruye (llame a DeleteObject() si es necesario).
End()Destruye el control y libera el handle del mapa de bits.

Comandos: @ ... IMAGE

@ nRow, nCol IMAGE oImg ;
   [ FILENAME cFile ] ;
   [ RESOURCE cRes ] ;
   [ SIZE nW, nH ] ;
   [ OF oWnd ] ;
   [ NOBORDER ] ;
   [ STRETCH ] ;
   [ ADJUST ] ;
   [ TRANSPARENT ]

Ejemplo: Cargar imagen desde archivo y guardar como PNG

#include "FiveWin.ch"

function Main()

   local oWnd, oImg

   DEFINE WINDOW oWnd TITLE "TImage Demo" SIZE 600, 500

   @ 20, 20 IMAGE oImg FILENAME "photo.bmp" ;
      SIZE 560, 400 OF oWnd STRETCH

   @ 440, 20 BUTTON "Save as PNG" SIZE 120, 30 OF oWnd ;
      ACTION oImg:SaveImage( "photo.png", 2 )   // 2 = PNG

   @ 440, 160 BUTTON "Rotate 90" SIZE 120, 30 OF oWnd ;
      ACTION oImg:RotateImage( 90 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TImage hereda de TControl, que a su vez hereda de TWindow. Todos los métodos estándar de control (Move(), Refresh(), SetFocus(), etc.) están disponibles.
  • La cláusula STRETCH escala la imagen para llenar las dimensiones del control. Sin ella, la imagen se dibuja a su tamaño natural.
  • La cláusula ADJUST redimensiona el control para coincidir automáticamente con las dimensiones de la imagen cargada.
  • Los formatos de imagen admitidos para la carga dependen de las bibliotecas GDI+ disponibles en el sistema. BMP, PNG, JPG, GIF y TIFF son compatibles de forma universal en Windows modernos.
  • SaveImage() usa GDI+ para la conversión de formato. El parámetro nQuality (1-100) controla el nivel de compresión JPG; los valores más altos producen mejor calidad pero archivos más grandes.
  • LoadFromURL() realiza una descarga HTTP bloqueante. Para una carga de imágenes de red no bloqueante, considere usar TWebClient o FW_CurlHttp() para descargar primero los datos y luego SetImage().
  • La superposición de progreso es útil al cargar imágenes grandes o durante el procesamiento por lotes. Llame a oImg:Progress( .T. ) para activarla, y luego establezca oImg:nProgress para actualizar el porcentaje.

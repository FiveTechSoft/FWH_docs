TPen

Fuente: source/classes/pen.prg

Clase independiente (sin herencia)

TPen encapsula un objeto lápiz (pen) GDI de Windows para dibujar líneas, bordes y contornos. Los lápices definen el color, el ancho y el estilo (sólido, discontinuo, punteado, etc.) de las líneas dibujadas en cualquier contexto de dispositivo. TPen lo utilizan internamente muchos controles de FiveWin y también está disponible para su uso directo en rutinas de dibujo personalizadas.

Miembros DATA Principales

DATATipoDescripción
hPenNumérico (Handle)Handle del lápiz GDI de Windows
nStyleNuméricoEstilo del lápiz (PS_SOLID, PS_DASH, PS_DOT, PS_DASHDOT, etc.)
nWidthNuméricoAncho del lápiz en unidades lógicas (píxeles)
nColorNuméricoColor del lápiz como valor RGB
oDeviceObjetoContexto de dispositivo propietario opcional para escalar el ancho según el DPI

Métodos Principales

MétodoDescripción
New( nStyle, nWidth, nColor, oDevice )Crea un nuevo lápiz. Valores por defecto: PS_SOLID, ancho 1, CLR_BLACK. Cuando se proporciona oDevice, el ancho se escala según el DPI.
End()Elimina el objeto lápiz GDI y libera los recursos. Alias de Release().

Estilos de Lápiz

ConstanteValorDescripción
PS_SOLID0Línea sólida (por defecto)
PS_DASH1Línea discontinua (válida solo cuando el ancho es 1)
PS_DOT2Línea punteada (válida solo cuando el ancho es 1)
PS_DASHDOT3Patrón alternado de raya y punto
PS_DASHDOTDOT4Patrón de raya, punto y punto
PS_NULL5Lápiz invisible
PS_INSIDEFRAME6Lápiz sólido que dibuja dentro del marco delimitador

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oPen

   DEFINE WINDOW oWnd TITLE "TPen Demo" SIZE 400, 300

   oWnd:bPainted = {| hDC |
      // Crea un lápiz rojo con ancho 2
      DEFINE PEN oPen WIDTH 2 COLOR CLR_RED

      // Dibuja una línea de la esquina superior izquierda a la inferior derecha
      MoveTo( hDC, 50, 50 )
      LineTo( hDC, 350, 250, oPen:hPen )

      oPen:End()
      }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Llame siempre a End() o Release() cuando el lápiz ya no sea necesario para evitar fugas de recursos GDI.
  • Al especificar un oDevice (ventana, impresora, etc.), el ancho del lápiz se escala automáticamente según los píxeles lógicos por pulgada del dispositivo, manteniendo el ancho visual coherente en diferentes configuraciones de DPI.
  • El comando DEFINE PEN ofrece una alternativa de sintaxis cómoda a llamar a TPen():New() directamente.
  • TPen lo utilizan ampliamente los controles de FiveWin de forma interna. Una vez que un lápiz se selecciona en un contexto de dispositivo mediante SelectObject(), afecta a todas las operaciones de dibujo posteriores hasta que se selecciona otro lápiz.

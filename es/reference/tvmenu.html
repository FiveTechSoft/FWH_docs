TVMenu

Fuente: source/classes/VMenu.prg

Hereda de: TControl

TVMenu es un panel estilo ExplorerBar que muestra una lista de objetos TVItem. Soporta encabezado colapsable, animacion de abrir/cerrar, multiples estilos de seleccion (SOLID, INSET, XBOX, BUMP, ETCHED, RAISED, UNDERLINE), fondos con degradado y renderizado con temas. TVMenu es el contenedor padre de los objetos TVItem, que se anaden automaticamente al array aItems del menu al crearse.

Ejemplo

local oMenu, oItem

oMenu := TVMenu():New( 0, 0, 220, 380, oWnd, ;
         {|| MsgInfo("Accion") }, ;
         RGB(55,65,80), RGB(245,246,248), ;
         oFont, .t., RGB(220,224,230), ;
         0, , "SOLID", 5, , 1, "FILLED" )

oMenu:SetTitle( "Explorador", 28, oFont, ;
                RGB(255,255,255), RGB(70,130,180), ;
                , 50, .f., , , , , , .t., 17 )

oItem := TVItem():New( oMenu, "Inicio" )
oItem:SetImage( hBmp )

oItem := TVItem():New( oMenu, "Documentos" )
oItem:SetImage( hBmp2 )

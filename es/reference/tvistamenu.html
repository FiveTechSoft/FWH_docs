TVistaMenu

Fuente: source/classes/vistamnu.prg

Hereda de: TControl

TVistaMenu proporciona un panel de menú vertical moderno con renderizado visual al estilo Vista. Cada elemento muestra texto y un icono opcional, con colores de resaltado configurables para la selección bajo el cursor. El control es adecuado para paneles de navegación y menús laterales.

Miembros DATA Principales

DATATipoDescripción
aItemsArrayArray con las definiciones de los elementos del menú
oOverNuméricoÍndice del elemento actualmente bajo el ratón
nOptionFocusNuméricoÍndice del elemento actualmente enfocado (navegación por teclado)
nClrPaneOverNuméricoColor de fondo del elemento bajo el cursor
nClrTextOverNuméricoColor de texto del elemento bajo el cursor
nClrBorderOverNuméricoColor de borde del elemento bajo el cursor

Métodos Principales

MétodoDescripción
New( nRow, nCol, nW, nH, oWnd, oFont, oFont2 )Crea un nuevo control de menú vista
Redefine( nId, oWnd, oFont, oFont2 )Redefine desde un recurso de diálogo
AddItem( cText, cImage, bAction )Añade un elemento de menú con texto, ruta de imagen y acción
InsertItem( n, cText, cImage, bAction )Inserta un elemento de menú en la posición especificada
DelItem( n )Elimina el elemento de menú en la posición dada
GoUp()Mueve el foco del teclado al elemento anterior
GoDown()Mueve el foco del teclado al elemento siguiente

Ejemplo: Menú Vertical con Iconos

#include "FiveWin.ch"

function Main()

   local oWnd, oVMenu

   DEFINE WINDOW oWnd TITLE "TVistaMenu Demo" SIZE 400, 400

   @ 10, 10 VISTAMENU oVMenu ;
      OF oWnd ;
      SIZE 180, 300 ;
      FONT oWnd:oFont

   oVMenu:AddItem( "&Dashboard",   "images/dash.bmp",  { || MsgInfo( "Dashboard" ) } )
   oVMenu:AddItem( "&Customers",  "images/cust.bmp",  { || MsgInfo( "Customers" ) } )
   oVMenu:AddItem( "&Orders",     "images/ord.bmp",   { || MsgInfo( "Orders" ) } )
   oVMenu:AddItem( "&Reports",    "images/rpt.bmp",   { || MsgInfo( "Reports" ) } )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El parámetro cImage de AddItem() acepta una ruta de archivo a un recurso de bitmap o icono. Si la imagen no se puede cargar, el elemento muestra solo el texto.
  • Use nClrPaneOver, nClrTextOver y nClrBorderOver para personalizar la apariencia del resaltado bajo el cursor.
  • La navegación por teclado se gestiona mediante GoUp() y GoDown(), normalmente asociados a las teclas de flecha ARRIBA y ABAJO en la ventana padre.
  • El carácter & en el texto del elemento define aceleradores de teclado (p. ej., "&Dashboard" se activa con Alt+D).
  • TVistaMenu hereda de TControl, por lo que admite todo el posicionamiento, dimensionado y gestión de eventos estándar de los controles.

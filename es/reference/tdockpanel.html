TDockPnel

Fuente: source/internal/tdockpnel.prg

Hereda de: TControl

TDockPnel es un control de panel acoplable que proporciona una ventana flotante o de herramientas con una barra de título y un área interior de contenido. Admite múltiples modos de contenido (nMode: 1=TPanel, 2=TScrollPanel, 9=TDialog) y diversos tipos de control (nType: 1=ButtonBar, 2=TTitle, 3=TRibbonBar, 4=TFolderEx, 5=TXBrowse). El panel puede acoplarse a cualquier borde y admite el redimensionado basado en divisores.

Miembros DATA Principales

DATATipoDescripción

oPnelP / oPnelHObjetoControles del cuerpo y de la cabecera del panel
nHTitNuméricoAltura de la barra de título
nTypeNuméricoTipo de control: 1=ButtonBar, 2=TTitle, 3=TRibbonBar, 4=TFolderEx, 5=TXBrowse
nClrPane / nClrTextNuméricoColores del área del panel
nClrPaneH / nClrTextHNuméricoColores del área de la cabecera
lBottomLógico.T. para acoplar en el borde inferior
lSplitVLógico.T. para un controlador de divisor vertical

Ejemplo: Panel Acoplable con XBrowse

#include "FiveWin.ch"

function Main()

   local oWnd, oDock, oBrw

   DEFINE WINDOW oWnd TITLE "Dock Panel Demo" SIZE 800, 600

   // Crea un panel acoplable con contenido XBrowse
   oDock := TDockPnel():New( oWnd, 30, 10, 400, 600, "Data Browser", ;
                              1, CLR_BLACK, RGB(240,240,255), .F. )

   oDock:nType := 5   // contenido TXBrowse

   // Configura las columnas de XBrowse
   oBrw := TXBrowse():New( oDock:oPnelP )
   oBrw:AddCol( "Name" )
   oBrw:AddCol( "Value" )
   oBrw:lRecordSelector := .F.

   oDock:SetCtrlsPnel( oBrw )
   oDock:SetColors( CLR_BLACK, RGB(240,240,255), CLR_WHITE, RGB(50,100,200) )
   oDock:Activate()

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Notas

  • La propiedad nMode determina el tipo de contenedor interior creado para alojar los controles. El modo 1 (TPanel) es el predeterminado para diseños sencillos; el modo 9 (TDialog) habilita un comportamiento de tipo diálogo con botones Aceptar/Cancelar.
  • La propiedad nType selecciona qué tipo de control integrado se representa dentro del panel. El tipo 5 (TXBrowse) se utiliza habitualmente para rejillas de datos.
  • Use SetSplitV() para añadir un divisor vertical arrastrable. El divisor permite a los usuarios redimensionar el panel en tiempo de ejecución.
  • Los 52 estilos predefinidos accesibles mediante SetStyle() controlan la apariencia visual, incluyendo degradados, bordes y representación de fuentes.

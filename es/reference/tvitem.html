TVItem

Fuente: source/classes/vitem.prg

Clase independiente (no hereda de TControl)

TVItem representa un elemento individual dentro de un panel TVMenu. Cada TVItem contiene un caption de texto, bitmap/icono opcional, bloque de accion y propiedades de visualizacion. Al crearse, un TVItem se anade automaticamente al array aItems de su TVMenu padre. TVItem soporta estilos de separador, encabezados de grupo, menus popup, clausulas when y colores personalizados.

Constructor New()

TVItem():New( oParent, cText, cBmp1, cBmp2, lGroup, nClrText, nClrPane,;
              nTextAlign, nImgAlign, nHeight, nLeft, separator, nWidth,;
              lUnder, nLeftImg, nClrPane2, lVGrad, bAction, oPopup,;
              nClrPSel, nClrTSel, lMirGrad, nSteps, cToolTip,;
              nColorSep, lIcon, nTop, bWhen, nClrPSel2 )
ParametroTipoDescripcion
oParentTVMenuMenu padre (requerido)
cTextCaracterTexto del caption
cBmp1Caracter/NumericoRuta de bitmap, nombre de recurso o handle
lGroupLogicoEs encabezado de grupo (por defecto: .f.)
nClrTextNumericoColor de texto personalizado
nClrPaneNumericoColor de fondo personalizado
separatorCaracter"LINE", "SEPARADOR", "INSET", "DOTDOT"
bActionBloqueBloque de accion del item
bWhenBloqueClausula when (retorna .t. para habilitar)

Metodos

MetodoRetornaDescripcion
SetImage(cBmp, lIcon)nilEstablecer imagen desde archivo, recurso o handle numerico
SetBold(lBold)LogicoAlternar texto en negrita
SetDialog(cResName)nilAsociar recurso de dialogo
lOption()LogicoEs el item seleccionado actualmente

Ejemplo

local oItem

oItem := TVItem():New( oMenu, "Documentos" )

oItem := TVItem():New( oMenu, "Inicio" )
oItem:SetImage( hMiBitmap )

oItem := TVItem():New( oMenu, "" )
oItem:nSeparator := 2

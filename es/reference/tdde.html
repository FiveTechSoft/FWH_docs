TDde / TDdeClient / TDdeServer

Fuentes: source/classes/dde.prg, source/classes/ddeclien.prg, source/classes/ddeserv.prg

Clases independientes (no basadas en controles)

Estas tres clases implementan la comunicación de Intercambio Dinámico de Datos (DDE) entre aplicaciones Windows. TDde es una envoltura DDE simplificada, mientras que TDdeClient y TDdeServer proporcionan una implementación cliente-servidor más completa con soporte para Execute, Request, Poke y manejo de confirmaciones (acknowledgment).

TDde (DDE Simple)

Miembros DATA Principales

DATATipoDescripción
nServiceNumericÁtomo global para el nombre del servicio
nTopicNumericÁtomo global para el nombre del tópico
oWndServerObjectObjeto ventana del servidor tras la conexión
lActiveLogical.T. cuando la conversación DDE está activa

Métodos Principales

MétodoDescripción
New( cService, cTopic, cItem, bAction, bEnd )Crea un objeto DDE con los átomos de servicio, tópico e ítem y los bloques de código de acción/fin
Activate()Difunde WM_DDE_INITIATE a todas las ventanas de nivel superior
Execute( cCommand )Envía un comando de ejecución DDE al servidor
End()Termina la conversación DDE y elimina los átomos

TDdeClient (Cliente Completo)

Miembros DATA Principales

DATATipoDescripción
oWndObjectObjeto ventana principal para el manejo de mensajes
cServiceCharacterNombre del servicio (convertido a átomo)
cTopicCharacterNombre del tópico (convertido a átomo)
lActiveLogical.T. cuando la conversación DDE está activa
nAckNumericEstado ACK: 0=OK, 1=Ocupado, 2=NoSoportado, 3=Tiempo agotado
cDataCharacterContiene los datos recibidos de una llamada Request

Métodos Principales

MétodoDescripción
New( oWnd, cService, cTopic )Crea el cliente; conecta bDDE_ACK y bDDE_DATA a la ventana
Activate( nWait )Envía WM_DDE_INITIATE; opcionalmente espera nWait segundos por el ACK
Execute( cCommand, nWaitOK )Envía una cadena de comando y opcionalmente espera la confirmación
Request( nType, cCommand, nWaitOK )Solicita datos al servidor (CF_TEXT por defecto); resultado en ::cData
Poke( nType, cItem, cData, nWaitOK )Envía datos al servidor identificados por cItem
End()Termina la conversación y elimina los átomos

TDdeServer (Servidor Completo)

Miembros DATA Principales

DATATipoDescripción
oWndObjectObjeto ventana principal para el manejo de mensajes
cServiceCharacterNombre del servicio al que responder
cTopicCharacterNombre del tópico al que responder
bInitBlockBloque de código ejecutado al iniciar el DDE (devuelve .F. para rechazar)
bExecuteBlockBloque de código ejecutado en DDE_EXECUTE
bRequestBlockBloque de código ejecutado en DDE_REQUEST (devuelve la cadena de datos)
bPokeBlockBloque de código ejecutado en DDE_POKE

Métodos Principales

MétodoDescripción
New( oWnd, cService, cTopic, bInit, bExecute, bRequest, bPoke, bTerminate )Crea el servidor y conecta los manejadores de mensajes DDE a la ventana
End()Elimina los manejadores de mensajes y marca como inactivo

Ejemplo: Cliente DDE

#include "FiveWin.ch"

function DDEClientDemo()

   local oClient := TDdeClient():New( oWnd, "MyService", "MyTopic" )

   // Activar con un tiempo de espera de 5 segundos
   if oClient:Activate( 5 )
      // Ejecutar un comando
      oClient:Execute( "OPEN_FILE|C:\data.txt" )
      // Solicitar datos
      oClient:Request( 1, "GET_STATUS" )
      MsgInfo( oClient:cData )
      oClient:End()
   endif

return nil

Ejemplo: Servidor DDE

#include "FiveWin.ch"

function DDEServerDemo( oWnd )

   local oServer := TDdeServer():New( oWnd, "MyService", "MyTopic",;
      {|cSrv,cTop| MsgInfo( "Client connected: "+cSrv ), .T. },;
      {|cCmd|   MsgInfo( "Exec: " + cCmd ), .T. },;
      {|cItem|  If( cItem == "TIME", Time(), "" ) },;
      {|cItem,cData| MsgInfo( "Poked: "+cItem+"="+cData ), .T. } )

return nil

Notas

  • DDE utiliza la mensajería de Windows (WM_DDE_*) y átomos globales para la identificación de servicio/tópico.
  • La ventana del servidor debe permanecer viva para que la conversación siga activa. La activación del servidor ocurre automáticamente cuando New() conecta los manejadores.
  • Los códigos ACK son: 0=OK, 1=Ocupado, 2=NoSoportado, 3=Tiempo agotado. Comprueba ::nAck después de cada operación.
  • Para Request(), los datos devueltos se almacenan en ::cData. Solo se soporta CF_TEXT.

TXBrCode

Fuente: source/classes/xbrcode.prg

Hereda de: TXBrowse + TXBrColCode

TXBrCode es una herramienta de generación de código que produce código fuente PRG de FiveWin a partir de una configuración TXBrowse en vivo. Inspecciona la definición del browse, incluyendo columnas, fuentes de datos, encabezados, pies y barras de botones, y genera código Harbour listo para compilar en múltiples estilos de codificación.

Métodos Principales

MétodoDescripción
PrgCode()Devuelve un array de 4 cadenas que representan los segmentos de código generados: (1) configuración de la ventana/browse principal, (2) definiciones de columnas, (3) barra de botones, (4) código de activación
PrgCodeMain()Genera el bloque de código de la ventana principal y la definición del browse
PrgCodeOpenData()Genera el bloque de código de apertura de la fuente de datos
PrgCodeBtnBar()Genera el bloque de código de la definición de la barra de botones
BrwDataCode( lOops )Genera las definiciones de columnas del browse con un envoltorio opcional de manejo de errores
RptCode()Genera una definición de informe basada en la disposición del browse

TXBrColCode

TXBrColCode amplía la generación de código de columnas con múltiples opciones de estilo y la capacidad de reutilizar definiciones de columnas en distintos formatos de salida.

MétodoDescripción
PrgCode( nStyle, lSameCols )Devuelve una cadena de caracteres con el código PRG de columnas en el estilo especificado (1=sintaxis de comando, 2=sintaxis WITH_OBJECT, 3=sintaxis OOP). Establezca lSameCols para reutilizar las definiciones de columnas de una llamada anterior

Ejemplo: Generar el PRG del Browse

#include "FiveWin.ch"

function Main()

   local oBrw, oCode
   local aCode

   // ... definición del browse ...

   oCode := TXBrCode()      // Mismo objeto que oBrw
   // o crear un generador de código independiente

   aCode := oCode:PrgCode()

   // aCode[1] = configuración de la ventana/browse
   // aCode[2] = definiciones de columnas
   // aCode[3] = barra de botones
   // aCode[4] = activación

   // Previsualizar el código generado
   MemoEdit( aCode[1] + aCode[2] + aCode[3] + aCode[4] )

return nil

Notas

  • TXBrCode comparte la misma instancia de objeto que el browse. Tras configurar el browse de forma interactiva, llame a PrgCode() para capturar su estructura como código fuente.
  • El método BrwDataCode() es útil para generar código de columnas que incluye el manejo de errores en torno al acceso a datos (parámetro lOops).
  • TXBrColCode ofrece tres estilos de salida: estilo de comando (@ ... XBROWSE ...), estilo WITH_OBJECT y estilo OOP puro para una máxima flexibilidad.
  • El código generado incluye todos los encabezados de columna, bloques de datos, anchos, pies y cláusulas picture tal como están configurados en el browse.

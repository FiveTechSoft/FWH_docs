TTreeItem / TTVItem

Fuente: source/classes/treeitem.prg, source/classes/ttvitem.prg

TTreeItem implementa un nodo de árbol de lista enlazada para widgets de árbol personalizados. Cada nodo almacena un prompt, un nivel, bitmaps, un bloque de código de acción y datos de carga (cargo), y mantiene punteros anterior/siguiente/hijo a través de un objeto TTree asociado. TTVItem encapsula un elemento nativo TreeView de Win32 (HTREEITEM) para su uso con el control de árbol estándar de Windows, proporcionando operaciones de inserción, expansión, edición, casilla de verificación y persistencia.

TTreeItem — Nodo de Árbol de Lista Enlazada

Miembros DATA Principales

DATATipoDescripción
cPromptCharacterTexto que se muestra en el nodo
oTreeObjectReferencia al objeto TTree hijo (hijos), nil si es una hoja
lOpenedLogicalEl nodo está expandido (hijos visibles)
nLevelNumericNivel de sangría (0 = raíz)
hBmpOpenHandleHandle del bitmap para el estado expandido
hBmpCloseHandleHandle del bitmap para el estado contraído
bActionCodeblockBloque de código ejecutado cuando se activa el nodo
CargoAnyDatos definidos por el usuario asociados al nodo

Métodos Principales

MétodoDescripción
New( cPrompt, nLevel, hBmpOpen, hBmpClose, bAction, uCargo, uValue )Crea un nuevo nodo de árbol en el nivel especificado
Open()Expande el nodo para mostrar los hijos
Close()Contrae el nodo para ocultar los hijos
Toggle()Alterna entre el estado abierto y cerrado
Add( cPrompt )Añade un nodo hermano después de este (inserción en lista enlazada)
AddChild( cPrompt, lFirst )Añade un nodo hijo (crea o usa un TTree existente)
Delete( oRoot )Elimina este nodo de la lista
MoveUp( oRoot )Mueve el nodo hacia arriba en la lista
MoveDown( oRoot )Mueve el nodo hacia abajo en la lista
Sort( oRoot, lAsc, lRecurs )Ordena los hermanos por prompt, opcionalmente de forma recursiva
Promote()Disminuye el nivel de sangría en uno
Demote()Aumenta el nivel de sangría en uno
Parent( nParent )Busca el ancestro en un nivel dado
ByIndex[ n ]Accede al nodo hijo/subnodo por índice (sobrecarga del operador [])

Ejemplo: Construcción de un Árbol

#include "FiveWin.ch"

function Main()

   local oTreeView, oRoot, oItem1, oItem2

   // Ejemplo de TTVItem con TreeView nativo
   DEFINE WINDOW oWnd TITLE "Tree Demo" SIZE 400, 300

   oTreeView = TTreeView():New( 10, 10, 380, 280, oWnd )

   oRoot = TTVItem():New( TVInsertItem( oTreeView:hWnd, "Root", 0, 0 ),;
                          oTreeView, NIL, "Root", 0, NIL )

   oItem1 = oRoot:Add( "Child 1", 1, "data1" )
   oItem2 = oRoot:Add( "Child 2", 1, "data2" )

   oItem1:Add( "Grandchild", 2, "deep" )

   oRoot:Expand()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTreeItem está diseñado para un árbol de lista enlazada personalizado donde cada nodo puede contener opcionalmente un TTree hijo (a través de oTree). La lista enlazada es doblemente enlazada mediante oPrev/oNext.
  • TTVItem encapsula un handle de elemento de árbol nativo de Windows y delega todas las operaciones de visualización/estructura al control común a través de SendMessage.
  • En TTVItem, Save() / Load() serializan las propiedades cPrompt, nImage, Cargo y lBold.
  • GetCheck() / SetCheck() requieren que el árbol tenga el estilo TVS_CHECKBOXES.
  • El acceso/asignación de Value en TTreeItem delega en un bloque de código bSetGet, permitiendo que el nodo actúe como una variable SET/GET.

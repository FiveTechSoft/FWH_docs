TEnhMetaFile

Fuente: source/classes/tenhmeta.prg

Hereda de: TControl

TEnhMetaFile muestra Metafiles Mejorados de Windows (EMF) dentro de ventanas y diálogos de FiveWin. Es una subclase completa de TControl que admite dimensionamiento, posicionamiento, acercar/alejar (zoom), efectos de sombra y liberación de recursos. Los archivos EMF contienen gráficos vectoriales que se escalan sin pérdida de calidad, lo que los hace ideales para diagramas, logotipos y contenido de vista previa de impresión.

Miembros DATA Principales

DATATipoDescripción
hMetaNumérico (Handle)Handle del metafile mejorado (HENHMETAFILE)
nWidthNuméricoAncho lógico del metafile
nHeightNuméricoAlto lógico del metafile
nXZoomNuméricoFactor de zoom del eje X (predeterminado 2)
nYZoomNuméricoFactor de zoom del eje Y (predeterminado 4)
nXorigNuméricoDesplazamiento del origen de scroll del eje X
nYorigNuméricoDesplazamiento del origen de scroll del eje Y
lZoomLógicoIndica si el modo de zoom está actualmente activo
lShadowLógicoMostrar el efecto de sombra alrededor del control (predeterminado .T.)

Métodos Principales

MétodoDescripción
New( nTop, nLeft, nW, nH, cFile, oWnd )Crea un nuevo control TEnhMetaFile que carga y muestra un archivo EMF
Redefine( nId, cFile, oWnd )Redefine desde una plantilla de recurso de diálogo
SetFile( cFile )Carga un nuevo archivo EMF, reemplazando el actual
ZoomIn()Acerca el metafile (divide nWidth/nHeight entre nXZoom/nYZoom)
ZoomOut()Aleja el metafile (restaura las dimensiones originales)
SetZoomFactor( nX, nY )Cambia el factor de zoom y ajusta el estado de zoom actual
SetOrg( nX, nY )Establece el origen de scroll para desplazar la vista del metafile
End()Libera el handle del metafile y llama al End() de la superclase

Comando EMF

TEnhMetaFile se puede crear directamente usando la sintaxis del comando EMF:

@ nRow, nCol EMF oEmf FILE cFile OF oWnd SIZE nW, nH

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oEmf

   DEFINE WINDOW oWnd TITLE "Visor EMF" SIZE 600, 500

   @ 10, 10 EMF oEmf FILE "diagram.emf" OF oWnd SIZE 560, 400

   oEmf:lShadow := .T.

   // Botón para acercar (zoom in)
   @ 420, 10 BUTTON "Zoom In" OF oWnd SIZE 80, 25 ;
      ACTION oEmf:ZoomIn()

   @ 420, 100 BUTTON "Zoom Out" OF oWnd SIZE 80, 25 ;
      ACTION oEmf:ZoomOut()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TEnhMetaFile maneja únicamente Metafiles Mejorados (.emf). Para archivos WMF con conversión automática, use TMetaFile en su lugar.
  • Los métodos ZoomIn/ZoomOut alternan entre los estados con zoom y sin zoom. El factor de zoom se establece mediante nXZoom (predeterminado 2) y nYZoom (predeterminado 4).
  • El efecto de sombra dibuja un borde con sombra tipo 3D usando un TPen. Desactívelo estableciendo lShadow := .F..
  • Los metafiles se cargan desde el archivo en el primer repintado. Use SetFile() para cambiar el archivo mostrado en tiempo de ejecución, lo cual libera el handle del metafile anterior.

TCursor

Fuente: source/classes/cursor.prg

Clase independiente (sin herencia)

TCursor carga, crea y gestiona recursos de cursor del ratón. Admite cursores del sistema predefinidos de Windows, cursores personalizados desde archivos .cur/.ico, cursores desde recursos del programa y cursores creados mediante programación a partir de imágenes de mapa de bits. TCursor es utilizada por el framework FiveWin para funciones de gestión de cursores como CursorHand(), CursorArrow(), CursorWait(), etc.

Miembros DATA Principales

DATATipoDescripción
hCursorNumérico (Handle)Handle del cursor de Windows
lPredefLógicoIndica si el cursor es un cursor del sistema predefinido (no se destruye en End)
SourceCarácterCadena de descripción del origen (p. ej., "PREDEF:HAND" o ruta de archivo)

Tipos de Cursor Predefinidos

NombreDescripción
ARROWPuntero de flecha estándar (IDC_ARROW)
IBEAMCursor de texto en forma de I (IDC_IBEAM)
WAITCursor de reloj de arena/espera (IDC_WAIT)
CROSSCursor en cruz (IDC_CROSS)
UPARROWCursor de flecha vertical (IDC_UPARROW)
SIZECursor de redimensionar/mover de cuatro puntas (IDC_SIZEALL)
HANDPuntero de mano (enlace pulsable)
STOPCursor de parada/prohibido
DRAGCursor de arrastre
SEARCHCursor de búsqueda/zoom
SIZENWSERedimensionar en diagonal NO-SE
SIZENESWRedimensionar en diagonal NE-SO
SIZEWERedimensionar horizontal (oeste-este)
SIZENSRedimensionar vertical (norte-sur)

Métodos Principales

MétodoDescripción
New( cResOrFile, cPredef )Crea un cursor a partir de un nombre de recurso, archivo .cur/.ico o tipo predefinido
NewBmp( oBitmap, nHotRow, nHotCol )Crea un cursor a partir de un objeto TBitmap o TBtnBmp con coordenadas del punto activo
NewFromBitmap( oBitmap, nHotRow, nHotCol, hMaskBitmap )Crea un cursor a partir de un mapa de bits con un mapa de bits de máscara aparte
SetSource( cSource, cPredef )Establece o cambia el origen del cursor y recarga el handle del cursor
End()Libera el handle del cursor (los cursores predefinidos no se destruyen)

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oCursor

   DEFINE WINDOW oWnd TITLE "TCursor Demo" SIZE 400, 300

   // Carga un cursor de mano desde un archivo
   oCursor := TCursor():New( "hand.cur" )
   // Alternativa: cursor de mano predefinido
   // oCursor := TCursor():New( , "HAND" )

   oWnd:SetCursor( oCursor:hCursor )

   ACTIVATE WINDOW oWnd CENTERED

   oCursor:End()

return nil

Notas

  • Los cursores predefinidos (ARROW, IBEAM, WAIT, etc.) se cargan desde los recursos del sistema de Windows y no deben destruirse. TCursor controla esto mediante el indicador lPredef y omite DestroyCursor() para los cursores del sistema.
  • Use Source (protegido) para consultar la descripción del origen del cursor cargado actualmente.
  • El método NewBmp() crea un cursor a partir de cualquier objeto TBitmap, gestionando automáticamente la paleta y la transparencia.
  • Los cursores desde recursos (compilados en el .exe) se cargan mediante LoadCursor( GetResources(), cResName ).

Funciones Principales de FWH

FiveWin proporciona cientos de funciones que extienden Harbour con acceso a la API de Windows, utilidades GUI y funciones auxiliares de conveniencia. Esta página documenta las más utilizadas.

Funciones de Cuadro de Mensaje

MsgInfo()

MsgInfo( cMessage [, cTitle ] ) --> nil

Muestra un cuadro de mensaje informativo con un icono "i" y botón Aceptar. El título por defecto es "Information". 

MsgInfo( "Record saved successfully" )
MsgInfo( "Total: " + LTrim( Str( nTotal ) ), "Calculation Result" )

MsgAlert()

MsgAlert( cMessage [, cTitle ] ) --> nil

Muestra un cuadro de mensaje de advertencia con un icono de exclamación. Título por defecto: "Alert". 

MsgAlert( "File not found: " + cFile )

MsgStop()

MsgStop( cMessage [, cTitle ] ) --> nil

Muestra un cuadro de mensaje de error/parada con un icono de X roja. Título por defecto: "Stop". 

MsgStop( "Invalid data entered", "Validation Error" )

MsgYesNo()

MsgYesNo( cMessage [, cTitle ] ) --> lYes

Muestra un diálogo de pregunta Sí/No. Devuelve .T. si el usuario hace clic en Sí, .F. para No. 

if MsgYesNo( "Are you sure you want to delete this record?" )
   oDb:Delete()
endif

MsgNoYes()

MsgNoYes( cMessage [, cTitle ] ) --> lYes

Igual que MsgYesNo() pero con "No" como botón predeterminado (enfocado).

MsgGet()

MsgGet( cTitle, cPrompt, @cValue [, cPicture ] ) --> lOk

Muestra un diálogo de entrada con un campo GET. Devuelve .T. si el usuario hace clic en Aceptar. El valor se devuelve por referencia en cValue. 

local cName := Space( 40 )
if MsgGet( "Input", "Enter your name:", @cName )
   ? "Name:", Trim( cName )
endif

Alert()

Alert( cMessage [, aButtons ] ) --> nButton

Función alert estándar de Harbour, mejorada por FiveWin para mostrar un diálogo GUI en lugar de una alerta de consola. Devuelve el número del botón pulsado (base 1). 

local nChoice := Alert( "Choose an action", { "Save", "Discard", "Cancel" } )
do case
   case nChoice == 1 ; SaveData()
   case nChoice == 2 ; // descartar
   case nChoice == 3 ; // cancelar
endcase

Idioma y Localización

FWString()

FWString( cEnglishText ) --> cLocalizedText

Devuelve la versión localizada de una cadena según la configuración de idioma actual. FiveWin incluye traducciones para español, francés, alemán, portugués, italiano, holandés, ruso y muchos otros idiomas. 

? FWString( "Save" )   // "Guardar" (si es español)
? FWString( "Cancel" ) // "Annuler" (si es francés)

FWSetLanguage()

FWSetLanguage( cLang [, hCustomStrings ] ) --> cPrevLang

Establecer el idioma de la aplicación. Los valores integrados incluyen: "EN" (inglés), "ES" (español), "FR" (francés), "DE" (alemán), "PT" (portugués), "IT" (italiano), "NL" (holandés), "RU" (ruso), "PL" (polaco), "CZ" (checo), "SK" (eslovaco), "HR" (croata), "HU" (húngaro), "RO" (rumano), "BG" (búlgaro), "TR" (turco), "ZH" (chino), "JA" (japonés), "KO" (coreano), "AR" (árabe). 

FWSetLanguage( "ES" )  // Cambiar a español

Diálogos de Archivo y Directorio

cGetFile()

cGetFile( cFilter, cTitle [, nFilterIndex [, cInitDir [, lMulti [, nFlags ] ] ] ] ) --> cFile

Muestra un diálogo de Abrir Archivo. Devuelve la ruta del archivo seleccionado, o cadena vacía si se cancela. 

local cFile

cFile := cGetFile( "DBF Files (*.dbf)|*.dbf|All Files (*.*)|*.*", ;
                   "Select Database" )

if ! Empty( cFile )
   ? "Seleccionado:", cFile
endif

// Selección múltiple de archivos
cFile := cGetFile( "Images|*.jpg;*.png;*.bmp", "Select Images",,,  .T. )
// Devuelve archivos separados por CRLF

cPutFile()

cPutFile( cFilter, cTitle [, nFilterIndex [, cInitDir [, cDefFile ] ] ] ) --> cFile

Muestra un diálogo de Guardar Archivo. Devuelve la ruta seleccionada, o cadena vacía si se cancela. 

local cFile := cPutFile( "PDF Files (*.pdf)|*.pdf", "Save Report As" )
if ! Empty( cFile )
   SaveReport( cFile )
endif

cGetDir()

cGetDir( [cTitle [, cInitDir ] ] ) --> cDir

Muestra un diálogo de selección de carpeta. Devuelve la ruta del directorio seleccionado. 

local cDir := cGetDir( "Select output folder" )
if ! Empty( cDir )
   SetErrorPath( cDir )
endif

Funciones de Conversión

cValToChar()

cValToChar( uValue ) --> cString

Convierte cualquier valor Harbour a su representación de cadena de caracteres. Funciona con tipos numérico, fecha, lógico, array, hash, nil y objeto. 

? cValToChar( 42 )           // "42"
? cValToChar( .T. )          // ".T."
? cValToChar( Date() )       // "03/24/2026"
? cValToChar( nil )          // "NIL"
? cValToChar( { 1, 2, 3 } ) // "{ 1, 2, 3 }"

nLoWord() / nHiWord()

nLoWord( nDWord ) --> nWord
nHiWord( nDWord ) --> nWord

Extraer la palabra de 16 bits de orden bajo o alto de un valor de 32 bits. Esencial para procesar mensajes de Windows donde wParam/lParam empaquetan dos valores. 

// En un manejador WM_SIZE:
local nWidth  := nLoWord( nLParam )
local nHeight := nHiWord( nLParam )

Funciones de Fecha/Hora

FW_ADDMONTH()

FW_ADDMONTH( tDate, nMths ) --> tDateTime

Añade un número de meses a una fecha o valor datetime. Maneja los límites de año y los ajustes de fin de mes automáticamente. 

? FW_ADDMONTH( CTOD( "01/15/2026" ), 3 )  // 04/15/2026
? FW_ADDMONTH( CTOD( "01/31/2026" ), 1 )  // 02/28/2026 (ajustado fin de mes)

FW_YMDLAPSED()

FW_YMDLAPSED( dFrom, dLast ) --> { nYears, nMonths, nDays }

Devuelve el tiempo transcurrido entre dos fechas como un array de años, meses y días. Útil para calcular edad o antigüedad en un formato legible. 

local aLapsed := FW_YMDLAPSED( CTOD( "03/15/2020" ), Date() )
? "Years:", aLapsed[ 1 ], "Months:", aLapsed[ 2 ], "Days:", aLapsed[ 3 ]

FW_MTHSLAPSED()

FW_MTHSLAPSED( dDate1, dDate2 ) --> nMonths

Devuelve el número de meses calendario completos entre dos fechas. A diferencia de una simple división por días, esta función respeta los límites de los meses calendario. 

? FW_MTHSLAPSED( CTOD( "01/15/2026" ), CTOD( "04/20/2026" ) )  // 3

FW_AGE()

FW_AGE( dDob, dAsOn ) --> nAge

Calcula la edad en años completos a partir de una fecha de nacimiento, hasta una fecha dada. 

local nAge := FW_AGE( CTOD( "04/15/1980" ), Date() )
? "Age:", nAge

FW_NEXTBIRTHDAY()

FW_NEXTBIRTHDAY( dDob, dToday, lIncludeToday ) --> dDate

Devuelve la fecha del próximo cumpleaños a partir de una fecha de nacimiento, relativa a una fecha dada. Si lIncludeToday es .T. y hoy es el cumpleaños, devuelve la fecha de hoy. 

local dNext := FW_NEXTBIRTHDAY( CTOD( "04/15/1980" ), Date() )
? "Next birthday:", dNext

FW_ADDTIME()

FW_ADDTIME( tDate, cTimeStr ) --> tDateTime

Añade una cadena de duración de tiempo a un valor datetime. La cadena de tiempo soporta el formato "HH:MM:SS" y puede abarcar múltiples días. 

local tStart := FW_ADDMONTH( Date(), 0 ) // hoy a medianoche
local tEnd   := FW_ADDTIME( tStart, "02:30:00" )
? "Two and a half hours later:", tEnd

FW_DateToUnix()

FW_DateToUnix( tDateTime ) --> nMilliSecs

Convierte un valor datetime a milisegundos epoch Unix (milisegundos desde 1970-01-01 00:00:00 UTC). Esencial para comunicación con APIs y aritmética de marcas de tiempo. 

local nMs := FW_DateToUnix( DateTime() )
? "Current epoch ms:", nMs

FW_UnixToDate()

FW_UnixToDate( nMilliSecs ) --> tDateTime

Convierte milisegundos epoch Unix de vuelta a un valor datetime. La inversa de FW_DateToUnix(). 

local tDate := FW_UnixToDate( 1713129600000 )
? "Date from epoch:", tDate

UTC_TIMESTAMP()

UTC_TIMESTAMP( dDateTime ) --> tDateTime

Convierte una fecha/hora local a Tiempo Universal Coordinado (UTC). Aplica el offset de la zona horaria local para producir el datetime UTC equivalente. 

local tUtc := UTC_TIMESTAMP( DateTime() )
? "UTC time:", tUtc

FW_UTCTOLOCAL()

FW_UTCTOLOCAL( tUtcTime ) --> tDateTime

Convierte un datetime UTC de vuelta a hora local. La inversa de UTC_TIMESTAMP(). 

local tLocal := FW_UTCTOLOCAL( tUtc )
? "Local time:", tLocal

FW_TIMEZONE()

FW_TIMEZONE() --> cTimezoneStr

Devuelve el offset de zona horaria local como una cadena formateada, ej. "+05:30" para India o "-05:00" para la Zona Horaria del Este. 

? "Timezone offset:", FW_TIMEZONE()  // ej. "+05:30"

FW_SToT()

FW_SToT( cDateTime ) --> tDateTime

Convierte una cadena datetime a un valor datetime de Harbour. Acepta varios formatos estándar incluyendo "YYYY-MM-DD HH:MM:SS" y "MM/DD/YYYY HH:MM:SS". 

local t := FW_SToT( "2026-05-28 14:30:00" )
? "Parsed datetime:", t

Información de Versión y Sistema

FWVersion()

FWVersion() --> cVersion

Devuelve la cadena de versión de FiveWin, ej. "FWH 26.05".

GetVersion()

GetVersion() --> aVersion

Devuelve un array con información de versión de Windows: { nMajor, nMinor, nBuild, cPlatform }.

hb_Compiler()

hb_Compiler() --> cCompiler

Devuelve la cadena de versión del compilador Harbour.

IsExe64()

IsExe64() --> lIs64

Devuelve .T. si la aplicación actual es un ejecutable de 64 bits.

IsWinNT() / IsWin10() / IsWin11()

IsWinNT() --> lNT
IsWin10() --> lWin10

Detectar la versión de Windows.

Funciones de Información del Sistema

ScreenWidth()

ScreenWidth() --> nPixels

Devuelve el ancho completo de la pantalla en píxeles. Útil para posicionar ventanas y diálogos relativos a los límites de la pantalla. 

local nW := ScreenWidth()
oWnd:SetSize( nW / 2, ScreenHeight() / 2 )

ScreenHeight()

ScreenHeight() --> nPixels

Devuelve la altura completa de la pantalla en píxeles. Se combina con ScreenWidth() para cálculos de centrado y dimensionamiento.

ScreenScaling()

ScreenScaling() --> nScale

Devuelve el factor de escalado DPI para el monitor principal. Devuelve 1.0 para 96 DPI (100%), 1.25 para 120 DPI (125%), 1.5 para 144 DPI (150%), etc. 

local nScale := ScreenScaling()
if nScale > 1.0
   MsgInfo( "Pantalla de alta densidad detectada: " + Str( nScale * 100, 3, 0 ) + "%" )
endif

IsWindows11()

IsWindows11() --> lBoolean

Devuelve .T. si la aplicación se ejecuta en Windows 11. Verifica el número de compilación de Windows (requiere compilación 22000 o superior). 

if IsWindows11()
   // Aplicar estilos específicos de Windows 11
   oWnd:lWin11 := .T.
endif

IsWindows10()

IsWindows10() --> lBoolean

Devuelve .T. si la aplicación se ejecuta en Windows 10.

IsWin64()

IsWin64() --> lBoolean

Devuelve .T. si se ejecuta en una versión de Windows de 64 bits, independientemente de si la aplicación en sí es de 32 o 64 bits. 

if IsWin64()
   ? "Ejecutándose en Windows de 64 bits"
endif

IsDarkTheme()

IsDarkTheme() --> lBoolean

Detecta si el tema oscuro de Windows (configuración de personalización) está actualmente activo. Útil para adaptar los colores de la aplicación en tiempo de ejecución. 

if IsDarkTheme()
   SetAppColors( CLR_BLACK, CLR_WHITE )
else
   SetAppColors( CLR_WHITE, CLR_BLACK )
endif

FW_IsTouchScreen()

FW_IsTouchScreen() --> lBoolean

Devuelve .T. si el sistema tiene capacidades de entrada táctil. Útil para adaptar la interfaz de usuario proporcionando objetivos táctiles más grandes y soporte de gestos. 

if FW_IsTouchScreen()
   oBtn:SetSize( 64, 48 )  // botones más grandes para táctil
endif

FW_IsMousePresent()

FW_IsMousePresent() --> lBoolean

Devuelve .T. si al menos un ratón está conectado al sistema. Útil para dispositivos solo táctiles donde los efectos hover y el clic derecho pueden no aplicarse. 

if ! FW_IsMousePresent()
   // Habilitar navegación táctil
   oWnd:SetTouchMode( .T. )
endif

GetCPUSpeed()

GetCPUSpeed() --> nMhz

Devuelve la velocidad aproximada de la CPU en MHz. Utiliza contadores de rendimiento de Windows para estimar la frecuencia del reloj del procesador. 

? "Velocidad de CPU:", GetCPUSpeed(), "MHz"

FW_ActiveMonitors()

FW_ActiveMonitors() --> nCount

Devuelve el número de monitores activos conectados al sistema. Útil para configuraciones multimonitor y colocación de ventanas. 

if FW_ActiveMonitors() > 1
   // Posicionar ventana en el monitor secundario
   oWnd:SetWindowPos(, 1920, 100, 800, 600 )
endif

cWinVersion()

cWinVersion() --> cVersion

Devuelve una cadena legible de versión de Windows como "Windows 11 Pro" o "Windows 10 Enterprise". Incluye información de edición cuando está disponible. 

? "SO:", cWinVersion()

ScrResolution()

ScrResolution() --> { nWidth, nHeight }

Devuelve la resolución de la pantalla como un array de ancho y alto en píxeles. Similar a ScreenWidth()/ScreenHeight() pero devuelve ambos en una sola llamada. 

local aRes := ScrResolution()
oWnd:SetSize( aRes[ 1 ] * 0.75, aRes[ 2 ] * 0.75 )

WndCenterEx()

WndCenterEx( hWnd, hParent ) --> nil

Centra una ventana en el monitor donde se muestra actualmente la ventana padre. A diferencia de la función básica WndCenter(), esta función maneja correctamente configuraciones multimonitor. 

WndCenterEx( hWnd, hParent )
// Centra la ventana hija en el mismo monitor que su padre

Funciones de Shell y Proceso

ShellExecute()

ShellExecute( nHwnd, cOperation, cFile [, cParams [, cDir [, nShowCmd ] ] ] ) --> nResult

Ejecutar o abrir un archivo usando el shell de Windows. Operaciones comunes: "open", "print", "explore", "runas". 

// Abrir un archivo con su aplicación predeterminada
ShellExecute( 0, "open", "report.pdf" )

// Abrir una URL en el navegador predeterminado
ShellExecute( 0, "open", "https://www.fivetechsoft.com" )

// Abrir el Explorador de Windows en una carpeta
ShellExecute( 0, "explore", "C:\data\" )

// Imprimir un documento
ShellExecute( 0, "print", "document.docx" )

// Ejecutar como administrador
ShellExecute( 0, "runas", "myapp.exe" )

WinExec()

WinExec( cCommandLine [, nShowCmd ] ) --> nResult

Ejecutar un programa. Alternativa simple a ShellExecute para lanzar ejecutables. 

WinExec( "notepad.exe C:\data\log.txt" )
WinExec( "calc.exe" )

Funciones del Sistema de Archivos

lIsDir()

lIsDir( cDirName ) --> lBoolean

Verifica si la ruta especificada es un directorio existente. Devuelve .T. si el directorio existe y es accesible. 

if ! lIsDir( "C:\data\backup" )
   lMkDir( "C:\data\backup" )
endif

lMkDir()

lMkDir( cPath ) --> lSuccess

Crea un directorio. Devuelve .T. en caso de éxito. Crea directorios intermedios si es necesario (similar a mkdir -p). 

if lMkDir( "C:\data\reports\2026\may" )
   ? "Directorio creado exitosamente"
endif

cFilePath()

cFilePath( cPathMask ) --> cPath

Extrae la porción de ruta de una ruta de archivo completa, excluyendo el nombre del archivo. Incluye la barra invertida final. 

? cFilePath( "C:\data\app\myfile.txt" )  // "C:\data\app\"

cFileNoPath()

cFileNoPath( cPathMask ) --> cFileName

Extrae la porción del nombre de archivo de una ruta completa, excluyendo la ruta del directorio. La inversa de cFilePath(). 

? cFileNoPath( "C:\data\app\myfile.txt" )  // "myfile.txt"

cFileNoExt()

cFileNoExt( cPathMask ) --> cName

Devuelve el nombre del archivo sin su extensión. Elimina todo después del último punto. 

? cFileNoExt( "C:\data\app\myfile.txt" )  // "C:\data\app\myfile"

cFileExt()

cFileExt( cPathMask ) --> cExt

Devuelve la extensión del archivo sin el punto. La inversa de cFileNoExt(). 

? cFileExt( "myfile.txt" )  // "txt"
? cFileExt( "C:\data\app\myfile.dbf" )  // "dbf"

cNewFileName()

cNewFileName( cRootName, cExt ) --> cFileName

Genera un nombre de archivo único añadiendo un sufijo numérico si el archivo destino ya existe. Útil para rutinas de copia de seguridad y exportación. 

local cName := cNewFileName( "backup", "zip" )
// Devuelve "backup.zip" o "backup_001.zip", "backup_002.zip", etc.

cTempFile()

cTempFile( cPath, cExtension ) --> cFileName

Crea un archivo temporal con un nombre único en el directorio especificado. El archivo se crea en disco pero se deja vacío para que el llamador escriba. 

local cTmp := cTempFile( "C:\temp", "tmp" )
? "Archivo temporal:", cTmp

FSize()

FSize( cFile ) --> nFileSize

Devuelve el tamaño de un archivo en bytes. Devuelve -1 si el archivo no existe o no se puede acceder. 

local nBytes := FSize( "C:\data\largefile.dbf" )
? "Tamaño del archivo:", nBytes, "bytes"
? "En KB:", nBytes / 1024

FDate()

FDate( cFile ) --> dFileDate

Devuelve la fecha de última modificación de un archivo como un valor de fecha de Harbour. 

local d := FDate( "C:\data\customer.dbf" )
? "Última modificación:", d

FTime()

FTime( cFile ) --> cFileTime

Devuelve la hora de última modificación de un archivo como una cadena de caracteres en formato "HH:MM:SS". 

local cTime := FTime( "C:\data\customer.dbf" )
? "Última modificación a las:", cTime

ADrives()

ADrives( nType ) --> aDrives

Devuelve un array de letras de unidad disponibles. El parámetro nType filtra por tipo de unidad: 0 = todas las unidades, 1 = disqueteras, 2 = discos duros, 3 = unidades de red, 4 = unidades CD/DVD, 5 = unidades RAM. 

local aHD := ADrives( 2 )  // solo discos duros
? "Unidades fijas:"
AEval( aHD, { |c| QOut( c ) } )

FW_MEMOWRIT()

FW_MEMOWRIT( cFile, cText ) --> lSuccess

Escribe contenido de texto en un archivo, sobrescribiendo cualquier contenido existente. Devuelve .T. en caso de éxito. Un envoltorio simplificado alrededor de MemoWrit() de Harbour. 

if FW_MEMOWRIT( "C:\log\output.txt", "Proceso completado a las " + Time() )
   ? "Archivo escrito exitosamente"
endif

aFindFile()

aFindFile( cFileName, cPath ) --> aFiles

Busca recursivamente archivos que coincidan con un patrón bajo la ruta de directorio especificada. Devuelve un array de rutas completas de archivos. 

local aPrgs := aFindFile( "*.prg", "C:\fwteam\source" )
? "Encontrados " + LTrim( Str( Len( aPrgs ) ) ) + " archivos PRG"

Funciones de Color

GetSysColor()

GetSysColor( nIndex ) --> nRGBColor

Obtener un color del sistema Windows. Índices comunes: COLOR_WINDOW (5), COLOR_WINDOWTEXT (8), COLOR_BTNFACE (15), COLOR_HIGHLIGHT (13), COLOR_HIGHLIGHTTEXT (14). 

local nBgColor := GetSysColor( 5 )  // Color de fondo de ventana

nRGB()

nRGB( nRed, nGreen, nBlue ) --> nRGBColor

Crear un valor de color RGB a partir de componentes individuales (0-255 cada uno).

local nRed   := nRGB( 255, 0, 0 )
local nGreen := nRGB( 0, 128, 0 )
local nBlue  := nRGB( 0, 0, 255 )
local nCustom := nRGB( 45, 52, 64 )  // gris-azul oscuro

Constantes CLR_*

CLR_BLACK, CLR_WHITE, CLR_RED, CLR_GREEN, CLR_BLUE,
CLR_YELLOW, CLR_CYAN, CLR_MAGENTA, CLR_BROWN, CLR_GRAY,
CLR_LIGHTGRAY, CLR_HGRAY, CLR_HRED, CLR_HGREEN, CLR_HBLUE,
CLR_HCYAN, CLR_HMAGENTA

Funciones de Imagen y Dibujo

FW_ReadImage()

FW_ReadImage( oWnd, uSource, aResize ) --> aImageInfo

Carga una imagen desde una ruta de archivo, URL, identificador de recurso o buffer de memoria. Devuelve un array: { hBitmap, hPalette, nWidth, nHeight, lAlpha, cName }. Soporta los formatos BMP, PNG, JPG, GIF y TIFF a través de GDI+. 

local aImg := FW_ReadImage( oWnd, "logo.png" )
if aImg[ 5 ]  // tiene canal alfa
   oBmp:SetBitmap( aImg[ 1 ] )
endif

FW_DrawImage()

FW_DrawImage( oWnd, hBmp, aRect, lTransp, nResize, nAlpha, lGray, cAlign )

Dibuja una imagen en una ventana o contexto de dispositivo con redimensionamiento opcional, mezcla alfa, conversión a escala de grises y alineación (C = centro, T = superior, B = inferior, L = izquierda, R = derecha). 

// Dibujar imagen centrada y semitransparente
FW_DrawImage( oWnd, hBmp, { 10, 10, 210, 210 }, .F., 0, 128, .F., "C" )

FW_SaveImage()

FW_SaveImage( uImage, cFile, nJpegQuality )

Guarda una imagen (handle o array de imagen) en un archivo. El formato de salida está determinado por la extensión del archivo: BMP, PNG, JPG, GIF o TIFF. El parámetro nJpegQuality (1-100) controla la calidad de compresión JPEG. 

FW_SaveImage( hBitmap, "thumbnail.jpg", 85 )

FW_SaveThumbNail()

FW_SaveThumbNail( cImage, cThumb, nWidth, nHeight ) --> lSuccess

Crea una imagen en miniatura a partir de un archivo de imagen fuente, guardándola en la ruta especificada. Mantiene la relación de aspecto mientras se ajusta a las dimensiones dadas. 

FW_SaveThumbNail( "photo.jpg", "thumb.jpg", 150, 150 )

FW_ImageToBLOB()

FW_ImageToBLOB( uImage, cType, nQuality ) --> cBuffer

Convierte una imagen a un BLOB binario (buffer de memoria) adecuado para almacenar en un campo de base de datos. El parámetro cType especifica el formato de salida ("JPG", "PNG", "BMP", "GIF"). 

local cBlob := FW_ImageToBLOB( hBmp, "JPG", 80 )
oRs:Fields( "photo" ):Value := cBlob

FW_TextToBitmap()

FW_TextToBitmap( cText, oFont, nClrText, nClrBack ) --> hBitmap

Renderiza texto en un handle de bitmap usando la fuente y colores especificados. Útil para crear etiquetas basadas en imágenes, marcas de agua o superposiciones de texto. 

local hBmp := FW_TextToBitmap( "Hello World", oFont, nRGB( 255,0,0 ), CLR_WHITE )

FW_BarCodeBmp()

FW_BarCodeBmp( cText, cType, nWidth, nHeight ) --> hBitmap

Genera un bitmap de código de barras a partir de datos de texto. Los tipos de código de barras soportados incluyen "EAN13", "CODE128", "CODE39", "UPCA", "QR" y más. 

local hBmp := FW_BarCodeBmp( "123456789012", "EAN13", 200, 60 )
oImage:SetBitmap( hBmp )

FW_DrawShadow()

FW_DrawShadow( hDC, aRect, nSize, nAlpha )

Dibuja un efecto de sombra paralela alrededor de un rectángulo en el contexto de dispositivo dado. El parámetro nSize controla el ancho de la sombra y nAlpha (0-255) controla la opacidad. 

FW_DrawShadow( hDC, { 10, 10, 300, 200 }, 8, 80 )

DrawProgressBar()

DrawProgressBar( hDC, aRect, nValue, nTotal, aColors )

Funciones de Formato y Conversión de Datos

cValToStr()

cValToStr( uVal, cPic ) --> cString

Convierte cualquier valor Harbour a una cadena formateada. El parámetro cPic acepta máscaras de fecha/hora como "dd/mm/yyyy hh:mi:ss" y "dddd, mmmm dd, yyyy", lo que lo hace más flexible que cValToChar(). 

? cValToStr( Date(), "dddd, mmmm dd, yyyy" )  // "Thursday, May 28, 2026"
? cValToStr( 1234.56, "999,999.99" )            // "  1,234.56"
? cValToStr( .T., "Yes/No" )                    // "Yes"

FW_TRANSFORM()

FW_TRANSFORM( uVal, cPic ) --> cString

Versión mejorada de Transform() que soporta tokens de fecha (dd, mmm, yyyy, hh, mi, ss) en la cadena de formato. Convierte automáticamente valores de fecha y numéricos a su cadena formateada apropiada. 

? FW_TRANSFORM( Date(), "dd/mm/yyyy" )  // "28/05/2026"
? FW_TRANSFORM( DateTime(), "dd-mm-yyyy hh:mi:ss" )

uCharToVal()

uCharToVal( cText, cType ) --> uVal

Convierte una cadena a un valor tipado basado en el tipo especificado ("N", "D", "L", "C"). Cuando se omite cType, detecta automáticamente el tipo a partir del contenido de la cadena. 

? uCharToVal( "123.45", "N" ) + 1        // 124.45
? uCharToVal( "20260324", "D" )           // 03/24/2026 (formato Sett)
? uCharToVal( ".T.", "L" )                // .T.
? uCharToVal( "123.45" )                  // detectado automáticamente como numérico

nStrToNum()

nStrToNum( cNum, lEuropean ) --> nValue

Analiza una cadena numérica que contiene separadores de miles y marcadores decimales. Cuando lEuropean es .T., trata la coma como separador decimal y el punto como separador de miles. Cuando es .F. (predeterminado), usa la convención americana. 

? nStrToNum( "1,234.56", .F. )   // 1234.56 (Americano)
? nStrToNum( "1.234,56", .T. )   // 1234.56 (Europeo)

FWNumFormat()

FWNumFormat( cFormat, lThouSep ) --> aPrev

Establece u obtiene el formato numérico actual para visualización. El parámetro cFormat acepta "A" (Americano: 1,234.56), "E" (Europeo: 1.234,56), "B" (Británico: 1,234.56), "I" (Indio: 12,34,56.78). Devuelve la configuración de formato anterior. 

FWNumFormat( "E", .T. )       // Cambiar a formato europeo
? Str( 1234567.89, 12, 2 )    // "1.234.567,89"

FW_ValToCSV()

FW_ValToCSV( uVal ) --> cCSV

Convierte un valor único a su representación CSV. Maneja el entrecomillado y escape automáticamente según el tipo de valor. 

? FW_ValToCSV( "Smith, John" )  // '"Smith, John"' (entrecomillado por la coma)
? FW_ValToCSV( 1234 )            // "1234"

FW_ArrayToCSV()

FW_ArrayToCSV( aData, aHead ) --> cCSV

Convierte un array (típicamente de un browse o consulta) a formato CSV. El parámetro opcional aHead proporciona encabezados de columna. Devuelve el texto CSV completo. 

local aData := { { "John", 30 }, { "Jane", 25 } }
local aHead := { "Name", "Age" }
local cCSV  := FW_ArrayToCSV( aData, aHead )
FW_MEMOWRIT( "export.csv", cCSV )

FW_ValToJSON / FW_JsonDecode()

FW_ValToJSON( uVal [, lPretty ] ) --> cJson
FW_JsonDecode( cJson ) --> uVal

Convierte un valor Harbour (array, hash o tipo simple) a cadena JSON y viceversa. La bandera lPretty habilita la salida indentada legible. Maneja estructuras anidadas, fechas y valores nil. 

local hData := { "name" => "John", "age" => 30 }
local cJson := FW_ValToJSON( hData, .T. )
// {
//   "name": "John",
//   "age": 30
// }

local hParsed := FW_JsonDecode( cJson )
? hParsed[ "name" ]  // "John"

FW_ArrayToHTML( aData, aHead, cCaption ) --> cHTML

Convierte un array 2D a una tabla HTML con encabezados y título opcionales. Devuelve una cadena completa de elemento <table> lista para visualización web o correo electrónico. 

local aData := { { "Item A", 10.99 }, { "Item B", 25.50 } }

FW_ProperCase( cText ) --> cString

Convierte una cadena a mayúsculas iniciales, capitalizando la primera letra de cada palabra y convirtiendo el resto a minúsculas. Maneja casos especiales como prefijos Mc- y O'-. 

? FW_ProperCase( "john doe" )            // "John Doe"
? FW_ProperCase( "o'brien" )             // "O'Brien"

FW_UTF8LEFT / FW_UTF8RIGHT / FW_UTF8SUBSTR()

FW_UTF8LEFT( cText, nCount ) --> cText
FW_UTF8RIGHT( cText, nCount ) --> cText
FW_UTF8SUBSTR( cText, nStart [, nCount ] ) --> cText

Versiones seguras para UTF-8 de Left(), Right() y SubStr(). Estas funciones cuentan caracteres (no bytes), lo que las hace seguras para usar con texto UTF-8 multibyte que incluye caracteres acentuados, ideogramas CJK y emojis. 

? FW_UTF8LEFT( "Café", 3 )               // "Caf"

FW_ArrayAsList()

FW_ArrayAsList( aItems, cDelim ) --> cString

Une un array de cadenas en una sola cadena delimitada, similar a implode() de PHP. Cada elemento se convierte a su representación de cadena. 

local aItems := { "Red", "Green", "Blue" }

FW_ListAsArray()

FW_ListAsArray( cList, cDelim ) --> aArray

Divide una cadena delimitada en un array, la inversa de FW_ArrayAsList(). Elimina espacios en blanco de cada elemento.

nRandom()

nRandom( nMin, nMax ) --> nRandom

Devuelve un entero aleatorio entre nMin y nMax, inclusive. Utiliza un generador aleatorio criptográficamente seguro cuando está disponible, recurriendo al RNG estándar de Harbour. 

local nDice := nRandom( 1, 6 )        // tirada de dado: 1-6
local nPick := nRandom( 1, 100 )      // porcentaje aleatorio

nHex()

nHex( nVal ) --> cHex

Convierte un valor numérico a su representación hexadecimal en cadena. Rellenado al menos a dos dígitos hexadecimales.

? nHex( 3735928559 )  // "DEADBEEF"

Funciones de Array y Datos

FW_DbfToArray()

FW_DbfToArray( cAlias, bFor, bWhile, nNext, nRecNo, lRest ) --> aData

Copia registros de un área de trabajo DBF a un array 2D. Soporta filtrado de alcance mediante condiciones FOR/WHILE, NEXT n, número de registro o alcance REST (compatible con SET FILTER). Devuelve un array vacío si no hay registros que coincidan. 

use customer alias cust shared
local aData := FW_DbfToArray( "cust", { || Cust->State = "CA" } )
? "Clientes de California:", Len( aData )

FW_ArrayToDBF()

FW_ArrayToDBF( aData, cAlias, lOverWrite )

Escribe datos de un array 2D en un archivo DBF. El parámetro cAlias especifica el alias y archivo de destino. Cuando lOverWrite es .T., reemplaza los datos existentes; de lo contrario, añade. 

local aData := { { "John", "Doe", 30 }, { "Jane", "Smith", 25 } }

FW_DbfToHash()

FW_DbfToHash( cAlias ) --> hHash

Convierte el registro actual de un DBF abierto a un hash/array asociativo, donde los nombres de campo se convierten en claves y los valores de campo en valores. Útil para serialización JSON y transferencia de registros. 

use customer alias cust shared
go top

? hRec[ "FIRST" ], hRec[ "LAST" ]

FW_HashToRec()

FW_HashToRec( hHash )

Escribe pares clave/valor de un hash en el registro actual de un DBF abierto. Los nombres de campo en el hash deben coincidir con los nombres de campo del DBF. Mapeo de hash a registro, la inversa de FW_DbfToHash(). 

local hData := { "FIRST" => "Alice", "LAST" => "Brown", "AGE" => 28 }
FW_HashToRec( hData )

FW_RecToJson( cAlias ) --> cJson

ArrTranspose()

ArrTranspose( aArray ) --> aArray

Transpone un array 2D, intercambiando filas y columnas. Útil para convertir datos orientados a filas a formato orientado a columnas (por ejemplo, para gráficos o visualización de tablas cruzadas).

Calcula la suma de una columna específica en un array 2D. Trata los valores no numéricos como cero.

FW_ArrGroupSum()

FW_ArrGroupSum( aArray, nGrpCol, nValCol ) --> aResult

Agrupa filas en un array 2D por una columna clave y suma una columna de valor dentro de cada grupo. Devuelve un array resultante de pares { clave, suma }.

ASHUFLE()

ASHUFLE( aArray ) --> aArray

Mezcla aleatoriamente los elementos de un array in-place usando el algoritmo Fisher-Yates. Devuelve la misma referencia del array, ahora reordenado. 

local aCards := { "Ace", "King", "Queen", "Jack", "Ten" }

FW_AReverse()

FW_AReverse( aArray, nStart, nCount ) --> aArray

Invierte el orden de los elementos en un subconjunto de un array. Cuando se omiten nStart y nCount, invierte todo el array. Devuelve la misma referencia del array.

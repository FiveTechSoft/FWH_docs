Funciones de Renderizado Gráfico

Fuente: source/function/imgtxtio.prg, source/winapi/gdipfwh.cpp

Las funciones de renderizado gráfico de FiveWin proporcionan las primitivas de dibujo básicas para toda la salida visual en ventanas, diálogos, impresoras y documentos PDF. Abstraen las operaciones de Windows GDI y GDI+, gestionando la conversión de recursos, la mezcla alfa (alpha blending), los rellenos con degradado y las transformaciones de coordenadas. La capa intermedia en imgtxtio.prg convierte los tipos de datos de Harbour (colores, arrays, objetos) en manejadores GDI de bajo nivel.

FW_Box() - Renderizado de Formas

FW_Box( hDC, aRect, uPen, uBrush, aText, nShape )

Dibuja rectángulos, rectángulos redondeados o elipses con plumas y brochas personalizables. Admite rellenos con degradado, mezcla alfa y texto opcional dentro de la forma.

ParámetroTipoDescripción
hDCManejador / ObjetoManejador de contexto de dispositivo, objeto TWindow, TDialog o TPrinter
aRectArray{ nTop, nLeft, nBottom, nRight } en píxeles
uPenVariosColor de pluma (numérico), array { color, nWidth }, objeto TPen o manejador
uBrushVariosColor de brocha, array de degradado, objeto TBrush o manejador de imagen
aTextArray / NilOpcional { cText, oFont, nClrText, cAlign } para dibujar dentro de la forma
nShapeNuméricoConstante de forma: 0 = Rectángulo, 1 = RoundRect, 2 = Elipse

FW_SayText() - Renderizado de Texto

FW_SayText( oWnd, cText, aRect, cAlign, oFont, nClrText, nClrBack, lBorder, nAddStyle )

Dibuja texto con control total de alineación, ajuste de palabras y relleno de fondo opcional. Admite el renderizado con GDI+ para colores con alfa y formato RTF básico.

IndicadorSignificado
CCentrar horizontalmente
LAlinear a la izquierda
RAlinear a la derecha
TAlinear arriba verticalmente
BAlinear abajo verticalmente
WAjuste de palabras

Los indicadores de alineación se combinan libremente: "CR" = centro-derecha, "TL" = arriba-izquierda, "CB" = centro-abajo.

Variantes de Texto

  • FW_SayHollow( hDC, cText, aRect, cAlign, oFont, nClrText, nClrBack ) - Renderiza el texto hueco (solo contorno) usando GDI o GDI+.
  • FW_SayTextHilite( oWnd, cText, aRect, cAlign, oFont, nClrText, nClrBack, aHilite, aFonts, aClrs ) - Renderiza el texto resaltando palabras concretas con distintas fuentes y colores.
  • FW_SayTextSpread( hDC, cText, aRect, oFont, nClrText, nClrBack, nAngle ) - Distribuye los caracteres uniformemente a lo ancho del rectángulo de destino.

FW_DrawImage() - Renderizado de Imágenes

FW_DrawImage( oWnd, hBmp, aRect, lTransp, nResize, nAlpha, lGray, cAlign, aColorMap )

Dibuja un bitmap sobre una ventana o contexto de dispositivo con soporte para modos de redimensionado, mezcla alfa, escala de grises y mapeo de colores.

nResizeConstanteComportamiento
0FIT_CENTERCentrar al tamaño original, sin escalado
1FIT_WIDTHEscalar al ancho del rectángulo, manteniendo la relación de aspecto
2FIT_HEIGHTEscalar al alto del rectángulo, manteniendo la relación de aspecto
3FIT_RECTEstirar para llenar el rectángulo de destino (puede distorsionar)
4FIT_ORGLMostrar al tamaño de píxel original, recortado si es mayor

Asigne a nAlpha un valor entre 0 (invisible) y 255 (opaco) para un renderizado semitransparente. Asigne .T. a lGray para la conversión a escala de grises. aColorMap es un array opcional de reemplazos de color { nFrom, nTo }.

FW_DrawShadow()

FW_DrawShadow( hDC, aRect, nSize, nAlpha )

Dibuja un efecto de sombra paralela alrededor de un rectángulo. nSize controla el ancho de la sombra en píxeles (normalmente 4-12), y nAlpha (0-255) controla la opacidad. La sombra se difumina de opaca en el borde a transparente hacia fuera.

GradientFill()

GradientFill( hDC, nTop, nLeft, nBottom, nRight, aGradInfo, lVert )

Rellena una región rectangular con un degradado de múltiples paradas. aGradInfo es un array de paradas { nColor }; dos paradas producen una mezcla simple, tres o más crean transiciones de varios pasos. Asigne .T. a lVert para un degradado vertical (de arriba a abajo) o .F. para horizontal (de izquierda a derecha).

Funciones de Dibujo Adicionales

  • FW_DrawShapes( oWnd, aShapes, aRect ) - Dibuja por lotes varias formas (rectángulo, roundrect, elipse, línea, polígono) a partir de un array de descriptores { nShape, aRect, uPen, uBrush }.
  • FW_PieChart( oWnd, aRect, aValues, aColors ) - Dibuja un gráfico de tarta/anillo a partir de arrays de datos numéricos y colores.
  • FillRectEx( hDC, aRect, nClr ) - Relleno de rectángulo con color sólido sin la sobrecarga de crear una brocha.
  • RingGradientFill( hDC, nTop, nLeft, nBottom, nRight, aGradInfo, nAngle ) - Relleno con degradado radial/anular para efectos brillantes y fondos personalizados.

Ejemplo: Caja con Texto y Sombra

#include "FiveWin.ch"

function DrawSample( hDC, oWnd )

   local aRect := { 50, 50, 350, 250 }
   local oFont := TFont():New( "Segoe UI", 0, -18 )

   // Dibujar primero la sombra paralela
   FW_DrawShadow( hDC, aRect, 8, 80 )

   // Dibujar un rectángulo redondeado con relleno de degradado
   FW_Box( hDC, aRect, CLR_BLUE, ;
           { CLR_WHITE, CLR_HBLUE }, ;
           { "Hello FWH Graphics", oFont, CLR_BLACK, "CR" }, ;
           1 ) // RoundRect

   oFont:End()

return nil

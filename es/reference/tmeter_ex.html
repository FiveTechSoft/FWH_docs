TMeterEx

Fuente: source/classes/tmeterex.prg

Hereda de: TControl

TMeterEx es un control de barra de progreso extendido con renderizado de doble gradiente. Muestra una barra de progreso rellena sobre una pista de fondo, admitiendo definiciones de gradiente personalizadas, esquinas redondeadas, superposición opcional de bitmap, orientación vertical y dirección de relleno invertida. El valor del medidor se gestiona mediante un bloque de código bSetGet.

Ejemplo: Medidor de Doble Valor

#include "FiveWin.ch"

function Main()

   local oWnd, oMeter, nVal := 50

   DEFINE WINDOW oWnd TITLE "TMeterEx Demo" SIZE 400, 150

   @ 30, 30 METEREX oMeter VAR nVal TOTAL 100 ;
      SIZE 340, 28 OF oWnd ;
      GRADIENTS { { 1, CLR_GRAY, CLR_WHITE } }, ;
                 { { 1, CLR_GREEN, CLR_YELLOW } } ;
      ROUND

   @ 80, 30 BUTTON "Update" SIZE 60, 25 ;
      ACTION ( nVal += 10, oMeter:Set( nVal ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use la cláusula GRADIENTS para establecer aGrad (fondo de la pista) y aGradMet (relleno de progreso). Cada uno es un array de entradas { fracción, colorDesde, colorHasta }.
  • La cláusula ROUND activa las esquinas redondeadas con un radio predeterminado de 3; pase nRound para un radio personalizado.
  • lVertical dibuja el medidor de abajo hacia arriba; lInverted invierte la dirección de relleno (de derecha a izquierda o de arriba hacia abajo).
  • Se puede especificar una superposición de bitmap mediante cBitmap: el bitmap se redimensiona y se dibuja sobre el área rellena.

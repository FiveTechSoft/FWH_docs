Recursos GDI

FiveWin encapsula los objetos GDI (Graphics Device Interface) de Windows en clases de Harbour. Estos objetos representan fuentes, brochas, cursores, iconos, bitmaps e imágenes. Todos los recursos GDI deben liberarse cuando ya no se necesiten llamando a :End() para evitar fugas de recursos. Esta página también cubre TIni (gestión de archivos INI) y TReg32 (acceso al Registro de Windows).

Ciclo de Vida de los Recursos

TFont

Fuente: source/classes/font.prg

Miembros DATA Principales

DATATipoDescripción
cFaceNameCharacterNombre de la fuente (ej. "Arial", "Segoe UI")
hFontNumericHandle HFONT de Windows
lBoldLogicalPeso negrita
lItalicLogicalEstilo cursiva
lUnderlineLogicalDecoración subrayado
lStrikeOutLogicalDecoración tachado
nWeightNumericPeso de la fuente (400=normal, 700=negrita)
nCharSetNumericConjunto de caracteres (0=ANSI, 1=DEFAULT, 255=OEM)
nEscapementNumericÁngulo del texto en décimas de grado
nOrientationNumericÁngulo de orientación de caracteres
nInpHeightNumericAltura solicitada (negativo = tamaño en puntos)

Métodos Principales

MétodoDescripción
New( cFaceName, nWidth, nHeight, lFromUser, lBold, ... )Crea una fuente (o devuelve una instancia en caché)
Choose( @nRGBColor )Muestra el diálogo de selección de fuente, devuelve la fuente seleccionada
nSize()Obtiene el tamaño de la fuente en puntos
Bold( lBold )Crea una nueva fuente con negrita alternada
Italic( lItalic )Crea una nueva fuente con cursiva alternada
Modify( nHeight, lBold, lItalic, lUnderline, lStrikeOut, nEsc )Crea una copia modificada
Rotate( nRotateBy )Crea una copia rotada
Clone()Comparte el mismo handle (conteo de referencias)
Activate( hDC )Selecciona la fuente en un contexto de dispositivo
DeActivate( hDC )Restaura la fuente anterior
End()Libera el handle de la fuente

Ejemplo

#include "FiveWin.ch"

function Main()

   local oFont, oFontBig, oFontItalic

   // Definición estándar mediante comando
   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14

   // Variante negrita
   DEFINE FONT oFontBig NAME "Segoe UI" SIZE 0, -20 BOLD

   // Cursiva mediante método
   oFontItalic := oFont:Italic( .T. )

   // Usar en un diálogo
   DEFINE DIALOG oDlg TITLE "Font Demo" SIZE 400, 200 FONT oFont
   @ 1, 1 SAY "Normal text" OF oDlg
   @ 2, 1 SAY "Bold text" OF oDlg FONT oFontBig
   @ 3, 1 SAY "Italic text" OF oDlg FONT oFontItalic
   ACTIVATE DIALOG oDlg CENTER

   // Selector de fuente
   // local oChosen := oFont:Choose()

   oFont:End()
   oFontBig:End()
   oFontItalic:End()

return nil

TBitmap

lScrollLogicalHabilitar desplazamiento
lTransparentLogicalFondo transparente
lHasAlphaLogicalLa imagen tiene canal alfa
nZoomNumericNivel de zoom (1 = 100%)
nImgWidthNumericAncho original de la imagen
nImgHeightNumericAlto original de la imagen

Métodos Principales

MétodoDescripción
LoadFromClipboard( oWnd )Cargar bitmap desde el portapapeles
CopyToClipboard()Copiar bitmap al portapapeles
LoadFromString( cString )Cargar bitmap desde una cadena binaria
Zoom( nZoom )Establecer nivel de zoom

Ejemplo

#include "FiveWin.ch"

function Main()

   local oDlg, oBmp

   DEFINE DIALOG oDlg TITLE "Bitmap Demo" SIZE 600, 400

   @ 1, 1 BITMAP oBmp FILE "photo.bmp" OF oDlg SIZE 250, 180 STRETCH

   // o desde recurso:
   // @ 1, 1 BITMAP oBmp RESOURCE "LOGO" OF oDlg SIZE 250, 180

   ACTIVATE DIALOG oDlg CENTER

return nil

TImage

Fuente: source/classes/image.prg

TImage extiende TBitmap con soporte de la biblioteca FreeImage, permitiendo cargar y guardar muchos formatos de imagen: BMP, PNG, JPEG, GIF, TIFF, WebP, ICO, PSD, RAW, y más. También puede cargar imágenes desde URLs.

Métodos Adicionales (más allá de TBitmap)

MétodoDescripción
LoadImage( cResName, cBmpFile, cResFile )Cargar cualquier formato mediante FreeImage
SaveImage( cFile, nFormat, nQuality )Guardar en cualquier formato soportado
LoadFromURL( cUrl )Descargar y mostrar una imagen desde una URL
LoadFromMemory( cBuffer, nWidth, nHeight )Cargar desde un buffer de memoria
RotateImage( nAngle )Rotar la imagen n grados
Progress( lProgress )Mostrar/ocultar progreso de carga

DLL FreeImage

TImage requiere freeimage.dll (32-bit) o freeimage64.dll (64-bit) en el directorio de la aplicación o en el PATH del sistema.

Ejemplo

#include "FiveWin.ch"

function Main()

   local oDlg, oImg

   DEFINE DIALOG oDlg TITLE "Image Demo" SIZE 800, 600

   // Cargar cualquier formato (PNG, JPG, GIF, WebP, etc.)
   @ 1, 1 IMAGE oImg FILE "photo.png" OF oDlg SIZE 350, 250 STRETCH

   // Cargar desde URL (después de iniciar el diálogo)
   // oImg:LoadFromURL( "https://example.com/image.jpg" )

   // Guardar en diferente formato
   // oImg:SaveImage( "output.jpg", FIF_JPEG, 85 )

   // Rotar
   // oImg:RotateImage( 90 )

   ACTIVATE DIALOG oDlg CENTER

return nil

TIni

Fuente: source/classes/ini.prg

TIni gestiona archivos de configuración INI de Windows. Utiliza las funciones de la API de Windows GetPrivateProfileString() y WritePrivateProfileString() para un acceso confiable a archivos INI.

Miembros DATA Principales

DATATipoDescripción
cIniFileCharacterRuta del archivo INI
lAutoSetLogicalAuto-guardar en Get (escribir valor por defecto si falta)

Métodos

MétodoDescripción
New( cIniFile )Crear gestor INI (agrega extensión ".ini" si falta)
Get( cSection, cEntry, uDefault, @uVar )Leer un valor (auto-detecta tipo desde el valor por defecto)
Set( cSection, cEntry, uValue )Escribir un valor
Sections()Obtener array con todos los nombres de sección
DelSection( cSection )Eliminar una sección completa
DelEntry( cSection, cEntry )Eliminar una entrada individual

Ejemplo

#include "FiveWin.ch"

function Main()

   local oIni, cUser, nPort, lDebug

   oIni := TIni():New( "myapp.ini" )

   // Leer configuraciones (con valores por defecto)
   oIni:Get( "Database", "Server",   "localhost", @cServer )
   oIni:Get( "Database", "Port",     3306,        @nPort )
   oIni:Get( "App",      "Debug",    "N",         @cDebug )

   lDebug := ( cDebug == "Y" )

   // Escribir configuraciones
   oIni:Set( "App", "LastRun", DToC( Date() ) + " " + Time() )
   oIni:Set( "App", "Version", FWVersion() )

   // Eliminar
   oIni:DelEntry( "Temp", "CacheFile" )

   ? "Server:", cServer, "Port:", nPort

return nil

Esto crea/lee un archivo INI como:

[Database]
Server=localhost
Port=3306

[App]
Debug=N
LastRun=03/24/2026 14:30:45
Version=FWH 26.05

TReg32

Fuente: source/classes/reg32.prg

TReg32 proporciona acceso de lectura/escritura al Registro de Windows. Encapsula las funciones de la API del Registro de Windows (RegOpenKeyEx, RegQueryValueEx, RegSetValueEx, etc.).

Miembros DATA Principales

DATATipoDescripción
cRegKeyCharacterRuta de la clave del registro
nKeyNumericClave raíz (HKEY_CURRENT_USER, HKEY_LOCAL_MACHINE, etc.)
nHandleNumericHandle de la clave abierta
nErrorNumericÚltimo código de error (0 = éxito)
lErrorLogicalIndicador de error

Métodos

MétodoDescripción
New( nKey, cRegKey )Abrir una clave de registro existente
Create( nKey, cRegKey )Crear una nueva clave de registro (o abrir si existe)
Get( cSubKey, @uVar )Leer un valor
GetBinary( cSubKey )Leer datos binarios
Set( cSubKey, uVar, nType )Escribir un valor (REG_SZ, REG_DWORD, REG_BINARY)
Delete( cSubKey )Eliminar una subclave
Close()Cerrar el handle de la clave del registro

Constantes de Clave Raíz

ConstanteDescripción
HKEY_CLASSES_ROOTAsociaciones de archivos y clases COM
HKEY_CURRENT_USERConfiguraciones del usuario actual
HKEY_LOCAL_MACHINEConfiguraciones de toda la máquina (requiere admin)
HKEY_USERSTodos los perfiles de usuario
HKEY_CURRENT_CONFIGConfiguración de hardware actual

Ejemplo

#include "FiveWin.ch"

#define HKEY_CURRENT_USER  2147483649

function Main()

   local oReg, cValue := ""

   // Leer un valor del registro
   oReg := TReg32():New( HKEY_CURRENT_USER, ;
      "Software\Microsoft\Windows\CurrentVersion\Themes\Personalize" )

   if oReg:nError == 0
      oReg:Get( "AppsUseLightTheme", @cValue )
      ? "Dark mode:", iif( cValue == Chr(0), "Yes", "No" )
      oReg:Close()
   endif

   // Crear y escribir un valor
   oReg := TReg32():Create( HKEY_CURRENT_USER, "Software\MyApp" )
   if oReg:nError == 0
      oReg:Set( "LastRun", DToC( Date() ) + " " + Time() )
      oReg:Set( "Version", FWVersion() )
      oReg:Close()
   endif

   // Leerlo de vuelta
   oReg := TReg32():New( HKEY_CURRENT_USER, "Software\MyApp" )
   if oReg:nError == 0
      oReg:Get( "LastRun", @cValue )
      ? "Last run:", cValue
      oReg:Close()
   endif

return nil

Mejores Prácticas de Gestión de Recursos

  • Siempre llame a :End() en los recursos GDI (TFont, TBrush, TIcon, TBitmap, TImage) cuando termine de usarlos. Windows tiene un conjunto limitado de handles GDI.
  • Caché de fuentes: TFont almacena fuentes en caché internamente. Crear la misma fuente dos veces devuelve el mismo objeto con un conteo de referencias incrementado. Llamar a :End() decrementa el conteo y solo libera el handle cuando llega a cero.
  • Brocha para ventanas: Al asignar una brocha a una ventana, la ventana toma posesión. La brocha se libera cuando la ventana es destruida.
  • TIni y TReg32 no usan handles GDI, pero TReg32:Close() debe llamarse para liberar el handle de la clave del registro.
  • Use GDI_GetObjectCount() durante el desarrollo para monitorear el uso de handles GDI y detectar fugas.

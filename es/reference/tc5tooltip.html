TC5Tooltip

Fuente: source/classes/c5tooltp.prg

Hereda de: TWindow

TC5Tooltip es una ventana emergente de tooltip enriquecida con soporte para texto de cuerpo multilínea, encabezado, pie, una imagen opcional en el lado izquierdo y colores personalizados de borde/fondo. Se renderiza como una ventana redondeada con sombra paralela, se autoajusta al contenido e incluye un temporizador de auto-cierre. El tooltip está diseñado para tooltips con tema de estilo C5 (CA-Visual Objects).

Ejemplo: Tooltip Enriquecido con Icono

#include "FiveWin.ch"

function Main()

   local oTip := TC5Tooltip():New( 100, 100, 250, 80, , , CLR_WHITE, CLR_YELLOW )

   oTip:cHeader := "Information"
   oTip:cBody   := "This is a rich tooltip with multi-line body text."
   oTip:cFoot   := "Tip: hover for details"
   oTip:cBmpLeft := "help.ico"
   oTip:lLineHeader := .T.
   oTip:Show()

return nil

Notas

  • El tooltip se auto-cierra después de nTimer milisegundos (por defecto 5000). Establezca lShowAgain a .F. para evitar que se vuelva a mostrar.
  • Usa CreateRoundRectRgn para las esquinas redondeadas y se registra con el estilo de clase CS_DROPSHADOW para el efecto de sombra paralela.
  • El texto del cuerpo usa DT_WORDBREAK para el ajuste automático de palabras dentro del ancho disponible.
  • Las tres secciones (encabezado, cuerpo, pie) son opcionales -- omítalas dejando vacío el DATA c* correspondiente.

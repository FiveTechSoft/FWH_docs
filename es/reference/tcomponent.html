TComponent / TDataBaseComp / TDbfComp

Fuentes: source/classes/tcompone.prg, source/classes/tdbasecomp.prg, source/classes/tdbfcomp.prg

TComponent FROM TControl; TDataBaseComp FROM TComponent; TDbfComp FROM TComponent

Las clases de componentes proporcionan un modelo de composición orientado a objetos para FiveWin. TComponent envuelve un objeto Harbour arbitrario (oObject) y le delega los mensajes, actuando como inspector/contenedor. TDataBaseComp lo extiende para tablas de bases de datos con eventos CRUD, y TDbfComp añade soporte de índices y relaciones específico de DBF. Las tres clases admiten la inspección de propiedades/eventos mediante los arrays aProperties y aEvents.

TComponent

TComponent hereda de TControl y envuelve un objeto destino (oObject). Su manejador de errores (Error()) delega automáticamente los mensajes desconocidos a oObject, de modo que puede interactuar con el objeto envuelto de forma transparente a través del componente.

DATA Principales

DATATipoDescripción
oObjectObjectEl objeto Harbour envuelto
aPropertiesArrayArray de descriptores de propiedades para el inspector
aEventsArrayArray de descriptores de eventos (pares de bloques de código)
bInspectBlockBloque de código evaluado cuando se solicita la inspección

MÉTODOs Principales

MétodoDescripción
New( oWnd, nId, oObject )Crea un componente que envuelve oObject
Error( ... )El manejador de errores delega automáticamente en oObject

TDataBaseComp

TDataBaseComp extiende TComponent para el acceso a tablas de bases de datos. Proporciona navegación y edición controladas por eventos con los callbacks OnOpen, OnSkip y OnSave.

DATA Principales

DATATipoDescripción
cFileCharacterRuta del archivo de la base de datos
cAliasCharacterAlias del área de trabajo
cDriverCharacterNombre del controlador RDD (p. ej. "DBFCDX")
OnOpenBlockBloque de código evaluado cuando se abre la tabla
OnSkipBlockBloque de código evaluado al navegar entre registros
OnSaveBlockBloque de código evaluado cuando se guarda un registro

MÉTODOs Principales

MétodoDescripción
CreateFromCode()Crea el componente mediante programación desde código
Skip( n )Avanza/retrocede n registros
Append()Añade un registro en blanco
Delete()Marca el registro actual como eliminado
Save()Confirma los cambios pendientes en disco

TDbfComp

TDbfComp extiende TComponent para operaciones específicas de DBF, incluyendo la gestión de índices y relaciones.

DATA Principales (propiedades SETGET)

DATATipoDescripción
cIndexNameCharacterNombre del archivo de índice
cTagNameCharacterNombre del tag del índice
aRelationsArrayArray de definiciones de relación con tablas hijas
lOpenedLogical (SETGET).T. si la tabla está abierta
lSelectedLogical (SETGET).T. si el área de trabajo está seleccionada
cAliasCharacter (SETGET)Nombre del alias del área de trabajo
cFileNameCharacter (SETGET)Ruta del archivo DBF
nWorkAreaNumeric (SETGET)Número del área de trabajo

Ejemplo: Componente de Base de Datos

#include "FiveWin.ch"

function Main()

   local oComp, oWnd

   DEFINE WINDOW oWnd TITLE "Component Demo" SIZE 600, 400

   // Crea un TDataBaseComp que envuelve una tabla de clientes
   oComp := TDataBaseComp():New( oWnd, 101 )
   oComp:cFile   := "customers.dbf"
   oComp:cDriver := "DBFCDX"

   oComp:OnOpen := { || MsgInfo( "Table opened!" ) }
   oComp:OnSkip := { || oWnd:SetText( "Rec: " + Str( oComp:RecNo() ) ) }

   oComp:CreateFromCode()
   oComp:GoTop()

   ACTIVATE WINDOW oWnd

return nil

Notas

  • El manejador de errores de TComponent intercepta cualquier acceso a método o dato no definido en el propio componente y lo reenvía a oObject. Esto hace que el objeto envuelto aparezca como si formara parte del componente.
  • Los arrays aProperties y aEvents están diseñados para usarse con el inspector de propiedades de FiveWin, permitiendo la edición visual en tiempo de diseño de las propiedades del componente.
  • Los bloques de eventos de TDataBaseComp (OnOpen, OnSkip, OnSave) se disparan automáticamente durante las operaciones de navegación y edición, lo que permite engancharse al ciclo de vida de los datos sin sobrescribir métodos.
  • Las propiedades SETGET de TDbfComp proporcionan validación en tiempo de ejecución al obtener o establecer el estado del área de trabajo.

Clases GDI+

Fuente: source/classes/tgdiplus.prg

Clases independientes: Graphics, Pen, Brush, GDIBmp, Path, Region

FiveWin proporciona un conjunto completo de clases envoltorio de GDI+ para renderizado 2D de alta calidad con suavizado de bordes (anti-aliasing), transparencia alfa, pinceles de degradado, dibujo basado en trazados, y procesamiento de imágenes. Estas clases encapsulan la API plana de GDI+ de Windows y no requieren componentes ActiveX externos. GDI+ se inicializa automáticamente cuando se instancia la primera clase.

Clase Graphics

La superficie de dibujo principal. Todas las operaciones de dibujo comienzan con un objeto Graphics.

MétodoDescripción
New( hDC [, lNoHighQuality] )Crea a partir de un manejador de contexto de dispositivo
NewWnd( hWnd [, lNoHighQuality] )Crea para dibujar sobre una ventana
NewFromWnd( oWnd [, lNoHighQuality] )Crea a partir de un objeto TWindow
NewImg( hImg [, lNoHighQuality] )Crea para renderizado de imagen fuera de pantalla
SetHighQuality()Activa el renderizado con suavizado de bordes
SetNormalQuality()Desactiva el suavizado de bordes para mayor velocidad
DrawLine( oPen, nLeft, nTop, nRight, nBottom )Dibuja una línea
DrawRect( oPen, oBrush, nLeft, nTop, nWidth, nHeight )Dibuja un rectángulo
DrawEllipse( oPen, oBrush, nLeft, nTop, nWidth, nHeight )Dibuja una elipse
DrawArc( oPen, nLeft, nTop, nW, nH, nStartAngle, nSweepAngle )Dibuja un arco
DrawRoundRect( oPen, oBrush, nLeft, nTop, nW, nH, nRadius )Dibuja un rectángulo redondeado
DrawPath( oPen, oPath )Dibuja el contorno de un trazado gráfico
FillPath( oBrush, oPath )Rellena un trazado gráfico
DrawImage( oImage, nTop, nLeft [, nW, nH] )Dibuja una imagen
Clear( nTrans, nRed, nGreen, nBlue )Limpia la superficie con un color ARGB
Translate( nRow, nCol )Traslada el sistema de coordenadas
Rotate( nAngle )Rota el sistema de coordenadas
Scale( nX, nY )Escala el sistema de coordenadas
Destroy()Libera el objeto graphics de GDI+

Clase Pen de GDI+

Lápiz de GDI+ para dibujar líneas con color, grosor y estilo.

MétodoDescripción
New( nAlpha, nR, nG, nB, nSize )Crea un lápiz con color ARGB y tamaño. Alfa 0..255.
SetColor( nAlpha, nR, nG, nB )Cambia el color del lápiz
SetSize( nSize )Cambia el grosor del lápiz
SetStyle( nStyle )Establece el estilo del lápiz (p. ej., GDI_PEN_ROUND para extremos redondeados)
SetLineJoin( nJoin )Establece el estilo de unión de líneas
Destroy()Libera el lápiz de GDI+

Clase Brush de GDI+

Pincel de GDI+ para rellenar formas con colores sólidos o degradados.

MétodoDescripción
NewSolidBrush( nAlpha, nR, nG, nB )Crea un pincel sólido ARGB
NewGradientBrush( nTop, nLeft, nW, nH, nType, nA1, nR1, nG1, nB1, nA2, nR2, nG2, nB2 )Crea un pincel de degradado lineal. nType: 0=horizontal, 1=vertical, 2=diagonal-derecha, 3=diagonal-izquierda.
AngleGradientBrush( ... nAngle, lScala )Crea un degradado con un ángulo arbitrario
Destroy()Libera el pincel de GDI+

Clase GDIBmp

Bitmap de GDI+ para cargar, manipular y guardar imágenes.

MétodoDescripción
New( cFile )Carga una imagen desde un archivo (BMP, JPG, GIF, TIF, PNG, EMF, WMF, ICO)
Resize( nWidth, nHeight )Redimensiona la imagen (mantiene la relación de aspecto si se omite una dimensión)
Rotate( nRotate )Rota/voltea la imagen
ImageRotate( nDegrees )Rota con un ángulo arbitrario
Save( cFile [, nQuality] )Guarda en un archivo. nQuality se aplica a JPEG (0-100).
GetWidth() / GetHeight()Devuelve las dimensiones de la imagen
CreateThumbnail( nW, nH )Crea una miniatura GDIBmp
Conver24to32Alpha()Convierte de 24 bits a 32 bits con transparencia alfa
GetGDIHbitmap()Extrae un manejador de bitmap GDI para usar con funciones GDI
End() / Destroy()Libera la imagen de GDI+

Clase Path

Trazado gráfico de GDI+ para la construcción de formas complejas.

MétodoDescripción
New()Crea un trazado vacío
AddLine( nLeft, nTop, nRight, nBottom )Añade un segmento de línea
AddArc( nLeft, nTop, nW, nH, nStartAngle, nSweepAngle )Añade un arco
AddRectangle( nLeft, nTop, nRight, nBottom )Añade un rectángulo
AddRoundRect( x, y, nW, nH, nRadius )Añade un rectángulo redondeado
AddElipse( nTop, nLeft, nW, nH )Añade una elipse
AddString( cText, cFont, nStyle, eMSize, ... )Añade texto como contorno de trazado
StarFigure() / CloseFigure()Inicia/cierra una figura dentro del trazado
Translate() / Rotate() / Scale()Transforma el trazado
Destroy()Libera el trazado

Clase Region

MétodoDescripción

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oGraphics, oPen, oBrush

   DEFINE WINDOW oWnd TITLE "GDI+ Demo" SIZE 500, 400

   oWnd:bPainted = {| hDC |
      local oGraphics := Graphics():New( hDC )
      local oPen      := Pen():New( 255, 255, 0, 0, 3 )   // Lápiz rojo, 3px
      local oBrush    := Brush():NewSolidBrush( 128, 0, 0, 255 ) // Azul semitransparente

      // Dibuja el contorno de una elipse roja
      oGraphics:DrawEllipse( oPen, oBrush, 50, 50, 200, 150 )

      // El relleno azul semitransparente lo aplica automáticamente DrawEllipse

      oPen:Destroy()
      oBrush:Destroy()
      oGraphics:Destroy()
      }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • GDI+ se inicializa automáticamente mediante un init procedure GdiPlusStart() y se finaliza mediante un exit procedure GdiPlusEnd(). No es necesario un arranque/cierre manual.
  • Todas las clases GDI+ son independientes en el sentido de que no derivan de TControl ni de ninguna otra clase base de FiveWin.
  • GDIBmp admite la carga desde archivo, desde recurso (PNG o bitmap) y desde una cadena en memoria. Formatos de entrada admitidos: BMP, JPG, GIF, TIF, PNG, EMF, WMF, ICO. Formatos de salida: BMP, JPG, GIF, TIF, PNG.
  • La clase Graphics establece la unidad de página en píxeles de forma predeterminada y activa el renderizado de alta calidad (con suavizado de bordes) a menos que lNoHighQuality sea .T.

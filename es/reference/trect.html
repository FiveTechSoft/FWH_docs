TRect / TPoint

Fuente: source/classes/rect.prg

Clases independientes (sin herencia)

TRect y TPoint son clases de utilidad para operaciones de geometría 2D. TRect representa un rectángulo definido por sus bordes superior, izquierdo, inferior y derecho. TPoint representa un único punto con coordenadas de fila y columna (o Y y X). Ambas clases admiten operadores aritméticos y transformaciones geométricas que se necesitan habitualmente en el diseño de la interfaz y el código de dibujo.

TRect

Miembros DATA Principales

DATATipoDescripción
aRectArrayDatos principales: { nTop, nLeft, nBottom, nRight }
nTopNumericBorde superior (accesor de aRect[1])
nLeftNumericBorde izquierdo (accesor de aRect[2])
nBottomNumericBorde inferior (accesor de aRect[3])
nRightNumericBorde derecho (accesor de aRect[4])
nWidthNumericAncho calculado
nHeightNumericAlto calculado
cRectCharacterEstructura binaria RECT (8 bytes) para llamadas a la API Win32

lWinRectLogicalRectángulo estilo Windows (derecha/inferior exclusivos). Por defecto .T.

Métodos de TRect

MétodoDescripción
New( nTop, nLeft, nBottom, nRight [, nWidth, nHeight] )Crea un nuevo rectángulo. Acepta un array, una cadena binaria o cuatro coordenadas. nWidth/nHeight prevalecen sobre nRight/nBottom.
MoveBy( nRows, nCols )Desplaza todo el rectángulo según los incrementos indicados
MoveTo( nNewTop, nNewLeft )Mueve el rectángulo de modo que su esquina superior izquierda quede en la posición dada
Contains( aPoint )Comprueba si un punto { fila, columna } u otro rectángulo está dentro de este
Resize( nRatio [, aPoint] )Redimensiona según una proporción relativa al centro (o al punto de anclaje especificado)
FitInside( oRect, nType, cAlign )Ajusta este rectángulo dentro de otro, ampliándolo opcionalmente. nType: 1=exacto, 2=llenar el exterior, 3=ajustar dentro.
AsSquare( lOuter, cAlign )Lo ajusta para formar un cuadrado expandiendo o contrayendo la dimensión mayor
Modify( ... )Devuelve un nuevo TRect con los bordes modificados; admite cambios absolutos, fraccionarios y relativos

Operadores de TRect

OperadorDescripción
==Comparación de igualdad (coinciden los cuatro bordes)
+, -, *, /, %Aritmética sobre los cuatro bordes mediante un valor o un array
+=, -=, *=, /=, %=Operadores aritméticos in situ
[]Acceso indexado: oRect[1] = nTop, oRect[2] = nLeft, etc.

TPoint

Miembros DATA Principales de TPoint

DATATipoDescripción
nRowNumericCoordenada de fila (Y)
nColNumericCoordenada de columna (X)
XNumericAlias de nCol
YNumericAlias de nRow
aPtArray{ nRow, nCol }
aXYArray{ X, Y } = { nCol, nRow }

Métodos de TPoint

MétodoDescripción
New( nRow, nCol )Crea a partir de fila/columna; también acepta un array {fila,columna}
NewXY( x, y )Crea a partir de coordenadas X/Y (almacenadas como nCol/nRow)
Rect( nRadius [, yRadius] )Devuelve un TRect centrado en este punto con el radio indicado
Distance( oPt )Distancia euclídea a otro punto
Plus( r, c [, lNew] )Suma incrementos y devuelve un nuevo punto (o modifica Self si lNew es .F.)

Operadores de TPoint

OperadorDescripción
+Crea un nuevo punto desplazado según el incremento indicado
+=Desplazamiento in situ
-Devuelve la distancia entre dos puntos

Ejemplo

#include "FiveWin.ch"

function Main()

   local oRect, oPt, oInner

   // Crea un rectángulo de 200x100 en la posición (10,10)
   oRect := TRect():New( 10, 10, 110, 210 )

   // Comprueba si un punto está dentro
   oPt := TPoint():New( 50, 100 )
   if oRect:Contains( oPt:aPt )
      MsgInfo( "El punto está dentro del rectángulo" )
   endif

   // Crea un cuadrado y lo ajusta dentro del rectángulo
   oInner := TRect():New( 0, 0, 100, 100 )
   oInner:FitInside( oRect, 3, "C" )  // Ajustar dentro, centrado

   // Mueve el rectángulo 10 píxeles en cada dirección
   oRect:MoveBy( 10, 10 )

return nil

Notas

  • TRect puede construirse a partir de un array, de una estructura binaria RECT o de cuatro coordenadas numéricas.
  • El indicador lWinRect controla si los cálculos de ancho/alto usan la convención de Windows (bordes inferior/derecho exclusivos, por defecto .T.) o la convención inclusiva (.F.).
  • El operador - de TPoint devuelve la distancia euclídea (un valor numérico), no un nuevo punto.
  • Ambas clases ofrecen sobrecarga de OPERATOR para una sintaxis natural de aritmética e indexación.
  • Las funciones auxiliares PointXY( x, y ) y PointRowCol( r, c ) crean objetos TPoint de forma directa.

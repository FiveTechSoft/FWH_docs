TGSelector / TChooseGradient / TInk

Fuente: source/classes/tgselect.prg

TGSelector deriva de TControl, TChooseGradient diálogo independiente, TInk independiente

TGSelector es un control editor de barra de degradado que permite a los usuarios crear y editar visualmente degradados de color añadiendo, moviendo y eliminando puntos de color ("inks") a lo largo de una barra de degradado. TChooseGradient proporciona un envoltorio de diálogo completo alrededor de TGSelector con deslizadores RGB para una edición precisa del color. TInk representa un único punto de color dentro del degradado.

TGSelector

Una subclase de TControl que muestra una barra de degradado interactiva con puntos de color móviles.

TChooseGradient

Un diálogo modal completo para editar degradados con retroalimentación visual y controles RGB.

MétodoDescripción
New( aInit, bCode, bOnOK, bOnCancel )Abre el diálogo del editor de degradado. aInit es el array de degradado inicial. bCode se evalúa al cambiar. bOnOK/bOnCancel son bloques de acción.

TInk

Representa un único punto de color en el degradado.

DATATipoDescripción
nPorcentClrNumericPosición porcentual a lo largo del degradado (0.0 a 1.0)
nColorStartNumericColor de inicio (lado izquierdo del punto)
nColorEndNumericColor de fin (lado derecho del punto)
lSelectedLogicalSi este ink está seleccionado actualmente
lMoveLogicalSi el ink puede moverse (falso para los inks de los extremos)
lFirstLogicalSi este es el primer ink (más a la izquierda) del degradado

Función Libre

FunciónDescripción
ChooseGradient( aInit ) --> aGradOutAbre el diálogo selector de degradado y devuelve el array de degradado resultante. Esta es la forma más sencilla de usar el editor de degradado.

Ejemplo

#include "FiveWin.ch"

function Main()

   local aGrad

   // Degradado inicial: de negro a blanco
   local aInit := { { 1, 0, nRGB( 255, 255, 255 ) } }

   // Abre el diálogo selector de degradado
   aGrad := ChooseGradient( aInit )

   if ! Empty( aGrad )
      // Usa el degradado: p. ej., rellenar el fondo de una ventana
      MsgInfo( "Gradient created with " + Str( Len( aGrad ) ) + " stops" )
   endif

return nil

Notas

  • La función ChooseGradient() es el punto de entrada más sencillo: abre un diálogo completo con deslizadores RGB, un panel de color y botones Aceptar/Cancelar, y luego devuelve el array de degradado resultante.
  • El formato del array de degradado de salida es { { nPercent, nColorStart, nColorEnd }, ... }, que puede usarse directamente con GradientFill() y otras funciones de dibujo de degradados.
  • Hacer clic con el botón derecho en un ink interior lo elimina (fusiona su espacio con los vecinos).
  • Hacer doble clic en un ink abre el selector de color de Windows (ChooseColor()) para editar su color.
  • Los inks pueden arrastrarse a izquierda/derecha para ajustar su posición en el degradado.

TTitle / TTitleText / TTitleImg

Fuente: source/classes/ttitle.prg

Hereda de: TControl

TTitle es un control decorativo de título / encabezado que combina fondos con degradado, elementos de texto e imágenes de mapa de bits en un único encabezado visual. Admite sombras, bordes, esquinas redondeadas, animación de imágenes, mezcla alfa y efectos de reflejo (espejo). El texto y las imágenes pueden añadirse de forma independiente mediante AddText() y LoadBitmaps().

Miembros DATA Principales

DATATipoDescripción
aImgsArrayArray de descriptores de imagen de 10 posiciones: fila, columna, hBitmap, hPalette, hasAlpha, alphaLevel, reflejo, transparente, anima, acción
aTextArrayArray de descriptores de texto: fila, columna, texto, justificación, brocha, lápiz, sombra, fuente, color de texto
aGrdBaseArrayArray de degradado para el área base (encabezado)
aGrdBackArrayArray de degradado para el fondo
hBackBrushHandleManejador interno de la brocha de patrón de fondo
nShadowNumericDirección de la sombra: TOPLEFT, TOPRIGHT, BOTTOMLEFT, BOTTOMRIGHT
nShadowIntensityNumericPorcentaje de opacidad de la sombra (0-100)
nShadowSizeNumericDistancia de difusión de la sombra en píxeles
lBaseLogicalPintar el área base estilo dock de Mac
lBorderLogicalDibujar un borde alrededor del encabezado
lRoundLogicalUsar esquinas redondeadas
lVerticalLogicalAplicar el degradado verticalmente (por defecto: verdadero)
nClrLine1NumericColor de la línea de borde 1
nClrLine2NumericColor de la línea de borde 2

Métodos Principales

MétodoDescripción
New( oWnd, nRow, nCol, nW, nH, cText, lBorder, lRound, lBase, lVertical, ... )Crear un encabezado de título decorativo con degradado, sombra y texto
AddText( nRow, nCol, cText, lBold, lStrike, lShadow, cAlign, oFont, nClr )Añadir un elemento de texto al encabezado en las coordenadas indicadas
LoadBitmaps( cFile, nRow, nCol, nW, nH, nAlpha, lReflex, lTransparent, lAnima, bAction, nAt )Cargar un mapa de bits en el array de imágenes en la posición especificada

Ejemplo: Encabezado con Degradado, Logo y Sombra

#include "FiveWin.ch"

function Main()

   local oWnd, oTitle

   DEFINE WINDOW oWnd TITLE "Main" SIZE 600, 400

   oTitle = TTitle():New( oWnd, 0, 0, 600, 60, "My Application",;
                          .T., .F., .F., .T.,,, "BOTTOMRIGHT", 8 )

   oTitle:AddText( 15, 40, "My Application", .T., .F., .T., "LEFT",;
                   oFont(), CLR_WHITE )

   oTitle:LoadBitmaps( "logo.png", 10, 540, 40, 40,,,, {|| MsgInfo( "Logo clicked" ) } )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El encabezado consta de hasta tres capas visuales: el degradado de fondo (aGrdBack), el degradado base (aGrdBase, efecto opcional tipo dock) y el texto e imágenes superpuestos.
  • La sombra se implementa desplazando una copia semitransparente del contenido del encabezado. La constante de dirección nShadow controla en qué cuadrante cae la sombra.
  • Las imágenes almacenadas en aImgs pueden tener niveles alfa individuales, efectos de reflejo (espejo) y transiciones animadas.
  • Cuando lBase es verdadero, se pinta una franja de degradado más oscura adicional en la parte inferior del encabezado (similar al Dock de macOS).
  • Los bordes se dibujan con dos colores (nClrLine1 y nClrLine2) para crear un efecto de bisel 3D.

TForm

Fuente: source/classes/tform.prg

Hereda de: TWindow

TForm es un contenedor visual de formularios que carga la disposición de sus controles desde un recurso .ffm (Forms File Memory). Lo utiliza el IDE Visual FiveWin para diseñar y ejecutar formularios en tiempo de ejecución. El formulario serializa los controles hijos, sus propiedades y los enlaces a la base de datos.

Miembros DATA Principales

DATATipoDescripción
nBorderStyleNumericEstilo del borde de la ventana (por defecto 3 = redimensionable)
nPositionNumericPosición de inicio: 0=normal, 1=maximizada, 2=minimizada
cDescriptionCharacterDescripción visible en el gestor de Proyectos Visuales
cClassNameCharacterNombre de clase usado como nombre de recurso por defecto para cargar el .ffm
oInspectorObjectObjeto inspector de propiedades para el modo de diseño
aPropertiesArrayArray DATA de clase que lista todas las propiedades serializables
lDesignLogicalActiva el modo de diseño con arrastrar y soltar para los controles hijos

Métodos Principales

MétodoDescripción
New()Crea un nuevo formulario con la configuración por defecto y carga el recurso .ffm
LoadRes( cResName, cResType )Carga la definición del formulario desde un recurso (tipo "FORMS" por defecto)
ShowModal()Muestra el formulario como un diálogo modal, respetando nPosition
Initiate()Inicializa los controles: crea las ventanas hijas, resuelve los alias, configura los enlaces a la base de datos
Default()Establece los valores por defecto del estilo de borde, posición y barras de desplazamiento

Ejemplo: Cargar y Mostrar un Formulario

#include "FiveWin.ch"

function Main()

   local oForm := TForm():New()

   oForm:cTitle     := "Mi Formulario"
   oForm:nWidth     := 600
   oForm:nHeight    := 400
   oForm:nPosition  := 0   // normal

   oForm:ShowModal()

return nil

Notas

  • TForm carga la disposición de sus controles desde un recurso binario .ffm almacenado bajo el tipo de recurso "FORMS", indexado por el nombre de la clase.
  • Initiate() procesa los componentes de base de datos (TDataBaseComp) antes que los demás controles, de modo que los alias estén disponibles para TXBrowse y controles similares.
  • El modo de diseño se activa mediante lDesign, que permite reposicionar todos los controles hijos arrastrando y soltando.
  • Los controles sin un hWnd existente se crean a partir de sus propiedades almacenadas; las coordenadas se normalizan si son negativas.

TBlockChain

Fuente: source/internal/TBlockChain.prg

Clase independiente

TBlockChain es una implementación de blockchain en Harbour puro con hash SHA-256, minería por prueba de trabajo (proof-of-work) y validación de bloques. Utiliza un hash CLASSDATA (aBlocks) para que todas las instancias compartan la misma cadena, permitiendo que aplicaciones multiventana operen sobre los mismos datos. La cadena almacena un array de bloques con hash, cada uno conteniendo una marca de tiempo, una carga de datos, un once (nonce) y el hash del bloque anterior. La minería itera a través de los valores del nonce hasta que el hash coincide con el prefijo de dificultad.

Miembros DATA Principales

DATATipoDescripción
aBlocksHash (CLASSDATA)Todos los bloques de la cadena, compartidos entre todas las instancias
cJsonCarácterRepresentación JSON de la cadena completa
uDifficultyCarácterPrefijo de dificultad de minería (por defecto: "0000")
nIterationsNuméricoTotal de iteraciones de minería realizadas
cPrivateKeyCarácterClave privada para firmar bloques
cPublicKeyCarácterClave pública para verificación de firma
cSignatureCarácterCadena de firma del bloque

Métodos Principales

MétodoDescripción
New( cKey )Crea una nueva blockchain con bloque génesis, identificada por cKey
AddNewBlock( uOnce, cData )Añade un nuevo bloque con nonce opcional y cadena de datos
BlockToHash( nIdx, uOnce, cData )Calcula el hash para un índice de bloque y datos dados
MineBlock( nIdx )Mina el bloque nIdx iterando los nonces hasta que el hash coincide con la dificultad
IsValidHash( nIdx )Comprueba si el bloque nIdx tiene un hash válido que coincide con la dificultad
IsValidBlock( nIdx, cHash )Valida el bloque nIdx contra el hash proporcionado
CountBlocks()Devuelve el número total de bloques de la cadena
UpdateAllBlocks()Recalcula los hashes de todos los bloques de la cadena

Ejemplo: Crear una Cadena

#include "FiveWin.ch"

function Main()

   local oChain := TBlockChain():New( "myapp" )

   // Añadir bloques con datos
   oChain:AddNewBlock( , "Genesis: Base record" )
   oChain:AddNewBlock( , "Block 2: Transaction data" )
   oChain:AddNewBlock( , "Block 3: Verification record" )

   // Minar el segundo bloque
   oChain:MineBlock( 2 )

   // Validar
   if oChain:IsValidHash( 2 )
      MsgInfo( "Block 2 is valid. Total blocks: " + ;
               Str( oChain:CountBlocks() ) )
   endif

   // Volcar la cadena como JSON
   if ! Empty( oChain:cJson )
      MemoWrit( "chain.json", oChain:cJson )
   endif

   oChain:End()

return nil

Notas

  • El miembro de datos aBlocks está marcado como CLASSDATA y se almacena como un hash identificado por el parámetro cKey pasado a New(). Todas las instancias que usan la misma clave comparten los mismos datos de la cadena.
  • La dificultad por defecto (uDifficulty) es "0000", lo que requiere que los primeros cuatro dígitos hexadecimales del hash SHA-256 sean cero. Aumente la longitud de la cadena (p. ej. "000000") para hacer la minería exponencialmente más difícil.
  • MineBlock() incrementa el nonce y vuelve a calcular el hash hasta que este coincide con el prefijo de dificultad. El número de iteraciones se acumula en nIterations.

TProgress

Fuente: source/classes/tprogres.prg

Hereda de: TControl

TProgress encapsula la barra de progreso de los controles comunes de Windows (msctls_progress32). Admite la indicación de progreso estándar con rango y posición configurables, incrementos por pasos, orientación vertical y modo marquesina (indeterminado). TProgress es adecuado para mostrar el progreso de una operación en ventanas, diálogos y barras de estado.

Miembros DATA Principales

DATATipoDescripción
nMinNumericValor mínimo del rango (predeterminado 0)
nMaxNumericValor máximo del rango (predeterminado determinado por el sistema)
nPosNumericPosición actual
nStepNumericValor del incremento por paso

Métodos Principales

MétodoDescripción
New( nTop, nLeft, oWnd, nPos, nClrF, nClrB, lPixel, lDesign, nW, nH, cMsg, lVert, lMarquee )Crea una barra de progreso. Admite los modos vertical y marquesina mediante lVert y lMarquee.
ReDefine( nId, oWnd )Redefine a partir de una plantilla de recurso de diálogo
SetPos( nPos )Establece la posición actual (alias _nPosition, nPosition)
GetPos()Devuelve la posición actual
SetRange( nMin, nMax )Establece los valores mínimo y máximo del rango
SetStep( nStepInc )Establece el valor del incremento por paso
StepIt()Avanza la posición según el valor de paso actual
DeltaPos( nIncrement )Cambia la posición en una cantidad relativa (positiva o negativa)
SetMarquee( lOnOff )Activa o desactiva el modo marquesina (indeterminado)

Comandos

// Barra de progreso estándar
DEFINE PROGRESS oProg OF oDlg

// Barra de progreso marquesina (indeterminada)
DEFINE PROGRESS oProg OF oDlg MARQUEE

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oProg, n

   DEFINE WINDOW oWnd TITLE "Progress Demo" SIZE 400, 150

   @ 30, 30 PROGRESS oProg OF oWnd SIZE 340, 25

   oProg:SetRange( 0, 100 )
   oProg:SetStep( 1 )

   @ 80, 30 BUTTON "Start" OF oWnd SIZE 80, 25 ;
      ACTION ( oProg:SetPos( 0 ), ;
               For n := 1 To 100,;
                   oProg:SetPos( n ),;
                   SysRefresh(),;
                   Sleep( 10 ),;
               Next )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • La barra de progreso utiliza la clase de control común de Windows msctls_progress32.
  • El modo marquesina (indeterminado) muestra una barra animada de desplazamiento cuando se desconoce la duración de la operación. Actívelo mediante lMarquee := .T. en la creación o llame a SetMarquee( .T. ) en tiempo de ejecución.
  • Las barras de progreso verticales se crean estableciendo lVertical := .T. (estilo PBS_VERTICAL).
  • El método StepIt() avanza la posición según el valor establecido mediante SetStep(). El paso predeterminado es 1.
  • Use DeltaPos() para cambios de posición relativos sin modificar el valor del paso.

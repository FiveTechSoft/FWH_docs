TAgent / TOLlama

Fuente: source/classes/tollama.prg

TOLlama: Independiente | TAgent: Usa TOLlama internamente

TOLlama proporciona integración con modelos LLM de Ollama que se ejecutan localmente a través de la API REST de Ollama. Admite prompts de texto, respuestas en streaming y análisis de imágenes (para modelos multimodales). TAgent se construye sobre TOLlama para crear un agente de IA que puede invocar funciones de Harbour como herramientas, habilitando la automatización dirigida por LLM.

Miembros DATA Principales

DATATipoDescripción
cModelCharacterNombre del modelo de Ollama (por defecto "deepseek-r1:14b")
cUrlCharacterURL de la API (por defecto "http://localhost:11434/api/chat")
cSystemPromptCharacterPrompt del sistema que define el comportamiento del agente
aToolsArrayArray de definiciones de herramientas para el agente

Métodos Principales

MétodoDescripción
New( cModel )Crea un cliente de Ollama con el modelo especificado
Send( cPrompt )Envía un prompt; devuelve la respuesta completa
SendStream( cPrompt, bWriteFunction )Envía con callback de streaming para salida de tokens en tiempo real
SendImage( cImageFile, cPrompt )Envía imagen + prompt para modelos multimodales
GetValue()Analiza la respuesta JSON y extrae el texto del contenido
End()Libera el handle de libcurl
SetSystemPrompt( c )Establece el prompt del sistema para el agente
AddTool( cName, cDesc, bAction )Registra una función de Harbour como herramienta invocable
Run( cPrompt )Ejecuta un prompt a través del agente; devuelve el resultado

Ejemplo: Agente con Herramienta de Calculadora

#include "FiveWin.ch"
function Main()
   local oAgent
   oAgent := TAgent():New( "deepseek-r1:14b" )
   oAgent:SetSystemPrompt( "You are a helpful assistant." )
   oAgent:AddTool( "calculator", "Add two numbers", { |a,b| a + b } )
   ? oAgent:Run( "What is 123 + 456?" )
return nil

Notas

  • TOLlama requiere un servidor Ollama local ejecutándose en el puerto 11434.
  • Usa libcurl (hbcurl.ch) para la comunicación HTTP con la API de Ollama.
  • SendStream permite la visualización incremental de los tokens generados a medida que llegan.
  • SendImage funciona con modelos multimodales como LLaVA o bakllava.
  • TAgent organiza las herramientas por categoría, proporcionando un framework extensible de uso de herramientas para LLM.

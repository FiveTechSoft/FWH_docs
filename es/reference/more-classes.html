TXmlDocument — Análisis y Creación de XML

TXmlDocument lo proporciona la biblioteca contrib hbxml de Harbour y se utiliza ampliamente en los ejemplos de FiveWin (más de 23 ejemplos). Ofrece análisis XML al estilo DOM desde archivos o cadenas, con iteración mediante TXmlIterator.

DATA clave

DATATipoDescripción
oRootTXmlNodeNodo raíz del documento XML analizado
nStatusNuméricoEstado del análisis (0 = éxito)
nErrorNuméricoCódigo de error si el análisis falló
nLineNuméricoNúmero de línea donde ocurrió el error

METHODs clave

METHODDescripción
New( hFile | cString )Analiza XML desde un manejador de archivo o cadena
Read( hFile )Lee y analiza desde un manejador de archivo abierto
ToString()Serializa el documento de vuelta a una cadena XML
Write( hFile )Escribe el documento en un manejador de archivo

TXmlNode (nodos hijos)

DATA/METHODDescripción
cNameNombre de etiqueta del nodo
cDataContenido de texto del nodo
aAttributesHash con pares nombre/valor de atributos
oChildPrimer nodo hijo
oNextSiguiente nodo hermano
AddBelow( oNode )Añade un nodo hijo

Ejemplo

#include "FiveWin.ch"

function Main()

   local hFile    := FOpen( "config.xml" )
   local oXmlDoc  := TXmlDocument():New( hFile )
   local oXmlIter := TXmlIterator():New( oXmlDoc:oRoot )
   local oTag

   while ( oTag := oXmlIter:Next() ) != nil
      MsgInfo( oTag:cName + ": " + oTag:cData )
      // Acceder a los atributos:
      // HEval( oTag:aAttributes, { |k,v| QOut( k, v ) } )
   end

   FClose( hFile )

return nil

TExplorerBar — Contenedor de Paneles Colapsables

Una barra lateral al estilo del Explorador con paneles de tareas colapsables. Cada panel tiene una barra de título con degradado que alterna entre colapsar/expandir al hacer clic, y un área de cuerpo donde puede colocar enlaces o cualquier control. Hereda de TControl.

TTaskPanel (paneles individuales)

DATA/METHODDescripción

   DEFINE WINDOW oWnd TITLE "Explorer Bar Demo" SIZE 300, 500

   oPanel1 := oExBar:AddPanel( "File Tasks", , 120 )

   oPanel1:AddLink( "Delete this file",   { || MsgInfo( "Delete" ) } )
   oPanel1:AddLink( "Share this folder",   { || MsgInfo( "Share" ) } )

   oPanel2 := oExBar:AddPanel( "Other Tasks", , 80 )
   oPanel2:AddLink( "Map network drive",  { || MsgInfo( "Map Drive" ) } )

TBarTabs — Barra de Botones con Pestañas

Seleccionar una pestaña cambia la barra de botones visible debajo, de forma similar al concepto de cinta (ribbon) de Office. Una alternativa ligera a TRibbon para aplicaciones que necesitan botones de barra de herramientas categorizados.

METHODs clave

METHODDescripción

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oBarTabs

   DEFINE WINDOW oWnd TITLE "BarTabs Demo" SIZE 800, 600

   oBarTabs := TBarTabs():New( oWnd, 64, 32, ;
      { "Home", "Edit", "View" },  ;    // Prompts de las pestañas
      { "home.bmp", "edit.bmp", "view.bmp" } )  // Bitmaps de las pestañas

   // Añadir botones a la barra de la primera pestaña:

      RESOURCE "NEW" PROMPT "New" ;
      ACTION MsgInfo( "New!" )

   DEFINE BUTTON OF oBarTabs:aBars[ 1 ] ;
      RESOURCE "OPEN" PROMPT "Open" ;

   ACTIVATE WINDOW oWnd

return nil

TWorkBook / TWorkSheet — Generación de Excel XLSX

Cree archivos Excel .xlsx nativos sin necesidad de Microsoft Office. Construido sobre la biblioteca C xlsxwriter (de John McNamara), envuelta para Harbour por Arturo Tamayo. Admite formato, fórmulas, imágenes, celdas combinadas y más.

Fuente: source/function/fwxlsxlb.prg

TWorkBook — DATA/METHODs clave

DATA/METHODDescripción
cFileRuta del archivo de salida
aSheetsArray de objetos TWorkSheet
New( cFile )Crea un nuevo libro (.xlsx)
AddSheet( cName )Añade una hoja de cálculo, devuelve TWorkSheet
Format( cPicture, cStyles, nAlign )Crea un TFormat para dar formato a las celdas
Close()Finaliza y escribe el archivo en disco

TWorkSheet — DATA/METHODs clave

DATA/METHODDescripción
Say( nRow, nCol, uValue, oFormat )Escribe un valor en una celda (detecta el tipo automáticamente)
SayRow( nRow, aValues, aFormat )Escribe una fila entera de valores
SayImage( nRow, nCol, cImage )Incrusta una imagen en una celda
SayFormula( nRow, nCol, cFormula )Escribe una fórmula de Excel
MergeRange( r1, c1, r2, c2, cValue )Combina un rango de celdas
SetColumnSize( nFrom, nTo, nWidth )Establece el ancho de columna
RowHeight( nRow, nHeight )Establece la altura de fila
Freeze( nRow, nCol )Inmoviliza paneles en la posición indicada
CreateFrom( uSource )Rellena desde un DBF, array o recordset
SetArrayData( aData, aStruct )Escribe un array 2D como datos de tabla

Ejemplo

#include "FiveWin.ch"

function Main()

   local oBook, oSheet, oFmtBold

   oBook := TWorkBook():New( "report.xlsx" )
   oSheet := oBook:AddSheet( "Sales" )

   // Crear un formato en negrita
   oFmtBold := oBook:Format( , "B" )   // "B" = Negrita

   // Escribir cabeceras
   oSheet:Say( 0, 0, "Product",  oFmtBold )
   oSheet:Say( 0, 1, "Quantity", oFmtBold )
   oSheet:Say( 0, 2, "Price",    oFmtBold )

   // Escribir filas de datos
   oSheet:SayRow( 1, { "Widget A", 150, 29.99 } )
   oSheet:SayRow( 2, { "Widget B",  75, 49.99 } )
   oSheet:SayRow( 3, { "Widget C", 200, 14.99 } )

   // Añadir una fórmula SUM
   oSheet:SayFormula( 4, 1, "=SUM(B2:B4)" )

   oSheet:SetColumnSize( 0, 0, 20 )   // Ensanchar la columna A
   oSheet:Freeze( 1, 0 )              // Inmovilizar la fila de cabecera

   oBook:Close()
   MsgInfo( "report.xlsx created!" )

return nil

Ofrece ejecución paso a paso, puntos de interrupción, inspección de variables, navegación de la pila de llamadas, expresiones de seguimiento e inspección de áreas de trabajo de bases de datos. TBlockChain — Implementación de Blockchain

Una implementación de blockchain en Harbour puro con hashing SHA-256, minería por prueba de trabajo (proof-of-work) y validación de bloques. Útil para aprender conceptos de blockchain o para implementar cadenas de datos a prueba de manipulaciones en sus aplicaciones. Escrito por Cristobal Navarro.

Fuente: source/internal/TBlockChain.prg

DATATipoDescripción

nIterationsNuméricoNúmero de iteraciones de minería realizadas

METHODs clave

METHODDescripción

#include "FiveWin.ch"

function Main()

   local oChain := TBlockChain():New( "mychain" )

   // Añadir bloques con datos
   oChain:AddNewBlock( , "First transaction: Alice pays Bob 10" )
   oChain:AddNewBlock( , "Second transaction: Bob pays Carol 5" )

   // Minar un bloque
   oChain:MineBlock( 2 )

   // Validar

      MsgInfo( "Block 2 is valid! Blocks: " + ;
               Str( oChain:CountBlocks() ) )
   endif

   oChain:End()

return nil

Modo Oscuro

FiveWin proporciona soporte integrado para el modo oscuro mediante la función FW_SetDarkMode(). Cuando está habilitado, todos los diálogos nuevos reciben automáticamente un tema de colores oscuros en TDialog:Initiate(), y las ventanas abiertas existentes también reciben el tema de inmediato.

Fuente: source/classes/dialog.prg (línea ~1462)

flowchart LR A["FW_SetDarkMode(.T.)"] --> B["Establece lDarkMode = .T."] B --> C["Aplica tema a todas las ventanas existentes"] B --> D["Diálogos nuevos con tema automático
en TDialog:Initiate()"] C --> E["SetDarkMode() en cada ventana"] D --> E E --> F["Fondo oscuro + texto claro
en todos los controles"]

API

LlamadaDescripción
FW_SetDarkMode( .T. )Habilita el modo oscuro con colores predeterminados (texto: RGB(220,220,220), fondo: RGB(30,30,30))
FW_SetDarkMode( .T., nClrText, nClrBack )Habilita con colores personalizados
FW_SetDarkMode( .F. )Deshabilita el modo oscuro (restaura los colores del sistema)
FW_SetDarkMode()Consulta el estado actual (devuelve .T. o .F.)

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oDlg

   // Habilitar el modo oscuro para toda la aplicación
   FW_SetDarkMode( .T. )

   DEFINE WINDOW oWnd TITLE "Dark Mode App" SIZE 600, 400

   // Todos los diálogos creados a partir de este punto son oscuros automáticamente
   DEFINE DIALOG oDlg TITLE "Settings" SIZE 400, 300 PIXEL TRUEPIXEL OF oWnd
   @ 30, 20 SAY "This dialog is automatically dark!" OF oDlg SIZE 350, 24 PIXEL
   @ 70, 20 GET oGet VAR cName OF oDlg SIZE 350, 24 PIXEL
   @ 120, 160 BUTTON "OK" OF oDlg SIZE 80, 30 PIXEL ACTION oDlg:End()
   ACTIVATE DIALOG oDlg CENTERED

   ACTIVATE WINDOW oWnd

return nil

Clases de Gráficos GDI+

FiveWin envuelve la API GDI+ de Windows mediante un conjunto de clases para gráficos 2D de alta calidad: líneas con suavizado (anti-aliasing), imágenes con mezcla alfa, rellenos en degradado, dibujo basado en trazados (paths) y más. Todas las clases residen en source/classes/tgdiplus.prg.

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "GDI+ Drawing" SIZE 600, 400

   ACTIVATE WINDOW oWnd ;
      ON PAINT DrawGdiPlus( oWnd:hDC )

return nil

function DrawGdiPlus( hDC )

   local oGfx    := Graphics():New( hDC )
   local oPen    := Pen():New( 255, 255, 0, 0, 3 )    // Pluma roja, 3px de ancho
   local oBrush  := Brush():NewSolidBrush( 128, 0, 0, 255 )  // Azul semitransparente
   local oPenGrn := Pen():New( 255, 0, 180, 0, 2 )    // Pluma verde

   // Dibujar un rectángulo relleno con borde
   oGfx:DrawRect( oPen, oBrush, 50, 50, 200, 150 )

   // Dibujar una elipse
   oGfx:DrawEllipse( oPenGrn, , 300, 80, 180, 120 )

   // Dibujar una línea
   oGfx:DrawLine( oPen, 50, 250, 500, 350 )

   // Dibujar texto con suavizado
   oGfx:DrawText( 20, 50, "GDI+ in FiveWin!", "Segoe UI", 24, ;
                  Brush():NewSolidBrush( 255, 0, 0, 0 ) )

IDE Visual de FiveWin

El IDE Visual de FiveWin (visual/visualfw.exe) es un diseñador visual de formularios que le permite diseñar diálogos arrastrando y soltando controles, y luego genera el código fuente .prg correspondiente. También admite la edición de archivos de recursos.

Características Principales

  • Diseño de diálogos por arrastrar y soltar con vista previa en vivo
  • Inspector de propiedades para todas las propiedades de los controles
  • Generación automática de código .prg
  • Importación y exportación de archivos de recursos (.rc)
  • Soporte para todos los controles de FiveWin (TGet, TButton, TXBrowse, TFolder, etc.)
  • Herramientas de alineación: ajustar a la cuadrícula, centrar, distribuir
  • Edición de múltiples diálogos en pestañas

Primeros Pasos

  1. Ejecute visual/visualfw.exe desde el directorio de FiveWin
  2. Cree un nuevo formulario o abra un archivo .prg existente
  3. Arrastre los controles desde la caja de herramientas a la superficie del diálogo
  4. Establezca las propiedades en el panel inspector de la derecha
  5. Haga clic en "Generar Código" para producir el código fuente .prg
  6. Compile el código generado con su compilador preferido

Consulte el directorio samples/FiveUI/ para ver 17 formularios de ejemplo creados con el diseñador visual.

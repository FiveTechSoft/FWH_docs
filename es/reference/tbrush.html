TBrush

Fuente: source/classes/brush.prg

Clase independiente (sin herencia)

TBrush gestiona los objetos de pincel (brush) GDI de Windows utilizados para rellenar áreas con colores sólidos, patrones de trama o imágenes de mapa de bits. Se necesita un pincel siempre que haya que pintar un fondo (panel de ventana, cara de un control, formas dibujadas a medida). TBrush admite pinceles de color sólido, estilos de trama predefinidos, patrones de degradado (mediante un mapa de bits interno), pinceles basados en imágenes desde archivos o recursos, y pinceles NULL que suprimen el relleno. Todo TBrush debe liberarse con End() para evitar fugas de recursos GDI.

Miembros DATA Principales

DATATipoDescripción
hBrushNumérico (Handle)Handle del pincel GDI de Windows. Creado por New().
hBitmapNumérico (Handle)Handle del mapa de bits que respalda los pinceles basados en imagen y de degradado. nil para pinceles sólidos y de trama.
cStyleCarácterNombre del estilo de trama: "HORIZONTAL", "VERTICAL", "CROSS", "DIAGCROSS", "BORLAND", "BRICKS", "TILED", "TABS" o "NULL".
nRGBColorNuméricoValor de color RGB para pinceles sólidos y de trama.
aGradArrayArray de definición de degradado para pinceles de degradado: { { nPercent, nRGB1, nRGB2 }, ... }.
cBmpFileCarácterRuta del archivo del mapa de bits usado en pinceles basados en imagen.
cBmpResCarácterNombre del recurso del mapa de bits usado en pinceles basados en recursos.
nBmpHandleNuméricoHandle directo del mapa de bits usado en pinceles basados en imagen (alternativa a archivo/recurso).
cResizeModeCarácterModo de redimensionado para pinceles de mapa de bits: "T" = mosaico, "S" = estirar.
lVerticalLógicoSi es .T., el degradado es vertical; si es .F., horizontal.
CargoCualquieraEspacio de datos de usuario de propósito general.

Estilos de Pincel

EstiloDescripción
"HORIZONTAL"Líneas de trama horizontales
"VERTICAL"Líneas de trama verticales
"CROSS"Trama cruzada (horizontal + vertical)
"DIAGCROSS"Trama cruzada diagonal
"BORLAND"Patrón diagonal estilo Borland
"BRICKS"Patrón de muro de ladrillos
"TILED"Mapa de bits en mosaico sobre el área de relleno
"TABS"Patrón tipo pestañas
"NULL"Pincel NULL (sin relleno). Se usa para evitar que GDI rellene una región.

Métodos Principales

MétodoDescripción
New( cStyle, nRGB, cBmpFile, cBmpRes, nBmpHandle, cResizeMode )Crea un pincel. Sin argumentos, crea un pincel sólido COLOR_BTNFACE. cStyle selecciona un estilo de trama o NULL. Cuando se proporciona cBmpFile o cBmpRes, crea un pincel basado en imagen.
End()Elimina el pincel GDI (y el mapa de bits de respaldo, si lo hay) mediante DeleteObject(). Debe llamarse cuando el pincel ya no se necesita.
Resized( x, y, nMode )Crea una versión redimensionada de un pincel de mapa de bits. x e y son las nuevas dimensiones; nMode es el modo de estirado (por defecto: COLORONCOLOR).
Cropped( oWnd, oRect )Recorta el mapa de bits del pincel a un rectángulo especificado. Útil para crear pinceles específicos de una región.
Resize( oWnd )Redimensiona el mapa de bits del pincel para ajustarse a las dimensiones de una ventana. El pincel se recrea con el mapa de bits escalado.
Copy()Crea una copia independiente del pincel con un nuevo handle GDI.
GdiBrush()Devuelve el handle del pincel GDI (hBrush). Se usa internamente al seleccionar pinceles en los DC.
SameAs( oB )Compara dos pinceles por sus atributos (estilo, color, mapa de bits). Devuelve .T. si son equivalentes.
SetColor( nRGB )Cambia el color del pincel. Recrea el handle del pincel GDI con el nuevo color.
SetStyle( cStyle )Cambia el estilo del pincel. Recrea el handle del pincel GDI con el nuevo estilo.

Comandos: DEFINE BRUSH

DEFINE BRUSH oBrush ;
   [ COLOR nRGBColor ] ;
   [ STYLE cStyle ] ;
   [ FILE cBmpFile ] ;
   [ RESOURCE cBmpRes ] ;
   [ RESIZE nWidth, nHeight ]

Ejemplo: Pinceles Sólido, de Trama, de Degradado y de Mapa de Bits

#include "FiveWin.ch"

function Main()

   local oWnd, oBrush1, oBrush2, oBrush3

   DEFINE WINDOW oWnd TITLE "TBrush Demo" SIZE 600, 400

   // Pincel azul sólido
   DEFINE BRUSH oBrush1 COLOR CLR_BLUE

   // Pincel rojo de trama cruzada
   DEFINE BRUSH oBrush2 COLOR CLR_RED STYLE "CROSS"

   // Pincel de degradado (vertical)
   oBrush3 := TBrush():New( , , , , , , .T. )
   oBrush3:aGrad := { { 1.0, nRGB( 40, 80, 140 ), nRGB( 20, 40, 70 ) } }

   oWnd:oBrush := oBrush1

   ACTIVATE WINDOW oWnd CENTERED

   oBrush1:End()
   oBrush2:End()
   oBrush3:End()

return nil

Notas

  • TBrush es una clase independiente: no hereda de TWindow ni de TControl.
  • Todo TBrush debe ir acompañado de una llamada a End(). Los pinceles GDI son un recurso limitado; dejar fugas degrada el rendimiento del sistema.
  • Para asignar un pincel al fondo de una ventana, use oWnd:SetBrush( oBrush ) o oWnd:oBrush := oBrush. La ventana asume la propiedad: establezca oWnd:lTransparent := .F. para que el pincel surta efecto.
  • Los pinceles de degradado generan internamente un mapa de bits temporal. El array aGrad especifica segmentos: cada entrada es { nPercent, nColorTopLeft, nColorBottomRight }.
  • Los pinceles de mapa de bits pueden mostrarse en mosaico (por defecto) o estirarse estableciendo cResizeMode en "S".
  • El estilo "NULL" crea un pincel hueco que no rellena. Úselo cuando necesite el contorno de una forma sin rellenar su interior.

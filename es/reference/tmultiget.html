TMultiGet

Fuente: source/classes/mget.prg

Descripción

TMultiGet es el control EDIT multilínea de Windows. XBrowse crea un TMultiGet temporal para edición en celda cuando el valor es carácter, nDataLines >= 2 y cEditPicture está vacío.

LimitText( nChars )

oMGet:LimitText( nChars ) envía EM_LIMITTEXT y el usuario no puede escribir ni pegar más de nChars. Pase 0 para sin límite (por defecto en un multi-get independiente).

Si la celda del XBrowse guarda cadenas rellenadas a ancho fijo (PadR / Space(n)), haga siempre RTrim() del texto antes de LimitText(n); si no, el control ya está lleno y no acepta más teclas. Ver TXBrowse edición multilínea y el sample samples/ui/xbrowse/xbrml250.prg.

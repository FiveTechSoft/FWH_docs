TBrushEx

Fuente: source/classes/brushex.prg

Clase independiente (sin herencia)

TBrushEx crea objetos pincel GDI extendidos con patrones de degradado. A diferencia de un pincel estándar de color sólido, TBrushEx genera un bitmap relleno con un degradado suave entre dos (o cuatro) colores y, a continuación, crea un pincel de patrón a partir de ese bitmap. Esto permite pintar ventanas y controles con fondos en degradado sin necesidad de código manual de dibujo de degradados.

Miembros DATA Principales

DATATipoDescripción
hBrushNumérico (Handle)Handle del pincel GDI de Windows creado a partir del bitmap de degradado
hBitmapNumérico (Handle)Handle del bitmap de degradado que respalda el pincel

Métodos Principales

MétodoDescripción
New( nWidth, nHeight, nColor, nColor2, lVGrad )Crea un pincel de degradado de dos colores. lVGrad es .T. para degradado vertical, .F. (por defecto) para horizontal.
NewEx( nWidth, nHeight, nC1, nC2, nC3, nC4, lVGrad )Crea un pincel de degradado de cuatro colores con dos colores de esquina adicionales para patrones más complejos.
End()Elimina tanto el pincel como el bitmap, liberando todos los recursos GDI.

Ejemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oBrush

   DEFINE WINDOW oWnd TITLE "TBrushEx Demo" SIZE 400, 300

   // Crea un pincel de degradado horizontal de rojo a azul
   oBrush := TBrushEx():New( 400, 300, CLR_RED, CLR_BLUE, .F. )

   oWnd:SetBrush( oBrush )
   oWnd:lTransparent := .F.

   ACTIVATE WINDOW oWnd CENTERED

   oBrush:End()

return nil

Notas

  • Las dimensiones del bitmap (nWidth, nHeight) deben coincidir o superar el área a rellenar para evitar artefactos de mosaico.
  • Establecer lVGrad en .T. crea un degradado vertical (de arriba a abajo); .F. crea uno horizontal (de izquierda a derecha).
  • Debe llamarse a End() cuando el pincel ya no se necesite para evitar fugas de recursos GDI. Tanto el handle del pincel como el handle del bitmap se eliminan internamente.
  • TBrushEx no deriva de ninguna clase base de FiveWin; es un envoltorio ligero alrededor de las funciones GDI CreaBitmapEx() y CreatePatternBrush().

TMenuItem

Fuente: source/classes/menuitem.prg

Clase independiente

TMenuItem representa una sola entrada dentro de un objeto TMenu. Cada elemento tiene un texto, una acción opcional (bloque de código), un estado marcado/sin marcar, un estado habilitado/deshabilitado y una condición WHEN para la visibilidad dinámica. Los elementos también pueden actuar como separadores o abrir submenús.

Miembros DATA Principales

DATATipoDescripción
cPromptCharacterTexto del elemento de menú, con & para el subrayado del acelerador
nIdNumericID de comando del elemento de menú
bActionBlockBloque de código ejecutado al seleccionar
bWhenBlockBloque de código evaluado para habilitar/deshabilitar el elemento dinámicamente
lCheckedLogicalIndica si el elemento muestra una marca de verificación
lActiveLogicalIndica si el elemento está habilitado (se puede pulsar)
lSeparatorLogical.T. para una barra separadora
oMenuObjectObjeto TMenu padre que contiene este elemento

Métodos Principales

MétodoDescripción
New( cPrompt, cMsg, lChecked, lActive, bAction, bWhen, ... )Crea un nuevo elemento de menú
ReDefine( cPrompt, ... )Redefine un elemento de menú desde un recurso
SetCheck( lOn )Activa/desactiva la marca de verificación
Enable()Habilita el elemento de menú
Disable()Deshabilita (atenúa) el elemento de menú
SetPrompt( cText )Cambia el texto del elemento de menú en tiempo de ejecución

Ejemplo: Elemento de menú con acción y marca de verificación

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu, oItemStatus

   DEFINE WINDOW oWnd TITLE "TMenuItem Demo" ;
      MENU buildMenu( @oItemStatus )

   ACTIVATE WINDOW oWnd CENTERED

return nil

function buildMenu( oItemStatus )

   local oMenu

   MENU oMenu
      MENUITEM "&View"
      MENU oSub
         MENUITEM "&Toolbar" ACTION MsgInfo( "Toggle Toolbar" )
         MENUITEM "&Status Bar" ;
            ACTION MsgInfo( "Toggle Status Bar" ) ;
            CHECKED
         SEPARATOR
         MENUITEM "E&xit" ACTION oWnd:End()
      ENDMENU
   ENDMENU

return oMenu

Notas

  • Use la cláusula CHECKED en el comando MENUITEM para crear un elemento que esté marcado inicialmente.
  • El bloque bWhen se evalúa cada vez que se abre el menú. Si devuelve .F., el elemento se deshabilita.
  • SetPrompt() permite cambiar el texto del menú dinámicamente, útil para listas de archivos recientes o indicadores de estado.
  • Los elementos separadores se crean con el comando SEPARATOR; no tienen acción ni texto.
  • El menú padre asigna a cada elemento de menú un nId único, usado para el enrutamiento de comandos y la asignación de aceleradores.

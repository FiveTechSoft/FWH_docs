TLex

Fuente: source/classes/tlex.prg

Hereda de: TFile

TLex es un analizador léxico (tokenizador) que lee texto fuente desde un archivo o cadena y lo divide en tokens. Admite caracteres separadores configurables, modos de omitir espacios en blanco y omitir CRLF, tablas de identificadores y mapeo de IDs de tokens. La clase devuelve los tokens secuencialmente mediante nGetToken(), que devuelve un ID numérico de token correspondiente a las entradas del array aTokens.

Miembros DATA Principales

DATATipoDescripción
aTokensArrayArray de definiciones de tokens (cada entrada: { cTokenString, nTokenId })
aIdsArrayArray de cadenas de identificadores reconocidos
lSkipBlankLógicoOmitir los caracteres de espacio en blanco al tokenizar
lSkipCRLFLógicoOmitir los caracteres de retorno de carro y avance de línea
cTokenCarácterEl último texto de token extraído
cSeparatorsCarácterCadena de caracteres separadores usada para delimitar tokens
uValueCualquieraValor opcional asociado al token actual
cTextCarácterEl texto fuente completo que se está tokenizando

Métodos Principales

MétodoDescripción
New( cFile, aTokens, aIds, cSeparators )Crea un TLex a partir de un archivo, con tabla de tokens, tabla de identificadores y separadores
nGetToken()Extrae el siguiente token y devuelve su ID numérico (0 = no reconocido, -1 = fin)
lEoF()Devuelve .T. cuando se ha alcanzado el final del texto fuente
SetText( c )Establece el texto fuente a tokenizar (alternativa al constructor basado en archivo)
Add( cToken, nId )Añade una nueva cadena de token con su ID numérico a la tabla de tokens

Ejemplo: Tokenizar un Script IF-THEN-ELSE

#include "FiveWin.ch"

function Main()

   local oLex, nToken
   local cScript := "IF x > 10 THEN print 'Hello' ELSE stop"

   // Definir tokens: { cadena, id }
   local aTokens := { ;
      { "IF",    1 }, ;
      { "THEN",  2 }, ;
      { "ELSE",  3 }, ;
      { ">",     4 }, ;
      { "print", 5 }, ;
      { "stop",  6 }  }

   // Crear el analizador léxico
   oLex := TLex():New( , aTokens )
   oLex:SetText( cScript )
   oLex:lSkipBlank := .T.

   // Tokenizar
   while ! oLex:lEoF()
      nToken := oLex:nGetToken()
      if nToken == 0
         ? "No reconocido:", oLex:cToken
      elseif nToken > 0
         ? "ID de Token:", nToken, "Texto:", oLex:cToken
      endif
   enddo

return nil

Notas

  • TLex hereda de TFile, lo que permite usar texto fuente basado en archivo. Use SetText() para tokenizar una cadena en su lugar.
  • El array aTokens asigna patrones de cadena a IDs numéricos. nGetToken() devuelve el ID del token coincidente, 0 para una secuencia no reconocida, o -1 al final de la entrada.
  • cSeparators define qué caracteres delimitan los tokens. Si no se especifican, los separadores predeterminados incluyen el espacio, el tabulador y los signos de puntuación comunes.
  • El miembro de datos cToken siempre contiene el último texto de token extraído, útil para mensajes de diagnóstico o búsquedas en la tabla de símbolos.

TYacc + TLex

Fuentes: source/classes/tyacc.prg, source/classes/tlex.prg

Clases independientes (TYacc, TLex)

TYacc y TLex implementan un generador de analizadores sintácticos LALR(1) completo y un analizador léxico en Harbour puro. TYacc realiza análisis sintáctico por desplazamiento-reducción (shift-reduce) usando una máquina de estados generada, mientras que TLex se encarga de la tokenización comparando la entrada con un conjunto de patrones de tokens. Juntos permiten analizar lenguajes estructurados, expresiones y archivos de configuración.

TLex

TLex hereda de TFile y proporciona servicios de tokenización: lee el texto de entrada y devuelve un flujo de tokens con sus valores semánticos asociados.

DATATipoDescripción
aTokensArrayArray de cadenas con los patrones de tokens
aIdsArrayArray de IDs numéricos de token correspondientes a cada patrón
cTokenCarácterTexto del token coincidente actual
uValueVariosValor semántico asociado al token actual
MétodoDescripción
New( cFile, aTokens, aIds, cSeparators )Crea un lexer con patrones de tokens, IDs y caracteres separadores
nGetToken()Obtiene el siguiente token de la entrada; devuelve el ID del token
SetText( c )Establece el texto de entrada que se va a tokenizar
Add( cToken, nId )Añade un nuevo patrón de token con su ID numérico

Ejemplo: Analizador de expresiones simple

#include "FiveWin.ch"

function Main()

   local oLex, oYacc
   local aTokens := { "\d+", "\+", "\-", "\*", "/", "\(", "\)" }
   local aIds    := { 1, 2, 3, 4, 5, 6, 7 }  // NUM, MAS, MENOS, MUL, DIV, LPAR, RPAR

   oLex := TLex():New( , aTokens, aIds, " " )
   oLex:SetText( "12 + 34 * ( 56 - 7 )" )

   oYacc := TYacc():New( oLex )
   oYacc:lDebug := .T.

   // Analiza la expresión
   oYacc:Parse( oLex:cToken )

return nil

Notas

  • TYacc utiliza un algoritmo de análisis LALR(1) dirigido por tablas. Las reglas de gramática y las transiciones de estado deben definirse mediante subclases o configurando las tablas de acciones por programa.
  • Los bloques de código bShift y bReduce permiten ejecutar acciones semánticas personalizadas durante el análisis.
  • TLex prueba los patrones de tokens en orden; el primer patrón coincidente determina el token. Coloque los patrones más específicos antes que los generales.
  • ProdValue( n ) accede a los valores semánticos de la parte derecha de una regla de gramática, donde n es la posición del símbolo en la producción (empezando en 1).
  • Active lDebug para rastrear las transiciones de estado del analizador y las decisiones de desplazamiento/reducción al depurar las definiciones de gramática.

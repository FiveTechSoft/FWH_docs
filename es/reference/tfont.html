TFont

Fuente: source/classes/font.prg

Clase independiente (sin herencia)

TFont gestiona los objetos de fuente GDI de Windows. Encapsula la creación, selección y destrucción de fuentes lógicas, proporcionando una interfaz de alto nivel para el nombre del tipo de letra, el tamaño, el peso, el estilo (negrita, cursiva, subrayado, tachado), el conjunto de caracteres, la inclinación (escapement) y la orientación. TFont es utilizada en todo el framework FiveWin por cada control y ventana que dibuja texto. Las fuentes deben liberarse explícitamente con End() cuando ya no se necesitan, para evitar fugas de recursos GDI.

Miembros DATA Principales

DATATipoDescripción
hFontNumérico (Handle)Handle de fuente GDI de Windows. Creado por New(), se usa al activarla sobre un DC.
cFaceNameCarácterNombre del tipo de letra (p. ej. "Arial", "Segoe UI", "Courier New").
nInpHeightNuméricoAltura nominal de la fuente en unidades lógicas. Los valores negativos indican altura de carácter (altura em); los positivos indican altura de celda.
nInpWidthNuméricoAncho medio de carácter. Cero permite que Windows elija un ancho proporcional.
nWeightNuméricoPeso de la fuente: 0=por defecto, 400=normal, 700=negrita. Se establece automáticamente cuando lBold es .T..
nEscapementNuméricoÁngulo de la línea base del texto en décimas de grado (0 = horizontal, 900 = vertical hacia arriba).
nOrientationNuméricoÁngulo de cada carácter en décimas de grado.
nCharSetNuméricoIdentificador del conjunto de caracteres: 0=ANSI, 1=DEFAULT, 204=RUSSIAN, 238=EASTEUROPE, 255=OEM.
lBoldLógicoSi es .T., la fuente se crea con peso negrita (700).
lItalicLógicoSi es .T., la fuente se crea con estilo cursiva.
lUnderlineLógicoSi es .T., la fuente se crea con subrayado.
lStrikeOutLógicoSi es .T., la fuente se crea con tachado.
lSubstituteLógicoSi es .T., el nombre de la fuente se sustituye a través de la tabla de sustitución de fuentes (FWFontSubst()).
lQualityLógicoSi es .T., se solicita calidad suavizada (CLEARTYPE) cuando está disponible.
CargoCualquieraEspacio de datos de usuario de propósito general.

Métodos Principales

MétodoDescripción
New( cFace, nW, nH, lBold, lItalic, lUnder, lStrike, nEscap, nOrient, nWeight, nCharSet, lQuality, lSubst )Crea un nuevo objeto de fuente. Un nH negativo especifica la altura de carácter; uno positivo especifica la altura de celda. Un nW de 0 selecciona ancho proporcional. El handle de fuente hFont se crea de inmediato.
End()Libera el handle de fuente GDI (DeleteObject( ::hFont )) y libera el objeto. Debe llamarse cuando la fuente ya no se necesita.
Activate( hDC )Selecciona la fuente en un contexto de dispositivo. Devuelve el handle de la fuente anterior. Use DeActivate() para restaurar.
DeActivate( hDC, hOldFont )Restaura el handle de la fuente anterior en el contexto de dispositivo. Llámelo después de Activate() para limpiar.
Modify( nH, lBold, lItalic, lUnder, lStrike, cFace, nW, nEscap, nOrient, nWeight, nCharSet, lQuality )Cambia los atributos de la fuente y recrea el handle de fuente GDI. El handle anterior se destruye.
Choose( nRGB )Abre el cuadro de diálogo estándar de selección de fuentes de Windows. El parámetro opcional nRGB preestablece el color. Devuelve el color RGB elegido o nil si se cancela. El objeto de fuente se actualiza con la selección.
Clone()Crea una copia independiente de la fuente con un nuevo handle GDI. Útil cuando la misma fuente lógica es necesaria para distintos propietarios.
nSize()Devuelve la altura de la fuente como un valor negativo (convención de altura de carácter).
Rotate( nDeg )Crea una versión rotada de la fuente. nDeg es el ángulo de rotación en grados (no décimas). Establece tanto la inclinación (escapement) como la orientación.
Release()Alias de End(). Libera el handle de fuente GDI.
lChanged()Devuelve .T. si los atributos de la fuente se han modificado desde su creación.

Comandos: DEFINE FONT

FiveWin proporciona un comando de preprocesador para crear fuentes cómodamente:

DEFINE FONT oFont ;
   NAME cFaceName ;
   SIZE nWidth, nHeight ;
   [ BOLD ] [ ITALIC ] [ UNDERLINE ] [ STRIKEOUT ] ;
   [ CHARSET nCharSet ] ;
   [ ESCAPEMENT nDeg ] ;
   [ ORIENTATION nDeg ] ;
   [ WEIGHT nWeight ] ;
   [ QUALITY ]

La cláusula SIZE toma el ancho y la altura. Usar una altura negativa (p. ej. 0, -14) especifica la altura de carácter en puntos; una positiva especifica la altura de celda en unidades lógicas. Un ancho de 0 permite que Windows elija proporcionalmente.

Ejemplo: Crear una Fuente y Usarla en un Contexto de Dispositivo

#include "FiveWin.ch"

function Main()

   local oWnd, oFont, hOldFont, hDC

   DEFINE WINDOW oWnd TITLE "TFont Demo" SIZE 500, 300

   // Crea una fuente en negrita y cursiva
   DEFINE FONT oFont NAME "Arial" SIZE 0, -24 BOLD ITALIC

   ACTIVATE WINDOW oWnd CENTERED ;
      ON PAINT ( hDC := oWnd:GetDC(), ;
                 hOldFont := oFont:Activate( hDC ), ;
                 SayText( hDC, "Hello FiveWin!", 50, 50,, oFont:nInpHeight ), ;
                 oFont:DeActivate( hDC, hOldFont ), ;
                 oWnd:ReleaseDC( hDC ) )

   oFont:End()

return nil

Notas

  • TFont es una clase independiente: no hereda de TWindow ni de TControl.
  • Cada objeto TFont debe ir acompañado de una llamada a End(). Los handles de fuente GDI son un recurso del sistema limitado; no liberarlos provoca una degradación visible en todas las aplicaciones en ejecución.
  • El par Activate() / DeActivate() debe enmarcar cualquier dibujo personalizado que use la fuente. Nunca deje una fuente seleccionada en un DC después de finalizar el dibujo.
  • Use el método Choose() para permitir que los usuarios elijan fuentes de forma interactiva. El diálogo de fuentes muestra todas las fuentes instaladas en el sistema.
  • La sustitución de fuentes (controlada por lSubstitute) permite mapear nombres de fuentes no disponibles a alternativas a través de la tabla FWFontSubst().
  • Para usar una fuente con un control, asígnela mediante el DATA oFont (p. ej. oSay:oFont := oFont) en lugar de activarla manualmente en un DC.
  • Para compatibilidad con alta DPI, especifique los tamaños de fuente en puntos usando valores de altura negativos (p. ej. -14 para texto de 10 puntos).

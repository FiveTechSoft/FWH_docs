TCalInfo

Fuente: source/classes/calinfo.prg

Hereda de: TControl

TCalInfo representa una cita o elemento de calendario mostrado dentro de un control de calendario TCalex. Gestiona la apariencia visual, el rango temporal y el estado de selección de las entradas individuales del calendario, admitiendo elementos coloreados con degradado en las vistas de día, semana y mes.

Miembros DATA Principales

DATATipoDescripción
nStart / nEndNumericDesplazamientos de hora de inicio y fin dentro del día (en minutos)
dStart / dEndDateFechas de inicio y fin para citas de varios días
cTextCharacterTexto que se muestra para el elemento de la cita
cSubjectCharacterAsunto o título de la cita
aGradColorArrayArray de colores de degradado para el fondo del elemento
aGradColorND / aGradColorAp / aGradColorBTArrayColores de degradado para los estados no mostrado, cita y horario laboral
lSelectedLogicalEstado de selección de la cita
oCalexObjectControl de calendario TCalex padre

Métodos Principales

MétodoDescripción
New( oCalex, nStart, nEnd, dStart, dEnd, cText, cSubject )Crea un nuevo elemento de calendario con límites temporales y texto a mostrar
BuildDates( nTop, nLeft, nW, nH )Calcula el rectángulo visual del elemento dentro de la cuadrícula del calendario
Move()Reposiciona el elemento en respuesta al desplazamiento o redimensionado del calendario
Paint()Dibuja el elemento en la vista predeterminada del calendario
PaintOnMonth()Dibuja el elemento dentro de la cuadrícula de vista mensual
PaintOnWeek()Dibuja el elemento dentro de la vista de semana/día
Show() / Hide()Muestra u oculta el elemento de calendario

Ejemplo: Crear una Cita

#include "FiveWin.ch"

function Main()

   local oCalex, oAppt

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 800, 600

   oCalex := TCalex():New( oWnd )

   oAppt := TCalInfo():New( oCalex, ;
      540, 600, ;              // 9:00 a.m. a 10:00 a.m.
      dDate(), dDate(), ;      // Solo hoy
      "Team Meeting", "Weekly sync" )

   oAppt:aGradColor := { CLR_BLUE, CLR_CYAN }
   oAppt:Show()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Los valores de tiempo (nStart, nEnd) se expresan en minutos desde la medianoche (0 a 1439).
  • Las citas de varios días usan los valores de fecha dStart y dEnd que abarcan la duración del evento.
  • Los arrays de degradado contienen dos valores numéricos de color para las paradas de degradado inicial y final.
  • El control TCalex padre distribuye las llamadas de dibujado al método de vista adecuado (PaintOnMonth, PaintOnWeek o Paint) según el modo de visualización actual.

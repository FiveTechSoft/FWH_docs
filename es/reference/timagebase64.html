TImageBase64

Fuente: source/classes/imageb64.prg

Clase utilitaria independiente

TImageBase64 es una clase utilitaria que codifica imágenes a Base64 para su uso en páginas web (etiquetas HTML <img> con URIs de datos). También puede extraer y guardar imágenes a partir de HTML codificado en Base64. La clase detecta automáticamente si el origen de entrada es una ruta de archivo, una URL o texto plano.

Miembros DATA Principales

DATATipoDescripción
aImageArrayArreglo interno de imagen procedente de FW_ReadImage
cFileCharacterRuta del archivo de origen o URL (si corresponde)
cBase64CharacterCadena de imagen codificada en Base64
lTagLogicalIncluir etiquetas <img> en la salida
lHtmlLogicalGenerar un documento HTML completo en la salida
lUrlEncodeLogicalCodificar en URL la URI de datos en lugar de base64 plano
nImgWidthNumericAncho de la imagen en píxeles (ACCESS de solo lectura)
nImgHeightNumericAlto de la imagen en píxeles (ACCESS de solo lectura)

Métodos Principales

MétodoDescripción
New( cSource )Crea el objeto; opcionalmente carga el origen de inmediato
SetSource( cSource )Establece el origen: detecta automáticamente archivo, URL o texto base64
ChooseFile()Abre el diálogo de selección de archivos para elegir una imagen
Paste()Carga la imagen desde el portapapeles
MakeText( lUrlEncode, lTag, lHtml, cTitle )Genera el texto de salida (URI de datos o HTML)
SaveText( cFile, lUrlEncode, lTag, lHtml )Guarda el texto de salida en un archivo; devuelve el nombre del archivo o nil
CopyText( lUrlEncode, lTag, lHtml )Copia el texto de salida al portapapeles; devuelve el texto
SaveImage()Guarda la imagen decodificada en un archivo (.jpg o .png)
TestHTML()Genera un archivo HTML de prueba y lo abre en el navegador

Ejemplo: Imagen a Etiqueta HTML Base64

#include "FiveWin.ch"

function Main()

   local oImg := TImageBase64():New( "c:\images\photo.jpg" )

   // Genera una etiqueta img HTML con datos base64 en línea
   oImg:lTag := .T.
   oImg:CopyText()   // copia al portapapeles

   // O guarda como un archivo HTML completo
   oImg:lHtml := .T.
   oImg:SaveText( "preview.html" )

   // Abre en el navegador para probar
   oImg:TestHTML()

return nil

Notas

  • La detección automática del origen comprueba: ruta de archivo (<=255 caracteres, existe en disco), URL HTTP/HTTPS o texto codificado en base64.
  • Utilice Paste() para tomar una imagen directamente del portapapeles de Windows (formato bitmap, lista de archivos o PNG).
  • El dato de clase nLineWidth (1024 por defecto) controla el salto de línea en la salida base64.
  • Formatos de salida soportados: URIs data:image/..., etiquetas <img> o documentos HTML completos.

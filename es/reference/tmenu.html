TMenu

Fuente: source/classes/menu.prg

Clase independiente (no basada en control)

TMenu es el sistema de menús de FiveWin. Gestiona tanto menús emergentes (popup) como menús del sistema, con soporte para temas modernos de Office (2007/2010/2013/2015), aceleradores de teclado y combinación de menús MDI. Los menús se pueden crear programáticamente mediante comandos o a partir de recursos de diálogo.

Miembros DATA Principales

DATATipoDescripción
hMenuHandleHandle de menú de Windows (HMENU)
aItemsArrayArreglo de objetos TMenuItem de este menú
oWndObjectVentana propietaria del menú
lPopupLogical.T. para menús emergentes (contextuales), .F. para la barra de menú de nivel superior
lSysMenuLogical.T. si es el menú del sistema
l2007LogicalTema visual de Office 2007
l2010LogicalTema visual de Office 2010
l2013LogicalTema visual de Office 2013
l2015LogicalTema visual de Office 2015
oAccTableObjectTabla de aceleradores de teclado
oFontObjectFuente utilizada para el texto del menú

Métodos Principales

MétodoDescripción
New( lPopup, oWnd, nClrT, nClrP, oFont, l2007, l2010, l2013, l2015 )Crea un nuevo menú; lPopup=.T. para menús contextuales
ReDefine( cRes, ... )Crea un menú a partir de la definición de un recurso de diálogo
NewSys( oWnd )Crea u obtiene el menú del sistema de una ventana
Add( oMenuItem, lRoot )Añade un TMenuItem; si lRoot es .T. lo añade como nivel superior
Insert( oMenuItem, nAt )Inserta un TMenuItem en la posición indicada
DelItem( nAt )Elimina un elemento de menú en una posición
Command( nCmd )Ejecuta la acción asociada a un ID de comando
Activate( nRow, nCol, oWnd )Muestra el menú emergente en coordenadas de pantalla

AddMdi( aColors )Configura la combinación de menús MDI con un arreglo de colores

Comandos de Menú

La forma más habitual de definir menús es mediante la sintaxis de comandos MENU / MENUITEM: 

MENU oMenu
   MENUITEM "&File"
      MENU oSub
         MENUITEM "&Open"   ACTION oWnd:Open()
         MENUITEM "&Save"   ACTION oWnd:Save()
         SEPARATOR
         MENUITEM "E&xit"   ACTION oWnd:End()
      ENDMENU
   MENUITEM "&Help"
      MENU oSub
         MENUITEM "&About"  ACTION MsgInfo( "My App v1.0" )
      ENDMENU
ENDMENU

Ejemplo: Menú Emergente

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu

   DEFINE WINDOW oWnd TITLE "TMenu Demo"

   // Crear un menú contextual emergente
   MENU oMenu POPUP
      MENUITEM "Cut"    ACTION MsgInfo( "Cut" )
      MENUITEM "Copy"   ACTION MsgInfo( "Copy" )
      MENUITEM "Paste"  ACTION MsgInfo( "Paste" )
      SEPARATOR
      MENUITEM "Delete" ACTION MsgInfo( "Delete" )
   ENDMENU

   // Asignar a la ventana como emergente al hacer clic derecho
   oWnd:bRClicked := { |nRow, nCol| oMenu:Activate( nRow, nCol, oWnd ) }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Los menús emergentes se posicionan en coordenadas de pantalla mediante Activate( nRow, nCol, oWnd ). Los valores de fila y columna provienen del bloque de evento bRClicked.
  • Los indicadores l2007, l2010, l2013 y l2015 activan el renderizado de menús con tema. Solo uno debe estar activo a la vez.
  • Use oAccTable para definir aceleradores de teclado (teclas de acceso rápido) para los elementos del menú.
  • Para aplicaciones MDI, AddMdi() gestiona la combinación automática de menús cuando se activan ventanas hijas.

TRColumn

Fuente: source/classes/rcolumn.prg

Clase independiente

TRColumn representa una única columna dentro de un TReport. Define cómo se obtienen, formatean y muestran los datos de cada columna en un informe impreso. Las columnas admiten totales, totales acumulados, campos memo, imágenes, barras de progreso y gráficos en línea.

Ejemplo: Columna con Total

#include "FiveWin.ch"
#include "report.ch"

function BuildReport()

   local oReport, oCol

   REPORT oReport TITLE "Sales Report" PREVIEW

   COLUMN oCol TITLE "Product" DATA { || oSale:Product }
   COLUMN oCol TITLE "Amount" ;
          DATA { || oSale:Amount } ;
          PICTURE "999,999.99" ;
          TOTAL

   END REPORT

   ACTIVATE REPORT oReport

return nil

Notas

  • TRColumn se crea implícitamente al usar el comando COLUMN dentro de un bloque REPORT.
  • Establezca lTotal := .T. para activar el totalizado automático en columnas numéricas.
  • El indicador lCumTotal acumula los totales entre grupos en lugar de reiniciarlos en cada grupo.
  • Las columnas memo (lMemo := .T.) admiten el ajuste de texto multilínea dentro del ancho de la columna.
  • Las columnas de imagen (lImage := .T.) muestran los bitmaps obtenidos por el bloque de código de datos.
  • Las columnas admiten gráficos de barras en línea mediante los miembros DATA cChartStyle y chartdata.

Generación de Códigos de Barras (FWER_BarCode)

Fuente: source/classes/fwbarcod.prg, source/function/fwzebra.prg

FWER_BarCode es el motor de renderizado de códigos de barras integrado en FiveWin. Soporta 17 simbologías de código de barras mediante un motor GDI nativo, con respaldo opcional a la librería hbzebra para códigos 2D (QR, DataMatrix, PDF417). Los códigos de barras se pueden renderizar en ventanas, diálogos, impresoras y salida PDF.

Funciones Libres

FW_SayBarCode()

Renderizado directo del código de barras sin crear una instancia de objeto:

FW_SayBarCode( oWnd, cText, aRect, cType, nClrT, nClrB, lVert, lTransp )

Parámetros: oWnd (ventana/diálogo/impresora), cText (datos a codificar), aRect (array { nTop, nLeft, nBottom, nRight }), cType (cadena de simbología), nClrT/nClrB (colores de frente/fondo), lVert (orientación vertical), lTransp (fondo transparente).

FW_BarCodeBmp()

Genera un handle de bitmap independiente del código de barras para usar en informes o controles de imagen.

Ejemplo: EAN-13 en Impresora

#include "FiveWin.ch"

FUNCTION PrintBarcode()
   LOCAL oPrn, nRow := 2.0  // cm desde arriba

   PRINT oPrn NAME "Barcode Test"
   PAGE
      oPrn:Say( nRow, 1.0, "Product Barcode:" )
      nRow += 0.8

      // Método 1: Usando FWER_BarCode directamente
      FWER_BarCode():New( oPrn:hDC, "5901234567890", ;
                          oPrn:CmToPix( nRow ),        // nTop
                          oPrn:CmToPix( 1.0 ),         // nLeft
                          oPrn:CmToPix( 5.0 ),         // nWidth
                          oPrn:CmToPix( 2.5 ),         // nHeight
                          8, 0, 16777215, .T., .F. ):ShowBarcode()

      // Método 2: Usando la función de conveniencia FW_SayBarCode
      nRow += 3.0
      FW_SayBarCode( oPrn, "5901234567890", ;
                     { oPrn:CmToPix( nRow ), oPrn:CmToPix( 1.0 ), ;
                       oPrn:CmToPix( nRow + 2.5 ), oPrn:CmToPix( 6.0 ) }, ;
                     "EAN13", 0, 16777215 )
   ENDPAGE
   ENDPRINT
RETURN NIL

Notas

  • Los nombres de tipo como cadena no distinguen entre mayúsculas y minúsculas y se normalizan eliminando el prefijo "CODE", los espacios, los guiones bajos y los guiones. Ejemplo: "CODE128", "code 128" y "128" se resuelven todos a Code 128 auto.
  • Cuando se enlaza la librería hbzebra, las simbologías 2D (QR, DataMatrix, PDF417) se encaminan automáticamente a través del motor Zebra, que también soporta salida PDF directa mediante la detección del objeto TPDF.
  • Use FWER_BarCode:lUseZebraLib := .T. a nivel de clase para forzar el motor Zebra en todas las simbologías soportadas.
  • La salida a impresora usa GDI FillRect para las barras y FillRectEx para el fondo, garantizando un escalado correcto en dispositivos de alta resolución (high-DPI).

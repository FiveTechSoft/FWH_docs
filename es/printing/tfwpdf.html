FWPdf

Fuente: source/classes/fwpdf.prg

Hereda de: TPdf

FWPdf es una clase mejorada de generación de PDF que extiende TPdf con características adicionales como soporte Unicode, renderizado de texto RTF, gráficos circulares, rellenos degradados, códigos de barras, impresión de imágenes, hipervínculos y soporte de coordenadas en múltiples unidades (puntos, pulgadas, centímetros, milímetros). Proporciona una API completa de alto nivel para crear documentos PDF profesionales.

Ejemplo: PDF Enriquecido con Imagen, Gráfico y Degradado

#include "FiveWin.ch"

function Main()

   local oPdf, oFont

   oPdf := FWPdf():New( "rich_doc.pdf" )
   oPdf:cAuthor  := "FWH User"
   oPdf:cTitle   := "Rich Document"
   oPdf:cSubject := "Demonstrates FWPdf features"

   oPdf:SetPage( HPDF_PAGE_SIZE_A4 )
   oPdf:StartPage()

   oFont := oPdf:DefineFont( "Arial", 16, .T., .T. )

   // Title text
   oPdf:Say( 2, 2, "FWPdf Rich Document", oFont, , , , , "CM" )

   // Gradient fill
   oPdf:GradientFill( { 2, 2, 19, 5 }, { { CLR_HRED, 0.5 }, { CLR_HBLUE, 0.5 } }, .F., "CM" )

   // Draw a line separator
   oPdf:Line( 2, 6, 19, 6, , "CM" )

   // Barcode
   oPdf:PrintBarcode( "FWH-12345", 2, 7, 6, 2, "CM" )

   oPdf:EndPage()
   oPdf:Save()

return nil

Notas

  • FWPdf hereda todos los métodos de TPdf y los extiende con sobrecargas que reconocen unidades. El parámetro cUnits acepta "P" (puntos), "I" (pulgadas), "C" (centímetros) o "M" (milímetros).
  • Unicode está habilitado por defecto según FW_SetUnicode(). Cuando está activo, se utiliza codificación UTF-8 para todo el texto PDF.
  • Los metadatos (autor, título, asunto, creador) se incrustan en el PDF y son visibles en las propiedades del documento.
  • Los rellenos degradados admiten degradados lineales con múltiples paradas de color y proporciones.
  • Los tipos de códigos de barras incluyen Code 128, Code 39, EAN-13 y otros.

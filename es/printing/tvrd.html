VRD - Motor de Diseño Visual de Informes

Fuente: source/classes/vrd.prg

Clase independiente (motor de informes)

VRD es el motor en tiempo de ejecución para el Diseñador Visual de Informes. Carga y procesa definiciones de informes almacenadas en archivos .rpt (formato INI), gestiona áreas de datos, procesa consultas de bases de datos y dirige la impresión o previsualización de informes complejos. No es un diseñador visual en sí mismo, sino el motor de ejecución que lee la salida del diseñador.

Ejemplo: Cargar y Previsualizar un Informe

#include "FiveWin.ch"

function Main()

   local oRpt

   // Load a report definition and open in preview mode
   oRpt := VRD():New( "C:\reports\invoice.rpt", .T. )
   oRpt:OpenDatabases()
   oRpt:AreaStart( 1 )
   oRpt:PrintArea( 1 )
   oRpt:End()

return nil

Notas

  • VRD lee definiciones de informes desde archivos .rpt en formato INI creados por la aplicación Diseñador Visual de Informes. Estos archivos definen áreas, elementos, fuentes, colores, conexiones de bases de datos y expresiones.
  • Las áreas del informe son secciones lógicas (ej., encabezado de página, detalle, pie de página). Cada área tiene su propio conjunto de elementos (texto, campos, líneas, cuadros) posicionados en coordenadas de diseño.
  • El motor admite expresiones calculadas, resúmenes de bases de datos, impresión condicional y gestión de saltos de página.
  • Se pueden abrir múltiples bases de datos simultáneamente mediante aDBAlias, admitiendo estructuras de informe maestro-detalle.

Impresión de Etiquetas

Fuentes: samples/labels/source/LABEL.PRG, LITEM.PRG, PDLABEL.PRG — por Manuel Calero Solis (1995)

FWH incluye un sistema completo de impresión de etiquetas en samples/labels/ con 17 programas de ejemplo y código fuente completo. Imprime etiquetas en una disposición de cuadrícula (p. ej. 2 a lo ancho, 7 a lo alto) con saltos de página automáticos, posicionamiento y soporte de mapas de bits. Las etiquetas pueden enviarse a la impresora, a una ventana de vista previa o a un archivo de texto.

Arquitectura

graph LR A["Comando LABEL"] --> B["Motor TLabel"] B --> C["TPrinter"] B --> D["TRFile (texto)"] B --> E["Diálogo de Vista Previa"] F["TLItem"] --> B G["Comando LBLITEM"] --> F

Comandos (include/label.ch)

LABEL

LABEL oLabel ;
   SIZE nWidth, nHeight ;          // mm
   SEPARATORS nH, nV ;              // separación horizontal, vertical en mm
   ON LINE nCount ;                 // etiquetas por fila
   FONT aFonts PEN aPens ;         // arrays opcionales de fuentes/lápices
   TO PRINTER | PREVIEW | FILE cFile | DEVICE oDevice ;
   CAPTION cTitle

LBLITEM

LBLITEM DATA bData1, bData2, ... ;
   AT nCol ;                        // desplazamiento de columna
   SIZE nChars ;                    // ancho en caracteres
   PICTURE cPict1, cPict2, ... ;
   FONT uFont ;                     // índice o nombre de fuente
   LEFT | CENTER | RIGHT ;
   SHADOW ;                         // fondo gris
   GRID nPen                        // línea de cuadrícula inferior

ACTIVATE LABEL

ACTIVATE LABEL oLabel ;
   FOR bFor WHILE bWhile ;
   ON INIT bInit ;
   ON STARTPAGE bStartPage ON ENDPAGE bEndPage ;
   ON STARTLINE bStartLine ON ENDLINE bEndLine ;
   ON STARTLABEL bStartLabel ON ENDLABEL bEndLabel ;
   ON CHANGE bChange

Clase TLabel

Motor central de etiquetas. Gestiona la disposición de la cuadrícula de etiquetas, los saltos de página, las fuentes y el dispositivo de salida.

DATADescripción
oDeviceDispositivo de salida (TPrinter, TRFile o pantalla)
nLblWidth / nLblHeightDimensiones de la etiqueta en píxeles
nHSeparator / nVSeparatorSeparación horizontal/vertical entre etiquetas
nLblOnLineEtiquetas por fila a lo ancho de la página
aoItemsArray de objetos TLItem (campos de la etiqueta)
aFont / aPenArrays de fuentes y lápices (escalados al dispositivo)
nLeftMargin / nRightMargin / nTopMargin / nDnMarginMárgenes de página en píxeles
MétodoDescripción
New(nW,nH,hSep,vSep,nPerLine,aFont,aPen,...)Constructor, crea el dispositivo, escala las unidades
AddItem(oItem)Añade un TLItem a la etiqueta
Activate(bFor,bWhile,bInit,...)Establece los hooks e inicia el bucle de impresión
Say(nRow,nCol,xText,nFont,nPad)Imprime texto con alineación izquierda/centro/derecha
SayBitmap(nRow,nCol,cBmp,nW,nH)Dibuja un mapa de bits en la posición indicada
Box(nRow,nCol,nBottom,nRight,nPen)Dibuja un rectángulo
Line(nTop,nLeft,nBottom,nRight,nPen)Dibuja una línea
Shadow(nH,nItem,nLine)Relleno de fondo gris detrás de una etiqueta
Grid(nH,nItem,nLine)Línea de cuadrícula horizontal a lo ancho de la etiqueta
Margin(nVal,nType)Establece márgenes individuales

Clase TLItem

Representa un campo de datos dentro de una etiqueta. Se crea con el comando LBLITEM.

DATADescripción
aDataArray de bloques de código que devuelven los valores a imprimir
aPictureCláusulas PICTURE por bloque de datos
bDataFontBloque de código que devuelve el índice de fuente
nWidth / nDataHeightDimensiones del campo en píxeles
nColDesplazamiento opcional de columna desde el borde izquierdo
nPadAlineación: RPT_LEFT(1), RPT_RIGHT(2), RPT_CENTER(3)
lShadow / lGridActiva el fondo de sombra / línea de cuadrícula inferior

Ejemplo: Etiqueta de Dirección Sencilla

#include "FiveWin.ch"
#include "label.ch"

FUNCTION Label01()
   local oLabel
   USE TEST NEW SHARED ALIAS "TEST"

   // etiquetas de 89x23mm, 2 por fila, vista previa
   LABEL oLabel SIZE 89, 23 ;
      SEPARATORS 5, 2 ;
      ON LINE 2 ;
      PREVIEW ;
      CAPTION "Address Labels"

   LBLITEM DATA "N.: " + Str( TEST->( RECNO() ), 0 )
   LBLITEM DATA TEST->FIRST
   LBLITEM DATA TEST->LAST
   LBLITEM DATA TEST->STREET

   END LABEL oLabel
   ACTIVATE LABEL oLabel
   CLOSE TEST
RETURN NIL

Etiquetas con Códigos QR

Combine la impresión de etiquetas con códigos QR usando FW_BarCodeBmp() + SayBitmap():

REQUEST FWZEBRA

LABEL oLabel SIZE 100, 60 ;
   SEPARATORS 3, 3 ;
   ON LINE 2 ;
   PREVIEW

LBLITEM DATA CUSTOMER->FIRST
LBLITEM DATA CUSTOMER->LAST
LBLITEM DATA CUSTOMER->CITY

ACTIVATE LABEL oLabel ;
   ON STARTLABEL { || ;
      oLabel:SayBitmap( 1, 3.5, ;
         FW_BarCodeBmp( ;
            "https://example.com/" + CUSTOMER->ID, ;
            "QR", 150, 150 ), ;
         0.5, 0.5 ) }

END LABEL oLabel

Programas de Ejemplo

El directorio samples/labels/ contiene 17 ejemplos listos para ejecutar:

  • LABEL01.PRG hasta LABEL17.PRG — ejemplos progresivos que cubren etiquetas de dirección, etiquetas de producto, códigos de barras, multipágina, salida a archivo y vista previa
  • DEMO.PRG — demostración combinada
  • source/LABEL.PRG — clase del motor TLabel
  • source/LITEM.PRG — clase de campo de datos TLItem
  • source/PDLABEL.PRG — funciones auxiliares de comandos
  • include/LABEL.CH — definiciones #xcommand
  • ilabel/ — subsistema de etiquetas italiano (ILABELS.PRG, MLABEL.PRG)

Consejos

  • Las etiquetas se miden en milímetros de forma predeterminada. Use TO PRINTER para impresión directa o PREVIEW para vista previa en pantalla.
  • Los hooks ON STARTLABEL y ON ENDLABEL son el mejor lugar para añadir dibujos personalizados (imágenes, códigos de barras, códigos QR).
  • Para códigos QR en etiquetas, genere un mapa de bits con FW_BarCodeBmp() y dibújelo mediante oLabel:SayBitmap() dentro de un hook STARTLABEL.
  • Para impresión de etiquetas independiente sin el sistema TLabel, use TPrinter directamente: establezca el tamaño del papel, recorra los registros, llame a Say() para cada campo y gestione las posiciones manualmente.

TRGroup

Fuente: source/classes/rgroup.prg

Clase independiente

TRGroup define un corte de grupo dentro de un TReport. Los grupos permiten informes jerárquicos con cabeceras de grupo, pies y subtotales automáticos. Cuando se produce un corte de grupo (detectado por un cambio en el valor de la expresión de grupo), se imprime el pie del grupo, se reinician los totales, y la cabecera del nuevo grupo se imprime en la página siguiente o en la línea siguiente.

Ejemplo: Agrupar por Estado con Subtotales

#include "FiveWin.ch"
#include "report.ch"

function GroupedReport()

   local oReport

   REPORT oReport TITLE "Sales by State" PREVIEW

   GROUPS oReport

   GROUP ON { || oSale:State } ;
          HEADER { || "State: " + oSale:State } ;
          FOOTER { || "Subtotal for " + oSale:State }

   COLUMN TITLE "Customer" DATA { || oSale:Customer }
   COLUMN TITLE "Amount"   DATA { || oSale:Amount } ;
          PICTURE "9,999.99" TOTAL

   END REPORT

   ACTIVATE REPORT oReport

return nil

Notas

  • Use el comando GROUP ON dentro de un bloque REPORT para definir cortes de grupo de forma declarativa.
  • Los cortes de grupo se detectan automáticamente comparando la evaluación actual de bGroup con el valor anterior.
  • Establezca lEject := .T. para forzar un salto de página cada vez que cambie el valor del grupo.
  • El array aTotal acumula subtotales para las columnas que tienen lTotal := .T..
  • Se pueden anidar varios niveles de grupo definiendo varios objetos TRGroup en secuencia.

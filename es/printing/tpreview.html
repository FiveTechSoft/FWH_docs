TPreview

Fuente: source/classes/rpreview.prg

Clase independiente (no hereda de TControl)

TPreview es el motor de vista previa de impresión de FiveWin. Se invoca automáticamente al usar la cláusula PREVIEW con el comando PRINTER, y proporciona un entorno de previsualización completo con zoom, navegación de páginas, vista de dos páginas, impresión y capacidades de exportación. También es utilizado internamente por TReport para la previsualización de informes.

Ejemplo: Vista Previa con Comando PRINTER

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "Print Preview Demo" SIZE 600, 400

   @ 20, 20 BUTTON "&Print Preview" SIZE 120, 30 OF oWnd ;
      ACTION DoPreview()

   ACTIVATE WINDOW oWnd CENTERED

return nil

function DoPreview()

   PRINTER oPrn PREVIEW
      PAGE
         @ 10, 10 SAY "Hello from FiveWin!" FONT oPrn:oFont
         @ 30, 10 SAY "Page: " + Str( oPrn:nPageCount )
      ENDPAGE
      PAGE
         @ 10, 10 SAY "This is page 2"
      ENDPAGE
   ENDPRINTER

return nil

Notas

  • TPreview se usa automáticamente cuando se especifica PRINTER ... PREVIEW. También puede instanciarse directamente pasando un dispositivo TPrinter y un objeto TReport opcional.
  • La ventana de previsualización admite navegación por teclado: teclas de flecha para desplazamiento, Re Pág/Av Pág para navegación de páginas, y +/- para acercar/alejar.
  • El modo oscuro se detecta y aplica automáticamente en Windows 11 cuando el tema del sistema está configurado en oscuro.
  • Las capacidades de exportación (PDF, Word, Excel) dependen de que el dispositivo de impresión y el informe tengan los bloques de código apropiados asignados.
  • oLvw (miniaturas en vista de lista) proporciona un selector visual de páginas en la barra lateral. Se puede ocultar mediante el classdata lListViewHide.

TEReport (Diseñador de EasyReport)

Fuente: source/classes/tereport.prg

TEReport es el diseñador visual interactivo para archivos de informe de EasyReport (.vrd / .erd). Envuelve a TEasyReport y proporciona un editor MDI completo con barra de menú, barra de botones, superficie de diseño del área del informe, inserción de elementos (texto, imagen, gráfico, código de barras), deshacer/rehacer, gestión de bases de datos, configuración de fuentes/colores y capacidades de vista previa/impresión. Es la herramienta principal para diseñar visualmente los diseños de los informes.

Miembros DATA Principales

DATATipoDescripción
oERTEasyReportInstancia subyacente del motor EasyReport
cFileReportCharacterRuta del archivo de informe actual
oGenVarTExStructContenedor de variables generales (colores, brochas, fuentes, ajustes)
aFontsArrayArray de objetos TFont (hasta 20) definidos para el informe
aAreasArrayÁreas del informe (bandas) accedidas mediante :oER:aAreaIni
aItemsArrayElementos del informe por área, accedidos mediante :oER:aItems[nArea, nItem]
oBarTButtonBarBarra de botones principal del diseñador
lVRDSaveLogicalIndica si existen cambios sin guardar

Métodos

MétodoDescripción
New( oP )Crea y ejecuta el diseñador como hijo MDI de una ventana existente, o como ventana MDI independiente
Activate( ... )Activa el diseñador como aplicación MDI independiente con soporte de archivo por línea de comandos
OpenFile( cFile, lChange, lAddDelNew )Abre un archivo de informe .vrd o .erd en el diseñador
SaveFile()Guarda el estado actual del informe (todas las áreas, ajustes generales)
SaveAs( cFile )Guarda el informe en una nueva ruta de archivo
SaveAsNewFormat()Convierte y guarda en el nuevo formato .erd
Undo()Deshace la última acción del diseñador
Redo()Rehace una acción previamente deshecha
BuildMenu()Construye la estructura completa de menú del diseñador
BarMenu()Construye la barra de botones del diseñador con todas las herramientas
SetGeneralSettings()Carga y aplica los ajustes generales a nivel de informe (medida, rejilla, bases de datos)
ClientWindows()Crea todas las ventanas hijas MDI para cada área del informe, cargando los datos del área
DefineFonts()Carga las definiciones de fuentes del archivo de informe en objetos TFont
OpenDatabases()Abre y carga las definiciones de bases de datos desde la configuración del informe

Ejemplo: Ejecutar el Diseñador de EasyReport desde Código

#include "FiveWin.ch"

function Main()

   local oER

   oER := TEReport():New()  // Diseñador independiente

return nil

Ejemplo: Abrir un Archivo de Informe en el Diseñador

#include "FiveWin.ch"

function Main()

   local oER

   oER := TEReport():New()
   oER:OpenFile( "myreport.vrd" )

return nil

Notas

  • TEReport es una aplicación completa de diseño visual, no un envoltorio de ejecución de informes. Aloja el motor TEasyReport y presenta una interfaz gráfica basada en MDI para diseñar diseños de informes.
  • Los archivos de informe vienen en dos formatos: el antiguo .vrd (formato VRD) y el nuevo .erd (formato EasyReport). El diseñador maneja ambos de forma transparente.
  • Cada área del informe (banda) se muestra como una ventana hija MDI dentro de la ventana principal del diseñador, con soporte para la colocación de elementos mediante arrastrar y soltar.
  • Los tipos de elementos incluyen TEXT, IMAGE, GRAPHIC y BARCODE. Cada elemento puede posicionarse, dimensionarse y estilizarse a través del diálogo de propiedades.
  • El deshacer/rehacer se implementa usando archivos DBF temporales que almacenan los cambios a nivel de entrada y a nivel de área.
  • El diseñador incluye un sistema multiidioma que soporta inglés, alemán, italiano, español, portugués y francés.

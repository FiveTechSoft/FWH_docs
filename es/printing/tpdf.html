TPdf

Fuente: source/classes/tpdf.prg

Clase independiente (usa libharu / hbhpdf.lib)

TPdf proporciona generación de documentos PDF utilizando la biblioteca Haru Free PDF (libharu). Soporta la creación de documentos PDF multipágina con texto, líneas, rectángulos, imágenes y fuentes. Los documentos pueden protegerse con contraseña y permisos configurables.

Ejemplo: Crear un PDF con Texto y Formas

#include "FiveWin.ch"
#include "harupdf.ch"

function Main()

   local oPdf, oFont

   oPdf := TPdf():New( "output.pdf" )

   // Set up the first page
   oPdf:SetPage( HPDF_PAGE_SIZE_A4 )
   oPdf:StartPage()

   // Define a font
   oFont := oPdf:DefineFont( "Courier", 12 )

   // Draw text
   oPdf:Say( 100, 100, "Hello, PDF World!", oFont )

   // Draw a rectangle
   oPdf:Rect( 80, 80, 300, 150, , CLR_RED )

   // Draw a line
   oPdf:Line( 80, 80, 300, 150 )

   oPdf:EndPage()

   // Second page with landscape orientation
   oPdf:SetPage( HPDF_PAGE_SIZE_A4 )
   oPdf:SetLandscape()
   oPdf:StartPage()
   oPdf:Say( 100, 100, "This is landscape", oFont )
   oPdf:EndPage()

   oPdf:Save()
   oPdf:End()

return nil

Notas

  • TPdf requiere enlazar hbhpdf.lib y libhpdf.lib de la carpeta lib de FWH.
  • Las coordenadas están en puntos (1/72 pulgada) por defecto. Use CmSay, CmLine, CmRect para coordenadas basadas en centímetros.
  • La incrustación de fuentes se admite mediante AddFont() y DefineFont( cFontName, nSize, lEmbed ).
  • La protección por contraseña con permisos se establece mediante el constructor. Los permisos incluyen HPDF_ENABLE_READ, HPDF_ENABLE_PRINT, HPDF_ENABLE_COPY y HPDF_ENABLE_EDIT.
  • Las fuentes TrueType del directorio Fonts del sistema se detectan automáticamente y están disponibles por nombre de tipo.

TRFile

Fuente: source/classes/rfile.prg

Clase independiente

TRFile es un dispositivo de salida de informes a fichero de texto que implementa la misma interfaz que TPrinter, permitiendo escribir informes en un fichero de texto plano en lugar de en una impresora. Sustituye al controlador de dispositivo de TReport, proporcionando Say(), StartPage(), EndPage() y métodos de medición que operan sobre celdas de caracteres en lugar de píxeles.

Miembros DATA Principales

DATATipoDescripción
hDCNuméricoManejador del fichero de texto de salida
aRowsArrayArray de cadenas de caracteres, una por cada fila de la página actual
cDocumentCarácterNombre del documento
nHeightNuméricoAltura de la página en filas de caracteres
nWidthNuméricoAncho de la página en columnas de caracteres
lPrintLógicoHabilita la salida (por defecto .T.)

Métodos

MétodoDescripción
New( cFile )Abre cFile para escritura y crea un dispositivo TRFile
Say( nRow, nCol, cText, oFont, nMaxSize, u6, u7, nPad )Escribe texto en la fila y columna especificadas dentro del búfer de caracteres
StartPage()Comienza una nueva página; limpia el búfer de filas
EndPage()Vuelca el búfer de la página actual al fichero
End()Cierra el fichero de salida
SetHeight( nHeight )Establece la altura de la página en filas de caracteres y reinicializa el búfer
SetSize( nWidth, nHeight )Establece las dimensiones de la página en celdas de caracteres
GetTextWidth( cText )Devuelve Len( cText ) (ancho basado en caracteres)
GetTextHeight()Siempre devuelve 1 (altura de una sola fila de caracteres)

Ejemplo: Escribir un Informe de Texto a Fichero

#include "FiveWin.ch"

function WriteTextReport()

   local oFile := TRFile():New( "report.txt" )

   oFile:SetSize( 80, 66 )

   oFile:StartPage()
   oFile:Say( 1, 30, "Monthly Report" )
   oFile:Say( 3, 1,  Replicate( "-", 80 ) )
   oFile:Say( 5, 1,  "Item" )
   oFile:Say( 5, 40, "Amount" )
   oFile:Say( 6, 1,  Replicate( "-", 80 ) )
   oFile:Say( 8, 1,  "Widget A" )
   oFile:Say( 8, 40, "  150.00" )
   oFile:Say( 9, 1,  "Widget B" )
   oFile:Say( 9, 40, "  275.00" )
   oFile:EndPage()

   oFile:End()

return nil

Notas

  • TRFile puede usarse como sustituto directo de TPrinter en TReport asignando oReport:oDevice := TRFile():New( "out.txt" ).
  • El posicionamiento del texto se basa en caracteres: la fila 1, columna 1 es la esquina superior izquierda.
  • No se admiten fuentes, mapas de bits, líneas ni cajas (los métodos son VIRTUAL).
  • Cada página se almacena en el búfer aRows y se vuelca a disco en EndPage().

TArrayData

Fuente: source/classes/tarrdata.prg

TArrayData proporciona una interfaz uniforme de fuente de datos sobre arrays de Harbour, tablas DBF y consultas MariaDB/MySQL. Actúa como puente entre los datos y XBrowse, permitiendo que cualquier fuente de datos sea navegada, ordenada, filtrada y editada usando la misma API. Internamente, los datos se almacenan como un array de filas con una definición de estructura de campos equivalente.

Ejemplo: Array a XBrowse con Ordenación

#include "FiveWin.ch"

function Main()

   local aData, aStruct, oWnd, oBrw

   // Define structure
   aStruct := { { "NAME", "C", 20, 0 }, ;
                { "AGE",  "N",  3, 0 }, ;
                { "CITY", "C", 15, 0 } }

   // Sample data
   aData := { { "Alice",   30, "New York" }, ;
              { "Bob",     25, "Boston"   }, ;
              { "Charlie", 35, "Chicago"  } }

   DEFINE WINDOW oWnd TITLE "Array Data Browser" SIZE 500, 300

   @ 0, 0 XBROWSE oBrw OF oWnd AUTOSORT
   oBrw:SetArrayData( aData, aStruct )
   oBrw:CreateFromCode()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TArrayData es la fuente de datos predeterminada utilizada por XBrowse cuando se llama a oBrw:SetArrayData(). Es creado internamente por XBrowse desde cualquier array de datos.
  • Cuando se carga desde DBF, los datos son una instantánea. Los cambios no se escriben de vuelta a menos que se llame a SaveData(), que actualiza los registros DBF originales.
  • Los constructores fromMYSQL() y fromQuery() requieren un objeto FWMariaConnection y mantienen un enlace activo para escribir los cambios de vuelta.
  • La ordenación crea un índice ordenado internamente; el orden original de aData se conserva en aNatural.

TSqlError

Fuente: source/classes/sqlerror.prg

Clase independiente

TSqlError encapsula la información de errores SQL de ODBC. Captura los detalles del error a nivel de los manejadores de entorno, conexión y sentencia, proporcionando acceso estructurado a los códigos nativos de estado SQL, los mensajes de error y los tipos de error. Se utiliza internamente en la clase TODBC y puede usarse directamente para el manejo personalizado de errores.

Miembros DATA Clave

DATATipoDescripción
hErrEnvManejadorManejador de entorno ODBC donde ocurrió el error
hErrDbcManejadorManejador de conexión ODBC donde ocurrió el error
hErrStmtManejadorManejador de sentencia ODBC donde ocurrió el error
cClassErrorCarácterCódigo de clase de estado SQL (p. ej., "42S02" para tabla no encontrada)
nTypeNuméricoCódigo numérico del tipo de error
cMsgErrorCarácterMensaje de error legible por humanos

Métodos

MétodoDescripción
New( hEnv, hDbc )Crea un nuevo objeto TSqlError; captura los errores de los manejadores de entorno y conexión
Init()Inicializa el objeto de error y recupera los registros de diagnóstico
GenerateError( hStmt )Captura los detalles del error desde un manejador de sentencia tras una operación SQL fallida
CreateError( cClass, nType, cMsg )Crea un error sintético con clase, tipo y mensaje explícitos
ClassError()Devuelve el código de clase de estado SQL
Type()Devuelve el código numérico del tipo de error
MsgError()Devuelve el mensaje de error legible por humanos

Ejemplo: Detectar y Mostrar un Error SQL

#include "FiveWin.ch"

function Main()

   local oOdbc, oErr

   oOdbc := TODBC():New( "MyDSN", "user", "pass" )

   if ! oOdbc:lSuccess
      // Crear y mostrar el error
      oErr := TSqlError():New( oOdbc:hEnv, oOdbc:hDbc )
      oErr:Init()

      ? "SQL Error:"
      ? "  Class:", oErr:ClassError()
      ? "  Type:",  oErr:Type()
      ? "  Message:", oErr:MsgError()

      MsgStop( oErr:MsgError(), "ODBC Error: " + oErr:ClassError() )
   endif

return nil

Notas

  • TSqlError utiliza las llamadas a la API ODBC SQLError() / SQLGetDiagRec() para recuperar la información de diagnóstico de los distintos manejadores involucrados en una operación fallida.
  • El cClassError contiene el código SQLSTATE estándar (cadena de 5 caracteres) definido por los estándares ODBC y SQL.
  • GenerateError( hStmt ) debe llamarse inmediatamente después de que falle la sentencia SQL, antes de cualquier otra llamada ODBC que pudiera sobrescribir la información de diagnóstico.
  • Utilice CreateError() para generar objetos TSqlError personalizados con mensajes de error definidos por la aplicación en escenarios de error ajenos a ODBC.

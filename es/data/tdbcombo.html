TDBCombo

Fuente: source/classes/dbcombo.prg

Hereda de: TComboBox

TDBCombo es un ComboBox con conocimiento de base de datos que muestra valores de un campo DBF y puede devolver un valor diferente a la variable enlazada. Admite una búsqueda incremental a medida que el usuario escribe, y puede autopoblar sus elementos desde la base de datos cuando no se proporciona un array explícito.

Ejemplo: Combo enlazado al campo Ciudad del cliente

#include "FiveWin.ch"

function Main()

   local oWnd, oCombo, cCity := Space( 20 )

   use Customer shared new
   index on field->city to tmpCity

   DEFINE WINDOW oWnd TITLE "TDBCombo Demo" SIZE 400, 150

   @ 30, 30 DBCOMBO oCombo VAR cCity ;
      ITEMS FIELD->city ;
      OF oWnd ;
      SIZE 150, 120

   ACTIVATE WINDOW oWnd CENTERED

   use

return nil

Notas

  • TDBCombo puede mostrar el valor de un campo mientras devuelve uno diferente. Por ejemplo, mostrar nombres de departamento (cFldList) pero devolver IDs de departamento (cFldItem).
  • Se admite la búsqueda incremental: al escribir caracteres se filtra la lista. Al pulsar Espacio se reinicia el búfer de búsqueda.
  • Cuando no se proporciona ni aItems ni aList, el constructor llama a Fill() para autopoblar desde los campos de la base de datos.
  • Los datos del combo pueden refrescarse manualmente con Refill() cuando cambian los registros de la base de datos subyacente.

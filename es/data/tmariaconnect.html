FWMariaConnection + FRecSet

Fuente: source/internal/fwmaria.prg

FWMariaConnection proporciona una conexión nativa y completa a servidores MariaDB y MySQL a través de la biblioteca cliente C libmariadb.dll. La clase complementaria FRecSet envuelve los conjuntos de resultados SQL con capacidades de navegación, paginación, ordenación y edición. Juntas forman la columna vertebral de la capa de acceso a datos MariaDB/MySQL de FiveWin.

FWMariaConnection

La clase de conexión gestiona las conexiones TCP/IP a servidores MariaDB/MySQL. Admite agrupación de conexiones, reconexión automática, sentencias preparadas, transacciones, copia de seguridad/restauración, y ejecución completa de DDL/DML.

FRecSet - Conjunto de Resultados MariaDB

FRecSet proporciona navegación orientada a registros sobre un conjunto de resultados MariaDB/MySQL. Admite paginación (controlada por nPageSize), acceso a nivel de campo, ordenación, edición e integración con XBrowse para su visualización en rejilla.

Ejemplo: Conectar y Navegar

#include "FiveWin.ch"

function Main()

   local oCn, oRs, oWnd, oBrw

   // Conectar a MariaDB
   oCn := FWMariaConnection():New( ;
      "localhost", ;     // servidor
      "mydb", ;          // base de datos
      "root", ;          // usuario
      "password", ;      // contraseña
      3306 )             // puerto

   if oCn:nError != 0
      MsgStop( "Connection failed: " + oCn:cError )
      return nil
   endif

   // Abrir un conjunto de resultados
   oRs := oCn:RowSet( "SELECT id, name, email, city FROM customers ORDER BY name" )

   // Navegar por los registros
   oRs:GoTop()
   while !oRs:Eof()
      ? oRs:FieldGet( "id" ), oRs:FieldGet( "name" ), oRs:FieldGet( "email" )
      oRs:Skip( 1 )
   end

   // Mostrar en XBrowse
   DEFINE WINDOW oWnd TITLE "Customers"

   @ 0, 0 XBROWSE oBrw OF oWnd
   oRs:SetXBrowse( oBrw )
   oBrw:CreateFromCode()

   ACTIVATE WINDOW oWnd MAXIMIZED

   oRs:Close()
   oCn:Close()

return nil

Notas

  • FWMariaConnection utiliza la biblioteca nativa MariaDB Connector/C (libmariadb.dll o libmariadb64.dll). La DLL debe estar disponible en la ruta de la aplicación o en el PATH del sistema.
  • FRecSet utiliza paginación automática con un tamaño de página predeterminado de 1000 filas. Establezca nPageSize para ajustar el uso de memoria en conjuntos de resultados grandes.
  • El método SetOrder() reemite la consulta con una cláusula ORDER BY, preservando las condiciones WHERE y la paginación.
  • Utilice oCn:ValToSQL() para escapar de forma segura los valores en cadenas SQL dinámicas, evitando la inyección SQL.
  • El soporte de transacciones requiere tablas InnoDB (u otras transaccionales). Utilice BeginTransaction(), CommitTransaction() y RollBack().

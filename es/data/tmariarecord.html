FWMariaRecord

Fuente: source/classes/mariarec.prg

Hereda de: TDataRow

FWMariaRecord proporciona acceso de tipo ORM a un único registro de tablas MariaDB/MySQL. Extiende TDataRow para detectar automáticamente la estructura de la tabla, las claves primarias y las columnas autoincrementales. La clase gestiona el ciclo CRUD completo: cargar un registro desde la base de datos, editar los valores de los campos mediante el acceso a propiedades de TDataRow, y guardar los cambios con upsert automático (INSERT o UPDATE según corresponda).

Métodos

MétodoDescripción
New( oCn, cTable, cWhere )Crea y carga un registro. Si cWhere es nil o está vacío, crea un registro en blanco para una nueva entrada.
Read( cWhere )Carga un registro específico identificado por la cláusula WHERE
Blank()Restablece el registro a una plantilla en blanco para insertar una nueva fila
Load( lBlank )Carga el registro desde el servidor (o una plantilla en blanco si lBlank es .T.)
Save()Guarda los cambios mediante upsert automático: INSERT si es nuevo, UPDATE si ya existe
MakePrimaryWhere()Construye una cláusula WHERE a partir de los valores actuales de los campos de clave primaria

Acceso a Campos

Dado que FWMariaRecord hereda de TDataRow, los valores de los campos son accesibles mediante los métodos FieldGet() y FieldPut() usando bien nombres de campo o bien posiciones numéricas: 

oRec:FieldGet( "name" )     // por nombre de campo
oRec:FieldGet( 2 )           // por posición numérica
oRec:FieldPut( "phone", "555-1234" )  // asignar por nombre de campo

Ejemplo: Cargar y Actualizar un Registro

#include "FiveWin.ch"

function Main()

   local oCn, oRec

   // Conectar a la base de datos
   oCn := FWMariaConnection():New( "localhost", "mydb", "root", "password" )
   if oCn:nError != 0
      MsgStop( "Connection failed" )
      return nil
   endif

   // --- LEER un registro existente ---
   oRec := FWMariaRecord():New( oCn, "customers", "id = 1" )
   if oRec:lValidData
      ? "Customer:", oRec:FieldGet( "name" )
      ? "Email:",    oRec:FieldGet( "email" )
      ? "Phone:",    oRec:FieldGet( "phone" )
   endif

   // --- ACTUALIZAR el registro ---
   oRec:FieldPut( "phone", "555-9999" )
   oRec:FieldPut( "city",  "Madrid" )
   if oRec:Save()
      MsgInfo( "Record updated successfully" )
   endif

   // --- CREAR un nuevo registro ---
   oRec := FWMariaRecord():New( oCn, "customers" )  // registro en blanco
   oRec:FieldPut( "name",  "Jane Smith" )
   oRec:FieldPut( "email", "jane@example.com" )
   oRec:FieldPut( "phone", "555-4321" )
   if oRec:Save()
      MsgInfo( "New customer ID: " + Str( oRec:FieldGet( "id" ) ) )
   endif

   // --- Cargar un registro diferente ---
   oRec:Read( "email = 'jane@example.com'" )
   if oRec:lValidData
      MsgInfo( "Found: " + oRec:FieldGet( "name" ) )
   endif

   oCn:Close()

return nil

Notas

  • FWMariaRecord detecta automáticamente la estructura de la tabla, las claves primarias y las columnas autoincrementales en la primera carga. Esto habilita un comportamiento de upsert inteligente sin configuración manual.
  • El método Save() utiliza internamente oCn:Upsert(), que genera una sentencia INSERT ... ON DUPLICATE KEY UPDATE. La detección de la clave primaria garantiza el comportamiento correcto.
  • Tras insertar un nuevo registro con una clave primaria autoincremental, el nuevo ID se recupera automáticamente y se almacena en los datos del registro.
  • Los campos de tipo carácter se rellenan hasta su longitud definida cuando el modo Unicode está activo (controlado por oCn:lUnicode).

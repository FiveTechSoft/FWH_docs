TTable / TAccTable

Fuente: source/classes/ttable.prg, source/classes/tacctbl.prg

TTable proporciona la gestión de metadatos de tablas DBF — almacena el nombre de la tabla, el alias, las definiciones de campos y la lista de índices, y puede crear o importar estructuras DBF. TAccTable gestiona las tablas de aceleradores de Windows, permitiendo asociar atajos de teclado (tecla virtual + estado de modificadores) con IDs de controles.

TTable — Metadatos de Tabla DBF

Miembros DATA Clave

DATATipoDescripción
cNameCarácterNombre de archivo de la tabla (sin extensión)
cAliasCarácterAlias usado al abrir la tabla
lSharedLógicoAbrir la tabla en modo compartido
aFieldsArrayArray de objetos TField que definen la estructura
aIndexesArrayArray de definiciones de índices

Métodos

MétodoDescripción
New( cName, cAlias, lShared, cComments )Crea un nuevo descriptor de metadatos de tabla
Import( cDbfFile )Importa la estructura de campos desde un archivo DBF existente
Create( cPath )Crea físicamente el archivo DBF en disco a partir de las definiciones de campos almacenadas

TAccTable — Tabla de Aceleradores

Miembros DATA Clave

DATATipoDescripción
nHandleNuméricoHandle de la tabla de aceleradores de Windows (devuelto por SetAccTable)
aItemsArrayArray de elementos, cada uno es { nVirtKey, nVKState, nId }

Métodos

MétodoDescripción
New()Crea una tabla de aceleradores vacía
Add( nVK, nState, nId )Añade una entrada de acelerador (tecla virtual + estado de modificadores + ID de comando)
Del( nVK, nState )Elimina una entrada de acelerador por tecla virtual y estado
Activate()Establece esta tabla de aceleradores como activa para el hilo llamante
DeActivate()Restaura la tabla de aceleradores anterior (pasa nil a SetAccTable)
End()Destruye la tabla de aceleradores y la desactiva si está activa actualmente

Ejemplo: Crear Tabla y Acelerador

#include "FiveWin.ch"

function Main()

   local oTable, oAccel

   // TTable: definir y crear un DBF
   oTable := TTable():New( "customers", "CUST", .F. )
   AAdd( oTable:aFields, TField():New( "customers", 1, .F., "NAME", "C", 40, 0 ) )
   AAdd( oTable:aFields, TField():New( "customers", 2, .F., "CITY", "C", 30, 0 ) )
   oTable:Create( "c:\data" )

   // TAccTable: definir atajos de teclado
   oAccel := TAccTable():New()
   oAccel:Add( VK_F2, 0, 101 )
   oAccel:Add( VK_F3, 0, 102 )
   oAccel:Add( VK_S, MOD_CONTROL, 103 )
   oAccel:Activate()

return nil

Notas

  • TTable no gestiona operaciones a nivel de registro; está destinada únicamente a la definición de estructura y la creación física del DBF.
  • El método Import() lee la cabecera de un DBF existente y rellena aFields con instancias de TField.
  • TAccTable encapsula la API SetAccTable() de Windows. El estado de modificadores (nVKState) puede ser una combinación de MOD_CONTROL, MOD_ALT, MOD_SHIFT, etc.
  • Llame a Activate() para registrar la tabla; el handle se almacena en nHandle para su posterior desactivación.
  • Solo puede haber una tabla de aceleradores activa a la vez por hilo.

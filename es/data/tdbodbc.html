TDbOdbc / TDbOdbcDirect

Fuente: source/classes/tdbodbc.prg / source/classes/tdbodbcd.prg

TDbOdbc proporciona acceso ODBC compatible con RDD a bases de datos SQL. Envuelve manejadores de sentencias ODBC y presenta una interfaz similar a DBF (GoTop, Skip, FieldGet, etc.), permitiendo navegar por tablas SQL usando los mismos patrones de navegación que los archivos DBF. TDbOdbcDirect es una alternativa más ligera que funciona directamente con conexiones ODBC compatibles con TDatabase sin la capa completa de emulación RDD.

Ejemplo: Exploración de Tabla ODBC

#include "FiveWin.ch"

function Main()

   local oOdbc, oTable, oWnd, oBrw

   oOdbc := TODBC():New( "MyDB" )  // ODBC data source name

   if oOdbc == nil
      MsgStop( "Cannot connect to ODBC source" )
      return nil
   endif

   oTable := TDbOdbc():New( "Employees", oOdbc )

   if oTable:lError
      MsgStop( "Cannot open table" )
      return nil
   endif

   DEFINE WINDOW oWnd TITLE "Employees from ODBC"

   @ 0, 0 XBROWSE oBrw OF oWnd AUTOSORT
   oBrw:SetRdd()
   oBrw:SetADO( oTable )     // link TDbOdbc to XBrowse
   oBrw:CreateFromCode()

   ACTIVATE WINDOW oWnd MAXIMIZED

   oTable:End()

return nil

Notas

  • TDbOdbc emula la interfaz RDD de DBF sobre ODBC, admitiendo navegación, edición, filtrado y ordenación usando constructos SQL de forma transparente.
  • Las claves primarias se detectan automáticamente mediante SQLPrimaryKeys() y se utilizan para sentencias UPDATE/DELETE.
  • El método GenDbf() permite exportar cualquier conjunto de resultados ODBC a un archivo DBF para uso sin conexión.
  • TDbOdbcDirect es más ligero y adecuado para acceso SQL directo de solo lectura o simple sin la emulación RDD completa.
  • Ambas clases trabajan con el objeto de conexión TODBC para la gestión de fuentes de datos ODBC.

TDict - Diccionario de Datos

Fuente: source/classes/tdict.prg

Clase independiente

TDict implementa un sistema de diccionario de datos que gestiona una colección de tablas de base de datos (DBFs), menús e informes. Almacena metadatos en más de 15 tablas del sistema (oTables) que abarcan definiciones de tablas, definiciones de campos, índices, relaciones, menús, informes, usuarios y seguridad. El diccionario puede construir automáticamente las tablas del sistema que falten (lAutoBuild) y proporciona métodos para crear tablas, abrir bases de datos, cargar menús, ejecutar informes e importar archivos.

Miembros DATA Principales

DATATipoDescripción
cPathCarácterRuta base donde se almacenan los archivos del diccionario
lAutoBuildLógico.T. para crear automáticamente las tablas del sistema que falten
oTablesArrayArray de más de 15 objetos TDatabase para las tablas del sistema

Métodos

MétodoDescripción
New( cPath )Crea un nuevo diccionario de datos en la ruta indicada
Activate()Abre todas las tablas del sistema y activa el diccionario
CreateTable( cTbl )Crea una nueva tabla de usuario definida en el diccionario
OpenDataBase( cDbName )Abre una base de datos con nombre y todas sus tablas
OpenTable( cTbl )Abre una tabla específica por su nombre
LoadMenu( cMenu )Carga una definición de menú del diccionario; devuelve un TMenu
Report( cReport )Ejecuta un informe definido en el diccionario
Import( cMask )Importa al diccionario los archivos que coincidan con una máscara de archivos
LoadWebBrowse( cTbl )Carga la configuración de navegación web para una tabla
LoadWebRecord( cTbl )Carga la configuración del formulario de registro web para una tabla
WebRecSave( cTbl )Guarda la configuración de registro web para una tabla

Ejemplo: Crear y Usar un Diccionario

#include "FiveWin.ch"

function Main()

   local oDict

   // Crea un diccionario de datos en el directorio de datos
   oDict := TDict():New( ".\data\" )
   oDict:lAutoBuild := .T.
   oDict:Activate()

   // Crea una nueva tabla de usuario
   oDict:CreateTable( "INVOICES" )

   // Abre una base de datos
   oDict:OpenDataBase( "SALES" )

   // Carga un menú
   DEFINE WINDOW oWnd TITLE "Dictionary Demo" SIZE 800, 600
   oDict:LoadMenu( "MAIN" ):Activate( oWnd )

   // Ejecuta un informe
   oDict:Report( "CUSTOMER_LIST" )

   ACTIVATE WINDOW oWnd

return nil

Notas

  • El diccionario mantiene tablas del sistema para las definiciones de tablas (_TABLES.DBF), definiciones de campos (_FIELDS.DBF), índices (_INDEXES.DBF), relaciones, menús, informes, usuarios, grupos y permisos.
  • Cuando lAutoBuild es .T., cualquier tabla del sistema que falte se crea automáticamente al llamar a Activate().
  • Use CreateTable() para materializar una tabla definida por el usuario a partir de los metadatos del diccionario. La estructura de la tabla se lee de la tabla del sistema _FIELDS.
  • LoadMenu() lee las definiciones de menú del diccionario y devuelve un objeto TMenu completamente construido y listo para su activación.

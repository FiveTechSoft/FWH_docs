TStruct / TField / TIndex

Fuente: source/classes/tstruct.prg, source/classes/tfield.prg, source/classes/tindex.prg

Estas tres clases utilitarias proporcionan representaciones orientadas a objetos para estructuras de memoria de estilo C (TStruct), definiciones de campos DBF (TField) y definiciones de índices DBF (TIndex). Se utilizan al trabajar con estructuras de datos de bajo nivel, definir esquemas DBF mediante programación o crear archivos de índice desde código Harbour.

TStruct - Constructor de Estructuras C

TStruct modela una estructura de lenguaje C en la memoria de Harbour. Mantiene un buffer binario y una lista de definiciones de miembros, permitiendo agregar y acceder a miembros por nombre o posición.

Miembros DATA

DATATipoDescripción
cBufferCarácterBuffer binario de memoria en bruto
aMembersArrayArray de { cName, nType, nLen, nOffset }

Constantes de Tipo

ConstanteDescripción
BYTE / CHAREntero sin signo de 1 byte
WORD / INT / BOOLEntero con signo de 2 bytes
LONG / DWORD / PTR / LPSTREntero con signo de 4 bytes o puntero
LONGLONGEntero con signo de 8 bytes

Métodos

MétodoDescripción
New()Crear estructura vacía
AddMember( cName, nType, nLen )Agregar un miembro con tipo y longitud opcional
SetMember( nMember, uData )Establecer valor de miembro por índice
GetMember( nMember )Obtener valor de miembro por índice
SizeOf()Devuelve la longitud total del buffer en bytes

Ejemplo: Definir y Usar una Estructura C

#include "FiveWin.ch"
#include "Struct.ch"

function Main()

   local oStru := TStruct():New()

   // Add members: name, type, length
   oStru:AddMember( "nId",   LONG,    4 )
   oStru:AddMember( "cName", CHAR,   20 )
   oStru:AddMember( "nAge",  BYTE      )   // defaults to 1 byte

   ? "Size:", oStru:SizeOf()               // 25

   // Set values
   oStru:SetMember( 1, 12345 )
   oStru:SetMember( 2, "John Smith" )

   // Read them back
   ? oStru:GetMember( 1 )                  // 12345
   ? oStru:GetMember( 2 )                  // "John Smith"

return nil

TField - Definición de Campo DBF

TField es un contenedor de datos simple que representa un campo DBF individual. Almacena todas las propiedades necesarias para definir un campo en una estructura de archivo DBF.

Miembros DATA

DATATipoDescripción
cDbfNameCarácterNombre del archivo DBF
nOrderNuméricoPosición del campo (base 1)
lIndexedLógicoIndica si el campo está indexado
cNameCarácterNombre del campo
cTypeCarácterTipo de campo (C, N, D, L, M)
nWidthNuméricoAncho del campo
nDecimalNuméricoDecimales para campos numéricos
cCommentsCarácterDescripción opcional del campo

Método

MétodoDescripción
New( cDbfName, nOrder, lIndexed, cName, cType, nWidth, nDecimal, cComments )Crear una definición de campo

Ejemplo: Definir un Campo DBF

#include "FiveWin.ch"

function Main()

   local oFld

   oFld := TField():New( "CUSTOMER.DBF", 1, .F., "CODE", "C", 5, 0, "Customer code" )

   ? oFld:cName     // "CODE"
   ? oFld:cType     // "C"
   ? oFld:nWidth    // 5

return nil

TIndex - Definición de Índice DBF

TIndex representa una definición de índice para un archivo DBF. Puede crear el archivo de índice real en disco (formato CDX o NTX) a partir de las propiedades de definición.

Miembros DATA

DATATipoDescripción
cDbfNameCarácterNombre del archivo DBF a indexar
cNameCarácterNombre del archivo de índice (sin extensión)
cTagCarácterNombre de etiqueta para índices CDX
cExpressionCarácterExpresión de clave de índice
lUniqueLógicoIndicador de índice único
lDescendingLógicoIndicador de orden descendente
cCommentsCarácterComentarios opcionales
cTypeCarácterTipo de índice ("CDX" predeterminado, o "NTX")

Métodos

MétodoDescripción
New( cDbfName, cName, cTag, cExpression, lUnique, lDescending, cComments )Crear una definición de índice
Create( cPath )Crear el archivo de índice en disco en la ruta dada

Ejemplo: Crear un Índice

#include "FiveWin.ch"

function Main()

   local oIdx

   // Define an index on CUSTOMER.DBF by the CODE field
   oIdx := TIndex():New( "CUSTOMER.DBF", "CODE_IDX", "CODE", "CODE", .F., .F., "Index by code" )

   // Create the index file
   oIdx:Create( "C:\data\" )

return nil

Notas

  • TStruct usa NumToBin() / BinToNum() de Harbour internamente para la serialización del buffer. Admite acceso a miembros tanto por índice numérico como por nombre (mediante manejador de errores).
  • TField es principalmente un contenedor de datos y no modifica el archivo DBF en sí mismo. Es útil para la construcción programática de esquemas y la gestión de metadatos.
  • TIndex:Create() abre el DBF, ejecuta el comando INDEX y cierra el archivo. Soporta formatos CDX (predeterminado) y NTX según el miembro cType.

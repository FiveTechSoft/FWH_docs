TDataRow

Fuente: source/classes/datarow.prg

Clase independiente

TDataRow es un editor de registros de datos que ofrece una interfaz cómoda para visualizar y editar registros individuales de una fuente de datos. Funciona con áreas de trabajo DBF, recordsets ADO, arrays y hashes, lo que lo convierte en una herramienta versátil para operaciones a nivel de registro. TDataRow mantiene una copia original de los datos y puede detectar modificaciones.

Miembros DATA Clave

DATATipoDescripción
aDataArrayArray con los valores actuales de los campos
aOrgArrayArray con los valores originales de los campos (para detección de cambios)
aPromptsArrayArray con las etiquetas/textos de los campos
uSourceVariantDatos de origen: alias (N), recordset ADO, array o hash
cSrcTypeCharacterCadena con el tipo de origen: "DBF", "ADO", "ARR" o "HSH"
bSaveBlockBloque de código evaluado al guardar correctamente
bValidBlockBloque de código para validar el registro antes de guardar
bEditBlockBloque de código evaluado cuando comienza la edición

Métodos

MétodoDescripción
New( uSource, cFieldList, lBlank, aInitVals )Crea una fila de datos a partir de un origen y una lista de campos opcional
Load( lBlank )Carga los valores actuales del origen en aData
Save( lCheck, lSilent )Escribe los cambios de vuelta en el origen; validación opcional
Edit( lReadOnly, lNavigate, cTitle, cMsg )Abre un diálogo para la edición interactiva del registro
Undo( fld )Revierte un campo a su valor original
Copy()Crea una copia de los datos del registro actual
Paste( hRec )Pega un registro copiado previamente en el búfer
Modified( fld )Comprueba si un campo (o cualquier campo) ha sido modificado
FieldGet( fld )Obtiene el valor de un campo por nombre o posición
FieldPut( fld, uVal )Establece el valor de un campo por nombre o posición

Ejemplo: Editar el Registro DBF Actual

#include "FiveWin.ch"

function Main()

   local oDb, oRow

   DATABASE oDb FILE "customers.dbf" DRIVER "DBFCDX" SHARED

   oDb:GoTop()

   // Crea una fila de datos para el registro actual
   oRow := TDataRow():New( oDb:nArea )

   // Abre el diálogo de edición
   if oRow:Edit( , , "Edit Customer" )
      // El usuario pulsó OK -- los cambios se guardan automáticamente
      MsgInfo( "Record saved" )
   else
      MsgInfo( "Edit cancelled" )
   endif

   oDb:Close()

return nil

Notas

  • TDataRow se adapta automáticamente al tipo de origen. Para orígenes DBF, pase el número de área de trabajo o el alias; para ADO, pase el objeto recordset; para arrays o hashes, pase la referencia directamente.
  • El método Edit() crea un diálogo predeterminado con controles TGet para cada campo. Cuando lReadOnly es .T., el diálogo muestra los datos sin permitir su edición.
  • Use bSave para ejecutar lógica personalizada tras un guardado correcto, como registrar la operación o refrescar controles relacionados.
  • El método Modified() sin argumentos comprueba si cualquier campo cambió; con un argumento de campo comprueba un campo específico.
  • Usar lNavigate=.T. en Edit() añade botones de navegación (Siguiente/Anterior) para moverse entre registros.

TDatabase

Fuente: source/classes/database.prg

TDatabase es el envoltorio orientado a objetos de FiveWin sobre el sistema DBF/RDD (Replaceable Database Driver) de Harbour. Encapsula todas las operaciones comunes de base de datos -- apertura, navegación, edición, filtrado, indexación y más -- en una interfaz de clase limpia. TDatabase puede trabajar con cualquier RDD soportado por Harbour, incluyendo DBFCDX, DBFNTX, DBFNSX y ADS (Advantage Database Server).

Constructores

New()

METHOD New( ncArea, cFile, cDriver, lShared, lReadOnly, cPassword )

Crea un objeto TDatabase. Si ncArea es un número o alias de un área de trabajo ya abierta, TDatabase envuelve el área existente. Si ncArea es una cadena con la ruta de un archivo, se prepara para abrir ese archivo. Si solo se pasa un parámetro, detecta automáticamente si se trata de un número de área, un alias o un nombre de archivo.

Open()

METHOD Open( cAlias, cFile, cDriver, lShared, lReadOnly, cPassword )

Abre un archivo DBF con un alias explícito. Este es el constructor preferido para abrir archivos nuevos.

Create()

METHOD Create( cFile, aStruct, cDriver, cIndexFields, cPassword )

Crea un nuevo archivo DBF con la estructura especificada y, opcionalmente, crea un índice.

Búsqueda y Filtrado

METHOD Seek( uExpr, lSoft, lWildSeek, lCurRec )
METHOD SetFilter( cFilter, aParams )
METHOD ClearFilter()
METHOD SetScope( uTop, uBot )
METHOD SetOrder( cnTag, cFile )

Seek() busca en el índice activo la expresión de clave especificada. lSoft habilita la búsqueda blanda (coincidencia más cercana). SetFilter() acepta una cadena de expresión de filtro con sustitución opcional de parámetros mediante aParams. SetScope() establece los valores de ámbito superior e inferior para restringir la navegación dentro de un rango del índice.

Navegación y XBrowse

METHOD Browse( cTitle, acFields )
METHOD SetXBrowse( oBrw, aCols, lAutoSort, lAutocols )
METHOD xBrowse( oWnd, aCols, lAutoSort, bSetUp )

xBrowse() es la forma más rápida de mostrar el contenido de una base de datos en una rejilla XBrowse. Configura automáticamente el browse con encabezados de columna, tipos de datos y ordenación.

Ejemplo: Operaciones Básicas con DBF

#include "FiveWin.ch"

function Main()

   local oDb, oWnd

   // Abrir un archivo DBF con el driver DBFCDX
   DATABASE oDb FILE "customers.dbf" DRIVER "DBFCDX" SHARED

   // Equivalente a:
   // oDb := TDatabase():Open( "CUST", "customers.dbf", "DBFCDX", .T. )

   // Navegar
   oDb:GoTop()
   ? oDb:FieldGet( "FIRST" )    // "John"
   ? oDb:FieldGet( "LAST" )     // "Smith"
   ? oDb:hRec[ "FIRST" ]        // "John" (acceso por hash)

   // Establecer un orden de índice y buscar
   oDb:SetOrder( "LAST" )
   if oDb:Seek( "Jones" )
      ? "Found:", oDb:FieldGet( "FIRST" ), oDb:FieldGet( "LAST" )
   endif

   // Editar un registro
   if oDb:RecLock()
      oDb:FieldPut( "PHONE", "555-1234" )
      oDb:UnLock()
   endif

   // Añadir un nuevo registro
   oDb:Append()
   oDb:FieldPut( "FIRST", "Jane" )
   oDb:FieldPut( "LAST",  "Doe" )
   oDb:FieldPut( "PHONE", "555-5678" )
   oDb:Save()

   // Aplicar un filtro
   oDb:SetFilter( "STATE = 'CA'" )
   oDb:GoTop()
   do while ! oDb:Eof()
      ? oDb:FieldGet( "FIRST" ), oDb:FieldGet( "LAST" )
      oDb:Skip()
   enddo
   oDb:ClearFilter()

   oDb:Close()

return nil

Ejemplo: Navegación con XBrowse

#include "FiveWin.ch"

function Main()

   local oDb, oWnd, oBrw

   DATABASE oDb FILE "customers.dbf" DRIVER "DBFCDX" SHARED

   DEFINE WINDOW oWnd TITLE "Customer Browser"

   oDb:xBrowse( oWnd,, .T., { |oBrw|
      oBrw:cHeaders := { "First Name", "Last Name", "Phone", "State" }
      oBrw:lRecordSelector := .F.
   } )

   ACTIVATE WINDOW oWnd MAXIMIZED

   oDb:Close()

return nil

Ejemplo: Edición con Buffer

#include "FiveWin.ch"

function Main()

   local oDb

   DATABASE oDb FILE "customers.dbf" DRIVER "DBFCDX" SHARED

   // Habilitar el buffer para el bloqueo optimista
   oDb:SetBuffer( .T. )

   oDb:GoTop()

   // Los cambios van al buffer, no al disco
   oDb:FieldPut( "PHONE", "555-0000" )

   if MsgYesNo( "Save changes?" )
      oDb:Save()        // escribe el buffer en disco
   else
      oDb:RollBack()    // descarta los cambios
   endif

   oDb:Close()

return nil

Ejemplo: Creación de Índices

#include "FiveWin.ch"

function Main()

   local oDb

   DATABASE oDb FILE "customers.dbf" DRIVER "DBFCDX" SHARED

   // Crear un índice compuesto con varios tags
   oDb:CreateIndex( "customers.cdx", "NAME",  "UPPER(LAST)+UPPER(FIRST)" )
   oDb:CreateIndex( "customers.cdx", "STATE", "STATE" )
   oDb:CreateIndex( "customers.cdx", "PHONE", "PHONE", .T. )  // único

   // Usar el orden NAME
   oDb:SetOrder( "NAME" )
   oDb:GoTop()

   // Navegación con ámbito: solo registros donde STATE = "CA"
   oDb:SetScope( "CA", "CA" )
   oDb:GoTop()
   do while ! oDb:Eof()
      ? oDb:FieldGet( "LAST" )
      oDb:Skip()
   enddo

   oDb:Close()

return nil

Localización y Soporte Multi-idioma

Fuente: source/function/strings.prg

El sistema de localización de FiveWin proporciona soporte multi-idioma centralizado a través de FWString() y FWSetLanguage(). Cientos de traducciones predefinidas se almacenan en un array estático dentro de strings.prg, cubriendo inglés, español, francés, portugués, alemán e italiano. Todos los componentes del framework -- ventanas, menús, diálogos, informes, vistas previas de impresión y manejadores de errores -- obtienen el texto de la interfaz a través de este sistema unificado. Las aplicaciones pueden cambiar de idioma en tiempo de ejecución o añadir nuevos idiomas con tablas de traducción personalizadas.

Funciones Principales

FWString()

FWString( cEnglishText ) --> cLocalized

La interfaz principal para obtener texto localizado. Busca en el array aStrings la clave en inglés y devuelve la traducción para el idioma seleccionado actualmente. Si no se encuentra ninguna traducción, recurre al texto original.

? FWString( "Save" )     // "Guardar" (si el idioma = Español)
? FWString( "Cancel" )    // "Annuler" (si el idioma = Francés)

FWSetLanguage()

FWSetLanguage( nLang [, cLang ] ) --> nPrevLang

Establece el idioma activo mediante su ID numérico (1-6). Opcionalmente se puede pasar un nombre de cadena ("ES", "FR", etc.) para mayor legibilidad. Devuelve el ID del idioma anterior. Todas las llamadas posteriores a FWString() usarán el nuevo idioma.

FWSetLanguage( 2 )    // Cambia a Español
FWSetLanguage( 4 )    // Cambia a Portugués

FWAddLanguage()

FWAddLanguage( cLang, hStrings ) --> lSuccess

Añade un nuevo idioma con un hash de traducción personalizado. cLang es un código de dos letras y hStrings es un hash que asocia cada cadena en inglés con su traducción. Esto permite módulos de traducción incluibles sin modificar el propio strings.prg.

FWMissingStrings()

FWMissingStrings( lWriteToFile ) --> nCount

Informa del número de cadenas usadas por la aplicación que no tienen traducción para el idioma actual. Cuando lWriteToFile es .T., escribe las cadenas faltantes en un archivo de texto como referencia para el traductor.

FWAddString()

FWAddString( cEnglish, cTranslated ) --> nil

Añade un único par de cadenas a la tabla de traducción del idioma actual en tiempo de ejecución. Útil para cadenas específicas de la aplicación que no están en el conjunto predefinido.

FWSetString()

FWSetString( nLang, cEnglish, cTranslated ) --> nil

Establece o sobrescribe la traducción de una clave en inglés para un idioma específico. Permite parchear entradas individuales sin recargar la tabla completa.

FWLanguageID()

FWLanguageID() --> nLang

Devuelve el ID numérico del idioma activo actualmente (1-6). Útil para lógica condicional que depende del idioma activo (por ejemplo, manejar la puntuación inicial en español).

if FWLanguageID() == 2  // Español
   cPrompt := FWString( "Open" ) + " " + FWString( "file" )
endif

FWLoadStrings() / FWSaveStrings()

FWLoadStrings( cFile ) --> lSuccess
FWSaveStrings( cFile ) --> lSuccess

Carga o guarda la tabla de traducción completa desde/hacia un archivo de texto. Útil para distribuir paquetes de idioma separados o permitir la personalización de traducciones por parte del usuario final.

Codificación de Archivos

El archivo fuente strings.prg debe estar codificado como CP1252 (Europa Occidental), no UTF-8. Los caracteres acentuados se almacenan como bytes individuales (por ejemplo, n=0xF1, a=0xE4, u=0xFC). El compilador Harbour preserva los bytes de los literales de cadena tal cual, por lo que la codificación debe coincidir con la página de código esperada en tiempo de compilación.

Soporte Unicode y Páginas de Código

FiveWin admite aplicaciones Unicode mediante FW_SetUnicode(.T.), que debe llamarse antes de crear cualquier ventana. Cuando el modo Unicode está activo:

  • Todas las cadenas se codifican internamente en UTF-8
  • Los controles de Windows reciben UTF-16 mediante conversión automática en fwunicode.c
  • Se usa hb_cdpSelect("UTF8") como página de código de Harbour
  • Los literales de cadena en los archivos fuente .prg deben guardarse como UTF-8

Habilitar Unicode

#include "FiveWin.ch"

function Main()
   FW_SetUnicode( .T. )  // Debe llamarse antes de cualquier interfaz
   // ... resto de la aplicación
return nil

Detalles de FW_SetUnicode()

Cuando FW_SetUnicode(.T.) está activo:

  • fwunicode.c: hbcdp_to_wincdp() convierte las páginas de código OEM (<1250) a CP_ACP cuando bAnsiOnly es TRUE, evitando la doble codificación de texto CP1252 con CP437
  • Plantillas de diálogo: dlg2chr.c y ctrl2chr.c usan CP_ACP (no CP_OEMCP) para la conversión MultiByteToWideChar
  • Controles comunes: las aplicaciones con manifiesto de Windows XP crean controles comunes Unicode; fwunicode.c gestiona el puente de codificación
  • GET/MultiGet: el flag lWideChar usa KeyWChar() para la entrada de caracteres Unicode

Tablas de Idioma Personalizadas (Más allá de las 6 incluidas)

La función FWAddLanguage() permite añadir idiomas más allá de los 6 incluidos. El sistema admite hasta Len(aStrings[1]) idiomas (actualmente hay 10 espacios disponibles). Use FWSetLanguage(n) con un ID > 6 después de añadir el idioma:

// Añadir tabla de traducción para Chino (ID 7)
FWAddLanguage( "ZH", { "Save" => "保存", "Cancel" => "取消", ;
   "File" => "文件", "Open" => "打开" } )
FWSetLanguage( 7 )

Ejemplo: Aplicación Multi-idioma

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu

   DEFINE WINDOW oWnd TITLE "Localization Demo" ;
      MENU BuildMenu( oWnd ) ;
      SIZE 600, 400

   ACTIVATE WINDOW oWnd

return nil

function BuildMenu( oWnd )

   local oMenu

   MENU oMenu
      MENUITEM FWString( "&File" )
      MENU
         MENUITEM FWString( "&Open" ) ACTION MsgInfo( FWString( "Open file" ) )
         MENUITEM FWString( "E&xit" )  ACTION oWnd:End()
      ENDMENU
      MENUITEM "Language"
      MENU
         MENUITEM "English"   ACTION ( FWSetLanguage( 1 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Espanol"   ACTION ( FWSetLanguage( 2 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Francais"  ACTION ( FWSetLanguage( 3 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Deutsch"   ACTION ( FWSetLanguage( 5 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Italiano"  ACTION ( FWSetLanguage( 6 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
      ENDMENU
   ENDMENU

return oMenu

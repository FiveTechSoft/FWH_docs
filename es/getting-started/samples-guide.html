Primeros Pasos: Tus 5 Primeros Ejemplos

Si eres completamente nuevo en FiveWin, trabaja estos cinco ejemplos en orden. Cada uno se apoya en lo aprendido en el anterior:

#ArchivoLo que Aprenderás
1 start/tutor01.prg Hola Mundo — MsgInfo(), el programa FWH más sencillo
2 start/tutor02.prg Ventanas — DEFINE WINDOW, ACTIVATE WINDOW
3 start/tutor03.prg Diálogos — DEFINE DIALOG, controles SAY/GET
4 start/tutor04.prg Botones y Acciones — creación de botones, cláusulas ACTION, manejo de eventos
5 start/tutor05.prg Menús — DEFINE MENU, MENUITEM, teclas aceleradoras

Después de estos cinco, continúa con tutor06.prg (bases de datos), tutor07.prg (diálogos avanzados) y tutor08.prg (integrando todo).

Cómo Compilar los Ejemplos

El directorio samples/ contiene varios scripts de compilación. El enfoque recomendado para proyectos nuevos: 

cd c:\fwteam\samples

REM Build a sample with Borland C++ (32-bit, most common):
buildh.bat start\tutor01

REM Build with MSVC 64-bit:
buildh64.bat start\tutor01

REM The universal build script (auto-detects compiler):
build_new.bat start\tutor01

Cada script de compilación compila el archivo .prg con Harbour, luego compila y enlaza el código C resultante con el compilador elegido. Consulta la página de Sistema de Construcción para todos los detalles.

Ejemplos Intermedios

database/ (19 ejemplos)

Operaciones con bases de datos incluyendo navegación de DBF, búsqueda indexada, consultas SQL vía ADO/ODBC, e integración con el grid TXBrowse. Empieza con los ejemplos básicos de DBF antes de pasar a SQL.

Archivos ClaveDescripción
dbfbrowse.prgNavegación básica de DBF con TXBrowse
sql*.prgConexiones y consultas a bases de datos SQL
xbrowse*.prgXBrowse avanzado con fuentes de datos

data/ (16 ejemplos)

Las clases TDatabase y TDataRow proporcionan una abstracción de nivel superior sobre las operaciones directas con DBF. Enlace de datos, campos calculados y navegación de registros.

menus/ (14 ejemplos)

Todos los tipos de menús: menús desplegables, menús emergentes/contextuales, barras ribbon, menús de bandeja del sistema. Cubre la creación dinámica de menús, menús con bitmaps y menús con dibujo personalizado.

report/ (41 ejemplos)

Impresión y generación de informes con TPrinter y TReport. Incluye exportación a PDF, diseños de múltiples columnas, códigos de barras, gráficos en informes y vista previa de impresión.

graphics/ (28 ejemplos)

Dibujo con GDI+, creación de gráficos, manipulación de bitmaps, carga/guardado de imágenes, mezcla alfa y rellenos de gradiente. Demuestra el uso de las clases Graphics, Pen, Brush y GDIBmp.

mail/ (5 ejemplos)

Envío de correo electrónico vía SMTP, recepción vía POP3 e integración con Outlook mediante automatización OLE.

ole/ (8 ejemplos)

Ejemplos de Automatización OLE para Microsoft Word, Excel y otras aplicaciones COM. Crear documentos, rellenar hojas de cálculo y controlar aplicaciones de Office programáticamente.

trees/ (5 ejemplos)

Ejemplos del control TTreeView: construcción de estructuras de árbol, arrastrar y soltar entre árboles, carga de árboles basada en XML y renderizado personalizado de nodos.

comm/ (10 ejemplos)

Comunicaciones por puerto serie, control de módem, integración con escáner de códigos de barras y comunicación con dispositivos de hardware.

unicode/ (2 ejemplos)

Manejo de cadenas Unicode, visualización de texto multi-script y conversión UTF-8/UTF-16. Usa FW_SetUnicode( .T. ) para habilitar el modo Unicode globalmente.

FiveUI/ (17 ejemplos)

El Diseñador Visual de Formularios de FiveWin. Diseña diálogos visualmente y genera código fuente .prg automáticamente. Consulta también el directorio visual/ en la raíz del proyecto para el IDE Visual completo.

misc/ (467 ejemplos)

La colección más grande, cubriendo prácticamente todas las características de FiveWin. Cuando necesites ver cómo funciona una clase o función específica, busca aquí primero. Temas destacados:

  • Arrastrar y soltar, portapapeles, bandeja del sistema
  • Barras divisoras, paneles acoplables
  • Visores de imágenes, reproducción de vídeo
  • Criptografía, hashing, codificación
  • Operaciones con archivos, compresión ZIP/GZIP
  • Pintado personalizado de controles, owner-draw

test/ (317 ejemplos)

El conjunto de pruebas de FiveWin y ejemplos adicionales. Muchos son pruebas de regresión que también sirven como documentación para casos especiales y comportamientos específicos de funcionalidades.

  • vmenu_test.prg — TVMenu + TVItem con iconos 32x32 (TC5ImgList). Compila en FWH64: build_new.bat vmenu_test hb64. Ver Novedades 26.08.
  • testblur.prg — box-blur sobre imagen (slider 0–100) con Blur() de la librería FWH (ribbon.c). Carga BMP/JPG/PNG con FW_ReadImage; use DEFINE DIALOG … PIXEL TRUEPIXEL para que el slider horizontal se vea. Compilar: build_new.bat testblur hb32. Ver Novedades 26.08.

test/fwunit/ — suite de regresión automatizada

samples/test/fwunit/ es un harness de pruebas unitarias autocontenido para la biblioteca FWH (142 aserciones). Cubre Unicode, cadenas CP1252, traducción de páginas de códigos, formato, métricas del sistema, recursos PalBmp, publicación de mensajes WinAPI y controles UI. Los resultados se escriben en fwunit_results.log vía LogFile().

Compilar y ejecutar:

cd samples\test\fwunit
run_all.bat

O solo la suite: C:\fwteam\samples\build_new.bat run_fwunit hm32 y luego run_fwunit.exe. Ejecutar una sola instancia a la vez.

Ejemplos de aplicaciones completas y más grandes que combinan múltiples características de FiveWin en programas del mundo real. Estúdialos para entender cómo estructurar una aplicación FWH completa con menús, barras de herramientas, múltiples diálogos, acceso a datos e informes.

Consejos para Aprender con los Ejemplos

  • Lee el código fuente. Cada archivo .prg es texto plano. Ábrelo en cualquier editor. El código es la documentación.
  • Modifica y experimenta. Cambia un color, agrega un botón, intercambia una base de datos. Recompila y observa qué sucede. FiveWin compila rápido.
  • Usa MsgInfo() para depurar. Inserta MsgInfo( cVariable ) en cualquier parte para inspeccionar valores en tiempo de ejecución. Es el mejor amigo del desarrollador FiveWin.
  • Busca en misc/ cuando te atasques. Con 467 ejemplos, casi seguro existe un ejemplo de lo que necesitas. Usa la función "buscar en archivos" de tu editor.
  • Mira los archivos include .ch. Comandos como DEFINE WINDOW son traducidos por el preprocesador. Revisa FiveWin.ch para ver a qué se expanden.
  • Cruza referencias con la documentación. Cuando un ejemplo usa una clase como TXBrowse, abre la documentación de TXBrowse junto al código.
  • Únete a la comunidad. Los foros de FiveTech son activos y acogedores. Publica tus preguntas con tu código de ejemplo.

Anatomía de un Ejemplo FiveWin

Todos los ejemplos siguen la misma estructura básica: 

#include "FiveWin.ch"     // Required: loads all FWH commands

function Main()           // Entry point

   local oWnd             // Declare local variables

   DEFINE WINDOW oWnd ... // Create UI objects using commands
   ACTIVATE WINDOW oWnd   // Start the event loop

return nil

La línea #include "FiveWin.ch" es esencial — carga los comandos del preprocesador que traducen la sintaxis de alto nivel como DEFINE WINDOW en llamadas a métodos de clase.

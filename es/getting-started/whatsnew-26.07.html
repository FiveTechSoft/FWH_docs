Remote View + WebView2 (testrvweb)

Nuevo ejemplo samples/RemoteView/testrvweb.prg que combina Remote View con TWebView2:

  • Barra de botones FWH nativos (HTML demo, Navigate, Eval, contador)
  • Edge WebView2 embebido con página demo y puente SendToFWH → bOnBind
  • RemoteViewStart en el puerto 8080 para ver/controlar la misma ventana desde cualquier navegador de la LAN

Disposición en la misma pantalla: ventana desktop abajo (FROM nTop, nLeft … PIXEL) para que la imagen del navegador quede arriba; RemoteViewSetOffset modesto. Requiere Runtime WebView2. Detalle: Remote View + WebView2.

XBrowse multilínea + LimitText (sample xbrml250)

Nuevo sample samples/ui/xbrowse/xbrml250.prg: edición de una columna de texto larga en varias líneas dentro de la celda, con tope de longitud (ejemplo: 250 caracteres).

  • nDataLines >= 2 y cEditPicture vacío para que XBrowse cree un TMultiGet (wrap al escribir). Si pones cEditPicture := Replicate( "X", 250 ) se fuerza un TGet de una sola línea y se pierde el wrap.
  • bOnPreEdit: siempre RTrim() del texto del editor y luego oEditGet:LimitText( nMax ). Valores rellenados a longitud fija (PadR / Space(250)) llenan el límite y impiden escribir; TMultiGet no hace SelectAll como TGet.
  • Teclas: Intro termina la edición; Ctrl+Intro o Shift+Intro insertan un solo salto de línea real. No uses Replace( CRLF ) a mano: se duplica el salto (tu inserción más el EDIT multilínea / ES_WANTRETURN).
  • bOnPostEdit: guardar Left( xVal, nMax ) (opcionalmente PadR si el backend exige ancho fijo).

Detalle: TXBrowse edición multilínea.

TControl F1 / ayuda CHM — nHelpId vacío sube al padre

F1 / WM_HELP llega al control con el foco. Si el control tenía nHelpId vacío, FWH no abría ayuda y no se usaba oWnd:nHelpId / oDlg:nHelpId. TControl:__HelpTopic() ahora llama a ::oWnd:HelpTopic() para aplicar el contexto de la ventana/diálogo.

Comportamiento de la ayuda contextual CHM:

  • Control con nHelpId numérico — HelpPopup() (popup pequeño; requiere SetHelpPopup( "popups.txt" ) para popups de texto CHM)
  • Control con nombre de topic (carácter) — HelpTopic() visor CHM completo
  • nHelpId de ventana/diálogo o control vacío — HelpTopic() del padre, visor completo
  • HelpTopic( nId ) / HelpTopic( "topic" ) explícito — siempre visor CHM completo

Los nombres de topic deben coincidir con los .htm reales del CHM. HelpSetPos() solo aplica a .hlp clásico, no a CHM. Sample: samples/test/testchmhlp.prg (+ popups.txt). Recompilar la librería PRG tras la actualización.

samples/misc/dshow.prg — webcam (Media Foundation)

samples/misc/dshow.prg muestra vista previa de webcam y captura BMP en un diálogo FiveWin. En Windows 10/11, DirectShow IVideoWindow / GetCurrentImage suele devolver un buffer negro aunque el grafo esté en Running (comprobado con FaceTime HD / UVC). El sample usa por tanto Media Foundation mediante una DLL auxiliar.

  • DLL auxiliar: samples/misc/mfcam.cpp → mfcam.dll (32-bit) / mfcam64.dll (64-bit). Compilar una vez con MSVC: build_mfcam.bat. Colocar la DLL junto al EXE del sample.
  • UI: un timer graba cada frame a BMP y lo carga en un control IMAGE real (vista en vivo) y opcionalmente el snapshot.
  • Compiladores: cualquier variante con build_new.bat; verificado con xHarbour + BCC32 (xb32).
  • Diagnóstico (opcional): build_camtest.bat genera tests C++ puros sin FiveWin — camtest_mf64.exe (MF, recomendado) y camtest64.exe (DirectShow; a menudo negro en el mismo PC).
cd samples\misc
build_mfcam.bat
build_new.bat dshow xb32
dshow.exe

Relacionado: clase TWebCam (VFW legado) y samples/web/webcam.prg.

TWebView2 — Fixed Version Runtime

TWebView2():New() acepta un tercer parámetro opcional cBrowserExecutableFolder (el browserExecutableFolder de Microsoft). Cuando se indica, WebView2 carga un Runtime Fixed Version / standalone desde esa carpeta en lugar del Runtime Evergreen instalado en el sistema.

  • Útil en SO antiguos (p. ej. Windows Server 2012 R2) donde el Evergreen actual ya no funciona
  • Útil cuando no se puede instalar o actualizar el Runtime en la máquina
  • Ruta = raíz del Fixed Version (carpeta con msedgewebview2.exe)
  • Debe pasarse en el constructor (el entorno se crea en New())
  • El código existente sin el parámetro no cambia
oWeb := TWebView2():New( oWnd, , "C:\MiPrograma\WebView2Runtime" )

También se corrigió el segundo parámetro cUserDataFolder: se sobrescribía con una ruta por defecto en AppData; ahora se respeta.

Referencia: TWebView2.

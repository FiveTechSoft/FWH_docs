TWebView2 — Fixed Version Runtime

TWebView2():New() acepta un tercer parámetro opcional cBrowserExecutableFolder (el browserExecutableFolder de Microsoft). Cuando se indica, WebView2 carga un Runtime Fixed Version / standalone desde esa carpeta en lugar del Runtime Evergreen instalado en el sistema.

  • Útil en SO antiguos (p. ej. Windows Server 2012 R2) donde el Evergreen actual ya no funciona
  • Útil cuando no se puede instalar o actualizar el Runtime en la máquina
  • Ruta = raíz del Fixed Version (carpeta con msedgewebview2.exe)
  • Debe pasarse en el constructor (el entorno se crea en New())
  • El código existente sin el parámetro no cambia
oWeb := TWebView2():New( oWnd, , "C:\MiPrograma\WebView2Runtime" )

También se corrigió el segundo parámetro cUserDataFolder: se sobrescribía con una ruta por defecto en AppData; ahora se respeta.

Referencia: TWebView2.

Novedades en FWH 26.09

Resumen de FiveWin for Harbour/xHarbour versión 26.09 (septiembre 2026). Ver también whatsnew.txt en la raíz de FWH para el registro día a día.

Barra de título oscura automática + FW_SetCaptionColors

Con FW_SetDarkMode( .T. ) ahora toda WINDOW y todo DIALOG recibe automáticamente una barra de título oscura, con los colores del modo oscuro: sin código adicional (source/classes/dialog.prg, source/classes/window.prg).

La nueva función FW_SetCaptionColors() personaliza la barra de título (source/classes/dialog.prg): 

// Colores personalizados de texto/fondo del título (también en modo claro)
FW_SetCaptionColors( nClrText, nClrBack )

// Volver a los colores automáticos
FW_SetCaptionColors( nil, nil )

// Consultar los colores personalizados: { nClrText, nClrBack } o nil
aClrs := FW_SetCaptionColors()

El tema del título usa DWM (DwmSetWindowAttribute, con dwmapi.dll cargada en tiempo de ejecución, sin nueva dependencia). Requiere Windows 11; en Windows anteriores no hace nada. Ver colores de título en TDialog y modo oscuro en TWindow.

TBitmap ASPECT: escalado proporcional

Nueva opción ASPECT para @ ... BITMAP y REDEFINE BITMAP, y nueva propiedad lAspectRatio (source/classes/bitmap.prg): el bitmap se dibuja escalado proporcionalmente y centrado dentro del control, sin distorsión, dejando el área restante en el color de fondo del control. Tiene precedencia sobre ADJUST; dimensiones cero no dibujan nada. También vale asignar oBmp:lAspectRatio := .T. y llamar a oBmp:Refresh(). Ver TBitmap.

TScrollPanel: salto de foco tras scroll horizontal corregido

Tras un scroll horizontal, el manejador bGotFocus que SetRange() asigna a los controles con tab-stop seguía llamando a ControlIntoView(), devolviendo el panel a su posición. Ahora también se omite tras un scroll horizontal (lHScrolled), como ya ocurría con el vertical (source/classes/scrlpanl.prg). No requiere cambios en el código de usuario. Ver TScrollPanel.

TWebView2: de 10 a más de 40 nativos

TWebView2 (source/classes/twebview2.prg, source/internal/twebview/cwebview.cpp, source/winapi/webview2.c, include/WebView2.ch) pasa de 10 a más de 40 nativos. Nuevos métodos: NavigateEx( cUrl, cMethod, cHeaders, cBody ) (POST nativo), GoBack/GoForward/Reload/Stop, CanGoBack/CanGoForward, GetSource, GetDocumentTitle, GetBrowserVersion, Print, SetZoomFactor/GetZoomFactor, SetDefaultScriptDialogs, SetDefaultContextMenus/SetContextMenuExclude, CapturePreview (PNG asíncrono) / PrintToPdf (PDF asíncrono), Add/RemoveWebResourceRequestedFilter, ClearSession/ClearBrowsingData, EnableConsole, CloseWebView, Reinitialize, SetSizeRatio y diagnósticos Diag/Reregister. Nuevos eventos bOn*: NavigationStarting (cancelable), SourceChanged, HistoryChanged, DocumentTitleChanged, NewWindow, Permission (permitir/denegar), FullScreen, ProcessFailed, FrameNavStarting/Completed y Console. La carpeta de datos de usuario por defecto es %LOCALAPPDATA%\FWH_webview2_UserData. Totalmente compatible hacia atrás; nuevo ejemplo en samples/webview2/.

TProlog: un motor Prolog dentro de FiveWin

Nueva clase TProlog (source/classes/tprolog.prg): un motor Prolog integrado en Harbour/FiveWin, con hechos y reglas, backtracking, unificación (occurs-check opcional), corte (!), negación (not/\+), findall/3, aritmética (is/2, =:=/2, ...) y builtins nativos rápidos de listas (member, append, permutation, numlist, alldiff, sort, between, ...). Query() devuelve un array de hashes { VarName => "term" }. El núcleo en C (source/function/prolog.c, trail + heap de términos propio) resuelve el problema de las 8 reinas (las 92 soluciones) unas 230 veces más rápido que el intérprete Harbour anterior. Ejemplos: samples/ai/tprolog.prg, samples/ai/tprologbench.prg y samples/ai/plpad.prg, un editor Prolog con resaltado de sintaxis, grafo 3D de la base de conocimiento y botón de explicación con TOpenCode.

MAPI: relleno de dirección SMTP con tipo

MAPISendMail() / DEFINE MAIL con TO cEmail de un solo parámetro: el fallback de la 26.07 copiaba el nombre tal cual a lpszAddress (sin prefijo de tipo), lo que hacía que Outlook creara un destinatario ocasional y Exchange Online no entregara nunca el adjunto. mapi.c ahora rellena la forma con tipo SMTP:user@domain, solo cuando el nombre contiene @. La nueva función opcional SetMapiAddrFill( .F. ) restaura el comportamiento anterior a 26.07 de dejar lpszAddress vacío para que lo resuelva el cliente. La forma dual TO cName, cAddress no cambia.

IsWindows10() corregido en Windows Server

IsWindows10() ahora lee el número de build, igual que IsWindows11(), en lugar del nombre de producto del registro, que en ediciones servidor dice "Windows Server": devolvía .F. por error en Windows Server 2016/2019/2022.

Correcciones de enlazado en xHarbour 64 y MinGW

xHarbour + BCC 64 (xb64): a Fivexh64.a le faltaba todo lo de source/function/harbour.prg (ASend(), OSend(), OClone(), ParamCount(), OleInvoke() y más), así que las aplicaciones xHarbour 64 bits no enlazaban, con errores como Unresolved external 'HB_FUN_ASEND'; también faltaba TVistaMenu. Ya están incluidos, y mfwh_new.bat xb64 ahora lista cualquier fuente que no compile y se detiene, en lugar de dejarla fuera de la librería sin avisar.

Las librerías FiveWin también vuelven a compilar con MinGW 32 (source/internal/remoteview/capture.c define SM_CXPADDEDBORDER cuando las cabeceras del SDK no lo tienen), y las aplicaciones FWMariaDB enlazan con xHarbour + MSVC 32 (source/internal/fwmaria.prg usa su propio nxs_crypt y Adler-32 ahí).

TOpenCode vuelve a hablar con OpenCode Zen

TOpenCode (source/classes/topencode.prg) funciona de nuevo con el servicio Zen: se envía la cabecera x-opencode-session: public (las peticiones antiguas fallaban con MissingSessionID), el catálogo de modelos gratuitos está al día (ling-3.0-flash-fin-free por defecto) y el estado HTTP usa el valor de retorno como respaldo. Ver TOpenCode.

Nuevos ejemplos

  • samples/menus/vistamenu.prg — un ejemplo mínimo de TVistaMenu (menú lateral con tres elementos); esta clase no tenía ningún ejemplo que compilar.
  • samples/ai/plpad.prg — editor Prolog: pega o abre un archivo .pl, consúltalo con TProlog y ejecuta consultas, con un grafo TWebView2/three.js de node()/edge().

PrinterKeepSetup

Nuevo: PrinterKeepSetup( lOn ) conserva la impresora elegida en PrinterSetup() o PageSetup() para los siguientes trabajos de impresión (desactivado por defecto, usa en silencio la predeterminada si la conservada ya no existe, PrinterResetSetup() la olvida). Ver TPrinter.

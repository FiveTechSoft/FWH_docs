Índice de Ejemplos

FWH incluye más de 500 programas de ejemplo organizados en el directorio samples\. Cada subdirectorio se centra en un área específica: Primeros Pasos, Controles UI, Acceso a Datos, impresión, internet, IA, utilidades heredadas y mucho más. Todos los ejemplos se pueden compilar con build_new.bat <name> <variant>.

Compilando los Ejemplos

Todos los ejemplos se compilan desde el directorio samples usando el script de compilación unificado:

cd \fwteam\samples
build_new.bat <program> <variant>

// Ejemplos:
build_new.bat tutor01 hb32       // Harbour + BCC32
build_new.bat tutor01 hm64       // Harbour + MSVC 64
build_new.bat xbrwedit hb32      // Edición en línea de TXBrowse
build_new.bat qrcode2 hb32       // Códigos QR

Variantes: hb32, hm32, hm64, hg32, hg64, hb64, xb32, xb64, xm64.

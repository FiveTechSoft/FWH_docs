TFLine

Fuente: source/classes/fline.prg

Clase independiente

TFLine (Línea Formateada) es una clase de utilidad para componer una línea formateada a partir de múltiples fragmentos de texto con estilo. Cada fragmento puede tener su propia fuente, color y alineación. TFLine se utiliza junto con TSay:oLine para representar etiquetas de texto enriquecido y con la salida de línea formateada de TReport. La clase mantiene un array de tripletes de texto, fuente y color que se dibujan como una sola línea con el ajuste de palabras controlado por lCrLf.

Miembros DATA Clave

DATATipoDescripción
oUpObjetoObjeto enlazado anterior (usado en cadenas de líneas)
oDownObjetoObjeto enlazado posterior
nalignNuméricoValor de alineación de la línea (0 = por defecto)
aTextArrayArray de cadenas de texto para cada fragmento
aFontsArrayArray de objetos de fuente o índices para cada fragmento
aColorsArrayArray de valores de color para cada fragmento
lCrLfLógicoInserta un retorno de carro/salto de línea tras esta línea

Métodos

MétodoDescripción
New( nalign, aText, aFonts, aColors, lCrLf )Crea una línea formateada con los fragmentos indicados. Valores por defecto: {}, {}, {}, 0, .F.
End()Libera los objetos enlazados (establece oUp y oDown a NIL)

Ejemplo: Fragmentos de Texto con Estilo

#include "FiveWin.ch"

function FormattedLabel()

   local oSay, oLine

   DEFINE FONT oFont1 NAME "Arial" SIZE 0, -24
   DEFINE FONT oFont2 NAME "Arial" SIZE 0, -18 BOLD

   oLine := TFLine():New( 0, ;
      { "Welcome ", "FiveWin ", "User" }, ;
      { oFont1, oFont2, oFont1 }, ;
      { CLR_BLUE, CLR_RED, CLR_BLACK } )

   // Usar oLine con TSay para mostrar
   @ 10, 10 SAY oSay PROMPT "" OF oWnd SIZE 300, 50
   oSay:oLine := oLine
   oSay:lTransparent := .T.

return nil

Notas

  • TFLine se utiliza principalmente de forma interna por TSay y TReport para permitir la representación de texto con múltiples estilos en una sola línea.
  • Cada elemento de array en aText, aFonts y aColors corresponde a un fragmento con estilo. Los fragmentos se concatenan horizontalmente.
  • Establezca lCrLf := .T. para forzar un salto de línea tras esta línea formateada.
  • Los punteros oUp y oDown permiten encadenar varios objetos TFLine entre sí.

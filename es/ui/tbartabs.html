TBarTabs

Fuente: source/classes/bartabs.prg

Clase independiente (no descendiente de TControl)

TBarTabs combina TTabs con TBar para crear una interfaz de barra de herramientas con pestañas estilo cinta. Cada pestaña está asociada con una barra de herramientas separada que se vuelve visible cuando se selecciona la pestaña. Esto proporciona una forma compacta de organizar botones de barra de herramientas en grupos funcionales, similar al patrón de cinta encontrado en aplicaciones de escritorio modernas.

Miembros DATA Principales

DATATipoDescripción
aBarsArrayArray of TBar objects, one per tab
oTabsObjectTTabs control for switching between toolbars
oPanelObjectTPanel container holding the tabs and buttons
oWndObjectParent window
nBarNumericIndex of the currently active toolbar tab

Métodos

MétodoDescripción
New( oWnd, nBtnWidth, nBtnHeight, aPrompts, acBitmaps, nOption, l3D, l2007 )Create a new TBarTabs control with initial tabs
AddBar( cPrompt, cBitmap )Add a new tab with its associated toolbar. Returns the TBar object.

Ejemplo: Three-Tab Toolbar

#include "FiveWin.ch"

function Main()

   local oWnd, oBarTabs, oBar
   local aPrompts := { "Home", "Insert", "View" }
   local acBitmaps := {}

   DEFINE WINDOW oWnd TITLE "BarTabs Demo" SIZE 600, 200

   oBarTabs := TBarTabs():New( oWnd, 64, 32, aPrompts, acBitmaps, 1, .F., .T. )

   // Home tab buttons
   oBar := oBarTabs:aBars[ 1 ]
   DEFINE BUTTON OF oBar PROMPT "Cut"
   DEFINE BUTTON OF oBar PROMPT "Copy"
   DEFINE BUTTON OF oBar PROMPT "Paste"

   // Insert tab buttons
   oBar := oBarTabs:aBars[ 2 ]
   DEFINE BUTTON OF oBar PROMPT "Table"
   DEFINE BUTTON OF oBar PROMPT "Image"

   // View tab buttons
   oBar := oBarTabs:aBars[ 3 ]
   DEFINE BUTTON OF oBar PROMPT "Zoom In"
   DEFINE BUTTON OF oBar PROMPT "Zoom Out"

   oBarTabs:oPanel:ReSize()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TBarTabs es una clase independiente que no hereda de TControl. Gestiona un contenedor TPanel que contiene un control TTabs y m
  • El constructor crea una barra de herramientas por cada texto. Use AddBar() para agregar barras de herramientas din
  • Establezca l3D := .T. para un aspecto de bot
  • El panel se posiciona como oWnd:oTop, lo que significa que se adhiere a la parte superior de la ventana padre. Llame a oBarTabs:oPanel:ReSize() despu
  • Solo la barra de herramientas correspondiente a la pesta
  • Los mapas de bits para los encabezados de pesta

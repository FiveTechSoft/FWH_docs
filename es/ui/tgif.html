TGif

Fuente: source/classes/tgif.prg

Jerarquía: TGif → TControl

TGif es un control para mostrar imágenes GIF animadas dentro de ventanas y diálogos de FiveWin. Soporta operaciones de reproducción, pausa y reinicio, y tres modos de redimensionamiento para controlar cómo los fotogramas del GIF se ajustan dentro del rectángulo delimitador del control. El control puede cargar GIFs desde archivos o desde recursos incrustados.

Comando GIF

@ nRow, nCol GIF oGif FILE cGifFile SIZE nW, nH OF oWnd

Miembros DATA Principales

DATATipoPredet.Descripción
hGifNuméricoManejador de la ventana interna de animación GIF
cFilenameCarácterRuta al archivo GIF (o nombre del recurso)
lAdjustLógico.F.Estirar el GIF para llenar las dimensiones del control cuando es .T.
nSizingTypeNuméricoFWGIF_SIZING_FILEUno de FWGIF_SIZING_FILE, FWGIF_SIZING_CLIP o FWGIF_SIZING_STRETCH

Modos de Redimensionamiento

ConstanteValorDescripción
FWGIF_SIZING_FILEPredeterminadoUsar las dimensiones naturales del GIF. El control se auto-redimensiona para coincidir.
FWGIF_SIZING_CLIPRecortar el GIF para que quepa en el rectángulo delimitador del control a su tamaño natural.
FWGIF_SIZING_STRETCHEstirar el GIF para llenar las dimensiones del control (igual que lAdjust := .T.).

Métodos Principales

MétodoDescripción
New( oWnd, cGifFile, nRow, nCol, nHeight, nWidth, oCursor, lAdjust, bAction )Constructor. Crea el control GIF e inicia la animación.
Play()Iniciar o reanudar la animación GIF.
Stop()Pausar la animación GIF en el fotograma actual.
Restart()Reiniciar la animación desde el primer fotograma.
IsRunning()Devolver .T. si la animación se está reproduciendo actualmente.
SetFile( cFile )Cargar un nuevo archivo GIF en el control.
SetSizing( nType )Cambiar el modo de redimensionamiento en tiempo de ejecución.
GetData()Devolver un array con metadatos del GIF (dimensiones, número de fotogramas, etc.).

Ejemplo: Animación de Carga

#include "FiveWin.ch"

function Main()

   local oWnd, oGif, lPlaying := .T.

   DEFINE WINDOW oWnd TITLE "Animated GIF" ;
      SIZE 400, 350

   @ 30, 100 GIF oGif FILE "spinner.gif" ;
      SIZE 64, 64 OF oWnd

   @ 250, 80 BUTTON "&Play / Pause" SIZE 80, 25 ;
      ACTION ( If( oGif:IsRunning(), oGif:Stop(), oGif:Play() ),;
               lPlaying := !lPlaying )

   @ 250, 170 BUTTON "&Restart" SIZE 70, 25 ;
      ACTION oGif:Restart()

   @ 250, 250 BUTTON "&Close" SIZE 60, 25 ;
      ACTION oWnd:End()

   ACTIVATE WINDOW oWnd

return nil

Notas

  • Los archivos GIF se pueden cargar desde disco o desde recursos incrustados (tipo de recurso 10 / RT_RCDATA). Cuando se pasa un nombre de recurso, el control lo extrae a un archivo temporal para mostrarlo.
  • Cuando no se proporciona un ancho/alto explícito, el control se auto-redimensiona a las dimensiones naturales del GIF.
  • El indicador lAdjust es una propiedad de conveniencia que internamente establece el modo de redimensionamiento a FWGIF_SIZING_STRETCH.
  • Múltiples controles TGif pueden coexistir en la misma ventana; cada uno gestiona su propia animación de forma independiente.
  • El control requiere el motor GIF interno de FWH (enlazado desde source/function/).

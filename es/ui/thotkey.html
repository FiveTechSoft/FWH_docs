THotKey

Fuente: source/classes/thotkey.prg

Hereda de: TControl

THotKey envuelve el control común de tecla rápida de Win32, permitiendo al usuario presionar una combinación de teclado (ej., Ctrl+Alt+F5) que se captura y almacena como un código de tecla virtual y máscara de modificadores. Se usa comúnmente en diálogos de configuración donde los usuarios definen atajos de teclado personalizados.

Miembros DATA Principales

DATATipoDescripción
nVirtKeyNumericCódigo de tecla virtual de la tecla seleccionada (ej., VK_F5)
nModifiersNumericMáscara de bits de teclas modificadoras: HOTKEYF_SHIFT, HOTKEYF_CONTROL, HOTKEYF_ALT

Methods

MétodoDescripción
New( nRow, nCol, oWnd, nVK, nMod )Crear un nuevo control de entrada de tecla rápida
SetHotKey( nVK, nMod )Establecer programáticamente la tecla rápida a nVK con modificadores nMod
GetHotKey()Devuelve un array { nVirtKey, nModifiers } de la tecla rápida actual
GetKeyName()Devuelve una cadena legible como "Ctrl+Alt+F5"
SetRules( nInv, nDef )Establecer combinaciones de teclas inválidas y comportamiento de anulación predeterminado

Ejemplo: Selector de Tecla Rápida con Callback de Cambio

#include "FiveWin.ch"

function Main()

   local oWnd, oHot, nVK := VK_F5, nMod := HOTKEYF_CONTROL + HOTKEYF_ALT

   DEFINE WINDOW oWnd TITLE "Hotkey Demo" SIZE 400, 150

   @ 40, 20 HOTKEY oHot ;
      SIZE 120, 25 OF oWnd ;
      ACTION MsgInfo( "Hotkey: " + oHot:GetKeyName() )

   oHot:SetHotKey( nVK, nMod )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • THotKey captura la combinación de teclas cuando el control tiene el foco y el usuario presiona un acorde modificador+tecla. La combinación se muestra en el control. The combination is displayed in the control.
  • Constantes de modificadores: HOTKEYF_SHIFT (1), HOTKEYF_CONTROL (2), HOTKEYF_ALT (4). Combine con + para teclas rápidas multi-modificador. Combine with + for multi-modifier hotkeys.
  • GetKeyName() devuelve una cadena localizada adecuada para mostrar en menús o listas de configuración.
  • Use SetRules() para especificar qué combinaciones de teclas son inválidas. nInv is a mask of invalid modifiers and nDef specifies the default modifier to use when the user types an invalid combination.

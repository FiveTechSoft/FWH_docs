TMetro

Fuente: source/classes/tmetro.prg

Clase independiente

TMetro crea una pantalla de inicio de UI moderna (estilo Metro) a pantalla completa con botones en mosaico, inspirada en el lenguaje de diseño Metro de Windows 8. Muestra una imagen de fondo, un título, la fecha y hora actuales, y una cuadrícula de botones en mosaico que pueden ser normales o grandes (de doble ancho). Cada mosaico tiene colores de texto y de fondo configurables y una imagen de icono opcional.

Miembros DATA Principales

DATATipoDescripción
oWndObjetoLa ventana emergente subyacente (estilo WS_POPUP)
cTitleCarácterTítulo mostrado en la parte superior de la pantalla de inicio
aButtonsArrayArray de objetos TButtonBmp creados por AddButton()
nBtnWidthNuméricoAncho del mosaico en píxeles (132 por defecto)
nBtnHeightNuméricoAlto del mosaico en píxeles (132 por defecto)
nOriginXNuméricoPosición X inicial de la cuadrícula de mosaicos (200 por defecto)
nOriginYNuméricoPosición Y inicial de la cuadrícula de mosaicos (200 por defecto)
hBitmapNuméricoHandle del bitmap de fondo
oFontObjetoFuente Segoe UI Light para los elementos de visualización
oFontBObjetoFuente Segoe UI Light en negrita para mostrar la hora
oTimerObjetoTemporizador para actualizar la visualización del reloj

Métodos

MétodoDescripción
New( cTitle, nBtnW, nBtnH, cBgFile )Crea una nueva pantalla de inicio TMetro. cBgFile es un archivo o recurso de bitmap de fondo.
Activate()Muestra la pantalla de inicio maximizada con fondo, título, fecha y hora
AddButton( cCaption, nClrText, nClrPane, lLarge, cImg, bAction )Añade un botón de mosaico con texto, colores, imagen opcional y acción
End()Cierra la pantalla de inicio y libera los recursos

Ejemplo: Pantalla Metro con Mosaicos

#include "FiveWin.ch"

function Main()

   local oMetro

   oMetro := TMetro():New( "My Application", 132, 132, "bg.bmp" )

   oMetro:AddButton( "Customers", CLR_WHITE, CLR_HBLUE, .F., "cust.bmp",;
      { || MsgInfo( "Customers" ) } )

   oMetro:AddButton( "Products", CLR_WHITE, CLR_HGREEN, .F., "prod.bmp",;
      { || MsgInfo( "Products" ) } )

   oMetro:AddButton( "Reports", CLR_WHITE, CLR_HRED, .T., "rpt.bmp",;
      { || MsgInfo( "Reports" ) } )

   oMetro:Activate()

return nil

Notas

  • TMetro crea una ventana emergente sin bordes que ocupa toda la pantalla. El estilo de ventana usa WS_POPUP sin título ni borde.
  • La imagen de fondo puede cargarse desde un archivo o desde un recurso. Si no se encuentra el archivo, recurre a la carga desde recurso.
  • Los mosaicos grandes (lLarge := .T.) ocupan dos posiciones de mosaico en ancho, proporcionando énfasis visual para las acciones principales.
  • Las posiciones de los mosaicos se calculan automáticamente en una disposición de cuadrícula. Cuando una fila excede el ancho de la pantalla, los mosaicos saltan a la siguiente fila.
  • El reloj se actualiza mediante un temporizador interno y se muestra en el área superior derecha usando la fuente Segoe UI Light.
  • TMetro usa la fuente Segoe UI Light, que está disponible en Windows 8 y posteriores. En sistemas más antiguos, recurre a una fuente por defecto.

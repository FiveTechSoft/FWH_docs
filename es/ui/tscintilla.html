TScintilla

Fuente: source/classes/scintila.prg

Jerarquía: TScintilla → TControl

TScintilla envuelve el componente de edición de código fuente Scintilla (scintilla.org) para su uso en aplicaciones FiveWin. Proporciona un editor de código completo con resaltado de sintaxis, plegado de código, numeración de líneas, marcadores, buscar/reemplazar, deshacer/rehacer y soporte para múltiples lexers incluyendo sintaxis Harbour/xHarbour.

Comando SCINTILLA

@ nRow, nCol SCINTILLA oSci SIZE nW, nH OF oWnd FONT oFont LEXER cLexer

Ejemplo: Editor de Código

#include "FiveWin.ch"

function Main()

   local oWnd, oSci, oFont

   DEFINE FONT oFont NAME "Consolas" SIZE 0, -12

   DEFINE WINDOW oWnd TITLE "Source Editor" ;
      SIZE 800, 600

   @ 0, 0 SCINTILLA oSci SIZE 800, 570 OF oWnd ;
      FONT oFont LEXER ""

   oSci:lMargLin   := .T.
   oSci:lFolding   := .T.
   oSci:lMarking   := .T.
   oSci:SetUp()

   // Botones de barra de herramientas
   @ 575, 10 BUTTON "&Open" SIZE 50, 20 ;
      ACTION oSci:Open()

   @ 575, 65 BUTTON "&Save" SIZE 50, 20 ;
      ACTION oSci:Save()

   @ 575, 120 BUTTON "&Find" SIZE 50, 20 ;
      ACTION oSci:DlgFindText()

   @ 575, 175 BUTTON "&Undo" SIZE 50, 20 ;
      ACTION oSci:Undo()

   @ 575, 230 BUTTON "&Redo" SIZE 50, 20 ;
      ACTION oSci:Redo()

   @ 575, 620 BUTTON "E&xit" SIZE 50, 20 ;
      ACTION oWnd:End()

   ACTIVATE WINDOW oWnd ;
      VALID ( oSci:End(), oFont:End(), .T. )

return nil

Configuración del Lexer

TScintilla soporta resaltado de sintaxis mediante conjuntos de colores de palabras clave configurables y arrays de colores específicos de token:

DATATipoDescripción
cCKeyw1..cCKeyw5ArrayConjuntos de color de palabras clave: { nForeColor, nBackColor, nCase } para niveles 1–5
cCStringArrayColor de literal de cadena: { nForeColor, nBackColor, nCase }
cCNumberArrayColor de literal numérico: { nForeColor, nBackColor, nCase }
cCOperatorArrayColor de operador: { nForeColor, nBackColor, nCase }
cCCommentArrayColor de comentario (soporta multi-línea): { nForeColor, nBackColor, nCase }

Cada array de color contiene tres elementos:

  • nForeColor — Color de primer plano (texto) como valor RGB numérico.
  • nBackColor — Color de fondo como valor RGB numérico.
  • nCase — Modo de mayúsculas: SC_CASE_MIXED, SC_CASE_UPPER o SC_CASE_LOWER.

Modos de Codificación de Archivos

TScintilla soporta múltiples modos de codificación de archivos para leer y guardar documentos en diferentes codificaciones de caracteres. Estos se controlan mediante los miembros de datos nModeSave y nModeLoad junto con el indicador lBom.

ModoConstanteDescripción
0nModeLoad := 0Codificación normal (ANSI/CP1252)
1nModeLoad := 1 / nModeSave := 1UTF-8 con BOM
2nModeLoad := 2 / nModeSave := 2UTF-8 sin BOM
3nModeLoad := 3 / nModeSave := 3UTF-16 Little Endian
  • nModeLoad controla cómo se interpreta el archivo al abrirlo. El modo 0 lee como ANSI; los modos 1–3 decodifican el formato Unicode apropiado.
  • nModeSave controla cómo se escribe el documento de vuelta al disco.
  • lBom (lógico) controla si se escribe una marca de orden de bytes al inicio del archivo al guardar. Relevante para modos UTF-8 y UTF-16.
  • Cuando OpenFile() carga un documento, el BOM UTF-8 se detecta automáticamente independientemente de nModeLoad.

Notas

  • TScintilla requiere la DLL Scintilla (SciLexer.dll para 32 bits o SciLex64.dll para 64 bits) en tiempo de ejecución. La DLL se carga dinámicamente mediante LoadLibrary.El resaltado de sintaxis Harbour/xHarbour se activa pasando "Harbour" o el número de lexer correspondiente como parámetro cLex.
  • Use cCKeyw1 a cCKeyw5 para personalizar los colores de sintaxis. Cada uno es un array de { nForeColor, nBackColor, nCaseMode }.
  • El indicador lModified y el bloque de código bModified le permiten rastrear cambios no guardados, por ejemplo, para actualizar el título de una ventana con un indicador de modificación.
  • La clase proporciona diálogos integrados para buscar/reemplazar (DlgFindText(), DlgReplace()), ir a línea (DlgGoToLine()) e inserción de caracteres (DlgInsChar()).
  • Los márgenes se configuran mediante nMargLines, nMargSymbol, nMargFold y nMargText. Llame a SetUp() después de cambiar la configuración de márgenes.

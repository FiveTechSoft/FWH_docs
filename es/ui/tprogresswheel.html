TProgressWheel

Fuente: source/classes/metrcirc.prg

Hereda de: TControl

TProgressWheel es un indicador de progreso circular/anillo basado en GDI+ que muestra texto de porcentaje completado en el centro. Admite colores de relleno degradados tanto para los segmentos de arco completados como restantes, un diámetro interior ajustable y un modo giratorio indeterminado adecuado para operaciones de duración desconocida. Las propiedades de color aceptan valores RGB numéricos, matrices de degradado, rutas de archivos de imagen u objetos TBrush.

Ejemplo: Ring Progress at 35%

#include "FiveWin.ch"

function Main()

   local oWnd, oWheel

   DEFINE WINDOW oWnd TITLE "Progress Wheel" SIZE 300, 300

   oWheel := TProgressWheel():New( 20, 20, oWnd, 35,, 100, 100,;
                                   .T.,,, .F., CLR_HGRAY,;
                                   CLR_HRED, CLR_HGREEN, CLR_WHITE,;
                                   0, 100, 0.60 )

   oWheel:lPercentage := .T.

   ACTIVATE WINDOW oWnd CENTERED

return nil

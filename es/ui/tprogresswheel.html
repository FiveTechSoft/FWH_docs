TProgressWheel

Fuente: source/classes/metrcirc.prg

Hereda de: TControl

TProgressWheel es un indicador de progreso circular/anillo basado en GDI+ que muestra texto de porcentaje completado en el centro. Admite colores de relleno degradado tanto para los segmentos de arco completados como restantes, un diámetro interior ajustable y un modo de giro indeterminado adecuado para operaciones de duración desconocida. Las propiedades de color aceptan valores RGB numéricos, arrays de degradado, rutas de archivo de imagen u objetos TBrush.

Ejemplo: Progreso de Anillo al 35%

#include "FiveWin.ch"

function Main()

   local oWnd, oWheel

   DEFINE WINDOW oWnd TITLE "Progress Wheel" SIZE 300, 300

   oWheel := TProgressWheel():New( 20, 20, oWnd, 35,, 100, 100,;
                                   .T.,,, .F., CLR_HGRAY,;
                                   CLR_HRED, CLR_HGREEN, CLR_WHITE,;
                                   0, 100, 0.60 )

   oWheel:lPercentage := .T.

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TProgressWheel usa GDI+ para todo el renderizado. La librería FWH enlaza soporte GDI+ de forma predeterminada en versiones recientes.
  • Las propiedades de color nColorRemain y nColorDoneMin aceptan RGB numérico, arrays de degradado de dos elementos { nClr1, nClr2 }, rutas de archivo de imagen para pinceles de textura u objetos TBrush.
  • En modo indeterminado (Indefinite( .T. )), un temporizador interno impulsa la rotación continua de dos arcos de colores, adecuado para operaciones de duración desconocida.
  • El diámetro interior controla el grosor del anillo. Valores cercanos a 0 producen un disco sólido; valores cercanos a 1 producen un contorno de anillo delgado.

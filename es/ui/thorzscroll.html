THorzScroll

Fuente: source/classes/hrzscrol.prg

Hereda de: TPanel

THorzScroll extiende TPanel con una barra de desplazamiento horizontal incorporada que desplaza una colección de paneles hijos. Está diseñado para diseños desplazables horizontalmente como filas de tarjetas de panel, paneles de herramientas o galerías de imágenes donde el contenido excede el ancho visible. It is designed for horizontally scrollable layouts such as dashboard card rows, toolbar panels, or image galleries where content exceeds the visible width.

Ejemplo: Panel de Desplazamiento Horizontal

#include "FiveWin.ch"

function Main()

   local oWnd, oHS, oP1, oP2, oP3

   DEFINE WINDOW oWnd TITLE "THorzScroll Demo" SIZE 600, 200

   @ 10, 10 PANEL oHS OF oWnd SIZE 560, 150

   oP1 := oHS:AddPanel( 150, CLR_RED )
   oP2 := oHS:AddPanel( 150, CLR_GREEN )
   oP3 := oHS:AddPanel( 150, CLR_BLUE )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • THorzScroll crea internamente un TScrollBar mediante ::oHScroll con bloques de código enlazados para desplazamiento de línea, página y seguimiento de pulgar.
  • Use AddPanel() para agregar paneles hijos. Cada panel se dimensiona según nWidth y se posiciona automáticamente con espaciado nBetween. Each panel is sized according to nWidth and automatically positioned with nBetween spacing.
  • UpdateScrollRange() recalcula nMaxWidth a partir del ancho total de todos los paneles hijos para establecer el máximo de la barra de desplazamiento.
  • El método MouseWheel soporta desplazamiento horizontal mediante la rueda del ratón cuando el panel tiene el foco.

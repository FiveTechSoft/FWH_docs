TURLLink

Fuente: source/classes/urllink.prg

Hereda de: TControl

TURLLink muestra un control de texto de hipervínculo en el que se puede hacer clic. Al hacer clic, se inicia el navegador web predeterminado con la URL especificada. El control admite colores personalizados para los estados normal, al pasar el ratón y visitado, fondos transparentes, y un bloque de código bAction personalizado para anular el comportamiento de navegación predeterminado.

Miembros DATA Principales

DATATipoDescripción
cURLCarácterLa URL de destino que se abre al hacer clic
nClrInitNuméricoColor del texto en el estado normal (no visitado)
nClrOverNuméricoColor del texto cuando el ratón pasa sobre el enlace
nClrVisitNuméricoColor del texto después de hacer clic en el enlace (visitado)
bActionBloqueBloque de acción personalizado que anula el lanzamiento de URL predeterminado

Métodos

MétodoDescripción
New( nTop, nLeft, oWnd, lPixel, lDesign, oFont, cMsg, cURL, cToolTip, nClrInit, nClrOver, nClrVisit, lTransp )Crea un nuevo control TURLLink

Ejemplo: Enlace URL con Acción Personalizada

#include "FiveWin.ch"

function Main()

   local oWnd, oLink

   DEFINE WINDOW oWnd TITLE "URL Link Demo" SIZE 400, 200

   @ 20, 20 URLLINK oLink ;
      TEXT "Visit FiveTech Software" ;
      URL "https://fivetechsoft.com" ;
      COLOR CLR_BLUE, CLR_RED, CLR_HGRAY ;
      TOOLTIP "Click to open website" ;
      OF oWnd

   // Anula el lanzamiento del navegador predeterminado con una acción personalizada
   oLink:bAction := {|| MsgInfo( "Navigating to: " + oLink:cURL ) }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • De forma predeterminada, al hacer clic en el enlace se ejecuta ShellExecute( "open", cURL ) para abrir la URL en el navegador predeterminado del sistema.
  • Establezca bAction para anular por completo el comportamiento predeterminado. El bloque de código recibe el objeto TURLLink como Self.
  • Los tres estados de color (nClrInit, nClrOver, nClrVisit) proporcionan retroalimentación visual a medida que el usuario interactúa con el enlace. nClrOver suele ser una variante más brillante o subrayada.
  • El cursor cambia automáticamente a un puntero de mano al pasar sobre el texto del enlace.
  • Use ReDefine() para vincularse a un control de texto estático definido en un recurso de diálogo .rc, convirtiéndolo en un enlace en el que se puede hacer clic en tiempo de ejecución.
  • Establezca lTransp en .T. para un fondo transparente, permitiendo que el enlace se integre en cualquier fondo de diálogo o ventana.

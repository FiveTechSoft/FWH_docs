TCalEx

Fuente: source/classes/tcalex.prg

Hereda de: TControl

TCalEx es la clase base de los controles extendidos de calendario y planificación de FiveWin. Proporciona un sistema completo de navegación de fechas con soporte para múltiples vistas (mes, semana, día), gestión de citas/eventos, renderizado con degradados personalizados y selección interactiva basada en el ratón. La clase está diseñada para manejar interfaces de planificación complejas con intervalos de tiempo, rangos de fechas y estilos visuales configurables.

TCalEx gestiona tres objetos de subvista -- oMonthView, oWeekView y oDayView -- que se encargan del renderizado real y de la gestión de eventos para cada modo de vista específico. La vista activa se controla mediante los métodos SetMonthView(), SetWeekView() y SetDayView().

Ejemplo: Calendario con Citas

#include "FiveWin.ch"

function Main()

   local oWnd, oCal

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 800, 600

   @ 10, 10 CALENDAR oCal OF oWnd

   // Cargar citas para un rango de fechas
   oCal:LoadDates( 9, 18, ;           // horas a mostrar 9:00-18:00
      CToD( "2026-06-01" ), ;        // fecha de inicio
      CToD( "2026-06-30" ), ;        // fecha de fin
      "Team Meeting", ;              // texto del evento
      "Project review", ;            // asunto
      , , , , , CLR_YELLOW, CLR_RED, 1 )

   // Cambiar inicialmente a la vista por semana
   oCal:SetWeekView( dDate(), 30 )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Ejemplo completo: Consulte samples/misc/calexmaria.prg para una aplicación TCalex completa con backend MySQL/MariaDB, arrastrar-y-soltar citas, y edición con diálogo RC.

Notas

  • TCalEx no usa el sistema de coordenadas PIXEL estándar. Todos los valores de posicionamiento usan unidades de diálogo (coordenadas de texto).
  • Los tres objetos de subvista (oMonthView, oWeekView, oDayView) son creados internamente por TCalEx. Alterne entre ellos usando los métodos SetMonthView(), SetWeekView() y SetDayView().
  • Los datos de eventos/citas se almacenan en la tabla hash hCalInfo y se renderizan dentro de la cuadrícula de la vista activa.
  • El coloreado con degradado de las celdas, cabeceras y etiquetas se configura mediante los arrays DATA aGrad*.
  • Los intervalos de tiempo controlan la granularidad de la cuadrícula de la vista por día/semana. Los valores válidos son 5, 10, 15, 20, 30 y 60 minutos.

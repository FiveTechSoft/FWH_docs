TTrackBar

Fuente: source/classes/trackbar.prg

Hereda de: TControl

TTrackBar encapsula el control común trackbar (deslizador) de Win32. Permite al usuario seleccionar un valor numérico arrastrando un cursor a lo largo de una guía, con marcas de graduación opcionales. Se usa habitualmente para controles de volumen, deslizadores de brillo y cualquier entrada de valor dentro de un rango.

Miembros DATA Principales

DATATipoDescripción
nMinNuméricoValor mínimo del rango del trackbar
nMaxNuméricoValor máximo del rango del trackbar
nPosNuméricoPosición actual del cursor
nFreqNuméricoFrecuencia de las marcas de graduación
bChangeBloqueBloque de código que se ejecuta cuando cambia la posición

Métodos

MétodoDescripción
New( nRow, nCol, oWnd, nW, nH, nMin, nMax, nPos, nFreq )Crea un nuevo control trackbar
SetPos( n )Sitúa el cursor en la posición n
GetPos()Devuelve la posición actual del cursor
SetRange( nMin, nMax )Establece los valores mínimo y máximo del rango
SetTicFreq( n )Establece la frecuencia de las marcas de graduación

Ejemplo: Control de Volumen 0-255

#include "FiveWin.ch"

function Main()

   local oWnd, oTrack, nVol := 128

   DEFINE WINDOW oWnd TITLE "Volume Control" SIZE 400, 150

   @ 40, 20 TRACKBAR oTrack VAR nVol ;
      SIZE 360, 30 OF oWnd ;
      RANGE 0, 255 ;
      ON CHANGE ( oWnd:SetText( "Volume: " + Str( nVol ) ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTrackBar encapsula el trackbar nativo de Win32 (TRACKBAR_CLASS). Admite orientaciones tanto horizontal como vertical según las dimensiones pasadas a New().
  • La cláusula VAR enlaza una variable numérica que se actualiza automáticamente cuando el usuario mueve el cursor.
  • Use SetTicFreq() para mostrar marcas de graduación a intervalos regulares. Una frecuencia de 0 oculta todas las marcas.
  • La cláusula ON CHANGE establece bChange, que se dispara continuamente mientras el usuario arrastra el cursor.

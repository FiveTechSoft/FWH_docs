TTreeView

Control de árbol jerárquico con expandir/contraer, casillas de verificación, arrastrar y soltar, y edición de etiquetas

Fuente: source/classes/ttreevie.prg, source/classes/treeitem.prg  |  Clase Padre: TControl

Visión General

TTreeView envuelve el control común SysTreeView32 de Windows. Muestra datos en una estructura de árbol jerárquico donde cada nodo puede tener nodos hijos. Los nodos pueden expandirse/contraerse, soportan iconos mediante listas de imágenes, casillas de verificación opcionales, edición de etiquetas in situ y reordenamiento mediante arrastrar y soltar.

TVItem -- Nodo del Árbol

Fuente: source/classes/treeitem.prg

Cada nodo del árbol es un objeto TVItem (llamado internamente TTreeItem en la versión Win32). Los elementos forman una lista enlazada con punteros oPrev/oNext y pueden contener un subárbol de hijos.

PropiedadTipoDescripción

Ejemplos de Código

Ejemplo 1: Árbol de Exploración de Archivos

#include "FiveWin.ch"

FUNCTION FileTreeDemo()
   LOCAL oDlg, oTV, oImgList
   LOCAL oRoot, oSrc, oRes

   DEFINE DIALOG oDlg TITLE "Project Explorer" SIZE 400, 500

   // Lista de imágenes: iconos de carpeta y archivo
   DEFINE IMAGELIST oImgList SIZE 16, 16
   IMAGELIST ADD BITMAP oImgList NAME "FOLDER", "FILE"

   @ 0.5, 0.5 TREEVIEW oTV OF oDlg ;
      SIZE 190, 220 PIXEL ;
      ON CHANGE { || ShowItemInfo( oTV ) }

   oTV:SetImageList( oImgList )

   // Construir el árbol
   oRoot := oTV:Add( "MyProject", 0 )         // icono de carpeta = 0

   oSrc := oRoot:AddItem( "Source", 0 )
   oSrc:AddItem( "main.prg", 1 )              // icono de archivo = 1
   oSrc:AddItem( "utils.prg", 1 )
   oSrc:AddItem( "database.prg", 1 )

   oRes := oRoot:AddItem( "Resources", 0 )
   oRes:AddItem( "main.rc", 1 )
   oRes:AddItem( "icons.rc", 1 )

   oTV:Add( "Libraries", 0 )

   // Iniciar expandido
   oTV:ExpandAll()

   @ 11, 1 BUTTON "Expand All"   OF oDlg SIZE 60, 14 ;
      ACTION oTV:ExpandAll()
   @ 11, 7 BUTTON "Collapse All" OF oDlg SIZE 60, 14 ;
      ACTION oTV:CollapseAll()

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

STATIC FUNCTION ShowItemInfo( oTV )
   LOCAL oItem := oTV:GetSelected()
   IF oItem != NIL
      // oItem:cPrompt tiene la etiqueta
      // oItem:Cargo puede contener datos personalizados
      SayStatus( "Selected: " + oItem:cPrompt )
   ENDIF
RETURN NIL

Ejemplo 2: Árbol con Casillas de Verificación

@ 0.5, 0.5 TREEVIEW oTV OF oDlg ;
   SIZE 190, 220 PIXEL ;
   CHECKBOXES

oTV:Add( "Option A" )
oTV:Add( "Option B" )
oTV:Add( "Option C" )

// Más tarde, comprobar qué elementos están marcados:
FOR n := 1 TO Len( oTV:aItems )
   IF oTV:GetCheck( oTV:aItems[ n ] )
      ? "Checked:", oTV:aItems[ n ]:cPrompt
   ENDIF
NEXT

Ejemplo 3: Árbol Editable con Reordenamiento

@ 0.5, 0.5 TREEVIEW oTV OF oDlg ;
   SIZE 190, 220 PIXEL ;
   EDITABLE ;
   ON CHANGE { || UpdatePreview( oTV ) }

// Poblar el árbol
oTV:Add( "Chapter 1" )
oTV:Add( "Chapter 2" )
oTV:Add( "Chapter 3" )

// Editar la etiqueta del elemento seleccionado
@ 11, 1 BUTTON "Rename" OF oDlg SIZE 50, 14 ;
   ACTION oTV:EditLabel()

// Reordenar elementos
@ 11, 5.5 BUTTON "Move Up" OF oDlg SIZE 50, 14 ;
   ACTION oTV:SwapUp()
@ 11, 10 BUTTON "Move Down" OF oDlg SIZE 55, 14 ;
   ACTION oTV:SwapDown()

Consejos

  • Use Cargo en cada TVItem para almacenar datos asociados (IDs de registro, rutas de archivo, etc.).
  • La cláusula CHECKBOXES habilita casillas de verificación en todos los elementos. Use GetCheck()/SetCheck() para gestionar su estado.
  • Para árboles grandes, pueble los hijos de forma diferida en el callback bExpanded en lugar de cargar todo al inicio.
  • Llame a Rebuild() tras manipular elementos mediante programación (mover, sangrar, anular sangría) para sincronizar el árbol Win32.
  • Scan( bAction ) recorre cada elemento recursivamente -- útil para buscar o recopilar elementos marcados.
  • Use SetItemHeight() para elementos del árbol más grandes y adecuados para pantallas táctiles.

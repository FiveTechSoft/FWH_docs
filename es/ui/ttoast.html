TToast

Fuente: source/classes/ttoast.prg

Hereda de: TWindow

TToast proporciona notificaciones de tipo toast al estilo de Windows 8/10. Las notificaciones aparecen como ventanas superpuestas que se auto-posicionan en la esquina de la pantalla, se descartan automáticamente después de un tiempo configurable, y soportan texto de cabecera, cuerpo y pie junto con imágenes de mapa de bits opcionales. El control usa mezcla alfa para efectos suaves de transparencia y sombras.

Ejemplo: Notificación Toast

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "Toast Demo" SIZE 400, 300

   @ 20, 20 BUTTON "Show Toast" SIZE 120, 30 OF oWnd ;
      ACTION ShowToast()

   ACTIVATE WINDOW oWnd CENTERED

return nil

function ShowToast()

   // Show a notification at the bottom-right corner
   // Auto-dismisses after 5000 ms (default)
   TToast():NewToast( ;
      1, ;                     // Notification type
      "System Update##"; + ;   // Header (separated by ##)
      "Your system has been updated successfully." + ;
      "##Please restart to apply changes.", ; // Body
      "..\bitmaps\info.bmp", ; // Optional icon
      320, 120, ;              // Width, Height
      , , , , 5000, .F. )      // 5 sec timeout, bottom position

return nil

Notas

  • TToast usa el método estático NewToast() como su API principal. Crea, posiciona y muestra la ventana de notificación en una sola llamada.
  • El formato de texto usa ## como separador: la primera parte se convierte en la cabecera, la segunda parte en el cuerpo y la tercera parte (opcional) en el texto de pie.
  • En Windows 8 y posteriores, el estilo predeterminado es oscuro con la fuente Segoe MDL2 Assets. En sistemas antiguos, usa un tema claro con Tahoma.
  • La opacidad se controla mediante nLevel (0-255). La ventana usa WS_EX_LAYERED y LWA_ALPHA para la mezcla alfa.
  • Los toasts se apilan automáticamente: cada nuevo toast se posiciona encima del anterior. El array aTToast a nivel de clase rastrea todas las notificaciones activas.
  • Al hacer clic en el toast se invoca bReturn. El botón de cerrar (si está habilitado) descarta la notificación inmediatamente.

TListView

Control común ListView de Windows con iconos, detalles, grupos y vistas de mosaico

Fuente: source/classes/tlistvie.prg  |  Padre: TControl

Visión General

TListView envuelve el control común SysListView32 de Windows. A diferencia de TXBrowse (diseñado para navegar registros de bases de datos), TListView está diseñado para mostrar listas de elementos con iconos -- similar al listado de archivos del Explorador de Windows. Soporta cinco modos de vista, agrupación de elementos, listas de imágenes y selección de elementos.

Modos de Vista

ConstanteValorDescripción
LV_VIEW_ICON0Vista de iconos grandes -- elementos mostrados como iconos grandes con etiqueta debajo
LV_VIEW_DETAILS1Vista de detalles/informe -- elementos en filas con múltiples columnas
LV_VIEW_SMALLICON2Vista de iconos pequeños -- elementos como iconos pequeños dispuestos libremente
LV_VIEW_LIST3Vista de lista -- elementos como iconos pequeños en una lista vertical
LV_VIEW_TILE4Vista de mosaico -- elementos mostrados como mosaicos con icono y texto multilínea

Ejemplos de Código

Ejemplo 1: ListView Básico con Iconos

#include "FiveWin.ch"

FUNCTION TestListView()
   LOCAL oWnd, oLvw, oImgList

   DEFINE WINDOW oWnd TITLE "ListView Demo"

   // Crear una lista de imágenes de 32x32
   oImgList := TImageList():New( 32, 32 )
   oImgList:AddMasked( TBitmap():Define( "FOLDER",, oWnd ), CLR_MAGENTA )
   oImgList:AddMasked( TBitmap():Define( "FILE",,   oWnd ), CLR_MAGENTA )

   @ 0, 0 LISTVIEW oLvw OF oWnd ;
      PROMPTS "Documents", "Pictures", "Music", "Videos" ;
      ON CHANGE { || MsgInfo( "Selected: " + Str( oLvw:nOption ) ) } ;
      SIZE 400, 300 PIXEL

   oLvw:SetImageList( oImgList, 0 )  // LVSIL_NORMAL

   ACTIVATE WINDOW oWnd
RETURN NIL

Ejemplo 2: Vista de Detalles con Grupos

#include "FiveWin.ch"

FUNCTION TestListViewGroups()
   LOCAL oWnd, oLvw

   DEFINE WINDOW oWnd TITLE "ListView Groups"

   @ 0, 0 LISTVIEW oLvw OF oWnd SIZE 500, 400 PIXEL ;
      ON CHANGE { || ProcessItem( oLvw:nOption ) }

   // Cambiar a vista de detalles
   oLvw:SetStyle( 1 )   // LV_VIEW_DETAILS

   // Insertar grupos
   oLvw:InsertGroup( "Contacts" )
   oLvw:InsertGroup( "Suppliers" )

   // Habilitar encabezados de grupo
   oLvw:EnableGroupView()

   // Insertar elementos en grupos
   oLvw:InsertItem( 0, "John Smith",     0 )  // Grupo 0 = predeterminado
   oLvw:InsertItem( 0, "Jane Doe",       1 )  // Grupo 1 = Contactos
   oLvw:InsertItem( 0, "Acme Corp",      2 )  // Grupo 2 = Proveedores
   oLvw:InsertItem( 0, "Widget Inc",     2 )

   ACTIVATE WINDOW oWnd
RETURN NIL

Ejemplo 3: Cambio de Modos de Vista

// Agregar un combobox para cambiar modos de vista
@ 0, 0 COMBOBOX oCbx ITEMS { "Large Icons", "Details", ;
   "Small Icons", "List", "Tiles" } ;
   OF oWnd SIZE 150, 200 PIXEL ;
   ON CHANGE { || oLvw:SetStyle( oCbx:nAt - 1 ) }

Consejos

  • Para navegar bases de datos con ordenamiento, filtrado y edición, use TXBrowse en su lugar.
  • TListView es más adecuado para selección basada en iconos (exploradores de archivos, galerías de imágenes, listas de opciones).
  • Llame a EnableGroupView() después de insertar grupos para hacer visibles los encabezados de grupo.
  • El parámetro nImageIndex en InsertItem() está basado en 0 (coincidiendo con el índice de la lista de imágenes).
  • Use SetIconSpacing() para controlar el espacio entre elementos en el modo de vista de iconos.

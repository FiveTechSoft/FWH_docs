TMsgBar / TMsgItem

Fuentes: source/classes/msgbar.prg, source/classes/tmsgitem.prg

TMsgBar hereda de TControl; TMsgItem es una clase auxiliar

TMsgBar es un reemplazo de barra de estado con temas que admite elementos interactivos incrustados (reloj, fecha, indicadores de teclado y botones de acción personalizados). Ofrece estilos visuales Office 2007/2010/2015 y alineación de texto centrada. TMsgItem define elementos individuales incrustables dentro de un TMsgBar.

Ejemplo: Barra de Mensajes con Reloj y Elemento Personalizado

#include "FiveWin.ch"

function Main()

   local oWnd, oMsgBar, oItem

   DEFINE WINDOW oWnd TITLE "TMsgBar Demo" SIZE 600, 400

   DEFINE MSGBAR oMsgBar OF oWnd PROMPT "Ready" ;
      2010 CLOCK DATE KEYBOARD

   // Agregar un elemento personalizado cliqueable
   oItem := TMsgItem():New( oMsgBar, "Records: 0", 120 )
   oItem:bAction := {|| MsgInfo( "Status clicked!" ) }
   oMsgBar:AddItem( oItem )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TMsgBar admite temas visuales mediante los indicadores l2007, l2010 y l2015. Solo debe estar habilitado un tema a la vez.
  • Las cláusulas CLOCK, DATE y KEYBOARD (o los métodos correspondientes) agregan indicadores de sistema estándar. El reloj y la fecha se actualizan automáticamente mediante un temporizador interno.
  • TMsgItem admite mapas de bits de dos estados (hBitmap1 para "encendido", hBitmap2 para "apagado"), útiles para indicadores de alternancia. Establezca lActive para cambiar entre ellos.
  • Use ShowPopup() para adjuntar un menú emergente a un elemento, permitiendo acciones sensibles al contexto cuando el usuario hace clic en el elemento.
  • TMsgBar se usa típicamente como oWnd:oMsgBar y reemplaza el tradicional oWnd:oStatusBar en aplicaciones con temas.

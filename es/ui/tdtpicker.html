TDatePick

Fuente: source/classes/tdtpicke.prg

Hereda de: TControl

TDatePick wraps the Windows date and time picker common control (SysDateTimePick32). It provides a drop-down calendar for date selection and supports both date-only and date-time modes with configurable display formats, range restrictions, and multi-select capability.

Sintaxis del Comando

@ nRow, nCol DTPICKER oDtp VAR dDate SIZE nW, nH PIXEL OF oWnd ;
   PICTURE cFmt ON CHANGE bBlock

Ejemplos

Selector de Fecha con Formato

#include "FiveWin.ch"

function Main()

   local oWnd, oDtp, dDate := Date()

   DEFINE WINDOW oWnd TITLE "Date Picker Demo" SIZE 350, 200

   @ 40, 30 DTPICKER oDtp VAR dDate SIZE 120, 22 PIXEL OF oWnd ;
      PICTURE "dd/mm/yyyy" ;
      ON CHANGE MsgInfo( DToC( dDate ), "Date Changed" )

   oDtp:SetRange( Date() - 365, Date() + 365 )

   @ 100, 30 BUTTON "&Get Date" SIZE 80, 25 PIXEL OF oWnd ;
      ACTION MsgInfo( DToC( oDtp:GetDate() ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Selector de Fecha-Hora

#include "FiveWin.ch"

function Main()

   local oWnd, oDtp, tDateTime := DateTime()

   DEFINE WINDOW oWnd TITLE "DateTime Picker" SIZE 350, 200

   @ 40, 30 DTPICKER oDtp VAR tDateTime SIZE 180, 22 PIXEL OF oWnd ;
      PICTURE "dd/mm/yyyy HH:MM:SS"

   @ 100, 30 BUTTON "&Show" SIZE 80, 25 PIXEL OF oWnd ;
      ACTION MsgInfo( DToC( oDtp:GetDate() ), "Selected" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Cuando la variable enlazada es de tipo T (DateTime), el control cambia automáticamente al modo fecha-hora (lDateTime := .T.) y muestra la porción de hora.
  • La cláusula PICTURE acepta cadenas de formato de fecha/hora estándar: dd/mm/yyyy, mm/dd/yyyy, yyyy-mm-dd, y añadiendo HH:MM:SS para visualización de hora.
  • Use SetRange() para restringir el rango de fechas que el usuario puede seleccionar. El calendario desplegable atenuará las fechas fuera de este rango.
  • El método Open() abre programáticamente el calendario MonthCal desplegable, lo cual es útil para flujos de validación o re-selección.
  • Las opciones de selección múltiple (lMultiSelect, lWeekNumbers) aplican al calendario desplegable y se establecen antes de crear el control.

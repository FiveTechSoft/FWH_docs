TCalendar

Fuente: source/classes/tcalenda.prg

Hereda de: TControl

TCalendar wraps the Windows month calendar common control for date selection. It supports single and multi-select date ranges, week number display, day state highlighting, today indicator suppression, and extensive color customization of all calendar elements.

Ejemplo: Calendario con Callback de Cambio

#include "FiveWin.ch"

function Main()

   local oWnd, oCal, dDate := Date()

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 400, 350

   @ 20, 20 CALENDAR oCal VAR dDate OF oWnd SIZE 350, 250 ;
      ON CHANGE MsgInfo( DToC( dDate ), "Date Selected" )

   oCal:lWeekNumbers := .T.
   oCal:SetColor( MCSC_TITLEBK, CLR_BLUE )
   oCal:SetColor( MCSC_TITLETEXT, CLR_WHITE )
   oCal:SetFirstDayOfWeek( 1 )  // Monday

   @ 300, 20 BUTTON "&OK" SIZE 60, 25 PIXEL OF oWnd ;
      ACTION ( MsgInfo( DToC( dDate ) ), oWnd:End() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

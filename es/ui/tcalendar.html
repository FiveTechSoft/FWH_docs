TCalendar

Fuente: source/classes/tcalenda.prg

Hereda de: TControl

TCalendar envuelve el control común de calendario mensual de Windows para selección de fechas. Admite rangos de fechas de selección única y múltiple, visualización de número de semana, resaltado de estado de día, supresión del indicador de hoy y amplia personalización de color de todos los elementos del calendario.

Sintaxis del Comando

@ nRow, nCol CALENDAR oCal VAR dDate OF oWnd SIZE nW, nH ON CHANGE bBlock

Ejemplo: Calendar with Change Callback

#include "FiveWin.ch"

function Main()

   local oWnd, oCal, dDate := Date()

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 400, 350

   @ 20, 20 CALENDAR oCal VAR dDate OF oWnd SIZE 350, 250 ;
      ON CHANGE MsgInfo( DToC( dDate ), "Date Selected" )

   oCal:lWeekNumbers := .T.
   oCal:SetColor( MCSC_TITLEBK, CLR_BLUE )
   oCal:SetColor( MCSC_TITLETEXT, CLR_WHITE )
   oCal:SetFirstDayOfWeek( 1 )  // Monday

   @ 300, 20 BUTTON "&OK" SIZE 60, 25 PIXEL OF oWnd ;
      ACTION ( MsgInfo( DToC( dDate ) ), oWnd:End() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

TRichEdit

Fuente: source/classes/trichedi.prg  |  Padre: TControl

TRichEdit envuelve el control RichEdit20A de Windows, proporcionando un editor RTF completo. Soporta formato negrita/cursiva/subrayado, cambios de fuente y color, alineación de párrafo, listas con viñetas, imágenes incrustadas mediante OLE, buscar/reemplazar, zoom, deshacer/rehacer e impresión/vista previa/exportación PDF.

Ejemplo: Editor RTF

#include "FiveWin.ch"
#include "RichEdit.ch"

FUNCTION RichEditDemo()
   LOCAL oDlg, oRTF, cText := ""

   DEFINE DIALOG oDlg TITLE "Rich Text Editor" SIZE 600, 450

   @ 0.5, 0.5 RICHEDIT oRTF VAR cText OF oDlg ;
      SIZE 280, 180 PIXEL

   // Botones de barra de herramientas para formato
   @ 8, 0.5 BUTTON "Bold"      OF oDlg SIZE 50, 14 ;
      ACTION oRTF:SetBold( .T. )
   @ 8, 5   BUTTON "Italic"    OF oDlg SIZE 50, 14 ;
      ACTION oRTF:SetItalic( .T. )
   @ 8, 9.5 BUTTON "Underline" OF oDlg SIZE 60, 14 ;
      ACTION oRTF:SetUnderline( .T. )

   // Cargar y guardar
   @ 10, 0.5 BUTTON "Open RTF" OF oDlg SIZE 60, 14 ;
      ACTION ( cFile := cGetFile( "*.rtf", "Open RTF" ), ;
               If( !Empty(cFile), oRTF:LoadFromRTFFile( cFile ), ) )

   @ 10, 6  BUTTON "Save RTF" OF oDlg SIZE 60, 14 ;
      ACTION oRTF:SaveToRTFFile( cGetNewFile( "*.rtf", "Save RTF" ) )

   @ 10, 12 BUTTON "Print" OF oDlg SIZE 50, 14 ;
      ACTION oRTF:Print( "RichEdit Document" )

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

TScintilla

Fuente: source/classes/scintila.prg  |  Padre: TControl

TScintilla envuelve el componente editor Scintilla, proporcionando un editor de código fuente profesional con resaltado de sintaxis, plegado de código, números de línea, marcadores, coincidencia de llaves, autocompletado y soporte multidocumento. Es el motor de editor utilizado en el IDE de FiveWin.

Para los detalles completos de TScintilla, consulte la página dedicada de TScintilla.

Consejos

  • Use TRichEdit para edición de documentos, redacción de cartas/memos y cualquier escenario que requiera texto formateado.
  • Use TScintilla para editores de código fuente, editores de scripts y editores de archivos de configuración.
  • TRichEdit soporta el modo HIGHLIGHT para resaltado de sintaxis básico de código Harbour, pero TScintilla es mucho más potente.
  • TScintilla requiere SciLexer.dll (o Scintilla.dll) para estar disponible en tiempo de ejecución.
  • Para TRichEdit, llame a SetZoom(2, 1) para zoom al 200% -- útil para pantallas de alta densidad.
  • Ambos controles soportan ON CHANGE para detectar modificaciones en tiempo real.

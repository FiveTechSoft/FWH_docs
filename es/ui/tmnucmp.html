TMnuComp

Fuente: source/classes/tmnucomp.prg

Hereda de: TComponent

TMnuComp es un componente no visual que envuelve un objeto TMenu en el marco de TComponent para su uso en el diseñador de formularios VisualFW. Permite diseñar, manipular y persistir menús dentro del entorno del diseñador visual junto con controles visuales. El componente crea un menú predeterminado con elementos de ejemplo y lo registra en la ventana padre.

Miembros DATA Principales

DATATipoDescripción
oMenuTMenuEl objeto TMenu envuelto
cResBmpCharacterNombre opcional de recurso de mapa de bits para el menú
cVarNameCharacterNombre de variable utilizado en el diseñador (de CLASSDATA aProperties)

Métodos

MétodoDescripción
New( nRow, nCol, oWnd, lDesign, oObject, cResBmp )Crear un componente de menú, envolver el TMenu y adjuntarlo a la ventana
aItems( aNewItems )Método SETGET; reemplaza todos los elementos del menú con un nuevo array de definiciones
Destroy()Finalizar el menú envuelto, desvincularlo de la ventana y destruir el componente

Ejemplo: Componente de Menú en el Diseñador

#include "FiveWin.ch"

function Main()

   local oWnd, oMnuComp

   DEFINE WINDOW oWnd TITLE "VisualFW Designer" SIZE 800, 600

   // TMnuComp es instanciado típicamente por el diseñador VisualFW.
   // Aquí se muestra explícitamente:

   oMnuComp := TMnuComp():New( 0, 0, oWnd, .T., , "mybmp" )

   // oMnuComp:oMenu ahora es la barra de menú de la ventana
   // Reemplazar todos los elementos en tiempo de ejecución:

   oMnuComp:aItems := { "&File", "&Edit", "&View", "&Help" }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TMnuComp deriva de TComponent, no de TControl, por lo que no tiene representación visual en el formulario. Aparece como un componente no visual en la lista de componentes del diseñador.
  • El constructor New() crea un menú predeterminado con tres elementos de nivel superior (&One, &Two, T&hree) y un submenú. Esto sirve como marcador de posición en el diseñador.
  • El método SETGET aItems destruye el menú actual y lo reconstruye desde un array de cadenas. Cada cadena se convierte en un elemento de menú de nivel superior.
  • El parámetro cResBmp se pasa a TComponent:New() para la visualización opcional del icono en el diseñador.
  • En el entorno VisualFW, el diseñador serializa aProperties (aItems, cVarName) del componente para guardar/cargar definiciones de formularios.

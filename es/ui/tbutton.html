TButton / TBtnBmp

Botones de pulsación estándar y botones con bitmap para diálogos y barras de herramientas

TButton

Fuente: source/classes/button.prg  |  Padre: TControl

TButton encapsula el control estándar de botón de pulsación de Windows. Es el elemento interactivo más básico -- un rectángulo con etiqueta que ejecuta una acción al hacer clic. Los botones pueden designarse como botón predeterminado (activado con Enter) o botón de cancelar (activado con Escape).

Propiedades de TButton

PropiedadTipoDescripción
bActionBlockBloque de código ejecutado cuando se hace clic en el botón
lDefaultLogicalSi es .T., este es el botón predeterminado (la tecla Enter lo activa)
lCancelLogicalSi es .T., este es el botón de cancelar (la tecla Escape lo activa)
cCaptionStringTexto mostrado en la cara del botón
lProcessingLogicalProtección interna contra reentrada -- evita que los dobles clics disparen la acción dos veces

Métodos de TButton

MétodoDescripción
New( nRow, nCol, cCaption, oWnd, bAction, nWidth, nHeight, ... )Constructor. Crea un nuevo botón en la posición indicada.
ReDefine( nId, bAction, oWnd, ... )Redefine un botón desde un recurso de diálogo (archivo RC).
Click()Dispara programáticamente la acción del botón.
SetFocus()Mueve el foco de teclado a este botón.

TBtnBmp

Fuente: source/classes/btnbmp.prg  |  Padre: TControl

TBtnBmp es un botón con bitmap dibujado por el propietario que soporta múltiples estados visuales (normal, presionado, ratón encima, deshabilitado). Es el tipo de botón utilizado en las barras de herramientas (TButtonBar) y en cualquier lugar donde se necesiten botones gráficos con iconos.

Propiedades de TBtnBmp

PropiedadTipoDescripción
cResNameStringNombre del recurso para el bitmap del botón
cBmpFileStringRuta a un archivo BMP/PNG externo para la imagen del botón
bActionBlockBloque de código ejecutado al hacer clic
lBtnUpLogicalEstado actual de presión (interno)
lGroupLogicalSi es .T., inicia un nuevo grupo de botones en la barra de herramientas
lPressedLogicalPara botones tipo toggle, indica el estado activado
cToolTipStringTexto del tooltip mostrado al pasar el ratón
lFlatLogicalApariencia plana (borde solo al pasar el ratón)

Sintaxis de Comando TBtnBmp

@ nRow, nCol BTNBMP oBtn ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ACTION codeblock ] ;
   [ FILENAME cBmpFile | RESOURCE cResName ] ;
   [ TOOLTIP cText ] ;
   [ FLAT ] ;
   [ PROMPT cText ] ;
   [ WHEN bWhen ]

BUTTONBAR (Barra de Herramientas)

El comando DEFINE BUTTONBAR crea un contenedor TButtonBar que aloja botones TBtnBmp como barra de herramientas en la parte superior de una ventana.

DEFINE BUTTONBAR oBar OF oWnd SIZE nBtnW, nBtnH [ 2007 | 2010 | 2013 | 2015 ]

DEFINE BUTTON oBtn1 OF oBar ;
   RESOURCE "NEW" ;
   TOOLTIP "New record" ;
   ACTION NewRecord()

DEFINE BUTTON oBtn2 OF oBar ;
   RESOURCE "EDIT" ;
   TOOLTIP "Edit record" ;
   ACTION EditRecord()

DEFINE BUTTON oBtn3 OF oBar ;
   RESOURCE "PRINT" ;
   TOOLTIP "Print report" ;
   ACTION PrintReport() ;
   GROUP                      // visual separator before this button

Ejemplos de Código

Ejemplo 1: Botones Estándar en Diálogo

#include "FiveWin.ch"

FUNCTION TestButtons()
   LOCAL oDlg, oBtn1, oBtn2

   DEFINE DIALOG oDlg TITLE "Button Demo" SIZE 400, 250

   @ 2, 2 BUTTON oBtn1 PROMPT "&Save" ;
      OF oDlg SIZE 80, 25 ;
      ACTION ( MsgInfo( "Saved!" ), oDlg:End() ) ;
      DEFAULT

   @ 2, 12 BUTTON oBtn2 PROMPT "&Cancel" ;
      OF oDlg SIZE 80, 25 ;
      ACTION oDlg:End() ;
      CANCEL

   // A button with a WHEN clause -- disabled until data is valid
   @ 4, 2 BUTTON PROMPT "&Delete" ;
      OF oDlg SIZE 80, 25 ;
      ACTION DeleteRecord() ;
      WHEN ( !Empty( cRecId ) )

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

Ejemplo 2: Botones con Bitmap

#include "FiveWin.ch"

FUNCTION TestBmpButtons()
   LOCAL oWnd, oBtn

   DEFINE WINDOW oWnd TITLE "Bitmap Button Demo"

   // Bitmap button from a file
   @ 2, 2 BTNBMP oBtn OF oWnd ;
      SIZE 120, 40 ;
      FILENAME "..\bitmaps\save.bmp" ;
      PROMPT "Save" ;
      ACTION MsgInfo( "Saving..." ) ;
      FLAT

   // Bitmap button from a resource
   @ 5, 2 BTNBMP OF oWnd ;
      SIZE 120, 40 ;
      RESOURCE "PRINT" ;
      PROMPT "Print" ;
      ACTION PrintReport() ;
      TOOLTIP "Print current report"

   ACTIVATE WINDOW oWnd
RETURN NIL

Ejemplo 3: Barra de Herramientas Completa

#include "FiveWin.ch"

FUNCTION Main()
   LOCAL oWnd, oBar

   DEFINE WINDOW oWnd TITLE "Application with Toolbar"

   DEFINE BUTTONBAR oBar OF oWnd SIZE 56, 56 2015

   DEFINE BUTTON OF oBar ;
      RESOURCE "NEW"   TOOLTIP "New"   ACTION NewDoc()
   DEFINE BUTTON OF oBar ;
      RESOURCE "OPEN"  TOOLTIP "Open"  ACTION OpenDoc()
   DEFINE BUTTON OF oBar ;
      RESOURCE "SAVE"  TOOLTIP "Save"  ACTION SaveDoc()

   DEFINE BUTTON OF oBar ;
      RESOURCE "PRINT" TOOLTIP "Print" ACTION PrintDoc() GROUP

   DEFINE BUTTON OF oBar ;
      RESOURCE "HELP"  TOOLTIP "Help"  ACTION HelpDoc() GROUP

   SET MESSAGE OF oWnd TO "Ready" CENTERED

   ACTIVATE WINDOW oWnd
RETURN NIL

Consejos

  • Usa & en el PROMPT para definir una tecla aceleradora: "&Save" hace que Alt+S active el botón.
  • Solo un botón por diálogo debe ser DEFAULT y uno debe ser CANCEL.
  • Para una apariencia moderna de la barra de herramientas, usa el estilo 2015 en DEFINE BUTTONBAR.
  • TBtnBmp soporta archivos PNG con transparencia alfa para iconos de alta calidad.
  • Usa la cláusula GROUP para insertar un separador visual entre grupos lógicos de botones de la barra de herramientas.

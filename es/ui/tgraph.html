TGraph

Fuente: source/classes/tgraph.prg

Hereda de: TControl

TGraph es el control de gráficos de FiveWin que soporta gráficos de barras, líneas, puntos, circulares y de dispersión XY. Proporciona un conjunto completo de capacidades de graficación directamente dentro de ventanas y diálogos de FiveWin, con soporte para múltiples series, renderizado 3D, leyendas, líneas de cuadrícula y exportación a imagen o impresora.

Tipos de Gráfico

TGraph soporta los siguientes tipos de gráfico, definidos como constantes numéricas:

ConstanteValorDescripción
GRAPH_TYPE_BAR1Gráfico de barras vertical (predeterminado)
GRAPH_TYPE_LINE2Gráfico de líneas conectando puntos de datos
GRAPH_TYPE_POINT3Gráfico de puntos/dispersión
GRAPH_TYPE_PIE4Gráfico circular
GRAPH_TYPE_XY_LINES6Gráfico de dispersión XY con líneas conectoras
GRAPH_TYPE_XY_POINTS7Gráfico de dispersión XY solo con puntos

Ejemplo: Gráfico de Barras con Dos Series

#include "FiveWin.ch"

function Main()

   local oWnd, oGraph

   DEFINE WINDOW oWnd TITLE "Quarterly Sales" SIZE 600, 400

   @ 10, 10 GRAPH oGraph SIZE 560, 340 OF oWnd TYPE GRAPH_TYPE_BAR ;
      TITLE "Sales by Quarter"

   oGraph:l3D      := .T.
   oGraph:lxGrid   := .T.
   oGraph:lyGrid   := .T.
   oGraph:lxVal    := .T.
   oGraph:lyVal    := .T.
   oGraph:lLegends := .T.
   oGraph:cPicture := "999,999.99"

   // Set category labels
   oGraph:SetYVals( { "Q1", "Q2", "Q3", "Q4" } )

   // Add two series
   oGraph:AddSerie( { 1200, 1500, 1100, 1800 }, "Product A", CLR_RED )
   oGraph:AddSerie( { 900, 1300, 1600, 1400 }, "Product B", CLR_BLUE )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TGraph es un motor de gráficos completamente autónomo que no depende de componentes ActiveX o OCX externos. Todo el renderizado se realiza mediante GDI.
  • Use la sintaxis del comando GRAPH con TYPE nType para establecer el tipo de gráfico en el momento de la creación.
  • Los colores para las series se asignan automáticamente desde una paleta interna si no se especifican. La paleta predeterminada recorre METRO_AMBER, METRO_OLIVE, CLR_HMAGENTA, CLR_HBLUE, CLR_HRED, CLR_HGREEN y colores estándar.
  • Los gráficos XY (tipos 6 y 7) esperan datos como arrays de pares de coordenadas { x, y }. Use AddXYSerie() para añadir series XY.
  • La exportación a imagen usa Save2Bmp() internamente. El gráfico también se puede copiar al portapapeles para pegarlo en otras aplicaciones.
  • El menú emergente (habilitado mediante lPopUp) proporciona acceso con clic derecho para cambiar el tipo de gráfico, alternar cuadrículas y opciones de exportación en tiempo de ejecución.

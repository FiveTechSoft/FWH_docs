TBar

Fuente: source/classes/bar.prg

Hereda de: TControl

TBar es un contenedor de barra de botones que muestra una franja horizontal o vertical de botones de mapa de bits con separadores de grupo opcionales. Admite múltiples estilos visuales, incluidos 3D plano, los temas de Office 2007/2010/2013/2015, renderizado GDI+, tema oscuro y barras de herramientas flotantes/acoplables.

Ejemplo: Barra Superior con 3 Botones

#include "FiveWin.ch"

function Main()

   local oWnd, oBar

   DEFINE WINDOW oWnd TITLE "Button Bar Demo" SIZE 600, 400

   oBar := TBar():New( oWnd, 32, 32,, "TOP" )

   oBar:Add( TButtonBmp():New(,, "New", oWnd,, 32, 32,,, .F., .F.,,,,, "new.bmp" ) )
   oBar:Add( TButtonBmp():New(,, "Open", oWnd,, 32, 32,,, .F., .F.,,,,, "open.bmp" ) )
   oBar:Add( TButtonBmp():New(,, "Save", oWnd,, 32, 32,,, .F., .F.,,,,, "save.bmp" ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TBar se autodimensiona para ajustarse al ancho de su ventana padre (superior/inferior) o a su alto (izquierda/derecha).
  • Use el parámetro cMode para establecer el acoplamiento inicial: "TOP", "LEFT", "RIGHT", "BOTTOM" o "FLOAT".
  • El miembro de datos l97Look controla la apariencia de botón plano compatible con versiones anteriores. Manténgalo como NIL para el renderizado moderno de botones.
  • Los temas de Office (l2007, l2010, l2013, l2015) son mutuamente excluyentes; habilite solo uno.
  • TBar admite menús contextuales con el botón derecho para la personalización en tiempo de ejecución.

TSay

Fuente: source/classes/say.prg

Hereda de: TControl

TSay renderiza texto estático dentro de una ventana o diálogo. Es el control estándar para etiquetas, avisos y visualización de texto de solo lectura. TSay admite enlace de datos mediante bSetGet, actualización automática cuando la variable vinculada cambia, cláusulas picture para salida formateada, efectos 3D (elevados o hundidos), fondos transparentes, estilos de borde y texto tooltip. Es uno de los controles más utilizados en aplicaciones FiveWin.

Miembros DATA Principales

DATATipoDescripción
bSetGetBlockBloque de código de enlace de datos. Cuando el say se actualiza, el bloque se evalúa y el resultado se convierte en el texto mostrado.
cPictureCharacterCláusula picture para salida formateada (ej. "999,999.99", "@!" para mayúsculas).
nClrBorderNumericColor del borde cuando lBorder es .T. (valor RGB).
bClrTextBlockBloque de código que devuelve un valor de color. Evaluado en tiempo de pintura para admitir colores de texto dinámicos.
l3DLogicalSi es .T., el texto se renderiza con un efecto 3D (elevado o grabado).
lAdjustLogicalSi es .T., el tamaño del control se ajusta automáticamente para ajustarse al contenido del texto.
lBorderLogicalSi es .T., se dibuja un borde alrededor del control say.
nClrTextNumericColor de primer plano del texto (valor RGB).
nClrPaneNumericColor de relleno de fondo (valor RGB).
cCaptionCharacterTexto mostrado actualmente.

Métodos

MétodoDescripción
New( nRow, nCol, bText, oWnd, nClrT, nClrP, oFont, lPixel, lDesign, lTransparent, cMsg, lUpdate, cPict, lBorder, lAdjust, oToolTip, nClrBorder )Crear un nuevo control say. bText es una cadena fija o bloque de código que devuelve el texto. El say se crea inmediatamente como hijo de oWnd.
ReDefine( nId, bText, oWnd )Redefinir un say desde un recurso de diálogo. Se enlaza a un control estático Win32 existente por su ID de control.
SetText( cText )Cambiar el texto mostrado directamente (anula bSetGet).
Refresh()Re-evaluar el texto vinculado a datos y repintar el control. Si bSetGet está establecido, el bloque se re-evalúa.
SetColor( nClrText, nClrPane )Cambiar los colores de texto y fondo dinámicamente.
SetFont( oFont )Asignar una nueva fuente al control say.
End()Destruir el control y eliminarlo de aControls del padre.

Comandos: @ ... SAY

@ nRow, nCol SAY oSay ;
   PROMPT cText | VAR cVar ;
   SIZE nW, nH ;
   [ OF oDlg ] ;
   [ COLOR nClrText, nClrPane ] ;
   [ FONT oFont ] ;
   [ PICTURE cPict ] ;
   [ TRANSPARENT ] ;
   [ 3D ] [ NO3D ] ;
   [ BORDER ] ;
   [ ADJUST ] ;
   [ UPDATE ] ;
   [ TOOLTIP cTip ]

Ejemplo: Say de Actualización Automática desde Variable

#include "FiveWin.ch"

function Main()

   local oWnd, oSay, nCounter := 0

   DEFINE WINDOW oWnd TITLE "TSay Demo" SIZE 400, 200

   // Aviso estático
   @ 30, 20 SAY "Counter:" OF oWnd SIZE 60, 12

   // Say vinculado a datos que se actualiza automáticamente
   @ 30, 90 SAY oSay VAR nCounter OF oWnd ;
      SIZE 100, 20 UPDATE PICTURE "999,999"

   @ 100, 20 BUTTON "Increment" OF oWnd SIZE 100, 30 ;
      ACTION ( nCounter++, oSay:Refresh() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TSay hereda de TControl, que hereda de TWindow. Todos los métodos de control estándar están disponibles.
  • Use la cláusula UPDATE (o establezca lUpdate := .T.) para que el say se actualice automáticamente cuando se llame a oWnd:Update(), lo cual es útil para visualizaciones de campos de base de datos que deben actualizarse cuando el puntero de registro se mueve.
  • La cláusula VAR (a diferencia de PROMPT) crea un bloque de código bSetGet vinculado a una variable Harbour. El say muestra el valor actual de la variable.
  • La cláusula PICTURE aplica formato al valor mostrado, siguiendo la sintaxis de función picture de Harbour (ej. "999,999.99" para formato numérico, "@!" para mayúsculas).
  • Establezca TRANSPARENT cuando el say se coloca sobre un fondo degradado o de mapa de bits. Sin ello, el say dibuja un fondo opaco que puede ocultar el fondo del padre.
  • El efecto 3D dibuja el texto con una sombra desplazada un píxel, creando una apariencia elevada o grabada. Use NO3D para texto plano.

TWebcam

Fuente: source/classes/twebcam.prg

Jerarquía: TWebcam → TControl

TWebcam proporciona funcionalidad de vista previa y captura de cámara web en vivo usando la API de Video for Windows (VFW). Es un control visual que muestra la transmisión de la cámara dentro de una ventana de FiveWin y soporta captura de instantáneas, diálogos de formato de video y configuración de fuente de video.

Comando WEBCAM

@ nRow, nCol WEBCAM oCam OF oWnd SIZE nW, nH INIT lInit

Métodos Principales

MétodoDescripción

Initialize()Conectar el controlador de la cámara web e iniciar la vista previa en vivo.

VideoFormat()Abrir el diálogo de formato de video (resolución, profundidad de color).

StopCapture()Detener cualquier captura de video en curso.
GetWidth()Devolver el ancho actual de la imagen de vista previa en píxeles.
GetHeight()Devolver la altura actual de la imagen de vista previa en píxeles.
SetRate( nRate )Establecer la tasa de actualización de vista previa en milisegundos.

Ejemplo: Vista Previa en Vivo con Captura

#include "FiveWin.ch"

function Main()

   local oWnd, oCam, lInit := .T.

   DEFINE WINDOW oWnd TITLE "Webcam Capture" ;
      SIZE 800, 600

   @ 10, 10 WEBCAM oCam OF oWnd SIZE 640, 480 INIT lInit

   @ 500, 10 BUTTON "&Snapshot" SIZE 60, 25 ;
      ACTION oCam:SaveFile( "snap.bmp" )

   @ 500, 80 BUTTON "&Format" SIZE 60, 25 ;
      ACTION oCam:VideoFormat()

   @ 500, 150 BUTTON "&Controls" SIZE 60, 25 ;
      ACTION oCam:VideoControl()

   @ 500, 220 BUTTON "&Close" SIZE 60, 25 ;
      ACTION oWnd:End()

   ACTIVATE WINDOW oWnd ;
      ON INIT oCam:Initialize() ;
      VALID ( oCam:Finalize(), .T. )

return nil

Notas

  • TWebcam depende de la API heredada VFW (Video for Windows). Funciona en todas las versiones de Windows de 32 y 64 bits a través de las bibliotecas de sistema avicap32.dll y msvfw32.dll.
  • El control debe crearse antes de que se active la ventana padre; use la cláusula INIT o llame a Initialize() manualmente desde ON INIT.
  • Las instantáneas se guardan como archivos BMP de 24 bits por defecto.
  • Use GetVideoCapDriver() (una función de utilidad en twebcam.prg) para enumerar los dispositivos de cámara web disponibles.
  • Los eventos de error se enrutan a través del bloque de código bError. El manejador predeterminado muestra un diálogo MsgAlert.

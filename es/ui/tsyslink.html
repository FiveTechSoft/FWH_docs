TSysLink

Fuente: source/classes/tsyslink.prg

Hereda de: TControl

TSysLink encapsula el control común SysLink de Windows (Vista+), proporcionando hipervínculos en los que se puede hacer clic dentro de los diálogos. Se pueden incrustar múltiples enlaces en una sola cadena de texto utilizando etiquetas <a> al estilo HTML. Los enlaces abren URLs en el navegador predeterminado o disparan bloques de código de Harbour.

Miembros DATA Clave

DATATipoDescripción
cTextCarácterTexto mostrado con etiquetas <a> que definen las regiones de enlace
cUrlCarácterURL que se abre al hacer clic en un enlace
nLinkIdNuméricoÍndice del último enlace en el que se hizo clic

Métodos

MétodoDescripción
New( nRow, nCol, oWnd, cText, cUrl, nW, nH, lPixel, lDesign, cMsg, bWhen, bClick, lTransparent, ... )Crea un nuevo control SysLink
ReDefine( nId, oWnd, cText, cUrl )Redefine desde un recurso de diálogo
SetText( cText ) / GetText()Cambia o recupera el texto del enlace
HitTest( nX, nY )Comprueba qué enlace se encuentra en las coordenadas dadas
GetIdealHeight( nWidth )Devuelve la altura ideal para un ancho dado
SetItem( nIndex, cUrl, nState ) / GetItem( nIndex )Modifica o consulta elementos de enlace individuales

Comandos

@ nRow, nCol SYSLINK oLink TEXT cText OF oWnd

Ejemplo: Múltiples Enlaces

#include "FiveWin.ch"
function Main()
   local oWnd, oLink
   DEFINE WINDOW oWnd TITLE "TSysLink Demo" SIZE 400, 200
   @ 20, 20 SYSLINK oLink TEXT ;
      "Visit <a href=""https://www.fivetechsoft.com"">FiveTech</a> " + ;
      "and <a href=""https://github.com"">GitHub</a>" ;
      OF oWnd
   ACTIVATE WINDOW oWnd CENTERED
return nil

Notas

  • Requiere Windows Vista o posterior (el control SysLink no está disponible en versiones anteriores).
  • Las regiones de enlace se definen con etiquetas <a href="...">. Al hacer clic se abre la URL en el navegador predeterminado.
  • Use lTransparent := .T. para que el fondo coincida con el del diálogo padre.

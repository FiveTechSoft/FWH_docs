TStatusBar

Fuente: source/classes/statusba.prg

Hereda de: TControl

TStatusBar envuelve el control común de barra de estado de Windows para mostrar una barra de estado de varios paneles en la parte inferior de una ventana. Admite un número arbitrario de paneles con anchos y texto individuales, un reloj integrado y la visualización automática de mensajes con un tiempo de espera configurable.

Miembros DATA Principales

DATATipoDescripción
cMsgDefCarácterTexto de mensaje predeterminado de la barra de estado
oTimerObjetoTemporizador interno para el tiempo de espera del mensaje y las actualizaciones del reloj
nPartTimeNuméricoÍndice de panel reservado para la visualización del reloj

Métodos

MétodoDescripción
New( oWnd, cText, aWidths, aPrompts, lClock )Crea un nuevo control TStatusBar
SetMsg( cText )Establece el texto de la barra de estado (normalmente desde oWnd:SetMsg())
SetParts( aWidths )Define los anchos de los paneles como un array de valores numéricos
SetPartText( nPart, cText )Establece el texto de un panel específico por su índice
GetParts()Devuelve las definiciones actuales de ancho de los paneles
ClockOn()Habilita la visualización del reloj en el último panel

Ejemplo: Barra de Estado de 3 Paneles con Reloj

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "StatusBar Demo" SIZE 600, 400

   DEFINE STATUSBAR oWnd PROMPT "Ready" ;
      CLOCK ;
      PARTS 150, 300

   // Establecer texto en paneles individuales
   oWnd:oStatusBar:SetPartText( 2, "User: Admin" )
   oWnd:oStatusBar:SetPartText( 3, "Records: 42" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • La barra de estado se crea automáticamente en la parte inferior de la ventana. El comando DEFINE STATUSBAR proporciona la sintaxis más cómoda; TStatusBar():New() puede utilizarse para la creación programática.
  • Los anchos de los paneles en SetParts() se especifican como valores en píxeles. El último panel siempre se estira para llenar el espacio restante, independientemente de su ancho especificado.
  • La cláusula CLOCK (o ClockOn()) habilita un reloj en tiempo real en el panel más a la derecha, actualizado cada segundo mediante un temporizador interno.
  • Los mensajes establecidos mediante SetMsg() se muestran en el primer panel (el más a la izquierda). El mensaje vuelve automáticamente a cMsgDef tras el período de tiempo de espera definido por nPartTime.
  • TStatusBar utiliza el control común de barra de estado de Windows (msctls_statusbar32), que proporciona dimensionamiento y posicionamiento automáticos en la parte inferior de la ventana padre.

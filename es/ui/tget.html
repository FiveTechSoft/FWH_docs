TGet / TMGet

Controles de entrada de texto con formato PICTURE, validación y edición multilínea

Visión General de TGet

Fuente: source/classes/tget.prg  |  Padre: TControl

TGet es el equivalente en FiveWin del clásico comando GET de Clipper -- un control de entrada de texto de una sola línea que soporta máscaras PICTURE, bloques de validación y enlace de datos mediante bSetGet. Es la herramienta principal de los formularios de entrada de datos.

Visión General de TMGet

Fuente: source/classes/mget.prg  |  Padre: TControl

TMGet (también conocido como GET memo) proporciona edición de texto multilínea. Se utiliza para campos de texto libre como notas, comentarios y descripciones. Encapsula el control Windows EDIT con el estilo ES_MULTILINE.

Propiedades Principales de TGet

PropiedadTipoDescripción
bSetGetBlockBloque de enlace de datos. Eval( bSetGet ) lee el valor; Eval( bSetGet, x ) lo escribe.
cPictureStringMáscara PICTURE que controla el formato de entrada (ej. "@E 999,999.99", "@!", "99/99/9999")
bValidBlockBloque de validación evaluado cuando el usuario sale del GET. Debe devolver .T. para permitir la salida.
bWhenBlockBloque de condición evaluado al acercarse el foco. Si devuelve .F., el GET se omite (solo lectura).
lReadOnlyLogicalCuando es .T., el campo no es editable.
lPasswordLogicalCuando es .T., la entrada se enmascara con caracteres de viñeta.
cCueTextStringTexto de marcador de posición mostrado cuando el GET está vacío y sin foco (marca de agua).
lSpinnerLogicalCuando es .T., agrega flechas de incremento/decremento para entrada numérica.
nMinNumericValor mínimo para el spinner.
nMaxNumericValor máximo para el spinner.
bChangeBlockBloque evaluado cada vez que el texto cambia (actualización en vivo).
lRightLogicalAlinear el texto a la derecha (útil para campos numéricos).

Sintaxis de Comandos

GET de una sola línea

@ nRow, nCol GET oGet VAR cVar ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ PICTURE cMask ] ;
   [ VALID bValid ] ;
   [ WHEN bWhen ] ;
   [ READONLY ] ;
   [ PASSWORD ] ;
   [ SPINNER [ MIN nMin ] [ MAX nMax ] ] ;
   [ CUETEXT cPlaceholder ] ;
   [ ON CHANGE bChange ] ;
   [ FONT oFont ] ;
   [ RIGHT ]

Ejemplos de Código

Ejemplo 1: Formulario de Entrada con Varios Tipos de GET

#include "FiveWin.ch"

FUNCTION CustomerForm()
   LOCAL oDlg, oFont
   LOCAL cName   := Space( 30 )
   LOCAL cPhone  := Space( 14 )
   LOCAL nAge    := 0
   LOCAL dBirth  := CToD( "" )
   LOCAL cPass   := Space( 12 )
   LOCAL nSalary := 0
   LOCAL cNotes  := Space( 500 )

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14
   DEFINE DIALOG oDlg TITLE "Customer Entry" SIZE 480, 520 FONT oFont

   // Text input with uppercase mask
   @ 1.0, 1 SAY "Name:" OF oDlg
   @ 1.0, 6 GET cName OF oDlg SIZE 200, 22 ;
      PICTURE "@!" ;
      VALID ( !Empty( cName ) ) ;
      CUETEXT "Enter full name"

   // Phone with template mask
   @ 2.5, 1 SAY "Phone:" OF oDlg
   @ 2.5, 6 GET cPhone OF oDlg SIZE 140, 22 ;
      PICTURE "(999)999-9999"

   // Numeric with spinner
   @ 4.0, 1 SAY "Age:" OF oDlg
   @ 4.0, 6 GET nAge OF oDlg SIZE 80, 22 ;
      PICTURE "999" ;
      SPINNER MIN 0 MAX 120

   // Date field
   @ 5.5, 1 SAY "Birth Date:" OF oDlg
   @ 5.5, 6 GET dBirth OF oDlg SIZE 100, 22 ;
      PICTURE "99/99/9999"

   // Password field
   @ 7.0, 1 SAY "Password:" OF oDlg
   @ 7.0, 6 GET cPass OF oDlg SIZE 160, 22 ;
      PASSWORD

   // Numeric with European formatting
   @ 8.5, 1 SAY "Salary:" OF oDlg
   @ 8.5, 6 GET nSalary OF oDlg SIZE 140, 22 ;
      PICTURE "@E 9,999,999.99" ;
      RIGHT

   // Multi-line memo
   @ 10.0, 1 SAY "Notes:" OF oDlg
   @ 10.5, 1 GET cNotes MEMO OF oDlg SIZE 400, 100

   // Buttons
   @ 17, 6  BUTTON "&Save"   OF oDlg SIZE 80, 25 ACTION oDlg:End() DEFAULT
   @ 17, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   RELEASE FONT oFont
RETURN NIL

Ejemplo 2: GET Validado con WHEN Dinámico

#include "FiveWin.ch"

FUNCTION ValidatedForm()
   LOCAL oDlg
   LOCAL cCode    := Space( 5 )
   LOCAL cDesc    := Space( 40 )
   LOCAL nQty     := 0
   LOCAL nPrice   := 0
   LOCAL lApprove := .F.

   DEFINE DIALOG oDlg TITLE "Order Entry" SIZE 400, 300

   @ 1, 1 SAY "Code:" OF oDlg
   @ 1, 5 GET cCode OF oDlg SIZE 80, 22 ;
      PICTURE "@!" ;
      VALID ( ValidateCode( cCode, @cDesc ) )  // look up code, fill description

   @ 2.5, 1 SAY "Description:" OF oDlg
   @ 2.5, 5 GET cDesc OF oDlg SIZE 200, 22 READONLY

   @ 4.0, 1 SAY "Quantity:" OF oDlg
   @ 4.0, 5 GET nQty OF oDlg SIZE 80, 22 ;
      PICTURE "9999" ;
      SPINNER MIN 1 MAX 9999 ;
      VALID ( nQty > 0 )

   @ 5.5, 1 SAY "Price:" OF oDlg
   @ 5.5, 5 GET nPrice OF oDlg SIZE 100, 22 ;
      PICTURE "@E 99,999.99" ;
      WHEN ( !Empty( cCode ) )          // only enabled after valid code

   @ 7.5, 5 BUTTON "&OK" OF oDlg SIZE 80, 25 ;
      ACTION ( lApprove := .T., oDlg:End() ) DEFAULT

   @ 7.5, 14 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ;
      ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   IF lApprove
      // process the order...
   ENDIF
RETURN NIL

STATIC FUNCTION ValidateCode( cCode, cDesc )
   IF Empty( cCode )
      MsgStop( "Code is required." )
      RETURN .F.
   ENDIF
   // Look up in database
   cDesc := GetDescForCode( AllTrim( cCode ) )
   IF Empty( cDesc )
      MsgStop( "Code not found." )
      RETURN .F.
   ENDIF
RETURN .T.

Consejos y Buenas Prácticas

  • El bloque bSetGet se crea automáticamente con el comando GET var. Para enlazar a un campo: GET FieldWBlock( "NAME", Select() ).
  • Usa CUETEXT (marcador de posición) para dar al usuario una pista sobre el formato de entrada esperado.
  • El bloque bValid puede mostrar un mensaje y devolver .F. para impedir que el usuario salga del campo.
  • Para GETs numéricos, proporciona siempre un PICTURE para controlar los decimales y los separadores de miles.
  • La cláusula SPINNER agrega flechas de incremento/decremento; combínala con MIN/MAX para restringir el rango.
  • TMGet soporta HSCROLL para agregar una barra de desplazamiento horizontal, y NO WORDWRAP para deshabilitar el ajuste de línea.
  • Al usar GETs en un diálogo, FiveWin gestiona automáticamente el orden de tabulación según el orden de creación.

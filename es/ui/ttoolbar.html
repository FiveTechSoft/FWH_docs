TToolBar

Fuente: source/classes/toolbar.prg

Hereda de: TControl

TToolBar es un control de barra de herramientas que aloja botones de mapa de bits con tooltips, imágenes y estilos visuales modernos opcionales. Proporciona una franja acoplable de botones que normalmente se coloca en la parte superior de una ventana. TToolBar admite estilos de botón planos y 3D, listas de imágenes para los iconos de los botones y temas modernos (2007/2010/2013/2015).

Ejemplo: Barra de Herramientas con Tres Botones

#include "FiveWin.ch"

function Main()

   local oWnd, oToolBar, oImgList

   DEFINE WINDOW oWnd TITLE "TToolBar Demo" SIZE 600, 400

   oImgList := TImageList():New( 24, 24 )

   oToolBar := TToolBar():New( oWnd, 32, 32, oImgList, , , .T., , , , , , , .T. )

   oToolBar:AddButton( { || MsgInfo( "New" ) }, "Create a new document", "New" )
   oToolBar:AddButton( { || MsgInfo( "Open" ) }, "Open an existing file", "Open" )
   oToolBar:AddSeparator()
   oToolBar:AddButton( { || MsgInfo( "Save" ) }, "Save current document", "Save" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TToolBar crea automáticamente objetos TButton hijos por cada llamada a AddButton. Los valores nBtnWidth y nBtnHeight controlan el tamaño de todos los botones de forma uniforme.
  • Use l2007, l2010, l2013 o l2015 para aplicar temas modernos de botones planos. Solo un indicador de tema debe estar a .T. a la vez.
  • Cuando lTTBalloon es .T., los tooltips se muestran con el estilo de globo, con esquinas redondeadas y una cola en punta.
  • Establezca oImageList para proporcionar las imágenes de los iconos de los botones. El índice de imagen de cada botón corresponde a su posición en el array interno de botones de la barra de herramientas.
  • La barra de herramientas se acopla normalmente en la parte superior de la ventana usando oWnd:oTop := oToolBar tras su creación.

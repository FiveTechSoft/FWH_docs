TExplorerBar

Fuente: source/classes/texplbar.prg

Hereda de: TControl

TExplorerBar es un panel de tareas vertical estilo Outlook con secciones plegables y encabezados degradados. Cada sección está representada por un objeto hijo TTaskPanel que puede expandirse o contraerse haciendo clic en su barra de título. El panel admite desplazamiento vertical cuando el contenido excede el área visible, lo que lo hace adecuado para menús de navegación, listas de tareas y grupos de propiedades.

Sintaxis del Comando

@ nRow, nCol EXPLORERBAR oBar OF oWnd SIZE nW, nH

Ejemplo: Explorer Bar with Two Panels

#include "FiveWin.ch"

function Main()

   local oWnd, oBar, oPanel

   DEFINE WINDOW oWnd TITLE "Explorer Bar Demo" SIZE 300, 500

   @ 0, 0 EXPLORERBAR oBar OF oWnd SIZE 300, 500

   // "Documents" panel with 2 links
   oPanel = oBar:AddPanel( "Documents",, 60, 25 )
   oPanel:AddLink( "Open Recent", { || MsgInfo( "Recent docs" ) }, "fileopen.bmp" )
   oPanel:AddLink( "Browse Folders", { || MsgInfo( "Browse" ) }, "folders.bmp" )

   // "Tools" panel with 2 links
   oPanel = oBar:AddPanel( "Tools",, 60, 25 )
   oPanel:AddLink( "Settings", { || MsgInfo( "Settings" ) }, "settings.bmp" )
   oPanel:AddLink( "Help", { || MsgInfo( "Help" ) }, "help.bmp" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

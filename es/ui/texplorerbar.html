TExplorerBar

Fuente: source/classes/texplbar.prg

Hereda de: TControl

TExplorerBar es un panel de tareas vertical estilo Outlook con secciones colapsables y encabezados degradados. Cada sección está representada por un objeto hijo TTaskPanel que puede expandirse o colapsarse haciendo clic en su barra de título. El panel soporta desplazamiento vertical cuando el contenido excede el área visible, lo que lo hace adecuado para menús de navegación, listas de tareas y grupos de propiedades. Each section is represented by a TTaskPanel child object that can be expanded or collapsed by clicking its title bar. The panel supports vertical scrolling when content exceeds the visible area, making it suitable for navigation menus, task lists, and property groups.

Sintaxis del Comando

@ nRow, nCol EXPLORERBAR oBar OF oWnd SIZE nW, nH

Ejemplo: Barra Exploradora con Dos Paneles

#include "FiveWin.ch"

function Main()

   local oWnd, oBar, oPanel

   DEFINE WINDOW oWnd TITLE "Explorer Bar Demo" SIZE 300, 500

   @ 0, 0 EXPLORERBAR oBar OF oWnd SIZE 300, 500

   // "Documents" panel with 2 links
   oPanel = oBar:AddPanel( "Documents",, 60, 25 )
   oPanel:AddLink( "Open Recent", { || MsgInfo( "Recent docs" ) }, "fileopen.bmp" )
   oPanel:AddLink( "Browse Folders", { || MsgInfo( "Browse" ) }, "folders.bmp" )

   // "Tools" panel with 2 links
   oPanel = oBar:AddPanel( "Tools",, 60, 25 )
   oPanel:AddLink( "Settings", { || MsgInfo( "Settings" ) }, "settings.bmp" )
   oPanel:AddLink( "Help", { || MsgInfo( "Help" ) }, "help.bmp" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Use la sintaxis del comando EXPLORERBAR para crear la barra; los paneles se agregan programáticamente con AddPanel().
  • Hacer clic en la barra de título de un panel alterna su estado colapsado. El método CloseAll() colapsa todos los paneles excepto el especificado. The CloseAll() method collapses all panels except the specified one.
  • Cada panel puede mostrar un mapa de bits en su área de encabezado (especificado mediante cBmpName en AddPanel()).
  • Los enlaces dentro de los paneles son controles TUrlLink que soportan efectos de resaltado, tooltips y colores personalizados.
  • La barra gestiona automáticamente el desplazamiento vertical cuando los paneles se extienden más allá del área visible.
  • Los estilos visuales (l2007, l2010, l2013, l2015) ajustan la apariencia predeterminada para coincidir con la estética de la versión de Windows.

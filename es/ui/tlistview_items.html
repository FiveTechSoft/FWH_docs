TListViewItem

Fuente: source/classes/tlistvie.prg

Clase independiente (usada por TListView)

TListViewItem representa un elemento individual en un control TListView. Cada elemento puede mostrar texto, una imagen de una lista de imágenes y asignarse a un grupo para vistas categorizadas. Los elementos admiten tooltips, sangría y estado marcado.

Miembros DATA Principales

DATATipoDescripción
cTextCharacterTexto de visualización del elemento
nImageNumericÍndice en la lista de imágenes (0 = sin imagen)
nGroupNumericID del grupo al que pertenece este elemento
nItemNumericÍndice del elemento dentro de la vista de lista

Métodos

MétodoDescripción
New( oParent )Crear un nuevo elemento asociado a un TListView
Create( oParent )Insertar el elemento en la vista de lista
SetText( cText ) / GetText()Cambiar u obtener el texto del elemento
SetImage( nImage ) / GetImage()Cambiar u obtener el índice de imagen
SetGroup( nGroup )Asignar el elemento a un grupo

TListViewGroup

Clase independiente (usada por TListView)

Define un encabezado de agrupación visual dentro de una vista de lista agrupada. Los grupos organizan elementos en categorías colapsables.

DATATipoDescripción
cHeaderCharacterTexto del encabezado del grupo
nGroupIdNumericIdentificador único del grupo
nStateNumericEstado: normal (0), colapsado (1), oculto (2)
MétodoDescripción
New( oParent )Crear un grupo
Create( oParent )Insertar el grupo en la vista de lista
SetState( nState )Colapsar, expandir u ocultar el grupo

Ejemplo: Vista de Lista Agrupada

#include "FiveWin.ch"
function Main()
   local oWnd, oList, oGrp1, oGrp2, oItem
   DEFINE WINDOW oWnd TITLE "Grouped ListView" SIZE 500, 400
   @ 10, 10 LISTBOX oList FIELDS "" OF oWnd SIZE 460, 350
   oList:EnableGroupView()
   oGrp1 := TListViewGroup():New( oList )
   oGrp1:cHeader := "Fruits"; oGrp1:Create()
   oGrp2 := TListViewGroup():New( oList )
   oGrp2:cHeader := "Vegetables"; oGrp2:Create()
   oItem := TListViewItem():New( oList )
   oItem:cText := "Apple"; oItem:nGroup := oGrp1:nGroupId; oItem:Create()
   ACTIVATE WINDOW oWnd CENTERED
return nil

Notas

  • Llame a oList:EnableGroupView() antes de agregar grupos.
  • Los elementos se añaden a oList:aItems al crearse. Los grupos van a oList:aGroups.
  • La propiedad nGroup en un elemento debe coincidir con el nGroupId de un grupo.

TRibbonBar

Barra de cinta estilo Office con pestañas, grupos y botones

Fuente: source/classes/tribbon.prg  |  Padre: TControl  |  Header: include/ribbon.ch

Visión General

TRibbonBar implementa una interfaz de cinta estilo Microsoft Office. La cinta se acopla a la parte superior de una ventana y organiza los comandos en pestañas, cada una conteniendo grupos de botones. Soporta múltiples estilos visuales (2010, 2013, 2015, 2016), una barra de herramientas de acceso rápido, aceleradores de teclado, vista backstage y renderizado completamente dibujado por el propietario con degradados.

Métodos de TRBGroup

Los grupos se crean mediante TRibbonBar:AddGroup() o el comando ADD GROUP. Cada grupo puede contener botones, separadores y otros controles.

MétodoDescripción
AddButton( nRow, nCol, nHeight, nWidth, cCaption, bAction, cType, bWhen, cBitmap, lBorder, lRound, cLayout, oPopup, ... )Agregar un botón a este grupo
AddSeparator( nCol )Agregar una línea separadora vertical

Sintaxis de Comandos

#include "ribbon.ch"

// Crear la barra de cinta
DEFINE RIBBONBAR [ oRBar ] ;
   [ OF oWnd ] ;
   [ PROMPTS cTab1, cTab2, cTab3 ] ;
   [ ACTION bAction ] ;
   [ OPTION nOption ] ;
   [ HEIGHT nHeight ] ;
   [ TOPMARGIN nTopMargin ] ;
   [ COLOR nClrPane ] ;
   [ COLORBOX nClrBoxOut, nClrBoxIn ] ;
   [ COLORSEL nClrBoxSelOut, nClrBoxSelIn ] ;
   [ 2010 | 2013 | 2015 | 2016 ] ;
   [ STARTBTN nStart ]

// Agregar un grupo a una pestaña
ADD GROUP [ oGr ] ;
   RIBBON oRBar ;
   TO nTabIndex ;
   [ PROMPT cCaption ] ;
   [ WIDTH nWidth ] ;
   [ ACTION bAction ] ;
   [ BITMAP cBitmap ]

// Agregar botones a un grupo (usando notación @ fila, col)
@ nRow, nCol ADD BUTTON [ oBtn ] ;
   [ PROMPT cCaption ] ;
   [ SIZE nWidth, nHeight ] ;
   [ BITMAP cBitmap ] ;
   [ ACTION bAction ] ;
   [ OF oGroup ] ;
   [ WHEN bWhen ] ;
   [ BORDER ] ;
   [ ROUND ] ;
   [ TOP | LEFT | BOTTOM | RIGHT | CENTER ] ;
   [ NORMAL | POPUP | SPLITPOPUP | SAYBUTTON ] ;
   [ MENU oPopup ] ;
   [ TOOLTIP cToolTip ]

// Agregar un separador
ADD SEPARATOR TO GROUP oGr [ COL nCol ]

Ejemplos de Código

Ejemplo 1: Cinta Básica con Grupos y Botones

#include "FiveWin.ch"
#include "Ribbon.ch"

FUNCTION Main()
   LOCAL oWnd, oRBar
   LOCAL oGrFile, oGrEdit, oGrView

   DEFINE WINDOW oWnd TITLE "Ribbon Demo"

   DEFINE RIBBONBAR oRBar OF oWnd ;
      PROMPTS "Home", "Insert", "View" ;
      HEIGHT 160 2015

   // ----- HOME TAB (option 1) -----

   ADD GROUP oGrFile RIBBON oRBar TO 1 ;
      PROMPT "File" WIDTH 140

   @ 2, 5 ADD BUTTON PROMPT "New" ;
      SIZE 36, 60 BITMAP "new32.bmp" ;
      ACTION NewDocument() ;
      OF oGrFile TOP

   @ 2, 45 ADD BUTTON PROMPT "Open" ;
      SIZE 36, 60 BITMAP "open32.bmp" ;
      ACTION OpenDocument() ;
      OF oGrFile TOP

   @ 2, 85 ADD BUTTON PROMPT "Save" ;
      SIZE 36, 60 BITMAP "save32.bmp" ;
      ACTION SaveDocument() ;
      OF oGrFile TOP

   ADD GROUP oGrEdit RIBBON oRBar TO 1 ;
      PROMPT "Editing" WIDTH 180

   @ 2, 5 ADD BUTTON PROMPT "Cut" ;
      SIZE 50, 22 BITMAP "cut16.bmp" ;
      ACTION Cut() OF oGrEdit

   @ 26, 5 ADD BUTTON PROMPT "Copy" ;
      SIZE 50, 22 BITMAP "copy16.bmp" ;
      ACTION Copy() OF oGrEdit

   @ 50, 5 ADD BUTTON PROMPT "Paste" ;
      SIZE 50, 22 BITMAP "paste16.bmp" ;
      ACTION Paste() OF oGrEdit

   ADD SEPARATOR TO GROUP oGrEdit COL 65

   @ 2, 70 ADD BUTTON PROMPT "Find" ;
      SIZE 50, 22 BITMAP "find16.bmp" ;
      ACTION FindText() OF oGrEdit

   @ 26, 70 ADD BUTTON PROMPT "Replace" ;
      SIZE 60, 22 BITMAP "replace16.bmp" ;
      ACTION ReplaceText() OF oGrEdit

   // ----- INSERT TAB (option 2) -----

   ADD GROUP oGrView RIBBON oRBar TO 2 ;
      PROMPT "Objects" WIDTH 200

   @ 2, 5 ADD BUTTON PROMPT "Table" ;
      SIZE 36, 60 BITMAP "table32.bmp" ;
      ACTION InsertTable() OF oGrView TOP

   @ 2, 50 ADD BUTTON PROMPT "Image" ;
      SIZE 36, 60 BITMAP "image32.bmp" ;
      ACTION InsertImage() OF oGrView TOP

   @ 2, 95 ADD BUTTON PROMPT "Chart" ;
      SIZE 36, 60 BITMAP "chart32.bmp" ;
      ACTION InsertChart() OF oGrView TOP

   SET MESSAGE OF oWnd TO "Ready" CENTERED

   ACTIVATE WINDOW oWnd
RETURN NIL

Ejemplo 2: Cinta con Acceso Rápido y Backstage

#include "FiveWin.ch"
#include "Ribbon.ch"

FUNCTION RibbonAdvanced()
   LOCAL oWnd, oRBar, oBackStage

   DEFINE WINDOW oWnd TITLE "Advanced Ribbon"

   DEFINE RIBBONBAR oRBar OF oWnd ;
      PROMPTS "Home", "Data", "Reports" ;
      HEIGHT 160 2016 ;
      STARTBTN 1

   // Quick Access round button (File orb)
   oRBar:QuickRoundBtn( "orb.bmp",, , , ;
      { || oRBar:BackStage() } )

   // Backstage panel (shown when orb is clicked)
   oBackStage := TPanel():New( 0, 0, 600, 300, oWnd )
   @ 2, 2 SAY "New"   OF oBackStage
   @ 4, 2 SAY "Open"  OF oBackStage
   @ 6, 2 SAY "Save"  OF oBackStage
   @ 8, 2 SAY "Print" OF oBackStage
   oBackStage:Hide()
   oRBar:SetBackStage( oBackStage )

   // Tab change handling
   oRBar:bAction := { |nTab, nOld| ;
      MsgInfo( "Switched from tab " + Str(nOld) + ;
               " to tab " + Str(nTab) ) }

   // Disable a tab at runtime
   // oRBar:Enable( 3, .F. )

   // Hide a tab at runtime
   // oRBar:Hide( 2 )

   ACTIVATE WINDOW oWnd
RETURN NIL

// Botón con menú desplegable
LOCAL oPopup

MENU oPopup POPUP
   MENUITEM "Option A" ACTION DoA()
   MENUITEM "Option B" ACTION DoB()
   SEPARATOR
   MENUITEM "More..."  ACTION DoMore()
ENDMENU

@ 2, 5 ADD BUTTON PROMPT "Dropdown" ;
   SIZE 80, 60 BITMAP "menu32.bmp" ;
   ACTION NIL ;
   OF oGroup ;
   POPUP ;
   MENU oPopup TOP

// Botón dividido: clic ejecuta acción, flecha abre menú

   SIZE 70, 60 BITMAP "print32.bmp" ;
   ACTION QuickPrint() ;
   OF oGroup ;
   SPLITPOPUP ;
   MENU oPopup TOP

Estilos Visuales

EstiloDescripción

2013Estilo plano Office 2013 con bordes mínimos
2015Estilo Office 2015/2016 con tira de pestaña coloreada

(predeterminado)Estilo de cinta clásico con degradados completos y cajas 3D

Puede cambiar el estilo en tiempo de ejecución usando SetStyles():

// Cambiar a estilo 2016
oRBar:SetStyles( .F., .F., .F., 25, , , , , , , , , , .T. )

Consejos

  • Incluya siempre ribbon.ch para las directivas del preprocesador de comandos de cinta.
  • La altura de la cinta debería ser de alrededor de 140-160 píxeles para una colocación cómoda de los botones.
  • Use el diseño TOP para botones de icono grande (icono sobre texto) y el diseño predeterminado para botones de icono pequeño (icono a la izquierda del texto).
  • Los grupos se agregan a pestañas específicas mediante la cláusula TO nOption. Los índices de pestañas están basados en 1.
  • Use el tipo SPLITPOPUP para botones que tienen tanto una acción directa como un menú desplegable.
  • Los aceleradores de teclado se admiten automáticamente cuando lUseAcc es .T. -- presione Alt para mostrar las sugerencias de teclas.
  • La cláusula WHEN en los botones admite habilitación/deshabilitación dinámica según el estado de la aplicación.
  • Para diseños adaptables, la cinta se redimensiona automáticamente con el ancho de la ventana.

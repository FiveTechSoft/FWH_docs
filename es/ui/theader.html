THeader

Fuente: source/classes/theader.prg

Hereda de: TControl

THeader es un envoltorio para el control común SysHeader32 de Win32. Proporciona una barra de encabezado de columna con clic y redimensionable, usada típicamente sobre vistas de lista o controles de cuadrícula personalizados. Cada columna puede mostrar un texto, tener un ancho específico, admitir flechas de ordenación al hacer clic y ejecutar una acción al ser clickeada. El control admite resaltado de seguimiento y redimensionamiento de columna con arrastre completo.

Miembros DATA Principales

DATATipoDescripción
aPromptsArrayArray of column header caption strings
aSizesArrayArray of column widths in pixels
bActionBlockCode block executed on column click. Receives nItem index and Self.

Métodos

InsertItem( nIndex, cCaption, nWidth, nAlign )Insert a new column at the specified position
SetItem( nIndex, cCaption, nWidth, nAlign, nSort )Modify an existing column's properties
GetItem( nIndex )Retrieve column information (caption, width, alignment)

Ejemplo: Three-Column Header with Click Action

#include "FiveWin.ch"

function Main()

   local oWnd, oHeader, aPrompts, aSizes

   aPrompts := { "Name", "Date", "Size" }
   aSizes   := { 150, 100, 80 }

   DEFINE WINDOW oWnd TITLE "Header Demo" SIZE 400, 200

   oHeader := THeader():New( oWnd, 10, 10, 380, 22, aPrompts, aSizes,,, ;
                             , { | nItem, oCtrl | MsgInfo( "Column " + Str( nItem ) ) } )

   ACTIVATE WINDOW oWnd CENTERED

return nil

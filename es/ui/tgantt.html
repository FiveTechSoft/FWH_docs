TGantt

Fuente: source/classes/gantt.prg

Hereda de: TControl

TGantt es el control de diagrama de Gantt de FiveWin para planificación de proyectos y visualización de cronogramas. Muestra barras horizontales sobre una cuadrícula basada en tiempo, donde cada barra representa una tarea con sus fechas de inicio y fin. El control soporta operaciones interactivas con el ratón, vistas de cuadrícula de mes-día y recálculo dinámico.

TGanttItem

Cada barra en el diagrama de Gantt está representada por un objeto TGanttItem con las siguientes propiedades:

PropiedadTipoDescripción
nRowNuméricoPosición de fila del elemento
nStartNuméricoColumna de inicio (típicamente número de día)
nEndNuméricoColumna de fin (típicamente número de día)
nClrBackNuméricoColor de fondo de la barra

Ejemplo: Diagrama de Gantt de Plan de Proyecto

#include "FiveWin.ch"

function Main()

   local oWnd, oGantt

   DEFINE WINDOW oWnd TITLE "Project Plan" SIZE 800, 400

   @ 10, 10 GANTT oGantt SIZE 760, 340 OF oWnd ;
      CHANGE { |oItem| MsgInfo( "Item changed: Row " + Str( oItem:nRow ) ) }

   // Configure month-day grid for a 4-week view
   oGantt:SetGridMonth( 4 )
   oGantt:nCols := 28

   // Add tasks (row, start_day, end_day, color)
   oGantt:AddItem( 1, 1,  5, CLR_HRED )
   oGantt:AddItem( 2, 3,  10, CLR_HBLUE )
   oGantt:AddItem( 3, 6,  18, CLR_HGREEN )
   oGantt:AddItem( 4, 12, 22, RGB( 255, 165, 0 ) )
   oGantt:AddItem( 5, 15, 28, CLR_HMAGENTA )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use SetGridMonth( nRows ) para mostrar cabeceras de día de la semana/mes. nRows determina cuántas semanas son visibles. Sin esto, la cuadrícula muestra una cabecera simple de números de columna.
  • Los elementos se almacenan en aItems como objetos TGanttItem. Use AtItem( nRow, nCol ) para localizar un elemento en una coordenada específica de la cuadrícula.
  • El bloque de código bChange se activa cuando un elemento se arrastra o modifica mediante interacción del ratón. El bloque recibe el TGanttItem afectado como parámetro.
  • El control recalcula las posiciones de las celdas al redimensionar mediante ReCalculate(), que se llama automáticamente desde el método Resize.
  • Las dimensiones de las celdas (nCellWidth, nCellHeight) se pueden ajustar para adaptarse a diferentes densidades de pantalla o duraciones de proyecto.

TEdit

Fuente: source/classes/edit.prg

Hereda de: TControl

TEdit envuelve el control EDIT estándar de Windows, soportando edición de texto tanto de una línea como multilínea. Ofrece formato con cláusula picture, modo contraseña, modo solo lectura, textos de sugerencia, límites de caracteres y opciones de alineación (izquierda, derecha, centro). TEdit es especialmente útil para texto multilínea donde TGet es demasiado limitado.

Ejemplo: Cuadro de Edición Multilínea

#include "FiveWin.ch"

function Main()

   local oWnd, oEdit, cText := MemoRead( "notes.txt" )

   DEFINE WINDOW oWnd TITLE "TEdit Demo" SIZE 600, 400

   @ 10, 10 EDIT oEdit VAR cText ;
      OF oWnd ;
      SIZE 560, 340 ;
      MULTILINE

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Use la cláusula MULTILINE para crear un cuadro de edición multilínea con barras de desplazamiento vertical y horizontal. El estilo ES_WANTRETURN se aplica automáticamente en modo multilínea. The ES_WANTRETURN style is automatically applied in multi-line mode.
  • El modo contraseña deshabilita multilínea automáticamente. El estilo ES_PASSWORD enmascara la entrada.
  • La cláusula cPicture aplica una máscara de picture. Si el picture contiene !, se añade el estilo mayúsculas (ES_UPPERCASE). If the picture contains !, the uppercase style (ES_UPPERCASE) is added.
  • El texto de sugerencia (marca de agua) aparece dentro del control de edición cuando está vacío y no tiene el foco.

TListBox

Fuente: source/classes/listbox.prg

Hereda de: TControl

TListBox envuelve el control de cuadro de lista estándar de Windows (LISTBOX). Muestra una lista desplazable de elementos de la cual el usuario puede seleccionar una o múltiples entradas. TListBox soporta elementos dibujados por el propietario con mapas de bits, reordenación por arrastrar y soltar, modos de selección múltiple, navegación por teclado y tooltips a nivel de elemento. Es el control de lista de una columna estándar en FiveWin. TListBox supports owner-drawn items with bitmaps, drag-and-drop reordering, multiple-selection modes, keyboard navigation, and item-level tooltips. It is the standard single-column list control in FiveWin.

Miembros DATA Principales

DATATipoDescripción
aItemsArrayArray de cadenas de caracteres mostradas en el cuadro de lista.
aBitmapsArrayArray de manejadores de mapa de bits o nombres de recurso para elementos con mapa de bits. Cada entrada corresponde a un elemento en aItems. Each entry corresponds to an item in aItems.
bSetGetBlockBloque de enlace de datos. Cuando se evalúa sin argumentos, devuelve el valor del elemento seleccionado; con un argumento, selecciona ese elemento.
lOwnerDrawLogicalSi es .T., el cuadro de lista se dibuja por el propietario, permitiendo renderizado personalizado mediante bDrawItem.
bDrawItemBlockBloque de código de dibujo personalizado para elementos dibujados por el propietario: { |nItem, hDC, aRect, nState, oLbx| ... }.
lMultiSelectLogicalSi es .T., se pueden seleccionar múltiples elementos a la vez.
lDragLogicalHabilitar reordenación de elementos de lista por arrastrar y soltar.
bChangeBlockEvaluado cuando cambia la selección: { |nItem, oLbx| ... }.
bValidBlockBloque de validación evaluado cuando el cuadro de lista pierde el foco.
nAtNumericÍndice del elemento actualmente seleccionado (basado en 1). 0 significa ninguna selección.

Methods

New( nRow, nCol, bSetGet, aItems, nW, nH, oWnd, lMultiSel, lDrag, lOwner, oFont, bDraw, lPixel, lDesign, oIcon, cMsg, lUpdate, bChange, bValid, ... )Crear un nuevo cuadro de lista. aItems is the initial item array. bSetGet binds the selected value to a variable.

Modify( cItem, nAt )Reemplazar el elemento en la posición nAt con el nuevo texto cItem.
Select( nItem )Seleccionar programáticamente el elemento en la posición nItem.
SetItems( aItems )Reemplazar todos los elementos en el cuadro de lista con un nuevo array de cadenas.
GetPos()Devuelve el índice del elemento actualmente seleccionado (basado en 1). Devuelve 0 si no hay elemento seleccionado.
GetSel()Devuelve el texto del elemento seleccionado como cadena.

Commands: @ ... LISTBOX

   ITEMS aItems ;
   [ VAR uVar ] ;
   [ SIZE nW, nH ] ;
   [ OF oDlg ] ;
   [ MULTISELECT ] ;
   [ DRAG ] ;
   [ ON CHANGE bChange ] ;
   [ ON VALID bValid ] ;
   [ BITMAPS aBitmaps ] ;
   [ OWNERDRAW ]

Ejemplo: Cuadro de Lista de 3 Elementos

#include "FiveWin.ch"

function Main()

   local oWnd, oLbx, cChoice := ""

   DEFINE WINDOW oWnd TITLE "TListBox Demo" SIZE 400, 300

   @ 20, 20 LISTBOX oLbx ;
      ITEMS { "Apples", "Oranges", "Bananas" } ;
      SIZE 200, 150 OF oWnd ;
      ON CHANGE MsgInfo( "Selected: " + oLbx:GetSel() )

   @ 200, 20 BUTTON "Get Selection" SIZE 120, 30 OF oWnd ;
      ACTION MsgInfo( "Item " + Str( oLbx:GetPos() ) + ;
                      ": " + oLbx:GetSel() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TListBox hereda de TControl. Todos los métodos estándar del control están disponibles.
  • Use lMultiSelect := .T. (o la cláusula MULTISELECT) para permitir al usuario seleccionar múltiples elementos usando Ctrl+clic o Shift+clic.
  • El bloque bDrawItem habilita el renderizado personalizado. Cuando lOwnerDraw es .T., el cuadro de lista se vuelve dibujado por el propietario y el bloque bDrawItem se llama para cada elemento visible durante el pintado. When lOwnerDraw is .T., the list box becomes owner-drawn and the bDrawItem block is called for each visible item during paint.
  • Los mapas de bits de elementos (aBitmaps) proporcionan un icono simple junto a cada elemento sin necesidad de owner-draw. Each element is a bitmap handle or resource name.
  • La reordenación por arrastrar y soltar se habilita mediante la cláusula DRAG. Los elementos pueden arrastrarse a nuevas posiciones dentro de la lista. Items can be dragged to new positions within the list.
  • Para navegación por teclado, el cuadro de lista maneja las flechas Arriba/Abajo, RePág/AvPág y las teclas Inicio/Fin automáticamente.

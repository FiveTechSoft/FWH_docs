TFolderEx

Fuente: source/classes/tfoldex.prg

Hereda de: TControl

TFolderEx es un control de carpetas con pestañas extendido que admite múltiples disposiciones de pestañas (arriba, izquierda, abajo, derecha), renderizado con degradados, bitmaps por pestaña, animación, reordenamiento mediante arrastre, habilitar/deshabilitar/ocultar por pestaña y pestañas multilínea. Es el control de pestañas principal utilizado en las aplicaciones FWH modernas, ofreciendo una alternativa rica al TFolder estándar.

Ejemplo: Carpeta de 3 pestañas con iconos

#include "FiveWin.ch"

function Main()

   local oWnd, oFolder, oDlg1, oDlg2, oDlg3

   DEFINE WINDOW oWnd TITLE "TFolderEx Demo" SIZE 600, 400

   oDlg1 := TDlg():New( 0, 0, 300, 200, "General", , , , , , , oWnd )
   oDlg2 := TDlg():New( 0, 0, 300, 200, "Options", , , , , , , oWnd )
   oDlg3 := TDlg():New( 0, 0, 300, 200, "About",   , , , , , , oWnd )

   @ 20, 20 FOLDEREX oFolder ;
        PROMPTS "General", "Options", "About" ;
        DIALOGS oDlg1, oDlg2, oDlg3 ;
        SIZE 560, 360 OF oWnd ;
        LAYOUT TOP

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TFolderEx admite cuatro disposiciones de pestañas mediante nLayOut: TOP (1), LEFT (2), BOTTOM (3), RIGHT (4). La barra de pestañas se dibuja en consecuencia y los diálogos hijo se posicionan para llenar el área restante.
  • Los arrays de estado por pestaña (aEnable, aVisible, aAlign, aBitmaps) se mantienen en paralelo con aPrompts.
  • Cuando lAnimation es verdadero, el cambio de pestaña activa una transición deslizante controlada por nSpeed.
  • El renderizado de las pestañas se divide en dos métodos internos: PaintLR() para las disposiciones izquierda/derecha y PaintTB() para las disposiciones arriba/abajo.
  • El clic derecho sobre una pestaña dispara bPopup si está asignado, permitiendo menús contextuales por pestaña.
  • El reordenamiento de pestañas se admite mediante aOrder: establezca el array con la secuencia de índices de pestaña deseada y llame a ChangeOrder().

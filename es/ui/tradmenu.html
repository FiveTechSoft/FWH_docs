TRadMenu

Fuente: source/classes/radmenu.prg

Clase independiente (no derivada de TControl)

TRadMenu gestiona un grupo de controles de botón de radio (TRadio) como una unidad lógica única con exclusión mutua: seleccionar un botón de radio deselecciona automáticamente los otros. Proporciona una interfaz simplificada para crear, navegar y consultar el estado de un grupo de botones de radio sin gestionar objetos TRadio individuales.

Miembros DATA Principales

DATATipoDescripción
aItemsArrayArray de objetos TRadio gestionados por este grupo
bSetGetBlockBloque de código SET/GET para el índice de opción actual
nOptionNumericÍndice de la opción actualmente seleccionada (basado en 1)
bChangeBlockBloque de código evaluado cuando cambia la selección

Métodos

MétodoDescripción
New( nRow, nCol, acItems, bSetGet, oWnd )Crear un nuevo grupo de radio con elementos de acItems
ReDefine( bSetGet, oWnd, anIDs )Redefinir desde recurso de diálogo por IDs de control
SetOption( n )Establecer programáticamente la opción seleccionada
Refresh()Actualizar la visualización de todos los elementos
GoPrev()Seleccionar la opción anterior (circular)
GoNext()Seleccionar la siguiente opción (circular)
Enable()Habilitar todos los botones de radio en el grupo
Disable()Deshabilitar todos los botones de radio en el grupo

Ejemplo: Grupo de Radio de 3 Opciones

#include "FiveWin.ch"

function Main()

   local oWnd, oRadMenu, nOption := 1

   DEFINE WINDOW oWnd TITLE "Radio Group" SIZE 300, 200

   @ 10, 10 RADMENU oRadMenu ;
      ITEMS { "Option &One", "Option &Two", "Option &Three" } ;
      SIZE 200, 100 OF oWnd ;
      ON CHANGE ( MsgInfo( "Selected: " + Str( oRadMenu:nOption ) ) )

   oRadMenu:bSetGet := {|u| If( u == nil, nOption, nOption := u ) }
   oRadMenu:SetOption( 1 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TRadMenu no hereda de TControl; es un contenedor que posee y gestiona controles TRadio individuales.
  • El array acItems contiene las cadenas de aviso para cada botón de radio. Cada aviso puede incluir un ampersand (&) para un acelerador de teclado.
  • El bloque bSetGet sigue el patrón estándar SET/GET de FiveWin: llamado sin argumento devuelve el valor actual; llamado con un argumento establece el valor.
  • GoPrev() y GoNext() se envuelven (navegación circular) al llegar al inicio o final del grupo.
  • Use ReDefine() para vincular TRadMenu a controles de radio definidos en un recurso .rc de diálogo pasando un array de IDs de control que coincidan con el grupo.

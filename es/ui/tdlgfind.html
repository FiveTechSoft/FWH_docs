TDlgFind

Fuente: source/classes/dlgfind.prg

Hereda de: TDialog

TDlgFind envuelve el cuadro de diálogo común de Buscar Texto de Windows (API FindText). Es un diálogo no modal gestionado por Windows que permite a los usuarios buscar texto dentro de una aplicación. El diálogo envía mensajes de notificación al llamante cuando el usuario hace clic en "Buscar Siguiente".

Methods

MétodoDescripción
New( cText, oWnd, bSearch )Crear el diálogo de búsqueda con texto inicial, ventana propietaria y bloque de acción de búsqueda

Función Libre

FunciónDescripción
DlgFindText( cText, oWnd, bSearch ) -> oDlgFunción de conveniencia que crea y devuelve un objeto TDlgFind

Ejemplo: Diálogo de Búsqueda con Callback

#include "FiveWin.ch"

function Main()

   local oWnd, oDlg

   DEFINE WINDOW oWnd TITLE "Find Demo" SIZE 600, 400

   oDlg = DlgFindText( "search text", oWnd, {|cText,lDir| MySearch( cText, lDir ) } )

   ACTIVATE WINDOW oWnd CENTERED

return nil

function MySearch( cText, lForward )

   // Perform search in your edit control
   ? "Searching for:", cText, If( lForward, "forward", "backward" )

return nil

Notes

  • El diálogo de búsqueda es no modal (lModal = .F.). La aplicación continúa procesando mientras está abierto.
  • El bloque bSearch recibe el texto de búsqueda y una bandera de dirección lógica (.T. = adelante, .F. = atrás).
  • El diálogo se centra automáticamente dentro de su ventana propietaria.
  • Internamente, la API FindText() de Windows crea el diálogo; TDlgFind lo subclasifica mediante RegDialog() para manejar eventos.

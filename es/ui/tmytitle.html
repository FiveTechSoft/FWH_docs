TMyTitle

Fuente: source/classes/tmytitle.prg

Hereda de: TControl

TMyTitle es un control de barra de título degradada personalizado que puede colocarse en la parte superior de una ventana o diálogo. Renderiza un fondo con relleno degradado (horizontal o vertical) con texto de título, un mapa de bits de encabezado opcional y un efecto tipo vidrio. Admite fuentes personalizadas, colores de borde y actualizaciones en tiempo de ejecución del texto del título y mapa de bits.

Ejemplo: Gradient Title Bar

#include "FiveWin.ch"

function Main()

   local oWnd, oTitle

   DEFINE WINDOW oWnd TITLE "Demo" SIZE 500, 300

   oTitle := TMyTitle():New( oWnd, 0, 0, 50, 500,;
              "My Custom Dialog", CLR_WHITE,;
              nRGB( 89, 135, 214 ), nRGB( 3, 56, 147 ),,,;
              .F., .T., CLR_BLACK, .F. )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • La fuente predeterminada es Tahoma, tama
  • Cuando lGlass es .T., la barra usa un degradado horizontal de dos pasadas que crea un efecto de reflejo tipo vidrio.

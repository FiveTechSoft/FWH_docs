TMyTitle

Fuente: source/classes/tmytitle.prg

Hereda de: TControl

TMyTitle es un control personalizado de barra de título con degradado que se puede colocar en la parte superior de una ventana o diálogo. Renderiza un fondo con relleno degradado (horizontal o vertical) con texto de título, un mapa de bits de encabezado opcional y un efecto similar al vidrio. Admite fuentes personalizadas, colores de borde y actualizaciones en tiempo de ejecución del texto y mapa de bits del título.

Ejemplo: Barra de Título con Degradado

#include "FiveWin.ch"

function Main()

   local oWnd, oTitle

   DEFINE WINDOW oWnd TITLE "Demo" SIZE 500, 300

   oTitle := TMyTitle():New( oWnd, 0, 0, 50, 500,;
              "My Custom Dialog", CLR_WHITE,;
              nRGB( 89, 135, 214 ), nRGB( 3, 56, 147 ),,,;
              .F., .T., CLR_BLACK, .F. )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • La fuente predeterminada es Tahoma, tamaño -18, negrita. Se puede proporcionar una fuente personalizada mediante el parámetro oFontTitle.
  • Cuando lGlass es .T., la barra usa un degradado horizontal de dos pasadas que crea un efecto de reflejo similar al vidrio.
  • Los mapas de bits se pueden cargar desde archivo (ruta con extensión) o desde recurso (nombre sin extensión). El mapa de bits se dibuja en el desplazamiento nOffSetX, nOffSetY desde la esquina superior izquierda.
  • La escala High-DPI se admite mediante nScale, que se calcula automáticamente desde el DPI lógico de la ventana activa.

TImageList

Fuente: source/classes/timaglst.prg

Clase independiente (not derived from TControl)

TImageList is a standalone wrapper around the Win32 HIMAGELIST API for managing collections of icons and bitmaps of equal size. Image lists are used extensively by tree views, list views, tab controls, toolbars, and other common controls to efficiently manage icon sets.

Miembros DATA Principales

DATATipoDescripción
hImageListHandleManejador HIMAGELIST de Win32
aBitmapsArrayArray de objetos TBitmap agregados a la lista

Methods

MétodoDescripción
New( nWidth, nHeight )Crear una nueva lista de imágenes. El tamaño predeterminado es 16x16 píxeles.
Add( oBmpImage, oBmpMask )Agregar una imagen con mapa de bits de máscara opcional a la lista. Devuelve el índice de la imagen.
AddMasked( oBmpImage, nClrMask )Agregar una imagen usando un color transparente como máscara. Devuelve el índice de la imagen.
AddIcon( oIcon )Agregar un icono (objeto TIcon o nombre de archivo/recurso de icono) a la lista. Devuelve el índice de la imagen.
AddImage( cFile )Cargar y agregar una imagen desde una ruta de archivo. Devuelve el índice de la imagen.
ReadBitmap( cFile, nWidth, nImages, nClrTransparent )Load a bitmap strip from a file, split into nImages frames, using nClrTransparent as the transparent mask color.
SetBkColor( nColor )Establecer el color de fondo usado al renderizar imágenes con máscara. Use CLR_NONE para fondo transparente. Use CLR_NONE for transparent background.
End()Destruir la lista de imágenes y liberar todos los recursos asociados.

Ejemplo: Crear una Lista de Imágenes para una Barra de Herramientas

#include "FiveWin.ch"

function Main()

   local oWnd, oImgList, oBar

   DEFINE WINDOW oWnd TITLE "ImageList Demo" SIZE 500, 300

   // Create a 24x24 image list
   oImgList := TImageList():New( 24, 24 )

   // Add masked bitmaps (using magenta as transparent color)
   oImgList:AddMasked( TBitmap():Load( "bitmaps\new.bmp"  ), CLR_MAGENTA )
   oImgList:AddMasked( TBitmap():Load( "bitmaps\open.bmp" ), CLR_MAGENTA )
   oImgList:AddMasked( TBitmap():Load( "bitmaps\save.bmp" ), CLR_MAGENTA )

   // Attach to a toolbar button bar
   oBar := TButtonBar():New( oWnd, , , oImgList )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TImageList es una clase no visual y no hereda de TControl. Gestiona el ciclo de vida de un manejador HIMAGELIST de Win32 que puede compartirse entre múltiples controles comunes. It manages the lifecycle of a Manejador HIMAGELIST de Win32 that can be shared across multiple common controls.
  • Todas las imágenes en una sola lista de imágenes deben tener el mismo tamaño (ancho y alto), que se especifica en el momento de la creación en New().
  • El método AddMasked() es la forma más común de agregar mapas de bits, usando un color transparente (típicamente CLR_MAGENTA o CLR_WHITE) para crear la máscara automáticamente.
  • ReadBitmap() es útil para cargar tiras de mapas de bits (múltiples imágenes dispuestas horizontalmente en un solo archivo). Especifique el número de imágenes y el color transparente para dividirlas automáticamente. Specify the number of images and the transparent color to split them automatically.
  • Siempre llame a End() cuando la lista de imágenes ya no sea necesaria para evitar fugas de manejadores GDI. La lista de imágenes a menudo se destruye automáticamente cuando se destruye la ventana padre. The image list is often destroyed automatically when the parent window is destroyed.

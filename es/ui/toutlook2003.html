TOutLook2003 / TOutLook2010

Fuentes: source/classes/outl2003.prg, source/classes/outl2010.prg

Hereda de: TControl

TOutLook2003 y TOutLook2010 son controles de panel de navegación modelados según la barra lateral de Microsoft Outlook. Muestran un encabezado, grupos colapsables con iconos y un área de cliente para diálogos hijos. Ambas clases comparten la misma API; la diferencia es el esquema de colores (azul de Outlook 2003 vs. gris claro de Outlook 2010).

Ejemplo: Panel de Navegación

#include "FiveWin.ch"

function Main()

   local oWnd, oOutlook
   local aPrompts := { "Mail", "Calendar", "Contacts" }
   local aBitmaps := { "mail.bmp", "cal.bmp", "cont.bmp" }

   DEFINE WINDOW oWnd TITLE "Outlook 2003 Pane" SIZE 700, 500

   @ 0, 0 OUTLOOK2003 oOutlook ;
      PROMPTS aPrompts BITMAPS aBitmaps ;
      SIZE 190, 500 OF oWnd

   // Para estilo Outlook 2010, use OUTLOOK2010
   // @ 0, 0 OUTLOOK2010 oOutlook ...

   ACTIVATE WINDOW oWnd CENTERED

return nil

Diferencias de TOutLook2010

TOutLook2010 usa la misma API y firmas de métodos que TOutLook2003. Las únicas diferencias son:

  • Color de fondo: nRGB( 220, 223, 228 ) (gris claro) vs. el azul oscuro de Outlook 2003.
  • Los colores degradados de los botones de grupo usan tonos naranja/cian cálidos en lugar de tonos azules.

Notas

  • El panel tiene 190 píxeles de ancho por defecto, posicionado en el lado izquierdo de la ventana.
  • Cada grupo tiene un diálogo hijo asociado creado como ventana WS_CHILD; cambie de grupo haciendo clic en el botón del grupo.
  • El bloque bChange se ejecuta cuando el usuario selecciona un grupo diferente mediante SetOption().
  • Un menú emergente con clic derecho permite a los usuarios cambiar entre grupos programáticamente.

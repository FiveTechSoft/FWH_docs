TIconGroup / TIconGet

Fuentes: source/classes/igroup.prg, source/classes/iget.prg

TIconGroup hereda de TControl | TIconGet hereda de TMultiGet

TIconGroup muestra una cuadrícula de iconos con textos descriptivos. Los usuarios pueden navegar con teclas de flecha, hacer clic para seleccionar y doble clic para ejecutar acciones. TIconGet es un control de edición usado internamente por TIconGroup para la edición en línea de textos. TIconGet is an edit control used internally by TIconGroup for inline prompt editing.

Ejemplo: Cuadrícula de Iconos con Acciones al Clic

#include "FiveWin.ch"

function Main()

   local oWnd, oIconGrp
   local aIcons   := {}
   local aPrompts := {}
   local aActions := {}

   DEFINE WINDOW oWnd TITLE "Icon Group Demo" SIZE 400, 300

   AAdd( aIcons,   "folder.ico" )
   AAdd( aPrompts, "Open" )
   AAdd( aActions, {|| MsgInfo( "Open clicked" ) } )

   AAdd( aIcons,   "help.ico" )
   AAdd( aPrompts, "Help" )
   AAdd( aActions, {|| MsgInfo( "Help clicked" ) } )

   @ 10, 10 ICONGROUP ITEMS aIcons, aPrompts, aActions ;
      SIZE 300, 200 OF oWnd

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Los iconos pueden cargarse desde archivos .ico pasando la ruta del archivo como cadena a Add() o al array aIcons.
  • Navigate with arrow keys; press Enter to activate the focused icon's action.
  • Presione F2 para editar el texto descriptivo cuando lAutoEdit es .T.
  • TIconGet es un control interno basado en TMultiGet, diseñado para edición centrada de una línea dentro del área del icono.

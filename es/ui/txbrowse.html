TXBrowse

El control de grid de datos más potente y versátil de FiveWin

Fuente: source/classes/xbrowse.prg  |  Padre: TControl  |  Cabecera: XBrowse.ch

Visión General

TXBrowse es el control de grid estrella de FiveWin. Renderiza datos tabulares desde prácticamente cualquier origen -- tablas DBF, arrays en memoria, RecordSets ADO, cursores ODBC o datos personalizados -- a través de una arquitectura de navegación unificada basada en bloques de código. Virtualiza el renderizado de modo que solo se procesan las filas visibles, lo que le permite manejar millones de registros sin consumo excesivo de memoria.

Capacidades principales:

  • Abstracción de origen de datos -- un solo control, múltiples backends (DBF/RDD, Array, ADO, ODBC, personalizado)
  • Objetos de columna avanzados -- cada columna (TXBrwCol) controla su propia cabecera, formato de datos, colores, edición y ancho
  • Edición en celda -- editores GET, ComboBox, CheckBox, DatePicker y Spinner por columna
  • Búsqueda/filtro incremental -- barra de búsqueda integrada lIncrFilter con búsqueda por columna
  • Multi-selección, columnas congeladas, selector de registro, estilos de marquesina
  • Exportar a Excel, CSV, portapapeles e impresora

Arquitectura

TXBrowse desacopla el grid visual de los datos subyacentes mediante un conjunto de bloques de código de navegación. Los métodos auxiliares como SetRDD(), SetArray() y SetAdo() simplemente rellenan estos bloques con la lógica adecuada para cada tipo de origen de datos.

Objeto Columna: TXBrwCol

Cada columna del navegador es un objeto TXBrwCol almacenado en el array aCols. Las columnas definen qué datos mostrar y cómo mostrarlos.

Bloques de Navegación

Estos bloques de código forman la capa de abstracción de datos. Se establecen automáticamente mediante SetRDD(), SetArray(), SetAdo(), etc., pero puedes proporcionar bloques personalizados para orígenes de datos especializados.

BloqueFirmaDescripción
bGoTop{|| ... }Posicionar el origen de datos en el primer registro
bGoBottom{|| ... }Posicionar el origen de datos en el último registro
bSkip{|n| ... }Mover n registros (positivo=adelante, negativo=atrás). Devuelve los registros realmente movidos.
bBof{|| ... }Devuelve .T. si está antes del primer registro
bEof{|| ... }Devuelve .T. si está después del último registro
bKeyNo{|n| ... }Obtener/establecer la posición lógica actual (para la barra de desplazamiento)
bKeyCount{|| ... }Devuelve el número total de registros (para la barra de desplazamiento)
bBookMark{|u| ... }Si u es NIL, devuelve un marcador para la fila actual. Si no, reposiciona al marcador u.
bSeek{|c| ... }Búsqueda incremental -- encuentra el primer registro que coincida con la cadena c

Comandos (XBrowse.ch)

FiveWin proporciona dos estilos de comando para crear controles TXBrowse:

Comando Posicionado

@ nRow, nCol XBROWSE oBrw ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ COLUMNS cCol1, cCol2, ... ] ;
   [ HEADERS cHead1, cHead2, ... ] ;
   [ ALIAS cAlias ] ;
   [ ON DBLCLICK bAction ] ;
   [ FONT oFont ] ;
   [ NOBORDER ]

Comando de Navegador Rápido

XBROWSER <cAlias>       // browse a DBF alias
XBROWSER <aArray>       // browse an array
XBROWSER <oRs>          // browse an ADO RecordSet

Ejemplos de Código

Ejemplo 1: Navegando una Tabla DBF

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw

   USE Customer VIA "DBFCDX" NEW

   DEFINE WINDOW oWnd TITLE "Customers" FROM 1, 1 TO 24, 80

   oBrw := TXBrowse():New( oWnd )
   oBrw:nTop    := 0
   oBrw:nLeft   := 0
   oBrw:nRight  := -1   // stretch to right edge
   oBrw:nBottom := -1   // stretch to bottom edge

   oBrw:SetRDD()        // bind to current work area

   // Configure individual columns
   WITH OBJECT oBrw:AddColumn( "ID", FieldBlock( "CUST_ID" ), "99999" )
      :nWidth       := 80
      :nDataStrAlign := AL_RIGHT
   END

   WITH OBJECT oBrw:AddColumn( "First Name", FieldBlock( "FIRSTNAME" ), "@!" )
      :nWidth := 140
      :lEdit  := .T.    // allow in-cell editing
   END

   oBrw:AddColumn( "Last Name",  FieldBlock( "LASTNAME" ),  "@!" )
   oBrw:AddColumn( "City",       FieldBlock( "CITY" ) )
   oBrw:AddColumn( "Balance",    FieldBlock( "BALANCE" ),    "@E 999,999.99" )

   oBrw:nFreeze         := 1       // freeze ID column
   oBrw:lRecordSelector := .T.     // show row indicator
   oBrw:nMarqueeStyle   := MARQSTYLE_HIGHLROW

   oBrw:CreateFromCode()

   oWnd:oClient := oBrw            // fill the window client area
   ACTIVATE WINDOW oWnd

   CLOSE Customer
RETURN NIL

Ejemplo 2: Navegando un Array

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw
   LOCAL aData := { ;
      { "Alice",   "Smith",    28, .T. }, ;
      { "Bob",     "Johnson",  34, .F. }, ;
      { "Charlie", "Williams", 45, .T. }, ;
      { "Diana",   "Brown",    31, .T. }, ;
      { "Edward",  "Jones",    52, .F. }  ;
   }

   DEFINE WINDOW oWnd TITLE "Array Browse" FROM 2, 2 TO 20, 70

   oBrw := TXBrowse():New( oWnd )
   oBrw:SetArray( aData, .F. )   // .F. = do not auto-create columns

   oBrw:aCols := {}
   oBrw:AddColumn( "First",  {|| aData[ oBrw:nArrayAt ][ 1 ] } )
   oBrw:AddColumn( "Last",   {|| aData[ oBrw:nArrayAt ][ 2 ] } )
   oBrw:AddColumn( "Age",    {|| aData[ oBrw:nArrayAt ][ 3 ] }, "999" )
   oBrw:AddColumn( "Active", {|| aData[ oBrw:nArrayAt ][ 4 ] } )

   // Make "Active" column render as a checkbox
   oBrw:aCols[ 4 ]:SetCheck( "CHECK1", "UNCHECK1" )

   oBrw:nMarqueeStyle := MARQSTYLE_HIGHLCELL
   oBrw:CreateFromCode()

   oWnd:oClient := oBrw
   ACTIVATE WINDOW oWnd
RETURN NIL

Ejemplo 3: Navegador Editable con Configuración de Columnas

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw, oCol

   USE Invoices VIA "DBFCDX" NEW

   DEFINE WINDOW oWnd TITLE "Editable Invoices"

   @ 0, 0 XBROWSE oBrw OF oWnd ;
      COLUMNS "INVNO", "CUSTNAME", "AMOUNT", "INVDATE", "PAID" ;
      HEADERS "Invoice #", "Customer", "Amount", "Date", "Paid?"

   oBrw:SetRDD()

   // Configure the Amount column
   oCol := oBrw:aCols[ 3 ]
   oCol:cPicture  := "@E 999,999.99"
   oCol:lEdit     := .T.
   oCol:nEditType := EDIT_GET             // edit with a GET control
   oCol:bClrStd   := {|| { CLR_BLACK, CLR_WHITE } }

   // Configure the Date column with a date picker editor
   oCol := oBrw:aCols[ 4 ]
   oCol:lEdit     := .T.
   oCol:nEditType := EDIT_DATE

   // Configure the Paid column as a checkbox
   oCol := oBrw:aCols[ 5 ]
   oCol:SetCheck( "CHECK1", "UNCHECK1" )
   oCol:lEdit := .T.

   oBrw:lFastEdit := .T.   // typing goes straight to edit mode
   oBrw:CreateFromCode()

   oWnd:oClient := oBrw
   ACTIVATE WINDOW oWnd

   CLOSE Invoices
RETURN NIL

Ejemplo 4: Barra de Búsqueda / Filtro Incremental

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw

   USE Customer INDEX Customer VIA "DBFCDX" NEW

   DEFINE WINDOW oWnd TITLE "Customer Search"

   oBrw := TXBrowse():New( oWnd )
   oBrw:SetRDD()

   oBrw:AddColumn( "Name",    FieldBlock( "NAME" ) )
   oBrw:AddColumn( "City",    FieldBlock( "CITY" ) )
   oBrw:AddColumn( "Phone",   FieldBlock( "PHONE" ) )
   oBrw:AddColumn( "Balance", FieldBlock( "BALANCE" ), "@E 999,999.99" )

   // Enable the incremental filter bar
   oBrw:lIncrFilter := .T.

   // Custom seek block -- performs an indexed seek on the NAME field
   oBrw:bSeek := {|cSeek| ( oBrw:cAlias )->( DbSeek( cSeek, .T. ) ) }

   oBrw:nMarqueeStyle   := MARQSTYLE_HIGHLROW
   oBrw:lRecordSelector := .T.

   oBrw:CreateFromCode()
   oWnd:oClient := oBrw
   ACTIVATE WINDOW oWnd

   CLOSE Customer
RETURN NIL

Consejos y Buenas Prácticas

  • Llama siempre a CreateFromCode() después de configurar el origen de datos, las columnas y las propiedades visuales.
  • Usa oWnd:oClient := oBrw para que el navegador se redimensione automáticamente con la ventana.
  • Evita lFastEdit en interfaces con mucha navegación -- intercepta las teclas de caracteres que de otro modo activarían búsquedas o atajos de teclado.
  • Para la búsqueda incremental en un DBF, asegúrate de que la tabla tenga un índice activo en la columna que estás buscando.
  • bClrEdit de la columna controla los colores de la celda mientras se está editando (bloque de primer plano/fondo). Es independiente de bClrStd que controla los colores en modo visualización.
  • Pintado con doble buffer: TXBrowse pinta en un bitmap fuera de pantalla, luego lo transfiere a la pantalla. Esto elimina el parpadeo pero significa que debes llamar a Refresh() -- no a Invalidate() -- para forzar un redibujado.
  • Para arrays muy grandes, considera usar SetRDD() con un DBF temporal en su lugar, ya que la navegación por array no virtualiza las búsquedas.

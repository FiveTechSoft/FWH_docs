TUpDown

Fuente: source/classes/tupdown.prg

Hereda de: TControl

TUpDown encapsula el control común up-down de Win32, también conocido como spinner o control buddy. Normalmente se asocia a un campo TGet para proporcionar botones de flecha de incremento/decremento que actualizan automáticamente el valor del buddy dentro de un rango configurable.

Miembros DATA Clave

DATATipoDescripción
nMinNuméricoValor mínimo del rango del spinner
nMaxNuméricoValor máximo del rango del spinner
nPosNuméricoPosición actual del spinner
oBuddyObjetoEl control buddy (normalmente un TGet) vinculado a este spinner
lWrapLógicoDa la vuelta al alcanzar el límite del rango
nAlignNuméricoAlineación respecto al buddy: 0=derecha, 1=izquierda

Métodos

MétodoDescripción
New( nRow, nCol, oWnd, oBuddy, nW, nH, nMin, nMax, nPos )Crea un nuevo control up-down
SetPos( n )Establece la posición del spinner en n
GetPos()Devuelve la posición actual del spinner
SetRange( nMin, nMax )Establece los valores mínimo y máximo del rango
SetBuddy( oBuddy )Asocia un control buddy al spinner
GetBuddy()Devuelve el control buddy actualmente asociado

Ejemplo: Spinner Vinculado a un Campo GET

#include "FiveWin.ch"

function Main()

   local oWnd, oGet, oSpinner, nVal := 5

   DEFINE WINDOW oWnd TITLE "Quantity" SIZE 300, 150

   @ 40, 20 GET oGet VAR nVal SIZE 60, 20 OF oWnd PICTURE "999"
   @ 38, 80 UPDOWN oSpinner BUDDY oGet ;
      RANGE 1, 100

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El control buddy se establece automáticamente como la ventana especificada en la cláusula BUDDY. El control up-down se posiciona adyacente al buddy.
  • Cuando lWrap está en .T., hacer clic hacia arriba en nMax da la vuelta a nMin y viceversa.
  • La cláusula RANGE establece a la vez nMin y nMax.
  • TUpDown utiliza el estilo UDS_SETBUDDYINT de Win32 para actualizar automáticamente el valor mostrado del control buddy.

TMetroPanel

Fuente: source/classes/metropnl.prg

Hereda de: TPanel

TMetroPanel implementa un panel de inicio estilo Metro de Windows 8 con grupos de mosaicos que se desplazan horizontalmente. Organiza los mosaicos TMetroBtn en grupos y filas, proporcionando una interfaz táctil con desplazamiento por arrastre, soporte para rueda del ratón y una barra de desplazamiento personalizada. Cada mosaico puede ser un botón grande o pequeño con una imagen, título y acción. TMetroBtn (clase hija de TBtnBmp) representa un mosaico Metro individual con alineación configurable, superposición de texto y pertenencia a grupo.

Ejemplo: Panel Metro con Dos Grupos

#include "FiveWin.ch"

function Main()

   local oWnd, oMetro

   DEFINE WINDOW oWnd TITLE "Metro Panel" SIZE 800, 600

   DEFINE METROPANEL oMetro OF oWnd TITLE "Start" ;
      COLOR CLR_WHITE, RGB( 30, 30, 120 ) ;
      ON CLICK oWnd:End()

   // Grupo 1: Mosaicos de comunicación
   oMetro:AddButton( .T., 1, "Email", { || MsgInfo( "Email" ) }, ;
                     CLR_WHITE, RGB( 0, 120, 200 ),, , , , 64, 64 )

   oMetro:AddButton( .F., 1, "Calendar", { || MsgInfo( "Calendar" ) }, ;
                     CLR_WHITE, RGB( 200, 50, 50 ) )

   // Grupo 2: Mosaicos de productividad
   oMetro:AddButton( .T., 2, "Documents", { || MsgInfo( "Docs" ) }, ;
                     CLR_WHITE, RGB( 50, 150, 50 ),, , , , 64, 64 )

   oMetro:AddButton( .F., 2, "Settings", { || MsgInfo( "Settings" ) }, ;
                     CLR_WHITE, RGB( 80, 80, 80 ) )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Notas

  • TMetroPanel requiere el comando DEFINE METROPANEL y usa fuentes "Segoe UI Light" para la estética Metro.
  • Los mosaicos se organizan en grupos separados por un espacio de 32 píxeles. Cada grupo distribuye los mosaicos en filas según nMetroRows (calculado desde la altura de la pantalla).
  • Los mosaicos grandes (lLarge := .T.) abarcan dos posiciones de columna, permitiendo una mezcla de mosaicos grandes y pequeños en el mismo grupo.
  • El desplazamiento horizontal se maneja mediante una barra de desplazamiento personalizada en la parte inferior. Se admiten arrastrar para desplazar y la rueda del ratón.
  • Use lDesignMode := .T. para habilitar funciones de tiempo de diseño como reposicionamiento de mosaicos mediante MoveBtn().
  • TMetroBtn hereda de TBtnBmp y admite carga de imágenes desde archivo o recurso, con alineación y tamaño de mapa de bits configurables.

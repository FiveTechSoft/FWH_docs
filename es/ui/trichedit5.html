TRichEdit5

Fuente: source/classes/triched5.prg

Hereda de: TControl

TRichEdit5 envuelve el control RichEdit 5.0 de Windows (clase de ventana RichEdit50W), proporcionando edición de texto enriquecido avanzada con soporte para formato RTF, resaltado de sintaxis, inserción de tablas, imágenes en línea, corrección ortográfica, impresión y exportación a PDF. Es adecuado para crear editores de texto completos y editores de código dentro de aplicaciones FiveWin.

Ejemplo: Editor RTF

#include "FiveWin.ch"

function Main()

   local oWnd, oRE

   DEFINE WINDOW oWnd TITLE "RichEdit 5.0 Editor" SIZE 800, 600

   @ 10, 10 RICHEDIT5 oRE VAR "" ;
      OF oWnd ;
      SIZE 760, 540 ;
      HIGHLIGHT ;
      BAR ;
      FILE "document.rtf"

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TRichEdit5 usa el control RichEdit 5.0 (MsftEdit 5.0), disponible en Windows Vista y posteriores. Proporciona significativamente más funciones que el control RichEdit estándar.
  • El resaltado de sintaxis se controla mediante lHighlight y se configura a través de los arrays aKeywords1, aKeywords2 y los valores de color nClrNumber, nClrString, nClrComment, nClrKey1, nClrKey2.
  • El indicador lBar habilita una barra de herramientas de formato integrada con botones de negrita, cursiva, subrayado, fuente, tamaño, color, alineación y tabla.
  • Use cText (acceso SETGET) para obtener o establecer el contenido de texto plano, o LoadRTF()/SaveAsRTF() para contenido RTF.
  • La corrección ortográfica (lSpell) resalta palabras mal escritas con un subrayado rojo.
  • La exportación a PDF y la vista previa de impresión están integradas mediante SaveToPDF() y Preview().
  • El control admite arrastrar y soltar archivos mediante la notificación EN_DROPFILES.

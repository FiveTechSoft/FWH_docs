TTabs

Fuente: source/classes/tabs.prg

Hereda de: TControl

TTabs es un control de barra de pestañas dibujado a medida que muestra una fila o columna de pestañas seleccionables. A diferencia de TFolder, TTabs solo dibuja la propia tira de pestañas sin un contenedor de páginas integrado. Admite orientaciones horizontales (arriba/abajo) y verticales (izquierda/derecha), etiquetas con bitmaps y navegación por teclado.

Miembros DATA Clave

DATATipoDescripción
aPromptsArrayArray con las cadenas de texto de las pestañas
nOptionNuméricoÍndice de la pestaña actualmente seleccionada (base 1)
nOrientationNuméricoOrientación de las pestañas: OR_TOP, OR_BOTTOM, OR_LEFT, OR_RIGHT
acBitmapsArrayArray de handles de bitmap o nombres de fichero para cada pestaña

Métodos

MétodoDescripción
New( nTop, nLeft, aPrompts, bAction, oWnd, nOption )Crea un nuevo control de barra de pestañas
SetOption( n )Selecciona la pestaña en el índice n
AddItem( cPrompt )Añade una nueva pestaña con el texto indicado
DelItem( nIndex )Elimina la pestaña en el índice especificado
SetTabs( aTabs )Reemplaza todas las definiciones de pestañas de una vez
GoTop()Selecciona la primera pestaña
GoLeft()Selecciona la pestaña de la izquierda
GoBottom()Selecciona la última pestaña
GoRight()Selecciona la pestaña de la derecha

Ejemplo: Barra de 3 Pestañas

#include "FiveWin.ch"

function Main()

   local oWnd, oTabs, nOpt := 1

   DEFINE WINDOW oWnd TITLE "TTabs Demo" SIZE 500, 300

   @ 10, 10 TAB oTabs PROMPTS "Files", "Edit", "View" ;
      SIZE 460, 30 OF oWnd ACTION oWnd:Refresh()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTabs es una tira de pestañas independiente. Combínela con TPages o con un mecanismo de cambio de diálogos para construir una interfaz con pestañas completa.
  • Las constantes de orientación son OR_TOP (predeterminada), OR_BOTTOM, OR_LEFT y OR_RIGHT.
  • Use acBitmaps para asignar imágenes bitmap a pestañas individuales. Los bitmaps pueden especificarse como nombres de fichero o handles de recurso.
  • El bloque de código bAction se evalúa cada vez que se selecciona una pestaña diferente.

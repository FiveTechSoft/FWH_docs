TTrayIcon

Fuente: source/classes/ttray.prg

Clase independiente (no derivada de TControl)

TTrayIcon crea y gestiona un icono en el área de notificación de la bandeja del sistema de Windows. Permite que las aplicaciones se ejecuten minimizadas o en segundo plano, a la vez que ofrece interacción con el usuario mediante eventos de clic del ratón, un tooltip y un menú contextual. Se utiliza habitualmente para servicios en segundo plano, aplicaciones tipo mensajería instantánea y aplicaciones que se minimizan a la bandeja del sistema.

Miembros DATA Principales

DATATipoDescripción
oWndObjetoLa ventana principal asociada (oculta o visible)
oWndParentObjetoLa ventana padre para el reenvío de notificaciones
oIconObjetoEl icono mostrado en la bandeja del sistema
cCaptionCarácterTexto del tooltip mostrado al pasar el ratón por encima
bLClickedBloqueBloque de código ejecutado al hacer clic con el botón izquierdo
bRClickedBloqueBloque de código ejecutado al hacer clic con el botón derecho
bLDblClickBloqueBloque de código ejecutado al hacer doble clic con el botón izquierdo

Métodos

MétodoDescripción
New( oWnd, oIcon, cTip, bLClick, bRClick )Crea un nuevo icono de bandeja
End()Elimina el icono de la bandeja del sistema y libera los recursos
Refresh( oIcon, cTip )Refresca la visualización del icono de bandeja
SetIcon( oIcon, cTip )Cambia el icono y/o el texto del tooltip
SetText( cTitle )Establece el texto del título

Ejemplo: Icono de Bandeja con Menú y Restauración al Hacer Doble Clic

#include "FiveWin.ch"

function Main()

   local oWnd, oTray, oMenu

   DEFINE WINDOW oWnd TITLE "Tray Demo" SIZE 400, 300

   oTray := TTrayIcon():New( oWnd, "app.ico", "My Application",;
      {|| MsgInfo( "Left click" ) },;
      {|| oMenu:Show( oTray ) } )

   oTray:bLDblClick := {|| oWnd:Restore(), oWnd:SetFocus() }

   MENU oMenu POPUP
      MENUITEM "&Restore"   ACTION {|| oWnd:Restore() }
      MENUITEM "&Exit"      ACTION {|| oTray:End(), oWnd:End() }
   ENDMENU

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTrayIcon no hereda de TControl; es una clase independiente que interactúa directamente con el área de notificación del shell de Windows mediante llamadas a la API Shell_NotifyIcon.
  • El parámetro oIcon puede ser la ruta de un archivo de icono (.ico), el nombre de un recurso o un número que identifica un icono de recurso.
  • Llame siempre a End() antes de que la aplicación finalice para eliminar el icono de la bandeja. No hacerlo puede dejar un icono fantasma hasta que el usuario pase el ratón por encima.
  • Los bloques de código bLClicked, bRClicked y bLDblClick proporcionan interacción completa con el ratón. El clic derecho se utiliza normalmente para mostrar un menú contextual emergente.
  • En Windows 11, la visibilidad del icono de bandeja puede depender de la configuración del sistema del "Área de notificación". Utilice SetIcon() para actualizar el icono dinámicamente en tiempo de ejecución.

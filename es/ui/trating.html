TRating

Fuente: source/classes/trating.prg

Hereda de: TControl

TRating es un control interactivo de valoración por estrellas que permite a los usuarios seleccionar un valor haciendo clic en imágenes de estrellas. Soporta vista previa al pasar el ratón, selección por clic, visualización de medias estrellas y valores máximos configurables. El control usa tres estados de imagen (vacía, media, llena) para representar la valoración visual.

Ejemplo: Control de Valoración de 5 Estrellas

#include "FiveWin.ch"

function Main()

   local oWnd, oRating, nRating := 0

   DEFINE WINDOW oWnd TITLE "Rate this App" SIZE 400, 250

   @ 60, 40 RATING oRating ;
      RATING 5 ;
      EMPTY   "star_empty.bmp" ;
      HALF    "star_half.bmp"  ;
      FULL    "star_full.bmp"  ;
      OF oWnd ;
      MAX 100 ;
      INITIAL 0 ;
      CHANGE ( nRating := oRating:nSelectedValue, ;
               oWnd:SetText( "Rating: " + Str( nRating ) ) )

   @ 140, 40 SAY "Click a star to rate" ;
      SIZE 200, 20 OF oWnd

   @ 180, 40 BUTTON "Reset" SIZE 60, 25 OF oWnd ;
      ACTION oRating:Reset()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El comando RATING requiere tres imágenes de mapa de bits para los tres estados visuales: EMPTY (no seleccionada), HALF (medio llena) y FULL (completamente seleccionada).
  • nRating especifica el número de imágenes de estrella mostradas (ej., 5 para una valoración de 5 estrellas). MAX establece el valor numérico máximo (predeterminado 100), y el control mapea la posición visual a un valor proporcional.
  • El bloque de código CHANGE no recibe parámetro; lea oRating:nSelectedValue dentro del bloque para obtener la valoración actual.
  • Use bSetGet para enlazar la valoración a una variable o campo de base de datos. El bloque de código se evalúa en la creación para leer el valor inicial y al hacer clic para escribir el nuevo valor.
  • El comportamiento de vista previa se maneja automáticamente: MouseMove actualiza nCurrentValue para retroalimentación visual en tiempo real, y MouseLeave restaura la visualización a nSelectedValue.
  • El miembro de datos nPercentual controla el factor de escala. Con el valor predeterminado de 100, al hacer clic en la última estrella se establece el valor en 100. Ajústelo para diferentes escalas de valoración.

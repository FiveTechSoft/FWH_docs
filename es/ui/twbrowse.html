TWBrowse

Fuente: source/classes/wbrowse.prg

Hereda de: TControl

TWBrowse es el control de navegación original de FiveWin para recorrer registros de bases de datos y datos en arrays con un formato tabular. Proporciona cabeceras de columna, ajuste de ancho de columnas, navegación por teclado, edición en línea e integración con objetos de base de datos, arrays y recordsets ADO. TXBrowse es su sucesor moderno, pero TWBrowse sigue en uso activo para escenarios más sencillos.

Ejemplo: Browse de 3 Columnas Vinculado a DBF

#include "FiveWin.ch"

function Main()

   local oWnd, oBrw

   USE CUSTOMER NEW

   DEFINE WINDOW oWnd TITLE "Customers" SIZE 600, 400

   @ 10, 10 BROWSE oBrw ;
      HEADERS "Code", "Name", "City" ;
      SIZES 60, 200, 150 ;
      OF oWnd

   oBrw:SetOBJ( TDatabase():Open( nil, "CUSTOMER" ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TWBrowse admite tres modos de vinculación de datos: array (SetArray), objeto de base de datos (SetOBJ) y recordset ADO (SetADO).
  • Para navegar DBF de forma sencilla sin un objeto TDatabase explícito, el browse usa automáticamente el área de trabajo actual (cAlias).
  • El bloque de código bLine permite el renderizado personalizado de filas. Recibe como parámetros el objeto de fila y el array de valores de columna.
  • Use bSkip para implementar lógica de navegación personalizada con fuentes de datos no estándar.
  • Para proyectos nuevos, considere usar TXBrowse, que ofrece características más completas como cabeceras con bitmaps, pies, grupos y estilos avanzados.

TSayBarCode

Fuente: source/classes/tsaybcod.prg

Hereda de: TControl

TSayBarCode renderiza códigos de barras como un control visual en ventanas y diálogos. Soporta múltiples simbologías de códigos de barras (Code 128, Code 39, EAN, etc.) con orientación configurable, tamaño de pin y banderas de visualización. El control puede vincularse a una variable de datos para actualización automática.

Miembros DATA Principales

DATATipoDescripción
cTextCharacterCadena de texto a codificar en el código de barras
bGetCode blockBloque de código que devuelve el valor del texto del código de barras
BarCodeTypeNumericTipo de simbología del código de barras (predeterminado 128 para Code 128)
lVerticalLogicalRenderizar el código de barras verticalmente
nPinSizeNumericAncho del elemento de barra más estrecho en píxeles
nFlagsNumericBanderas de renderizado adicionales para el motor de códigos de barras

Métodos

Comandos

@ nRow, nCol SAYBARCODE oBar VAR bBlock TYPE cType SIZE nW, nH OF oDlg

Ejemplo: Código de Barras Code128

#include "FiveWin.ch"

function Main()

   local oWnd, oBar
   local cCode := "ABC-12345"

   DEFINE WINDOW oWnd TITLE "Barcode Demo" SIZE 400, 200

   @ 20, 20 SAYBARCODE oBar VAR { || cCode } ;
      TYPE "CODE128" SIZE 360, 80 OF oWnd

   oBar:nPinSize := 2
   oBar:lVertical := .F.

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El BarCodeType predeterminado es 128 (Code 128). Otros tipos compatibles incluyen 39 (Code 39), EAN-13, EAN-8, UPC-A e Interleaved 2 of 5.
  • Establezca lVertical a .T. para aplicaciones donde el espacio vertical es más abundante que el horizontal.
  • La propiedad nPinSize controla el ancho de la barra más estrecha. Auméntelo para códigos de barras más grandes adecuados para distancias de escaneo largas.
  • Use un bloque de código bGet (o la cláusula VAR) para vincular el código de barras a una variable que se actualiza automáticamente.
  • Llame a Refresh() después de cambiar cualquier propiedad de renderizado para actualizar la visualización.

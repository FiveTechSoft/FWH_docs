TRadio

Fuente: source/classes/radio.prg

Hereda de: TControl

TRadio implementa un botón de radio individual (estilo de botón de radio automático). Los botones de radio se usan en grupos donde solo una opción puede seleccionarse a la vez. Normalmente son gestionados por un padre TRadMenu que maneja la exclusión mutua y la navegación por teclado dentro del grupo.

Miembros DATA Principales

DATATipoDescripción
lCheckedLogicalEstado marcado actual del botón de radio
oRadMenuObjectTRadMenu padre que gestiona este grupo de botones de radio
nPosNumericPosición/índice de este botón dentro del grupo

Métodos

MétodoDescripción
New( nRow, nCol, cPrompt, oWnd, bSetGet, lChecked, nPos, oRadMenu )Crear un botón de radio; bSetGet es un bloque de código SETGET para el valor seleccionado
Redefine( nId, lChecked, nPos, oDlg, oRadMenu )Redefinir desde un recurso de diálogo
SetCheck( lOnOff )Establecer el estado marcado y actualizar el control de botón de Windows
IsChecked()Consultar el estado marcado del botón desde Windows
Check()Establecer marcado a .T. (método de conveniencia)
UnCheck()Establecer marcado a .F. (método de conveniencia)
Click()Manejar clic: selecciona este botón en el TRadMenu padre y actualiza

Comandos

@ nRow, nCol RADIO oRad VAR nOpt PROMPT cText OF oDlg

Ejemplo: Grupo de Radio con TRadMenu

#include "FiveWin.ch"

function Main()

   local oWnd, oRadMenu, nOption := 1

   DEFINE WINDOW oWnd TITLE "Radio Demo" SIZE 300, 200

   @ 10, 10 RADIO oRadMenu VAR nOption ;
      ITEMS "Option &1", "Option &2", "Option &3" ;
      OF oWnd SIZE 120, 80

   @ 100, 10 BUTTON "Show" SIZE 60, 25 OF oWnd ;
      ACTION MsgInfo( "Selected: " + Str( nOption ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Cada TRadio es un control de Windows BS_AUTORADIOBUTTON. El primer botón en un grupo debe usar el parámetro lGroup (estilo WS_GROUP) para definir los límites del grupo.
  • ACCESS lChanged compara el estado marcado actual con el valor original, útil para seguimiento de cambios.
  • Los botones TRadio se crean típicamente mediante el comando RADIO, que configura automáticamente el TRadMenu y los objetos TRadio individuales.
  • La navegación por teclado (teclas de flecha) dentro del grupo es gestionada por el TRadMenu padre.

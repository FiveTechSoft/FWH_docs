TRibbonBar

Fuente: source/classes/tribbonbar.prg

Descripción

TRibbonBar — clase de barra de cintas del framework FiveWin para Harbour/xHarbour.

Aceleradores

TRibbonBar soporta aceleradores estándar de Windows con & para cambiar de pestaña. Coloque & antes de la letra deseada en cada prompt:

DEFINE RIBBONBAR oRBar WINDOW oWnd ;
   PROMPT "&Configuración", "&Ficheros", "&Informes", "&Ayudas" ;
   HEIGHT 133 TOPMARGIN 25

Cuando lUseAcc es .F. (por defecto), al pulsar Alt+letra se cambia a la pestaña correspondiente. La letra subrayada se muestra en el prompt de la pestaña. No se muestran los recuadros de keytip con números.

Para activar el overlay de keytip (recuadros numerados), establezca oRBar:lUseAcc := .T..

TPanel

Fuente: source/classes/tpanel.prg

Hereda de: TControl

TPanel es un control contenedor que aloja controles hijos con soporte para transparencia, color de fondo personalizado y un borde opcional. Se usa comúnmente para agrupar controles relacionados visualmente dentro de un diálogo o ventana. El panel se puede diseñar en tiempo de ejecución o vincularse a un recurso de diálogo.

Miembros DATA Principales

DATATipoDescripción
aControlsArrayArray de controles hijos alojados en el panel
nOpacityNumericNivel de opacidad de 0 (transparente) a 255 (opaco)
nClrPaneNumericColor de relleno de fondo (valor RGB)

Métodos

MétodoDescripción
New( nTop, nLeft, nBottom, nRight, oWnd, lDesign, cVar, lBorder )Crear un nuevo control panel
Redefine( nId, oWnd )Redefinir desde un recurso de diálogo
Paint()Pintar el fondo y el borde del panel
GotFocus( hCtlLost )Manejar la llegada del foco; reenviar a controles hijos

Ejemplo: Panel con Controles Hijos

#include "FiveWin.ch"

function Main()

   local oWnd, oPanel

   DEFINE WINDOW oWnd TITLE "TPanel Demo" SIZE 500, 400

   @ 20, 20 PANEL oPanel SIZE 460, 200 OF oWnd ;
      TRANSPARENT COLOR CLR_BTNFACE

   @ 30, 40 SAY "Name:" OF oPanel SIZE 40, 12
   @ 30, 90 GET ... OF oPanel SIZE 120, 20

   @ 60, 40 SAY "Email:" OF oPanel SIZE 40, 12
   @ 60, 90 GET ... OF oPanel SIZE 180, 20

   @ 100, 40 BUTTON "Save" OF oPanel SIZE 60, 25

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use la cláusula TRANSPARENT para hacer el fondo del panel transparente. Cuando es transparente, los controles hijos se dibujan directamente sobre el fondo de la ventana padre.
  • La cláusula COLOR establece nClrPane para el relleno de fondo cuando la transparencia está deshabilitada.
  • TPanel admite edición en modo de diseño cuando lDesign es verdadero, permitiendo reposicionamiento por arrastrar y soltar de controles hijos en tiempo de ejecución durante el desarrollo.
  • El panel maneja la gestión del foco reenviando eventos GotFocus al primer control hijo.

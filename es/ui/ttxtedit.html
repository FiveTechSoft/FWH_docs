TTxtEdit

Fuente: source/classes/ttxtedit.prg

Hereda de: TControl

TTxtEdit es un control editor de texto para código fuente con soporte de resaltado de sintaxis. Proporciona edición orientada a líneas con modos de inserción/sobrescritura, operaciones de portapapeles, historial de deshacer/rehacer, diálogos de buscar y reemplazar, y comandos de manipulación de líneas. El coloreado de sintaxis basado en tokens puede personalizarse para diferentes lenguajes de programación.

Miembros DATA Clave

DATATipoDescripción
aLinesArrayArray de cadenas de caracteres, una por cada línea de texto
lInsertLógicoModo inserción cuando es .T., modo sobrescritura cuando es .F.
lChangedLógicoIndicador de que el texto ha sido modificado
cFileNameCarácterNombre del archivo asociado al documento editado
cTokens1 / cTokens2 / cTokens3CarácterListas de tokens para tres grupos de resaltado de sintaxis
nClrTok1 / nClrTok2 / nClrTok3NuméricoColores de texto para cada grupo de tokens
nClrNumberNuméricoColor para literales numéricos
nClrStringNuméricoColor para literales de cadena

Ejemplo: Editor con Resaltado de Sintaxis

#include "FiveWin.ch"

function Main()

   local oWnd, oEdit

   DEFINE WINDOW oWnd TITLE "Source Editor" SIZE 600, 400

   oEdit := TTxtEdit():New( 0, 0, 600, 380, oWnd )

   // Tokens de sintaxis de Harbour
   oEdit:cTokens1 := "function|procedure|local|if|else|endif|do|while|return"
   oEdit:nClrTok1 := CLR_BLUE

   oEdit:cTokens2 := "MAIN|NIL|TRUE|FALSE|.T.|.F."
   oEdit:nClrTok2 := CLR_RED

   oEdit:nClrNumber := CLR_PURPLE
   oEdit:nClrString := CLR_GREEN

   oEdit:Load( "source.prg" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El resaltado de sintaxis utiliza tres grupos de tokens (cTokens1 a cTokens3) con colores configurables de forma independiente.
  • Los tokens son cadenas delimitadas por barras verticales. Cada token se compara como palabra completa en el texto fuente.
  • El indicador lChanged se mantiene automáticamente; compruébelo antes de cerrar para solicitar el guardado.
  • Use DlgFind() y DlgGoLine() para ofrecer al usuario los diálogos estándar de Buscar e Ir a Línea.
  • El array aLines proporciona acceso directo a las líneas individuales para su manipulación programática.

TOutLook

Fuente: source/classes/outlook.prg

Hereda de: TControl

TOutLook implementa una barra de navegación estilo Outlook con grupos colapsables que contienen elementos de navegación con icono y texto. Se usa comúnmente como panel lateral en aplicaciones MDI o SDI para organizar destinos de navegación en categorías lógicas, similar al panel de carpetas de Microsoft Outlook.

Miembros DATA Principales

DATATipoDescripción
aGroupArrayArray de objetos de grupo que contienen elementos
nActualNumericÍndice del elemento actualmente seleccionado

Métodos

MétodoDescripción
New( nTop, nLeft, nW, nH, nClrF, nClrB, nStyle, oFont, lPixel, oWnd )Crear un nuevo control TOutLook
AddGroup( cPrompt )Agregar un nuevo grupo colapsable con el título indicado
AddItem( cPrompt, cBmp, cRes, bAction, nGroup )Agregar un elemento al grupo especificado
Set( nGroup )Expandir un grupo específico por su índice
DeleteItem( oItem )Eliminar un elemento de su grupo
MoveToGroup( xItem, nGroup )Mover un elemento (por índice u objeto) a un grupo diferente
SaveOrder()Devolver el orden actual de grupo/elemento como una cadena serializada
RestoreOrder( cOrder )Restaurar un orden de grupo/elemento previamente guardado

Ejemplo: Dos Grupos con Elementos

#include "FiveWin.ch"

function Main()

   local oWnd, oOutLook

   DEFINE WINDOW oWnd TITLE "Outlook Bar" SIZE 300, 500

   @ 10, 10 OUTLOOK oOutLook ;
      SIZE 280, 460 OF oWnd

   oOutLook:AddGroup( "Mail" )
   oOutLook:AddItem( "Inbox",    "mail1.ico", , {|| MsgInfo( "Inbox" ) }, 1 )
   oOutLook:AddItem( "Sent",     "mail2.ico", , {|| MsgInfo( "Sent" ) }, 1 )
   oOutLook:AddItem( "Drafts",   "mail3.ico", , {|| MsgInfo( "Drafts" ) }, 1 )

   oOutLook:AddGroup( "Calendar" )
   oOutLook:AddItem( "Today",    "cal1.ico",  , {|| MsgInfo( "Today" ) }, 2 )
   oOutLook:AddItem( "Week",     "cal2.ico",  , {|| MsgInfo( "Week" ) }, 2 )
   oOutLook:AddItem( "Month",    "cal3.ico",  , {|| MsgInfo( "Month" ) }, 2 )

   oOutLook:Set( 1 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Los grupos se muestran como encabezados colapsables. Al hacer clic en un encabezado de grupo, se expande y colapsa el grupo expandido anteriormente.
  • Los elementos muestran un icono y un título. El parámetro cBmp acepta una ruta de archivo de mapa de bits, nombre de recurso o icono.
  • El bloque de código bAction en AddItem() se ejecuta cuando el usuario hace clic en el elemento.
  • Use SaveOrder() para persistir la disposición personalizada de grupos/elementos del usuario (por ejemplo, en el registro o un archivo INI) y RestoreOrder() para recargarla en la siguiente sesión.
  • El control maneja automáticamente el desplazamiento vertical cuando los grupos y elementos exceden el área visible.

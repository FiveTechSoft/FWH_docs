TVideo

Fuente: source/classes/video.prg

Hereda de: TControl

TVideo es un control de reproducción multimedia que utiliza la interfaz MCI (Media Control Interface) de Windows para reproducir archivos de vídeo. Admite AVI y otros formatos de vídeo compatibles con MCI. El control muestra el vídeo en un área rectangular dentro de una ventana o diálogo de FiveWin, con renderizado sin borde opcional.

Miembros DATA Principales

DATATipoDescripción
oMciObjetoObjeto interno del dispositivo MCI que gestiona la reproducción
cAviFileCarácterRuta al archivo AVI (u otro vídeo)
cTypeCarácterCadena del tipo de dispositivo MCI (p. ej., "AVIVideo")

Métodos

MétodoDescripción
New( nRow, nCol, nW, nH, cFile, oWnd, lNoBorder, cType )Crea un nuevo control de reproducción de vídeo
Play( nFrom, nTo )Reproduce el vídeo desde el fotograma nFrom hasta nTo. Si se omite, reproduce el vídeo completo.
PlayFull()Reproduce el vídeo en modo pantalla completa
Position()Devuelve la posición de reproducción actual en fotogramas
Length()Devuelve el número total de fotogramas del vídeo
End()Detiene la reproducción y cierra el dispositivo MCI

Ejemplo: Reproducir un archivo AVI

#include "FiveWin.ch"

function Main()

   local oWnd, oVideo

   DEFINE WINDOW oWnd TITLE "Reproductor de Vídeo" SIZE 640, 520

   @ 10, 10 VIDEO oVideo FILE "sample.avi" ;
      SIZE 600, 450 OF oWnd

   oVideo:Play()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TVideo encapsula la API MCI de Windows (mciSendString) para la reproducción de vídeo. Asegúrese de que los controladores MCI adecuados estén instalados en el sistema de destino.
  • Utilice el parámetro lNoBorder en New() para eliminar el borde alrededor del área de visualización del vídeo.
  • El parámetro cType especifica el tipo de dispositivo MCI. El valor predeterminado es "AVIVideo" para archivos AVI.
  • Llame a End() cuando el vídeo ya no sea necesario para liberar los recursos del dispositivo MCI.

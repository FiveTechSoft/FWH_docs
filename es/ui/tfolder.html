TFolder

Control de pestañas para organizar diálogos complejos en páginas

Fuente: source/classes/folder.prg  |  Padre: TControl

Visión General

TFolder implementa un control de pestañas de Windows. Cada página de pestaña es un objeto TDialog independiente, por lo que puede colocar cualquier control en cada página usando la sintaxis estándar de diálogos. El folder gestiona qué página es visible cuando el usuario hace clic en una pestaña.

Características principales:

  • Cada página es un TDialog completo -- se puede colocar cualquier control en ella
  • Iconos en las pestañas mediante oImageList
  • Cambio de página programático mediante nOption
  • Pestañas arriba o abajo
  • Agregar/eliminar páginas dinámicamente en tiempo de ejecución

Propiedades Clave

PropiedadTipoDescripción
aPromptsArrayArray de cadenas para cada etiqueta de pestaña (ej. {"General", "Detalles", "Notas"})
aDialogsArrayArray de objetos TDialog, uno por página de pestaña
nOptionNumericÍndice de la pestaña seleccionada actualmente (basado en 1). Establezca este valor para cambiar de página programáticamente.

Métodos Clave

MétodoDescripción
New( nRow, nCol, oWnd, aPrompts, ... )Constructor. Crea el folder con las etiquetas de pestaña indicadas.
AddPage( cPrompt, oDlg )Agregar una nueva página en tiempo de ejecución.
DelPage( nPage )Eliminar una página en tiempo de ejecución.
SetOption( n )Cambiar a la página n programáticamente.
GetPage( n )Retorna el TDialog de la página n.

Sintaxis de Comandos

@ nRow, nCol FOLDER oFld ;
   OF oDlg ;
   PROMPTS "Tab1", "Tab2", "Tab3" ;
   DIALOGS oDlg1, oDlg2, oDlg3 ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ] ;
   [ BOTTOM ]

Cada variable de diálogo (oDlg1, oDlg2, oDlg3) se crea automáticamente como un TDialog hijo. Luego se colocan controles en cada diálogo de página en el bloque ACTIVATE DIALOG.

Ejemplos de Código

Ejemplo 1: Diálogo de Edición de Cliente con Pestañas

#include "FiveWin.ch"

FUNCTION CustomerEdit()
   LOCAL oDlg, oFld, oFont
   LOCAL oDlg1, oDlg2, oDlg3
   LOCAL cName   := "John Smith"
   LOCAL cPhone  := "(555)123-4567"
   LOCAL cEmail  := "john@example.com"
   LOCAL cAddr   := "123 Main St"
   LOCAL cCity   := "New York"
   LOCAL cState  := "NY"
   LOCAL cZip    := "10001"
   LOCAL nCredit := 5000.00
   LOCAL cNotes  := "VIP customer since 2015"
   LOCAL lActive := .T.

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14

   DEFINE DIALOG oDlg TITLE "Edit Customer" ;
      SIZE 520, 420 FONT oFont

   // Crear el folder con 3 pestañas
   @ 0.5, 0.5 FOLDER oFld ;
      OF oDlg ;
      PROMPTS "General", "Address", "Notes" ;
      DIALOGS oDlg1, oDlg2, oDlg3 ;
      SIZE 490, 310

   // --- Página 1: General ---
   @ 1.0, 1 SAY "Name:" OF oDlg1
   @ 1.0, 5 GET cName OF oDlg1 SIZE 200, 22 PICTURE "@!"

   @ 2.5, 1 SAY "Phone:" OF oDlg1
   @ 2.5, 5 GET cPhone OF oDlg1 SIZE 140, 22 PICTURE "(999)999-9999"

   @ 4.0, 1 SAY "Email:" OF oDlg1
   @ 4.0, 5 GET cEmail OF oDlg1 SIZE 220, 22

   @ 5.5, 1 SAY "Credit Limit:" OF oDlg1
   @ 5.5, 5 GET nCredit OF oDlg1 SIZE 120, 22 PICTURE "@E 99,999.99"

   @ 7.0, 1 CHECKBOX lActive PROMPT "Active Customer" OF oDlg1

   // --- Página 2: Dirección ---
   @ 1.0, 1 SAY "Street:" OF oDlg2
   @ 1.0, 5 GET cAddr OF oDlg2 SIZE 280, 22

   @ 2.5, 1 SAY "City:" OF oDlg2
   @ 2.5, 5 GET cCity OF oDlg2 SIZE 180, 22

   @ 4.0, 1 SAY "State:" OF oDlg2
   @ 4.0, 5 GET cState OF oDlg2 SIZE 40, 22 PICTURE "!!"

   @ 4.0, 9 SAY "ZIP:" OF oDlg2
   @ 4.0, 11 GET cZip OF oDlg2 SIZE 80, 22 PICTURE "99999"

   // --- Página 3: Notas ---
   @ 0.5, 1 GET cNotes MEMO OF oDlg3 SIZE 440, 200

   // Botones debajo del folder
   @ 24, 12 BUTTON "&Save"   OF oDlg SIZE 80, 25 ACTION oDlg:End() DEFAULT
   @ 24, 22 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   RELEASE FONT oFont
RETURN NIL

Ejemplo 2: Folder con Browse y Cambio Dinámico de Página

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION DataViewer()
   LOCAL oDlg, oFld, oBrw
   LOCAL oDlg1, oDlg2
   LOCAL aLog := { ;
      { "2026-03-24 09:00", "Login",  "admin" }, ;
      { "2026-03-24 09:15", "Edit",   "admin" }, ;
      { "2026-03-24 10:00", "Export", "user1" }  ;
   }

   DEFINE DIALOG oDlg TITLE "Data Viewer" SIZE 600, 450

   @ 0.2, 0.2 FOLDER oFld ;
      OF oDlg ;
      PROMPTS "Browse Data", "Activity Log" ;
      DIALOGS oDlg1, oDlg2 ;
      SIZE 570, 340

   // Notificar cuando cambia la pestaña
   oFld:bChange := {|| MsgBeep() }

   // --- Página 1: XBrowse de un DBF ---
   USE Customer VIA "DBFCDX" NEW
   oBrw := TXBrowse():New( oDlg1 )
   oBrw:SetRDD()
   oBrw:CreateFromCode()
   oDlg1:oClient := oBrw

   // --- Página 2: XBrowse de un array ---
   LOCAL oBrw2 := TXBrowse():New( oDlg2 )
   oBrw2:SetArray( aLog )
   oBrw2:aCols := {}
   oBrw2:AddColumn( "Timestamp", {|| aLog[ oBrw2:nArrayAt ][ 1 ] } )
   oBrw2:AddColumn( "Action",    {|| aLog[ oBrw2:nArrayAt ][ 2 ] } )
   oBrw2:AddColumn( "User",      {|| aLog[ oBrw2:nArrayAt ][ 3 ] } )
   oBrw2:CreateFromCode()
   oDlg2:oClient := oBrw2

   // Botones
   @ 27, 18 BUTTON "&Close" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   // Saltar a la pestaña Registro de Actividad programáticamente
   @ 27, 2 BUTTON "Show &Log" OF oDlg SIZE 100, 25 ;
      ACTION oFld:SetOption( 2 )

   ACTIVATE DIALOG oDlg CENTERED

   CLOSE Customer
RETURN NIL

Consejos

  • Coloque los controles en cada diálogo de página (oDlg1, oDlg2, ...) -- no en el diálogo padre oDlg.
  • Los botones que deben permanecer visibles en todas las pestañas (Guardar, Cancelar) van en el diálogo padre, posicionados debajo del folder.
  • Use oFld:SetOption( n ) para cambiar de pestaña desde el código, por ejemplo en respuesta a un clic de botón.
  • Use bChange para actualizar datos cuando el usuario cambia de pestaña (ej. refrescar un browse en una pestaña).
  • Para agregar iconos a las pestañas, cree un TImageList y asígnelo a oFld:oImageList antes de la activación.
  • Cada diálogo de página hereda la fuente del diálogo padre, así que establezca la fuente en el padre para mantener consistencia.

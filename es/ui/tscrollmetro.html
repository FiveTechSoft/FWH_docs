TScrollMetro

Fuente: source/classes/scrollm.prg

Hereda de: TControl

TScrollMetro proporciona un control de barra de desplazamiento moderno estilo Metro. Reemplaza la barra de desplazamiento clásica de Windows con un diseño plano y táctil adecuado para tabletas y aplicaciones de interfaz moderna. El control soporta posicionamiento programático, gestión de rango y enlaces de eventos de bloques de código para todas las acciones de desplazamiento.

Miembros DATA Principales

DATATipoDescripción
lVerticalLógicoOrientación: .T. para vertical, .F. para horizontal
nMin / nMaxNuméricoValores mínimo y máximo del rango de desplazamiento
nPgStepNuméricoIncremento de paso de página para acciones de avance/retroceso de página
nPosNuméricoPosición actual del pulgar de desplazamiento
bGoUp / bGoDownBloque de códigoSe ejecuta cuando se hace clic en el botón arriba/izquierda o abajo/derecha
bGoTop / bGoBottomBloque de códigoSe ejecuta cuando el pulgar se arrastra al tope o al fondo
bPageUp / bPageDownBloque de códigoSe ejecuta al hacer clic en el área de la pista de avance/retroceso de página
bPos / bTrackBloque de códigoSe ejecuta en cambio de posición y seguimiento del pulgar

Métodos

MétodoDescripción
New( nRow, nCol, nMin, nMax, nPgStep, lVert, oWnd, nW, nH )Crear una nueva barra de desplazamiento Metro con rango, paso y orientación
SetRange()Actualizar el rango de desplazamiento desde los valores nMin y nMax
SetPos( nPos ) / GetPos()Establecer u obtener la posición actual del pulgar de desplazamiento
GoUp() / GoDown()Mover el pulgar arriba (o izquierda) / abajo (o derecha) un paso
GoTop() / GoBottom()Mover el pulgar a la posición mínima o máxima
PageUp() / PageDown()Mover el pulgar según la cantidad del paso de página

Ejemplo: Barra de Desplazamiento Vertical para Browse

#include "FiveWin.ch"

function Main()

   local oWnd, oScroll
   local nPos := 0

   DEFINE WINDOW oWnd TITLE "TScrollMetro Demo" SIZE 400, 300

   oScroll := TScrollMetro():New( 10, 370, 0, 100, 10, .T., oWnd, 20, 250 )

   oScroll:bGoUp    := { || nPos := oScroll:GetPos(), oWnd:Refresh() }
   oScroll:bGoDown  := { || nPos := oScroll:GetPos(), oWnd:Refresh() }
   oScroll:bPageUp  := { || nPos := oScroll:GetPos(), oWnd:Refresh() }
   oScroll:bPageDown:= { || nPos := oScroll:GetPos(), oWnd:Refresh() }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El control dispara eventos de bloques de código para cada acción de desplazamiento: bGoUp, bGoDown, bGoTop, bGoBottom, bPageUp, bPageDown, bPos y bTrack.
  • La orientación se define en el momento de creación mediante el parámetro lVert y no se puede cambiar dinámicamente.
  • Use SetRange() después de cambiar nMin o nMax para recalibrar el pulgar de desplazamiento.
  • La barra de desplazamiento Metro es particularmente adecuada para aplicaciones con pantalla táctil donde la pista estrecha de las barras clásicas es difícil de interactuar.

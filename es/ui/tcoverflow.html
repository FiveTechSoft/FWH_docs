TCoverFlow

Fuente: source/classes/tcvrflow.prg

Hereda de: TControl

TCoverFlow is a cover-flow image browser control inspired by the iTunes / Apple Cover Flow user interface. It displays a horizontal row of images with the center item enlarged and the side items angled outward. Users can navigate left and right via mouse clicks, keyboard arrows, or programmatic calls.

Miembros DATA Principales

DATATipoDescripción
aCoversArrayArray de definiciones de cubierta (mapa de bits, texto, color)
nAtNumericÍndice de la cubierta actualmente seleccionada
nAngleNumericÁngulo (en grados) aplicado a las cubiertas laterales
nSeparationNumericSeparación en píxeles entre cubiertas
nCoverWidthNumericAncho de cada imagen de cubierta
bActionBlockBloque de código evaluado cuando se selecciona una cubierta

Methods

MétodoDescripción
New( nTop, nLeft, nBottom, nRight, oWnd )Crear un nuevo control TCoverFlow
AddCover( cBmp, cText, nClrText )Agregar una cubierta con mapa de bits, título y color de texto
GoLeft()Navegar una cubierta a la izquierda
GoRight()Navegar una cubierta a la derecha
GoTo( n )Saltar directamente a la cubierta en el índice n
AtCover( nRow, nCol )Devuelve el índice de cubierta en las coordenadas de píxel dadas

Ejemplo: Explorador de Álbumes

#include "FiveWin.ch"

function Main()

   local oWnd, oCover, aCovers := { "cover1.jpg", "cover2.jpg", "cover3.jpg" }

   DEFINE WINDOW oWnd TITLE "Album Browser" SIZE 800, 400

   @ 20, 20 COVERFLOW oCover ;
      SIZE 760, 320 OF oWnd ;
      ACTION ( MsgInfo( "Selected cover #" + Str( oCover:nAt ) ) )

   oCover:AddCover( "cover1.jpg", "Album One",   CLR_WHITE )
   oCover:AddCover( "cover2.jpg", "Album Two",   CLR_WHITE )
   oCover:AddCover( "cover3.jpg", "Album Three", CLR_WHITE )

   oCover:nAngle      := 20
   oCover:nSeparation := 60
   oCover:nCoverWidth := 200
   oCover:GoTo( 1 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • El método AddCover() espera una ruta de archivo de mapa de bits o un nombre de recurso para cBmp. Las imágenes se escalan internamente a nCoverWidth preservando la relación de aspecto.
  • La navegación puede realizarse con clics del ratón en las cubiertas izquierda/derecha o usando las teclas de flecha izquierda/derecha cuando el control tiene el foco.
  • El bloque de código bAction (o la cláusula ACTION en el comando COVERFLOW) se dispara cuando el usuario hace doble clic o presiona Enter en la cubierta central.
  • El método AtCover() es útil para pruebas de impacto durante el manejo personalizado del ratón.
  • Ajuste nAngle y nSeparation para controlar la perspectiva y el espaciado de las cubiertas laterales.

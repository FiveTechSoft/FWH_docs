TPages

Fuente: source/classes/tpages.prg

Hereda de: TControl, usa TPagesDialog

TPages es un contenedor de páginas con pestañas que gestiona una colección de páginas de diálogo dentro de un área de ventana padre única. Cada página es un diálogo alojado dentro del contenedor, y el usuario cambia entre páginas mediante programación o a través de controles de pestañas asociados. Internamente funciona con TPagesDialog para renderizar cada superficie de página.

Miembros DATA Principales

DATATipoDescripción
nOptionNumericÍndice de la página actualmente seleccionada (basado en 1)
aDialogsArrayArray de objetos de diálogo hijo, uno por página
aPagesArrayArray de definiciones de página { cTitle, nId, bInit }
bChangeBlockBloque de código ejecutado cuando cambia la página activa

Métodos

MétodoDescripción
New( nRow, nCol, nBottom, nRight, oWnd )Crear un nuevo contenedor TPages dentro de una ventana
Redefine( nId, oWnd, aDialogs, nOption, bChange )Recrear desde un control de recurso de diálogo
AddPage( cPage )Agregar una nueva página con el título indicado
DelPage( nPage )Eliminar la página en el índice especificado
SetOption( n )Cambiar a la página en el índice n
GoPrev()Cambiar a la página anterior
GoNext()Cambiar a la página siguiente

Ejemplo: Contenedor de Dos Páginas

#include "FiveWin.ch"

function Main()

   local oWnd, oPages

   DEFINE WINDOW oWnd TITLE "TPages Demo" SIZE 500, 400

   @ 10, 10 PAGES oPages SIZE 460, 340 OF oWnd

   oPages:AddPage( "General" )
   oPages:AddPage( "Advanced" )

   @ 20, 20 SAY "User Name" OF oPages:aDialogs[ 1 ] SIZE 60, 12
   @ 20, 100 GET ... OF oPages:aDialogs[ 1 ]

   @ 20, 20 SAY "Timeout" OF oPages:aDialogs[ 2 ] SIZE 60, 12
   @ 20, 100 GET ... OF oPages:aDialogs[ 2 ]

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Cada página se implementa como un diálogo hijo no modal. Acceda a los controles hijos a través del objeto de diálogo correspondiente en aDialogs.
  • Use bChange para realizar validación o actualizar el estado de la interfaz cuando el usuario cambie de página.
  • TPagesDialog es la clase de diálogo interna utilizada para cada superficie de página; no se instancia directamente normalmente.
  • El contenedor ejecuta el bloque de código bChange con el nuevo índice de opción cada vez que se cambia de página.

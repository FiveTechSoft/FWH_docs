TSliderMetro

Fuente: source/classes/sliderm.prg

No hereda de TControl (clase independiente)

TSliderMetro implementa una pantalla de deslizar para desbloquear al estilo de Windows Metro / Modern UI. Muestra una superposición de bitmap a pantalla completa con los textos "FiveWin touch" y "Slide to unlock", y responde a gestos de arrastre vertical. Arrastrar el bitmap hacia arriba revela la ventana subyacente. Está diseñada para aplicaciones de tipo quiosco o tablet con pantalla táctil.

Miembros DATA Principales

DATATipoDescripción
oBmpObjetoInstancia de TBitmap que contiene la imagen de fondo a pantalla completa
oFont1ObjetoFuente grande ("Segoe UI Light" 90pt negrita) para el texto del título
oFont2ObjetoFuente mediana ("Segoe UI Light" 60pt negrita) para el texto de instrucción
lDragLógicoIndica que hay una operación de arrastre en curso

Métodos

MétodoDescripción
New( cBmpFile, oWnd )Crea una superposición de deslizar para desbloquear. Carga el bitmap de fondo y crea las fuentes del título
GoBottom()Anima el bitmap de vuelta a la posición bloqueada (nTop = 0)
GoTop()Anima el bitmap hacia arriba fuera de pantalla para desbloquear la ventana
MouseMove( nRow, nCol )Realiza el seguimiento de la distancia de arrastre vertical y reposiciona el bitmap en consecuencia

Ejemplo: Pantalla de Desbloqueo

#include "FiveWin.ch"

function Main()

   local oWnd, oLock

   DEFINE WINDOW oWnd TITLE "App" SIZE 800, 600

   oLock = TSliderMetro():New( "lock_bg.jpg", oWnd )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TSliderMetro no es descendiente de TControl; gestiona un TBitmap directamente a través del handle de la ventana.
  • El bitmap de fondo debería coincidir con las dimensiones de la ventana para lograr un efecto de pantalla completa sin cortes.
  • El texto se dibuja sobre el bitmap usando oBmp:Say() en el codeblock bPainted con color blanco y fuentes Segoe UI Light.
  • Arrastrar el bitmap más de la mitad hacia arriba activa GoTop(), que mueve el bitmap fuera de pantalla y habilita la ventana subyacente.
  • Arrastrar menos de la mitad o soltar por debajo del punto medio activa GoBottom(), que devuelve el bloqueo a su sitio.
  • GoTop() deshabilita la ventana de origen durante la animación y la vuelve a habilitar al finalizar.

TTimePick

Fuente: source/classes/ttmpicke.prg

Hereda de: TControl

TTimePick envuelve el control común de selector de fecha y hora de Windows configurado para selección de solo hora. Proporciona una interfaz intuitiva para seleccionar horas, minutos y segundos usando controles giratorios o entrada directa por teclado. El control opera sobre una cadena de hora en formato "HH:MM:SS".

Sintaxis del Comando

@ nRow, nCol TMPICKER oTmp VAR cTime SIZE nW, nH PIXEL OF oWnd ;
   ON CHANGE bBlock

Ejemplo: Time Picker with Change Callback

#include "FiveWin.ch"

function Main()

   local oWnd, oTmp, cTime := Time()   // e.g. "14:25:30"

   DEFINE WINDOW oWnd TITLE "Time Picker Demo" SIZE 300, 200

   @ 40, 30 TMPICKER oTmp VAR cTime SIZE 100, 22 PIXEL OF oWnd ;
      ON CHANGE MsgInfo( cTime, "Time Changed" )

   @ 100, 30 BUTTON "&Get Time" SIZE 80, 25 PIXEL OF oWnd ;
      ACTION MsgInfo( oTmp:GetTime(), "Current Time" )

   @ 100, 130 BUTTON "&Set 12:00" SIZE 80, 25 PIXEL OF oWnd ;
      ACTION oTmp:SetTime( "12:00:00" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

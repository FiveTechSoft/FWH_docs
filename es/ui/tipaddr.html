TIPAddress

Fuente: source/classes/tipaddr.prg

Hereda de: TControl

TIPAddress envuelve el control común de dirección IP de Win32, proporcionando un campo de entrada especializado para ingresar direcciones IPv4 en notación decimal separada por puntos. Cada uno de los cuatro octetos se edita en un segmento de campo separado, con validación incorporada y restricciones de rango opcionales por campo. Each of the four octets is edited in a separate field segment, with built-in validation and optional per-field range constraints.

Miembros DATA Principales

DATATipoDescripción
cIPAddressCharacterLa dirección IP actual como cadena (ej., "192.168.1.1")
aFieldRangesArrayArray de arrays de rango { nMin, nMax } para cada uno de los cuatro campos de octeto

Methods

Ejemplo: Entrada de Dirección IP con Rangos de Campo

#include "FiveWin.ch"

function Main()

   local oWnd, oIP

   DEFINE WINDOW oWnd TITLE "IP Address" SIZE 350, 150

   @ 40, 20 IPADDRESS oIP ;
      SIZE 120, 25 OF oWnd ;
      ADDRESS "192.168.1.1"

   // Restrict the first octet to valid private ranges
   oIP:SetRange( 1, 10, 192 )
   oIP:SetRange( 4, 1, 254 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TIPAddress envuelve el control común SysIPAddress32 de Win32. Solo maneja direcciones IPv4.
  • Use SetRange( nField, nMin, nMax ) para restringir octetos individuales. nField está basado en 1 (1 = octeto más a la izquierda, 4 = más a la derecha). nField is 1-based (1 = leftmost octet, 4 = rightmost).
  • El método GetAddress() devuelve una cadena vacía si el control está en blanco; use IsBlank() para verificar antes de leer.
  • La navegación entre campos de octeto es automática: presionar . (punto) o → mueve al siguiente campo.
  • La cláusula ADDRESS en el comando @ ... IPADDRESS establece el valor IP inicial.

TScrollPanelEx

Fuente: source/classes/scrollex.prg

Hereda de: TPanel

TScrollPanelEx es un panel desplazable mejorado que admite el desplazamiento horizontal de los controles hijos mediante teclado, rueda del ratón, barra de desplazamiento y gestos (entrada táctil/pan). Rastrea los controles hijos situados más a la izquierda y más a la derecha para calcular el rango de desplazamiento y proporciona una gestión automática de la barra de desplazamiento. Este panel se usa habitualmente para barras de herramientas, diseños tipo cinta (ribbon) y contenedores de desbordamiento.

Ejemplo: Panel de Desplazamiento Suave con Controles Hijos

#include "FiveWin.ch"

function Main()

   local oWnd, oPanel, oBtn

   DEFINE WINDOW oWnd TITLE "Demo de TScrollPanelEx" SIZE 600, 150

   @ 20, 20 SCROLLPANEX oPanel SIZE 560, 60 OF oWnd

   for n := 1 to 15
      @ 10, ( n - 1 ) * 90 BUTTON "Btn " + Str( n ) ;
         SIZE 80, 30 OF oPanel PIXEL
   next

   oPanel:SetRange()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Llame a SetRange() después de añadir todos los controles hijos para calcular los límites de desplazamiento y activar el seguimiento del foco para el auto-desplazamiento a la vista.
  • Use SetPage( cName, nCol ) junto con GoToPage( cName ) para la navegación por secciones con nombre.
  • El desplazamiento por arrastre se activa manteniendo pulsado el botón izquierdo del ratón y arrastrando horizontalmente sobre el fondo del panel.
  • Los gestos táctiles (pan) son compatibles en dispositivos con entrada táctil mediante el método HandleGesture (GID_PAN).

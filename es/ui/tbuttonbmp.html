TButtonBmp

Fuente: source/classes/buttonb.prg

Hereda de: TButton

TButtonBmp is a push button that displays a bitmap image alongside or instead of text. It supports multiple image formats, alpha-channel transparency, GDI+ rendering, color mapping, and flexible text positioning. TButtonBmp is commonly used inside TBar and TRibbonBar controls.

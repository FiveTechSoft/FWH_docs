TNavigator

Fuente: source/classes/navpanels.prg

Hereda de: TControl

TNavigator es un panel de navegación plegable con una barra de título degradada, botón de alternancia y reposicionamiento automático de paneles hermanos. Cuando está contraído, el panel se reduce a una barra vertical estrecha con un título rotado; cuando está expandido, revela los controles hijo. Múltiples instancias de TNavigator pueden vincularse mediante aRelatedNavigators para que al alternar un panel se reposicionen sus hermanos, ideal para barras de navegación acopladas lateralmente.

Ejemplo: Linked Navigator Panels

#include "FiveWin.ch"

function Main()

   local oWnd, oNav1, oNav2

   DEFINE WINDOW oWnd TITLE "Navigator" SIZE 600, 400

   oNav1 := TNavigator():New( 0, 0, 400, 200, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Files" )

   oNav2 := TNavigator():New( 0, 202, 400, 402, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Search" )

   oNav1:aRelatedNavigators := { oNav2 }
   oNav2:aRelatedNavigators := { oNav1 }

   ACTIVATE WINDOW oWnd CENTERED

return nil

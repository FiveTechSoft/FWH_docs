TNavigator

Fuente: source/classes/navpanels.prg

Hereda de: TControl

TNavigator es un panel de navegación colapsable con una barra de título degradada, botón de alternancia y reposicionamiento automático de paneles hermanos. Cuando está colapsado, el panel se reduce a una barra vertical estrecha con un título rotado; cuando está expandido, revela los controles hijos. Varias instancias de TNavigator se pueden vincular mediante aRelatedNavigators para que al alternar un panel se reposicionen sus hermanos, ideal para barras de navegación acopladas lateralmente.

Ejemplo: Paneles de Navegación Vinculados

#include "FiveWin.ch"

function Main()

   local oWnd, oNav1, oNav2

   DEFINE WINDOW oWnd TITLE "Navigator" SIZE 600, 400

   oNav1 := TNavigator():New( 0, 0, 400, 200, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Files" )

   oNav2 := TNavigator():New( 0, 202, 400, 402, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Search" )

   oNav1:aRelatedNavigators := { oNav2 }
   oNav2:aRelatedNavigators := { oNav1 }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Los paneles hermanos se reposicionan automáticamente mediante aRelatedNavigators. El array se ordena por nOriginalLeft para mantener el orden de izquierda a derecha durante la alternancia.
  • Cuando está colapsado, el texto del título se dibuja verticalmente usando la fuente oBoldVertical. Cuando está expandido, se dibuja horizontalmente en el encabezado degradado.
  • La imagen del botón de alternancia predeterminada son flechas integradas (CreaArrowLeft / CreaArrowRight). Se pueden suministrar imágenes de botón personalizadas mediante cBtnImage1 y cBtnImage2.
  • Los controles hijos se muestran u ocultan automáticamente cuando el panel se expande o colapsa.

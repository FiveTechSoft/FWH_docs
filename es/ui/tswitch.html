TSwitch

Fuente: source/classes/tswitch.prg

Hereda de: TControl

TSwitch es un control de interruptor con cuatro modos de renderizado: alternancia estándar, ovalado, estilo radio y casilla de verificación. Proporciona un interruptor moderno de encendido/apagado con colores personalizables, tamaño del indicador y apariencia del borde. El control admite efectos de desplazamiento del ratón, navegación por teclado y modo de solo lectura.

Sintaxis del Comando

@ nRow, nCol SWITCH oSw VAR lVar SIZE nW, nH PIXEL OF oWnd ;
   COLORS nClrOn, nClrOff BORDER nClrBorder

Ejemplo: Toggle with Colors

#include "FiveWin.ch"

function Main()

   local oWnd, oSw, lOn := .F.

   DEFINE WINDOW oWnd TITLE "Toggle Switch Demo" SIZE 300, 200

   @ 40, 30 SWITCH oSw VAR lOn SIZE 60, 22 PIXEL OF oWnd ;
      COLORS CLR_GREEN, CLR_GRAY BORDER CLR_HGRAY

   oSw:bChange := { | lValue | MsgInfo( If( lValue, "ON", "OFF" ), "Switch Changed" ) }

   @ 120, 30 BUTTON "Toggle" SIZE 60, 25 PIXEL OF oWnd ;
      ACTION oSw:Toggle()

   ACTIVATE WINDOW oWnd CENTERED

return nil

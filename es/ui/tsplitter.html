TSplitter

Fuente: source/classes/splitter.prg

Hereda de: TControl

TSplitter proporciona una barra divisoria arrastrable que permite a los usuarios redimensionar paneles de controles adyacentes en tiempo de ejecución. Se utiliza habitualmente para crear diseños de paneles divididos redimensionables (por ejemplo, una vista de árbol a la izquierda y un área de edición a la derecha) donde el usuario puede arrastrar el divisor para asignar más o menos espacio a cada panel.

Ejemplo: Divisor Vertical Entre Árbol y Edición

#include "FiveWin.ch"

function Main()

   local oWnd, oTree, oEdit, oSplit

   DEFINE WINDOW oWnd TITLE "Splitter Demo" SIZE 700, 500

   @ 0, 0 TREE oTree SIZE 200, 500 OF oWnd
   oTree:AddNode( "Node 1" )
   oTree:AddNode( "Node 2" )

   @ 0, 210 GET oEdit VAR cVar MEMO SIZE 480, 500 OF oWnd

   @ 0, 200 SPLITTER oSplit ;
      VERTICAL ;
      PREVIOUS oTree ;
      HIND oEdit ;
      SIZE 10, 500 OF oWnd

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TSplitter rastrea automáticamente el movimiento del ratón y redimensiona los controles previos y posteriores a medida que el usuario arrastra la barra divisoria.
  • El parámetro lVert determina la orientación: .T. para vertical (paneles izquierdo/derecho), .F. para horizontal (paneles superior/inferior).
  • aPrevCtrols y aHindCtrols aceptan bien un único objeto de control o bien un array de controles a redimensionar conjuntamente.
  • El bloque de código bChange se dispara cada vez que el usuario termina de arrastrar hasta una nueva posición, permitiendo que el código de la aplicación responda al cambio de diseño.
  • Utilice AdjClient() para que el divisor participe en la lógica de redimensionamiento del área cliente de la ventana, asegurando que se reposicione correctamente cuando la ventana cambia de tamaño.

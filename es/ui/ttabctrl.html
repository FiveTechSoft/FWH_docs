TTabControl

Fuente: source/classes/ttabctrl.prg

Hereda de: TControl

TTabControl encapsula el control común estándar de Windows SysTabControl32. Muestra una fila de pestañas seleccionables, cada una con un texto, y notifica a la aplicación cuando el usuario hace clic en una pestaña mediante un bloque de código de acción. TTabControl es un control de pestañas ligero sin gestión de páginas integrada: dispara una acción al cambiar de selección y deja la lógica de cambio de página a la aplicación. Para el cambio automático de páginas, consulte TTabs o TPages.

Miembros DATA Principales

nOptionNumericÍndice de la pestaña actualmente seleccionada (empezando en 1).
nClrTextNumericColor del texto de las etiquetas de las pestañas (valor RGB).
nClrPaneNumericColor de relleno del fondo (valor RGB).
hFontNumeric (Handle)Handle de la fuente usada para el texto de las etiquetas de las pestañas.
oFontTFontObjeto de fuente usado para el texto de las etiquetas de las pestañas.
cMsgCharacterTexto de la barra de mensajes que se muestra cuando el control de pestañas recibe el foco.

Métodos

MétodoDescripción
New( nRow, nCol, aPrompts, bAction, oWnd, nClrT, nClrP, oFont, lPixel, lDesign, nW, nH, cMsg )Crea un nuevo control de pestañas. aPrompts es un array de cadenas con las etiquetas de las pestañas. bAction se invoca al seleccionar una pestaña.
ReDefine( nId, oWnd )Redefine desde un recurso de diálogo. Enlaza con un SysTabControl32 existente mediante su ID de control.
Add( cPrompt )Añade una nueva pestaña al final con el texto de etiqueta indicado.
DelItem( nItem )Elimina la pestaña en la posición nItem (empezando en 1).
SetPrompts( aPrompts )Reemplaza todas las etiquetas de las pestañas con un nuevo array de cadenas.
SetOption( nOption )Selecciona una pestaña por su índice de forma programática.
End()Destruye el control.

Comandos: @ ... TAB

@ nRow, nCol TAB oTab ;
   ITEMS aItems ;
   [ SIZE nW, nH ] ;
   [ OF oDlg ] ;
   [ ACTION bAction ] ;
   [ ON CHANGE bChange ] ;
   [ COLOR nClrText, nClrPane ]

Ejemplo: control con 3 pestañas y acción

#include "FiveWin.ch"

function Main()

   local oWnd, oTab
   local aPrompts := { "General", "Details", "Settings" }

   DEFINE WINDOW oWnd TITLE "TTabControl Demo" SIZE 500, 400

   @ 10, 10 TAB oTab ITEMS aPrompts ;
      SIZE 460, 50 OF oWnd ;
      ACTION MsgInfo( "Selected tab: " + Str( oTab:nOption ) )

   @ 80, 20 SAY "Content area for tab " + Str( oTab:nOption ) ;
      OF oWnd SIZE 300, 20

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTabControl hereda de TControl. Todos los métodos estándar del control están disponibles.
  • A diferencia de TTabs (que gestiona los controles hijos mediante el cambio de páginas), TTabControl solo encapsula la tira de pestañas en sí. La aplicación debe gestionar los cambios de contenido en respuesta a bAction.
  • Use nOption para leer en cualquier momento el índice de la pestaña actualmente seleccionada, o SetOption() para cambiarlo de forma programática.
  • Las etiquetas de las pestañas se establecen mediante aPrompts en el constructor o con SetPrompts() en tiempo de ejecución. Se pueden añadir o eliminar pestañas individuales con Add() y DelItem().
  • Para la gestión automática de páginas con controles hijos que se muestran u ocultan según la pestaña seleccionada, use TFolder en su lugar.
  • Las pestañas se pueden reposicionar en tiempo de diseño usando Move(), SetSize() y SetPos().

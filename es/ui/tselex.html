TSelex / TSelector

Fuente: source/classes/tselex.prg, source/classes/selector.prg

Hereda de: TControl (ambos)

TSelex es un control deslizante segmentado con un pulsador arrastrable que permite a los usuarios elegir entre un conjunto discreto de opciones. TSelector es un control de dial circular/radial para seleccionar un valor a lo largo de un arco. Ambos proporcionan selección visual con renderizado de degradado e interacción por teclado/ratón.

Ejemplo: Deslizador Segmentado y Dial Radial

#include "FiveWin.ch"

function Main()

   local oWnd, oSelex, oSelector, nOpt := 1, nVal := 5

   DEFINE WINDOW oWnd TITLE "TSelex + TSelector Demo" SIZE 400, 300

   @ 20, 20 SELEX oSelex VAR nOpt OPTIONS { "Low", "Med", "High" } ;
        SIZE 200, 30 OF oWnd

   @ 80, 20 SELECTOR oSelector VAR nVal ;
        ANGLES 180, 540 MIN 0 MAX 10 ;
        MARKS 11 EXACT OF oWnd SIZE 120, 120

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Las pistas de TSelex se renderizan con dos capas de degradado (aGradOut = pista exterior, aGradIn = resalte interior).
  • El pulsador se dibuja como un rectángulo redondeado; su tamaño se controla mediante nWidthThumb / nHeightThumb.
  • TSelector utiliza un sistema de coordenadas angulares. Los ángulos se especifican en grados; el constructor los convierte a radianes internamente.
  • Cuando lExact es verdadero y hay marcas definidas, el dial se ajusta a la marca más cercana al soltar el ratón.
  • Ambos controles soportan navegación por teclado (teclas de flecha para TSelex, flechas para TSelector).

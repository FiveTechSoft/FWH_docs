TCheckBox / TRadio

Casillas de verificación booleanas y grupos de botones de radio mutuamente excluyentes

TCheckBox

Fuente: source/classes/checkbox.prg  |  Padre: TControl

TCheckBox envuelve el control estándar de casilla de verificación de Windows. Se enlaza a una variable lógica -- .T. cuando está marcada, .F. cuando no lo está. Las casillas de verificación son independientes; se pueden marcar cualquier número simultáneamente.

Propiedades de TCheckBox

PropiedadTipoDescripción
bSetGetBlockBloque de enlace de datos que lee/escribe la variable lógica
cCaptionStringTexto mostrado junto a la casilla de verificación
lCheckedLogicalEstado actual de marcado

Métodos de TCheckBox

MétodoDescripción
New( nRow, nCol, cCaption, bSetGet, oWnd, ... )Constructor.
Click()Alternar el estado de marcado y evaluar bSetGet.
Check()Establecer el estado de marcado a .T.
UnCheck()Establecer el estado de marcado a .F.
SetCheck( lOnOff )Establecer el estado de marcado al valor dado.
lIsChecked()Retorna el estado visual actual de marcado desde la API de Windows.
Refresh()Releer la variable enlazada y actualizar el estado visual.

Comando de TCheckBox

@ nRow, nCol CHECKBOX oChk VAR lVar ;
   PROMPT "Label text" ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ] ;
   [ WHEN bWhen ] ;
   [ FONT oFont ]

TRadio y TRadMenu

Fuente: source/classes/radio.prg  |  Padre: TControl

TRadio representa un único botón de radio. Los botones de radio son mutuamente excluyentes dentro de un grupo -- al seleccionar uno se deseleccionan todos los demás. El grupo es gestionado por un objeto TRadMenu, que se enlaza a una variable numérica indicando qué opción está seleccionada (basada en 1).

Propiedades de TRadio

PropiedadTipoDescripción
oRadMenuObjectReferencia al TRadMenu que posee este botón de radio

Comando de Radio

@ nRow, nCol RADIO oRad VAR nChoice ;
   PROMPT "Option text" ;
   [ OF oWnd ] ;
   [ WHEN bWhen ] ;
   [ ON CHANGE bChange ]

Cuando varios comandos RADIO comparten la misma VAR, FiveWin los agrupa automáticamente en un TRadMenu.

Ejemplos de Código

Ejemplo 1: Casillas de Verificación para Opciones

#include "FiveWin.ch"

FUNCTION PrintOptions()
   LOCAL oDlg
   LOCAL lLandscape  := .F.
   LOCAL lColor      := .T.
   LOCAL lDuplex     := .F.
   LOCAL lCollate    := .T.
   LOCAL lPreview    := .F.

   DEFINE DIALOG oDlg TITLE "Print Options" SIZE 350, 320

   @ 1.0, 2 SAY "Select print options:" OF oDlg

   @ 2.5, 2 CHECKBOX lLandscape PROMPT "&Landscape orientation" OF oDlg SIZE 200, 18
   @ 4.0, 2 CHECKBOX lColor     PROMPT "&Color printing"        OF oDlg SIZE 200, 18
   @ 5.5, 2 CHECKBOX lDuplex    PROMPT "&Duplex (two-sided)"    OF oDlg SIZE 200, 18
   @ 7.0, 2 CHECKBOX lCollate   PROMPT "Co&llate copies"        OF oDlg SIZE 200, 18
   @ 8.5, 2 CHECKBOX lPreview   PROMPT "Print Pre&view"         OF oDlg SIZE 200, 18

   @ 11, 5  BUTTON "&Print"  OF oDlg SIZE 80, 25 ;
      ACTION ( PrintDoc( lLandscape, lColor, lDuplex, lCollate, lPreview ), ;
               oDlg:End() ) DEFAULT
   @ 11, 15 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

Ejemplo 2: Grupo de Botones de Radio

#include "FiveWin.ch"

FUNCTION ShippingMethod()
   LOCAL oDlg
   LOCAL nShipping := 1   // 1=Estándar, 2=Express, 3=Nocturno

   DEFINE DIALOG oDlg TITLE "Shipping Method" SIZE 350, 280

   @ 1.0, 2 SAY "Select shipping method:" OF oDlg

   @ 2.5, 3 RADIO nShipping PROMPT "&Standard (5-7 days)"  OF oDlg
   @ 4.0, 3 RADIO nShipping PROMPT "&Express (2-3 days)"   OF oDlg
   @ 5.5, 3 RADIO nShipping PROMPT "&Overnight (1 day)"    OF oDlg

   @ 8, 5  BUTTON "&OK" OF oDlg SIZE 80, 25 ;
      ACTION ( ShowShippingCost( nShipping ), oDlg:End() ) DEFAULT
   @ 8, 15 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

STATIC FUNCTION ShowShippingCost( nMethod )
   LOCAL aCosts := { 4.99, 12.99, 29.99 }
   LOCAL aNames := { "Standard", "Express", "Overnight" }

   MsgInfo( aNames[ nMethod ] + " shipping: $" + ;
            LTrim( Str( aCosts[ nMethod ], 8, 2 ) ) )
RETURN NIL

Ejemplo 3: Mezcla de Checkboxes y Radios en un Diálogo de Configuración

#include "FiveWin.ch"

FUNCTION AppSettings()
   LOCAL oDlg, oFld, oDlg1, oDlg2
   // Configuración de visualización
   LOCAL lShowToolbar := .T.
   LOCAL lShowStatus  := .T.
   LOCAL lFullScreen  := .F.
   LOCAL nTheme       := 1    // 1=Claro, 2=Oscuro, 3=Sistema
   // Configuración de comportamiento
   LOCAL lAutoSave    := .T.
   LOCAL lConfirmDel  := .T.
   LOCAL lSounds      := .F.
   LOCAL nStartup     := 1    // 1=Último archivo, 2=Nuevo archivo, 3=Nada

   DEFINE DIALOG oDlg TITLE "Application Settings" SIZE 450, 400

   @ 0.3, 0.3 FOLDER oFld OF oDlg ;
      PROMPTS "Display", "Behavior" ;
      DIALOGS oDlg1, oDlg2 ;
      SIZE 420, 280

   // --- Página de Visualización ---
   @ 1.0, 2 CHECKBOX lShowToolbar PROMPT "Show &Toolbar"      OF oDlg1 SIZE 200, 18
   @ 2.5, 2 CHECKBOX lShowStatus  PROMPT "Show &Status Bar"   OF oDlg1 SIZE 200, 18
   @ 4.0, 2 CHECKBOX lFullScreen  PROMPT "&Full Screen Mode"  OF oDlg1 SIZE 200, 18

   @ 6.0, 2 SAY "Color Theme:" OF oDlg1
   @ 7.5, 3 RADIO nTheme PROMPT "&Light"  OF oDlg1
   @ 9.0, 3 RADIO nTheme PROMPT "&Dark"   OF oDlg1
   @ 10.5, 3 RADIO nTheme PROMPT "&System" OF oDlg1

   // --- Página de Comportamiento ---
   @ 1.0, 2 CHECKBOX lAutoSave   PROMPT "&Auto-save every 5 minutes" OF oDlg2 SIZE 250, 18
   @ 2.5, 2 CHECKBOX lConfirmDel PROMPT "&Confirm before deleting"   OF oDlg2 SIZE 250, 18
   @ 4.0, 2 CHECKBOX lSounds    PROMPT "Enable &Sounds"             OF oDlg2 SIZE 250, 18

   @ 6.0, 2 SAY "On startup:" OF oDlg2
   @ 7.5, 3 RADIO nStartup PROMPT "Open &last file"    OF oDlg2
   @ 9.0, 3 RADIO nStartup PROMPT "Create &new file"   OF oDlg2
   @ 10.5, 3 RADIO nStartup PROMPT "Do ¬hing"        OF oDlg2

   // Botones en el diálogo padre
   @ 23, 8  BUTTON "&Save"   OF oDlg SIZE 80, 25 ;
      ACTION ( SaveSettings( lShowToolbar, lShowStatus, lFullScreen, nTheme, ;
                             lAutoSave, lConfirmDel, lSounds, nStartup ), ;
               oDlg:End() ) DEFAULT
   @ 23, 18 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

Consejos

  • Checkbox se enlaza a una variable lógica. Grupo de Radio se enlaza a una variable numérica (el índice de la opción).
  • FiveWin agrupa automáticamente comandos RADIO consecutivos que comparten la misma VAR en un TRadMenu.
  • Use & en el PROMPT para establecer un acelerador con la tecla Alt: "&Landscape" significa que Alt+L lo activa.
  • Para un checkbox enlazado a un campo lógico de DBF, use FieldWBlock( "ACTIVE", Select() ) como bSetGet.
  • La cláusula ON CHANGE se ejecuta después de cada cambio de estado, útil para habilitar/deshabilitar controles dependientes.
  • Los botones de radio soportan navegación con teclas de flecha dentro del grupo automáticamente.
  • Para más de 5-6 opciones, considere usar un TComboBox en lugar de un grupo largo de radios.

TMenu / TMenuItem

Menús desplegables, menús emergentes y menús contextuales

Fuente: source/classes/menu.prg  |  Cabecera: FiveWin.ch

Visión General

TMenu gestiona una barra de menú o un menú emergente, mientras que TMenuItem representa un elemento individual dentro de un menú. Los menús de FiveWin soportan submenús jerárquicos, separadores, marcas de verificación, teclas aceleradoras, bitmaps y estilos visuales modernos (2007, 2010, 2013, 2015).

Existen dos patrones principales de uso:

  • Barra de menú -- adjunta a una ventana mediante DEFINE MENU oMenu OF oWnd
  • Menú emergente / contextual -- mostrado en una posición mediante ACTIVATE POPUP oMenu AT nRow, nCol OF oWnd

Sintaxis de Comandos

Barra de Menú

DEFINE MENU oMenu OF oWnd [ 2007 | 2010 | 2013 | 2015 ]

   MENUITEM "&File"
   MENU
      MENUITEM "&New"   ACTION NewDoc()   RESOURCE "NEW"
      MENUITEM "&Open"  ACTION OpenDoc()  RESOURCE "OPEN"
      SEPARATOR
      MENUITEM "E&xit"  ACTION oWnd:End()
   ENDMENU

   MENUITEM "&Edit"
   MENU
      MENUITEM "Cu&t"   ACTION CutText()   ACCELERATOR ACC_CTRL, VK_X
      MENUITEM "&Copy"  ACTION CopyText()  ACCELERATOR ACC_CTRL, VK_C
      MENUITEM "&Paste" ACTION PasteText() ACCELERATOR ACC_CTRL, VK_V
   ENDMENU

ENDMENU

Menú Contextual Emergente

DEFINE MENU oPopup POPUP [ 2015 ]
   MENUITEM "Edit"   ACTION EditRecord()
   MENUITEM "Delete" ACTION DeleteRecord()
   SEPARATOR
   MENUITEM "Properties" ACTION ShowProperties()
ENDMENU

// Activar con clic derecho
ACTIVATE POPUP oPopup AT nRow, nCol OF oWnd

Ejemplos de Código

Ejemplo 1: Menú Completo de Aplicación

#include "FiveWin.ch"

FUNCTION Main()
   LOCAL oWnd, oMenu

   DEFINE WINDOW oWnd TITLE "Menu Demo" FROM 1, 1 TO 30, 80

   DEFINE MENU oMenu OF oWnd 2015

      MENUITEM "&File"
      MENU
         MENUITEM "&New"        ACTION NewDoc()      RESOURCE "NEW"
         MENUITEM "&Open..."    ACTION OpenDoc()     RESOURCE "OPEN"
         MENUITEM "&Save"       ACTION SaveDoc()     RESOURCE "SAVE"
         MENUITEM "Save &As..." ACTION SaveDocAs()
         SEPARATOR
         MENUITEM "&Print..."   ACTION PrintDoc()    RESOURCE "PRINT" ;
            ACCELERATOR ACC_CTRL, VK_P
         SEPARATOR
         MENUITEM "Recent Files"
         MENU
            MENUITEM "Document1.dbf" ACTION OpenRecent( 1 )
            MENUITEM "Report2.prg"   ACTION OpenRecent( 2 )
            MENUITEM "Data3.xls"     ACTION OpenRecent( 3 )
         ENDMENU
         SEPARATOR
         MENUITEM "E&xit"       ACTION oWnd:End()
      ENDMENU

      MENUITEM "&Edit"
      MENU
         MENUITEM "&Undo"  ACTION Undo()  ACCELERATOR ACC_CTRL, VK_Z
         SEPARATOR
         MENUITEM "Cu&t"   ACTION Cut()   ACCELERATOR ACC_CTRL, VK_X
         MENUITEM "&Copy"  ACTION Copy()  ACCELERATOR ACC_CTRL, VK_C
         MENUITEM "&Paste" ACTION Paste() ACCELERATOR ACC_CTRL, VK_V
         SEPARATOR
         MENUITEM "Select &All" ACTION SelectAll() ACCELERATOR ACC_CTRL, VK_A
      ENDMENU

      MENUITEM "&View"
      MENU
         MENUITEM "&Toolbar"    ACTION ToggleToolbar()  CHECK
         MENUITEM "&Status Bar" ACTION ToggleStatus()   CHECK
         SEPARATOR
         MENUITEM "&Refresh"    ACTION Refresh()        ACCELERATOR 0, VK_F5
      ENDMENU

      MENUITEM "&Help"
      MENU
         MENUITEM "&Contents"     ACTION HelpContents()  ACCELERATOR 0, VK_F1
         MENUITEM "&About..."     ACTION MsgAbout()
      ENDMENU

   ENDMENU

   SET MESSAGE OF oWnd TO "Ready" CENTERED

   ACTIVATE WINDOW oWnd
RETURN NIL

Ejemplo 2: Menú Contextual con Clic Derecho

#include "FiveWin.ch"

FUNCTION SetupContextMenu( oWnd, oBrw )
   // Asignar al evento de clic derecho del browse
   oBrw:bRClicked := {|nRow, nCol| ShowContextMenu( oWnd, oBrw, nRow, nCol ) }
RETURN NIL

FUNCTION ShowContextMenu( oWnd, oBrw, nRow, nCol )
   LOCAL oMenu

   DEFINE MENU oMenu POPUP 2015

      MENUITEM "&Edit Record"   ACTION EditCurrentRecord( oBrw )
      MENUITEM "&Delete Record" ACTION DeleteCurrentRecord( oBrw ) ;
         WHEN ( !oBrw:cAlias->( Eof() ) )
      SEPARATOR
      MENUITEM "&Copy Row"      ACTION oBrw:ClipRow()
      MENUITEM "Copy &All"      ACTION oBrw:ToClip()
      SEPARATOR
      MENUITEM "Export to &Excel" ACTION oBrw:ToExcel()
      MENUITEM "Export to &CSV"   ACTION ExportCSV( oBrw )
      SEPARATOR
      MENUITEM "&Print..."       ACTION oBrw:Report()

   ENDMENU

   ACTIVATE POPUP oMenu AT nRow, nCol OF oWnd
RETURN NIL

Ejemplo 3: Menú Dinámico con bWhen

#include "FiveWin.ch"

FUNCTION BuildDynamicMenu( oWnd )
   LOCAL oMenu, oMI_Save, oMI_Paste

   DEFINE MENU oMenu OF oWnd 2013

      MENUITEM "&File"
      MENU
         MENUITEM "&Save" ACTION SaveDoc() ;
            WHEN ( lDocModified ) ;    // en gris cuando el documento no ha cambiado
            MESSAGE "Save current document"
         MENUITEM "E&xit" ACTION oWnd:End()
      ENDMENU

      MENUITEM "&Edit"
      MENU
         MENUITEM "&Paste" ACTION PasteText() ;
            WHEN ( !Empty( GetClipboardText() ) )  // en gris cuando el portapapeles está vacío
      ENDMENU

   ENDMENU
RETURN NIL

Estilos Visuales

FiveWin soporta múltiples estilos de renderizado de menús controlados por banderas en el comando DEFINE MENU:

EstiloApariencia
(predeterminado)Aspecto clásico de Windows
2007Degradado Office 2007 con selecciones redondeadas
2010Degradado más suave Office 2010
2013Plano Office 2013 con barra de acento de color
2015Apariencia plana moderna, recomendado para nuevas aplicaciones

Consejos

  • Use & en el texto de MENUITEM para establecer la tecla aceleradora Alt: "&File" significa Alt+F.
  • Use ACCELERATOR para asignar atajos de teclado como Ctrl+S, F5, etc.
  • La cláusula CHECK hace que un elemento de menú sea conmutable; cada clic alterna lChecked.
  • Use RESOURCE o FILENAME para mostrar un pequeño icono junto al elemento de menú.
  • El bloque bWhen se evalúa cada vez que se abre el emergente, por lo que los elementos se habilitan/deshabilitan dinámicamente.
  • Para menús muy largos, considere bloques MENU...ENDMENU anidados para crear submenús emergentes.

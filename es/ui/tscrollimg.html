TScrollImg

Fuente: source/classes/scrolimg.prg

Hereda de: TPanel

TScrollImg es un control de banner / carrusel de imágenes que muestra una colección desplazable de imágenes. Soporta múltiples modos de visualización, animación automática, transiciones de desvanecimiento, zoom al pasar el ratón, acciones por clic en cada imagen y persistencia de estado. Diseñado originalmente para exhibidores de productos y banners publicitarios.

Miembros DATA Principales

DATATipoDescripción
aElementsArrayArray de definiciones de elementos (archivo, URL, acción, prompt)
nImagesNuméricoNúmero de imágenes cargadas desde la lista de banners
nModeNuméricoModo de visualización 1-4 (dirección de desplazamiento / variante de diseño)
nSpeedNuméricoVelocidad de desplazamiento en píxeles por tick del temporizador
lRunningLógicoLa animación está actualmente en ejecución
lPausedLógicoLa animación está pausada
aOpacityArrayValores de opacidad por imagen (0-255)
nZoomedImageNuméricoÍndice de la imagen actualmente ampliada (0 = ninguna)
lFadingLógicoTransición de desvanecimiento en progreso
lMouseWheelLógicoHabilitar desplazamiento con rueda del ratón
lChangeSpeedLógicoPermitir cambio de velocidad mediante teclas +/-

Métodos

MétodoDescripción
New( nRow, nCol, nW, nH, oWnd, aBanners, nMode, nSpeed, ... )Crear un nuevo carrusel de imágenes con lista de banners y modo de visualización
Redefine( nId, oWnd, aBanners, nMode, nSpeed, ... )Redefinir desde un recurso de diálogo
Reset()Restablecer el carrusel a su estado inicial, reposicionar todas las imágenes
Animate()Iniciar o reiniciar el temporizador de animación de desplazamiento
Paint()Renderizar el fondo y todas las imágenes visibles
TimerAction()Callback del temporizador que avanza la posición de desplazamiento en cada tick
SaveState( cFile )Guardar el estado actual del carrusel (posiciones, imágenes) en un archivo
LoadState( cFile )Restaurar un estado de carrusel previamente guardado desde un archivo
MouseMove( nRow, nCol )Manejar el movimiento del ratón para detección de hover y zoom
LButtonUp( nRow, nCol )Ejecutar la acción asociada a la imagen cliqueada
KeyDown( nKey, nFlags )Manejar teclas +/- para control de velocidad
MouseWheel( nKeys, nDelta, nX, nY )Manejar la rueda del ratón para desplazamiento manual

Ejemplo: Carrusel de Imágenes

#include "FiveWin.ch"

function Main()

   local oWnd, oScroll

   DEFINE WINDOW oWnd TITLE "Image Carousel" SIZE 800, 300

   oScroll = TScrollImg():New( 10, 10, 780, 240, oWnd,;
      { "banner1.jpg", "banner2.jpg", "banner3.jpg", "banner4.jpg" },;
      1, 3, 20 )

   oScroll:Animate()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El array aBanners puede contener nombres de archivo, o sub-arrays con { file, url, action, prompt } para interactividad extendida.
  • El modo determina la dirección de desplazamiento: 1 = horizontal izquierda, 2 = horizontal derecha, 3 = vertical arriba, 4 = vertical abajo.
  • Cuando el ratón se posa sobre una imagen, nZoomedImage activa un efecto de zoom usando nZoomFactor.
  • Las transiciones de opacidad (desvanecimiento) se aplican mediante aOpacity y lFading / nFadeDuration.
  • La persistencia de estado con SaveState / LoadState permite que el carrusel se reanude desde donde quedó.

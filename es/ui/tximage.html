TXImage

Fuente: source/classes/ximage.prg

Hereda de: TControl

TXImage es un control visor de imágenes extendido que admite zoom, rotación, brillo, contraste, corrección gamma, mezcla alfa (alpha blending), conversión a escala de grises y efectos de desenfoque. Proporciona un menú contextual emergente integrado con opciones para guardar, imprimir, copiar al portapapeles y navegar entre imágenes.

Miembros DATA Principales

DATATipoDescripción
cImageFileCarácterRuta o identificador de la imagen cargada
nZoomNuméricoPorcentaje de zoom (100 = tamaño original)
nRotateNuméricoÁngulo de rotación en grados
nSizeNuméricoDimensión de la imagen para el ajuste basado en tamaño
cAlignCarácterCadena de alineación (p. ej., "C" para centrar)
nGammaNuméricoValor de corrección gamma
nBrightnessNuméricoAjuste de brillo
nContrastNuméricoAjuste de contraste
nAlphaNuméricoNivel de transparencia alfa (0-255)
lGrayLógicoMostrar la imagen en escala de grises
nBlurNuméricoRadio de desenfoque

Métodos

MétodoDescripción
New( nTop, nLeft, nW, nH, bImage, oWnd )Crea un nuevo control TXImage. bImage puede ser un nombre de archivo, un manejador de bitmap o un bloque de código que devuelve una imagen.
Center()Centra la imagen dentro del área del control
FitWidth()Escala la imagen para ajustarla al ancho del control
FitHeight()Escala la imagen para ajustarla al alto del control
FitRect()Escala la imagen para que quepa por completo dentro del control
FitOrglSize()Restaura la imagen a sus dimensiones originales en píxeles
Zoom( n )Establece el nivel de zoom a n por ciento
Rotate( nDeg )Rota la imagen nDeg grados
SetSource( uNew )Reemplaza la imagen mostrada por una nueva fuente
Paste()Pega una imagen desde el portapapeles
CopyToClipBoard()Copia la imagen actual al portapapeles
Save( lAsViewed, cFile )Guarda la imagen en disco. Si lAsViewed es .T., se conservan los ajustes (zoom, efectos).

Funciones Libres

FunciónDescripción
XImage( uImage, cTitle )Muestra una imagen en una ventana de diálogo visor independiente
XImageArray( aImages, cTitle )Muestra un conjunto de imágenes navegable en un diálogo visor

Ejemplo: Visor de Imágenes con Menú Contextual

#include "FiveWin.ch"

function Main()

   local oWnd, oImg

   DEFINE WINDOW oWnd TITLE "Visor de Imágenes" SIZE 800, 600

   @ 10, 10 XIMAGE oImg FILE "photo.jpg" ;
      SIZE 760, 540 OF oWnd

   oImg:FitRect()
   oImg:Rotate( 90 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TXImage proporciona un menú contextual emergente integrado que se activa con el clic derecho, ofreciendo opciones de zoom, rotación, guardar, imprimir, copiar y ajuste en tiempo de ejecución.
  • La función libre XImage() abre un diálogo modal con un control TXImage y todas las acciones estándar de la barra de herramientas. Use XImageArray() para navegar entre varias imágenes.
  • Los ajustes de imagen (zoom, rotación, brillo, contraste, gamma, desenfoque, escala de grises, alfa) se aplican en memoria y no modifican el archivo de origen original salvo que se guarden explícitamente con Save().
  • El parámetro bImage de New() acepta una cadena con el nombre de archivo, un manejador de bitmap (HBITMAP) o un bloque de código que devuelve cualquiera de ambos.

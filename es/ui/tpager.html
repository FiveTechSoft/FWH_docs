TPager

Fuente: source/classes/tpager.prg

Hereda de: TControl

TPager es un envoltorio para el control común SysPager de Win32. Proporciona botones de desplazamiento (flechas) que permiten al usuario navegar a través de una ventana hija que es más grande que el área visible. Se usa típicamente con controles de barra de herramientas u otras ventanas hijas anchas que necesitan desplazamiento horizontal o vertical sin barras de desplazamiento estándar.

Miembros DATA Principales

lHorzLogicalOrientación horizontal (predeterminado .F. = vertical)
lAutoScrollLogicalHabilitar desplazamiento automático cuando el ratón se acerca al borde
lDragDropLogicalHabilitar desplazamiento por arrastrar y soltar

nBkColorNumericColor de fondo (predeterminado COLOR_BTNFACE)
nBorderNumericAncho del borde en píxeles (predeterminado 0)

Ejemplo: Pager Horizontal con Barra de Herramientas

#include "FiveWin.ch"

function Main()

   local oWnd, oPager, oToolBar

   DEFINE WINDOW oWnd TITLE "Pager Demo" SIZE 600, 100

   // Crear una barra de herramientas con muchos botones
   DEFINE BUTTONBAR oToolBar OF oWnd SIZE 800, 30

   DEFINE BUTTON OF oToolBar PROMPT "File"
   DEFINE BUTTON OF oToolBar PROMPT "Edit"
   DEFINE BUTTON OF oToolBar PROMPT "View"
   DEFINE BUTTON OF oToolBar PROMPT "Tools"
   DEFINE BUTTON OF oToolBar PROMPT "Format"
   DEFINE BUTTON OF oToolBar PROMPT "Insert"
   DEFINE BUTTON OF oToolBar PROMPT "Table"
   DEFINE BUTTON OF oToolBar PROMPT "Help"

   // Envolver la barra de herramientas en un pager horizontal
   TPager():New( 10, 10, oWnd, oToolBar, 580, 30,,,, .T., .T., .F., 14 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TPager envuelve el control común SysPager de Win32. El pager proporciona botones de flecha que aparecen automáticamente cuando la ventana hija excede el área visible.
  • Establezca lHorz := .T. para paginación horizontal (flechas izquierda/derecha) o .F. para vertical (flechas arriba/abajo).
  • lAutoScroll habilita el desplazamiento automático cuando el usuario coloca el ratón cerca del borde del pager, sin hacer clic en los botones.
  • lDragDrop permite al usuario hacer clic y arrastrar para desplazar la ventana hija.
  • Llame a RecalcSize() después de cambiar las dimensiones de la ventana hija para actualizar el diseño del pager.
  • El pager reenvía los mensajes de la rueda del ratón a la ventana hija cuando ForwardMouse() está habilitado.

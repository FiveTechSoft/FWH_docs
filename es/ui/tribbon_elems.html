TRbGroup / TRBtn / TRPanel — Elementos de Cinta

Fuente: source/classes/trbgroup.prg, source/classes/trbtn.prg, source/classes/trpanel.prg

Hereda de: TControl (los tres)

TRbGroup, TRBtn y TRPanel son los componentes fundamentales del sistema de barra de cinta. TRbGroup representa un grupo nombrado de botones dentro de una cinta. TRBtn es un botón de cinta individual que soporta diseños normal, popup y split-popup. TRPanel es un panel ligero usado como contenedor para controles de cinta. Juntos proporcionan la interfaz de usuario de cinta estilo Office 2007/2010.

Ejemplo: Grupo de Cinta con Tres Botones

#include "FiveWin.ch"

function Main()

   local oWnd, oRBar, oGrp, oBtn1, oBtn2, oBtn3

   DEFINE WINDOW oWnd TITLE "Ribbon Demo" SIZE 800, 500

   oRBar = TRibbonBar():New( oWnd )

   oGrp = TRbGroup():New( oWnd, 30, 10, 90, 180, 1, "Clipboard",;
                          {|| MsgInfo( "Group clicked" ) } )
   oGrp:aGradSel := { { 1, CLR_WHITE, CLR_HGRAY } }

   oBtn1 = TRBtn():New( 35, 20, 32, 32, "Paste", {|| MsgInfo( "Paste" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn1 )

   oBtn2 = TRBtn():New( 35, 60, 32, 32, "Copy", {|| MsgInfo( "Copy" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn2 )

   oBtn3 = TRBtn():New( 35, 100, 32, 32, "Cut", {|| MsgInfo( "Cut" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn3 )

   oRBar:AddGroup( oGrp )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TRbGroup actúa como contenedor para instancias de TRBtn y dibuja el título y borde del grupo.
  • TRBtn soporta tres tipos visuales: NORMAL (objetivo de un solo clic), POPUP (clic muestra menú emergente) y SPLITPOPUP (clic ejecuta acción, flecha muestra menú).
  • La propiedad nLayout controla la posición del texto relativa al mapa de bits: TOP, LEFT, BOTTOM, RIGHT, MOSTLEFT, MOSTRIGHT o CENTER.
  • TRPanel es el contenedor más simple; dibuja un rectángulo relleno usando el pincel de la ventana padre.
  • Los arrays de degradado siguen el formato { { fraction, color1, color2 }, ... } usado en todo FWH.

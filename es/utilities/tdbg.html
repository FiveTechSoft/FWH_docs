TDbg - FiveWin Debugger

Fuente: source/classes/fwdbg.prg

Clase independiente

TDbg es un depurador completo a nivel de código fuente para aplicaciones FiveWin. Proporciona una ventana de depuración gráfica (oDlg) que contiene hasta nueve paneles XBrowse para inspeccionar el código fuente, la pila de llamadas, las variables locales/privadas, los arrays, los objetos, los puntos de interrupción, las áreas de trabajo, los comandos SET y los datos del profiler. El depurador se activa compilando con #pragma /b+ o pasando el indicador /b en la línea de comandos.

Miembros DATA Principales

DATATipoDescripción
oDlgTDialogLa ventana de diálogo del depurador
oBrwTXBrowseArray u objeto para 9 paneles de navegación (código fuente, pila, variables, arrays, objetos, puntos de interrupción, áreas, SETs, profiler)
aStackArrayEntradas actuales de la pila de llamadas
aModulesArrayMódulos de código fuente cargados
aBreakArrayDefiniciones de puntos de interrupción
aTraceArrayEntradas del registro de seguimiento

Métodos Principales

MétodoDescripción
New()Crea la instancia del depurador
Activate()Abre y muestra la ventana de diálogo del depurador
Exec()Ejecuta el bucle principal del depurador
DbgNext()Avanza a la siguiente línea de código fuente
DbgGo()Continúa la ejecución hasta el siguiente punto de interrupción
DbgNextRoutine()Salta por encima (ejecuta las llamadas a subrutinas sin entrar en ellas)
DbgSetBreak( cMod, nLine )Establece un punto de interrupción en un módulo y línea específicos
DbgSetTrace( lOn )Activa o desactiva el registro de seguimiento
DbgEditVar( cVarName )Abre un editor para modificar el valor de una variable
DbgEditObj( oObj )Abre un inspector de objetos para un objeto dado

Ejemplo: Sesión de Depuración

// Añade este pragma a los módulos que quieras depurar:
#pragma /b+

#include "FiveWin.ch"

function Main()

   local cName := "FiveWin"
   local nCount := 0

   // El depurador se abre automáticamente cuando el programa
   // se compila con /b+ y se enlaza FWDbg.lib.

   // Usa F5 para continuar, F8 para avanzar, F9 para puntos de interrupción
   for nCount := 1 to 5
      ? "Iteration:", nCount
      ProcessItem( cName )
   next

return nil

function ProcessItem( cItem )

   ? "Processing:", cItem

return nil

Notas

  • Para habilitar la depuración, añade #pragma /b+ al inicio de cada módulo de código fuente que quieras depurar, y enlaza FWDbg.lib (o asegúrate de que forma parte de tu conjunto de bibliotecas FWH).
  • El depurador también puede activarse en tiempo de ejecución pasando el indicador /b en la línea de comandos al iniciar tu aplicación.
  • Los nueve paneles de navegación muestran: código fuente (con resaltado de la línea actual), pila de llamadas, variables locales/privadas, arrays, objetos, puntos de interrupción, áreas de trabajo de base de datos, estados de los comandos SET y estadísticas del profiler.

TComm

Fuente: source/classes/tcomm.prg

Clase independiente

TComm proporciona capacidades de comunicación por puerto serie (RS-232) para interactuar con módems, impresoras serie, lectores de códigos de barras y otros dispositivos serie heredados. Envuelve la API COM de Windows con métodos para la configuración del puerto, la transmisión de datos y el control de flujo.

Miembros DATA Principales

DATATipoDescripción
nDeviceNumericNúmero de puerto COM (base 1: COM1, COM2, etc.)
nIdNumericManejador de archivo de Windows del puerto COM abierto
nBaudNumericVelocidad en baudios (p. ej., 9600, 19200, 115200)
cParityCharacterConfiguración de paridad: "N" (ninguna), "E" (par), "O" (impar)
nStopNumericBits de parada: 1, 1.5 o 2
nDataNumericBits de datos: 5, 6, 7 u 8
nInQueue / nOutQueueNumericTamaños de los búferes de entrada y salida en bytes

Métodos Principales

MétodoDescripción
New( nDev, nInQ, nOutQ, cStyle, nBaud, cParity, nStop, nData )Abre un puerto COM con los parámetros especificados
SetUp()Aplica la configuración del puerto (baudios, paridad, bits de parada, bits de datos)
Write( cStr )Escribe una cadena en el puerto serie
Close()Cierra la conexión del puerto serie
Break() / UnBreak()Activa o desactiva la señal de interrupción (break) serie
Flush()Vacía los búferes de entrada y salida
Error()Devuelve el último código de error

Ejemplo: COM1 a 9600 Baudios

#include "FiveWin.ch"

function Main()

   local oComm
   local cData

   oComm := TComm():New( 1, 4096, 4096, , 9600, "N", 1, 8 )

   if oComm:nId != 0
      oComm:Write( "AT" + Chr( 13 ) )   // Envía el comando AT al módem
      cData := oComm:Read()
      MsgInfo( cData )
   else
      MsgStop( "No se puede abrir COM1" )
   endif

   oComm:Close()

return nil

Notas

  • El parámetro cStyle del constructor acepta una cadena de modo extendido que no se usa habitualmente; pase nil para el estilo predeterminado.
  • Los tamaños de los búferes (nInQueue, nOutQueue) se establecen al abrir el puerto y no se pueden cambiar sin reabrirlo.
  • Use Error() tras una operación fallida para obtener el código de error del sistema con fines de diagnóstico.
  • La clase gestiona internamente la configuración del DCB (Bloque de Control de Dispositivo) a través del método SetUp(), invocado automáticamente desde New().

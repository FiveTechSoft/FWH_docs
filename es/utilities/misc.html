Clases Misceláneas

FiveWin incluye una amplia variedad de clases de utilidad que cubren temporizadores, manipulación de tiempo, rectángulos, plumas GDI, gestión de diseño (layout), protocolos de internet (FTP, SMTP, POP3), correo electrónico, análisis de expresiones y gráficos. Esta página documenta cada una de estas clases con sus miembros DATA, métodos y ejemplos prácticos.

TTimer - Acciones de Temporizador Periódicas

TTimer envuelve la API SetTimer/KillTimer de Windows para ejecutar un bloque de código a intervalos regulares. Los temporizadores se gestionan en un array estático y se despachan a través de la función TimerEvent(). Pueden estar activos varios temporizadores simultáneamente, cada uno con diferentes intervalos y acciones.

Miembros DATA

DATATipoDescripción
nIntervalNumericIntervalo del temporizador en milisegundos (por defecto 18)
bActionCodeblockBloque de código a ejecutar en cada tick
lActiveLogical.T. cuando el temporizador está en marcha
nIdNumericID único del temporizador (asignado automáticamente)
hWndOwnerNumericHandle de la ventana propietaria
CargoAnyDatos de carga definidos por el usuario

Referencia de MÉTODOS

MétodoDescripción
New( nInterval, bAction, oWnd )Crea un nuevo temporizador. NO lo inicia -- llame a Activate() para iniciarlo.
Activate()Inicia el temporizador mediante SetTimer() de Windows. Establece lActive a .T.
DeActivate()Detiene el temporizador mediante KillTimer(). Establece lActive a .F.
End()Desactiva y elimina el temporizador del array interno de temporizadores.

Sintaxis de Comando

// Comando FiveWin:
DEFINE TIMER oTimer INTERVAL 1000 ACTION UpdateClock() OF oWnd
ACTIVATE TIMER oTimer

// Desactivar más tarde:
DEACTIVATE TIMER oTimer
// o
oTimer:End()

Ejemplo: Visualización de Reloj con Auto-Refresco

local oWnd, oTimer, oSay

DEFINE WINDOW oWnd TITLE "Timer Demo"

@ 2, 2 SAY oSay PROMPT Time() OF oWnd SIZE 200, 30

// Actualizar el reloj cada segundo (1000 ms)
DEFINE TIMER oTimer INTERVAL 1000 ;
   ACTION ( oSay:SetText( Time() ) ) OF oWnd
ACTIVATE TIMER oTimer

ACTIVATE WINDOW oWnd ;
   VALID ( oTimer:End(), .T. )

Ejemplo: Auto-Guardado con Temporizador

// Guardar datos cada 5 minutos
local oAutoSave := TTimer():New( 300000, {|| SaveAllData() }, oWnd )
oAutoSave:Activate()

// Pausar temporalmente el auto-guardado
oAutoSave:DeActivate()

// Reanudar
oAutoSave:Activate()

// Limpieza al salir
oAutoSave:End()

TTime - Manipulación de Tiempo

TTime almacena el tiempo como segundos totales desde medianoche (0-86399) y proporciona métodos para aritmética y formateo. Puede construirse a partir de horas/minutos/segundos o inicializarse desde el reloj del sistema.

Miembros DATA

DATATipoDescripción
nTimeNumericTiempo almacenado como segundos totales desde medianoche (0-86399)

Referencia de MÉTODOS

MétodoDescripción
New( nHours, nMinutes, nSeconds )Crea TTime a partir de componentes. Se ajusta cíclicamente en 86400 (24 horas).
System()Constructor: crea TTime a partir de la hora actual del sistema.
AddHours( nHours )Añade horas al tiempo actual.
AddMinutes( nMinutes )Añade minutos al tiempo actual.
AddSeconds( nSeconds )Añade segundos al tiempo actual.
cAdd( nHours, nMinutes, nSeconds )Suma componentes de tiempo y devuelve una cadena formateada "HH:MM:SS".
cSub( nHours, nMinutes, nSeconds )Resta tiempo y devuelve una cadena formateada. También puede aceptar un objeto TTime.
cGetTime()Devuelve la cadena de tiempo formateada "HH:MM:SS".
SysChange()Establece la hora del sistema al valor nTime almacenado.

Ejemplo: Cálculos de Tiempo

// Crear a partir de componentes
local oStart := TTime():New( 9, 30, 0 )    // 09:30:00
local oEnd   := TTime():New( 17, 45, 0 )    // 17:45:00

? "Start:", oStart:cGetTime()   // "09:30:00"
? "End:",   oEnd:cGetTime()     // "17:45:00"

// Calcular duración
local oDuration := TTime():New( 0, 0, oEnd:nTime - oStart:nTime )
? "Duration:", oDuration:cGetTime()  // "08:15:00"

// Añadir 1,5 horas al inicio
oStart:AddHours( 1 )
oStart:AddMinutes( 30 )
? "Break ends:", oStart:cGetTime()   // "11:00:00"

// Desde el reloj del sistema
local oNow := TTime():System()
? "Current time:", oNow:cGetTime()

TRect - Objeto Rectángulo

TRect representa un rectángulo con coordenadas nTop, nLeft, nBottom, nRight. Soporta ACCESS/ASSIGN para propiedades calculadas (nWidth, nHeight, CenterPt), sobrecarga de operadores para aritmética (+, -, *, /) y métodos de utilidad para mover, redimensionar y ajustar rectángulos. También puede convertir hacia/desde el formato de estructura binaria RECT de Windows.

Miembros DATA

DATATipoDescripción
aRectArray{ nTop, nLeft, nBottom, nRight }
lWinRectLogicalSi .T. (por defecto), usa la convención de Windows para el cálculo de ancho/alto

Propiedades ACCESS/ASSIGN

PropiedadDescripción
nTopCoordenada superior (lectura/escritura)
nLeftCoordenada izquierda (lectura/escritura)
nBottomCoordenada inferior (lectura/escritura)
nRightCoordenada derecha (lectura/escritura)
nWidthAncho calculado (lectura/escritura -- al asignarlo ajusta nRight)
nHeightAlto calculado (lectura/escritura -- al asignarlo ajusta nBottom)
CenterPtPunto central como { nRow, nCol } (lectura/escritura -- al asignarlo mueve el rectángulo)
cRectEstructura binaria RECT para la API de Windows (lectura/escritura)

Referencia de MÉTODOS

MétodoDescripción
New( nTop, nLeft, nBottom, nRight )Crea a partir de coordenadas. También acepta un array o una cadena RECT binaria.
MoveBy( nRows, nCols )Mueve el rectángulo por un desplazamiento (preservando el tamaño).
MoveTo( nNewTop, nNewLeft )Mueve el rectángulo a una posición absoluta (preservando el tamaño).
Contains( aRect )Devuelve .T. si aRect está completamente dentro de este rectángulo.
Resize( nRatio, aPoint )Redimensiona el rectángulo según una proporción alrededor de un punto.
FitInside( oRect, nResizeType, cAlign, nEnlarge )Ajusta este rectángulo dentro de oRect manteniendo la relación de aspecto.
AsSquare( lOuter, cAlign )Convierte el rectángulo en un cuadrado (interior o exterior).
Modify( ... )Modifica varias propiedades a la vez.

Sobrecarga de Operadores

local oRect1 := TRect():New( 10, 20, 100, 200 )
local oRect2 := oRect1 + { 5, 5, 5, 5 }    // expandir 5 en todos los lados
local oRect3 := oRect1 * 2                   // duplicar todas las coordenadas

? oRect1 == oRect2    // .F. (operador de comparación)

Ejemplo: Trabajando con Rectángulos

local oRect := TRect():New( 10, 20, 110, 220 )

? "Position:", oRect:nTop, oRect:nLeft
? "Size:", oRect:nWidth, "x", oRect:nHeight
? "Center:", oRect:CenterPt[ 1 ], oRect:CenterPt[ 2 ]

// Mover a una nueva posición
oRect:MoveTo( 50, 100 )
? "New position:", oRect:nTop, oRect:nLeft    // 50, 100
? "Size unchanged:", oRect:nWidth, "x", oRect:nHeight

// Ajustar dentro de otro rectángulo
local oContainer := TRect():New( 0, 0, 400, 600 )
oRect:FitInside( oContainer )

TPen - Objeto Pluma GDI

TPen envuelve una pluma GDI de Windows para dibujar líneas y bordes. Encapsula el estilo, ancho y color de la pluma, y gestiona el ciclo de vida del handle GDI. Cuando se asocia a un dispositivo de impresora, escala automáticamente el ancho de la pluma según los DPI del dispositivo.

Constantes de Estilo de Pluma

ConstanteDescripción
PS_SOLIDLínea sólida (por defecto)
PS_DASHLínea de trazos
PS_DOTLínea de puntos
PS_DASHDOTTrazo-punto alternados
PS_DASHDOTDOTPatrón trazo-punto-punto
PS_NULLPluma invisible (sin dibujo)

Miembros DATA

DATATipoDescripción
hPenNumericHandle de la pluma GDI (HPEN)
nStyleNumericEstilo de la pluma (PS_SOLID, PS_DASH, etc.)
nWidthNumericAncho de la pluma en píxeles (escalado para los DPI del dispositivo)
nInpWidthNumericAncho de entrada original antes del escalado por DPI
nColorNumericColor de la pluma (valor RGB)
oDeviceObjectDispositivo asociado (impresora) para el escalado por DPI

Referencia de MÉTODOS

MétodoDescripción
New( nStyle, nWidth, nColor, oDevice )Crea la pluma. Valores por defecto: PS_SOLID, ancho 1, CLR_BLACK. Escala automáticamente el ancho según los DPI de la impresora.
Release()Elimina el handle de la pluma GDI.
End()Alias de Release().

Ejemplo: Dibujar con Plumas

local oPenRed, oPenBlue, oPenDash

// Crear diferentes plumas
oPenRed  := TPen():New( PS_SOLID, 2, CLR_RED )
oPenBlue := TPen():New( PS_SOLID, 3, CLR_BLUE )
oPenDash := TPen():New( PS_DASH,  1, CLR_BLACK )

// Usar en un manejador de Pintado
oWnd:bPainted := {| hDC |  ;
   local hOldPen := SelectObject( hDC, oPenRed:hPen ), ;
   LineTo( hDC, 100, 100 ), ;
   SelectObject( hDC, oPenBlue:hPen ), ;
   LineTo( hDC, 200, 100 ), ;
   SelectObject( hDC, hOldPen ) ;
}

// Para impresión (escala automáticamente a los DPI de la impresora)
local oPrnPen := TPen():New( PS_SOLID, 1, CLR_BLACK, oPrinter )

// Liberar siempre al terminar
oPenRed:End()
oPenBlue:End()
oPenDash:End()

TLayout - Gestor de Diseño

TLayout hereda de TPanel y proporciona la disposición automática de los controles hijos cuando la ventana padre se redimensiona. Soporta diseños horizontales y verticales con tamaño fijo o proporcional. Los diseños pueden anidarse para crear disposiciones complejas.

Tipos de Diseño

ConstanteValorDescripción
LAYOUT_TYPE_MAIN0Diseño de nivel superior (asociado a la ventana)
LAYOUT_TYPE_HORIZONTAL1Subdivisión horizontal
LAYOUT_TYPE_VERTICAL2Subdivisión vertical

Miembros DATA

DATATipoDescripción
aHLayoutArrayArray de diseños hijos horizontales
aVLayoutArrayArray de diseños hijos verticales
nTypeNumericTipo de diseño (MAIN, HORIZONTAL, VERTICAL)
lFixedLogicalSi .T., este panel tiene tamaño fijo; si .F., se estira proporcionalmente
bOnResizeCodeblockManejador de redimensionado anterior (encadenado)

Referencia de MÉTODOS

MétodoDescripción
New( oWnd )Crea el diseño principal asociado a oWnd. Captura bResized para el diseño automático.
AddHLayout( nWidth )Añade un panel hijo horizontal. nWidth > 0 = píxeles fijos; 0 = proporcional.
AddVLayout( nHeight )Añade un panel hijo vertical. nHeight > 0 = píxeles fijos; 0 = proporcional.
onResized( nType, nWidth, nHeight )Interno: recalcula las posiciones de todos los paneles hijos al redimensionar.

Ejemplo: Diseño de Dos Paneles con Barra Lateral Fija

local oWnd, oLayout, oLeft, oRight

DEFINE WINDOW oWnd TITLE "Layout Demo" SIZE 800, 600

oLayout := TLayout():New( oWnd )

// Panel izquierdo: barra lateral fija de 250px de ancho
oLeft := oLayout:AddHLayout( 250 )

// Panel derecho: ocupa el espacio restante
oRight := oLayout:AddHLayout( 0 )

// Añadir controles a cada panel
@ 1, 1 LISTBOX oLbx VAR cItem ITEMS { "Option 1", "Option 2", "Option 3" } ;
   OF oLeft SIZE oLeft:nWidth - 10, oLeft:nHeight - 20

@ 1, 1 SAY "Content area" OF oRight

ACTIVATE WINDOW oWnd

Ejemplo: Diseño Anidado Vertical + Horizontal

local oWnd, oLayout, oTop, oBottom, oBottomLeft, oBottomRight

DEFINE WINDOW oWnd TITLE "Nested Layout" SIZE 800, 600

oLayout := TLayout():New( oWnd )

// Superior: área de barra de herramientas fija de 40px
oTop := oLayout:AddVLayout( 40 )

// Inferior: ocupa el espacio restante
oBottom := oLayout:AddVLayout( 0 )

// Dividir la parte inferior en izquierda/derecha
oBottomLeft  := oBottom:AddHLayout( 0 )   // 50% cada uno
oBottomRight := oBottom:AddHLayout( 0 )

ACTIVATE WINDOW oWnd

TFTP / TFtpClient - Transferencia de Archivos FTP

FiveWin proporciona dos clases FTP: TFTP usa la API WinINet para operaciones FTP simples y de alto nivel, mientras que TFtpClient usa sockets en crudo para el control de bajo nivel del protocolo FTP. Se recomienda TFTP para la mayoría de los casos de uso.

Miembros DATA de TFTP (basada en WinINet)

DATATipoDescripción
oInternetObjectObjeto contenedor TInternet
cSiteCharacterURL/nombre de host del servidor FTP
hFTPNumericHandle de la conexión FTP
cUserNameCharacterNombre de usuario de acceso
cPasswordCharacterContraseña de acceso

Referencia de MÉTODOS de TFTP

MétodoDescripción
New( cFTPSite, oInternet, cUserName, cPassword )Conecta al servidor FTP mediante InternetConnect() de WinINet.
End()Cierra el handle de la conexión FTP.
DeleteFile( cFileName )Elimina un archivo remoto.
Directory( cMask )Lista el directorio remoto (como la función Directory() de Clipper).
RenameFile( cOldName, cNewName )Renombra un archivo remoto.
SetCurrentDirectory( cDirName )Cambia el directorio de trabajo remoto.
CreateDirectory( cDirName )Crea un directorio remoto.

Referencia de MÉTODOS de TFtpClient (basada en Sockets)

MétodoDescripción
New( cIPServer, nPort, User, Pass )Crea una conexión por socket al servidor FTP (puerto 21 por defecto).
PWD()Devuelve la ruta del directorio remoto actual.
CWD( cDirName )Cambia el directorio remoto.
MKD( cDirName )Crea un directorio remoto.
DELE( cFileName )Elimina un archivo remoto.
STOR( cFileName, bBlock )Sube un archivo. bBlock recibe actualizaciones de progreso.
RETR( cFileName )Descarga un archivo.
TYPE( cType )Establece el tipo de transferencia: "A" para ASCII, "I" para binario.
QUIT()Se desconecta del servidor FTP.

Ejemplo: Subida FTP con WinINet

local oInternet, oFtp

oInternet := TInternet():New()
oFtp := TFTP():New( "ftp.myserver.com", oInternet, "user", "password" )

if oFtp:hFTP != nil
   // Subir un archivo
   FtpPutFile( oFtp:hFTP, "c:\local\report.pdf", "/remote/report.pdf", 0, 0 )

   // Listar el directorio remoto
   local aFiles := oFtp:Directory( "*.pdf" )
   AEval( aFiles, {|a| QOut( a[ 1 ], a[ 2 ] ) } )

   // Crear directorio y navegar
   oFtp:CreateDirectory( "/remote/backup" )
   oFtp:SetCurrentDirectory( "/remote/backup" )

   oFtp:End()
endif

oInternet:End()

TSmtp - Enviar Correo mediante SMTP

TSmtp envía correo electrónico mediante el protocolo SMTP usando la clase TSocket de FiveWin. Soporta autenticación (método LOGIN), contenido HTML, archivos adjuntos, destinatarios CC/BCC, acuses de recibo y ajustes de prioridad. La comunicación es asíncrona a través de callbacks de eventos de socket.

Miembros DATA

DATATipoDescripción
oSocketObjectTSocket usado para la sesión SMTP
cIPServerCharacterIP o nombre de host del servidor SMTP
cFromCharacterDirección de correo del remitente
aToArrayArray de direcciones de correo de los destinatarios
aCCArrayDestinatarios en CC
aBCCArrayDestinatarios en BCC
cReplyToCharacterDirección de respuesta (reply-to)
cSubjectCharacterAsunto del correo
cMsgCharacterCuerpo del mensaje en texto plano
cHTMLCharacterCuerpo del mensaje en HTML
aFilesArrayArray de rutas de archivos a adjuntar
cPriorityCharacterPrioridad del mensaje: "normal", "high", "low"
lReceiptLogicalSolicitar acuse de recibo
cUserCharacterNombre de usuario de autenticación SMTP
cPasswordCharacterContraseña de autenticación SMTP
lDoAuthLogicalHabilitar la autenticación SMTP
bConnectingCodeblockAcción mientras se conecta
bConnectedCodeblockAcción al conectarse
bDoneCodeblockAcción cuando el correo se envía con éxito
bFailureCodeblockAcción en caso de fallo
cErrorCharacterÚltimo mensaje de error

Ejemplo: Enviar Correo

function SendEmail()
   local oSmtp

   oSmtp := TSmtp():New( "smtp.myserver.com", 25, .T., "user@myserver.com", "password" )

   oSmtp:cFrom    := "sender@myserver.com"
   oSmtp:aTo      := { "recipient@example.com" }
   oSmtp:aCC      := { "cc@example.com" }
   oSmtp:cSubject := "Test Email from FiveWin"
   oSmtp:cMsg     := "This is a plain text email."
   oSmtp:cHTML    := "<h1>Hello!</h1><p>This is an <b>HTML</b> email.</p>"
   oSmtp:aFiles   := { "c:\docs\report.pdf" }
   oSmtp:cPriority := "high"

   oSmtp:bDone    := {|| MsgInfo( "Email sent successfully!" ) }
   oSmtp:bFailure := {|| MsgAlert( "Failed: " + oSmtp:cError ) }

   oSmtp:SendMail()

return nil

TPop3 - Recibir Correo mediante POP3

TPop3 recupera mensajes de correo de un servidor de correo POP3 usando la clase TSocket de FiveWin. Se conecta, autentica y descarga mensajes en un array de objetos compatibles con TMail. Soporta la recuperación de solo cabeceras y la eliminación de mensajes.

Miembros DATA

DATATipoDescripción
oSocketObjectTSocket para la comunicación POP3
cIPServerCharacterNombre de host del servidor POP3
nPortNumericNúmero de puerto (por defecto 110)
UserCharacterNombre de usuario POP3
PassCharacterContraseña POP3
aMsgsArrayArray de mensajes recuperados
lDelMsgsLogicalEliminar mensajes tras la recuperación (por defecto .T.)
lHeaderOnlyLogicalRecuperar solo cabeceras (por defecto .F.)
bConnectingCodeblockAcción mientras se conecta
bConnectedCodeblockAcción al conectarse
bDoneCodeblockAcción cuando se han recuperado todos los mensajes

Ejemplo: Recuperar Correo

function CheckMail()
   local oPop3

   oPop3 := TPop3():New( "pop3.myserver.com", 110, "user@myserver.com", "password" )
   oPop3:lDelMsgs    := .F.   // No eliminar tras la descarga
   oPop3:lHeaderOnly := .F.   // Obtener los mensajes completos

   oPop3:bDone := {|| ShowMessages( oPop3:aMsgs ) }
   oPop3:GetMail()

return nil

function ShowMessages( aMsgs )
   local n
   for n := 1 to Len( aMsgs )
      ? "Subject:", aMsgs[ n ]:cSubject
      ? "From:",    aMsgs[ n ]:cFrom
      ? "Date:",    aMsgs[ n ]:dDate
      ? "---"
   next
return nil

TMail - Mensaje de Correo MAPI

TMail usa MAPI (Messaging Application Programming Interface) de Windows para componer y enviar correo a través del cliente de correo predeterminado (normalmente Outlook). Proporciona un enfoque más sencillo que TSmtp cuando el usuario tiene instalado un cliente compatible con MAPI.

Miembros DATA

DATATipoDescripción
cSubjectCharacterAsunto del correo
cNoteTextCharacterTexto del cuerpo del correo
cMsgTypeCharacterTipo de mensaje
dDateDateFecha del mensaje
cTimeCharacterHora del mensaje
lReceiptLogicalSolicitar acuse de lectura
lFromUserLogicalMostrar el diálogo de composición para edición por el usuario (por defecto .T.)
aOriginArrayInformación del remitente
aRecipientsArrayArray de arrays de destinatarios: { cName, cAddress }
aFilesArrayArray de rutas de archivos a adjuntar
nRetCodeNumericCódigo de retorno MAPI (0 = SUCCESS_SUCCESS)

Ejemplo: Enviar mediante el Cliente de Correo Predeterminado

local oMail := TMail():New( ;
   "Monthly Report",  ;                   // Asunto
   "Please find the report attached.",  ;  // Cuerpo
   ,, ;                                    // MsgType, ConversationID
   Date(), Time(),  ;                      // Fecha, Hora
   .F., .T.,  ;                            // Receipt, FromUser
   {},  ;                                  // Origen
   { { "John Doe", "john@example.com" } },  ; // Destinatarios
   { "c:\reports\monthly.pdf" } )           // Adjuntos

oMail:Activate()   // Abre el cliente de correo predeterminado con los campos rellenados

if oMail:nRetCode == 0
   ? "Email sent or queued successfully"
endif

oMail:End()

TParser - Análisis de Expresiones

TParser proporciona un motor de análisis (parser) sencillo basado en reglas. Se definen reglas gramaticales como símbolos no terminales con secuencias de tokens y bloques de código de acción asociados. Mantiene estados del parser para construir gramáticas más complejas.

Miembros DATA

DATATipoDescripción
aRulesArrayArray de reglas de análisis: { cNonTerminal, aTokens, bAction }
aStatesArrayEstados de la máquina de estados del parser

Referencia de MÉTODOS

MétodoDescripción
New()Crea un parser vacío.
Add( cNonTerminal, aTokens, bAction )Añade una regla gramatical. cNonTerminal es el nombre de la regla, aTokens define la secuencia de tokens esperada, bAction se ejecuta cuando la regla coincide.

Ejemplo: Analizador de Expresiones Sencillo

local oParser := TParser():New()

// Definir reglas: expresión -> número operador número
oParser:Add( "expr", { "number", "operator", "number" }, ;
   {|aTokens| Eval( aTokens ) } )

oParser:Add( "number", { "digit" }, ;
   {|aTokens| Val( aTokens[ 1 ] ) } )

TGraph - Gráficos y Diagramas

TGraph hereda de TControl y dibuja gráficos de barras, de líneas, de puntos, circulares (de tarta) y diagramas de dispersión XY directamente en una ventana o diálogo. Soporta efectos 3D, líneas de cuadrícula, leyendas, múltiples series, visualización de valores, fuentes y colores personalizados, y puede exportar a BMP o al portapapeles.

GRAPH_TYPE_PIE4Gráfico circular (de tarta)
GRAPH_TYPE_ALL5Combinado barras + líneas + puntos
GRAPH_TYPE_XY_LINES6Dispersión XY con líneas
GRAPH_TYPE_XY_POINTS7Dispersión XY solo con puntos

cSubTitCharacterTexto del subtítulo

lxGrid, lyGridLogicalMostrar líneas de cuadrícula X/Y

Referencia de MÉTODOS

MétodoDescripción
New( nTop, nLeft, oWnd, nWidth, nHeight, cTitle, ... )Crea un control de gráfico en oWnd.
AddSerie( aDat, cLegend, nColor, nType, l3D, lViewVal, lDrawPoint, lDrawLine )Añade una serie de datos con etiqueta, color y sobrescrituras opcionales.
AddXYSerie( aDat, cLegend, nColor, nType, l3D, lViewVal, lDrawPoint, lDrawLine )Añade una serie de dispersión XY. aDat es un array de pares { x, y }.
SetYVals( aTextos )Establece etiquetas de valor personalizadas para el eje Y.
SelSerie( nSerie )Selecciona/resalta una serie específica.
SelPeriod( nPeriod )Selecciona un período específico (columna de datos).
SetFonts( aFonts )Establece las fuentes: { oTitleFont, oXFont, oYFont, oLegendFont }.
SaveAsImage( cFile )Guarda el gráfico como archivo de imagen BMP.
Save2Bmp( cFile )Guarda el gráfico como BMP (alias de SaveAsImage).
Copy2ClipBoard( lMsg )Copia el gráfico al portapapeles como mapa de bits.
End()Destruye el control de gráfico.

Ejemplo: Gráfico de Barras

local oDlg, oGraph

DEFINE DIALOG oDlg TITLE "Sales Report" SIZE 700, 500

oGraph := TGraph():New( 10, 10, oDlg, 680, 450, "Quarterly Sales" )
oGraph:nType   := GRAPH_TYPE_BAR
oGraph:l3D     := .T.
oGraph:lxGrid  := .T.
oGraph:lyGrid  := .T.
oGraph:lxVal   := .T.
oGraph:lyVal   := .T.
oGraph:lLegends := .T.

// Etiquetas de períodos
oGraph:aSeries := { "Q1", "Q2", "Q3", "Q4" }

// Series de datos (un array por producto)
oGraph:AddSerie( { 15000, 22000, 18000, 25000 }, "Product A", CLR_BLUE )
oGraph:AddSerie( { 12000, 19000, 24000, 21000 }, "Product B", CLR_RED )
oGraph:AddSerie( {  8000, 11000, 13000, 17000 }, "Product C", CLR_GREEN )

ACTIVATE DIALOG oDlg CENTER

Ejemplo: Gráfico de Líneas con Exportación

local oDlg, oGraph

DEFINE DIALOG oDlg TITLE "Temperature Trends" SIZE 700, 400

oGraph := TGraph():New( 10, 10, oDlg, 680, 350, "Monthly Temperatures" )
oGraph:nType     := GRAPH_TYPE_LINE
oGraph:lxGrid    := .T.
oGraph:lyGrid    := .T.
oGraph:nPenWidth := 2
oGraph:cTitX     := "Month"
oGraph:cTitY     := "Degrees C"

oGraph:aSeries := { "Jan","Feb","Mar","Apr","May","Jun", ;
                     "Jul","Aug","Sep","Oct","Nov","Dec" }

oGraph:AddSerie( { 5, 7, 12, 18, 23, 28, 31, 30, 25, 18, 11, 6 }, ;
                 "Madrid", CLR_RED, GRAPH_TYPE_LINE )
oGraph:AddSerie( { 2, 3, 8, 14, 19, 24, 27, 26, 21, 14, 8, 3 }, ;
                 "Berlin", CLR_BLUE, GRAPH_TYPE_LINE )

ACTIVATE DIALOG oDlg CENTER ;
   ON INIT ( oGraph:SaveAsImage( "c:\temp\temperatures.bmp" ) )

TMRU - Lista de Archivos Usados Recientemente

Fuente: source/classes/mru.prg

TMRU gestiona una lista de archivos usados recientemente (MRU, Most Recently Used), normalmente mostrada en el menú Archivo de las aplicaciones. Persiste la lista en un archivo INI (mediante TIni) y actualiza automáticamente un menú emergente. Cuando un usuario abre un archivo, la lista MRU se actualiza con la nueva entrada en la parte superior, y las entradas más antiguas descienden o se eliminan si la lista supera el tamaño máximo. Al seleccionar un elemento del menú MRU se ejecuta el codeblock bAction asociado.

DATA Members

DATATipoDescripción
aItemsArrayArray de cadenas con rutas de archivo en orden MRU (el más reciente primero)
nMaxItemsNuméricoNúmero máximo de elementos en la lista MRU (por defecto 4)
cIniFileCarácterRuta al archivo INI para persistir la lista MRU
cSectionCarácterNombre de la sección INI donde se almacenan las entradas MRU
oMenuObjetoObjeto de menú emergente que muestra las entradas MRU
bActionCodeblockCodeblock que se ejecuta cuando se selecciona un elemento MRU; recibe la ruta del archivo

Métodos Principales

MétodoDescripción
New( cIni, cSec, nMax, cMsg, bAction, oMenu, nPos )Crea la lista MRU. Carga desde el INI, crea los elementos del menú emergente y los adjunta a oMenu en la posición nPos
Save( uNew )Añade un nuevo archivo a la parte superior de la lista MRU. Si ya existe, lo mueve a la parte superior. Persiste en el INI. uNew puede ser un único archivo o un array de archivos
Clear()Vacía la lista MRU, elimina todos los elementos del menú y borra la sección del INI

Ejemplo: Menú MRU en el Menú Archivo

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu, oMru

   DEFINE WINDOW oWnd TITLE "MRU Demo"

   MENU oMenu
      MENUITEM "~File"
      POPUP
         MENUITEM "~Open..."   ACTION OpenFile( oWnd, oMru )
         MENUITEM "~Save"      ACTION MsgInfo( "Save" )
         SEPARATOR
         // La lista MRU se insertará aquí en la posición 4
      ENDPOPUP
   ENDMENU

   oWnd:oMenu := oMenu

   // Crea el MRU con máximo 5 elementos, adjunto al menú Archivo en la posición 4
   oMru := TMRU():New( "C:\MyApp\settings.ini", "MRU", 5, ;
                       "Open recent file", {|cFile| OpenRecent( cFile ) }, ;
                       oMenu, 4 )

   ACTIVATE WINDOW oWnd

return nil

function OpenFile( oWnd, oMru )

   local cFile := cGetFile( "All files (*.*)|*.*" )

   if ! Empty( cFile )
      oMru:Save( cFile )   // Añadir al MRU y actualizar el menú
      // ... abrir el archivo
   endif

return nil

function OpenRecent( cFile )

   MsgInfo( "Opening recent: " + cFile )
   // ... abrir el archivo

return nil

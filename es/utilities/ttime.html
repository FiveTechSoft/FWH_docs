TTime

Fuente: source/classes/time.prg

TTime representa un valor de tiempo como segundos transcurridos desde la medianoche. Proporciona aritmética de tiempo (sumar/restar horas, minutos, segundos), formateo a "HH:MM:SS" y la capacidad de leer el reloj del sistema o escribir la hora de vuelta en el reloj del sistema. Internamente, el tiempo se almacena como un único valor numérico (nTime) módulo 86400.

Miembros DATA Principales

DATATipoDescripción
nTimeNumericSegundos desde la medianoche (0-86399)

Métodos Principales

MétodoDescripción
New( nHours, nMinutes, nSeconds )Crea un TTime a partir de valores de hora/minuto/segundo. Todos toman 0 por defecto
System()Inicializa con la hora actual del reloj del sistema
AddHours( n )Suma n horas al tiempo almacenado
AddMinutes( n )Suma n minutos al tiempo almacenado
AddSeconds( n )Suma n segundos al tiempo almacenado
cAdd( nH, nM, nS )Suma una duración de tiempo y devuelve el resultado como una cadena con formato "HH:MM:SS"
cSub( nH, nM, nS )Resta una duración de tiempo (u otro objeto TTime) y devuelve el resultado formateado
cGetTime()Devuelve el tiempo almacenado con formato "HH:MM:SS"
SysChange()Establece el reloj del sistema al valor de tiempo almacenado

Ejemplo: Aritmética de Tiempo

#include "FiveWin.ch"

function Main()

   local oTime, cResult

   // Crear un tiempo: 09:30:00
   oTime := TTime():New( 9, 30, 0 )

   // Sumar 2 horas y 15 minutos
   cResult := oTime:cAdd( 2, 15, 0 )
   MsgInfo( cResult )   // --> "11:45:00"

   // Restar 45 minutos
   cResult := oTime:cSub( 0, 45, 0 )
   MsgInfo( cResult )   // --> "11:00:00"

   // Obtener la hora actual del sistema
   oTime:System()
   MsgInfo( "Current time: " + oTime:cGetTime() )

return nil

Notas

  • Todas las operaciones aritméticas se ajustan módulo 86400 (segundos de un día). Los valores que superan las 24 horas dan la vuelta.
  • cAdd() y cSub() modifican el valor interno nTime y devuelven la nueva cadena formateada.
  • cSub() puede aceptar como primer parámetro valores numéricos de hora/minuto/segundo u otro objeto TTime.
  • SysChange() llama a SysTime( ::nTime ) para escribir la hora en el reloj del sistema; esto puede requerir los privilegios adecuados.

TBackup + TRestore

Fuentes: source/classes/tbackup.prg, source/classes/trestore.prg

Clases independientes

TBackup y TRestore proporcionan funcionalidad de copia de seguridad y restauración de datos, soportando tres tipos de almacenamiento: copia de archivos normal, compresión ZIP y Windows Backup (NTBackup). TBackup gestiona la creación de la copia de seguridad, mientras que TRestore administra el proceso de restauración, incluyendo los puntos de restauración del sistema.

TBackup Miembros DATA Principales

DATATipoDescripción
nTypeNuméricoTipo de copia: BK_NORMAL (copia de archivos), BK_ZIP (comprimida), BK_WIN (Windows Backup)
cSourceCarácterRuta de origen o especificación de archivo
cTargetDirCarácterDirectorio de destino para la copia de seguridad

Comandos

DEFINE BACKUP oZip TYPE BK_ZIP ;
   SOURCE cSrc TARGET cDst ZIPNAME cZip FILES aFiles

Ejemplo: Copia de Seguridad y Restauración ZIP

#include "FiveWin.ch"

function Main()

   local oBackup, oRestore
   local aFiles := { "data1.dbf", "data2.dbf", "data3.dbf" }

   DEFINE BACKUP oBackup TYPE BK_ZIP ;
      SOURCE "C:\Data" TARGET "D:\Backup" ;
      ZIPNAME "backup.zip" FILES aFiles

   if oBackup:Execute()
      MsgInfo( "Backup completed successfully" )
   else
      MsgStop( "Backup failed" )
   endif

   oRestore := TRestore():New( RES_ZIP, "D:\Backup\backup.zip", ;
      "C:\Data\Restored", , aFiles, .T. )

   if oRestore:Execute()
      MsgInfo( "Restore completed successfully" )
   endif

return nil

Notas

  • BK_NORMAL realiza una simple copia de archivos desde el origen al directorio de destino.
  • BK_ZIP comprime los archivos de origen en un único archivo ZIP usando el nombre de archivo ZIP especificado.
  • BK_WIN delega en la utilidad Windows NTBackup para copias de seguridad a nivel de sistema.
  • Use CreateRestorePoint() antes de operaciones destructivas para permitir la reversión del sistema.
  • El array aFiles puede contener nombres de archivo individuales o especificaciones con comodines.

Clases de Archivos, Texto y Datos

FiveWin proporciona un completo conjunto de clases para E/S de archivos, edición de texto, configuración INI, acceso al registro de Windows, operaciones con el portapapeles, interoperabilidad con estructuras C y gestión de diccionarios de datos. Estas clases encapsulan funcionalidades de bajo nivel del sistema operativo en interfaces orientadas a objetos y bien definidas.

TFile - Operaciones con Archivos Binarios

TFile es la clase base para la manipulación de archivos binarios. Encapsula las funciones de bajo nivel FOpen/FCreate/FRead/FWrite de Harbour en un objeto que controla el manejador del archivo, su longitud y la posición actual. TTxtFile hereda de TFile para añadir acceso basado en líneas.

Miembros DATA

DATATipoDescripción
cNameCharacterNombre del archivo (ruta) pasado al constructor
hFileNumericManejador del archivo del SO devuelto por FOpen/FCreate
nLenNumericLongitud total del archivo en bytes
nBufferLenNumericTamaño del buffer de lectura (por defecto 2048)
nModeNumericModo de apertura (FO_READWRITE, FC_NORMAL, etc.)

Referencia de MÉTODOS

MétodoDescripción
New( cFileName, nMode )Abre un archivo existente o crea uno nuevo. Si el archivo existe, lo abre con nMode (por defecto FO_READWRITE). Si no, lo crea con FC_NORMAL.
Create( cFileName, nMode )Borra el archivo existente y luego llama a New() para crear un archivo nuevo.
Open()Devuelve .T. si el manejador del archivo es válido (hFile > 0).
Close()Cierra el manejador del archivo mediante FClose().
End()Alias de Close().
GoTop()Se posiciona en el byte 0 (principio del archivo).
GoBottom()Se posiciona al final del archivo y actualiza nLen.
GoTo( nRecno )Se posiciona en la posición absoluta de byte nRecno.
Skip( nBytes )Mueve el puntero del archivo hacia adelante/atrás en nBytes relativos a la posición actual.
nRecNo()Devuelve la posición de byte actual en el archivo.
lEoF()Devuelve .T. si la posición actual >= nLen.
lBoF()Devuelve .T. si la posición actual == 0.
nGetByte()Lee y devuelve un byte como numérico (valor Asc), o -1 si falla.
nGetWord()Lee y devuelve una palabra de 16 bits (2 bytes) mediante Bin2I(), o -1 si falla.
cGetStr( nLen )Lee nLen bytes y los devuelve como cadena.
PutByte( nByte )Escribe un byte en la posición actual.
PutWord( nWord )Escribe una palabra de 16 bits en la posición actual mediante I2Bin().
PutStr( cStr )Escribe una cadena en la posición actual mediante FWrite().
AppByte( nByte )Añade un byte al final del archivo e incrementa nLen.
AppWord( nWord )Añade una palabra de 16 bits al final del archivo.
AppStr( cStr )Añade una cadena al final del archivo.
Count( cStr )Cuenta las apariciones de cStr en todo el archivo (por defecto CRLF).
Seek( cStr, nDirection, nCase )Busca cStr desde la posición actual. nDirection: 0=adelante, 1=atrás. nCase: 0=sin distinción, 1=mayúsculas, 2=minúsculas.
DelBytes( nLen )Elimina nLen bytes en la posición actual.
InsBytes( nLen )Inserta nLen bytes vacíos en la posición actual.

Ejemplo: Lectura de un archivo binario

local oFile := TFile():New( "data.bin" )

if oFile:Open()
   oFile:GoTop()
   ? "File size:", oFile:nLen, "bytes"

   // Lee la cabecera: firma de 2 bytes + longitud de 4 bytes
   local nSig  := oFile:nGetWord()
   local cData := oFile:cGetStr( 256 )

   ? "Signature:", nSig
   ? "First 256 bytes:", cData

   // Busca un patrón
   oFile:GoTop()
   if oFile:Seek( "MARKER" )
      ? "Found MARKER at position:", oFile:nRecNo()
   endif

   oFile:Close()
endif

Ejemplo: Creación y escritura de un archivo binario

local oFile := TFile():Create( "output.dat" )

oFile:PutWord( 0x4657 )           // firma de 2 bytes "FW"
oFile:PutStr( "Hello World" )     // datos de cadena
oFile:AppStr( CRLF + "Line 2" )  // añade al final

? "Bytes written:", oFile:nLen
oFile:Close()

TTxtFile - Acceso por Líneas a Archivos de Texto

TTxtFile hereda de TFile y añade navegación línea a línea. Cuenta los finales de línea CRLF al abrir y proporciona los métodos Skip/GoTo/ReadLine que trabajan con números de línea en lugar de desplazamientos de byte. Ideal para leer archivos de registro, datos CSV o archivos de configuración.

Miembros DATA

DATATipoDescripción
cLineCharacterContenido de la línea actual tras ReadLine()
nLineNumericNúmero de línea actual (base 1)
nTLinesNumericNúmero total de líneas del archivo
nMaxLineLengthNumericLongitud máxima de línea esperada (por defecto 1024)
nOffsetNumericDesplazamiento de byte del inicio de la línea actual

Referencia de MÉTODOS

MétodoDescripción
New( cFileName, nMode )Abre el archivo, cuenta las líneas (CRLF) y lee la primera línea.
ReadLine()Lee la línea actual en ::cLine desde el desplazamiento de byte actual.
ReadLn()Alias de ReadLine() (compatibilidad hacia atrás).
GoTo( nLine )Se posiciona en la línea número nLine y la lee.
GoTop()Va a la línea 1, restablece el desplazamiento a 0 y lee la primera línea.
GoBottom()Va a la última línea.
Skip( nSkip )Avanza o retrocede nSkip líneas.
Advance()Avanza a la siguiente línea (busca el siguiente CRLF). Devuelve .F. al llegar al final del archivo.
Add( cLine )Añade una nueva línea al final del archivo.
InsLine( cLine )Inserta una nueva línea en la posición actual.
DelLine()Elimina la línea actual.
RepLine( cLine )Reemplaza la línea actual (DelLine + InsLine).
AppendLn( cLine )Añade una línea con terminador CRLF.
RecCount()Devuelve el número total de líneas (igual que nTLines).
RecNo()Devuelve el número de línea actual.
LastRec()Devuelve el número total de líneas.
Skipper( nRecs )Método de desplazamiento compatible con TBrowse.
GetValue( cSection, cKeyword, xDefVal )Lee un valor de secciones de estilo INI en el archivo de texto.
SetValue( cSection, cKeyword, xValue )Escribe un valor en secciones de estilo INI.

Ejemplo: Procesar un archivo de texto línea a línea

local oTxt := TTxtFile():New( "logfile.txt", FO_READ )

if oTxt:Open()
   ? "Total lines:", oTxt:RecCount()

   oTxt:GoTop()
   while ! oTxt:Eof()
      if "ERROR" $ Upper( oTxt:cLine )
         ? "Line", oTxt:nLine, ":", oTxt:cLine
      endif
      oTxt:Skip( 1 )
   end

   oTxt:Close()
endif

Ejemplo: Construir un archivo de texto

local oTxt := TTxtFile():New( "report.csv" )

oTxt:Add( "Name,Age,City" )
oTxt:Add( "John,30,New York" )
oTxt:Add( "Maria,25,Madrid" )
oTxt:Add( "Hans,40,Berlin" )

? "Written", oTxt:RecCount(), "lines"
oTxt:Close()

TTxtEdit - Control Editor de Texto Multilínea

TTxtEdit es un control editor de texto completo con resaltado de sintaxis, deshacer/rehacer, selección de bloques, buscar/reemplazar, numeración de líneas y soporte para el portapapeles. Hereda de TControl y puede colocarse en cualquier ventana o diálogo. Lo utiliza internamente el editor de código de FiveWin y es adecuado para construir interfaces de tipo IDE.

cTokens1, cTokens2, cTokens3CharacterListas de tokens de palabras clave para el resaltado de sintaxis (separadas por espacios)

TIni - Acceso a Archivos INI

TIni proporciona acceso de lectura/escritura a archivos INI de estilo Windows. Encapsula las funciones de la API de Windows GetPrivateProfileString/WritePrivateProfileString. Cuando no se especifica ningún archivo, lee de/escribe en WIN.INI. El indicador lAutoSet (por defecto .T.) escribe automáticamente los valores por defecto si no se encuentra una clave.

Miembros DATA

DATATipoDescripción
cIniFileCharacterRuta al archivo INI. Una cadena vacía significa WIN.INI.
lAutoSetLogicalSi es .T. (por defecto), escribe los valores por defecto cuando no se encuentra la clave en Get().

Referencia de MÉTODOS

MétodoDescripción
New( cIniFile )Crea el objeto TIni. Añade la extensión ".ini" si el nombre de archivo no contiene un punto.
Get( cSection, cEntry, uDefault, uVar )Lee un valor. El tipo lo determina uDefault: numérico devuelve un entero, fecha devuelve CToD(), lógico devuelve la comparación .T./.F., en caso contrario cadena.
Set( cSection, cEntry, uValue )Escribe un valor (convertido a cadena mediante cValToChar).
Sections()Devuelve un array con todos los nombres de sección del archivo INI.
DelSection( cSection )Elimina una sección entera del archivo INI.
DelEntry( cSection, cEntry )Elimina una única entrada de una sección.

Sintaxis de comandos

// FiveWin provides INI command wrappers:
INI oIni FILENAME "myapp.ini"

   GET cServer  SECTION "Database" ENTRY "Server"  DEFAULT "localhost" OF oIni
   GET nPort    SECTION "Database" ENTRY "Port"    DEFAULT 3306        OF oIni
   GET lDebug   SECTION "App"      ENTRY "Debug"   DEFAULT .F.         OF oIni

   SET SECTION "App" ENTRY "LastRun" TO DToC( Date() ) OF oIni

ENDINI

Ejemplo: Configuración de la aplicación

function LoadSettings()
   local oIni := TIni():New( "myapp.ini" )
   local cServer, nPort, cUser

   cServer := oIni:Get( "Database", "Server", "localhost" )
   nPort   := oIni:Get( "Database", "Port",   3306 )
   cUser   := oIni:Get( "Database", "User",   "admin" )

   // Lista todas las secciones
   local aSections := oIni:Sections()
   AEval( aSections, {|c| QOut( "Section:", c ) } )

return nil

function SaveSettings( cServer, nPort )
   local oIni := TIni():New( "myapp.ini" )

   oIni:Set( "Database", "Server", cServer )
   oIni:Set( "Database", "Port",   nPort )
   oIni:Set( "App",      "LastRun", DToC( Date() ) )

return nil

TReg32 - Acceso al Registro de Windows

TReg32 proporciona acceso orientado a objetos al Registro de Windows. Soporta la lectura y escritura de valores de cadena (REG_SZ), numéricos (REG_DWORD) y binarios (REG_BINARY) bajo cualquier subárbol del registro. En aplicaciones de 32 bits que se ejecutan en Windows de 64 bits, añade automáticamente KEY_WOW64_64KEY para acceder correctamente a la vista del registro.

Constantes HKEY

ConstanteValorDescripción
HKEY_CLASSES_ROOT0x80000000Asociaciones de tipos de archivo y registros COM
HKEY_CURRENT_USER0x80000001Preferencias y configuración del usuario actual
HKEY_LOCAL_MACHINE0x80000002Datos de configuración de todo el equipo
HKEY_USERS0x80000003Todos los perfiles de usuario del equipo
HKEY_CURRENT_CONFIG0x80000005Perfil de hardware actual

Miembros DATA

DATATipoDescripción
cRegKeyCharacterRuta de la clave del registro (p. ej. "Software\\MyApp")
nKeyNumericConstante raíz HKEY
nHandleNumericManejador de la clave del registro abierta
nErrorNumericÚltimo código de error (0 = ERROR_SUCCESS)
lErrorLogicalIndicador de error

Referencia de MÉTODOS

MétodoDescripción
New( nKey, cRegKey )Abre una clave del registro existente. Primero intenta KEY_ALL_ACCESS y recurre a KEY_READ.
Create( nKey, cRegKey )Crea una nueva clave del registro (o la abre si ya existe).
Get( cSubKey, uVar )Lee un valor. Devuelve cadena para REG_SZ y numérico para REG_DWORD.
GetBinary( cSubKey )Lee un valor binario como cadena en bruto.
Set( cSubKey, uVar, nType )Escribe un valor. nType vale por defecto REG_SZ para cadenas y REG_DWORD para numéricos.
Delete( cSubKey )Elimina una subclave.
Close()Cierra el manejador de la clave del registro.

Ejemplo: Lectura y escritura de valores del registro

#define HKEY_CURRENT_USER  2147483649

function ReadAppSettings()
   local oReg, cValue := "", nValue := 0

   oReg := TReg32():New( HKEY_CURRENT_USER, "Software\MyCompany\MyApp" )

   if oReg:nError == 0
      oReg:Get( "InstallPath", @cValue )
      ? "Install path:", cValue

      oReg:Get( "RunCount", @nValue )
      ? "Run count:", nValue

      // Incrementa el contador de ejecuciones
      oReg:Set( "RunCount", nValue + 1 )
   endif

   oReg:Close()
return nil

function CreateAppKey()
   local oReg

   oReg := TReg32():Create( HKEY_CURRENT_USER, "Software\MyCompany\MyApp" )
   oReg:Set( "Version", "26.05" )
   oReg:Set( "InstallDate", DToC( Date() ) )
   oReg:Set( "RunCount", 0 )
   oReg:Close()
return nil

TClipBoard - Acceso al Portapapeles

TClipBoard proporciona acceso al portapapeles de Windows para leer y escribir texto, bitmaps, metarchivos y archivos arrastrados. Gestiona automáticamente el texto Unicode cuando FW_SetUnicode() está activo, convirtiendo entre UTF-8 y UTF-16 según sea necesario.

CF_BITMAP2Bitmap (HBITMAP)
CF_OEMTEXT7Texto OEM
CF_UNICODETEXT13Texto Unicode (UTF-16)
CF_ENHMETAFILE14Metarchivo mejorado
CF_HDROP15Lista de archivos arrastrados

Miembros DATA

DATATipoDescripción
nFormatNumericFormato de portapapeles por defecto (CF_TEXT)
oWndObjectVentana propietaria para las operaciones del portapapeles

Referencia de MÉTODOS

MétodoDescripción

Empty()Vacía el contenido del portapapeles.
Clear()Abre, vacía y cierra en un solo paso.
IsEmpty()Devuelve .T. si el portapapeles no tiene datos en el formato actual.
SetText( cText )Escribe texto. Detecta automáticamente UTF-8 y lo convierte a UTF-16 si es necesario.

SetWideText( cText )Escribe texto explícitamente como Unicode (CF_UNICODETEXT).

local oClip := TClipBoard():New()

local oClip := TClipBoard():New()

oBmp:End()

// Recupera un bitmap del portapapeles

   ? "Bitmap recuperado del portapapeles"

TStruct - Interoperabilidad con Estructuras C

TStruct permite definir y manipular estructuras del lenguaje C desde código Harbour/xHarbour. Los miembros se definen con nombre, tipo y longitud opcional. Una vez definidos, se puede acceder a los miembros como propiedades usando el mecanismo de manejo de errores de Harbour. El buffer interno (cBuffer) es una cadena binaria compatible con los parámetros STRUCT de la API de Windows.

Constantes de tipo soportadas

TipoTamaño (bytes)Descripción
BYTE / CHAR1Valor de 8 bits
WORD / _INT / BOOL2Valor de 16 bits
LONG / DWORD / PTR / LPSTR4Valor de 32 bits o puntero
LONGLONG8Valor de 64 bits

Miembros DATA

DATATipoDescripción
cBufferCharacterBuffer binario en bruto que contiene los datos de la estructura
aMembersArrayArray de { cName, nType, nLen, nOffset } para cada miembro

Referencia de MÉTODOS

MétodoDescripción
New()Crea una estructura vacía con un buffer en blanco.
AddMember( cName, nType, nLen )Añade un miembro con nombre. nLen se determina automáticamente a partir de nType si se omite.
SetMember( nMember, uData )Establece el valor de un miembro por índice.
GetMember( nMember )Obtiene el valor de un miembro por índice.
SizeOf()Devuelve el tamaño total de la estructura en bytes (Len de cBuffer).

Ejemplo: Definir y usar una estructura POINT

#include "Struct.ch"

local oPoint := TStruct():New()
oPoint:AddMember( "x", LONG )
oPoint:AddMember( "y", LONG )

// Establece mediante acceso a propiedades (usa el manejador OnError)
oPoint:x := 100
oPoint:y := 200

? "Point:", oPoint:x, oPoint:y
? "Size:", oPoint:SizeOf(), "bytes"    // 8 bytes

// Pasa cBuffer a funciones de la API de Windows que esperan LPPOINT
// GetCursorPos( oPoint:cBuffer )

Ejemplo: Estructura RECT para llamadas a la API

#include "Struct.ch"

local oRect := TStruct():New()
oRect:AddMember( "left",   LONG )
oRect:AddMember( "top",    LONG )

TDict - Diccionario de Datos de la Aplicación

TDict es un gestor de diccionario de datos para aplicaciones FiveWin. Crea y gestiona un conjunto de tablas DBF (en una carpeta "system" por defecto) que describen la estructura de su aplicación: scripts, bases de datos, tablas, browses, columnas, formularios, menús, textos de ayuda y traducciones de idioma. Proporciona métodos para construir automáticamente la interfaz a partir de metadatos, cargar menús dinámicamente y generar vistas web de exploración/edición.

CloseDataBase( cDbName )Cierra una base de datos registrada.
OpenTable( cTblName )Abre una tabla concreta del diccionario.
CreateTable( cTblName )Crea una nueva definición de tabla.
LoadMenu( cMenuName )Carga una definición de menú del diccionario.
BuildSubMenu()Construye submenús a partir de los datos del diccionario.
Report( cReportName )Genera un informe a partir de las definiciones del diccionario.
Import( cMask, bOnEachFile )Importa archivos de datos externos al diccionario.
LoadWebBrowse( cParams )Genera una vista HTML de exploración a partir de los metadatos del diccionario.
LoadWebEdit( cParams )Genera un formulario HTML de edición a partir de los metadatos del diccionario.

Ejemplo: Uso del diccionario de datos

local oDict := TDict():New( "c:\myapp\system" )

oDict:Activate()

// Abre una base de datos registrada
oDict:OpenDataBase( "customers" )

// Carga un menú del diccionario
oDict:LoadMenu( "MainMenu" )

// Genera un informe
oDict:Report( "CustomerList" )

oDict:End()

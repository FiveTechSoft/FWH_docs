TXmlWriter

Fuente: source/classes/TXmlWriter.prg

TXmlWriter es un escritor XML de flujo (streaming) minimalista que escribe directamente en disco. Soporta el patrón estándar OpenTag / Element / CloseTag y produce XML bien formado con sangría automática y escapado de caracteres. Cada método devuelve Self, lo que permite una API fluida (encadenable). El escritor utiliza la E/S de archivos de bajo nivel de Harbour (FCreate / FWrite), por lo que se mantiene eficiente en memoria incluso para documentos grandes.

Miembros DATA Principales

DATATipoDescripción
cFileCharacterRuta del archivo de salida
hFileNumericManejador de archivo devuelto por FCreate ( -1 si la creación falló )
nIndentNumericNivel de sangría actual (basado en 0)
aStackArrayPila de nombres de etiquetas para el anidamiento; asegura que CloseTag sepa qué etiqueta cerrar
lOpenLogicalEl archivo está abierto y se puede escribir en él

Métodos Principales

MétodoDescripción
New( cFile )Crea un escritor y abre el archivo de salida. Devuelve Self
Start( cVersion, cEncoding )Escribe la declaración XML <?xml ... ?>. Valores por defecto: "1.0", "UTF-8". Devuelve Self
OpenTag( cTag, hAttribs )Abre una etiqueta con nombre y un hash opcional de atributos. Aumenta la sangría. Devuelve Self
CloseTag( cTag )Cierra la etiqueta más reciente (o la indicada por nombre). Disminuye la sangría. Devuelve Self
Element( cTag, cValue, hAttribs )Escribe una etiqueta autocerrada o un elemento completo con contenido de texto escapado. Devuelve Self
Comment( cText )Escribe un comentario XML <!-- ... -->. Devuelve Self
CData( cText )Escribe una sección CDATA <![CDATA[...]]>. Devuelve Self
End()Cierra cualquier etiqueta abierta que quede para garantizar una salida bien formada. Devuelve Self
Destroy()Cierra el manejador de archivo si aún está abierto

Ejemplo: Generar XML

#include "FiveWin.ch"

function Main()

   local oXml := TXmlWriter():New( "catalog.xml" )

   oXml:Start()
   oXml:OpenTag( "catalog", { "version" -> "1.0" } )
   oXml:OpenTag( "book",    { "id" -> "101" } )
   oXml:Element( "title",   "FiveWin Programming" )
   oXml:Element( "author",  "Antonio Linares" )
   oXml:Element( "price",   "49.95", { "currency" -> "USD" } )
   oXml:CloseTag( "book" )
   oXml:CloseTag( "catalog" )
   oXml:End()
   oXml:Destroy()

return nil

Notas

  • Todos los métodos públicos (excepto New y Destroy) devuelven Self, lo que permite el encadenamiento de métodos: oXml:Start():OpenTag(...):Element(...):CloseTag():End().
  • Los hashes de atributos utilizan la sintaxis key -> value (hashes de Harbour). Los valores se escapan automáticamente para XML.
  • El método Escape() gestiona las cinco entidades XML predefinidas: &, <, >, " y '.
  • End() cierra automáticamente cualquier etiqueta que quede en la pila, garantizando una salida bien formada incluso si el llamador omitió las llamadas de cierre explícitas.
  • El escritor utiliza una sangría de dos espacios por nivel de anidamiento, controlada por cIndStr.

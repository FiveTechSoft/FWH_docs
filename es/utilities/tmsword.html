FWMSWordDoc

Fuente: source/classes/fwmsword.prg

FWMSWordDoc genera documentos de Microsoft Word de forma programática mediante Automatización OLE. Encapsula el modelo de objetos de Word para crear, formatear y guardar documentos con texto, tablas, imágenes, formas y control de diseño de página. La clase proporciona una superficie de API compatible con TPrinter, permitiendo que el código orientado a impresión produzca salida de Word con cambios mínimos.

Ejemplo: Generar un Documento Word con Tabla

#include "FiveWin.ch"

function Main()

   local oWord

   oWord := FWMSWordDoc():New( "report.docx" )
   if oWord == nil
      MsgStop( "Microsoft Word is not available" )
      return nil
   endif

   oWord:Say( 1, 1, "Sales Report", oWord:oWord:Selection:Font,;
              nil, 0, nil, TA_CENTER )

   oWord:Line( 2, 1, 2, 100, 1, "CM" )

   oWord:Box( 4, 1, 8, 100, 1, RGB( 200, 200, 255 ), , "CM" )

   oWord:PrintImage( 10, 1, "logo.bmp", 40, 20, .T., , , , "MM" )

   oWord:End()

return nil

Notas

  • FWMSWordDoc requiere que Microsoft Word esté instalado en la máquina de destino. El constructor New() devuelve nil si no se puede crear el objeto OLE.
  • La clase está diseñada con una API compatible con TPrinter: Say(), Line(), Box(), PrintImage() y los métodos de conversión de unidades reflejan la interfaz de TPrinter para facilitar la migración.
  • Las unidades de coordenadas se gestionan mediante Units2Pix() / Pix2Units(), que aceptan "PIXEL", "INCH", "CM" o "MM".
  • El método Save() puede exportar a formato PDF cuando se utiliza Word 2007 o posterior (versión 12.0+).
  • Cuando lPreview es .T. (el valor predeterminado), la ventana de Word se hace visible tras End(), permitiendo al usuario revisar el documento.

RRW (Rave Reports Wrapper)

Fuente: source/classes/rrw.prg

Clase independiente

RRW es una clase envoltorio (wrapper) para el motor de ejecución de Rave Reports (RRW). Gestiona la ejecución de informes mediante un archivo de control (un registro de informes basado en DBF), genera un archivo de control .CNT temporal, lanza el motor RRWRUN.EXE como un proceso externo y recopila los resultados de la ejecución. Los informes se definen en un DBF de control (por defecto RREPORTS.DBF) y se ejecutan por nombre.

cRi_FilterCharacterExpresión de filtro opcional
cRi_QueryCharacterModo de consulta: "S"=silencioso, "?"=preguntar, "O"=filtro

cDataDirectoryCharacterDirectorio de los archivos de datos

Métodos Principales

MétodoDescripción
New( cControlFile, cReport, lQuery, lPreview, nBegPage, nEndPage, cDataDirectory, cLibDirectory, cTempDir, cOutFile )Inicializa una ejecución de informe: abre el DBF de control, localiza el informe y genera el archivo de control .CNT
End()Cierra las áreas de la base de datos y marca el objeto como inactivo
Print()Ejecuta el informe mediante RRWRUN.EXE y recopila los resultados
Activate()Alias de Print()
SetFilter( cVar )Establece una expresión de filtro y cambia al modo de consulta por filtro
SetPrinter( cVar )Establece el nombre de la impresora en el archivo de control

ShowError()Muestra un cuadro de mensaje con los detalles del error de ejecución

Ejemplo: Ejecutar un informe de Rave Reports

#include "FiveWin.ch"

function Main()

   local oReport

   oReport := RRW():New( "RREPORTS.DBF", "Invoice", .F., .T., 1, 99999, ;
                         "\data", "\reports" )

   if oReport != nil
      oReport:Print()
      if oReport:aResults[ 1 ] != "0"
         oReport:ShowError()
      else
         MsgInfo( "Informe generado correctamente" )
      endif
      oReport:End()
   endif

return nil

Notas

  • El DBF de control (RREPORTS.DBF) debe contener al menos un campo RI_REPORT para el nombre del informe, RI_LIBRARY para el archivo de la biblioteca de informes, RI_WTITLE para el título de la ventana y RI_WPTR para el nombre de la impresora.
  • La clase invoca RRWRUN.EXE (el motor de ejecución de Rave Reports) como un proceso externo mediante WaitRun().
  • Los resultados se escriben en un archivo .OUT en formato INI y se leen de nuevo mediante TIni.

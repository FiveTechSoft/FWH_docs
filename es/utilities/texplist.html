TExplorerList / TItemListbar

Fuente: source/classes/texplist.prg

TExplorerList hereda de: TControl. TItemListbar es una clase de colaboración interna para los elementos individuales.

TExplorerList es un control de lista de navegación vertical con elementos expandibles/contraíbles, similar al árbol de carpetas del Explorador de Windows o a la barra de Outlook. Cada elemento puede mostrar un bitmap, texto y elementos hijos opcionales con sangría. El control admite navegación por teclado, efectos de paso del ratón, resaltado de selección con degradado y desplazamiento vertical para el contenido que excede el área visible.

TItemListbar admite AddItem() para crear elementos hijos, OpenClose() para expandir/contraer los hijos y Click() para disparar acciones.

Ejemplo: Lista de Navegación con Grupos

#include "FiveWin.ch"

function Main()

   local oWnd, oList, oInbox, oSent

   DEFINE WINDOW oWnd TITLE "TExplorerList Demo" SIZE 300, 400

   @ 10, 10 EXPLORERLIST oList SIZE 280, 380 OF oWnd

   oInbox := oList:AddItem( "Inbox", "inbox.bmp" )
   oInbox:AddItem( "Today", "mail.bmp" )
   oInbox:AddItem( "Yesterday", "mail.bmp" )

   oSent := oList:AddItem( "Sent Items", "sent.bmp" )
   oSent:AddItem( "This Week", "mail.bmp" )

   oList:AddItem( "Deleted Items", "trash.bmp" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Añada elementos hijos llamando a AddItem() sobre un objeto TItemListbar padre. Los elementos hijos se sangran 10 píxeles por nivel.
  • Los elementos se dibujan con fondos en degradado y esquinas redondeadas en tres estados: normal, al pasar el ratón, y seleccionado+al pasar el ratón.
  • Navegación por teclado: flechas Arriba/Abajo, +/- para expandir/contraer, Enter para disparar la acción, Inicio/Fin para el primer/último elemento.
  • La animación de fundido (FadeOn/FadeOff) proporciona retroalimentación visual en los eventos de entrada/salida del ratón.

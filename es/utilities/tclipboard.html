TClipBoard - Portapapeles de Windows

Fuente: source/classes/clipbrd.prg

TClipBoard encapsula la API del Portapapeles de Windows (OpenClipboard, GetClipboardData, SetClipboardData, CloseClipboard, etc.) en una interfaz orientada a objetos. Soporta texto ANSI y Unicode, imágenes bitmap, metarchivos y listas de archivos (del copiar/pegar del Explorador). La clase gestiona automáticamente la propiedad del portapapeles y la secuencia de open/empty/close.

Miembros DATA

DATATipoDescripción
nFormatNuméricoFormato de portapapeles por defecto para operaciones de texto (CF_TEXT)
oWndObjetoVentana propietaria de las operaciones del portapapeles

Métodos Principales

MétodoDescripción
New( nFormat )Crea el objeto portapapeles con formato opcional (por defecto CF_TEXT)
SetText( c )Copia texto ANSI al portapapeles
GetText()Obtiene texto ANSI del portapapeles
SetWideText( c )Copia texto Unicode (wide) al portapapeles
GetUnicodeText()Obtiene texto Unicode del portapapeles
SetBitmap( oBmp )Copia un bitmap al portapapeles
GetBitmap()Obtiene un bitmap del portapapeles
SetMetaFile( o )Copia un metarchivo al portapapeles
GetMetaFile()Obtiene un metarchivo del portapapeles
GetFiles()Devuelve un array con los nombres de archivo de un portapapeles CF_HDROP (copiados desde el Explorador)
Clear()Borra todo el contenido del portapapeles
Open()Abre el portapapeles para múltiples operaciones (después se debe llamar a Empty() y Close())
Empty()Vacía el contenido del portapapeles (se debe llamar tras Open() antes de establecer datos)
Close()Cierra el portapapeles (se debe llamar tras Open())

Ejemplo: Copiar/Pegar texto y archivos

#include "FiveWin.ch"

function Main()

   local oClip := TClipBoard():New()

   // Copia texto al portapapeles
   oClip:SetText( "Hello from FiveWin!" )
   ? "Text copied to clipboard"

   // Pega texto desde el portapapeles
   ? "Clipboard content:", oClip:GetText()

   // Copia una lista de archivos (como si fuera del Explorador)
   oClip:Open()
   oClip:Empty()
   // ... establece datos CF_HDROP mediante la API de Windows
   oClip:Close()

   // Lee los archivos copiados desde el Explorador
   local aFiles := oClip:GetFiles()
   if ValType( aFiles ) == "A"
      AEval( aFiles, {|c| ? "File: " + c } )
   endif

return nil

Ejemplo: Copiar un bitmap

function CopyBitmap()

   local oClip := TClipBoard():New()
   local oBmp  := TBitmap():New( "logo.bmp" )

   oClip:SetBitmap( oBmp )
   MsgInfo( "Bitmap copied to clipboard" )

return nil

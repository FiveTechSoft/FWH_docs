OLE, COM, ActiveX & Interoperabilidad .NET

FiveWin proporciona soporte integral para automatización COM/OLE de Windows, incrustación de ActiveX y APIs modernas de correo electrónico en la nube. Estas clases permiten automatizar aplicaciones de Microsoft Office, incrustar controles ActiveX en diálogos, interactuar con ensamblados .NET y enviar correo electrónico a través de las APIs de Gmail y Outlook.

TOleAuto - Automatización OLE

TOleAuto es la clase principal de FiveWin para automatización OLE/COM. Encapsula la funcionalidad win_oleAuto de Harbour, permitiendo crear y controlar objetos OLE como Microsoft Word, Excel, Outlook, Internet Explorer y cualquier otro servidor de automatización. Las propiedades y métodos del objeto OLE se acceden de forma transparente a través del manejador de errores de Harbour -- se llaman como si fueran miembros nativos de la clase.

Cómo Funciona

Cuando se llama a TOleAuto():New("Word.Application"), FiveWin llama a CreateOleObject() que invoca CoCreateInstance() internamente para crear el objeto COM. El puntero IDispatch devuelto se almacena en el miembro DATA hObj. Cualquier acceso a método o propiedad que no esté definido en la clase es interceptado por el manejador OnError, que lo enruta a través de OleInvoke() u OleGetProperty()/OleSetProperty().

Miembros DATA

DATATipoDescripción
hObjPointer/NumericPuntero IDispatch al objeto de automatización OLE

Referencia de Métodos

MétodoDescripción
New( cClassName )Crea un objeto de automatización OLE por ProgID (ej. "Excel.Application", "Word.Application").
End()Libera el objeto COM y llama a OleUninitialize().
(cualquier propiedad)Obtener/Establecer cualquier propiedad OLE mediante el manejador OnError. Ej. oExcel:Visible := .T.
(cualquier método)Invocar cualquier método OLE de forma transparente. Ej. oWord:Documents:Add()

Ejemplo: Crear un Documento de Word

function CreateWordDoc()
   local oWord, oDoc, oSelection

   // Create Word application
   oWord := TOleAuto():New( "Word.Application" )
   oWord:Visible := .T.

   // Add a new document
   oDoc := oWord:Documents:Add()

   // Get the selection (cursor) and type text
   oSelection := oWord:Selection
   oSelection:Font:Name := "Arial"
   oSelection:Font:Size := 14
   oSelection:Font:Bold := .T.
   oSelection:TypeText( "FiveWin Report" )
   oSelection:TypeParagraph()

   oSelection:Font:Size := 11
   oSelection:Font:Bold := .F.
   oSelection:TypeText( "Generated on " + DToC( Date() ) + " at " + Time() )
   oSelection:TypeParagraph()
   oSelection:TypeParagraph()
   oSelection:TypeText( "This document was created from a Harbour/FiveWin application." )

   // Save and close
   oDoc:SaveAs( "c:\temp\report.docx" )

   MsgInfo( "Word document created successfully!" )

   // Don't quit Word - let user review the document
   // oWord:Quit()

return nil

Ejemplo: Crear una Hoja de Cálculo de Excel

function CreateExcel()
   local oExcel, oBook, oSheet, n

   oExcel := TOleAuto():New( "Excel.Application" )
   oExcel:Visible := .T.

   oBook  := oExcel:WorkBooks:Add()
   oSheet := oExcel:ActiveSheet

   // Column headers
   oSheet:Cells( 1, 1 ):Value := "Product"
   oSheet:Cells( 1, 2 ):Value := "Quantity"
   oSheet:Cells( 1, 3 ):Value := "Price"
   oSheet:Cells( 1, 4 ):Value := "Total"

   // Bold headers
   oSheet:Range( "A1:D1" ):Font:Bold := .T.
   oSheet:Range( "A1:D1" ):Interior:Color := RGB( 200, 220, 255 )

   // Data rows
   local aData := { ;
      { "Widget A", 100, 9.99 }, ;
      { "Widget B",  50, 19.99 }, ;
      { "Widget C", 200, 4.99 }, ;
      { "Widget D",  75, 29.99 } }

   for n := 1 to Len( aData )
      oSheet:Cells( n + 1, 1 ):Value := aData[ n ][ 1 ]
      oSheet:Cells( n + 1, 2 ):Value := aData[ n ][ 2 ]
      oSheet:Cells( n + 1, 3 ):Value := aData[ n ][ 3 ]
      oSheet:Cells( n + 1, 4 ):Formula := "=B" + AllTrim( Str( n + 1 ) ) + ;
                                            "*C" + AllTrim( Str( n + 1 ) )
   next

   // Total formula
   oSheet:Cells( 6, 3 ):Value := "Grand Total:"
   oSheet:Cells( 6, 3 ):Font:Bold := .T.
   oSheet:Cells( 6, 4 ):Formula := "=SUM(D2:D5)"
   oSheet:Cells( 6, 4 ):Font:Bold := .T.

   // Auto-fit columns
   oSheet:Columns( "A:D" ):AutoFit()

   oBook:SaveAs( "c:\temp\products.xlsx" )
   MsgInfo( "Excel file created!" )

return nil

function SendOutlookEmail()

TComObject - Interfaz COM de Bajo Nivel

TComObject es una alternativa de más bajo nivel a TOleAuto para interoperabilidad COM. Almacena el puntero IDispatch como un valor numérico y proporciona llamadas Invoke() explícitas. Las propiedades se acceden a través del manejador OnError, que las enruta mediante OleGetProperty/OleSetProperty. Cuando un método devuelve otro objeto COM, TComObject lo encapsula automáticamente.

Miembros DATA

DATATipoDescripción
nIDispatchNumericPuntero IDispatch en bruto al objeto COM

Referencia de Métodos

MétodoDescripción
New( cClassName )Crea un objeto COM mediante una cadena ProgID, o encapsula un IDispatch existente si se pasa un valor numérico.
Invoke( cMethodName, uParam1, uParam2, uParam3 )Invoca un método explícitamente. Devuelve un nuevo TComObject si el resultado es un IDispatch.
ClassName()Devuelve el nombre de clase del objeto COM mediante OleGetProperty.
End()Llama a OleUninitialize() para liberar el objeto COM.

Ejemplo: Uso de TComObject

local oCom := TComObject():New( "Scripting.FileSystemObject" )

if oCom:nIDispatch != 0
   ? "Drives available:"

   local oDrives := oCom:Drives
   ? "Total drives:", oDrives:Count

   // Check if C: drive exists
   if oCom:DriveExists( "C:" )
      local oDrive := oCom:GetDrive( "C:" )
      ? "C: Drive - Total:", oDrive:TotalSize, "Free:", oDrive:FreeSpace
   endif

   oCom:End()
endif

TActiveX - Controles ActiveX Incrustados

TActiveX hereda de TControl y permite incrustar cualquier control ActiveX/OCX dentro de una ventana o diálogo de FiveWin. Crea el contenedor ActiveX usando la incrustación OLE de Windows, y luego expone los métodos y propiedades del control a través de un objeto TOleAuto interno. Los eventos del control ActiveX pueden capturarse mediante el codeblock bOnEvent.

Miembros DATA

DATATipoDescripción
hActiveXNumericManejador del contenedor ActiveX
cProgIDCharacterProgID del control ActiveX (ej. "Shell.Explorer.2")
cStringCharacterCadena de visualización del control ActiveX
oOleAutoObjectEnvoltorio TOleAuto interno para el IDispatch del control
aPropertiesArrayPropiedades disponibles (rellenadas por ReadTypes)
aMethodsArrayMétodos disponibles (rellenados por ReadTypes)
aEventsArrayEventos disponibles (rellenados por ReadTypes)
bOnEventCodeblockManejador de eventos: {|nEvent, aParams, pParams| ... }

Referencia de Métodos

MétodoDescripción
New( oWnd, cProgID, nRow, nCol, nWidth, nHeight )Crea un control ActiveX en oWnd en la posición indicada.
ReDefine( nId, oWnd, cProgID )Redefine desde un ID de control de recurso de diálogo.
Do( ... )Invoca un método sobre el objeto OLE subyacente. Pase el nombre del método y los parámetros.
GetProp( cPropName )Obtiene el valor de una propiedad del control ActiveX.
SetProp( cPropName, uValue )Establece el valor de una propiedad en el control ActiveX.
ReadTypes()Lee la información de tipos (propiedades, métodos, eventos) del control.
OnEvent( nEvent, aParams, pParams )Despachador de eventos interno. Sobrescriba bOnEvent para un manejo personalizado.
Destroy()Destruye el contenedor ActiveX y libera los recursos.

Ejemplo: Incrustar un Navegador Web

function EmbedBrowser()
   local oDlg, oActiveX

   DEFINE DIALOG oDlg TITLE "Embedded Browser" SIZE 800, 600

   // Shell.Explorer.2 is Internet Explorer's ActiveX ProgID
   oActiveX := TActiveX():New( oDlg, "Shell.Explorer.2", 0, 0, 800, 600 )

   // Handle navigation events
   oActiveX:bOnEvent := {| nEvent, aParams |  ;
      If( nEvent == 252, ( MsgInfo( "Navigating to: " + aParams[ 2 ] ) ), ) }

   ACTIVATE DIALOG oDlg CENTER ;
      ON INIT ( oActiveX:Navigate( "https://www.fivetechsoft.com" ) )

return nil

Ejemplo: Incrustar un Visor de PDF

function ShowPDF( cPdfFile )
   local oDlg, oActiveX

   DEFINE DIALOG oDlg TITLE "PDF Viewer" SIZE 800, 600

   // Adobe Acrobat Reader ActiveX
   oActiveX := TActiveX():New( oDlg, "AcroPDF.PDF.1", 0, 0, 800, 600 )

   ACTIVATE DIALOG oDlg CENTER ;
      ON INIT ( oActiveX:LoadFile( cPdfFile ), ;
                oActiveX:SetView( "FitH" ) )

return nil

Ejemplo: Incrustar Windows Media Player

function PlayMedia( cMediaFile )
   local oDlg, oWMP

   DEFINE DIALOG oDlg TITLE "Media Player" SIZE 640, 480

   oWMP := TActiveX():New( oDlg, "WMPlayer.OCX", 0, 0, 640, 480 )

   ACTIVATE DIALOG oDlg CENTER ;
      ON INIT ( oWMP:URL := cMediaFile )

TDotNet - Interoperabilidad .NET

FiveWin admite la llamada a ensamblados .NET desde Harbour a través de interoperabilidad COM. Aunque no existe una clase TDotNet dedicada en el código fuente, los componentes .NET que exponen interfaces COM pueden instanciarse mediante TOleAuto. Para ensamblados .NET personalizados, puede registrarlos para interoperabilidad COM usando regasm y luego crearlos como cualquier otro objeto COM.

Enfoque: Usar .NET mediante Interoperabilidad COM

sequenceDiagram participant Harbour as Harbour/FiveWin participant COM as COM Runtime participant CLR as .NET CLR participant Assembly as .NET Assembly Harbour->>COM: CreateOleObject("MyLib.MyClass") COM->>CLR: Load CLR Host CLR->>Assembly: Instantiate class Assembly-->>COM: IDispatch pointer COM-->>Harbour: TOleAuto object Harbour->>COM: Property/Method calls COM->>Assembly: Invoke via IDispatch

Ejemplo: Llamar a .NET mediante COM

// Paso 1: Registrar el ensamblado .NET para interoperabilidad COM (ejecutar una vez desde la línea de comandos):
//   regasm MyLibrary.dll /tlb:MyLibrary.tlb /codebase

// Paso 2: Usar desde Harbour/FiveWin
function UseDotNet()
   local oDotNet

   TRY
      oDotNet := TOleAuto():New( "MyLibrary.MyClass" )
      ? oDotNet:MyMethod( "Hello from Harbour!" )
      ? oDotNet:MyProperty
      oDotNet:End()
   CATCH
      MsgAlert( "Componente .NET no registrado o no disponible" )
   END

return nil

Ejemplo: Usar Bibliotecas de Sistema .NET

// Los tipos mscorlib de .NET expuestos mediante COM se pueden acceder directamente
function DotNetExample()
   local oNet

   // Crear un StringBuilder de .NET mediante COM
   TRY
      oNet := TOleAuto():New( "System.Text.StringBuilder" )
      oNet:Append( "Hello" )
      oNet:Append( " World" )
      ? oNet:ToString()
   CATCH
      // La interoperabilidad COM de .NET puede no estar disponible en todos los sistemas
      MsgAlert( "Requiere registro COM de .NET" )
   END

return nil

TGmail - Integración con la API de Gmail

TGmail hereda de TOAuth y proporciona acceso autenticado con OAuth2 a la API de Gmail. Utiliza libcurl para la comunicación HTTP y admite el envío de correos con contenido HTML y archivos adjuntos. La autenticación se gestiona mediante el flujo OAuth2 de Google con tokens de actualización.

Miembros DATA

DATATipoDescripción
cTokenCharacterToken de actualización OAuth2
hTokenHashRespuesta de token analizada (access_token, etc.)
hConfigHashConfiguración OAuth: client_id, client_secret, redirect_uri

Referencia de Métodos

MétodoDescripción
New( cToken )Crea una instancia de TGmail con un token de actualización opcional.
SetConfig( hConfig )Establece el hash de configuración OAuth2 con client_id, client_secret, redirect_uri.
SetToken( cToken )Establece el token de actualización.
Auth()Inicia el flujo de autorización OAuth2. Abre el navegador para el consentimiento del usuario.
IsAuth()Comprueba si el token actual es válido (lo valida contra el endpoint de información de token de Google).
GetToken( cCode )Intercambia el código de autorización por un token de acceso.
Me()Devuelve la información de perfil del usuario autenticado.
Send( cTo, cSubject, cMessage, lHTML, aAttachment )Envía un correo. lHTML: .T. para cuerpo HTML. aAttachment: array de rutas de archivo.
Revoke()Revoca el token OAuth2.

Ejemplo: Enviar Correo a través de Gmail

function SendGmail()
   local oGmail := TGmail():New()

   // Configurar credenciales OAuth2 (desde Google Cloud Console)
   oGmail:SetConfig( { ;
      "client_id"     => "your-client-id.apps.googleusercontent.com", ;
      "client_secret" => "your-client-secret", ;
      "redirect_uri"  => "http://localhost:8888" ;
   } )

   // Autenticación por primera vez (abre el navegador)
   if ! oGmail:IsAuth()
      oGmail:Auth()
   endif

   if oGmail:IsAuth()
      // Enviar un correo de texto plano
      oGmail:Send( "recipient@example.com", ;
                   "Hello from FiveWin", ;
                   "This email was sent using TGmail class.", ;
                   .F. )   // .F. = texto plano

      // Enviar correo HTML con archivo adjunto
      oGmail:Send( "recipient@example.com", ;
                   "Monthly Report", ;
                   "<h1>Report</h1><p>Please see attached.</p>", ;
                   .T., ;   // .T. = HTML
                   { "c:\reports\monthly.pdf" } )

      MsgInfo( "Emails sent successfully!" )
   else
      MsgAlert( "La autenticación de Gmail falló" )
   endif

return nil

TOutlookMail - API de Correo de Outlook

TOutlookMail hereda de TOAuth y proporciona acceso autenticado con OAuth2 a la API de Microsoft Graph para enviar correo a través de Outlook/Office 365. Al igual que TGmail, utiliza libcurl y admite contenido HTML, archivos adjuntos y destinatarios CC y BCC. Gestiona automáticamente la rotación del token de actualización cuando Microsoft los rota.

Miembros DATA

DATATipoDescripción
cTokenCharacterToken de actualización OAuth2
hTokenHashRespuesta de token analizada (access_token, refresh_token, etc.)
hConfigHashConfiguración OAuth: client_id, client_secret, redirect_uri, tenant
hUserHashInformación de perfil del usuario autenticado

Referencia de Métodos

MétodoDescripción
New( cToken )Crea una instancia con un token de actualización opcional.
SetConfig( hConfig )Establece la configuración OAuth2: client_id, client_secret, redirect_uri (con puerto para el servidor local).
SetToken( cToken )Establece el token de actualización.
Auth()Inicia el flujo de autorización OAuth2 de Microsoft.
IsAuth()Valida el token, lo renueva automáticamente si ha expirado. Actualiza refresh_token si fue rotado.
GetToken( cCode )Intercambia el código de autorización por tokens de acceso/actualización.
Me( cPhoto )Devuelve el perfil del usuario. Opcionalmente guarda la foto de perfil en la ruta cPhoto.
Send( aTo, cSubject, cMessage, lHTML, aAttachment, aBCC, aCC )Envía un correo. aTo/aBCC/aCC son arrays de direcciones de correo.
Revoke()Revoca el token OAuth2.

Ejemplo: Enviar Correo a través de Outlook/Office 365

function SendOutlookAPI()
   local oMail := TOutlookMail():New()

   // Configurar las credenciales de la app de Azure AD
   oMail:SetConfig( { ;
      "client_id"     => "your-azure-app-client-id", ;
      "client_secret" => "your-azure-client-secret", ;
      "redirect_uri"  => "http://localhost:9090", ;
      "tenant"        => "common" ;
   } )

   // Autenticar (abre el navegador para el inicio de sesión de Microsoft)
   if ! oMail:IsAuth()
      oMail:Auth()
   endif

   if oMail:IsAuth()
      // Obtener información del usuario
      local hUser := oMail:Me()
      ? "Sending as:", hUser[ "displayName" ], hUser[ "mail" ]

      // Enviar correo con CC y BCC
      oMail:Send( ;
         { "recipient@example.com", "another@example.com" }, ;  // Para
         "Project Update", ;                                      // Asunto
         "<h2>Weekly Update</h2><p>All tasks completed.</p>", ; // Cuerpo
         .T., ;                                                   // HTML
         { "c:\docs\status.pdf" }, ;                             // Adjuntos
         { "boss@example.com" }, ;                                // BCC
         { "team@example.com" } )                                 // CC

      MsgInfo( "Email sent via Outlook API!" )
   endif

return nil

Consejos y Buenas Prácticas

Manejo de Errores OLE

// Envuelva siempre las llamadas OLE en TRY/CATCH
TRY
   local oExcel := TOleAuto():New( "Excel.Application" )
   // ... trabajar con Excel
   oExcel:Quit()
CATCH oErr
   MsgAlert( "OLE Error: " + oErr:Description + CRLF + ;
             "Make sure the application is installed." )
END

Patrón de Manejo de Eventos ActiveX

// El codeblock bOnEvent recibe:
//   nEvent  - ID numérico del evento
//   aParams - array de parámetros del evento
//   pParams - punteros de parámetros en bruto

oActiveX:bOnEvent := {| nEvent, aParams, pParams |  ;
   do case ;
   case nEvent == 250 ;   // BeforeNavigate2
      ? "Navigating to:", aParams[ 2 ] ;
   case nEvent == 252 ;   // DocumentComplete
      ? "Page loaded" ;
   case nEvent == 259 ;   // NewWindow3
      ? "Popup blocked" ;
   endcase ;
}

Liberación de Objetos COM

Libere siempre los objetos COM cuando termine. Para aplicaciones de Office, llame a Quit() antes de liberar, o el proceso puede permanecer en memoria:

// Orden de limpieza correcto para Excel:
oSheet := nil
oBook:Close( .F. )    // .F. = no guardar
oBook  := nil
oExcel:Quit()
oExcel := nil
SysRefresh()           // Permitir la limpieza de COM

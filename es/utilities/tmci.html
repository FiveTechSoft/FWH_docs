TMci

Fuente: source/classes/tmci.prg

Clase independiente

TMci proporciona control de reproducción multimedia a través de la API Windows Media Control Interface (MCI). Admite la reproducción de archivos de audio y vídeo, incluyendo vídeo AVI, audio de CD, WAV, MIDI y otros dispositivos compatibles con MCI. La clase puede reproducir medios en una ventana o a pantalla completa.

Miembros DATA Principales

DATATipoDescripción
nErrorNuméricoÚltimo código de error MCI; cero indica éxito
nIdNuméricoIdentificador del dispositivo MCI asignado al abrir
cTypeCarácterTipo de dispositivo: "AVIVideo", "CDAudio", "WaveAudio", "Sequencer", etc.
cFileNameCarácterRuta al archivo multimedia que se está reproduciendo
oWndObjetoVentana padre para la reproducción de vídeo

Métodos Principales

MétodoDescripción
New( cDev, cFile )Crea un nuevo objeto MCI para el tipo de dispositivo y archivo multimedia indicados
lOpen()Abre el dispositivo MCI; devuelve .T. si tiene éxito
Play( nFrom, nTo, hWnd )Reproduce un segmento desde nFrom hasta nTo, opcionalmente en un manejador de ventana
PlayFull()Reproduce los medios en modo pantalla completa
SetWindow( oWnd )Establece la ventana padre para la salida de vídeo
Position()Devuelve la posición actual de reproducción
Length()Devuelve la duración total del medio
SendStr( cMci )Envía una cadena de comando MCI sin procesar directamente al dispositivo
cGetError()Devuelve una descripción legible del último error
End()Cierra el dispositivo MCI y libera los recursos

Ejemplo: Reproducir un archivo AVI

#include "FiveWin.ch"

function Main()

   local oMci, oWnd

   DEFINE WINDOW oWnd TITLE "MCI Video Player" SIZE 640, 480

   oMci := TMci():New( "AVIVideo", "sample.avi" )

   if oMci:lOpen()
      oMci:SetWindow( oWnd )
      oMci:Play()
      MsgInfo( "Playing: " + oMci:cFileName )
   else
      MsgStop( "Cannot open: " + oMci:cGetError() )
   endif

   ACTIVATE WINDOW oWnd CENTERED

   oMci:End()

return nil

Notas

  • El parámetro cType determina qué controlador MCI se carga. Entre los tipos comunes se incluyen "AVIVideo", "WaveAudio", "CDAudio" y "Sequencer" (MIDI).
  • Llame a lOpen() antes de cualquier operación de reproducción. Compruebe el valor devuelto para confirmar que el dispositivo se abrió correctamente.
  • Use Play() con un manejador de ventana para incrustar el vídeo en la interfaz de su aplicación, o PlayFull() para la reproducción a pantalla completa.
  • El método SendStr() ofrece acceso de bajo nivel a cualquier cadena de comando MCI para operaciones avanzadas no cubiertas por los métodos de la clase.
  • Llame siempre a End() al terminar para liberar el dispositivo MCI y evitar fugas de recursos.

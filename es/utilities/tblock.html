TBlock - Bloque de Código desde Cadena de Expresión

Fuente: source/classes/block.prg

TBlock crea bloques de código de Harbour (bBlock) a partir de cadenas de expresión de caracteres en tiempo de ejecución. Esto permite la evaluación dinámica de expresiones introducidas por el usuario o leídas desde archivos de configuración. La clase compila la cadena de expresión usando el operador & (macro) de Harbour y almacena el bloque de código resultante. El método Eval() evalúa el bloque con parámetros opcionales, mientras que Exec() lo ejecuta por sus efectos secundarios.

DATA Members

DATATipoDescripción
cExpressionCharacterLa cadena de expresión a partir de la cual se compiló el bloque de código
bBlockCodeblockEl bloque de código compilado listo para su evaluación

Métodos Principales

MétodoDescripción
New( cExpr )Crea un objeto TBlock a partir de la cadena de expresión cExpr. La compila en bBlock
Eval( uPar1 .. uPar5 )Evalúa el bloque de código con hasta cinco parámetros y devuelve el resultado
Exec( uPar1 .. uPar5 )Evalúa el bloque de código por sus efectos secundarios (el valor de retorno se descarta)

Ejemplo: Evaluación de Expresiones en Tiempo de Ejecución

#include "FiveWin.ch"

function Main()

   local cExpr, oBlock, nResult

   // Obtener la expresión de la entrada del usuario
   cExpr := "2 + 3 * 4"

   oBlock := TBlock():New( cExpr )
   if oBlock:bBlock != nil
      nResult := oBlock:Eval()
      ? cExpr + " = " + Str( nResult )    // 14
   endif

   // Expresión con parámetros
   oBlock := TBlock():New( "x + y" )
   if oBlock:bBlock != nil
      nResult := oBlock:Eval( 10, 20 )
      ? "x + y = " + Str( nResult )       // 30
   endif

   // Expresión desde archivo de configuración
   local cConfigExpr := "Year( Date() ) - 2000"
   oBlock := TBlock():New( cConfigExpr )
   ? "Year offset:", oBlock:Eval()

   // Exec con efectos secundarios
   oBlock := TBlock():New( "MsgInfo( 'Hello from TBlock!' )" )
   oBlock:Exec()

return nil

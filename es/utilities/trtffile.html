TRtfFile - Generador de Documentos de Ayuda RTF/HPJ

Fuente: source/classes/rtffile.prg

TRtfFile genera archivos en formato Rich Text Format (.RTF) adecuados para compilarse en archivos de Ayuda de Windows (.HLP) con el Microsoft Help Workshop (HCW.EXE). Produce entradas de temas cortos y largos, enlaces de salto (jump) y emergentes (popup), referencias a mapas de bits, identificadores de temas, listas de temas relacionados (see-also) y saltos de página, todo ello en sintaxis RTF válida que el Compilador de Ayuda comprende.

Métodos Principales

MétodoDescripción
New( cFile )Crea un nuevo archivo RTF con la cabecera de ayuda estándar (formato de notas al pie)
WriteShort( cText, cJump, lPopup, cBmp )Escribe un tema corto. cText es lo que se muestra; cJump es la cadena de contexto; lPopup indica emergente (popup) frente a salto (jump); cBmp opcionalmente incrusta un mapa de bits
WriteLong( cText )Escribe un párrafo de tema largo con texto del cuerpo
WriteId( cId )Escribe una nota al pie # con la cadena del identificador del tema (usada como nombre de contexto para los saltos)
WriteSeeAlso( cList )Escribe una nota al pie $ con una lista de "Ver también" de títulos de temas relacionados
NewPage()Inserta un salto de página (form-feed) para separar temas en el RTF
End()Finaliza el archivo RTF con las llaves de cierre y lo cierra

Ejemplo: Generar un Archivo de Temas de Ayuda

#include "FiveWin.ch"

function Main()

   local oRtf := TRtfFile():New( "help.rtf" )

   // Primer tema: Introducción
   oRtf:WriteId( "INTRO" )
   oRtf:WriteShort( "Welcome to MyApp", "INTRO", .F., "" )
   oRtf:WriteLong( "This is the introduction to MyApp." )
   oRtf:WriteLong( "Click below for more information." )
   oRtf:WriteSeeAlso( "Instalación|Configuration" )
   oRtf:NewPage()

   // Segundo tema: Instalación
   oRtf:WriteId( "INSTALL" )
   oRtf:WriteShort( "Instalación Guide", "INSTALL", .F., "" )
   oRtf:WriteLong( "Follow these steps to install MyApp." )
   oRtf:WriteSeeAlso( "Introduction" )
   oRtf:NewPage()

   oRtf:End()
   MsgInfo( "Help file help.rtf generated" )

return nil

FWStack

Fuente: source/classes/fwstack.prg

FWStack implementa una estructura de datos de pila clásica LIFO (Last-In, First-Out, último en entrar, primero en salir). Almacena los elementos en un array interno y proporciona operaciones de apilar (push), desapilar (pop) y consultar (peek). El constructor y el método Push() aceptan listas de argumentos de longitud variable, permitiendo añadir varios elementos en una sola llamada. FWStack es útil para operaciones de deshacer/rehacer, evaluación de expresiones y cualquier escenario que requiera una gestión de datos de tipo último-en-entrar-primero-en-salir.

Miembros DATA Principales

DATATipoDescripción
aStackArrayArray interno que contiene los elementos de la pila

Métodos Principales

MétodoDescripción
New( item1, item2, ... )Crea una pila inicializada con los elementos indicados (de abajo hacia arriba)
Push( item1, item2, ... )Apila uno o más elementos en la cima de la pila. Devuelve Self para encadenamiento.
Pop()Elimina y devuelve el elemento superior de la pila. Devuelve nil si la pila está vacía.
Peek( n )Devuelve el n-ésimo elemento desde la cima sin eliminarlo. n vale 1 por defecto (la cima). Un n negativo indexa desde el fondo (p. ej., -1 es el fondo). Devuelve nil si el índice está fuera de rango.
Size()Devuelve el número de elementos de la pila
Clear()Elimina todos los elementos de la pila. Devuelve Self para encadenamiento.

Ejemplo: Apilar/Desapilar Valores

#include "FiveWin.ch"

function Main()

   local oStack := FWStack():New()

   // Apilar varios elementos
   oStack:Push( 10, 20, 30, 40, 50 )

   ? "Stack size:", oStack:Size()       // 5

   // Consultar el elemento superior sin eliminarlo
   ? "Top item:", oStack:Peek()         // 50

   // Consultar el elemento 2 desde la cima
   ? "Second from top:", oStack:Peek( 2 )  // 40

   // Desapilar elementos
   while oStack:Size() > 0
      ? "Popped:", oStack:Pop()
   end

   ? "Stack is empty:", oStack:Size() == 0  // .T.

   // Inicializar con elementos
   oStack := FWStack():New( "apple", "banana", "cherry" )
   ? oStack:Pop()   // "cherry"
   ? oStack:Pop()   // "banana"
   ? oStack:Pop()   // "apple"
   ? oStack:Pop()   // nil (vacía)

return nil

Notas

  • Los métodos de FWStack que aceptan argumentos variables (New, Push) funcionan tanto con Harbour como con xHarbour. En xHarbour, aceptan un parámetro de tipo array en lugar de varargs.
  • El método Peek() sin argumento devuelve el elemento superior sin eliminarlo. Con un argumento positivo n, busca n posiciones desde la cima (1 = cima). Con un argumento negativo, cuenta desde el fondo (-1 = fondo).
  • Push() y Clear() devuelven Self, lo que permite encadenar métodos: oStack:Clear():Push( 1, 2, 3 ):Push( 4 ).
  • Pop() devuelve nil cuando la pila está vacía -- compruebe con oStack:Size() > 0 antes de desapilar.

Integración con Excel

Fuente: source/function/fwxlsxlb.prg, source/function/drxl.prg, source/function/readxlsx.prg

FiveWin proporciona tres estrategias complementarias para la integración de archivos Excel, que van desde la generación nativa de alta velocidad usando la librería C xlsxlibhb (basada en libxlsxwriter), hasta la automatización OLE mediante TOleAuto para el control COM completo de Excel, y el análisis directo de XML para leer archivos .xlsx sin Excel.

Visión General de las Estrategias

EstrategiaFuenteCaso de Uso
XLSX Nativo (TWorkBook/TWorkSheet)fwxlsxlb.prgCreación de alto rendimiento, no requiere Excel, admite formato e imágenes
Automatización OLE (FWDrXLSX)drxl.prgModelo de objetos COM completo de Excel para formato heredado y funciones avanzadas
Lector XML (TXlsxReader)readxlsx.prgLectura de archivos .xlsx mediante análisis ZIP/XML, no requiere Excel

TWorkBook / TWorkSheet - Generación Nativa de XLSX

Las clases TWorkBook y TWorkSheet proporcionan una interfaz orientada a objetos para la librería C xlsxlibhb. Este es el método preferido para generar hojas de cálculo grandes rápidamente sin ninguna dependencia de Microsoft Excel.

TXlsxReader - Lectura Basada en XML

La clase TXlsxReader lee archivos .xlsx tratando el archivo como un fichero comprimido ZIP y analizando los componentes internos OpenXML. No se requiere ninguna instalación de Excel.

MétodoDescripción
New( cXlsx, cSheet )Abre un archivo .xlsx para su lectura. Opcionalmente especifica un nombre de hoja. Devuelve nil si el archivo no se encuentra o no es válido.
ReadData()Lee todos los datos en aData (array 2D). Detecta automáticamente los tipos (N, D, T, L, C, M) y calcula la estructura.
ShowData()Muestra la hoja de cálculo en un diálogo XBrowse con detección automática de tipos.
Range( cRange )Lee un rango específico (p. ej., "A1:C10") como un array 2D.
Cells( nRow, nCol )Lee una sola celda o un conjunto de columnas de una fila específica.
SaveAs( cSave )Guarda los datos cargados en un nuevo archivo .xlsx usando la librería XLSX nativa.
Close()Libera los recursos internos.

Automatización OLE (FWDrXLSX)

Para entornos donde Microsoft Excel está instalado, la clase FWDrXLSX envuelve el modelo de objetos COM de Excel. La clase se carga dinámicamente mediante HB_FuncPtr() para evitar dependencias rígidas.

Say( nRow, nCol, uValue, oFormat, cPicture )Escribe un valor en una celda. Acepta tanto coordenadas numéricas como referencias de celda (p. ej., "A1").
Format( cPicture, cStyles, nAlign )Crea un objeto de formato (FWDrXLSXFormat) para la hoja OLE.
SayRow( nRow, aValues, oFormat, aPicture )Escribe un array de valores en una fila.
SayHeader( nRow, aHead )Escribe una fila de encabezado con formato en negrita y borde inferior.
SetColSizes( aSizes )Establece los anchos de columna a partir de un array de estructura.
SetStruct( aStruct, nRow, aGroup )Define una tabla estructurada con encabezados y dimensionamiento de columnas.
SetArrayData( aData, aStruct, aGroup )Escribe un array 2D como una tabla con formato.
CreateFrom( uSrc )Importa datos desde el alias DBF actual o desde un conjunto de registros ADO.

Ejemplo: Crear un Libro y Escribir Celdas

#include "FiveWin.ch"

function Main()

   local oBook, oSheet, oFmt, nRow := 1

   // Crear un nuevo libro de trabajo
   oBook := TWorkBook():New( "c:\temp\example.xlsx" )

   if oBook == nil
      MsgStop( "Cannot create workbook" )
      return nil
   endif

   // Agregar una hoja de cálculo
   oSheet := oBook:AddSheet( "Employees" )

   // Crear un formato de encabezado en negrita
   oFmt := oBook:Format()
   oFmt:Bold():Align( 2, 10 ):SetBottom( 2 )

   // Escribir encabezados
   oSheet:Say( nRow, 0, "ID",   oFmt )
   oSheet:Say( nRow, 1, "Name",     oFmt )
   oSheet:Say( nRow, 2, "Hired",    oFmt )
   oSheet:Say( nRow, 3, "Salary",   oFmt )

   // Escribir filas de datos (autodetección de tipo: N, C, D, N)
   oSheet:Say( ++nRow, 0, 1001 )
   oSheet:Say( nRow, 1, "John Smith" )
   oSheet:Say( nRow, 2, STOD( "20240315" ) )
   oSheet:Say( nRow, 3, 75000.00 )

   oSheet:Say( ++nRow, 0, 1002 )
   oSheet:Say( nRow, 1, "Maria Garcia" )
   oSheet:Say( nRow, 2, STOD( "20240110" ) )
   oSheet:Say( nRow, 3, 82000.00 )

   // Inmovilizar la fila de encabezado
   oSheet:Freeze( 1, 0 )

   // Finalizar y guardar
   oBook:Close()

   // Mostrar el resultado
   FW_ShowXlsx( "c:\temp\example.xlsx" )

return nil

Ejemplo: Leer un Archivo XLSX

#include "FiveWin.ch"

function ReadXlsx()

   local oXlsx := FW_OpenXlsx( "c:\temp\example.xlsx" )

   if oXlsx == nil
      MsgStop( "Cannot open file" )
      return nil
   endif

   ? "Rows:", oXlsx:nRows, "Cols:", oXlsx:nCols
   ? "Header:", oXlsx:aHead[ 1 ], oXlsx:aHead[ 2 ], oXlsx:aHead[ 3 ]

   // Acceder a una celda específica
   MsgInfo( oXlsx:Cells( 2, 2 ), "Cell B2" )

   // Leer un rango
   XBROWSER oXlsx:Range( "A1:D3" ) TITLE "Range A1:D3"

   oXlsx:Close()

return nil

Notas

  • XLSX Nativo (TWorkBook) es el enfoque recomendado para crear hojas de cálculo. No tiene dependencias externas, admite archivos grandes y proporciona control total del formato a través de la clase TFormat.
  • Automatización OLE (FWDrXLSX) requiere que Microsoft Excel esté instalado en la máquina de destino. Es adecuada para código heredado o cuando se necesitan funciones específicas de Excel (macros, tablas dinámicas).
  • TXlsxReader detecta automáticamente los tipos de datos a partir de los metadatos XML de Excel, manejando cadenas (tabla de cadenas compartidas), números, fechas, fechas-hora, booleanos e imágenes.
  • Las funciones cTempXlsx() y cGetFileXlsx() gestionan el manejo de archivos temporales y la detección de conflictos (los archivos actualmente abiertos en Excel no pueden sobrescribirse).
  • Cuando tanto la librería nativa como la OLE están disponibles, UseXLSXLIB() y UseDrXlsx() controlan qué estrategia se prefiere. De forma predeterminada, se elige la librería nativa cuando Excel no está instalado.
  • Los valores de cadena en XLSX nativo se convierten automáticamente de ANSI a UTF-8 para una codificación correcta en el XML .xlsx. Los datos de memo binarios se detectan y se reemplazan por "<binary data>".

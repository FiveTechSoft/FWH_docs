TTxtFile - Fichero de Texto Orientado a Líneas

Fuente: source/classes/ttxtfile.prg

TTxtFile hereda de TFile y proporciona lectura y escritura de ficheros de texto orientados a líneas con soporte para secciones de estilo INI. Almacena el fichero completo en memoria y ofrece navegación basada en cursor (Advance, Rewind, Skip, GoTo), operaciones a nivel de línea (ReadLine, Add, AppendLn, DelLine, InsLine, RepLine) y acceso a claves/valores de secciones INI (GetValue, SetValue).

DATA Members

DATATipoDescripción
cLineCharacterContenido de la línea actual en la posición del cursor
nTLinesNumericNúmero total de líneas en el fichero
nLineNumericPosición de la línea actual (empezando en 1)

Métodos Principales

MétodoDescripción
Advance()Avanza a la línea siguiente. Devuelve .T. si tiene éxito, .F. si está en EOF
Rewind()Retrocede a la línea anterior. Devuelve .T. si tiene éxito, .F. si está en BOF
Skip( n )Mueve hacia adelante (positivo) o hacia atrás (negativo) n líneas
ReadLine()Devuelve el contenido de la línea actual como cadena
Add( c )Añade la línea c al final del fichero
AppendLn( c )Inserta la línea c después de la línea actual
DelLine()Elimina la línea actual
InsLine( c )Inserta la línea c antes de la línea actual
RepLine( c )Reemplaza la línea actual con c
GoTop()Mueve el cursor a la primera línea
GoBottom()Mueve el cursor a la última línea
GoTo( n )Mueve el cursor al número de línea absoluto n
GetValue( cSec, cKey, xDef )Devuelve el valor de una clave en una sección de estilo INI, o xDef si no existe
SetValue( cSec, cKey, xVal )Establece el valor de una clave en una sección de estilo INI (crea la sección/clave si es necesario)

Ejemplo: Lector de Fichero de Configuración

#include "FiveWin.ch"

function Main()

   local oTxt := TTxtFile():New( "config.ini", 2 )

   if oTxt:hFile != nil
      // Lee valores de secciones de estilo INI
      ? "Server:",  oTxt:GetValue( "Database", "Server",  "localhost" )
      ? "Port:",    oTxt:GetValue( "Database", "Port",    3306 )
      ? "User:",    oTxt:GetValue( "Database", "User",    "admin" )

      // Actualiza o añade un valor
      oTxt:SetValue( "Database", "LastAccess", DToC( Date() ) )

      // Navega por las líneas manualmente
      oTxt:GoTop()
      while ! oTxt:lEof()
         ? oTxt:ReadLine()
         oTxt:Advance()
      endwhile

      oTxt:Close()
   else
      ? "File not found"
   endif

return nil

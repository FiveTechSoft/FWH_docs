TBtnClr / TPickerColor

Fuente: source/classes/tbtnclr.prg

TBtnClr hereda de: TControl. TPickerColor es una clase auxiliar independiente.

TBtnClr es un control de botón selector de color que muestra una muestra del color seleccionado y, opcionalmente, un mapa de bits de flecha desplegable. Al hacer clic en el botón se dispara una acción (normalmente mostrar el diálogo TPickerColor). TPickerColor proporciona un diálogo de selección de color con tema visual que incluye una cuadrícula de colores estándar, una fila de colores base/tema y una opción "Más colores" que utiliza el diálogo ChooseColor del sistema.

TPickerColor

MétodoDescripción

La función libre ChooseColor( nInitClr ) abre el selector de color estándar de Windows y devuelve el color RGB seleccionado.

Ejemplo: Botón de Color

#include "FiveWin.ch"

function Main()

   local oWnd, oBtnClr, nColor := CLR_RED

   DEFINE WINDOW oWnd TITLE "Color Picker Demo" SIZE 300, 150

   @ 30, 30 BTNBMP oBtnClr PROMPT "Color" ;
      SIZE 40, 25 OF oWnd ;
      ACTION ( nColor := ChooseColor( nColor ), ;
               oBtnClr:SetColor( nColor ), ;
               oBtnClr:Refresh() )

   @ 80, 30 SAY "Selected color shown on button" OF oWnd SIZE 200, 20

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TBtnClr admite los temas de Windows mediante C5_DrawThemeBackground con estados de hover y presionado.
  • La muestra de color se dibuja como un rectángulo relleno dentro del botón utilizando nColorSel.
  • nTypeClr controla la posición de la muestra: 1 rellena toda la cara del botón, 2 deja espacio para la flecha emergente.
  • TPickerColor muestra una cuadrícula de 6x10 colores estándar más una fila de 10 colores de tema/base. El botón "Más colores" invoca el diálogo ChooseColor del sistema.

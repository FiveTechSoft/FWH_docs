TComObject

Fuente: source/classes/tcomobj.prg

Clase independiente

TComObject proporciona un envoltorio genérico alrededor de los objetos COM (Component Object Model) de Windows a través de la interfaz IDispatch. Almacena el puntero nIDispatch y expone métodos para invocar métodos COM, obtener/establecer propiedades y envolver automáticamente los punteros IDispatch devueltos. La clase admite llamadas COM encadenadas mediante su manejador de errores: los nombres de propiedades con el prefijo _ establecen valores, los nombres de propiedades sin prefijo obtienen valores, y los valores IDispatch devueltos se envuelven automáticamente en nuevas instancias de TComObject.

Miembros DATA Principales

DATATipoDescripción
nIDispatchNuméricoPuntero a la interfaz COM IDispatch

Métodos Principales

MétodoDescripción
New( cProgID )Crea un objeto COM a partir de una cadena ProgID (p. ej. "Word.Application")
Invoke( cMethod, u1, u2, u3 )Invoca un método COM con hasta tres parámetros opcionales
End()Libera el objeto COM y libera el puntero IDispatch
ClassName()Devuelve el nombre de clase de Harbour ("TComObject")

Ejemplo: Automatización de Word

#include "FiveWin.ch"

function Main()

   local oWord, oDoc

   // Crear objeto COM de Word Application
   oWord := TComObject():New( "Word.Application" )

   // Establecer propiedad (con prefijo _)
   oWord:_Visible := .T.

   // Acceder a la colección de documentos (devuelve un TComObject autoenvuelto)
   oDoc := oWord:Documents

   // Agregar un nuevo documento
   oDoc:Add()

   // Invocar métodos
   oWord:Invoke( "Activate" )

   // Establecer contenido
   oWord:Selection:TypeText( "Hello from FiveWin!" )

   MsgInfo( "Word is running. Press OK to close." )

   // Limpieza
   oWord:Quit()
   oWord:End()

return nil

Notas

  • El manejador de errores (Error()) es el núcleo de la comodidad de TComObject. Cuando accede a una propiedad sin el prefijo de subrayado, llama a IDispatch::GetIDsOfNames e Invoke con DISPATCH_PROPERTYGET. Si el valor devuelto es otro puntero IDispatch, se envuelve automáticamente en un nuevo TComObject, lo que permite la navegación encadenada como oWord:Selection:Text.
  • Establecer una propiedad requiere el prefijo de subrayado (p. ej. oWord:_Visible := .T.), lo que desencadena DISPATCH_PROPERTYPUT.
  • Use Invoke() para métodos que necesitan un control explícito sobre los parámetros, o cuando el comportamiento de autoenvoltura no se aplica.
  • Llame siempre a End() para liberar el puntero de la interfaz COM y evitar fugas de recursos.
  • Requiere el subsistema COM de Windows (OLE32.dll). Funciona en todas las plataformas Windows de 32 y 64 bits.

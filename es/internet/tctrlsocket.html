TCtrlSocket

Fuente: source/classes/tctrsock.prg

Clase independiente

TCtrlSocket implementa un servidor de sockets multiplexado que gestiona múltiples conexiones de clientes a través de una cola de peticiones. En lugar de dedicar un hilo por cliente, mantiene un array de peticiones pendientes (aRequests) y las atiende en secuencia. Cada entrada de petición almacena el objeto socket y bloques de callback opcionales para el fin de la conexión (abEnd) y la oportunidad de procesamiento (abChance). La clase lleva el conteo de bytes enviados (anSended) y el estado de ejecución del servidor (lServerWorking).

Miembros DATA Principales

DATATipoDescripción
aRequestsArrayArray de objetos de petición pendiente (socket + callbacks)
abEndArrayArray de codeblocks evaluados cuando cada conexión de petición termina
abChanceArrayArray de codeblocks evaluados cuando cada petición recibe tiempo de procesamiento
anSendedArrayArray de conteos de bytes enviados por cada petición
lServerWorkingLógico.T. cuando el servidor está sirviendo peticiones activamente

Métodos Principales

MétodoDescripción
New()Crea un nuevo controlador de sockets multiplexado
AddRequest( oSocket, bEnd, bChance )Pone en cola un socket con callbacks opcionales de fin y oportunidad
ServeClients()Procesa todas las peticiones pendientes en modo round-robin

Ejemplo: Servidor Multiplexado de 2 Sockets

#include "FiveWin.ch"

function Main()

   local oCtrl, oSocket1, oSocket2

   // Create the multiplexed socket controller
   oCtrl := TCtrlSocket():New()

   // Create two client sockets
   oSocket1 := TSocket():New()
   oSocket2 := TSocket():New()

   // Add requests with callbacks
   oCtrl:AddRequest( oSocket1, ;
      { || QOut( "Socket 1 ended" ) }, ;
      { || QOut( "Socket 1 processing" ) } )

   oCtrl:AddRequest( oSocket2, ;
      { || QOut( "Socket 2 ended" ) }, ;
      { || QOut( "Socket 2 processing" ) } )

   // Serve clients in a loop
   do while oCtrl:lServerWorking
      oCtrl:ServeClients()
      // Yield to Windows message queue
      SysRefresh()
   enddo

return nil

Notas

  • TCtrlSocket está diseñado para multitarea cooperativa dentro de un solo hilo. Llame a ServeClients() periódicamente para dar a cada socket en cola la oportunidad de leer/escribir datos.
  • Use el callback abChance para manejar el procesamiento de datos de cada socket. Este callback recibe el objeto socket y puede llamar a Recv()/Send() para comunicarse.
  • El callback abEnd se dispara cuando una conexión termina, permitiendo la limpieza de recursos por socket.
  • anSended rastrea los bytes acumulados enviados por petición, útil para monitoreo de progreso.

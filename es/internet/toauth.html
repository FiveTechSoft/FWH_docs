Correo OAuth2: TOAuth, TGmail, TOutlookMail

Fuentes: source/classes/oauth.prg, source/classes/gmail.prg, source/classes/outlookmail.prg

FiveWin proporciona soporte de correo electrónico OAuth2 para Gmail (TGmail) y Outlook/Office 365 (TOutlookMail) a través de una jerarquía de clases común. TOAuth maneja la autenticación, la gestión de tokens y la construcción de mensajes MIME. TGmail implementa la API REST de Gmail, TOutlookMail usa Microsoft Graph. Toda la comunicación de red usa libcurl; el inicio de sesión interactivo usa TWebView2.

Flujo de Autenticación OAuth2

sequenceDiagram participant App as "App FWH" participant WV as "TWebView2" participant Srv as "THttpServer" participant Cloud as "API del Proveedor" App->>Srv: Iniciar en puerto local App->>WV: Navegar a URL de auth WV->>Cloud: El usuario concede permiso Cloud-->>WV: Redirigir a localhost/?code=XYZ WV->>Srv: HTTP GET con código auth Srv-->>App: Devolver código capturado App->>WV: Cerrar ventana del navegador App->>Cloud: POST /token (code + client_secret) Cloud-->>App: JSON {access_token, refresh_token} Note over App: Almacenar refresh_token localmente App->>Cloud: Enviar correo vía API REST

TOAuth: Clase Base

TOAuth proporciona el flujo de trabajo OAuth2 principal y la construcción multiparte MIME. Gestiona las credenciales del cliente, el servidor HTTP local para la captura de redirección y el ciclo de vida del token incluyendo la actualización automática.

TGmail: API de Google Gmail

MétodoDescripción
New(cClientId,cClientSecret,cUser)Crea una instancia de TGmail para el usuario especificado. Activa el flujo de autenticación OAuth2 si no hay token en caché.
Send(cTo,cSubj,cBody,aAttach)Envía un correo electrónico vía el endpoint de la API de Gmail. aAttach es un array de rutas de archivos.
GetToken()Obtiene un token de acceso nuevo, verificando primero la validez vía el endpoint tokeninfo.
RefreshToken()Forza la actualización del token de acceso desde el token de actualización almacenado.

TGmail envía vía https://gmail.googleapis.com/gmail/v1/users/me/messages/send?uploadType=multipart y requiere un ID de cliente de "Aplicación Web" de Google Cloud Console con URI de redirección configurada a http://localhost:2025.

TOutlookMail: API de Microsoft Graph

MétodoDescripción
New(cClientId,cTenantId,cUser)Crea una instancia de TOutlookMail. cTenantId identifica el inquilino de Azure AD.
Send(cTo,cSubj,cBody,aAttach)Envía correo vía el endpoint de Microsoft Graph /users/{user}/sendMail. Soporta cuerpo HTML y adjuntos.
me()Recupera el perfil del usuario autenticado desde https://graph.microsoft.com/v1.0/me

Ámbitos OAuth2 requeridos: Mail.Send, offline_access, openid, profile, SMTP.Send, User.Read. Microsoft puede rotar los tokens de actualización; la clase detecta nuevos tokens de actualización en las respuestas y actualiza el almacén local automáticamente.

Ejemplo: Envío Gmail OAuth2

#include "FiveWin.ch"

function Main()

   local oGmail := TGmail():New( ;
      "your-client-id.apps.googleusercontent.com", ;
      "your-client-secret", ;
      "user@gmail.com" )

   // The OAuth2 browser window opens automatically
   // if no cached token is found

   if ! Empty( oGmail:cAccessToken )
      oGmail:Send( "recipient@example.com", ;
                   "Test from FWH", ;
                   "<h1>Hello!</h1><p>Sent via Gmail API.</p>", ;
                   { "C:\docs\invoice.pdf" } )
      MsgInfo( "Email sent successfully!" )
   else
      MsgStop( "Authentication failed" )
   endif

return nil

Notas

  • Requiere libcurl.dll, libssl-3-x64.dll, zlib1.dll para compilaciones de 64 bits; el runtime de TWebView2 debe estar instalado.
  • Los tokens se almacenan en caché local; la rotación del token de actualización asegura acceso de larga duración sin solicitudes de inicio de sesión repetidas.
  • El THttpServer local escucha en el puerto 2025 (por defecto) para capturar la redirección con el código de autorización.
  • Los mensajes MIME usan delimitadores adecuados, cabeceras Content-Type y codificación base64 de adjuntos según RFC 2822.

TGemini (Google Gemini)

Fuente: source/classes/tgemini.prg

TGemini es el cliente de FiveWin para la API de Google Gemini. Proporciona acceso a la familia de modelos Gemini de Google con soporte para chat de texto, respuestas en streaming, análisis de imágenes y archivos (PNG, JPEG, PDF, TXT, CSV, PRG) y subida de archivos al servicio de archivos de Google. La clase utiliza la biblioteca hb_curl de Harbour para la comunicación HTTPS. Las claves de API pueden pasarse explícitamente o leerse de la variable de entorno GEMINI_API_KEY.

Métodos

MétodoDescripción
New( cKey, cModel )Crea una instancia de TGemini. Lee GEMINI_API_KEY del entorno si cKey está vacío. Inicializa el handle de libcurl.
Send( uContent, [cPrompt], [bCallback] )Método principal que acepta entrada flexible. uContent puede ser una cadena de texto, una ruta de archivo o un array de rutas de archivo. cPrompt proporciona texto opcional junto a los archivos. bCallback habilita el streaming mediante codeblock. Devuelve JSON sin procesar.
GetValue()Extrae el texto de la respuesta del JSON de cResponse. Navega por la ruta candidates[1].content.parts[1].text. Devuelve información de error en caso de fallo.
GetTokens( cBuffer )Analiza un fragmento de respuesta en streaming y extrae el token de texto. Maneja fragmentos JSON tanto en estilo array como en estilo objeto.
UploadFile( cFileName, lDeleteAfter )Sube un archivo a la API de archivos de Google. Devuelve la cadena URI del archivo. Opcionalmente elimina cFileName cuando lDeleteAfter es .T..
End()Libera el handle de libcurl. Se llama automáticamente desde el destructor.

Ejemplo: Chat de Texto

#include "FiveWin.ch"

function Main()

   local oAI := TGemini():New( "your-gemini-api-key" )

   oAI:Send( "What are the key features of the Harbour language?" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      MsgInfo( oAI:GetValue() )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Ejemplo: Análisis de Imagen / Archivo

#include "FiveWin.ch"

function Main()

   local oAI := TGemini():New( "your-gemini-api-key" )

   // Imagen única
   oAI:Send( "C:\photos\chart.png", "Describe this chart." )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   // Análisis de múltiples archivos
   oAI:Send( { "C:\docs\invoice.pdf", "C:\docs\photo.jpg" }, ;
      "Compare and summarize." )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Ejemplo: Respuesta en Streaming

#include "FiveWin.ch"

function Main()

   local oAI := TGemini():New( "your-gemini-api-key" )
   local cFull := ""

   // Pasar un codeblock como tercer parámetro para activar el streaming
   oAI:Send( "Write a short story about AI.", , ;
      { |cChunk| cFull += cChunk, QOut( cChunk ) } )

   if oAI:nError == 0
      MsgInfo( "Complete:" + CRLF + cFull )
   endif

   oAI:End()

return nil

Notas

  • Requiere la biblioteca hb_curl. Incluye #include "hbcurl.ch" para las constantes de curl.
  • La verificación SSL está desactivada por defecto (HB_CURLOPT_SSL_VERIFYPEER = .F.).
  • Send() detecta automáticamente los archivos por su extensión y los codifica en base64 para su envío en línea. Tipos soportados: PNG, JPEG, PDF, TXT, CSV, PRG, CH.
  • El streaming se habilita pasando un codeblock como tercer parámetro a Send(). El endpoint cambia de :generateContent a :streamGenerateContent.
  • UploadFile() utiliza el servicio dedicado de subida de archivos de Google y devuelve un URI para su posterior referencia en conversaciones de múltiples turnos.

TRas

Fuente: source/classes/tras.prg

TRas es la clase de Servicio de Acceso Remoto (RAS) de FiveWin para gestionar conexiones de acceso telefónico en Windows. Envuelve la API RAS de Windows para iniciar conexiones telefónicas, monitorear el estado de la conexión y colgar. TRas admite modos de conexión tanto manual como automático (bloqueante) con protecciones basadas en tiempo de espera.

Métodos

MétodoDescripción
New( oWnd, cPhone, cUser, cPass )Crear una instancia RAS. Requiere un manejador de ventana válido, número de teléfono, nombre de usuario y contraseña. Valida todos los parámetros en la construcción.
Call( lMode, bStatus )Iniciar la conexión de acceso telefónico. Si lMode es .T. (espera automática), bloquea hasta conectar o agotar tiempo de espera. Opcionalmente establece el callback bStatus.
Status()Consultar el estado actual de la conexión y actualizar todos los miembros DATA de estado. Invoca el callback bStatus si está configurado.
HangUp()Terminar la conexión RAS. Llama a RaHangUp() con el manejador almacenado.

Ejemplo: Acceso Telefónico con Espera Automática

#include "FiveWin.ch"

function Main()

   local oWnd, oRas

   DEFINE WINDOW oWnd TITLE "RAS Dial-up"

   oRas := TRas():New( oWnd, "555-1234", "myuser", "mypass" )

   if oRas:lOperation
      // Auto-wait mode: blocks until connected (or timeout)
      if oRas:Call( .T. )
         MsgInfo( "Connected! Status: " + oRas:cStatus )
         // ... use the connection ...
         oRas:HangUp()
      else
         MsgStop( "Connection failed: " + oRas:cError )
      endif
   else
      MsgStop( "RAS initialization failed" )
   endif

return nil

Notas

  • TRas requiere un manejador de ventana o diálogo válido de FiveWin (oWnd:hWnd) para que la API RAS publique notificaciones de estado de conexión.
  • En modo de espera automática (Call( .T. )), el método consulta el estado de la conexión en un bucle hasta que se conecta, el tiempo de espera expira o lPanic se establece a .T..
  • El bloque de código callback bStatus se invoca en cada cambio de estado, permitiendo actualizaciones de UI durante el proceso de conexión.
  • Siempre verifique lOperation después de la construcción y Call() para confirmar el éxito.

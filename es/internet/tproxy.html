TProxy

Fuente: source/classes/tproxy.prg

TProxy es el servidor proxy TCP multiprotocolo de FiveWin. Escucha en un puerto local, acepta conexiones entrantes y reenvía el tráfico a un servidor backend remoto. El proxy funciona de forma transparente para cualquier protocolo basado en TCP (HTTP, POP3, SMTP, FTP, etc.) creando conexiones de socket emparejadas entre el cliente y el servidor backend y retransmitiendo datos bidireccionalmente.

Métodos

MétodoDescripción
New( nPort, cServerIP )Crear una instancia de proxy. Crea el TSocket de escucha y configura el callback de aceptación. Valor predeterminado: puerto 110 (POP3). Resuelve nombres de host a IPs automáticamente.
Activate()Comenzar a escuchar conexiones entrantes. Delega en oSocket:Listen().
End()Detener el proxy y liberar el socket de escucha. Delega en oSocket:End().
OnAccept()Interno: Se llama cuando un nuevo cliente se conecta. Crea un socket de cliente emparejado y un socket backend, configura la retransmisión bidireccional con callbacks de lectura/cierre.
OnRead( oSocket, oServer )Interno: Se llama cuando llegan datos del cliente. Reenvía los datos al servidor backend.

Ejemplo: Proxy POP3

#include "FiveWin.ch"

function Main()

   local oProxy, oWnd

   DEFINE WINDOW oWnd TITLE "POP3 Proxy - Port 8080"

   // Proxy on port 8080, forwarding to the mail server
   oProxy := TProxy():New( 8080, "mail.example.com" )
   oProxy:lDebug := .T.
   oProxy:Activate()

   ACTIVATE WINDOW oWnd VALID ( oProxy:End(), .T. )

return nil

Cuando un cliente se conecta al puerto 8080, TProxy crea una conexión backend a mail.example.com:8080 (mismo puerto) y retransmite todos los datos bidireccionalmente. Con lDebug := .T., todo el tráfico se registra en proxy.log.

Notas

  • TProxy es independiente del protocolo: funciona con cualquier protocolo basado en TCP ya que simplemente retransmite bytes en bruto entre cliente y servidor.
  • El método New() acepta nombres de host y los resuelve a IPs usando GetHostByName().
  • Cada conexión entrante crea dos objetos TSocket: uno para el cliente y otro para el backend. Ambos se limpian cuando la conexión se cierra.
  • Establecer lDebug := .T. registra todos los datos del cliente y del servidor en el archivo especificado por cLogFile.
  • El puerto del proxy predeterminado es 110 (POP3) si no se especifica.

TFtpServer

Fuente: source/classes/tftpserv.prg

Clase independiente

TFtpServer implementa un servidor FTP básico usando TSocket. Escucha en el puerto 21 y maneja comandos FTP estándar (USER, PASS, STOR, RETR, LIST, CWD, PWD, QUIT). Soporta acceso anónimo y sirve archivos desde un directorio raíz configurable.

Miembros DATA Principales

DATATipoDescripción
oSocketObjetoTSocket de escucha principal
cRootDirCarácterDirectorio FTP por defecto (por defecto "ftp")
nPortNuméricoPuerto de escucha (por defecto 21)
lDebugLógicoHabilita registro de depuración en cLogFile

Métodos Principales

MétodoDescripción
New( nPort )Crea el servidor; crea el directorio raíz si no existe
Activate()Inicia la escucha de clientes
End()Detiene el servidor
OnAccept()Maneja nuevas conexiones de clientes
OnRead( oSocket )Procesa comandos FTP de un cliente

TFTP

Fuente: source/classes/tftp.prg

Cliente FTP vía WinINet. Soporta listado de directorios, eliminación de archivos, renombrado y gestión de directorios.

MétodoDescripción
New( cFTPSite, oInternet, cUser, cPass )Conecta a un sitio FTP
Directory( cMask )Devuelve un array de registros de archivos remotos
DeleteFile( cFile )Elimina un archivo remoto
RenameFile( cOld, cNew )Renombra un archivo remoto

TFTPFile

Fuente: source/classes/tftpfile.prg

Gestiona transferencias individuales de archivos remotos. Soporta modos ASCII y binario.

MétodoDescripción
New( cFileName, oFTP )Crea un objeto de archivo
OpenRead() / OpenWrite()Abre para lectura o escritura
Read( nBytes ) / Write( cData )Lee o escribe datos
Seek( nBytes, nFrom )Posiciona en una ubicación
End()Cierra el manejador del archivo

Ejemplo: Iniciar Servidor FTP

#include "FiveWin.ch"
function Main()
   local oServer
   oServer := TFtpServer():New( 21 )
   oServer:cRootDir = "c:\ftproot"
   oServer:lDebug   = .T.
   oServer:Activate()
return nil

Notas

  • TFtpServer solo soporta inicio de sesión anónimo; no se exige autenticación con contraseña.
  • Comandos manejados: NOOP, USER, PASS, QUIT, CWD, CDUP, PWD, PORT, TYPE, RETR, STOR, LIST, SYST.
  • El cliente TFTP usa WinINet, requiriendo componentes de Internet Explorer.
  • TFTPFile soporta modos de transferencia binario (lBinary := .T.) y ASCII.

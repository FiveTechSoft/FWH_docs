TNeuralNetwork

Fuente: source/classes/tneuralnet.prg

TNeuralNetwork es la red neuronal feedforward de FiveWin implementada en Harbour puro. Proporciona un perceptrón multicapa (MLP) con entrenamiento por retropropagación. La red consta de tres tipos de capas: una capa de entrada, una o más capas ocultas y una capa de salida. Cada neurona usa la función de activación sigmoide. La clase es ideal para tareas simples de reconocimiento de patrones como el problema XOR.

Métodos

MétodoDescripción
New( nInputs, aHiddenLayers, nOutputs )Crear una red neuronal con nInputs neuronas de entrada, un array de tamaños de capas ocultas (ej., { 4, 3 } para dos capas ocultas) y nOutputs neuronas de salida.
Learn( aInputs, aOutputs, lDebug )Entrenar la red en una muestra: ejecuta propagación hacia adelante, luego retropropagación para ajustar pesos y sesgos.
Propagation( aInputs )Ejecutar propagación hacia adelante: calcular valores de activación desde la entrada a través de las capas ocultas hasta la salida. Usa la función de activación sigmoide.
BackPropagation( aInputs, aOutputs )Ejecutar propagación hacia atrás: calcular gradientes de error y actualizar todos los pesos y sesgos según la tasa de aprendizaje.

Ejemplo: Entrenamiento XOR

#include "FiveWin.ch"

function Main()

   local oNN, n

   // Network: 2 inputs, hidden layer with 2 neurons, 1 output
   oNN := TNeuralNetwork():New( 2, { 2 }, 1 )

   // Train for 10000 iterations
   for n = 1 to 10000
      oNN:Learn( { 0, 0 }, { 0 } )
      oNN:Learn( { 1, 0 }, { 1 } )
      oNN:Learn( { 0, 1 }, { 1 } )
      oNN:Learn( { 1, 1 }, { 0 } )
   next

   // Test the trained network
   ? "XOR Truth Table:"
   ? "0 XOR 0 =", oNN:Propagation( { 0, 0 } )[ 1 ]  // ~0.0
   ? "1 XOR 0 =", oNN:Propagation( { 1, 0 } )[ 1 ]  // ~1.0
   ? "0 XOR 1 =", oNN:Propagation( { 0, 1 } )[ 1 ]  // ~1.0
   ? "1 XOR 1 =", oNN:Propagation( { 1, 1 } )[ 1 ]  // ~0.0

return nil

Ejemplo: Entrenamiento con Salida de Depuración

#include "FiveWin.ch"

function Main()

   local oNN := TNeuralNetwork():New( 2, { 4 }, 1 )

   // Debug mode prints inputs, outputs, expected values, and errors
   oNN:Learn( { 1, 0 }, { 1 }, .T. )

return nil

Notas

  • Los pesos y sesgos se inicializan con valores aleatorios usando hb_Random().
  • La función de activación sigmoide mapea valores al rango (0, 1). La derivada se usa durante la retropropagación para el cálculo del gradiente.
  • nLearningRate controla cuánto cambian los pesos durante cada actualización. Valores más bajos (ej., 0.01 - 0.1) proporcionan entrenamiento más estable, mientras que valores más altos pueden converger más rápido pero riskan oscilación.
  • Se pueden crear múltiples capas ocultas pasando un array con varios valores: { 4, 3 } crea dos capas ocultas con 4 y 3 neuronas respectivamente.
  • Esta es una implementación en Harbour puro sin dependencias externas. La función Math_E() se implementa a través de la API de extensión C de Harbour.
  • Para capacidades de red neuronal más avanzadas, consulte la clase Transformer en source/classes/transformer.prg.

TSocket

Fuente: source/classes/tsocket.prg

TSocket es la clase de socket TCP/IP de bajo nivel de FiveWin, envolviendo la API Winsock de Windows. Proporciona funcionalidad de socket tanto cliente como servidor a través de un modelo asíncrono orientado a eventos que se integra de forma natural con el bucle de mensajes de FiveWin. TSocket es la base para TWebServer, TSmtp, TPop3, TFtpClient y TWebClient.

Métodos

MétodoDescripción
New( nPort, oWnd, cIp )Crear un socket y vincularlo a un puerto. Llama a WSAStartup en el primer socket. Se registra con oWnd para eventos asíncronos.
Listen()Comenzar a escuchar conexiones entrantes en el puerto vinculado
Accept( nSocket, oWnd )Aceptar una conexión entrante. Devuelve un nuevo TSocket para la sesión del cliente.
Connect( cIPAddr, nPort )Conectarse a un servidor remoto como cliente
GetData()Leer datos disponibles del socket. Devuelve una cadena de caracteres.
SendData( cData )Enviar datos de caracteres. Almacena datos en buffer si hay un envío previo en progreso.
SendFile( cFileName, nBlockSize )Enviar un archivo en bloques. El tamaño de bloque predeterminado es 30,000 bytes.
SendChunk( nBlockSize )Enviar el siguiente bloque desde un handle de archivo abierto (usado internamente por SendFile)
ClientIP()Obtener la dirección IP del par remoto conectado
Refresh()Forzar al socket a re-registrarse para eventos asíncronos
Close()Cerrar el handle del socket. Espera a que los envíos pendientes se completen.
End()Cerrar el socket y eliminarlo de la lista de sockets a nivel de clase. Llama a WSACleanup cuando es el último socket.

Callbacks de Evento

TSocket usa WSAAsyncSelect para registrarse en eventos de socket de Windows. Cuando ocurre un evento, el bucle de mensajes de FiveWin lo enruta a HandleEvent(), que lo despacha al método callback apropiado. Asigne el bloque de código correspondiente para manejar el evento:

CodeblockEventoMétodo Callback
bAcceptConexión entranteOnAccept()
bReadDatos disponiblesOnRead()
bWriteListo para enviarOnWrite()
bCloseRemoto cerróOnClose()
bConnectResultado de conexiónOnConnect( nErrorCode )
bOOBDatos OOBOnOOB()

Ejemplo: Cliente TCP

#include "FiveWin.ch"

function Main()

   local oWnd, oSocket, cResponse := ""

   DEFINE WINDOW oWnd TITLE "TCP Client"

   oSocket := TSocket():New( 0, oWnd )

   oSocket:bRead := { |oSock|
      cResponse += oSock:GetData()
      oWnd:SetText( "Received: " + cResponse )
   }

   oSocket:bClose := { |oSock|
      MsgInfo( "Connection closed" )
      oSock:End()
   }

   // Connect to a remote server
   oSocket:Connect( "93.184.216.34", 80 )

   // Send HTTP request
   oSocket:SendData( "GET / HTTP/1.1" + CRLF + ;
                     "Host: example.com" + CRLF + ;
                     "Connection: close" + CRLF + CRLF )

   ACTIVATE WINDOW oWnd ;
      ON INIT SysRefresh() ;
      VALID ( oSocket:End(), .T. )

return nil

Ejemplo: Servidor de Chat

#include "FiveWin.ch"

static aClients := {}

function Main()

   local oWnd, oSocket

   DEFINE WINDOW oWnd TITLE "Chat Server - Port 9000"

   oSocket := TSocket():New( 9000, oWnd )
   oSocket:Listen()

   oSocket:bAccept := { ||
      local oClient := TSocket():Accept( oSocket:nSocket, oWnd )
      AAdd( aClients, oClient )

      oClient:bRead := { |oSock|
         local cMsg := oSock:GetData()
         AEval( aClients, { |o| o:SendData( cMsg ) } )
      }

      oClient:bClose := { |oSock|
         local nAt := AScan( aClients, ;
            { |o| o:nSocket == oSock:nSocket } )
         if nAt > 0
            ADel( aClients, nAt, .T. )
         endif
         oSock:End()
      }
   }

   ACTIVATE WINDOW oWnd VALID ( oSocket:End(), .T. )

return nil

Notas

  • TSocket requiere una ventana (o diálogo) de FiveWin para su modelo de eventos asíncronos. El bucle de mensajes de la ventana despacha eventos Winsock a través de WSAAsyncSelect.
  • El array aSockets a nivel de clase rastrea todos los sockets activos. HandleEvent() busca en este array por handle de socket para despachar eventos al objeto correcto.
  • WSAStartup() se llama cuando se crea el primer TSocket. WSACleanup() se llama cuando se destruye el último socket.
  • El método SendData() maneja envíos parciales y almacena datos en buffer automáticamente. Los envíos grandes se dividen transparentemente en múltiples segmentos TCP.
  • Use ShowIP() (una función de utilidad en tsocket.prg) para obtener rápidamente la dirección IP de la máquina local.

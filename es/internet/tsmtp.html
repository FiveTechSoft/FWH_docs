TSmtp

Fuente: source/classes/tsmtp.prg

TSmtp es la clase de envío de correo electrónico de FiveWin. Implementa el protocolo SMTP para enviar mensajes a través de un servidor de correo, con soporte para autenticación (AUTH LOGIN), contenido HTML, archivos adjuntos, destinatarios CC/BCC y acuses de recibo. Está construida sobre TSocket y utiliza el modelo de eventos asíncronos para la comunicación.

Métodos

MétodoDescripción
New( cIPServer, nPort, lAuth, cUser, cPassword )Crear una nueva sesión SMTP. nPort predeterminado es 25. Resuelve el nombre del servidor a IP si es necesario.
SendMail( cFrom, aTo, cMsg, cSubject, aFiles, aCC, aBCC, lReceipt, cHTML )Redactar y enviar un correo electrónico. Todos los parámetros después de aTo son opcionales.
End()Cerrar el socket subyacente y limpiar
Priority()Devuelve la prioridad numérica: 1=High, 3=Normal, 5=Low

Ejemplo: Enviar un Correo Simple

#include "FiveWin.ch"

function Main()

   local oSmtp

   oSmtp := TSmtp():New( "mail.example.com" )

   oSmtp:SendMail( "sender@example.com", ;
                   { "recipient@example.com" }, ;
                   "Hello, this is a test message.", ;
                   "Test Subject" )

return nil

Ejemplo: SMTP Autenticado con Adjunto

#include "FiveWin.ch"

function Main()

   local oSmtp

   // Gmail SMTP with authentication
   oSmtp := TSmtp():New( "smtp.gmail.com", 587, .T., ;
                         "user@gmail.com", "password" )

   oSmtp:bConnecting := { || MsgInfo( "Connecting to SMTP server..." ) }
   oSmtp:bDone       := { || MsgInfo( "Email sent successfully!" ) }
   oSmtp:bFailure    := { |o,n,c| MsgStop( "Error: " + oSmtp:cError ) }

   oSmtp:SendMail( "user@gmail.com", ;
                   { "recipient@example.com" }, ;
                   "Please find the attached report.", ;
                   "Monthly Report", ;
                   { "C:\reports\report.pdf" } )

return nil

Ejemplo: Correo HTML con CC

#include "FiveWin.ch"

function Main()

   local oSmtp, cHtml

   TEXT INTO cHtml
   <html>
   <body style="font-family: Arial; color: #333;">
      <h1>Welcome!</h1>
      <p>This is an <b>HTML email</b> sent from FiveWin.</p>
      <hr>
      <p>Regards,<br>The FiveWin Team</p>
   </body>
   </html>
   ENDTEXT

   oSmtp := TSmtp():New( "mail.example.com" )

   oSmtp:SendMail( "sender@example.com", ;
                   { "alice@example.com" }, ;
                   "Plain text fallback message.", ;
                   "HTML Email Test", , ;
                   { "bob@example.com" }, ;   // CC
                   .F., cHtml )

return nil

Notas

  • TSmtp soporta el método de autenticación AUTH LOGIN. Para servidores que requieran PLAIN o MD5, se necesita implementación adicional.
  • El nombre del servidor (cIPServer) puede ser un nombre amigable (ej. "smtp.gmail.com") o una dirección IP. TSmtp lo resuelve automáticamente.
  • Los archivos adjuntos se codifican como base64 para archivos binarios o quoted-printable para archivos de texto. Los nombres de archivo conservan su mayúsculas/minúsculas original.
  • Los correos HTML incluyen una estructura multipart/alternative: se envía un texto plano de respaldo junto con el contenido HTML.
  • Si el servidor agota el tiempo de espera después de enviar archivos adjuntos grandes, incremente el DATA miembro nDelay en uno para añadir demora entre envíos.

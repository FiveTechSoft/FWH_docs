TOpenAI / TChatGPT

Fuente: source/classes/topenai.prg (TOpenAI), source/classes/chatgpt.prg (TChatGPT)

FiveWin proporciona dos clases para integración con la API de OpenAI: TOpenAI (completa, con visión, streaming y soporte de imágenes) y TChatGPT (envoltorio más simple para completaciones de chat básicas). Ambas usan la biblioteca hb_curl de Harbour para comunicación HTTPS.

Miembros DATA

Métodos

MétodoDescripción

SendStream( cPrompt, bCallback )Enviar prompt con streaming; bCallback recibe fragmentos

End()Limpiar el handle de curl

Clase TChatGPT

TChatGPT es una alternativa más simple con menos funciones, adecuada para interacciones básicas de prompt/respuesta.

Miembros DATA

DATATipoPor DefectoDescripción

cUrlCharacter"https://api.openai.com/v1/chat/completions"Endpoint de la API

Métodos

MétodoDescripción
New( cKey )Crear instancia con clave API
Send()Enviar cPrompt, almacenar respuesta en cResponse
GetValue( cKey1, cKey2, ... )Navegar la respuesta JSON por ruta de claves. Argumentos variables.
Reset()Reiniciar estado de curl para la siguiente solicitud
End()Limpiar el handle de curl

Ejemplo: Prompt/Respuesta Básico (TOpenAI)

#include "FiveWin.ch"

function Main()

   local oAI, cAnswer

   // Clave API desde la variable de entorno OPENAI_API_KEY
   oAI := TOpenAI():New()

   // O con clave y modelo explícitos:
   // oAI := TOpenAI():New( "sk-...", "gpt-4o" )

   oAI:Send( "What is the capital of France? Answer in one word." )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      cAnswer := oAI:GetValue()
      MsgInfo( cAnswer )   // "Paris"
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Ejemplo: Respuesta en Streaming

#include "FiveWin.ch"

function Main()

   local oAI, cBuffer := ""

   oAI := TOpenAI():New()
   oAI:cModel := "gpt-4o"

   // El callback de streaming recibe fragmentos de datos a medida que llegan
   oAI:SendStream( "Write a short poem about coding.", ;
      { |cChunk| cBuffer += cChunk, QOut( cChunk ) } )

   if oAI:nError == 0
      MsgInfo( "Respuesta completa:" + CRLF + cBuffer )
   endif

   oAI:End()

return nil

Ejemplo: Visión (Analizar una Imagen)

#include "FiveWin.ch"

function Main()

   local oAI

   oAI := TOpenAI():New( , "gpt-4o" )

   // Enviar un archivo de imagen local
   oAI:SendImage( "C:\photos\chart.png", "Describe what you see in this image." )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   // Enviar una imagen por URL
   oAI:SendImageURL( ;
      "https://example.com/photo.jpg", ;
      "What objects are in this photo?" )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Ejemplo: TChatGPT (Envoltorio Simple)

#include "FiveWin.ch"

function Main()

   local oChat

   oChat := TChatGPT():New( "sk-your-api-key-here" )

   // Establecer el prompt y enviar
   oChat:cPrompt := "Translate 'Hello, how are you?' to Spanish"
   oChat:Send()

   if oChat:nError == 0
      // Navegar la respuesta JSON
      ? oChat:GetValue( "choices", "message", "content" )
      // Salida: "Hola, como estas?"
   endif

   // Enviar otro prompt (reiniciar primero)
   oChat:Reset()
   oChat:cPrompt := "Now translate it to French"
   oChat:Send()

   if oChat:nError == 0
      ? oChat:GetValue( "choices", "message", "content" )
   endif

   oChat:End()

return nil

Ejemplo: Ajustar la Temperatura

#include "FiveWin.ch"

function Main()

   local oAI

   oAI := TOpenAI():New()

   // Temperatura baja = más determinista
   oAI:nTemperature := 0.1
   oAI:Send( "What is 2 + 2?" )
   ? "Preciso:", oAI:GetValue()

   // Temperatura alta = más creativo
   oAI:nTemperature := 1.5
   oAI:Send( "Write a creative product name for a new coffee brand" )
   ? "Creativo:", oAI:GetValue()

   oAI:End()

return nil

Consejos

  • Almacene su clave API en la variable de entorno OPENAI_API_KEY en lugar de codificarla directamente.
  • TOpenAI:New() lee automáticamente del entorno si no se pasa ninguna clave.
  • La biblioteca hb_curl debe estar enlazada. Use #include "hbcurl.ch" para las constantes.
  • La verificación SSL está deshabilitada por defecto (HB_CURLOPT_SSL_VERIFYPEER = .F.) por compatibilidad.
  • Use SendStream() para respuestas largas para obtener salida en tiempo real en lugar de esperar la respuesta completa.
  • El método GetValue() maneja el análisis JSON internamente. Para TOpenAI devuelve choices[1].message.content. Para TChatGPT, pase la ruta de claves como argumentos.

Transformer (Red Neuronal en Harbour)

Fuente: source/classes/transformer.prg

Avanzado Una red neuronal Transformer completa implementada en Harbour puro. Soporta entrenamiento, propagación hacia adelante/atrás, atención multi-cabeza y predicción de texto.

DATADescripción
d_modelDimensión del modelo (tamaño del embedding)
n_headsNúmero de cabezas de atención
num_layersNúmero de capas del transformer
vocab_sizeTamaño del vocabulario
max_seq_lenLongitud máxima de secuencia
aVocabArray de vocabulario (palabras)
Embedding, PositionalMatrices de embedding y codificación posicional
MétodoDescripción
New()Constructor: num_layers, d_model, n_heads, vocab_size, max_seq_len, hEmbeddings, aVocab
Forward()Propagación hacia adelante: src_indices, pos_indices → salida
Backward()Propagación hacia atrás: calcular gradientes para entrenamiento
zero_grad()Reiniciar todos los gradientes a cero

Ejemplo: Predicción de Siguiente Palabra (transf1.prg)

local vocab := { "hola", "mundo", "adios", "gato", "perro" }
local oT := Transformer():New( 1, 6, 2, Len(vocab), 8,, vocab )

// Entrenar con secuencias
for e = 1 to 60
   for i = 1 to Len(train_src)
      output := oT:Forward( train_src[i], train_pos[i] )
      oT:Backward( output, train_tgt[i], train_src[i], train_pos[i] )
   next
next

// Predecir siguiente palabra
output := oT:Forward( { 1, 2 }, { 1, 2 } )  // "hola mundo" -> ?

TNeuralNetwork (Red Neuronal Clásica)

Fuente: source/classes/tneuralnet.prg

Red neuronal feedforward clásica con retropropagación. Buena para reconocimiento de patrones simples.

// Ejemplo de entrenamiento XOR
local oNN := TNeuralNetwork():New( 2, { 2 }, 1 )  // 2 entradas, 1 capa oculta con 2 neuronas, 1 salida

for n = 1 to 30000
   oNN:Learn( { 0, 0 }, { 0 }, .F. )
   oNN:Learn( { 1, 0 }, { 1 }, .F. )
   oNN:Learn( { 0, 1 }, { 1 }, .F. )
   oNN:Learn( { 1, 1 }, { 0 }, .F. )
next

? oNN:Predict( { 1, 0 } )  // -> ~1.0
? oNN:Predict( { 1, 1 } )  // -> ~0.0

TEmbeddings (Similitud Semántica)

Fuente: source/classes/tembeddings.prg

Embeddings de texto para comparación de similitud semántica. Usa APIs de HuggingFace u OpenAI.

local oE1 := TEmbeddings():New()
local oE2 := TEmbeddings():New()
local oE3 := TEmbeddings():New()

oE1:GetEmbeddings( "I feel very well" )
oE2:GetEmbeddings( "How are you?" )
oE3:GetEmbeddings( "I saw Peter" )

? oE1 - oE2   // Alta similitud (ambos sobre sentimientos)
? oE1 - oE3   // Baja similitud (temas diferentes)

Agentes de IA (TOLlama + TAgent)

Los agentes de IA combinan LLMs con herramientas (funciones) que la IA puede invocar. La IA decide qué herramienta usar según la solicitud del usuario.

local oLlama := TOLlama():New()
local oAgent

// Agente para fecha/hora
oAgent := TAgent():New( "datetime", { ;
   { "get_time", {|hParams| GetCurrentTime(hParams) } }, ;
   { "get_date", {|hParams| GetDate(hParams) } } } )
AAdd( oLlama:aAgents, oAgent )

// Agente para sistema de archivos
oAgent := TAgent():New( "filesystem", { ;
   { "create_folder", {|hParams| CreateFolder(hParams) } }, ;
   { "create_file",   {|hParams| CreateFile(hParams) } } } )
AAdd( oLlama:aAgents, oAgent )

// La IA decide qué herramienta usar
oLlama:Send( "What time is it?" )       // -> llama a get_time
oLlama:Send( "Create a folder test" )   // -> llama a create_folder

TInternet

Fuente: source/classes/internet.prg

Hereda de: ninguna (clase base)

TInternet es la clase base para el acceso a Internet basado en WinInet en FWH. Gestiona un manejador de sesión WinInet global y proporciona un método fábrica para crear conexiones TFTP. La clase usa un patrón singleton con conteo de referencias para el manejador de sesión WinINet.

Miembros DATA Principales

DATATipoDescripción
hWinINetManejador(Dato de clase) Manejador de WinINet.dll abierto
hSessionManejador(Dato de clase) Manejador de la sesión WinINet actual (InternetOpen)
nCountNumérico(Dato de clase) Conteo de referencia de objetos TInternet activos
aFTPsArray(Dato de clase) Array de todos los objetos TFTP actualmente en uso

Métodos Principales

MétodoDescripción
New()Crea un nuevo objeto TInternet; incrementa el conteo de referencia de la sesión y abre la sesión WinINet en el primer uso
End()Libera el objeto internet; decrementa el conteo de referencia y cierra la sesión WinINet cuando el conteo llega a cero
FTP( cFTPSite, cUserName, cPassword )Crea y devuelve un nuevo objeto TFTP conectado al sitio FTP especificado

Ejemplo: Subida de Archivo FTP vía WinInet

#include "FiveWin.ch"

function Main()

   local oInet := TInternet():New()
   local oFtp  := oInet:FTP( "ftp.example.com", "user", "pass" )

   if oFtp:hFTP != nil
      oFtp:SetCurrentDirectory( "/uploads" )
      FtpPutFile( oFtp:hFTP, "c:\data\report.txt", "report.txt" )
      MsgInfo( "File uploaded successfully" )
   else
      MsgAlert( "FTP connection failed" )
   endif

   oFtp:End()
   oInet:End()

return nil

Notas

  • TInternet usa un patrón singleton con datos de clase: el manejador hSession se comparte entre todas las instancias de TInternet. La sesión se abre en el primer New() y se cierra en el último End().
  • El método FTP() crea un objeto TFTP (definido en tftp.prg) que usa InternetConnect con INTERNET_SERVICE_FTP en el puerto 21.
  • Todas las conexiones TFTP activas se rastrean en aFTPs y se cierran adecuadamente cuando el conteo de referencia de TInternet llega a cero.
  • Las llamadas directas a la API WinINet (InternetOpen, InternetConnect, InternetCloseHandle, FtpPutFile, etc.) están disponibles para uso avanzado más allá de los métodos envolventes.

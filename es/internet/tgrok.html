TGrok (xAI)

Fuente: source/classes/tgrok.prg

TGrok es el cliente de FiveWin para la API xAI Grok. Proporciona acceso a los modelos de lenguaje Grok con soporte para chat de texto, respuestas en streaming y análisis de imágenes (incluyendo carga de archivos locales y URLs de imágenes). La clase utiliza la biblioteca hb_curl de Harbour para la comunicación HTTPS con el endpoint de la API xAI. Las claves API pueden pasarse explícitamente o leerse de la variable de entorno XAI_API_KEY.

Métodos

MétodoDescripción
New( cKey, cModel )Crear una instancia de TGrok. Si cKey está vacío, lee XAI_API_KEY del entorno. Inicializa el manejador libcurl.
Send( cPrompt )Enviar un prompt de texto a la API Grok. Almacena la respuesta JSON en bruto en cResponse.
SendStream( cPrompt, bCallback )Enviar un prompt con streaming habilitado. El bloque de código bCallback recibe cada fragmento de datos a medida que llega.
SendImage( cImageFile, cPrompt )Enviar un archivo de imagen local con un prompt de texto para análisis de visión. Codifica la imagen como base64.
SendImageURL( cImageUrl, cPrompt )Enviar una URL de imagen con un prompt de texto para análisis de visión.
GetValue()Extraer la respuesta de texto del JSON en cResponse. Devuelve el contenido del mensaje o información de error.
End()Limpiar el manejador libcurl. Se llama automáticamente por el destructor.

Ejemplo: Chat de Texto

#include "FiveWin.ch"

function Main()

   local oAI := TGrok():New( "your-xai-key-here" )

   oAI:Send( "What are the key features of the Harbour language?" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      MsgInfo( oAI:GetValue() )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Ejemplo: Respuesta en Streaming

#include "FiveWin.ch"

function Main()

   local oAI := TGrok():New( "your-xai-key-here" )
   local cBuffer := ""

   oAI:SendStream( "Write a short story about AI.", ;
      { |cChunk| cBuffer += cChunk, QOut( cChunk ) } )

   if oAI:nError == 0
      MsgInfo( "Complete response:" + CRLF + cBuffer )
   endif

   oAI:End()

return nil

Ejemplo: Análisis de Imagen

#include "FiveWin.ch"

function Main()

   local oAI := TGrok():New( "your-xai-key-here", "grok-3-latest" )

   // Analyze a local image
   oAI:SendImage( "C:\photos\chart.png", "Describe this chart in detail." )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   // Analyze an image by URL
   oAI:SendImageURL( "https://example.com/photo.jpg", ;
      "What objects are in this photo?" )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Notas

  • TGrok requiere la biblioteca hb_curl. Incluya #include "hbcurl.ch" para las constantes curl.
  • La verificación SSL está deshabilitada por defecto (HB_CURLOPT_SSL_VERIFYPEER = .F.) para compatibilidad.
  • La clave API se puede leer de la variable de entorno XAI_API_KEY pasando una clave vacía a New().
  • GetValue() navega la ruta JSON choices[1].message.content para extraer el texto. Si ocurrió un error, devuelve el objeto de error en su lugar.
  • El método SendImage() lee el archivo del disco, lo codifica como base64 y lo envía en línea con la solicitud.

TNewsServer / TNewsInstance

Fuentes: source/classes/tnewssrv.prg, source/classes/tnewsins.prg

TNewsServer independiente | TNewsInstance auxiliar

TNewsServer implementa un servidor de noticias NNTP (Network News Transfer Protocol) en el puerto 119. Está construido sobre TSocket y usa archivos DBF/CDX para almacenar grupos de noticias y artículos. TNewsInstance maneja cada sesión de cliente conectada, analizando comandos NNTP y sirviendo datos de artículos.

Ejemplo: Iniciar Servidor de Noticias

#include "FiveWin.ch"

function Main()

   local oWnd, oServer

   DEFINE WINDOW oWnd TITLE "NNTP News Server" SIZE 600, 400

   oServer := TNewsServer():New( oWnd, "c:\newsserver\data" )
   oServer:Activate()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • El servidor escucha en el puerto TCP 119 (puerto NNTP estándar). Cada conexión de cliente crea un TNewsInstance.
  • Los grupos de noticias y artículos se almacenan en archivos DBF con índices CDX, organizados por ID de grupo.
  • El temporizador (intervalo de 10ms) procesa tareas pendientes del cliente (p.ej., enviar resultados LIST en fragmentos).
  • El análisis de comandos no distingue mayúsculas/minúsculas. Los comandos no reconocidos reciben "500 Command not implemented."

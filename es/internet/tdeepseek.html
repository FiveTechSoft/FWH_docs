TDeepSeek

Fuente: source/classes/tdeepseek.prg

TDeepSeek es el cliente de FiveWin para la API DeepSeek. DeepSeek es conocido por sus sólidas capacidades de codificación y razonamiento, lo que lo convierte en una excelente opción para generación de código, análisis y tareas de lógica. La clase proporciona una interfaz simple de completación de chat utilizando la biblioteca hb_curl de Harbour. Soporta los modelos deepseek-chat y deepseek-reasoner.

Métodos

MétodoDescripción
New( cKey, cModel )Crear una instancia de TDeepSeek. Si cKey está vacío, lee DEEPSEEK_API_KEY del entorno. Establece el endpoint de la API e inicializa un manejador libcurl.
Send( cPrompt )Enviar un prompt de texto a la API DeepSeek. Almacena la respuesta JSON en bruto en cResponse.
GetValue()Extraer la respuesta de texto del JSON en cResponse. Navega choices[1].message.content en caso de éxito, o devuelve el mensaje de error en caso de fallo.
End()Limpiar el manejador libcurl.

Ejemplo: Completación de Chat

#include "FiveWin.ch"

function Main()

   local oAI := TDeepSeek():New( "sk-deepseek-key" )
   local cAnswer

   // Send a prompt
   oAI:Send( "Write a Harbour function to calculate the Fibonacci sequence" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      cAnswer := oAI:GetValue()
      MsgInfo( cAnswer )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Ejemplo: Usando el Modelo Reasoner

#include "FiveWin.ch"

function Main()

   local oAI := TDeepSeek():New( "sk-deepseek-key", "deepseek-reasoner" )

   oAI:Send( "Solve this logic puzzle: A man pushes his car to a hotel " + ;
             "and tells the owner he is bankrupt. What happened?" )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Notas

  • TDeepSeek requiere la biblioteca hb_curl. Incluya #include "hbcurl.ch" para las constantes curl.
  • La clave API se puede leer de la variable de entorno DEEPSEEK_API_KEY pasando una clave vacía a New().
  • La verificación SSL está deshabilitada por defecto (HB_CURLOPT_SSL_VERIFYPEER = .F.) para una amplia compatibilidad.
  • El modelo deepseek-reasoner proporciona razonamiento de cadena de pensamiento antes de responder, lo que lo hace adecuado para tareas complejas de lógica y análisis.
  • GetValue() navega la ruta JSON choices[1].message.content y devuelve el texto. Si la API devuelve un error, navega error.message en su lugar.
  • La clase no tiene estado para los prompts: cada llamada a Send() es independiente. Para conversaciones de múltiples turnos, mantenga su propio historial de mensajes y envíe el contexto completo.

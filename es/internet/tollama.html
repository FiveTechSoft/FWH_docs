TOLlama (Ollama / Local LLM)

Fuente: source/classes/tollama.prg

TOLlama es el cliente de FiveWin para la API de Ollama, que permite interactuar con LLMs alojados localmente a través de la API REST de Ollama (por defecto: http://localhost:11434). Admite chat de texto, respuestas en streaming y análisis de imágenes para modelos con capacidad de visión. La clase utiliza la librería hb_curl de Harbour y se conecta a tu servidor Ollama local, sin necesidad de claves de API ni conexión a Internet. La clase complementaria TAgent proporciona un contenedor de datos para las definiciones de herramientas/agentes.

Métodos

MétodoDescripción
New( cModel )Crea una instancia de TOLlama. Establece el nombre del modelo e inicializa el handle de libcurl. El endpoint por defecto es http://localhost:11434/api/chat.
Send( cPrompt )Envía un prompt de texto a la API de chat de Ollama. Almacena la respuesta JSON sin procesar en cResponse y la devuelve.
SendStream( cPrompt, bWriteFunction )Envía un prompt con streaming habilitado. El codeblock bWriteFunction recibe cada fragmento JSON a medida que llega del servidor.
SendImage( cImageFileName, cPrompt )Envía un archivo de imagen local junto con un prompt de texto para el análisis de visión. Codifica la imagen en base64. Compatible con modelos de visión como LLaVA.
GetValue()Extrae el texto de respuesta del JSON en cResponse. Devuelve message.content o el mensaje de error.
End()Libera el handle de libcurl. Se llama automáticamente desde el destructor.

Clase TAgent

DATATipoDescripción
cCategoryCarácterCategoría o identificador del agente

TAgent es un contenedor de datos para definir agentes y sus conjuntos de herramientas asociados. Funciona junto con el array aAgents de TOLlama para organizar múltiples configuraciones de agentes.

MétodoDescripción
New( cCategory, aTools )Crea una instancia de TAgent con un nombre de categoría y un array de definiciones de herramientas.

Ejemplo: Chat con LLM Local

#include "FiveWin.ch"

function Main()

   local oAI := TOLlama():New( "llama3.2" )

   oAI:Send( "What is the capital of France?" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      MsgInfo( oAI:GetValue() )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Ejemplo: Respuesta en Streaming

#include "FiveWin.ch"

function Main()

   local oAI := TOLlama():New( "llama3.2" )
   local cBuffer := ""

   oAI:SendStream( "Tell me a joke.", ;
      { |cChunk| cBuffer += cChunk, QOut( cChunk ) } )

   if oAI:nError == 0
      MsgInfo( "Complete response:" + CRLF + cBuffer )
   endif

   oAI:End()

return nil

Ejemplo: Análisis de Imágenes

#include "FiveWin.ch"

function Main()

   local oAI := TOLlama():New( "llava" )  // modelo con capacidad de visión

   oAI:SendImage( "C:\photos\photo.jpg", "What objects do you see?" )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Notas

  • TOLlama se conecta a un servidor Ollama que se ejecuta localmente. No requiere clave de API ni acceso a Internet.
  • El modelo por defecto es "deepseek-r1:14b" (definido en la clase), pero deberías pasar el nombre del modelo que hayas descargado localmente (por ejemplo, "llama3.2", "llava", "mistral").
  • Para el análisis de imágenes, utiliza un modelo con capacidad de visión como "llava" o "bakllava".
  • GetValue() extrae el campo message.content de la respuesta JSON de Ollama. En caso de error devuelve el campo error.message.
  • El método Send() establece stream: false y temperature: 0.5 en la petición. SendStream() establece stream: true.
  • Requiere la librería hb_curl. Incluye #include "hbcurl.ch" para las constantes de curl.

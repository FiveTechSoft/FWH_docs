TKimi (Moonshot)

Fuente: source/classes/tkimi.prg

TKimi es el cliente de FiveWin para la API Moonshot Kimi. Cuenta con un método Send() unificado que detecta automáticamente el tipo de entrada: texto plano, archivo de imagen local, URL de imagen o solicitud de streaming. Este diseño simplifica la integración al eliminar la necesidad de llamar a diferentes métodos para diferentes tipos de entrada. Los modelos Kimi ofrecen potentes capacidades multilingües con ventanas de contexto de 8K a 128K tokens.

Métodos

MétodoDescripción
New( cKey, cModel )Crear una instancia de TKimi. Si cKey está vacío, lee KIMI_API_KEY del entorno.
Send( xInput, uOptional )Método de envío unificado. Detecta automáticamente el tipo de entrada: cadena de texto plano, ruta de archivo local (envía como imagen), URL HTTP (envía como URL de imagen), o si el segundo parámetro es un bloque de código (streaming).
GetValue()Extraer la respuesta de texto del JSON en cResponse. Navega choices[1].message.content.
End()Limpiar el manejador libcurl.

Ejemplo: Prompt de Texto Plano

#include "FiveWin.ch"

function Main()

   local oKimi := TKimi():New( "your-moonshot-key" )

   // Simple text prompt
   oKimi:Send( "What is the capital of France?" )

   if oKimi:nError == 0
      MsgInfo( oKimi:GetValue() )
   endif

   oKimi:End()

return nil

Ejemplo: Análisis de URL de Imagen

#include "FiveWin.ch"

function Main()

   local oKimi := TKimi():New( "your-moonshot-key" )

   // Image URL - auto-detected by the "http" prefix
   oKimi:Send( "https://example.com/photo.jpg", ;
               "What do you see in this image?" )

   if oKimi:nError == 0
      MsgInfo( oKimi:GetValue() )
   endif

   oKimi:End()

return nil

Ejemplo: Respuesta en Streaming

#include "FiveWin.ch"

function Main()

   local oKimi := TKimi():New( "your-moonshot-key" )
   local cBuffer := ""

   // Pass a codeblock as the second parameter for streaming
   oKimi:Send( "Tell me a joke", { |c| cBuffer += c, QOut( c ) } )

   if oKimi:nError == 0
      MsgInfo( "Complete:" + CRLF + cBuffer )
   endif

   oKimi:End()

return nil

Notas

  • El método Send() detecta tipos de entrada automáticamente: una ruta de archivo existente activa la carga de imagen, una URL que comienza con "http" activa el modo de URL de imagen, un bloque de código como segundo parámetro habilita streaming, y texto plano envía una solicitud de completación de chat estándar.
  • TKimi requiere la biblioteca hb_curl. Incluya #include "hbcurl.ch" para las constantes curl.
  • La clave API se puede leer de la variable de entorno KIMI_API_KEY pasando una clave vacía a New().
  • Modelos Kimi: moonshot-v1-8k (contexto 8K), moonshot-v1-32k (contexto 32K) y moonshot-v1-128k (contexto 128K).
  • La verificación SSL está deshabilitada por defecto para una amplia compatibilidad.

Clases de IA

Fuentes: source/classes/topenai.prg, source/classes/tdeepseek.prg, source/classes/tgemini.prg, source/classes/tollama.prg

FiveWin proporciona un conjunto unificado de clases de IA/LLM que se integran con proveedores de IA en la nube populares y modelos locales. Todas las clases siguen el mismo patrón básico: instanciar con una clave API (o nombre del modelo para local), enviar un prompt y extraer la respuesta. Utilizan la librería hb_curl de Harbour para la comunicación HTTPS con los puntos finales de la API respectivos.

Para la documentación completa de IA incluyendo todos los miembros de las clases y ejemplos extendidos, consulte TOpenAI / TChatGPT — esa página documenta cada clase de IA con tablas de referencia completas, ejemplos de código y una guía comparativa.

Patrón Común

Todas las clases de IA comparten este flujo de trabajo básico: 

// 1. Create instance with API key (or model name for local)
oAI := TSomeAI():New( cApiKey )

// 2. Send a prompt
oAI:Send( "Your question here" )

// 3. Extract the response text
cAnswer := oAI:GetValue()

// 4. Clean up
oAI:End()

TOpenAI

Fuente: source/classes/topenai.prg

Integración con OpenAI ChatGPT. Soporta texto, visión (análisis de imágenes) y respuestas en streaming.

DATADefaultDescripción
cKeyenv OPENAI_API_KEYClave API de OpenAI
cModelgpt-4o-miniNombre del modelo (ej. gpt-4o, gpt-4o-mini)
nTemperature0.5Temperatura de muestreo (0.0 a 2.0)
cResponseRespuesta JSON cruda de la API
MétodoParámetrosDescripción
New()cKey, cModelConstructor. Lee la variable de entorno si cKey está vacío.
Send()cPromptEnviar un prompt de texto, devuelve JSON crudo
SendStream()cPrompt, bCallbackRespuesta en streaming a través de callback
SendImage()cImageFile, cPromptVisión: analizar una imagen local
SendImageURL()cImageUrl, cPromptVisión: analizar imagen desde URL
GetValue()Extraer texto de la respuesta JSON

TGemini

Fuente: source/classes/tgemini.prg

Integración con Google Gemini. Soporta texto, imágenes, subida de archivos y streaming.

DATADefaultDescripción
cKeyenv GEMINI_API_KEYClave API de Google
cModelgemini-2.0-flashNombre del modelo
nTemperature0Creatividad de la respuesta (0-2)
MétodoParámetrosDescripción
New()cKey, cModelConstructor
Send()uContent, cPrompt, bCallbackEnviar texto, archivo de imagen o array de archivos con prompt

GetValue()Extraer texto de la respuesta JSON
 
local oAI := TGemini():New( "google-api-key" )

// Text prompt
oAI:Send( "Explain quantum computing in simple terms" )
MsgInfo( oAI:GetValue() )

// Image analysis
oAI:Send( "C:\photos\chart.png", "Describe this chart" )
MsgInfo( oAI:GetValue() )

oAI:End()

TOLlama (IA Local)

Fuente: source/classes/tollama.prg

Integración con LLM local a través de Ollama. No necesita clave API — ejecuta modelos en su propia máquina. Modelo predeterminado: deepseek-r1:14b.

DATADefaultDescripción
cModeldeepseek-r1:14bNombre del modelo de Ollama
cUrlhttp://localhost:11434/api/chatPunto final del servidor Ollama
MétodoParámetrosDescripción
New()cModelConstructor. Modelo predeterminado: deepseek-r1:14b.
Send()cPromptEnviar prompt, devuelve JSON crudo
SendStream()cPrompt, bCallbackRespuesta en streaming a través de callback
SendImage()cImageFile, cPromptVisión para modelos multimodales (ej. llava)
GetValue()Extraer contenido del mensaje desde JSON
 
// Local AI - no API key needed
local oAI := TOLlama():New( "llama3" )
oAI:Send( "What is FiveWin?" )
MsgInfo( oAI:GetValue() )

// Streaming response
oAI:SendStream( "Write a poem", {|c| QOut(c)} )

// Image analysis (vision model)
oAI:SendImage( "photo.jpg", "What do you see?" )

oAI:End()

Consejos

  • Todas las clases de IA requieren la librería hb_curl. Enlace con #include "hbcurl.ch" para constantes curl.
  • La verificación SSL está deshabilitada por defecto (HB_CURLOPT_SSL_VERIFYPEER = .F.) para amplia compatibilidad.
  • Use GetValue() para extraer la respuesta de texto del JSON crudo almacenado en cResponse.
  • El DATA miembro cResponse siempre contiene el JSON crudo. Acceda a él directamente para depuración o análisis personalizado.
  • Para documentación completa incluyendo todos los métodos, codeblocks de callback y uso avanzado, consulte la página TOpenAI / TChatGPT.

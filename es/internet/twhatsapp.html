TWhatsApp

Fuente: source/classes/twhatsapp.prg

Jerarquía: TWhatsApp (clase independiente, sin herencia)

TWhatsApp es un cliente de la API Cloud de WhatsApp que se comunica con la Plataforma de Negocios de Meta mediante solicitudes HTTPS usando la biblioteca cURL. Requiere una Cuenta de Negocios de Meta, un ID de número de teléfono registrado y un token de acceso de sistema permanente generado desde el Panel de Aplicaciones de Meta. Todos los tipos de mensajes se envían como cargas JSON a través de la API Graph.

Miembros DATA Principales

DATATipoPredet.Descripción
cTokenCarácterToken de acceso Bearer para autenticación de API
cPhoneIdCarácterID del número de teléfono remitente (ID numérico de Meta, no el número de teléfono)
cVersionCarácter"v18.0"Cadena de versión de la API Graph
cBaseUrlCarácter"https://graph.facebook.com"URL base para todas las llamadas a la API
cResponseCarácterRespuesta JSON cruda de la última llamada a la API
nErrorNumérico0Código de error cURL de la última operación
nHttpCodeNumérico0Código de estado HTTP de la última respuesta

Métodos Principales

MétodoDescripción
New( cToken, cPhoneId, cVersion )Constructor. Inicializa el manejador cURL y almacena las credenciales. Opcionalmente establece la versión de la API.
End()Limpiar el manejador cURL. Llamar cuando se termine con el objeto.
SendText( cTo, cMsg, lPreviewUrl )Enviar un mensaje de texto plano. lPreviewUrl habilita la generación de vista previa de enlaces.
SendTemplate( cTo, cName, cLang, aBodyParams )Enviar una plantilla de mensaje pre-aprobada con valores de parámetros de cuerpo opcionales.
SendImage( cTo, cLinkOrId, cCaption )Enviar una imagen por URL o ID de medio previamente subido.
SendDocument( cTo, cLinkOrId, cFilename, cCaption )Enviar un documento por URL o ID de medio con nombre de archivo y pie opcionales.
SendAudio( cTo, cLinkOrId )Enviar un archivo de audio por URL o ID de medio.
SendVideo( cTo, cLinkOrId, cCaption )Enviar un video por URL o ID de medio con pie opcional.
SendLocation( cTo, nLat, nLong, cName, cAddress )Enviar un pin de ubicación con latitud, longitud y nombre/dirección opcionales.
UploadMedia( cFileName, cMimeType )Subir un archivo de medio a los servidores de WhatsApp. Devuelve la cadena del ID de medio, o nil en caso de error.
DownloadMedia( cMediaId, cTargetFile )Descargar un archivo de medio desde los servidores de WhatsApp y guardarlo en disco. Devuelve .T. en caso de éxito.
GetMessageId()Extraer el ID del mensaje de la última respuesta de la API. Devuelve cadena vacía en caso de error.
GetError()Extraer el mensaje de error de la última respuesta de la API. Devuelve cadena vacía si no hay error.

Ejemplo: Enviar Mensaje de Texto

#include "FiveWin.ch"

function Main()

   local oWA := TWhatsApp():New( "EAAx...token", "123456789", "v18.0" )
   local cResp, cMsgId

   // Send a simple text message
   cResp := oWA:SendText( "5215512345678", "Hello from FiveWin!" )

   cMsgId := oWA:GetMessageId()
   if ! Empty( cMsgId )
      MsgInfo( "Message sent. ID: " + cMsgId )
   else
      MsgInfo( "Error: " + oWA:GetError() )
   endif

   oWA:End()

return nil

Ejemplo: Mensaje de Plantilla

#include "FiveWin.ch"

function SendTemplate()

   local oWA  := TWhatsApp():New( "EAAx...token", "123456789" )
   local aParams := { "John", "FWH 26.05", "Monday" }

   // "welcome_message" must be pre-approved by Meta
   oWA:SendTemplate( "5215512345678", "welcome_message", "en_US", aParams )
   oWA:End()

return nil

Notas

  • Se requiere una Cuenta de Negocios de Meta y un número de teléfono registrado. El ID del número de teléfono es un identificador numérico asignado por Meta, no el número de teléfono en sí.
  • Use un token de acceso de sistema permanente desde el Panel de Aplicaciones de Meta. Los tokens de usuario temporales caducan.
  • SendImage, SendDocument, SendAudio y SendVideo aceptan una URL pública o un ID de medio previamente subido. Las URLs deben comenzar con http (sin distinción de mayúsculas/minúsculas).
  • Los nombres de plantilla deben coincidir con plantillas pre-aprobadas en la cuenta de Negocios de Meta. Los parámetros del cuerpo se insertan posicionalmente.
  • Todos los métodos de envío devuelven la respuesta JSON cruda en cResponse. Llame a GetMessageId() o GetError() para analizar el resultado.
  • La clase usa hbcurl.ch y requiere que la biblioteca cURL esté enlazada en la aplicación.

TPop3

Fuente: source/classes/tpop3.prg

TPop3 es la clase de recuperación de correo de FiveWin, implementando el protocolo POP3 para recibir mensajes desde un servidor de correo. Maneja el ciclo de vida completo de una sesión POP3: conectar, autenticar, listar mensajes, recuperar contenido, opcionalmente eliminar mensajes del servidor, y cerrar sesión. Al igual que TSmtp, está construida sobre TSocket.

Flujo del Protocolo

sequenceDiagram participant App as FiveWin App participant POP3 as TPop3 participant Server as POP3 Server App->>POP3: GetMail() POP3->>Server: USER username Server-->>POP3: +OK POP3->>Server: PASS password Server-->>POP3: +OK POP3->>Server: STAT Server-->>POP3: +OK count size loop For each message POP3->>Server: RETR n Server-->>POP3: [message content] POP3->>Server: DELE n (if lDelMsgs=.T.) Server-->>POP3: +OK end POP3->>Server: QUIT Server-->>POP3: +OK

Métodos

MétodoDescripción
New( cIPServer, nPort, User, Pass )Crear una nueva sesión POP3. nPort predeterminado es 110.
GetMail()Conectarse al servidor y comenzar la secuencia de recuperación de correo. Los mensajes se almacenan en aMsgs[].

Ejemplo: Consultar Bandeja de Entrada

#include "FiveWin.ch"

function Main()

   local oPop3, n

   oPop3 := TPop3():New( "mail.example.com", 110, ;
                         "user@example.com", "password" )

   oPop3:bConnected := { || MsgInfo( "Connected! Messages: " + ;
                                     LTrim( Str( Len( oPop3:aMsgs ) ) ) ) }

   oPop3:bDone := { ||
      MsgInfo( "Retrieved " + LTrim( Str( Len( oPop3:aMsgs ) ) ) + ;
               " messages." )
   }

   oPop3:GetMail()

   // Wait for async operation to complete
   while ! oPop3:AllOk
      SysRefresh()
   end

   // Display messages
   for n := 1 to Len( oPop3:aMsgs )
      ? "Message", n, ":", SubStr( oPop3:aMsgs[ n ], 1, 200 )
   next

return nil

Ejemplo: Recuperar Solo Cabeceras

#include "FiveWin.ch"

function Main()

   local oPop3, n

   oPop3 := TPop3():New( "mail.example.com", 110, ;
                         "user@example.com", "password" )

   // Only retrieve headers (faster, less bandwidth)
   oPop3:lHeaderOnly := .T.

   // Keep messages on the server
   oPop3:lDelMsgs := .F.

   oPop3:GetMail()

   while ! oPop3:AllOk
      SysRefresh()
   end

   // Display headers
   for n := 1 to Len( oPop3:aMsgs )
      ? "--- Message", n, "---"
      ? SubStr( oPop3:aMsgs[ n ], 1, 500 )
   next

return nil

Notas

  • TPop3 usa el modelo de socket asíncrono. Después de llamar a GetMail(), la recuperación ocurre a través del bucle de mensajes de FiveWin. Llame a SysRefresh() en un bucle si usa una aplicación de tipo consola sin ventana.
  • Por defecto, los mensajes se eliminan del servidor después de recuperarlos (lDelMsgs := .T.). Establézcalo a .F. para dejar los mensajes en el servidor.
  • Establezca lHeaderOnly := .T. para recuperar solo las cabeceras del correo usando el comando POP3 TOP. Esto es útil para escanear rápidamente el contenido de la bandeja de entrada sin descargar mensajes completos.
  • Los mensajes en aMsgs[] se almacenan en formato POP3 crudo incluyendo todas las cabeceras. Para extraer asunto, remitente, fecha, etc., se requiere extracción de cadenas del contenido crudo.
  • Los detalles de error se registran en MailErr.log en el directorio de la aplicación cuando ocurre un error POP3.

TWebView2

Fuente: source/classes/twebview2.prg

Overview

TWebView2 embebe Microsoft Edge WebView2 en una ventana o diálogo FiveWin. Sirve para alojar UIs HTML/CSS/JS modernas junto a controles FWH nativos. Requiere el Runtime WebView2.

Desktop + Web con una sola UI

El sample samples/DesktopWeb/login.prg muestra el patrón en el que desktop y navegador comparten el mismo HTML/CSS/JS:

  • Un servidor HTTP multi-hilo en el puerto 8080 sirve login y dashboard generados en Harbour.
  • El shell desktop crea TWebView2 y hace Navigate("http://localhost:8080/").
  • Cualquier navegador abre la misma URL con la misma UI y API.
  • La validación de credenciales está en PRG (ValidateLogin); sesión con cookie DWSESS.

Compilar con VM multi-hilo: samples\DesktopWeb\build.bat o build_new.bat login hm64 -mt. Demo: admin/1234, demo/demo.

FWH 26.09

La API ampliada, incluidos bOnConsole y EnableConsole, está disponible desde FWH 26.09, día 12 (12 de septiembre de 2026). Son características de la biblioteca FWH, no basta con actualizar el Runtime de Microsoft. Las bibliotecas anteriores pueden carecer del setter DATA _BONCONSOLE y del método EnableConsole.

bOnFrameNavCompleted( cUrl, hWebView )Navegación de frame completada. Retorno ignorado.
bOnCapturePreview( lOk, cPath, hWebView )Resultado final de captura/escritura PNG. Retorno ignorado.
bOnPrintToPdf( lOk, cPath, hWebView )Resultado final de exportación PDF. Retorno ignorado.

Consola JavaScript

EnableConsole(.T.) intercepta console.log/warn/error/info sin quitar la salida original de consola y añade un listener de errores JavaScript. Envía un sobre interno por SendToFWH; bOnConsole recibe la cadena JSON interior, no el sobre externo. args contiene cadenas: los objetos se convierten con JSON.stringify. line aparece en errores de window y no en llamadas normales a console.

Llama a EnableConsole(.T.) tras cada navegación principal: la intercepción se instala una vez por documento. EnableConsole(.F.) detiene la entrega por el despachador de consola, pero no deshace la intercepción JavaScript ya instalada. Su retorno lógico es el indicador guardado, no prueba de inyección correcta. La consola va separada de los mensajes normales de bOnBind.

Ejemplos de JSON recibido

{
  "type": "log",
  "args": [
    "ready",
    "{\"count\":2}"
  ],
  "url": "https://example.com/"
}

{
  "type": "error",
  "args": [
    "Uncaught ReferenceError: x is not defined"
  ],
  "url": "https://example.com/",
  "line": 12
}

Ejemplo de consola

oWeb := TWebView2():New( oWnd )
IF ! Empty( oWeb:hWebView )
   oWeb:bOnConsole := { | cJson, hWebView | LogConsole( cJson ) }
   oWeb:bOnNavigationCompleted := { | cUrl, hWebView | oWeb:EnableConsole( .T. ) }
   oWeb:Navigate( "https://example.com/" )
ENDIF

STATIC FUNCTION LogConsole( cJson )
   LOCAL hData
   hb_jsonDecode( cJson, @hData )
   IF ValType( hData ) == "H"
      // hData[ "type" ], hData[ "args" ], hData[ "url" ]
      // hData[ "line" ]: only for a window error
      OutputDebugString( cJson )
   ENDIF
RETURN NIL

Compatibilidad de bibliotecas

Para admitir bibliotecas FWH anteriores, comprueba tanto la asignación del DATA como la llamada a EnableConsole. Usa la misma comprobación al activar la traza tras navegar. Solo se omite el diagnóstico de consola; el tráfico normal SendToFWH/bOnBind no cambia.

IF __objHasMsg( oWeb, "_BONCONSOLE" ) .AND. ;
   __objHasMsg( oWeb, "ENABLECONSOLE" )
   oWeb:bOnConsole := { | cJson, hWebView | LogConsole( cJson ) }
   oWeb:EnableConsole( .T. )
ENDIF

Límites y requisitos del runtime

AddHostObject no está implementado. SetContextMenuExclude guarda la lista pero no filtra elementos del menú. La limpieza es mediante JavaScript, no borra todo el perfil ni cookies HttpOnly. Comprueba el resultado PNG/PDF asíncrono en sus eventos. Las interfaces disponibles del runtime pueden limitar PDF, descargas y peticiones HTTP. Consulta samples/webview2/wvdemo.prg + pulse.html y las constantes WV_CONTEXT_*, WV_DIALOG_*, WV_PERM_* y WV_FAIL_* en include/WebView2.ch.

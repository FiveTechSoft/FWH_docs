TWebView2

Fuente: source/classes/twebview2.prg

Overview

TWebView2 embebe Microsoft Edge WebView2 en una ventana o diálogo FiveWin. Sirve para alojar UIs HTML/CSS/JS modernas junto a controles FWH nativos. Requiere el Runtime WebView2.

Desktop + Web con una sola UI

El sample samples/DesktopWeb/login.prg muestra el patrón en el que desktop y navegador comparten el mismo HTML/CSS/JS:

  • Un servidor HTTP multi-hilo en el puerto 8080 sirve login y dashboard generados en Harbour.
  • El shell desktop crea TWebView2 y hace Navigate("http://localhost:8080/").
  • Cualquier navegador abre la misma URL con la misma UI y API.
  • La validación de credenciales está en PRG (ValidateLogin); sesión con cookie DWSESS.

Compilar con VM multi-hilo: samples\DesktopWeb\build.bat o build_new.bat login hm64 -mt. Demo: admin/1234, demo/demo.

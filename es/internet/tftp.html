TFtpClient / TFtpSession

Fuente: source/classes/tftpcli.prg (TFtpClient), source/classes/tftpsess.prg (TFtpSession)

FiveWin proporciona capacidades de cliente FTP a través de TFtpClient, que implementa el protocolo FTP para operaciones de transferencia de archivos. Soporta subida (STOR), bajada (RETR), navegación de directorios (CWD, PWD), creación de directorios (MKD), eliminación de archivos (DELE) y modos de transferencia binario/texto (TYPE). TFtpSession es una clase ligera usada por el servidor FTP interno para rastrear sesiones de cliente conectadas.

Clase TFtpClient

Miembros DATA

DATATipoDescripción
cIPServerCharacterNombre del servidor FTP o dirección IP
nPortNumericPuerto del servidor FTP (predeterminado 21)
UserCharacterNombre de usuario FTP
PassCharacterContraseña FTP
oSocketTSocketSocket de conexión de control
oDataSocketTSocketSocket de conexión de datos para transferencias de archivos
nStatusNumericEstado de la sesión (CONNECTING, IDENTIFY1, IDENTIFY2)
AllOkLogicalSe establece a .T. después de un inicio de sesión exitoso
SrvLastMsgCharacterÚltimo mensaje de respuesta del servidor
lWaitingLogicalIndicador de ocupado durante la ejecución síncrona de comandos
lTimeOutLogicalSe establece a .T. si un comando agota el tiempo de espera (30 segundos)
nSendedNumericContador de bytes enviados
bConnectingBlockCallback durante la conexión
bConnectedBlockCallback cuando se conecta
bDoneBlockCallback cuando la operación se completa

Métodos

MétodoDescripción
New( cIPServer, nPort, User, Pass )Crear cliente FTP y conectarse al servidor. nPort predeterminado es 21.
PWD()Mostrar directorio de trabajo actual. Devuelve la respuesta del servidor.
CWD( cDirName )Cambiar el directorio de trabajo en el servidor
MKD( cDirName )Crear un directorio en el servidor
DELE( cFileName )Eliminar un archivo del servidor
TYPE( cType )Establecer modo de transferencia: "I" (binario/imagen) o "A" (ASCII)
STOR( cFileName, bBlock )Subir un archivo (STORE). Usa modo activo PORT.
RETR( cFileName )Descargar un archivo (RETRIEVE). Devuelve .T. si tiene éxito, .F. si el archivo no se encuentra (550).
PORT( oTransSocket )Generar cadena de comando PORT para conexión de datos activa
QUIT()Desconectarse del servidor
DoWait()Esperar síncronamente la respuesta del servidor (tiempo de espera de 30 segundos)

Clase TFtpSession

TFtpSession es una clase de datos simple usada internamente para representar una sesión de cliente FTP conectada en el lado del servidor:

DATATipoDescripción
cUserNameCharacterNombre de usuario autenticado
cPasswordCharacterContraseña autenticada
cCurDirCharacterDirectorio de trabajo actual de la sesión
cIPCharacterDirección IP del cliente desde el comando PORT
nPortNumericPuerto del cliente desde el comando PORT
oSocketTSocketSocket de respuesta para la sesión

Ejemplo: Subir un Archivo

#include "FiveWin.ch"

function Main()

   local oFtp

   oFtp := TFtpClient():New( "ftp.example.com", 21, ;
                             "username", "password" )

   if oFtp:AllOk
      oFtp:CWD( "/public_html" )
      oFtp:STOR( "C:\files\index.html" )
      oFtp:QUIT()
      MsgInfo( "Upload complete" )
   else
      MsgStop( "FTP connection failed" )
   endif

return nil

Ejemplo: Descargar un Archivo

#include "FiveWin.ch"

function Main()

   local oFtp, lResult

   oFtp := TFtpClient():New( "ftp.example.com", 21, ;
                             "username", "password" )

   if oFtp:AllOk
      oFtp:CWD( "/backups" )
      lResult := oFtp:RETR( "data_2026.zip" )
      if lResult
         MsgInfo( "Download successful" )
      else
         MsgAlert( "File not found on server" )
      endif
      oFtp:QUIT()
   endif

return nil

Ejemplo: Operaciones de Directorio

#include "FiveWin.ch"

function Main()

   local oFtp, cCurrentDir

   oFtp := TFtpClient():New( "ftp.example.com", 21, ;
                             "username", "password" )

   if oFtp:AllOk
      // Get current directory
      cCurrentDir := oFtp:PWD()

      // Create a directory
      oFtp:MKD( "new_folder" )

      // Change into it
      oFtp:CWD( "new_folder" )

      // List current directory
      ? oFtp:PWD()

      oFtp:QUIT()
   endif

return nil

Notas

  • TFtpClient usa modo FTP activo (comando PORT) para las transferencias de datos. El cliente abre un socket de escucha y envía el comando PORT con información de IP y puerto al servidor.
  • Después de llamar a New(), verifique AllOk para confirmar que el inicio de sesión fue exitoso antes de intentar operaciones con archivos.
  • El método DoWait() implementa ejecución síncrona de comandos con un tiempo de espera de 30 segundos. Si el servidor no responde a tiempo, lTimeOut se establece a .T..
  • Para descargas, RETR() devuelve .F. si el servidor responde con el código de error 550 (archivo no encontrado).
  • TFtpSession está diseñada para usarse con la clase de servidor FTP interno y no se instancia típicamente directamente desde el código de la aplicación.

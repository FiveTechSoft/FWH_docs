TMail

Fuente: source/classes/tmail.prg

TMail is FiveWin's MAPI (Messaging API) email class. It uses the Windows Simple MAPI interface to send emails through the default email client (such as Microsoft Outlook, Windows Mail, or any MAPI-compliant email application). TMail supports subject, body text, multiple recipients, file attachments, read receipts, and originator information.

Methods

MethodDescription
New( cSubject, cNoteText, cMsgType, cConversationID, dDate, cTime, lReceipt, lFromUser, aOrigin, aRecipients, aFiles )Create a new mail message with all optional parameters. Defaults: empty subject, empty body, today's date, current time, no receipt, prompt user.
Activate()Send the email via MAPI. Calls MAPISendMail() with all configured properties. Stores the return code in nRetCode.
End()Log off from the MAPI session. Calls MAPILogOff().

Example: Send Email with Attachments

#include "FiveWin.ch"

function Main()

   local oMail

   // Configure the email
   oMail := TMail():New( "Report for May 2026", ;
                         "Please find the attached report.",,,, .T. )

   // Add recipients
   oMail:aRecipients := { "user@example.com", "manager@example.com" }

   // Attach files
   oMail:aFiles := { "C:\reports\may2026.xlsx", "C:\reports\summary.pdf" }

   // Request read receipt
   oMail:lReceipt := .T.

   // Send without prompting the user
   oMail:lFromUser := .F.

   // Activate sends the email
   oMail:Activate()

   if oMail:nRetCode == 0
      MsgInfo( "Email sent successfully!" )
   else
      MsgStop( "Failed to send email. Error code: " + Str( oMail:nRetCode ) )
   endif

   oMail:End()

return nil

Notes

  • TMail uses the default MAPI client installed on the system. Outlook, Windows Mail, Thunderbird (with MAPI plugin), and most email clients support MAPI.
  • When lFromUser is .T. (default), the email client's compose window opens for the user to review and send. When .F., the email is sent silently.
  • The aFiles array accepts full paths to files. Attachments can be any file type supported by the recipient's email client.
  • Recipients in aRecipients can be simple email address strings or MAPI recipient structures with name and address fields.
  • Check nRetCode after Activate() to determine if the send was successful.

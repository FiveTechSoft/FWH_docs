TMail

Fuente: source/classes/tmail.prg

TMail es la clase de correo electrónico MAPI (Messaging API) de FiveWin. Utiliza la interfaz Simple MAPI de Windows para enviar correos electrónicos a través del cliente de correo predeterminado (como Microsoft Outlook, Windows Mail o cualquier aplicación de correo compatible con MAPI). TMail soporta asunto, texto del cuerpo, múltiples destinatarios, archivos adjuntos, confirmaciones de lectura e información del remitente.

Métodos

MétodoDescripción
New( cSubject, cNoteText, cMsgType, cConversationID, dDate, cTime, lReceipt, lFromUser, aOrigin, aRecipients, aFiles )Crear un nuevo mensaje de correo con todos los parámetros opcionales. Valores predeterminados: asunto vacío, cuerpo vacío, fecha de hoy, hora actual, sin confirmación, preguntar al usuario.
Activate()Enviar el correo a través de MAPI. Llama a MAPISendMail() con todas las propiedades configuradas. Almacena el código de retorno en nRetCode.
End()Cerrar sesión de MAPI. Llama a MAPILogOff().

Ejemplo: Enviar Correo con Archivos Adjuntos

#include "FiveWin.ch"

function Main()

   local oMail

   // Configure the email
   oMail := TMail():New( "Report for May 2026", ;
                         "Please find the attached report.",,,, .T. )

   // Add recipients
   oMail:aRecipients := { "user@example.com", "manager@example.com" }

   // Attach files
   oMail:aFiles := { "C:\reports\may2026.xlsx", "C:\reports\summary.pdf" }

   // Request read receipt
   oMail:lReceipt := .T.

   // Send without prompting the user
   oMail:lFromUser := .F.

   // Activate sends the email
   oMail:Activate()

   if oMail:nRetCode == 0
      MsgInfo( "Email sent successfully!" )
   else
      MsgStop( "Failed to send email. Error code: " + Str( oMail:nRetCode ) )
   endif

   oMail:End()

return nil

Notas

  • TMail utiliza el cliente MAPI predeterminado instalado en el sistema. Outlook, Windows Mail, Thunderbird (con plugin MAPI) y la mayoría de los clientes de correo soportan MAPI.
  • Cuando lFromUser es .T. (predeterminado), se abre la ventana de redacción del cliente de correo para que el usuario revise y envíe. Cuando es .F., el correo se envía silenciosamente.
  • El array aFiles acepta rutas completas a archivos. Los adjuntos pueden ser de cualquier tipo de archivo compatible con el cliente de correo del destinatario.
  • Los destinatarios en aRecipients pueden ser cadenas de dirección de correo simples o estructuras de destinatario MAPI con campos de nombre y dirección.
  • Verifique nRetCode después de Activate() para determinar si el envío fue exitoso.

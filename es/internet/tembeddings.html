TEmbeddings

Fuente: source/classes/tembeddings.prg

TEmbeddings es la clase de FiveWin para generar y comparar embeddings de texto (representaciones vectoriales del texto). Soporta tanto la API de HuggingFace (a través del pipeline de extracción de características de la Inference API) como la API de embeddings de OpenAI. Los embeddings convierten texto en vectores de alta dimensión que capturan el significado semántico, permitiendo operaciones como búsqueda de similitud semántica, agrupamiento y clasificación.

Métodos

MétodoDescripción
New( cModel, cKey )Crear una instancia de TEmbeddings. Por defecto usa el modelo HuggingFace MiniLM. Lee la clave API de las variables de entorno HF_API_KEY y luego OPENAI_API_KEY si no se proporciona.
GetEmbeddings( cText )Generar embeddings para el texto dado. Almacena el vector en aEmbeddings. Devuelve el array de vector en bruto.
Distance( aVector, lCosine )Calcular la distancia entre aEmbeddings y otro vector. Por defecto usa distancia coseno. Establezca lCosine := .F. para distancia euclidiana.
DistanceFrom( oEmbeddings )Calcular la distancia a otro objeto TEmbeddings comparando sus vectores aEmbeddings.
End()Limpiar el manejador libcurl.

Ejemplo: Similitud Semántica

#include "FiveWin.ch"

function Main()

   local oE1 := TEmbeddings():New()
   local oE2 := TEmbeddings():New()
   local oE3 := TEmbeddings():New()
   local nSimilarity1, nSimilarity2

   // Generate embeddings for three phrases
   oE1:GetEmbeddings( "I feel very well" )
   oE2:GetEmbeddings( "How are you?" )
   oE3:GetEmbeddings( "I saw Peter" )

   // Cosine distance: lower = more similar
   nSimilarity1 := oE1:DistanceFrom( oE2 )  // Low distance (similar topic)
   nSimilarity2 := oE1:DistanceFrom( oE3 )  // High distance (different topic)

   QOut( "Similarity between 'feel well' and 'How are you':", nSimilarity1 )
   QOut( "Similarity between 'feel well' and 'saw Peter':", nSimilarity2 )

   // Using the OPERATOR "-" syntax (equivalent to DistanceFrom)
   ? oE1 - oE2   // Same as oE1:DistanceFrom( oE2 )
   ? oE1 - oE3   // Same as oE1:DistanceFrom( oE3 )

   oE1:End()
   oE2:End()
   oE3:End()

return nil

Ejemplo: Distancia Euclidiana

#include "FiveWin.ch"

function Main()

   local oE1 := TEmbeddings():New()
   local oE2 := TEmbeddings():New()

   oE1:GetEmbeddings( "Machine learning is fascinating" )
   oE2:GetEmbeddings( "Deep learning and AI are interesting" )

   // Euclidean distance instead of cosine
   ? "Euclidean distance:", oE1:Distance( oE2:aEmbeddings, .F. )

   oE1:End()
   oE2:End()

return nil

Notas

  • El modelo predeterminado es sentence-transformers/all-MiniLM-L6-v2 de HuggingFace. Cambiar el nombre del modelo cambia automáticamente entre proveedores: si el nombre del modelo contiene "openai" o "text-embedding-", usa el endpoint de OpenAI; de lo contrario, usa HuggingFace.
  • Cuando use HuggingFace, establezca la variable de entorno HF_API_KEY. Cuando use OpenAI, establezca OPENAI_API_KEY.
  • El método Distance() soporta dos métricas: distancia coseno (predeterminada) va de 0 (idéntico) a 1 (completamente diferente); la distancia euclidiana mide la distancia en línea recta entre vectores.
  • El OPERATOR "-" permite una sintaxis intuitiva: oE1 - oE2 calcula la distancia entre dos objetos TEmbeddings. Esto es equivalente a llamar a oE1:DistanceFrom( oE2 ).
  • Ambos vectores deben tener la misma longitud. El método Distance() devuelve -1 en caso de error.

TWebClient

Fuente: source/classes/twebclie.prg

TWebClient es la clase cliente HTTP ligera de FiveWin, construida directamente sobre TSocket. Proporciona una interfaz simple para conectarse a servidores web, obtener páginas y procesar respuestas HTTP. Para funcionalidades HTTP más avanzadas (HTTPS, POST con JSON, cabeceras personalizadas), considere usar la librería hb_curl directamente o las clases TOpenAI/AI como referencia.

Miembros DATA Principales

DATATipoDescripción
oSocketTSocketSocket TCP subyacente para la conexión HTTP
bOnConnectBlockCallback ejecutado cuando se establece la conexión con el servidor
bOnReadBlockCallback ejecutado cuando llegan datos del servidor

Métodos

MétodoDescripción
New()Crear un nuevo TWebClient. Crea y configura el TSocket subyacente con manejadores de lectura/conexión/cierre predeterminados.
Connect( cIPAddress )Conectarse a un servidor web. Acepta nombre de servidor (ej. "example.com") o dirección IP. Resuelve nombres de servidor automáticamente.
GetPage( cPageName )Enviar una solicitud HTTP GET para la ruta de página especificada. Soporta tanto URLs completas (http://...) como rutas relativas.
OnConnect()Llamado internamente cuando se establece la conexión. Activa el callback bOnConnect si está definido.
OnRead( cData )Llamado internamente cuando se reciben datos. Activa el callback bOnRead con los datos recibidos.

Ejemplo: Obtener una Página Web

#include "FiveWin.ch"

function Main()

   local oClient, cResponse := ""

   oClient := TWebClient():New()

   oClient:bOnConnect := { ||
      oClient:GetPage( "/" )
   }

   oClient:bOnRead := { |cData|
      cResponse += cData
   }

   oClient:Connect( "www.example.com" )

   // Wait for response
   SysRefresh()
   Inkey( 3 )

   // Display the HTTP response
   ? "Response received:", Len( cResponse ), "bytes"
   ? SubStr( cResponse, 1, 500 )

return nil

Ejemplo: Llamada a API REST

#include "FiveWin.ch"

function Main()

   local oClient, cResponse := ""
   local cApiHost := "api.github.com"
   local cEndpoint := "/repos/FiveTechSoft/FWH"

   oClient := TWebClient():New()

   oClient:bOnConnect := { ||
      // Send a GET request to the GitHub API
      oClient:GetPage( cEndpoint + ;
        " HTTP/1.1" + CRLF + ;
        "Host: " + cApiHost + CRLF + ;
        "User-Agent: FWH-WebClient" + CRLF + ;
        "Accept: application/vnd.github.v3+json" + CRLF + ;
        "Connection: close" )
   }

   oClient:bOnRead := { |cData|
      cResponse += cData
   }

   oClient:Connect( cApiHost )

   // Wait for the async operation
   SysRefresh()
   Inkey( 5 )

   // Display the response
   if ! Empty( cResponse )
      MemoWrit( "github_response.txt", cResponse )
      ? "Response saved to github_response.txt"
   endif

return nil

Notas

  • TWebClient es un envoltorio mínimo alrededor de TSocket. No analiza respuestas HTTP ni maneja redirecciones automáticamente.
  • El método GetPage() envía una solicitud HTTP GET cruda. Cuando se proporciona una URL completa que comienza con "http://", analiza el nombre del servidor y la ruta de la URL y usa HTTP/1.1 con una cabecera Host. De lo contrario, envía una solicitud HTTP/1.0 simple solo con la ruta.
  • Para conexiones HTTPS, use la librería hb_curl directamente en lugar de TWebClient, ya que TSocket no soporta TLS/SSL de forma nativa.
  • La clase reinicializa automáticamente el socket después de que una conexión se cierra (el manejador bClose recrea el socket).
  • Dado que TWebClient usa eventos de socket asíncronos, se debe llamar a SysRefresh() para procesar los datos entrantes en aplicaciones de modo consola.

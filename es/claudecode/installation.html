Instalación y Configuración

Requisitos

  • Node.js 18+
  • API key de Anthropic o suscripción Claude
  • Git

Instalar Claude Code

npm install -g @anthropic-ai/claude-code

Autenticar

claude login

O con API key: $env:ANTHROPIC_API_KEY = "sk-..."

Configuración del Proyecto FWH

git clone https://github.com/FiveTechSoft/fwh.git
cd fwh
claude

Claude lee CLAUDE.md automáticamente. El proyecto FWH incluye:

  • CLAUDE.md — Reglas de compilación, rutas, librerías
  • .claude/settings.local.json — Hooks y permisos
  • .claude/projects/c--fwteam/memory/ — Memoria persistente

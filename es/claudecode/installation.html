Installation & Setup

Prerequisites

  • Node.js 18+ (for Claude Code CLI)
  • Anthropic API key or Claude subscription
  • Git (for repository operations)

Install Claude Code

npm install -g @anthropic-ai/claude-code

Authenticate

claude login

Or set API key: $env:ANTHROPIC_API_KEY = "sk-..."

FWH Project Setup

Clone and enter the project:

git clone https://github.com/FiveTechSoft/fwh.git
cd fwh
claude

Claude reads CLAUDE.md automatically. The FWH project includes:

  • CLAUDE.md — Build rules, compiler paths, library naming
  • .claude/settings.local.json — Hooks and permissions
  • .claude/projects/c--fwteam/memory/ — Persistent memory

First Run

cd c:\fwteam
claude

Claude launches with full project context. Try: "build samples\misc\calexmaria.prg"

Claude Code

Claude Code es la herramienta CLI oficial de Anthropic y un agente de codificación con IA que opera directamente en tu terminal. Lee todo el código del proyecto, ejecuta comandos, edita archivos y orquesta tareas complejas multi-paso.

FiveWin para Harbour se integra con Claude Code mediante CLAUDE.md, memoria persistente, skills especializados y flujos multi-agente.

¿Qué es Claude Code?

  • Nativo de terminal — PowerShell, cmd, bash
  • Conocimiento total del código — lee todo tu proyecto
  • Agente con herramientas — edita, compila, ejecuta, usa git
  • Multi-agente — sub-agentes en paralelo
  • Memoria persistente — recuerda preferencias y convenciones
  • Hooks — automatización por eventos
  • MCP — extensible por Model Context Protocol

# FiveWin for Harbour/xHarbour (FWH) - Build Rules

## Building samples
Always use build_new.bat, never manual steps:
  cd /d C:\fwteam\samples\<folder>
  C:\fwteam\samples\build_new.bat <progname> <variant>

## Building FWH libraries
  C:\fwteam\mfwh_new.bat <variant>

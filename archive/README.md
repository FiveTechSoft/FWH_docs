# FiveWin Documentation — Archive

This folder contains **historical / superseded** documentation that is no
longer the maintained form of the FWH docs. It is kept for reference only.

## What was archived and why

* **`classes/`, `modules/`, `tutorials/`** — an earlier, incomplete markdown
  mirror of the class/function reference. Superseded by the HTML reference under
  `en/reference/` (and `es/`, `pt/`).
* **`architecture.md`, `installation.md`** — early drafts duplicated by the
  localized `getting-started/` pages (`overview.html`, `installation.html`).
* **`SUMMARY.md`** — a one-off status note rendered obsolete by `STATUS.md`.
* **Standalone topic docs** (`CE_TWindow.md`, `DatabaseUtilities.md`,
  `Internationalization.md`, `MessageBoxAPI.md`, `ShellAPI.md`,
  `SystemInternals.md`, `SystemMonitoring.md`) — early notes; their topics are
  covered by the HTML trees. `CE_TWindow.md` was in Spanish.
* **`chatgpt.prg_analisis.md`** — Spanish source analysis of `chatgpt.prg`;
  the AI documentation now lives under `en/ai/` (and `es/ai/`, `pt/ai/`).
* **`pytorch-lite-roadmap.md`** — planning notes for the AI/transformer effort;
  the published version is `en/ai/pytorch-lite-roadmap.html`.
* **`superpowers/`** (plans, specs) and **`webinar-agentic-ai/`** — auxiliary
  AI planning/webinar material.
* **`reorganize_docs.bat`, `standardize_lang.bat`** — scripts tied to the
  abandoned `reference/`-centric markdown layout.

## Current documentation

The authoritative documentation is the localized HTML set under `en/`, `es/`
and `pt/`; see `../README.md`, `../STRUCTURE.md` and `../STATUS.md` at the
docs root.

El problema

Sin agente

Yo: "Cuánto stock tengo del producto X?"

LLM: "No puedo acceder a tu base de datos"

Con agente

Yo: "Cuánto stock tengo del producto X?"

Agente: → consulta tu DB
→ procesa el resultado
→ responde con el dato exacto

Definición

Chatbot responde preguntas
Agente recibe un objetivo y ejecuta pasos hasta lograrlo

Patrón ReAct

Reasoning + Acting

Pensamiento: Necesito buscar información sobre X
Acción: buscar_web("X")
Observación: Encontré 3 fuentes relevantes
Pensamiento: Debo leer las 3 fuentes
Acción: leer_archivo("fuente1.txt")

Caso de Uso: Code Review Agent

Objetivo: Revisar PR y sugerir mejoras
1 Leer archivos modificados
2 Buscar patrones anti-patrones
3 Ejecutar tests
4 Generar reporte con sugerencias

Caso de Uso: Data Pipeline Agent

Objetivo: Importar datos de CSV a DBF
1 Leer CSV
2 Validar estructura
3 Convertir tipos
4 Insertar en DBF
5 Generar log de errores

Resumen

1 Un agente = LLM + Herramientas + Memoria
2 El loop: Observar → Pensar → Actuar → Evaluar
3 Las herramientas dan superpoderes al LLM
4 La memoria permite trabajo continuo
5 Los multi-agentes coordinan tareas complejas

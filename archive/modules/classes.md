# Classes Module

The `Classes` module is the heart of the FiveWin framework. It provides a rich set of object-oriented classes for building graphical user interfaces (GUIs) in Windows.

## Overview

The classes in this module represent various GUI elements, such as windows, dialogs, buttons, and listboxes. They encapsulate the functionality and behavior of these elements, making it easy to create and manage complex user interfaces.

The class hierarchy is designed to be intuitive and easy to extend. Most classes inherit from the `TWindow` or `TControl` base classes, which provide common functionality for all GUI elements.

## Main Classes

Here is a list of some of the most important classes in this module:

*   **[TWindow](classes/TWindow.md):** The base class for all windows and dialogs.
*   **[TDialog](classes/TDialog.md):** A specialized window for creating dialog boxes.
*   **[TControl](classes/TControl.md):** The base class for all controls.
*   **[TButton](classes/TButton.md):** A standard push button control.
*   **[TListBox](classes/TListBox.md):** A list box control.
*   **[TComboBox](classes/TComboBox.md):** A combination of a list box and an edit control.
*   **[TGet](classes/TGet.md):** A versatile data entry control.
*   **[TBrowse](classes/TBrowse.md):** A powerful control for browsing and editing data in a tabular format.

For a complete list of all classes, please refer to the `source/classes` directory.

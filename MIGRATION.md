# Documentation Migration Guide

This guide explains how to migrate documentation from Spanish to English and standardize the format.

## Language Standardization

All documentation should be written in English to ensure consistency and broader accessibility.

### Translation Guidelines

1. Use technical terminology consistently
2. Maintain the original meaning and intent
3. Follow standard technical writing conventions
4. Use American English spelling and grammar

## Format Standardization

All documentation should follow the standard template:

1. Title (H1)
2. Brief description
3. Source file reference
4. Overview (H2)
5. Key properties/methods/functions (H2)
6. Usage patterns with examples (H2)
7. Related components (H2)
8. Further reading (H2)

## Migration Process

1. Copy the Spanish file to a new English-named file
2. Translate the content while maintaining technical accuracy
3. Update the structure to match the standard template
4. Verify all links and references are correct
5. Delete the original Spanish file after verification

## Quality Assurance

Before committing changes:

1. Verify all links work correctly
2. Check that code examples compile and run
3. Ensure consistent terminology throughout
4. Validate formatting and structure
5. Confirm that the content follows the template

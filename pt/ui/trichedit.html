TRichEdit

Fonte: source/classes/trichedi.prg  |  Pai: TControl

TRichEdit encapsula o controle RichEdit20A do Windows, fornecendo um editor RTF completo. Suporta formatação negrito/itálico/sublinhado, alterações de fonte e cor, alinhamento de parágrafo, listas com marcadores, imagens incorporadas via OLE, localizar/substituir, zoom, desfazer/refazer e impressão/pré-visualização/exportação PDF.

Exemplo: Editor RTF

#include "FiveWin.ch"
#include "RichEdit.ch"

FUNCTION RichEditDemo()
   LOCAL oDlg, oRTF, cText := ""

   DEFINE DIALOG oDlg TITLE "Rich Text Editor" SIZE 600, 450

   @ 0.5, 0.5 RICHEDIT oRTF VAR cText OF oDlg ;
      SIZE 280, 180 PIXEL

   // Botoes da barra de ferramentas para formatacao
   @ 8, 0.5 BUTTON "Bold"      OF oDlg SIZE 50, 14 ;
      ACTION oRTF:SetBold( .T. )
   @ 8, 5   BUTTON "Italic"    OF oDlg SIZE 50, 14 ;
      ACTION oRTF:SetItalic( .T. )
   @ 8, 9.5 BUTTON "Underline" OF oDlg SIZE 60, 14 ;
      ACTION oRTF:SetUnderline( .T. )

   // Carregar e salvar
   @ 10, 0.5 BUTTON "Open RTF" OF oDlg SIZE 60, 14 ;
      ACTION ( cFile := cGetFile( "*.rtf", "Open RTF" ), ;
               If( !Empty(cFile), oRTF:LoadFromRTFFile( cFile ), ) )

   @ 10, 6  BUTTON "Save RTF" OF oDlg SIZE 60, 14 ;
      ACTION oRTF:SaveToRTFFile( cGetNewFile( "*.rtf", "Save RTF" ) )

   @ 10, 12 BUTTON "Print" OF oDlg SIZE 50, 14 ;
      ACTION oRTF:Print( "RichEdit Document" )

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

TScintilla

Fonte: source/classes/scintila.prg  |  Pai: TControl

TScintilla encapsula o componente editor Scintilla, fornecendo um editor de código fonte profissional com realce de sintaxe, dobramento de código, números de linha, marcadores, correspondência de colchetes, autocompletar e suporte a múltiplos documentos. É o motor de editor usado no IDE do FiveWin.

Para detalhes completos do TScintilla, consulte a página dedicada do TScintilla.

Dicas

  • Use TRichEdit para edição de documentos, redação de cartas/memos e qualquer cenário que exija texto formatado.
  • Use TScintilla para editores de código fonte, editores de script e editores de arquivos de configuração.
  • TRichEdit suporta o modo HIGHLIGHT para realce básico de sintaxe de código Harbour, mas TScintilla é muito mais capaz.
  • TScintilla requer SciLexer.dll (ou Scintilla.dll) para estar disponível em tempo de execução.
  • Para TRichEdit, chame SetZoom(2, 1) para zoom de 200% -- útil para telas de alta densidade.
  • Ambos os controles suportam ON CHANGE para detectar modificações em tempo real.

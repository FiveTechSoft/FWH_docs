TTagCloud

Fonte: source/classes/tagcloud.prg

Herda de: TControl

O TTagCloud exibe uma nuvem de tags ponderada onde cada tag é renderizada em um de sete tamanhos de fonte com base em seu peso (frequência). As tags se organizam automaticamente em um layout fluido, destacam-se ao passar o mouse com cor de texto e fundo personalizáveis e respondem a eventos de clique. O controle é ideal para navegação por palavras-chave, navegação por categorias ou qualquer cenário que exija uma lista visualmente ponderada.

Principais Membros DATA

DATATipoDescrição
aItemsArrayMatriz de itens, cada { cText, nPeso, nFontIndex, nOriginalPos }
aFontsArraySete handles de fonte, um por nível de tamanho (maior para menor)
nHLineNumericAltura da linha para quebra de linha de tags (padrão 30)
nClrTextNumericCor padrão do texto da tag
nClrTextOverNumericCor de destaque do texto ao passar o mouse (padrão laranja)
nClrPaneNumericCor de fundo padrão
nClrPaneOverNumericCor de fundo de destaque ao passar o mouse
aCoorsArrayRetângulos delimitadores por item, usados para teste de clique
nMaxDescendNumericDescida máxima da fonte em todas as sete fontes
nOverNumericÍndice do item atualmente com mouse, ou -1 se nenhum

Métodos

MétodoDescrição
New( nTop, nLeft, nW, nH, oWnd, oFont )Criar um novo controle TTagCloud
AddItem( cText, nPeso )Adicionar uma tag com texto e valor de peso
AsignFonts()Atribuir índices de tamanho de fonte aos itens com base nos pesos ordenados
GetFonts()Construir os sete tamanhos de fonte a partir da fonte base atual

Exemplo: Nuvem de Tags com Três Tags

#include "FiveWin.ch"

function Main()

   local oWnd, oTagCloud

   DEFINE WINDOW oWnd TITLE "Tag Cloud" SIZE 400, 300

   oTagCloud := TTagCloud():New( 10, 10, 360, 240, oWnd )

   oTagCloud:AddItem( "FiveWin", 95 )
   oTagCloud:AddItem( "Harbour", 80 )
   oTagCloud:AddItem( "xHarbour", 60 )
   oTagCloud:AsignFonts()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • As tags são ordenadas internamente por peso. O peso mais alto recebe a maior fonte (nível 1) e os pesos mais baixos descem pelos níveis 2-7.
  • Chame AsignFonts() após adicionar todos os itens para atribuir tamanhos de fonte correspondentes. As fontes são criadas uma vez por GetFonts() durante New().
  • O rastreamento de passagem do mouse é tratado por MouseMove, que define nOver e aciona Refresh() para repintar a tag destacada.
  • Clicar em uma tag (LButtonUp padrão) produz o texto da tag. Sobrescreva bLClicked ou subclassifique LButtonUp para ações de clique personalizadas.

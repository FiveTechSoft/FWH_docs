TClipGet

Source: source/classes/tclipget.prg

Inherits from: TGet

TClipGet is a clipboard-aware GET control that extends the standard TGet with enhanced clipboard operations. It is created via the convenience function FWGetNew() which returns a configured GET object. TClipGet provides standard cut, copy, and paste behavior with proper handling of formatted clipboard content.

Key DATA Members

TClipGet inherits all DATA members from TGet including bVar, cVar, cPicture, cColor, and standard edit control properties. It does not introduce additional DATA members beyond the TGet inheritance chain.

Methods

Method / FunctionDescription
FWGetNew( nRow, nCol, bVar, cVar, cPic, cColor )Convenience function that creates and returns a TClipGet object bound to a variable with optional picture and color clauses.

Example: Clipboard-Enabled GET

#include "FiveWin.ch"

function Main()

   local oWnd, oGet
   local cName := Space( 30 )

   DEFINE WINDOW oWnd TITLE "Clipboard GET" SIZE 400, 150

   @ 40, 20 GET oGet VAR cName SIZE 200, 20 OF oWnd

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TClipGet inherits all standard TGet clipboard functionality: Ctrl+C copies, Ctrl+V pastes, Ctrl+X cuts. The class adds safeguards for formatted clipboard content.
  • The FWGetNew() function provides a compact one-call constructor alternative to the standard @ ... GET command syntax.
  • Like all TGet-based controls, the picture clause (cPicture) controls input masking and formatting. Standard TGet picture tokens (9, N, A, !, etc.) apply.
  • Use SET GET oGet FOCUS to give keyboard focus to the TClipGet control programmatically.

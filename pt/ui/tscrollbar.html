TScrollBar

Fonte: source/classes/scrllbar.prg

Herda de: TControl

TScrollBar é um controle de barra de rolagem independente que pode ser colocado autonomamente dentro de uma janela ou diálogo. Diferente das barras de rolagem automáticas de janela, TScrollBar é um objeto de controle que dispara blocos de ação quando o usuário rola, tornando-o adequado para painéis de navegação personalizados, seletores de intervalo e contêineres roláveis.

Membros DATA Principais

DATATipoDescrição
nMinNuméricoValor mínimo da barra de rolagem
nMaxNuméricoValor máximo da barra de rolagem
nPgStepNuméricoIncremento de passo de página para a barra de rolagem
lVerticalLógico.T. para barra vertical, .F. para horizontal
bGoUpBlocoAção no incremento pequeno (seta para baixo / seta para direita)
bGoDownBlocoAção no decremento pequeno
bGoTopBlocoAção ao atingir o extremo superior/esquerdo
bGoBottomBlocoAção ao atingir o extremo inferior/direito
bPageUpBlocoAção no incremento de página (clique acima do polegar)
bPageDownBlocoAção no decremento de página

Métodos

MétodoDescrição
New( nRow, nCol, nMin, nMax, nPgStep, lVert, oWnd )Criar um novo controle de barra de rolagem
WinNew( nMin, nMax, nPgStep, lVert, oWnd )Criar uma barra de rolagem usando coordenadas de janela
GoUp()Rolar para cima/direita um passo
GoDown()Rolar para baixo/esquerda um passo
GoTop()Rolar para a posição mínima
GoBottom()Rolar para a posição máxima
PageUp()Rolar para cima um passo de página
PageDown()Rolar para baixo um passo de página
SetPos( n )Definir a posição do polegar para n
GetPos()Retornar a posição atual do polegar

Exemplo: Barra de Rolagem Vertical Vinculada a um Browse

#include "FiveWin.ch"

function Main()

   local oWnd, oScroll, nPos := 1

   DEFINE WINDOW oWnd TITLE "ScrollBar Demo" SIZE 300, 300

   @ 10, 260 SCROLLBAR oScroll ;
      RANGE 1, 100 ;
      PAGE 10 ;
      VERTICAL OF oWnd ;
      ON UP nPos-- ;
      ON DOWN nPos++

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use a cláusula VERTICAL para uma barra de rolagem vertical; omita-a ou use HORIZONTAL para uma barra horizontal.
  • A cláusula RANGE define nMin e nMax. A cláusula PAGE define nPgStep.
  • Os blocos de ação (ON UP, ON DOWN, ON PAGEUP, ON PAGEDN) são disparados quando o usuário interage com as regiões correspondentes da barra de rolagem.
  • TScrollBar é ideal para rolagem personalizada em controles tipo browse onde as barras de rolagem incorporadas da janela não são utilizadas.

TReBar

Fonte: source/classes/rebar.prg

Herda de: TControl

TReBar encapsula o controle comum rebar/coolbar do Windows para criar um contêiner que hospeda múltiplas janelas filhas em faixas redimensionáveis. Cada faixa pode conter uma barra de ferramentas, um combobox ou qualquer outro controle, e pode ser reorganizada ou redimensionada pelo usuário em tempo de execução através de uma alça de agarre na borda esquerda de cada faixa.

Principais Membros DATA

DATATipoDescrição
aBandsArrayArray de definições de faixas (controles e texto)

Métodos

MétodoDescrição
New( oWnd )Criar um novo controle TReBar anexado a uma janela
InsertBand( oControl, cText )Inserir uma nova faixa contendo oControl com texto de legenda opcional

Exemplo: Rebar com Duas Faixas de Barra de Ferramentas

#include "FiveWin.ch"

function Main()

   local oWnd, oReBar, oBar1, oBar2

   DEFINE WINDOW oWnd TITLE "ReBar Demo" SIZE 600, 400

   oReBar := TReBar():New( oWnd )

   DEFINE BUTTONBAR oBar1 _3D OF oWnd SIZE 30, 30
   DEFINE BUTTON OF oBar1 RESOURCE "new.bmp"   ACTION MsgInfo( "New" )
   DEFINE BUTTON OF oBar1 RESOURCE "open.bmp"  ACTION MsgInfo( "Open" )
   DEFINE BUTTON OF oBar1 RESOURCE "save.bmp"  ACTION MsgInfo( "Save" )

   DEFINE BUTTONBAR oBar2 _3D OF oWnd SIZE 30, 30
   DEFINE BUTTON OF oBar2 RESOURCE "cut.bmp"   ACTION MsgInfo( "Cut" )
   DEFINE BUTTON OF oBar2 RESOURCE "copy.bmp"  ACTION MsgInfo( "Copy" )
   DEFINE BUTTON OF oBar2 RESOURCE "paste.bmp" ACTION MsgInfo( "Paste" )

   oReBar:InsertBand( oBar1, "File" )
   oReBar:InsertBand( oBar2, "Edit" )

   oWnd:oClient := oReBar

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Cada faixa no rebar exibe uma alça no lado esquerdo, permitindo ao usuário arrastar e reordenar faixas em tempo de execução.
  • Faixas também podem ser redimensionadas arrastando a borda direita da área de legenda da faixa.
  • O parâmetro cText em InsertBand() torna-se o texto da legenda/rótulo da faixa, exibido à esquerda do controle incorporado.
  • Definir oWnd:oClient := oReBar faz o rebar abranger toda a largura da janela abaixo do menu e acima da área de cliente.
  • TReBar é ideal para aplicativos que oferecem múltiplas barras de ferramentas personalizáveis em um layout compacto e eficiente em espaço.

TTabControl

Fonte: source/classes/ttabctrl.prg

Herda de: TControl

TTabControl encapsula o controle comum padrão do Windows SysTabControl32. Ele exibe uma linha de abas selecionáveis, cada uma com um rótulo, e notifica a aplicação quando o usuário clica em uma aba através de um code block de ação. TTabControl é um controle de abas leve sem gerenciamento de páginas embutido — ele dispara uma ação na mudança de seleção e deixa a lógica de troca de páginas para a aplicação. Para troca automática de páginas, veja TTabs ou TPages.

Membros DATA Principais

DATATipoDescrição
aPromptsArrayArray de strings de caracteres exibidas como rótulos das abas.
bActionBlockCode block avaliado quando o usuário clica em uma aba: { |nOption, oCtrl| ... }.
nOptionNumericÍndice da aba atualmente selecionada (começando em 1).
nClrTextNumericCor do texto dos rótulos das abas (valor RGB).
nClrPaneNumericCor de preenchimento do fundo (valor RGB).
hFontNumeric (Handle)Handle da fonte usada para o texto dos rótulos das abas.
oFontTFontObjeto de fonte usado para o texto dos rótulos das abas.
cMsgCharacterTexto da barra de mensagens exibido quando o controle de abas recebe o foco.

Métodos

MétodoDescrição
New( nRow, nCol, aPrompts, bAction, oWnd, nClrT, nClrP, oFont, lPixel, lDesign, nW, nH, cMsg )Cria um novo controle de abas. aPrompts é um array de strings de rótulos das abas. bAction é chamado na seleção da aba.
ReDefine( nId, oWnd )Redefine a partir de um recurso de diálogo. Vincula-se a um SysTabControl32 existente pelo seu ID de controle.
Add( cPrompt )Adiciona uma nova aba ao final com o texto de rótulo fornecido.
DelItem( nItem )Remove a aba na posição nItem (começando em 1).
SetPrompts( aPrompts )Substitui todos os rótulos das abas por um novo array de strings.
SetOption( nOption )Seleciona programaticamente uma aba pelo seu índice.
End()Destrói o controle.

Comandos: @ ... TAB

@ nRow, nCol TAB oTab ;
   ITEMS aItems ;
   [ SIZE nW, nH ] ;
   [ OF oDlg ] ;
   [ ACTION bAction ] ;
   [ ON CHANGE bChange ] ;
   [ COLOR nClrText, nClrPane ]

Exemplo: Controle com 3 Abas e Ação

#include "FiveWin.ch"

function Main()

   local oWnd, oTab
   local aPrompts := { "General", "Details", "Settings" }

   DEFINE WINDOW oWnd TITLE "TTabControl Demo" SIZE 500, 400

   @ 10, 10 TAB oTab ITEMS aPrompts ;
      SIZE 460, 50 OF oWnd ;
      ACTION MsgInfo( "Selected tab: " + Str( oTab:nOption ) )

   @ 80, 20 SAY "Content area for tab " + Str( oTab:nOption ) ;
      OF oWnd SIZE 300, 20

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTabControl herda de TControl. Todos os métodos padrão de controle estão disponíveis.
  • Diferente de TTabs (que gerencia controles filhos através da troca de páginas), TTabControl encapsula apenas a faixa de abas em si. A aplicação deve tratar as mudanças de conteúdo em resposta a bAction.
  • Use nOption para ler o índice da aba atualmente selecionada a qualquer momento, ou SetOption() para alterá-lo programaticamente.
  • Os rótulos das abas são definidos via aPrompts no construtor ou SetPrompts() em tempo de execução. Abas individuais podem ser adicionadas ou removidas com Add() e DelItem().
  • Para gerenciamento automático de páginas com controles filhos que aparecem/ocultam com base na aba selecionada, use TFolder em vez disso.
  • As abas podem ser reposicionadas em tempo de design usando Move(), SetSize() e SetPos().

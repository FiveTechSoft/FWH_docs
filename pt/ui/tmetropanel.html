TMetroPanel

Fonte: source/classes/metropnl.prg

Herda de: TPanel

TMetroPanel implements a Windows 8-style Metro start panel with tile groups that scroll horizontally. It arranges TMetroBtn tiles into groups and rows, providing a touch-friendly interface with drag-to-scroll, mouse-wheel support, and a custom scrollbar. Each tile can be a large or small button with an image, caption, and action. TMetroBtn (child class from TBtnBmp) represents an individual Metro tile with configurable alignment, text overlay, and group membership.

Exemplo: Painel Metro com Dois Grupos

#include "FiveWin.ch"

function Main()

   local oWnd, oMetro

   DEFINE WINDOW oWnd TITLE "Metro Panel" SIZE 800, 600

   DEFINE METROPANEL oMetro OF oWnd TITLE "Start" ;
      COLOR CLR_WHITE, RGB( 30, 30, 120 ) ;
      ON CLICK oWnd:End()

   // Group 1: Communication tiles
   oMetro:AddButton( .T., 1, "Email", { || MsgInfo( "Email" ) }, ;
                     CLR_WHITE, RGB( 0, 120, 200 ),, , , , 64, 64 )

   oMetro:AddButton( .F., 1, "Calendar", { || MsgInfo( "Calendar" ) }, ;
                     CLR_WHITE, RGB( 200, 50, 50 ) )

   // Group 2: Productivity tiles
   oMetro:AddButton( .T., 2, "Documents", { || MsgInfo( "Docs" ) }, ;
                     CLR_WHITE, RGB( 50, 150, 50 ),, , , , 64, 64 )

   oMetro:AddButton( .F., 2, "Settings", { || MsgInfo( "Settings" ) }, ;
                     CLR_WHITE, RGB( 80, 80, 80 ) )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Observações

  • O TMetroPanel requer o comando DEFINE METROPANEL e usa fontes "Segoe UI Light" para a estética Metro.
  • Os blocos são organizados em grupos separados por um intervalo de 32 pixels. Cada grupo distribui os blocos em linhas com base em nMetroRows (calculado a partir da altura da tela).
  • Blocos grandes (lLarge := .T.) ocupam duas posições de coluna, permitindo uma mistura de blocos grandes e pequenos no mesmo grupo.
  • A rolagem horizontal é tratada por uma barra de rolagem personalizada na parte inferior. Arrastar-para-rolar e roda do mouse são suportados.
  • Use lDesignMode := .T. para habilitar recursos de tempo de design, como reposicionamento de blocos via MoveBtn().
  • O TMetroBtn herda de TBtnBmp e suporta carregamento de imagem de arquivo ou recurso, com alinhamento e dimensionamento de bitmap configuráveis.

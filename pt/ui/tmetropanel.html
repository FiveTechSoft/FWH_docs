TMetroPanel

Fonte: source/classes/metropnl.prg

Herda de: TPanel

TMetroPanel implementa um painel inicial estilo Metro do Windows 8 com grupos de blocos que rolam horizontalmente. Organiza os blocos TMetroBtn em grupos e linhas, fornecendo uma interface amigável ao toque com rolagem por arrasto, suporte à roda do mouse e uma barra de rolagem personalizada. Cada bloco pode ser um botão grande ou pequeno com imagem, legenda e ação. TMetroBtn (subclasse de TBtnBmp) representa um bloco Metro individual com alinhamento configurável, sobreposição de texto e associação a grupo.

Exemplo: Painel Metro com Dois Grupos

#include "FiveWin.ch"

function Main()

   local oWnd, oMetro

   DEFINE WINDOW oWnd TITLE "Metro Panel" SIZE 800, 600

   DEFINE METROPANEL oMetro OF oWnd TITLE "Start" ;
      COLOR CLR_WHITE, RGB( 30, 30, 120 ) ;
      ON CLICK oWnd:End()

   // Grupo 1: Blocos de comunicacao
   oMetro:AddButton( .T., 1, "Email", { || MsgInfo( "Email" ) }, ;
                     CLR_WHITE, RGB( 0, 120, 200 ),, , , , 64, 64 )

   oMetro:AddButton( .F., 1, "Calendar", { || MsgInfo( "Calendar" ) }, ;
                     CLR_WHITE, RGB( 200, 50, 50 ) )

   // Grupo 2: Blocos de produtividade
   oMetro:AddButton( .T., 2, "Documents", { || MsgInfo( "Docs" ) }, ;
                     CLR_WHITE, RGB( 50, 150, 50 ),, , , , 64, 64 )

   oMetro:AddButton( .F., 2, "Settings", { || MsgInfo( "Settings" ) }, ;
                     CLR_WHITE, RGB( 80, 80, 80 ) )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Notas

  • TMetroPanel requer o comando DEFINE METROPANEL e usa fontes "Segoe UI Light" para a estética Metro.
  • Os blocos são organizados em grupos separados por um espaço de 32 pixels. Cada grupo distribui blocos em linhas baseado em nMetroRows (calculado da altura da tela).
  • Blocos grandes (lLarge := .T.) ocupam duas posições de coluna, permitindo uma mistura de blocos grandes e pequenos no mesmo grupo.
  • A rolagem horizontal é gerenciada por uma barra de rolagem personalizada na parte inferior. Arrastar para rolar e roda do mouse são suportados.
  • Use lDesignMode := .T. para habilitar funcionalidades de tempo de design como reposicionamento de blocos via MoveBtn().
  • TMetroBtn herda de TBtnBmp e suporta carregamento de imagem de arquivo ou recurso, com alinhamento e dimensionamento de bitmap configuráveis.

TUpDown

Fonte: source/classes/tupdown.prg

Herda de: TControl

TUpDown encapsula o controle comum up-down do Win32, também conhecido como spinner ou controle buddy. Geralmente é associado a um campo TGet para fornecer botões de seta de incremento/decremento que atualizam automaticamente o valor do buddy dentro de um intervalo configurável.

Membros DATA Principais

DATATipoDescrição
nMinNuméricoValor mínimo do intervalo do spinner
nMaxNuméricoValor máximo do intervalo do spinner
nPosNuméricoPosição atual do spinner
oBuddyObjetoO controle buddy (geralmente um TGet) vinculado a este spinner
lWrapLógicoDá a volta ao atingir o limite do intervalo
nAlignNuméricoAlinhamento relativo ao buddy: 0=direita, 1=esquerda

Métodos

MétodoDescrição
New( nRow, nCol, oWnd, oBuddy, nW, nH, nMin, nMax, nPos )Cria um novo controle up-down
SetPos( n )Define a posição do spinner como n
GetPos()Retorna a posição atual do spinner
SetRange( nMin, nMax )Define os valores mínimo e máximo do intervalo
SetBuddy( oBuddy )Anexa um controle buddy ao spinner
GetBuddy()Retorna o controle buddy atualmente anexado

Exemplo: Spinner Vinculado a um Campo GET

#include "FiveWin.ch"

function Main()

   local oWnd, oGet, oSpinner, nVal := 5

   DEFINE WINDOW oWnd TITLE "Quantidade" SIZE 300, 150

   @ 40, 20 GET oGet VAR nVal SIZE 60, 20 OF oWnd PICTURE "999"
   @ 38, 80 UPDOWN oSpinner BUDDY oGet ;
      RANGE 1, 100

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O controle buddy é definido automaticamente como a janela especificada na cláusula BUDDY. O controle up-down posiciona-se adjacente ao buddy.
  • Quando lWrap está definido como .T., clicar para cima em nMax dá a volta para nMin e vice-versa.
  • A cláusula RANGE define nMin e nMax simultaneamente.
  • TUpDown usa o estilo UDS_SETBUDDYINT do Win32 para atualizar automaticamente o valor exibido do controle buddy.

TTabs

Fonte: source/classes/tabs.prg

Herda de: TControl

TTabs é um controle de barra de abas desenhado de forma personalizada que exibe uma linha ou coluna de abas selecionáveis. Diferentemente de TFolder, TTabs renderiza apenas a faixa de abas em si, sem um contêiner de página integrado. Suporta orientações horizontais (topo/base) e verticais (esquerda/direita), rótulos com bitmaps e navegação por teclado.

Membros DATA Principais

DATATipoDescrição
aPromptsArrayArray de strings de rótulos das abas
nOptionNuméricoÍndice da aba atualmente selecionada (base 1)
nOrientationNuméricoOrientação da aba: OR_TOP, OR_BOTTOM, OR_LEFT, OR_RIGHT
acBitmapsArrayArray de handles de bitmap ou nomes de arquivo para cada aba

Métodos

MétodoDescrição
New( nTop, nLeft, aPrompts, bAction, oWnd, nOption )Cria um novo controle de barra de abas
SetOption( n )Seleciona a aba no índice n
AddItem( cPrompt )Adiciona uma nova aba com o texto de rótulo fornecido
DelItem( nIndex )Remove a aba no índice especificado
SetTabs( aTabs )Substitui todas as definições de abas de uma vez
GoTop()Seleciona a primeira aba
GoLeft()Seleciona a aba à esquerda
GoBottom()Seleciona a última aba
GoRight()Seleciona a aba à direita

Exemplo: Barra com 3 Abas

#include "FiveWin.ch"

function Main()

   local oWnd, oTabs, nOpt := 1

   DEFINE WINDOW oWnd TITLE "TTabs Demo" SIZE 500, 300

   @ 10, 10 TAB oTabs PROMPTS "Files", "Edit", "View" ;
      SIZE 460, 30 OF oWnd ACTION oWnd:Refresh()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTabs é uma faixa de abas independente. Combine-a com TPages ou um mecanismo de troca de diálogos para construir uma interface completa com abas.
  • As constantes de orientação são OR_TOP (padrão), OR_BOTTOM, OR_LEFT e OR_RIGHT.
  • Use acBitmaps para atribuir imagens bitmap a abas individuais. Os bitmaps podem ser especificados como nomes de arquivo ou handles de recurso.
  • O bloco de código bAction é avaliado toda vez que uma aba diferente é selecionada.

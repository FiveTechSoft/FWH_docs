TButton / TBtnBmp

Botões padrão e botões com bitmap para diálogos e barras de ferramentas

TButton

Fonte: source/classes/button.prg  |  Pai: TControl

TButton encapsula o controle padrão de botão do Windows. É o elemento interativo mais básico -- um retângulo com rótulo que executa uma ação quando clicado. Botões podem ser designados como o botão padrão (ativado pelo Enter) ou o botão de cancelar (ativado pelo Escape).

Propriedades de TButton

PropriedadeTipoDescrição
bActionBlockBloco de código executado quando o botão é clicado
lDefaultLogicalSe .T., este é o botão padrão (tecla Enter o ativa)
lCancelLogicalSe .T., este é o botão de cancelar (tecla Escape o ativa)
cCaptionStringTexto exibido na face do botão
lProcessingLogicalGuarda interna de reentrância -- impede que cliques duplos disparem a ação duas vezes

Métodos de TButton

MétodoDescrição
New( nRow, nCol, cCaption, oWnd, bAction, nWidth, nHeight, ... )Construtor. Cria um novo botão na posição indicada.
ReDefine( nId, bAction, oWnd, ... )Redefine um botão a partir de um recurso de diálogo (arquivo RC).
Click()Dispara programaticamente a ação do botão.
SetFocus()Move o foco do teclado para este botão.

Sintaxe de Comando TButton

@ nRow, nCol BUTTON oBtn PROMPT "text" ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ACTION codeblock ] ;
   [ DEFAULT ] ;
   [ CANCEL ] ;
   [ FONT oFont ] ;
   [ WHEN bWhen ]

TBtnBmp

Fonte: source/classes/btnbmp.prg  |  Pai: TControl

TBtnBmp é um botão com bitmap desenhado pelo proprietário que suporta múltiplos estados visuais (normal, pressionado, mouse sobre, desabilitado). É o tipo de botão usado em barras de ferramentas (TButtonBar) e em qualquer lugar onde você precise de botões gráficos com ícones.

Propriedades de TBtnBmp

PropriedadeTipoDescrição
cResNameStringNome do recurso para o bitmap do botão
cBmpFileStringCaminho para um arquivo BMP/PNG externo para a imagem do botão
bActionBlockBloco de código executado ao clicar
lBtnUpLogicalEstado atual de pressionamento (interno)
lGroupLogicalSe .T., inicia um novo grupo de botões na barra de ferramentas
lPressedLogicalPara botões estilo toggle, indica o estado ativado
cToolTipStringTexto do tooltip exibido ao passar o mouse
lFlatLogicalAparência flat (borda apenas ao passar o mouse)

Sintaxe de Comando TBtnBmp

@ nRow, nCol BTNBMP oBtn ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ACTION codeblock ] ;
   [ FILENAME cBmpFile | RESOURCE cResName ] ;
   [ TOOLTIP cText ] ;
   [ FLAT ] ;
   [ PROMPT cText ] ;
   [ WHEN bWhen ]

BUTTONBAR (Barra de Ferramentas)

O comando DEFINE BUTTONBAR cria um contêiner TButtonBar que hospeda botões TBtnBmp como uma barra de ferramentas no topo de uma janela.

DEFINE BUTTONBAR oBar OF oWnd SIZE nBtnW, nBtnH [ 2007 | 2010 | 2013 | 2015 ]

DEFINE BUTTON oBtn1 OF oBar ;
   RESOURCE "NEW" ;
   TOOLTIP "New record" ;
   ACTION NewRecord()

DEFINE BUTTON oBtn2 OF oBar ;
   RESOURCE "EDIT" ;
   TOOLTIP "Edit record" ;
   ACTION EditRecord()

DEFINE BUTTON oBtn3 OF oBar ;
   RESOURCE "PRINT" ;
   TOOLTIP "Print report" ;
   ACTION PrintReport() ;
   GROUP                      // visual separator before this button

Exemplos de Código

Exemplo 1: Botões Padrão de Diálogo

#include "FiveWin.ch"

FUNCTION TestButtons()
   LOCAL oDlg, oBtn1, oBtn2

   DEFINE DIALOG oDlg TITLE "Button Demo" SIZE 400, 250

   @ 2, 2 BUTTON oBtn1 PROMPT "&Save" ;
      OF oDlg SIZE 80, 25 ;
      ACTION ( MsgInfo( "Saved!" ), oDlg:End() ) ;
      DEFAULT

   @ 2, 12 BUTTON oBtn2 PROMPT "&Cancel" ;
      OF oDlg SIZE 80, 25 ;
      ACTION oDlg:End() ;
      CANCEL

   // A button with a WHEN clause -- disabled until data is valid
   @ 4, 2 BUTTON PROMPT "&Delete" ;
      OF oDlg SIZE 80, 25 ;
      ACTION DeleteRecord() ;
      WHEN ( !Empty( cRecId ) )

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

Exemplo 2: Botões com Bitmap

#include "FiveWin.ch"

FUNCTION TestBmpButtons()
   LOCAL oWnd, oBtn

   DEFINE WINDOW oWnd TITLE "Bitmap Button Demo"

   // Bitmap button from a file
   @ 2, 2 BTNBMP oBtn OF oWnd ;
      SIZE 120, 40 ;
      FILENAME "..\bitmaps\save.bmp" ;
      PROMPT "Save" ;
      ACTION MsgInfo( "Saving..." ) ;
      FLAT

   // Bitmap button from a resource
   @ 5, 2 BTNBMP OF oWnd ;
      SIZE 120, 40 ;
      RESOURCE "PRINT" ;
      PROMPT "Print" ;
      ACTION PrintReport() ;
      TOOLTIP "Print current report"

   ACTIVATE WINDOW oWnd
RETURN NIL

Exemplo 3: Barra de Ferramentas Completa

#include "FiveWin.ch"

FUNCTION Main()
   LOCAL oWnd, oBar

   DEFINE WINDOW oWnd TITLE "Application with Toolbar"

   DEFINE BUTTONBAR oBar OF oWnd SIZE 56, 56 2015

   DEFINE BUTTON OF oBar ;
      RESOURCE "NEW"   TOOLTIP "New"   ACTION NewDoc()
   DEFINE BUTTON OF oBar ;
      RESOURCE "OPEN"  TOOLTIP "Open"  ACTION OpenDoc()
   DEFINE BUTTON OF oBar ;
      RESOURCE "SAVE"  TOOLTIP "Save"  ACTION SaveDoc()

   DEFINE BUTTON OF oBar ;
      RESOURCE "PRINT" TOOLTIP "Print" ACTION PrintDoc() GROUP

   DEFINE BUTTON OF oBar ;
      RESOURCE "HELP"  TOOLTIP "Help"  ACTION HelpDoc() GROUP

   SET MESSAGE OF oWnd TO "Ready" CENTERED

   ACTIVATE WINDOW oWnd
RETURN NIL

Dicas

  • Use & no PROMPT para definir uma tecla de atalho: "&Save" faz Alt+S ativar o botão.
  • Apenas um botão por diálogo deve ser DEFAULT e um deve ser CANCEL.
  • Para um visual moderno de barra de ferramentas, use o estilo 2015 no DEFINE BUTTONBAR.
  • TBtnBmp suporta arquivos PNG com transparência alfa para ícones de alta qualidade.
  • Use a cláusula GROUP para inserir um separador visual entre grupos lógicos de botões na barra de ferramentas.

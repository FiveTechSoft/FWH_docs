THorzScroll

Fonte: source/classes/hrzscrol.prg

Herda de: TPanel

THorzScroll estende TPanel com uma barra de rolagem horizontal incorporada que percorre uma coleção de painéis filhos. É projetado para layouts horizontalmente roláveis como fileiras de cartões de painel, painéis de ferramentas ou galerias de imagens onde o conteúdo excede a largura visível.

Principais Membros DATA

DATATipoDescrição
oHScrollObjectObjeto TScrollBar que gerencia a barra de rolagem horizontal
nHPosNumericPosição atual de rolagem horizontal
nMaxWidthNumericLargura total do conteúdo; determina o intervalo de rolagem
aPanelsArrayArray de objetos TPanel filhos gerenciados pelo contêiner
nBetweenNumericEspaçamento em pixels entre painéis consecutivos (padrão 10)
lBorderLogicalExibe uma borda ao redor do contêiner
nClrBorderNumericCor da borda (valor RGB)

Métodos

MétodoDescrição
New( nTop, nLeft, nBottom, nRight, oWnd, nClrPane, lHScroll, lBorder, nClrBorder )Cria um novo painel de rolagem horizontal
Redefine( nId, oWnd, nClrPane, lHScroll, lBorder, nClrBorder )Redefine a partir de um recurso de diálogo
AddPanel( nWidth, nClrBack )Adiciona um painel filho à área rolável; retorna o objeto do painel
RemovePanel( xParam )Remove um painel filho por índice ou referência de objeto
HScroll( nCode )Trata eventos de rolagem (linha à esquerda/direita)
UpdateScrollRange()Recalcula o intervalo da barra de rolagem após adicionar/remover painéis
StartSmoothScroll( nNewPos )Inicia rolagem suave animada até uma posição alvo

Exemplo: Painel de Rolagem Horizontal

#include "FiveWin.ch"

function Main()

   local oWnd, oHS, oP1, oP2, oP3

   DEFINE WINDOW oWnd TITLE "THorzScroll Demo" SIZE 600, 200

   @ 10, 10 PANEL oHS OF oWnd SIZE 560, 150

   oP1 := oHS:AddPanel( 150, CLR_RED )
   oP2 := oHS:AddPanel( 150, CLR_GREEN )
   oP3 := oHS:AddPanel( 150, CLR_BLUE )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • THorzScroll cria internamente um TScrollBar via ::oHScroll com blocos de código associados para rolagem de linha, página e arrasto do cursor.
  • Use AddPanel() para anexar painéis filhos. Cada painel é dimensionado de acordo com nWidth e posicionado automaticamente com o espaçamento nBetween.
  • UpdateScrollRange() recalcula nMaxWidth a partir da largura total de todos os painéis filhos para definir o máximo da barra de rolagem.
  • O método MouseWheel suporta rolagem horizontal através da roda do mouse quando o painel está em foco.

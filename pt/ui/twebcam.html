TWebcam

Fonte: source/classes/twebcam.prg

Hierarquia: TWebcam → TControl

TWebcam fornece visualização ao vivo de webcam e funcionalidade de captura usando a API Video for Windows (VFW). É um controle visual que exibe o feed da câmera dentro de uma janela FiveWin e suporta captura de instantâneos, diálogos de formato de vídeo e configuração de fonte de vídeo.

Comando WEBCAM

@ nRow, nCol WEBCAM oCam OF oWnd SIZE nW, nH INIT lInit

Métodos Principais

MétodoDescrição
New( oWnd, nTop, nLeft, nWidth, nHeight, lInit, lAdjust, nRate, bError )Construtor. Cria a janela de captura VFW e opcionalmente inicia a visualização.
Initialize()Conectar o driver da webcam e iniciar a visualização ao vivo.
Finalize()Desconectar o driver da webcam e parar a visualização.
SaveFile( cFileName )Capturar o quadro atual para um arquivo BMP. Padrão é um nome de arquivo baseado em timestamp.
VideoControl()Abrir o diálogo de propriedades da fonte de vídeo (brilho, contraste, etc.).
VideoFormat()Abrir o diálogo de formato de vídeo (resolução, profundidade de cor).
StartCapture( cFile )Iniciar captura de streaming para um arquivo de vídeo.
StopCapture()Parar qualquer captura de vídeo em andamento.
GetWidth()Retornar a largura atual da imagem de visualização em pixels.
GetHeight()Retornar a altura atual da imagem de visualização em pixels.
SetRate( nRate )Definir a taxa de atualização da visualização em milissegundos.

Exemplo: Visualização Ao Vivo com Captura

#include "FiveWin.ch"

function Main()

   local oWnd, oCam, lInit := .T.

   DEFINE WINDOW oWnd TITLE "Webcam Capture" ;
      SIZE 800, 600

   @ 10, 10 WEBCAM oCam OF oWnd SIZE 640, 480 INIT lInit

   @ 500, 10 BUTTON "&Snapshot" SIZE 60, 25 ;
      ACTION oCam:SaveFile( "snap.bmp" )

   @ 500, 80 BUTTON "&Format" SIZE 60, 25 ;
      ACTION oCam:VideoFormat()

   @ 500, 150 BUTTON "&Controls" SIZE 60, 25 ;
      ACTION oCam:VideoControl()

   @ 500, 220 BUTTON "&Close" SIZE 60, 25 ;
      ACTION oWnd:End()

   ACTIVATE WINDOW oWnd ;
      ON INIT oCam:Initialize() ;
      VALID ( oCam:Finalize(), .T. )

return nil

Notas

  • TWebcam depende da API VFW (Video for Windows) legada. Funciona em todas as versões de 32 e 64 bits do Windows através das bibliotecas de sistema avicap32.dll e msvfw32.dll.
  • O controle deve ser criado antes que a janela pai seja ativada; use a cláusula INIT ou chame Initialize() manualmente a partir de ON INIT.
  • Os instantâneos são salvos como arquivos BMP de 24 bits por padrão.
  • Use GetVideoCapDriver() (uma função utilitária em twebcam.prg) para enumerar os dispositivos de webcam disponíveis.
  • Eventos de erro são roteados através do bloco de código bError. O manipulador padrão mostra um diálogo MsgAlert.

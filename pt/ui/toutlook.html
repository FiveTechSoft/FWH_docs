TOutLook

Fonte: source/classes/outlook.prg

Herda de: TControl

TOutLook implementa uma barra de navegação estilo Outlook com grupos recolhíveis contendo itens de navegação com ícone e texto. É comumente usada como painel lateral em aplicações MDI ou SDI para organizar destinos de navegação em categorias lógicas, similar ao painel de pastas do Microsoft Outlook.

Principais Membros DATA

DATATipoDescrição
aGroupArrayArray de objetos de grupo contendo itens
nActualNumericÍndice do item atualmente selecionado

Métodos

MétodoDescrição
New( nTop, nLeft, nW, nH, nClrF, nClrB, nStyle, oFont, lPixel, oWnd )Criar um novo controle TOutLook
AddGroup( cPrompt )Adicionar um novo grupo recolhível com a legenda fornecida
AddItem( cPrompt, cBmp, cRes, bAction, nGroup )Adicionar um item ao grupo especificado
Set( nGroup )Expandir um grupo específico pelo seu índice
DeleteItem( oItem )Remover um item de seu grupo
MoveToGroup( xItem, nGroup )Mover um item (por índice ou referência de objeto) para um grupo diferente
SaveOrder()Retornar a ordem atual de grupo/item como uma string serializada
RestoreOrder( cOrder )Restaurar uma ordem de grupo/item previamente salva

Exemplo: Dois Grupos com Itens

#include "FiveWin.ch"

function Main()

   local oWnd, oOutLook

   DEFINE WINDOW oWnd TITLE "Outlook Bar" SIZE 300, 500

   @ 10, 10 OUTLOOK oOutLook ;
      SIZE 280, 460 OF oWnd

   oOutLook:AddGroup( "Mail" )
   oOutLook:AddItem( "Inbox",    "mail1.ico", , {|| MsgInfo( "Inbox" ) }, 1 )
   oOutLook:AddItem( "Sent",     "mail2.ico", , {|| MsgInfo( "Sent" ) }, 1 )
   oOutLook:AddItem( "Drafts",   "mail3.ico", , {|| MsgInfo( "Drafts" ) }, 1 )

   oOutLook:AddGroup( "Calendar" )
   oOutLook:AddItem( "Today",    "cal1.ico",  , {|| MsgInfo( "Today" ) }, 2 )
   oOutLook:AddItem( "Week",     "cal2.ico",  , {|| MsgInfo( "Week" ) }, 2 )
   oOutLook:AddItem( "Month",    "cal3.ico",  , {|| MsgInfo( "Month" ) }, 2 )

   oOutLook:Set( 1 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Grupos são exibidos como cabeçalhos recolhíveis. Clicar em um cabeçalho de grupo o expande e recolhe o grupo anteriormente expandido.
  • Itens exibem um ícone e uma legenda. O parâmetro cBmp aceita um caminho de arquivo bitmap, nome de recurso ou ícone.
  • O bloco de código bAction em AddItem() é executado quando o usuário clica no item.
  • Use SaveOrder() para persistir a disposição personalizada de grupos/itens do usuário (por exemplo, no registro ou um arquivo INI) e RestoreOrder() para recarregá-la na próxima sessão.
  • O controle gerencia automaticamente a rolagem vertical quando grupos e itens excedem a área visível.

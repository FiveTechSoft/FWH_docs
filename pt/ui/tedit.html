TEdit

Fonte: source/classes/edit.prg

Herda de: TControl

TEdit encapsula o controle EDIT padrão do Windows, suportando edição de texto de linha única e multilinha. Possui formatação com cláusula picture, modo senha, modo somente leitura, textos de sugestão, limites de caracteres e opções de alinhamento (esquerda, direita, centro). TEdit é especialmente útil para texto multilinha onde TGet é muito limitado.

Exemplo: Caixa de Edição Multilinha

#include "FiveWin.ch"

function Main()

   local oWnd, oEdit, cText := MemoRead( "notes.txt" )

   DEFINE WINDOW oWnd TITLE "TEdit Demo" SIZE 600, 400

   @ 10, 10 EDIT oEdit VAR cText ;
      OF oWnd ;
      SIZE 560, 340 ;
      MULTILINE

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Use a cláusula MULTILINE para criar uma caixa de edição multilinha com barras de rolagem vertical e horizontal. O estilo ES_WANTRETURN é aplicado automaticamente no modo multilinha. The ES_WANTRETURN style is automatically applied in multi-line mode.
  • O modo senha desabilita multilinha automaticamente. O estilo ES_PASSWORD mascara a entrada.
  • The cPicture clause applies a picture mask. If the picture contains !, the uppercase style (ES_UPPERCASE) is added.
  • O texto de sugestão (marca d'água) aparece dentro do controle de edição quando está vazio e não tem o foco.

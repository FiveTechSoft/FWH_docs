TFolder

Controle de abas para organizar dialogos complexos em paginas

Fonte: source/classes/folder.prg  |  Parent: TControl

Visão Geral

TFolder implementa um controle de abas do Windows. Cada pagina de aba e um objeto TDialog independente, permitindo colocar qualquer controle em cada pagina usando a sintaxe padrao de dialogos. O folder gerencia qual pagina esta visivel quando o usuario clica em uma aba.

Recursos principais:

  • Cada pagina e um TDialog completo -- qualquer controle pode ser colocado nela
  • Icones nas abas via oImageList
  • Troca de pagina programatica via nOption
  • Abas no topo ou na parte inferior
  • Adicao/remocao dinamica de paginas em tempo de execucao

Propriedades Principais

PropriedadeTipoDescrição
aPromptsArrayArray de strings para cada rotulo de aba (ex.: {"Geral", "Detalhes", "Notas"})
aDialogsArrayArray de objetos TDialog, um por pagina de aba
nOptionNumericIndice da aba atualmente selecionada (base 1). Defina para trocar de pagina programaticamente.
oImageListObjectTImageList opcional fornecendo icones para cada aba
bChangeBlockBloco de codigo executado quando o usuario troca de aba
lBottomLogicalQuando .T., as abas aparecem na parte inferior em vez do topo
nTabHeightNumericAltura da faixa de abas em pixels

Metodos Principais

MetodoDescrição
New( nRow, nCol, oWnd, aPrompts, ... )Construtor. Cria o folder com os rotulos de aba fornecidos.
AddPage( cPrompt, oDlg )Adiciona uma nova pagina em tempo de execucao.
DelPage( nPage )Remove uma pagina em tempo de execucao.
SetOption( n )Troca para a pagina n programaticamente.
GetPage( n )Retorna o TDialog da pagina n.

Sintaxe de Comandos

@ nRow, nCol FOLDER oFld ;
   OF oDlg ;
   PROMPTS "Tab1", "Tab2", "Tab3" ;
   DIALOGS oDlg1, oDlg2, oDlg3 ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ] ;
   [ BOTTOM ]

Cada variavel de dialogo (oDlg1, oDlg2, oDlg3) e criada automaticamente como um TDialog filho. Voce entao coloca os controles em cada dialogo de pagina no bloco ACTIVATE DIALOG.

Exemplos de Codigo

Exemplo 1: Dialogo de Edicao de Cliente com Abas

#include "FiveWin.ch"

FUNCTION CustomerEdit()
   LOCAL oDlg, oFld, oFont
   LOCAL oDlg1, oDlg2, oDlg3
   LOCAL cName   := "John Smith"
   LOCAL cPhone  := "(555)123-4567"
   LOCAL cEmail  := "john@example.com"
   LOCAL cAddr   := "123 Main St"
   LOCAL cCity   := "New York"
   LOCAL cState  := "NY"
   LOCAL cZip    := "10001"
   LOCAL nCredit := 5000.00
   LOCAL cNotes  := "VIP customer since 2015"
   LOCAL lActive := .T.

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14

   DEFINE DIALOG oDlg TITLE "Edit Customer" ;
      SIZE 520, 420 FONT oFont

   // Create the folder with 3 tabs
   @ 0.5, 0.5 FOLDER oFld ;
      OF oDlg ;
      PROMPTS "General", "Address", "Notes" ;
      DIALOGS oDlg1, oDlg2, oDlg3 ;
      SIZE 490, 310

   // --- Page 1: General ---
   @ 1.0, 1 SAY "Name:" OF oDlg1
   @ 1.0, 5 GET cName OF oDlg1 SIZE 200, 22 PICTURE "@!"

   @ 2.5, 1 SAY "Phone:" OF oDlg1
   @ 2.5, 5 GET cPhone OF oDlg1 SIZE 140, 22 PICTURE "(999)999-9999"

   @ 4.0, 1 SAY "Email:" OF oDlg1
   @ 4.0, 5 GET cEmail OF oDlg1 SIZE 220, 22

   @ 5.5, 1 SAY "Credit Limit:" OF oDlg1
   @ 5.5, 5 GET nCredit OF oDlg1 SIZE 120, 22 PICTURE "@E 99,999.99"

   @ 7.0, 1 CHECKBOX lActive PROMPT "Active Customer" OF oDlg1

   // --- Page 2: Address ---
   @ 1.0, 1 SAY "Street:" OF oDlg2
   @ 1.0, 5 GET cAddr OF oDlg2 SIZE 280, 22

   @ 2.5, 1 SAY "City:" OF oDlg2
   @ 2.5, 5 GET cCity OF oDlg2 SIZE 180, 22

   @ 4.0, 1 SAY "State:" OF oDlg2
   @ 4.0, 5 GET cState OF oDlg2 SIZE 40, 22 PICTURE "!!"

   @ 4.0, 9 SAY "ZIP:" OF oDlg2
   @ 4.0, 11 GET cZip OF oDlg2 SIZE 80, 22 PICTURE "99999"

   // --- Page 3: Notes ---
   @ 0.5, 1 GET cNotes MEMO OF oDlg3 SIZE 440, 200

   // Buttons below the folder
   @ 24, 12 BUTTON "&Save"   OF oDlg SIZE 80, 25 ACTION oDlg:End() DEFAULT
   @ 24, 22 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   RELEASE FONT oFont
RETURN NIL

Exemplo 2: Folder com Browse e Troca Dinamica de Paginas

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION DataViewer()
   LOCAL oDlg, oFld, oBrw
   LOCAL oDlg1, oDlg2
   LOCAL aLog := { ;
      { "2026-03-24 09:00", "Login",  "admin" }, ;
      { "2026-03-24 09:15", "Edit",   "admin" }, ;
      { "2026-03-24 10:00", "Export", "user1" }  ;
   }

   DEFINE DIALOG oDlg TITLE "Data Viewer" SIZE 600, 450

   @ 0.2, 0.2 FOLDER oFld ;
      OF oDlg ;
      PROMPTS "Browse Data", "Activity Log" ;
      DIALOGS oDlg1, oDlg2 ;
      SIZE 570, 340

   // Notify when tab changes
   oFld:bChange := {|| MsgBeep() }

   // --- Page 1: XBrowse of a DBF ---
   USE Customer VIA "DBFCDX" NEW
   oBrw := TXBrowse():New( oDlg1 )
   oBrw:SetRDD()
   oBrw:CreateFromCode()
   oDlg1:oClient := oBrw

   // --- Page 2: XBrowse of an array ---
   LOCAL oBrw2 := TXBrowse():New( oDlg2 )
   oBrw2:SetArray( aLog )
   oBrw2:aCols := {}
   oBrw2:AddColumn( "Timestamp", {|| aLog[ oBrw2:nArrayAt ][ 1 ] } )
   oBrw2:AddColumn( "Action",    {|| aLog[ oBrw2:nArrayAt ][ 2 ] } )
   oBrw2:AddColumn( "User",      {|| aLog[ oBrw2:nArrayAt ][ 3 ] } )
   oBrw2:CreateFromCode()
   oDlg2:oClient := oBrw2

   // Buttons
   @ 27, 18 BUTTON "&Close" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   // Jump to Activity Log tab programmatically
   @ 27, 2 BUTTON "Show &Log" OF oDlg SIZE 100, 25 ;
      ACTION oFld:SetOption( 2 )

   ACTIVATE DIALOG oDlg CENTERED

   CLOSE Customer
RETURN NIL

Dicas

  • Coloque os controles em cada dialogo de pagina (oDlg1, oDlg2, ...) -- nao no dialogo pai oDlg.
  • Botoes que devem permanecer visiveis em todas as abas (Salvar, Cancelar) vao no dialogo pai, posicionados abaixo do folder.
  • Use oFld:SetOption( n ) para trocar de aba via codigo, por exemplo em resposta a um clique de botao.
  • Use bChange para atualizar dados quando o usuario troca de aba (ex.: atualizar um browse em uma aba).
  • Para adicionar icones nas abas, crie um TImageList e atribua a oFld:oImageList antes da ativacao.
  • Cada dialogo de pagina herda a fonte do dialogo pai, portanto defina a fonte no pai para manter a consistencia.

Veja Também

  • TControl -- classe pai
  • TGet -- comumente usado dentro de paginas do folder

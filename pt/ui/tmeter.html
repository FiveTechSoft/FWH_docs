TMeter

Fonte: source/classes/meter.prg

Herda de: TControl

TMeter é um controle de medidor de progresso que exibe o status de conclusão de uma operação demorada. Suporta três estilos de renderização: barra retangular padrão, medidor circular e array de bitmaps. O medidor pode exibir um rótulo de texto e a porcentagem, com cores de primeiro plano e de fundo personalizáveis.

Exemplo: Progresso Circular

#include "FiveWin.ch"

function Main()

   local oWnd, oMeter, nVal := 0

   DEFINE WINDOW oWnd TITLE "Circular Meter Demo" SIZE 400, 300

   @ 10, 10 METER oMeter VAR nVal TOTAL 100 ;
      OF oWnd SIZE 120, 120 CIRCULAR ;
      COLORS CLR_HGREEN, CLR_WHITE, CLR_GRAY

   DEFINE TIMER oTimer OF oWnd INTERVAL 100 ;
      ACTION ( nVal++,;
               oMeter:Set( nVal ),;
               If( nVal >= 100, oTimer:End(), ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O codeblock bSetGet fornece uma ligação bidirecional a uma variável numérica. Ele é avaliado para ler o valor atual e recebe uma atribuição quando o valor muda.
  • O estilo circular é ativado passando .T. para lCircular em New(), o que define cStyle como "CIRCULAR".
  • O estilo de array de bitmaps é ativado por lBmpArray := .T., o que define cStyle como "BMPARRAY".
  • Use Set() para atualizar a posição do progresso; o medidor é redesenhado automaticamente.
  • Para medidores circulares, nInnerDia controla o tamanho do furo de um medidor estilo rosca.

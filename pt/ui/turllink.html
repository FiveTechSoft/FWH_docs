TURLLink

Fonte: source/classes/urllink.prg

Herda de: TControl

TURLLink exibe um controle de texto de hiperlink clicável. Ao ser clicado, ele inicia o navegador web padrão com a URL especificada. O controle suporta cores personalizadas para os estados normal, sobre (hover) e visitado, fundos transparentes e um code block bAction personalizado para substituir o comportamento de navegação padrão.

Principais Membros DATA

DATATipoDescrição
cURLCaractereA URL de destino a abrir ao clicar
nClrInitNuméricoCor do texto no estado normal (não visitado)
nClrOverNuméricoCor do texto quando o mouse passa sobre o link
nClrVisitNuméricoCor do texto após o link ter sido clicado (visitado)
bActionBlockCode block de ação personalizada que substitui a abertura padrão da URL

Métodos

MétodoDescrição
New( nTop, nLeft, oWnd, lPixel, lDesign, oFont, cMsg, cURL, cToolTip, nClrInit, nClrOver, nClrVisit, lTransp )Cria um novo controle TURLLink
ReDefine( nId, oWnd )Redefine a partir de um recurso de diálogo

Exemplo: Link de URL com Ação Personalizada

#include "FiveWin.ch"

function Main()

   local oWnd, oLink

   DEFINE WINDOW oWnd TITLE "URL Link Demo" SIZE 400, 200

   @ 20, 20 URLLINK oLink ;
      TEXT "Visit FiveTech Software" ;
      URL "https://fivetechsoft.com" ;
      COLOR CLR_BLUE, CLR_RED, CLR_HGRAY ;
      TOOLTIP "Click to open website" ;
      OF oWnd

   // Substitui a abertura padrão do navegador por uma ação personalizada
   oLink:bAction := {|| MsgInfo( "Navigating to: " + oLink:cURL ) }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Por padrão, clicar no link executa ShellExecute( "open", cURL ) para abrir a URL no navegador padrão do sistema.
  • Defina bAction para substituir completamente o comportamento padrão. O code block recebe o objeto TURLLink como Self.
  • Os três estados de cor (nClrInit, nClrOver, nClrVisit) permitem feedback visual conforme o usuário interage com o link. nClrOver é tipicamente uma variante mais clara ou sublinhada.
  • O cursor muda automaticamente para um ponteiro em forma de mão ao passar sobre o texto do link.
  • Use ReDefine() para vincular a um controle de texto estático definido em um recurso de diálogo .rc, convertendo-o em um link clicável em tempo de execução.
  • Defina lTransp como .T. para um fundo transparente, permitindo que o link se misture a qualquer fundo de diálogo ou janela.

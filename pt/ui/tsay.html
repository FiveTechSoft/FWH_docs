TSay

Fonte: source/classes/say.prg

Herda de: TControl

TSay renderiza texto estático dentro de uma janela ou diálogo. É o controle padrão para rótulos, prompts e exibição de texto somente leitura. TSay suporta vínculo de dados via bSetGet, atualização automática quando a variável vinculada muda, cláusulas picture para saída formatada, efeitos 3D (elevados ou rebaixados), fundos transparentes, estilos de borda e texto tooltip. É um dos controles mais frequentemente usados em aplicações FiveWin.

Principais Membros DATA

DATATipoDescrição
bSetGetBlockBloco de código de vínculo de dados. Quando o say é atualizado, o bloco é avaliado e o resultado torna-se o texto exibido.
cPictureCharacterCláusula picture para saída formatada (ex. "999,999.99", "@!" para maiúsculas).
nClrBorderNumericCor da borda quando lBorder é .T. (valor RGB).
bClrTextBlockBloco de código que retorna um valor de cor. Avaliado no momento da pintura para suportar cores de texto dinâmicas.
l3DLogicalSe .T., o texto é renderizado com efeito 3D (elevado ou gravado).
lAdjustLogicalSe .T., o tamanho do controle se ajusta automaticamente para caber o conteúdo do texto.
lBorderLogicalSe .T., uma borda é desenhada ao redor do controle say.
nClrTextNumericCor de primeiro plano do texto (valor RGB).
nClrPaneNumericCor de preenchimento de fundo (valor RGB).
cCaptionCharacterTexto atualmente exibido.

Métodos

MétodoDescrição
New( nRow, nCol, bText, oWnd, nClrT, nClrP, oFont, lPixel, lDesign, lTransparent, cMsg, lUpdate, cPict, lBorder, lAdjust, oToolTip, nClrBorder )Criar um novo controle say. bText é uma string fixa ou bloco de código que retorna o texto. O say é criado imediatamente como filho de oWnd.
ReDefine( nId, bText, oWnd )Redefinir um say a partir de um recurso de diálogo. Vincula-se a um controle estático Win32 existente pelo seu ID de controle.
SetText( cText )Alterar o texto exibido diretamente (substitui bSetGet).
Refresh()Reavaliar o texto vinculado a dados e repintar o controle. Se bSetGet estiver definido, o bloco é reavaliado.
SetColor( nClrText, nClrPane )Alterar as cores de texto e fundo dinamicamente.
SetFont( oFont )Atribuir uma nova fonte ao controle say.
End()Destruir o controle e removê-lo de aControls do pai.

Comandos: @ ... SAY

@ nRow, nCol SAY oSay ;
   PROMPT cText | VAR cVar ;
   SIZE nW, nH ;
   [ OF oDlg ] ;
   [ COLOR nClrText, nClrPane ] ;
   [ FONT oFont ] ;
   [ PICTURE cPict ] ;
   [ TRANSPARENT ] ;
   [ 3D ] [ NO3D ] ;
   [ BORDER ] ;
   [ ADJUST ] ;
   [ UPDATE ] ;
   [ TOOLTIP cTip ]

Exemplo: Say de Atualização Automática a partir de Variável

#include "FiveWin.ch"

function Main()

   local oWnd, oSay, nCounter := 0

   DEFINE WINDOW oWnd TITLE "TSay Demo" SIZE 400, 200

   // Prompt estático
   @ 30, 20 SAY "Counter:" OF oWnd SIZE 60, 12

   // Say vinculado a dados que atualiza automaticamente
   @ 30, 90 SAY oSay VAR nCounter OF oWnd ;
      SIZE 100, 20 UPDATE PICTURE "999,999"

   @ 100, 20 BUTTON "Increment" OF oWnd SIZE 100, 30 ;
      ACTION ( nCounter++, oSay:Refresh() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TSay herda de TControl, que herda de TWindow. Todos os métodos de controle padrão estão disponíveis.
  • Use a cláusula UPDATE (ou defina lUpdate := .T.) para fazer o say atualizar automaticamente quando oWnd:Update() for chamado, o que é útil para exibições de campos de banco de dados que devem atualizar quando o ponteiro de registro se move.
  • A cláusula VAR (ao contrário de PROMPT) cria um bloco de código bSetGet vinculado a uma variável Harbour. O say exibe o valor atual da variável.
  • A cláusula PICTURE aplica formatação ao valor exibido, seguindo a sintaxe de função picture do Harbour (ex. "999,999.99" para formatação numérica, "@!" para maiúsculas).
  • Defina TRANSPARENT quando o say for colocado sobre um fundo gradiente ou bitmap. Sem ele, o say desenha um fundo opaco que pode obscurecer o fundo do pai.
  • O efeito 3D desenha o texto com uma sombra deslocada por um pixel, criando uma aparência elevada ou gravada. Use NO3D para texto plano.

TTreeView

Controle de arvore hierarquica com expandir/recolher, checkboxes, arrastar-soltar e edicao de rotulos

Fonte: source/classes/ttreevie.prg, source/classes/treeitem.prg  |  Parent: TControl

Visão Geral

TTreeView encapsula o controle comum SysTreeView32 do Windows. Exibe dados em uma estrutura de arvore hierarquica onde cada no pode ter nos filhos. Os nos podem ser expandidos/recolhidos, suportam icones via listas de imagens, checkboxes opcionais, edicao de rotulos in-place e reordenacao por arrastar-soltar.

TVItem -- No da Arvore

Fonte: source/classes/treeitem.prg

Cada no na arvore e um objeto TVItem (internamente chamado TTreeItem na versao Win32). Os itens formam uma lista encadeada com ponteiros oPrev/oNext e podem conter uma sub-arvore de filhos.

PropertyTypeDescrição
cPromptStringText label displayed for this node
hItemHandleWin32 handle for this tree item
nLevelNumericDepth level in the tree (root = 0 or 1)
lOpenedLogicalWhether the node is expanded
oTreeObjectSub-tree object (children container)
oPrev / oNextObjectPrevious and next sibling items
bActionBlockAction when this item is activated
CargoAnyUser data attached to the item
ValueAnyItem value (via ACCESS/ASSIGN, uses bSetGet)
hBmpOpen / hBmpCloseHandleBitmap handles for expanded/collapsed states

Exemplos de Codigo

Exemplo 1: Arvore de Navegacao de Arquivos

#include "FiveWin.ch"

FUNCTION FileTreeDemo()
   LOCAL oDlg, oTV, oImgList
   LOCAL oRoot, oSrc, oRes

   DEFINE DIALOG oDlg TITLE "Project Explorer" SIZE 400, 500

   // Image list: folder and file icons
   DEFINE IMAGELIST oImgList SIZE 16, 16
   IMAGELIST ADD BITMAP oImgList NAME "FOLDER", "FILE"

   @ 0.5, 0.5 TREEVIEW oTV OF oDlg ;
      SIZE 190, 220 PIXEL ;
      ON CHANGE { || ShowItemInfo( oTV ) }

   oTV:SetImageList( oImgList )

   // Build the tree
   oRoot := oTV:Add( "MyProject", 0 )         // folder icon = 0

   oSrc := oRoot:AddItem( "Source", 0 )
   oSrc:AddItem( "main.prg", 1 )              // file icon = 1
   oSrc:AddItem( "utils.prg", 1 )
   oSrc:AddItem( "database.prg", 1 )

   oRes := oRoot:AddItem( "Resources", 0 )
   oRes:AddItem( "main.rc", 1 )
   oRes:AddItem( "icons.rc", 1 )

   oTV:Add( "Libraries", 0 )

   // Start expanded
   oTV:ExpandAll()

   @ 11, 1 BUTTON "Expand All"   OF oDlg SIZE 60, 14 ;
      ACTION oTV:ExpandAll()
   @ 11, 7 BUTTON "Collapse All" OF oDlg SIZE 60, 14 ;
      ACTION oTV:CollapseAll()

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

STATIC FUNCTION ShowItemInfo( oTV )
   LOCAL oItem := oTV:GetSelected()
   IF oItem != NIL
      // oItem:cPrompt has the label
      // oItem:Cargo can hold custom data
      SayStatus( "Selected: " + oItem:cPrompt )
   ENDIF
RETURN NIL

Exemplo 2: Arvore com Checkboxes

@ 0.5, 0.5 TREEVIEW oTV OF oDlg ;
   SIZE 190, 220 PIXEL ;
   CHECKBOXES

oTV:Add( "Option A" )
oTV:Add( "Option B" )
oTV:Add( "Option C" )

// Later, check which items are selected:
FOR n := 1 TO Len( oTV:aItems )
   IF oTV:GetCheck( oTV:aItems[ n ] )
      ? "Checked:", oTV:aItems[ n ]:cPrompt
   ENDIF
NEXT

Exemplo 3: Arvore Editavel com Reordenacao

@ 0.5, 0.5 TREEVIEW oTV OF oDlg ;
   SIZE 190, 220 PIXEL ;

   ON CHANGE { || UpdatePreview( oTV ) }

oTV:Add( "Chapter 1" )
oTV:Add( "Chapter 2" )
oTV:Add( "Chapter 3" )

// Edit label of selected item
@ 11, 1 BUTTON "Rename" OF oDlg SIZE 50, 14 ;

@ 11, 5.5 BUTTON "Move Up" OF oDlg SIZE 50, 14 ;
   ACTION oTV:SwapUp()
@ 11, 10 BUTTON "Move Down" OF oDlg SIZE 55, 14 ;
   ACTION oTV:SwapDown()

Dicas

  • Use Cargo em cada TVItem para armazenar dados associados (IDs de registro, caminhos de arquivo, etc.).
  • A clausula CHECKBOXES habilita checkboxes em todos os itens. Use GetCheck()/SetCheck() para gerenciar o estado.
  • Para arvores grandes, preencha os filhos sob demanda no callback bExpanded em vez de carregar tudo na inicializacao.
  • Chame Rebuild() apos manipulacao programatica de itens (mover, promover, rebaixar) para sincronizar a arvore Win32.
  • Scan( bAction ) percorre todos os itens recursivamente -- util para buscar ou coletar itens marcados.
  • Use SetItemHeight() para itens de arvore maiores, mais amigaveis ao toque.

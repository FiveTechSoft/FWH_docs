TXImage

Fonte: source/classes/ximage.prg

Herda de: TControl

TXImage é um controle de visualização de imagens estendido que suporta zoom, rotação, brilho, contraste, correção de gama, mesclagem alpha, conversão para tons de cinza e efeitos de desfoque. Ele oferece um menu de contexto pop-up integrado com opções para salvar, imprimir, copiar para a área de transferência e navegação entre imagens.

Métodos

MétodoDescrição
New( nTop, nLeft, nW, nH, bImage, oWnd )Cria um novo controle TXImage. bImage pode ser um nome de arquivo, handle de bitmap ou um code block que retorna uma imagem.
Center()Centraliza a imagem dentro da área do controle
FitWidth()Escala a imagem para ajustar à largura do controle
FitHeight()Escala a imagem para ajustar à altura do controle
FitRect()Escala a imagem para caber inteiramente dentro do controle
FitOrglSize()Restaura a imagem às suas dimensões originais em pixels
Zoom( n )Define o nível de zoom para n por cento
Rotate( nDeg )Rotaciona a imagem em nDeg graus
SetSource( uNew )Substitui a imagem exibida por uma nova fonte
Paste()Cola uma imagem da área de transferência
CopyToClipBoard()Copia a imagem atual para a área de transferência
Save( lAsViewed, cFile )Salva a imagem em disco. Se lAsViewed for .T., os ajustes (zoom, efeitos) são preservados.

Funções Livres

FunçãoDescrição

Exemplo: Visualizador de Imagens com Menu de Contexto

#include "FiveWin.ch"

function Main()

   local oWnd, oImg

   DEFINE WINDOW oWnd TITLE "Visualizador de Imagens" SIZE 800, 600

   @ 10, 10 XIMAGE oImg FILE "photo.jpg" ;
      SIZE 760, 540 OF oWnd

   oImg:FitRect()
   oImg:Rotate( 90 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TXImage oferece um menu de contexto pop-up integrado ativado com o botão direito do mouse, disponibilizando opções de zoom, rotação, salvar, imprimir, copiar e ajuste em tempo de execução.
  • A função livre XImage() abre um diálogo modal com um controle TXImage e todas as ações padrão da barra de ferramentas. Use XImageArray() para navegar entre múltiplas imagens.
  • Os ajustes de imagem (zoom, rotação, brilho, contraste, gama, desfoque, tons de cinza, alpha) são aplicados em memória e não modificam o arquivo de origem original, a menos que sejam explicitamente salvos com Save().
  • O parâmetro bImage em New() aceita uma string de nome de arquivo, um handle de bitmap (HBITMAP) ou um code block que retorna qualquer um dos dois.

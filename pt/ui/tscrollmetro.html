TScrollMetro

Fonte: source/classes/scrollm.prg

Herda de: TControl

TScrollMetro fornece um controle de barra de rolagem moderno no estilo Metro. Ele substitui a barra de rolagem clássica do Windows por um design plano e adequado para toque, ideal para aplicações de tablet e interfaces modernas. O controle suporta posicionamento programático, gerenciamento de faixa e ganchos de eventos com code blocks para todas as ações de rolagem.

Principais Membros DATA

DATATipoDescrição
lVerticalLógicoOrientação: .T. para vertical, .F. para horizontal
nMin / nMaxNuméricoValores mínimo e máximo da faixa de rolagem
nPgStepNuméricoIncremento de passo de página para ações de página acima/página abaixo
nPosNuméricoPosição atual do indicador de rolagem
bGoUp / bGoDownCode blockExecutado quando o botão de subir/esquerda ou descer/direita é clicado
bGoTop / bGoBottomCode blockExecutado quando o indicador é arrastado para o topo ou para o fim
bPageUp / bPageDownCode blockExecutado ao clicar na área da trilha de página acima/página abaixo
bPos / bTrackCode blockExecutado na mudança de posição e no rastreamento do indicador

Métodos

MétodoDescrição
New( nRow, nCol, nMin, nMax, nPgStep, lVert, oWnd, nW, nH )Cria uma nova barra de rolagem Metro com faixa, passo e orientação
SetRange()Atualiza a faixa de rolagem a partir dos valores nMin e nMax
SetPos( nPos ) / GetPos()Define ou obtém a posição atual do indicador de rolagem
GoUp() / GoDown()Move o indicador para cima (ou esquerda) / para baixo (ou direita) em um passo
GoTop() / GoBottom()Move o indicador para a posição mínima ou máxima
PageUp() / PageDown()Move o indicador pela quantidade do passo de página

Exemplo: Barra de Rolagem Vertical para Browse

#include "FiveWin.ch"

function Main()

   local oWnd, oScroll
   local nPos := 0

   DEFINE WINDOW oWnd TITLE "TScrollMetro Demo" SIZE 400, 300

   oScroll := TScrollMetro():New( 10, 370, 0, 100, 10, .T., oWnd, 20, 250 )

   oScroll:bGoUp    := { || nPos := oScroll:GetPos(), oWnd:Refresh() }
   oScroll:bGoDown  := { || nPos := oScroll:GetPos(), oWnd:Refresh() }
   oScroll:bPageUp  := { || nPos := oScroll:GetPos(), oWnd:Refresh() }
   oScroll:bPageDown:= { || nPos := oScroll:GetPos(), oWnd:Refresh() }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O controle dispara eventos com code blocks para cada ação de rolagem: bGoUp, bGoDown, bGoTop, bGoBottom, bPageUp, bPageDown, bPos e bTrack.
  • A orientação é definida no momento da criação através do parâmetro lVert e não pode ser alterada dinamicamente.
  • Use SetRange() após alterar nMin ou nMax para recalibrar o indicador de rolagem.
  • A barra de rolagem Metro é particularmente adequada para aplicações de tela sensível ao toque, onde a trilha estreita das barras de rolagem clássicas é difícil de manipular.

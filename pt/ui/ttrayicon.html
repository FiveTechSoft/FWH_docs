TTrayIcon

Fonte: source/classes/ttray.prg

Classe autônoma (não derivada de TControl)

TTrayIcon cria e gerencia um ícone na área de notificação da bandeja do sistema do Windows. Permite que aplicações sejam executadas minimizadas ou em segundo plano, ao mesmo tempo em que oferece interação com o usuário por meio de eventos de clique do mouse, uma dica de ferramenta (tooltip) e um menu de contexto. É comumente utilizada para serviços em segundo plano, aplicações no estilo de mensageiros instantâneos e aplicações que minimizam para a bandeja do sistema.

Principais Membros DATA

DATATipoDescrição
oWndObjetoA janela principal associada (oculta ou visível)
oWndParentObjetoA janela pai para encaminhamento de notificações
oIconObjetoO ícone exibido na bandeja do sistema
cCaptionCaractereTexto da dica de ferramenta exibido ao passar o mouse
bLClickedBlocoBloco de código executado no clique esquerdo
bRClickedBlocoBloco de código executado no clique direito
bLDblClickBlocoBloco de código executado no clique duplo esquerdo

Métodos

MétodoDescrição
New( oWnd, oIcon, cTip, bLClick, bRClick )Cria um novo ícone na bandeja
End()Remove o ícone da bandeja do sistema e libera os recursos
Refresh( oIcon, cTip )Atualiza a exibição do ícone da bandeja
SetIcon( oIcon, cTip )Altera o ícone e/ou o texto da dica de ferramenta
SetText( cTitle )Define o texto do título

Exemplo: Ícone na Bandeja com Menu e Restauração no Clique Duplo

#include "FiveWin.ch"

function Main()

   local oWnd, oTray, oMenu

   DEFINE WINDOW oWnd TITLE "Tray Demo" SIZE 400, 300

   oTray := TTrayIcon():New( oWnd, "app.ico", "My Application",;
      {|| MsgInfo( "Left click" ) },;
      {|| oMenu:Show( oTray ) } )

   oTray:bLDblClick := {|| oWnd:Restore(), oWnd:SetFocus() }

   MENU oMenu POPUP
      MENUITEM "&Restore"   ACTION {|| oWnd:Restore() }
      MENUITEM "&Exit"      ACTION {|| oTray:End(), oWnd:End() }
   ENDMENU

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTrayIcon não herda de TControl; é uma classe autônoma que interage diretamente com a área de notificação do shell do Windows por meio de chamadas à API Shell_NotifyIcon.
  • O parâmetro oIcon pode ser o caminho de um arquivo de ícone (.ico), o nome de um recurso ou um número que identifica um ícone de recurso.
  • Sempre chame End() antes de a aplicação encerrar para remover o ícone da bandeja. Não fazer isso pode deixar um ícone fantasma até que o usuário passe o mouse sobre ele.
  • Os blocos de código bLClicked, bRClicked e bLDblClick oferecem interação completa com o mouse. O clique direito é normalmente utilizado para exibir um menu de contexto pop-up.
  • No Windows 11, a visibilidade do ícone na bandeja pode depender das configurações de sistema da "Área de Notificação". Use SetIcon() para atualizar o ícone dinamicamente em tempo de execução.

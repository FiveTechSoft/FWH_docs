TCalEx

Fonte: source/classes/tcalex.prg

Inherits from: TControl

TCalEx is the base class for FiveWin's extended calendar and scheduling controls. It provides a full-featured date navigation system with support for multiple views (month, week, day), appointment/event management, custom gradient rendering, and interactive mouse-based selection. The class is designed to handle complex scheduling UIs with configurable time intervals, date ranges, and visual styling.

TCalEx manages three sub-view objects -- oMonthView, oWeekView, and oDayView -- which handle the actual rendering and event handling for each specific view mode. The active view is controlled via SetMonthView(), SetWeekView(), and SetDayView() methods.

Command Syntax

Example: Calendar with Appointments

#include "FiveWin.ch"

function Main()

   local oWnd, oCal

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 800, 600

   @ 10, 10 CALENDAR oCal OF oWnd

   // Load appointments for a date range
   oCal:LoadDates( 9, 18, ;           // display hours 9:00-18:00
      CToD( "2026-06-01" ), ;        // start date
      CToD( "2026-06-30" ), ;        // end date
      "Team Meeting", ;              // event text
      "Project review", ;            // subject
      , , , , , CLR_YELLOW, CLR_RED, 1 )

   // Switch to week view initially
   oCal:SetWeekView( dDate(), 30 )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Full example: See samples/misc/calexmaria.prg for a complete TCalex application with MySQL/MariaDB backend, drag-and-drop appointment moving, and RC dialog editing.

Notes

  • TCalEx does not use the standard PIXEL coordinate system. All positioning values use dialog units (text coordinates).
  • The three sub-view objects (oMonthView, oWeekView, oDayView) are created internally by TCalEx. Switch between them using the SetMonthView(), SetWeekView(), and SetDayView() methods.
  • Event/appointment data is stored in the hCalInfo hash table and rendered within the active view grid.
  • Gradient coloring for cells, headers, and labels is configured via the aGrad* DATA arrays.
  • Time intervals control the granularity of the day/week view grid. Valid values are 5, 10, 15, 20, 30, and 60 minutes.

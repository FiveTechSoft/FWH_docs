TCalEx

Fonte: source/classes/tcalex.prg

Herda de: TControl

TCalEx é a classe base dos controles estendidos de calendário e agendamento do FiveWin. Ela fornece um sistema completo de navegação por datas com suporte a múltiplas visualizações (mês, semana, dia), gerenciamento de compromissos/eventos, renderização personalizada com gradiente e seleção interativa baseada no mouse. A classe foi projetada para lidar com interfaces de agendamento complexas, com intervalos de tempo, faixas de datas e estilo visual configuráveis.

TCalEx gerencia três objetos de subvisualização -- oMonthView, oWeekView e oDayView -- que tratam a renderização real e o tratamento de eventos para cada modo de visualização específico. A visualização ativa é controlada pelos métodos SetMonthView(), SetWeekView() e SetDayView().

Exemplo: Calendário com Compromissos

#include "FiveWin.ch"

function Main()

   local oWnd, oCal

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 800, 600

   @ 10, 10 CALENDAR oCal OF oWnd

   // Carrega compromissos para uma faixa de datas
   oCal:LoadDates( 9, 18, ;           // horas exibidas 9:00-18:00
      CToD( "2026-06-01" ), ;        // data inicial
      CToD( "2026-06-30" ), ;        // data final
      "Team Meeting", ;              // texto do evento
      "Project review", ;            // assunto
      , , , , , CLR_YELLOW, CLR_RED, 1 )

   // Alterna inicialmente para a visualização semanal
   oCal:SetWeekView( dDate(), 30 )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Notas

  • O TCalEx não usa o sistema de coordenadas PIXEL padrão. Todos os valores de posicionamento usam unidades de diálogo (coordenadas de texto).
  • Os três objetos de subvisualização (oMonthView, oWeekView, oDayView) são criados internamente pelo TCalEx. Alterne entre eles usando os métodos SetMonthView(), SetWeekView() e SetDayView().
  • Os dados de evento/compromisso são armazenados na tabela hash hCalInfo e renderizados dentro da grade da visualização ativa.
  • A coloração com gradiente de células, cabeçalhos e rótulos é configurada por meio dos arrays DATA aGrad*.
  • Os intervalos de tempo controlam a granularidade da grade de visualização diária/semanal. Os valores válidos são 5, 10, 15, 20, 30 e 60 minutos.

TScrollMsg

Fonte: source/classes/scrolmsg.prg

Herda de: TPanel

O TScrollMsg é um controle de texto de rolagem automática (marquee). Ele rola continuamente o texto horizontalmente (estilo fita de ticker) ou verticalmente (estilo créditos rolantes). Um temporizador conduz a rolagem incremental de pixels, e o texto se enrola perfeitamente quando atinge o final. Ele suporta velocidade configurável, cores, bordas e atualizações de texto em tempo de execução.

Principais Membros DATA

DATATipoDescrição
cTextCharacterO texto a ser rolado (somente leitura, use SetText() para atualizar)
lVerticalLogicalRolagem vertical quando .T. (padrão), horizontal quando .F.
nSpeedNumericVelocidade de rolagem em pixels por tick (padrão 2)
lBorderLogicalDesenhar uma borda ao redor do controle (padrão .T.)
nScrollPixNumericDeslocamento atual da rolagem em pixels (protegido)
nTextSizeNumericDimensão de texto em cache para cálculo de quebra (protegido)

Métodos

Exemplo: Marquee Horizontal

#include "FiveWin.ch"

function Main()

   local oWnd, oScroll

   DEFINE WINDOW oWnd TITLE "News Ticker" SIZE 600, 100

   oScroll := TScrollMsg():New( 10, 10, 560, 30,;
               "Breaking news: FWH 26.05 released!",;
               oWnd,, 3, CLR_YELLOW, CLR_BLUE, .T., .T. )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • O intervalo do temporizador do marquee é fixo em 18 ms (aproximadamente 55 fps). Ajuste nSpeed (pixels por tick) para controlar a velocidade efetiva da rolagem.
  • Ao rolar verticalmente, o texto quebra usando DT_WORDBREAK. A rolagem horizontal usa uma única linha com DT_SINGLELINE.
  • Passe lHoriz := .T. para ativar a rolagem horizontal; o padrão é vertical.
  • O controle cria e ativa automaticamente seu temporizador na primeira pintura e o destrói em Destroy().
  • Defina lNoBorder := .T. para suprimir o contorno da caixa ao redor.

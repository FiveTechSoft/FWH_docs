TXBrowse

O controle grid de dados mais poderoso e versátil do FiveWin

Fonte: source/classes/xbrowse.prg  |  Pai: TControl  |  Cabeçalho: XBrowse.ch

Visão Geral

TXBrowse é o principal controle grid de dados do FiveWin. Ele renderiza dados tabulares de praticamente qualquer fonte -- tabelas DBF, arrays em memória, ADO RecordSets, cursores ODBC ou dados personalizados -- através de uma arquitetura unificada de navegação baseada em blocos. Ele virtualiza a renderização para que apenas as linhas visíveis sejam processadas, permitindo manipular milhões de registros sem consumo excessivo de memória.

As principais capacidades incluem:

  • Abstração de fonte de dados -- um controle, muitos back-ends (DBF/RDD, Array, ADO, ODBC, personalizado)
  • Objetos de coluna ricos -- cada coluna (TXBrwCol) controla seu próprio cabeçalho, formatação de dados, cores, edição e largura
  • Edição na célula -- editores GET, ComboBox, CheckBox, DatePicker e Spinner por coluna
  • Busca/filtro incremental -- barra de busca lIncrFilter integrada com pesquisa por coluna
  • Multi-seleção, congelamento de colunas, seletor de registro, estilos de marcação
  • Exportação para Excel, CSV, área de transferência e impressora

Arquitetura

TXBrowse desacopla o grid visual dos dados subjacentes através de um conjunto de blocos de código de navegação. Métodos auxiliares como SetRDD(), SetArray() e SetAdo() simplesmente preenchem estes blocos com a lógica apropriada para cada tipo de fonte de dados.

Objeto de Coluna: TXBrwCol

Cada coluna do navegador de dados é um objeto TXBrwCol armazenado no array aCols. As colunas definem quais dados exibir e como exibi-los.

Principais Propriedades (DATA)

PropriedadeTipoDescrição

nHeaderHeightNumericAltura em pixels da linha de cabeçalho das colunas

Blocos de Navegação

Estes blocos de código formam a camada de abstração de dados. Eles são definidos automaticamente por SetRDD(), SetArray(), SetAdo(), etc., mas você pode fornecer blocos personalizados para fontes de dados especializadas.

BlocoAssinaturaDescrição
bGoTop{|| ... }Posiciona a fonte de dados no primeiro registro
bGoBottom{|| ... }Posiciona a fonte de dados no último registro
bSkip{|n| ... }Move n registros (positivo=avançar, negativo=retroceder). Retorna registros efetivamente movidos.
bBof{|| ... }Retorna .T. se antes do primeiro registro
bEof{|| ... }Retorna .T. se após o último registro
bKeyNo{|n| ... }Obtém/define a posição lógica atual (para barra de rolagem)
bKeyCount{|| ... }Retorna o número total de registros (para barra de rolagem)
bBookMark{|u| ... }Se u for NIL, retorna um marcador para a linha atual. Caso contrário, reposiciona para o marcador u.
bSeek{|c| ... }Busca incremental -- encontra o primeiro registro que corresponda à string c

Comandos (XBrowse.ch)

O FiveWin fornece dois estilos de comando para criar controles TXBrowse:

Comando Posicionado

@ nRow, nCol XBROWSE oBrw ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ COLUMNS cCol1, cCol2, ... ] ;
   [ HEADERS cHead1, cHead2, ... ] ;
   [ ALIAS cAlias ] ;
   [ ON DBLCLICK bAction ] ;
   [ FONT oFont ] ;
   [ NOBORDER ]

Comando de Navegação Rápida

XBROWSER <cAlias>       // browse a DBF alias
XBROWSER <aArray>       // browse an array
XBROWSER <oRs>          // browse an ADO RecordSet

Exemplos de Código

Exemplo 1: Navegando uma Tabela DBF

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw

   USE Customer VIA "DBFCDX" NEW

   DEFINE WINDOW oWnd TITLE "Customers" FROM 1, 1 TO 24, 80

   oBrw := TXBrowse():New( oWnd )
   oBrw:nTop    := 0
   oBrw:nLeft   := 0
   oBrw:nRight  := -1   // stretch to right edge
   oBrw:nBottom := -1   // stretch to bottom edge

   oBrw:SetRDD()        // bind to current work area

   // Configure individual columns
   WITH OBJECT oBrw:AddColumn( "ID", FieldBlock( "CUST_ID" ), "99999" )
      :nWidth       := 80
      :nDataStrAlign := AL_RIGHT
   END

   WITH OBJECT oBrw:AddColumn( "First Name", FieldBlock( "FIRSTNAME" ), "@!" )
      :nWidth := 140
      :lEdit  := .T.    // allow in-cell editing
   END

   oBrw:AddColumn( "Last Name",  FieldBlock( "LASTNAME" ),  "@!" )
   oBrw:AddColumn( "City",       FieldBlock( "CITY" ) )
   oBrw:AddColumn( "Balance",    FieldBlock( "BALANCE" ),    "@E 999,999.99" )

   oBrw:nFreeze         := 1       // freeze ID column
   oBrw:lRecordSelector := .T.     // show row indicator
   oBrw:nMarqueeStyle   := MARQSTYLE_HIGHLROW

   oBrw:CreateFromCode()

   oWnd:oClient := oBrw            // fill the window client area
   ACTIVATE WINDOW oWnd

   CLOSE Customer
RETURN NIL

Exemplo 2: Navegando um Array

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw
   LOCAL aData := { ;
      { "Alice",   "Smith",    28, .T. }, ;
      { "Bob",     "Johnson",  34, .F. }, ;
      { "Charlie", "Williams", 45, .T. }, ;
      { "Diana",   "Brown",    31, .T. }, ;
      { "Edward",  "Jones",    52, .F. }  ;
   }

   DEFINE WINDOW oWnd TITLE "Array Browse" FROM 2, 2 TO 20, 70

   oBrw := TXBrowse():New( oWnd )
   oBrw:SetArray( aData, .F. )   // .F. = do not auto-create columns

   oBrw:aCols := {}
   oBrw:AddColumn( "First",  {|| aData[ oBrw:nArrayAt ][ 1 ] } )
   oBrw:AddColumn( "Last",   {|| aData[ oBrw:nArrayAt ][ 2 ] } )
   oBrw:AddColumn( "Age",    {|| aData[ oBrw:nArrayAt ][ 3 ] }, "999" )
   oBrw:AddColumn( "Active", {|| aData[ oBrw:nArrayAt ][ 4 ] } )

   // Make "Active" column render as a checkbox
   oBrw:aCols[ 4 ]:SetCheck( "CHECK1", "UNCHECK1" )

   oBrw:nMarqueeStyle := MARQSTYLE_HIGHLCELL
   oBrw:CreateFromCode()

   oWnd:oClient := oBrw
   ACTIVATE WINDOW oWnd
RETURN NIL

Exemplo 3: Browse Editável com Configuração de Colunas

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw, oCol

   USE Invoices VIA "DBFCDX" NEW

   DEFINE WINDOW oWnd TITLE "Editable Invoices"

   @ 0, 0 XBROWSE oBrw OF oWnd ;
      COLUMNS "INVNO", "CUSTNAME", "AMOUNT", "INVDATE", "PAID" ;
      HEADERS "Invoice #", "Customer", "Amount", "Date", "Paid?"

   oBrw:SetRDD()

   // Configure the Amount column
   oCol := oBrw:aCols[ 3 ]
   oCol:cPicture  := "@E 999,999.99"
   oCol:lEdit     := .T.
   oCol:nEditType := EDIT_GET             // edit with a GET control
   oCol:bClrStd   := {|| { CLR_BLACK, CLR_WHITE } }

   // Configure the Date column with a date picker editor
   oCol := oBrw:aCols[ 4 ]
   oCol:lEdit     := .T.
   oCol:nEditType := EDIT_DATE

   // Configure the Paid column as a checkbox
   oCol := oBrw:aCols[ 5 ]
   oCol:SetCheck( "CHECK1", "UNCHECK1" )
   oCol:lEdit := .T.

   oBrw:lFastEdit := .T.   // typing goes straight to edit mode
   oBrw:CreateFromCode()

   oWnd:oClient := oBrw
   ACTIVATE WINDOW oWnd

   CLOSE Invoices
RETURN NIL

Exemplo 4: Barra de Busca/Filtro Incremental

#include "FiveWin.ch"
#include "XBrowse.ch"

FUNCTION Main()
   LOCAL oWnd, oBrw

   USE Customer INDEX Customer VIA "DBFCDX" NEW

   DEFINE WINDOW oWnd TITLE "Customer Search"

   oBrw := TXBrowse():New( oWnd )
   oBrw:SetRDD()

   oBrw:AddColumn( "Name",    FieldBlock( "NAME" ) )
   oBrw:AddColumn( "City",    FieldBlock( "CITY" ) )
   oBrw:AddColumn( "Phone",   FieldBlock( "PHONE" ) )
   oBrw:AddColumn( "Balance", FieldBlock( "BALANCE" ), "@E 999,999.99" )

   // Enable the incremental filter bar
   oBrw:lIncrFilter := .T.

   // Custom seek block -- performs an indexed seek on the NAME field
   oBrw:bSeek := {|cSeek| ( oBrw:cAlias )->( DbSeek( cSeek, .T. ) ) }

   oBrw:nMarqueeStyle   := MARQSTYLE_HIGHLROW
   oBrw:lRecordSelector := .T.

   oBrw:CreateFromCode()
   oWnd:oClient := oBrw
   ACTIVATE WINDOW oWnd

   CLOSE Customer
RETURN NIL

Dicas e Boas Práticas

  • Sempre chame CreateFromCode() após configurar fonte de dados, colunas e propriedades visuais.
  • Use oWnd:oClient := oBrw para fazer o browse redimensionar automaticamente com a janela.
  • Evite lFastEdit em UIs com muita navegação -- ele intercepta teclas de caractere que normalmente disparariam buscas ou atalhos de teclado.
  • Para busca incremental em um DBF, garanta que a tabela tenha um índice ativo na coluna que você está pesquisando.
  • bClrEdit da coluna controla as cores da célula enquanto está sendo editada (bloco de primeiro plano/fundo). Isto é separado de bClrStd que controla as cores no modo de exibição.
  • Pintura com buffer duplo: TXBrowse pinta em um bitmap fora da tela e depois transfere para a tela. Isso elimina tremulação mas significa que você deve chamar Refresh() -- não Invalidate() -- para forçar uma repintura.
  • Para arrays muito grandes, considere usar SetRDD() com um DBF temporário, pois a navegação em arrays não virtualiza buscas.

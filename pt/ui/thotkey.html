THotKey

Fonte: source/classes/thotkey.prg

Herda de: TControl

THotKey encapsula o controle comum de tecla de atalho do Win32, permitindo ao usuário pressionar uma combinação de teclado (ex., Ctrl+Alt+F5) que é capturada e armazenada como um código de tecla virtual e máscara de modificadores. É comumente usado em diálogos de configuração onde os usuários definem atalhos de teclado personalizados.

Principais Membros DATA

DATATipoDescrição
nVirtKeyNumericCódigo da tecla virtual da tecla selecionada (ex., VK_F5)
nModifiersNumericMáscara de bits das teclas modificadoras: HOTKEYF_SHIFT, HOTKEYF_CONTROL, HOTKEYF_ALT

Métodos

MétodoDescrição
New( nRow, nCol, oWnd, nVK, nMod )Cria um novo controle de entrada de tecla de atalho
SetHotKey( nVK, nMod )Define programaticamente a tecla de atalho como nVK com os modificadores nMod
GetHotKey()Retorna um array { nVirtKey, nModifiers } da tecla de atalho atual
GetKeyName()Retorna uma string legível como "Ctrl+Alt+F5"
SetRules( nInv, nDef )Define combinações de teclas inválidas e o comportamento de substituição padrão

Exemplo: Seletor de Tecla de Atalho com Callback

#include "FiveWin.ch"

function Main()

   local oWnd, oHot, nVK := VK_F5, nMod := HOTKEYF_CONTROL + HOTKEYF_ALT

   DEFINE WINDOW oWnd TITLE "Hotkey Demo" SIZE 400, 150

   @ 40, 20 HOTKEY oHot ;
      SIZE 120, 25 OF oWnd ;
      ACTION MsgInfo( "Hotkey: " + oHot:GetKeyName() )

   oHot:SetHotKey( nVK, nMod )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • THotKey captura a combinação de teclas quando o controle tem o foco e o usuário pressiona um conjunto modificador+tecla. A combinação é exibida no controle.
  • Constantes de modificadores: HOTKEYF_SHIFT (1), HOTKEYF_CONTROL (2), HOTKEYF_ALT (4). Combine com + para teclas de atalho com múltiplos modificadores.
  • GetKeyName() retorna uma string localizada adequada para exibição em menus ou listas de configuração.
  • Use SetRules() para especificar quais combinações de teclas são inválidas. nInv é uma máscara de modificadores inválidos e nDef especifica o modificador padrão a ser usado quando o usuário digita uma combinação inválida.

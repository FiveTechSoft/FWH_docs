TCBrowse

Source: source/classes/tcbrowse.prg

Inherits from: TWBrowse

TCBrowse is a column-based browse control that extends TWBrowse with multi-column support, column drag-reorder, frozen columns, incremental seek, inline editing, bitmap columns, and built-in report generation. It can be bound to both arrays and DBF objects, making it a versatile data-browsing control for tabular data.

Example: 3-Column Browse

#include "FiveWin.ch"

function Main()

   local oWnd, oBrowse, oCol1, oCol2, oCol3
   local aData := { { "Widget A", 150, Date() },;
                    { "Widget B", 275, Date() - 1 },;
                    { "Widget C", 100, Date() - 2 } }

   DEFINE WINDOW oWnd TITLE "TCBrowse Demo" SIZE 600, 400

   @ 10, 10 BROWSE oBrowse ;
      SIZE 580, 360 ;
      OF oWnd

   oBrowse:SetArray( aData )

   oCol1 := TCColumn():New( "Item",   { || aData[ oBrowse:nArrayAt, 1 ] } )
   oCol2 := TCColumn():New( "Price",  { || aData[ oBrowse:nArrayAt, 2 ] }, "999.99" )
   oCol3 := TCColumn():New( "Date",   { || aData[ oBrowse:nArrayAt, 3 ] }, "D" )

   oBrowse:AddColumn( oCol1 )
   oBrowse:AddColumn( oCol2 )
   oBrowse:AddColumn( oCol3 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TCBrowse supports both array-based data (SetArray()) and DBF-based data (SetoDBF()).
  • Freeze columns by setting nFreeze to the number of leftmost columns that should remain visible during horizontal scrolling.
  • In-place editing is enabled via the lEdit flag on individual TCColumn objects.
  • Column drag-reorder is enabled by setting lColDrag := .T.. Use Exchange() to programmatically swap columns.
  • The Report() method provides quick printing of browse contents with column headers and data.
  • TCBrowse supports ClipMore context objects (oCtx) for advanced filtering and context management.

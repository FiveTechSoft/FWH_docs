TSayBarCode

Fonte: source/classes/tsaybcod.prg

Herda de: TControl

TSayBarCode renderiza códigos de barras como um controle visual em janelas e diálogos. Suporta múltiplas simbologias de códigos de barras (Code 128, Code 39, EAN, etc.) com orientação configurável, tamanho de pin e flags de exibição. O controle pode ser vinculado a uma variável de dados para atualização automática.

Principais Membros DATA

DATATipoDescrição
cTextCharacterString de texto a codificar no código de barras
bGetCode blockBloco de código que retorna o valor do texto do código de barras
BarCodeTypeNumericTipo de simbologia do código de barras (padrão 128 para Code 128)
lVerticalLogicalRenderizar o código de barras verticalmente
nPinSizeNumericLargura do elemento de barra mais estreito em pixels
nFlagsNumericFlags de renderização adicionais para o motor de códigos de barras

Métodos

MétodoDescrição
New( nRow, nCol, bText, cType, oWnd, nW, nH )Criar um novo controle de código de barras com bloco de texto, tipo e dimensões
Redefine( nID, bText, cType, oWnd )Redefinir a partir de um recurso de diálogo por ID de controle
Paint()Desenhar o gráfico do código de barras na área do controle
Refresh()Renderizar novamente o código de barras após alterar propriedades
SetText( c )Atualizar o texto do código de barras e atualizar a exibição

Comandos

@ nRow, nCol SAYBARCODE oBar VAR bBlock TYPE cType SIZE nW, nH OF oDlg

Exemplo: Código de Barras Code128

#include "FiveWin.ch"

function Main()

   local oWnd, oBar
   local cCode := "ABC-12345"

   DEFINE WINDOW oWnd TITLE "Barcode Demo" SIZE 400, 200

   @ 20, 20 SAYBARCODE oBar VAR { || cCode } ;
      TYPE "CODE128" SIZE 360, 80 OF oWnd

   oBar:nPinSize := 2
   oBar:lVertical := .F.

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O BarCodeType padrão é 128 (Code 128). Outros tipos suportados incluem 39 (Code 39), EAN-13, EAN-8, UPC-A e Interleaved 2 of 5.
  • Defina lVertical como .T. para aplicações onde o espaço vertical é mais abundante que o horizontal.
  • A propriedade nPinSize controla a largura da barra mais estreita. Aumente para códigos de barras maiores adequados para distâncias longas de escaneamento.
  • Use um bloco de código bGet (ou a cláusula VAR) para vincular o código de barras a uma variável que atualiza automaticamente.
  • Chame Refresh() após alterar qualquer propriedade de renderização para atualizar a exibição.

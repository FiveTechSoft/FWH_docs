TCalendar

Fonte: source/classes/tcalenda.prg

Herda de: TControl

TCalendar wraps the Windows month calendar common control for date selection. It supports single and multi-select date ranges, week number display, day state highlighting, today indicator suppression, and extensive color customization of all calendar elements.

Sintaxe do Comando

@ nRow, nCol CALENDAR oCal VAR dDate OF oWnd SIZE nW, nH ON CHANGE bBlock

Exemplo: Calendário com Retorno de Alteração

#include "FiveWin.ch"

function Main()

   local oWnd, oCal, dDate := Date()

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 400, 350

   @ 20, 20 CALENDAR oCal VAR dDate OF oWnd SIZE 350, 250 ;
      ON CHANGE MsgInfo( DToC( dDate ), "Date Selected" )

   oCal:lWeekNumbers := .T.
   oCal:SetColor( MCSC_TITLEBK, CLR_BLUE )
   oCal:SetColor( MCSC_TITLETEXT, CLR_WHITE )
   oCal:SetFirstDayOfWeek( 1 )  // Monday

   @ 300, 20 BUTTON "&OK" SIZE 60, 25 PIXEL OF oWnd ;
      ACTION ( MsgInfo( DToC( dDate ) ), oWnd:End() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • O TCalendar encapsula o controle comum Win32 SysMonthCal32. O controle ajusta automaticamente seu tamanho mínimo com base na fonte e no número de meses visíveis.
  • No modo de seleção múltipla (lMultiselect := .T.), use bSetGet2 para vincular a variável de data final e GetDateRange() para recuperar as datas inicial e final.
  • Os estados de dia permitem que dias individuais sejam renderizados em negrito (acinzentado = GRAY, negrito = BOLD). Use SetArrayDayState() para configurar estados por mês.
  • As constantes MCSC_* para personalização de cores são: MCSC_BACKGROUND (0), MCSC_TEXT (1), MCSC_TITLEBK (2), MCSC_TITLETEXT (3), MCSC_MONTHBK (4), MCSC_TRAILINGTEXT (5).

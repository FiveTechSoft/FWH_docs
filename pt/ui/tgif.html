TGif

Fonte: source/classes/tgif.prg

Hierarquia: TGif → TControl

TGif é um controle para exibir imagens GIF animadas dentro de janelas e diálogos FiveWin. Ele suporta operações de reproduzir, parar, reiniciar e três modos de redimensionamento para controlar como os quadros do GIF se ajustam ao retângulo delimitador do controle. O controle pode carregar GIFs de arquivos ou de recursos incorporados.

Comando GIF

@ nRow, nCol GIF oGif FILE cGifFile SIZE nW, nH OF oWnd

Principais Membros DATA

DATATipoPadrãoDescrição
hGifNuméricoIdentificador da janela de animação GIF interna
cFilenameCaractereCaminho para o arquivo GIF (ou nome do recurso)
lAdjustLógico.F.Esticar GIF para preencher as dimensões do controle quando .T.
nSizingTypeNuméricoFWGIF_SIZING_FILEUm de FWGIF_SIZING_FILE, FWGIF_SIZING_CLIP ou FWGIF_SIZING_STRETCH

Modos de Redimensionamento

ConstanteValorDescrição
FWGIF_SIZING_FILEPadrãoUsar as dimensões naturais do GIF. O controle se redimensiona automaticamente para corresponder.
FWGIF_SIZING_CLIPRecortar o GIF para caber no retângulo delimitador do controle em seu tamanho natural.
FWGIF_SIZING_STRETCHEsticar o GIF para preencher as dimensões do controle (mesmo que lAdjust := .T.).

Métodos Principais

MétodoDescrição
New( oWnd, cGifFile, nRow, nCol, nHeight, nWidth, oCursor, lAdjust, bAction )Construtor. Cria o controle GIF e inicia a animação.
Play()Iniciar ou retomar a animação do GIF.
Stop()Pausar a animação do GIF no quadro atual.
Restart()Reiniciar a animação do primeiro quadro.
IsRunning()Retornar .T. se a animação está sendo reproduzida no momento.
SetFile( cFile )Carregar um novo arquivo GIF no controle.
SetSizing( nType )Alterar o modo de redimensionamento em tempo de execução.
GetData()Retornar um array com metadados do GIF (dimensões, número de quadros, etc.).

Exemplo: Spinner de Carregamento

#include "FiveWin.ch"

function Main()

   local oWnd, oGif, lPlaying := .T.

   DEFINE WINDOW oWnd TITLE "Animated GIF" ;
      SIZE 400, 350

   @ 30, 100 GIF oGif FILE "spinner.gif" ;
      SIZE 64, 64 OF oWnd

   @ 250, 80 BUTTON "&Play / Pause" SIZE 80, 25 ;
      ACTION ( If( oGif:IsRunning(), oGif:Stop(), oGif:Play() ),;
               lPlaying := !lPlaying )

   @ 250, 170 BUTTON "&Restart" SIZE 70, 25 ;
      ACTION oGif:Restart()

   @ 250, 250 BUTTON "&Close" SIZE 60, 25 ;
      ACTION oWnd:End()

   ACTIVATE WINDOW oWnd

return nil

Notas

  • Arquivos GIF podem ser carregados do disco ou de recursos incorporados (tipo de recurso 10 / RT_RCDATA). Quando um nome de recurso é passado, o controle o extrai para um arquivo temporário para exibição.
  • Quando nenhuma largura/altura explícita é fornecida, o controle se redimensiona automaticamente para as dimensões naturais do GIF.
  • A flag lAdjust é uma propriedade de conveniência que internamente define o modo de redimensionamento para FWGIF_SIZING_STRETCH.
  • Múltiplos controles TGif podem coexistir na mesma janela; cada um gerencia sua própria animação independentemente.
  • O controle requer o mecanismo GIF interno do FWH (vinculado de source/function/).

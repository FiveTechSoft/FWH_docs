TTrackBar

Fonte: source/classes/trackbar.prg

Herda de: TControl

TTrackBar encapsula o controle comum trackbar (slider) do Win32. Permite ao usuário selecionar um valor numérico arrastando um cursor ao longo de uma trilha, com marcas de graduação opcionais. É comumente usado para controles de volume, sliders de brilho e qualquer entrada de valor dentro de um intervalo.

Membros DATA Principais

DATATipoDescrição
nMinNuméricoValor mínimo do intervalo do trackbar
nMaxNuméricoValor máximo do intervalo do trackbar
nPosNuméricoPosição atual do cursor
nFreqNuméricoFrequência das marcas de graduação
bChangeBlocoBloco de código executado quando a posição muda

Métodos

MétodoDescrição
New( nRow, nCol, oWnd, nW, nH, nMin, nMax, nPos, nFreq )Cria um novo controle trackbar
SetPos( n )Define o cursor na posição n
GetPos()Retorna a posição atual do cursor
SetRange( nMin, nMax )Define os valores mínimo e máximo do intervalo
SetTicFreq( n )Define a frequência das marcas de graduação

Exemplo: Controle de Volume 0-255

#include "FiveWin.ch"

function Main()

   local oWnd, oTrack, nVol := 128

   DEFINE WINDOW oWnd TITLE "Controle de Volume" SIZE 400, 150

   @ 40, 20 TRACKBAR oTrack VAR nVol ;
      SIZE 360, 30 OF oWnd ;
      RANGE 0, 255 ;
      ON CHANGE ( oWnd:SetText( "Volume: " + Str( nVol ) ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTrackBar encapsula o trackbar nativo do Win32 (TRACKBAR_CLASS). Suporta orientações tanto horizontal quanto vertical, dependendo das dimensões passadas para New().
  • A cláusula VAR vincula uma variável numérica que é atualizada automaticamente quando o usuário move o cursor.
  • Use SetTicFreq() para exibir marcas de graduação em intervalos regulares. Uma frequência de 0 oculta todas as marcas de graduação.
  • A cláusula ON CHANGE define bChange, que é disparado continuamente enquanto o usuário arrasta o cursor.

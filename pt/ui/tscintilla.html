TScintilla

Fonte: source/classes/scintila.prg

Hierarquia: TScintilla → TControl

TScintilla encapsula o componente de edição de código-fonte Scintilla (scintilla.org) para uso em aplicações FiveWin. Ele fornece um editor de código completo com realce de sintaxe, dobragem de código, numeração de linhas, marcadores, busca/substituição, desfazer/refazer e suporte para múltiplos analisadores léxicos incluindo sintaxe Harbour/xHarbour.

Comando SCINTILLA

@ nRow, nCol SCINTILLA oSci SIZE nW, nH OF oWnd FONT oFont LEXER cLexer

Exemplo: Editor de Código

#include "FiveWin.ch"

function Main()

   local oWnd, oSci, oFont

   DEFINE FONT oFont NAME "Consolas" SIZE 0, -12

   DEFINE WINDOW oWnd TITLE "Source Editor" ;
      SIZE 800, 600

   @ 0, 0 SCINTILLA oSci SIZE 800, 570 OF oWnd ;
      FONT oFont LEXER ""

   oSci:lMargLin   := .T.
   oSci:lFolding   := .T.
   oSci:lMarking   := .T.
   oSci:SetUp()

   // Toolbar buttons
   @ 575, 10 BUTTON "&Open" SIZE 50, 20 ;
      ACTION oSci:Open()

   @ 575, 65 BUTTON "&Save" SIZE 50, 20 ;
      ACTION oSci:Save()

   @ 575, 120 BUTTON "&Find" SIZE 50, 20 ;
      ACTION oSci:DlgFindText()

   @ 575, 175 BUTTON "&Undo" SIZE 50, 20 ;
      ACTION oSci:Undo()

   @ 575, 230 BUTTON "&Redo" SIZE 50, 20 ;
      ACTION oSci:Redo()

   @ 575, 620 BUTTON "E&xit" SIZE 50, 20 ;
      ACTION oWnd:End()

   ACTIVATE WINDOW oWnd ;
      VALID ( oSci:End(), oFont:End(), .T. )

return nil

Notas

  • TScintilla requer a DLL Scintilla (SciLexer.dll para 32 bits ou SciLex64.dll para 64 bits) em tempo de execução. A DLL é carregada dinamicamente via LoadLibrary.
  • O realce de sintaxe Harbour/xHarbour é ativado passando "Harbour" ou o número de analisador léxico correspondente como parâmetro cLex.
  • Use cCKeyw1 a cCKeyw5 para personalizar as cores de sintaxe. Cada um é um array de { nForeColor, nBackColor, nCaseMode }.
  • A flag lModified e o bloco de código bModified permitem rastrear alterações não salvas, por exemplo, para atualizar o título da janela com um indicador de modificação.
  • A classe fornece diálogos incorporados para busca/substituição (DlgFindText(), DlgReplace()), ir para linha (DlgGoToLine()) e inserção de caracteres (DlgInsChar()).
  • As margens são configuradas via nMargLines, nMargSymbol, nMargFold e nMargText. Chame SetUp() após alterar as configurações de margem.

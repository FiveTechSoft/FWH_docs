TScintilla

Fonte: source/classes/scintila.prg

Hierarquia: TScintilla → TControl

TScintilla encapsula o componente de edição de código fonte Scintilla (scintilla.org) para uso em aplicações FiveWin. Fornece um editor de código completo com realce de sintaxe, dobramento de código, numeração de linhas, marcadores, localizar/substituir, desfazer/refazer e suporte a múltiplos lexers incluindo sintaxe Harbour/xHarbour.

Comando SCINTILLA

@ nRow, nCol SCINTILLA oSci SIZE nW, nH OF oWnd FONT oFont LEXER cLexer

Exemplo: Editor de Código

#include "FiveWin.ch"

function Main()

   local oWnd, oSci, oFont

   DEFINE FONT oFont NAME "Consolas" SIZE 0, -12

   DEFINE WINDOW oWnd TITLE "Source Editor" ;
      SIZE 800, 600

   @ 0, 0 SCINTILLA oSci SIZE 800, 570 OF oWnd ;
      FONT oFont LEXER ""

   oSci:lMargLin   := .T.
   oSci:lFolding   := .T.
   oSci:lMarking   := .T.
   oSci:SetUp()

   // Botoes da barra de ferramentas
   @ 575, 10 BUTTON "&Open" SIZE 50, 20 ;
      ACTION oSci:Open()

   @ 575, 65 BUTTON "&Save" SIZE 50, 20 ;
      ACTION oSci:Save()

   @ 575, 120 BUTTON "&Find" SIZE 50, 20 ;
      ACTION oSci:DlgFindText()

   @ 575, 175 BUTTON "&Undo" SIZE 50, 20 ;
      ACTION oSci:Undo()

   @ 575, 230 BUTTON "&Redo" SIZE 50, 20 ;
      ACTION oSci:Redo()

   @ 575, 620 BUTTON "E&xit" SIZE 50, 20 ;
      ACTION oWnd:End()

   ACTIVATE WINDOW oWnd ;
      VALID ( oSci:End(), oFont:End(), .T. )

return nil

Configuração do Lexer

TScintilla suporta realce de sintaxe via conjuntos de cores de palavras-chave configuráveis e arrays de cores específicos de token:

DATATipoDescrição
cCKeyw1..cCKeyw5ArrayConjuntos de cor de palavra-chave: { nForeColor, nBackColor, nCase } para níveis 1–5
cCStringArrayCor de literal de string: { nForeColor, nBackColor, nCase }
cCNumberArrayCor de literal numérico: { nForeColor, nBackColor, nCase }
cCOperatorArrayCor de operador: { nForeColor, nBackColor, nCase }
cCCommentArrayCor de comentário (suporta multilinha): { nForeColor, nBackColor, nCase }

Cada array de cor contém três elementos:

  • nForeColor — Cor de primeiro plano (texto) como valor RGB numérico.
  • nBackColor — Cor de fundo como valor RGB numérico.
  • nCase — Modo de maiúsculas: SC_CASE_MIXED, SC_CASE_UPPER ou SC_CASE_LOWER.

Modos de Codificação de Arquivos

TScintilla suporta múltiplos modos de codificação de arquivos para ler e salvar documentos em diferentes codificações de caracteres. Estes são controlados pelos membros de dados nModeSave e nModeLoad juntamente com o indicador lBom.

ModoConstanteDescrição
0nModeLoad := 0Codificação normal (ANSI/CP1252)
1nModeLoad := 1 / nModeSave := 1UTF-8 com BOM
2nModeLoad := 2 / nModeSave := 2UTF-8 sem BOM
3nModeLoad := 3 / nModeSave := 3UTF-16 Little Endian
  • nModeLoad controla como o arquivo é interpretado ao abrir. Modo 0 lê como ANSI; modos 1–3 decodificam o formato Unicode apropriado.
  • nModeSave controla como o documento é escrito de volta ao disco.
  • lBom (lógico) controla se uma Marca de Ordem de Byte é escrita no início do arquivo ao salvar. Relevante para modos UTF-8 e UTF-16.
  • Quando OpenFile() carrega um documento, o BOM UTF-8 é detectado automaticamente independentemente de nModeLoad.

Notas

  • TScintilla requer a DLL Scintilla (SciLexer.dll para 32 bits ou SciLex64.dll para 64 bits) em tempo de execução. A DLL é carregada dinamicamente via LoadLibrary.
  • O realce de sintaxe Harbour/xHarbour é ativado passando "Harbour" ou o número do lexer correspondente como parâmetro cLex.
  • Use cCKeyw1 a cCKeyw5 para personalizar as cores de sintaxe. Cada um é um array de { nForeColor, nBackColor, nCaseMode }.
  • O indicador lModified e o bloco de código bModified permitem rastrear alterações não salvas, por exemplo, para atualizar o título de uma janela com um indicador de modificação.
  • A classe fornece diálogos integrados para localizar/substituir (DlgFindText(), DlgReplace()), ir para linha (DlgGoToLine()) e inserção de caracteres (DlgInsChar()).
  • As margens são configuradas via nMargLines, nMargSymbol, nMargFold e nMargText. Chame SetUp() após alterar as configurações de margem.

TRadMenu

Fonte: source/classes/radmenu.prg

Classe independente (não derivada de TControl)

TRadMenu gerencia um grupo de controles de botão de rádio (TRadio) como uma unidade lógica única com exclusão mútua: selecionar um botão de rádio desseleciona automaticamente os outros. Fornece uma interface simplificada para criar, navegar e consultar o estado de um grupo de botões de rádio sem gerenciar objetos TRadio individuais.

Principais Membros DATA

DATATipoDescrição
aItemsArrayArray de objetos TRadio gerenciados por este grupo
bSetGetBlockBloco de código SET/GET para o índice de opção atual
nOptionNumericÍndice da opção atualmente selecionada (base 1)
bChangeBlockBloco de código avaliado quando a seleção muda

Métodos

MétodoDescrição
New( nRow, nCol, acItems, bSetGet, oWnd )Criar um novo grupo de rádio com itens de acItems
ReDefine( bSetGet, oWnd, anIDs )Redefinir a partir de recurso de diálogo por IDs de controle
SetOption( n )Definir programaticamente a opção selecionada
Refresh()Atualizar a exibição de todos os itens
GoPrev()Selecionar a opção anterior (circular)
GoNext()Selecionar a próxima opção (circular)
Enable()Habilitar todos os botões de rádio no grupo
Disable()Desabilitar todos os botões de rádio no grupo

Exemplo: Grupo de Rádio com 3 Opções

#include "FiveWin.ch"

function Main()

   local oWnd, oRadMenu, nOption := 1

   DEFINE WINDOW oWnd TITLE "Radio Group" SIZE 300, 200

   @ 10, 10 RADMENU oRadMenu ;
      ITEMS { "Option &One", "Option &Two", "Option &Three" } ;
      SIZE 200, 100 OF oWnd ;
      ON CHANGE ( MsgInfo( "Selected: " + Str( oRadMenu:nOption ) ) )

   oRadMenu:bSetGet := {|u| If( u == nil, nOption, nOption := u ) }
   oRadMenu:SetOption( 1 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TRadMenu não herda de TControl; é um contêiner que possui e gerencia controles TRadio individuais.
  • O array acItems contém as strings de prompt para cada botão de rádio. Cada prompt pode incluir um e-comercial (&) para um acelerador de teclado.
  • O bloco bSetGet segue o padrão padrão SET/GET do FiveWin: chamado sem argumento retorna o valor atual; chamado com um argumento define o valor.
  • GoPrev() e GoNext() fazem wrap-around (navegação circular) ao atingir o início ou fim do grupo.
  • Use ReDefine() para vincular TRadMenu a controles de rádio definidos em um recurso .rc de diálogo passando um array de IDs de controle que correspondam ao grupo.

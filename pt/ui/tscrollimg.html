TScrollImg

Fonte: source/classes/scrolimg.prg

Herda de: TPanel

TScrollImg é um controle de banner / carrossel de imagens que exibe uma coleção rolável de imagens. Suporta múltiplos modos de exibição, animação automática, transições de desvanecimento, zoom ao passar o mouse, ações por clique em cada imagem e persistência de estado. Originalmente projetado para vitrines de produtos e banners publicitários.

Membros DATA Principais

DATATipoDescrição
aElementsArrayArray de definições de elementos (arquivo, URL, ação, prompt)
nImagesNuméricoNúmero de imagens carregadas da lista de banners
nModeNuméricoModo de exibição 1-4 (direção de rolagem / variante de layout)
nSpeedNuméricoVelocidade de rolagem em pixels por tick do temporizador
lRunningLógicoAnimação está atualmente em execução
lPausedLógicoAnimação está pausada
aOpacityArrayValores de opacidade por imagem (0-255)
nZoomedImageNuméricoÍndice da imagem atualmente ampliada (0 = nenhuma)
lFadingLógicoTransição de desvanecimento em progresso
lMouseWheelLógicoHabilitar rolagem com roda do mouse
lChangeSpeedLógicoPermitir alteração de velocidade via teclas +/-

Métodos

MétodoDescrição
New( nRow, nCol, nW, nH, oWnd, aBanners, nMode, nSpeed, ... )Criar um novo carrossel de imagens com lista de banners e modo de exibição
Redefine( nId, oWnd, aBanners, nMode, nSpeed, ... )Redefinir a partir de um recurso de diálogo
Reset()Restaurar o carrossel ao seu estado inicial, reposicionar todas as imagens
Animate()Iniciar ou reiniciar o temporizador de animação de rolagem
Paint()Renderizar o fundo e todas as imagens visíveis
TimerAction()Callback do temporizador que avança a posição de rolagem a cada tick
SaveState( cFile )Salvar o estado atual do carrossel (posições, imagens) em um arquivo
LoadState( cFile )Restaurar um estado de carrossel previamente salvo de um arquivo
MouseMove( nRow, nCol )Lidar com movimento do mouse para detecção de hover e zoom
LButtonUp( nRow, nCol )Executar a ação associada à imagem clicada
KeyDown( nKey, nFlags )Lidar com teclas +/- para controle de velocidade
MouseWheel( nKeys, nDelta, nX, nY )Lidar com roda do mouse para rolagem manual

Exemplo: Carrossel de Imagens

#include "FiveWin.ch"

function Main()

   local oWnd, oScroll

   DEFINE WINDOW oWnd TITLE "Image Carousel" SIZE 800, 300

   oScroll = TScrollImg():New( 10, 10, 780, 240, oWnd,;
      { "banner1.jpg", "banner2.jpg", "banner3.jpg", "banner4.jpg" },;
      1, 3, 20 )

   oScroll:Animate()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O array aBanners pode conter nomes de arquivo, ou sub-arrays com { file, url, action, prompt } para interatividade estendida.
  • O modo determina a direção de rolagem: 1 = horizontal esquerda, 2 = horizontal direita, 3 = vertical cima, 4 = vertical baixo.
  • Quando o mouse passa sobre uma imagem, nZoomedImage ativa um efeito de zoom usando nZoomFactor.
  • Transições de opacidade (desvanecimento) são aplicadas via aOpacity e lFading / nFadeDuration.
  • A persistência de estado com SaveState / LoadState permite que o carrossel retome de onde parou.

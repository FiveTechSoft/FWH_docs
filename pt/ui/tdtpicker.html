TDatePick

Fonte: source/classes/tdtpicke.prg

Herda de: TControl

TDatePick wraps the Windows date and time picker common control (SysDateTimePick32). It provides a drop-down calendar for date selection and supports both date-only and date-time modes with configurable display formats, range restrictions, and multi-select capability.

Sintaxe do Comando

@ nRow, nCol DTPICKER oDtp VAR dDate SIZE nW, nH PIXEL OF oWnd ;
   PICTURE cFmt ON CHANGE bBlock

Exemplos

Seletor de Data com Formato

#include "FiveWin.ch"

function Main()

   local oWnd, oDtp, dDate := Date()

   DEFINE WINDOW oWnd TITLE "Date Picker Demo" SIZE 350, 200

   @ 40, 30 DTPICKER oDtp VAR dDate SIZE 120, 22 PIXEL OF oWnd ;
      PICTURE "dd/mm/yyyy" ;
      ON CHANGE MsgInfo( DToC( dDate ), "Date Changed" )

   oDtp:SetRange( Date() - 365, Date() + 365 )

   @ 100, 30 BUTTON "&Get Date" SIZE 80, 25 PIXEL OF oWnd ;
      ACTION MsgInfo( DToC( oDtp:GetDate() ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Seletor de Data-Hora

#include "FiveWin.ch"

function Main()

   local oWnd, oDtp, tDateTime := DateTime()

   DEFINE WINDOW oWnd TITLE "DateTime Picker" SIZE 350, 200

   @ 40, 30 DTPICKER oDtp VAR tDateTime SIZE 180, 22 PIXEL OF oWnd ;
      PICTURE "dd/mm/yyyy HH:MM:SS"

   @ 100, 30 BUTTON "&Show" SIZE 80, 25 PIXEL OF oWnd ;
      ACTION MsgInfo( DToC( oDtp:GetDate() ), "Selected" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • Quando a variável vinculada é do tipo T (DateTime), o controle alterna automaticamente para o modo data-hora (lDateTime := .T.) e exibe a parte da hora.
  • A cláusula PICTURE aceita strings de formato de data/hora padrão: dd/mm/yyyy, mm/dd/yyyy, yyyy-mm-dd, e adicionando HH:MM:SS para exibição da hora.
  • Use SetRange() para restringir o intervalo de datas que o usuário pode selecionar. O calendário suspenso mostrará datas fora deste intervalo em cinza.
  • O método Open() abre programaticamente o calendário suspenso MonthCal, que é útil para fluxos de validação ou reseleção.
  • As opções de seleção múltipla (lMultiSelect, lWeekNumbers) se aplicam ao calendário suspenso e são definidas antes da criação do controle.

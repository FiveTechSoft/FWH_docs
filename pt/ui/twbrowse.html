TWBrowse

Fonte: source/classes/wbrowse.prg

Herda de: TControl

TWBrowse é o controle de navegação original do FiveWin para percorrer registros de banco de dados e dados de array em formato tabular. Ele fornece cabeçalhos de coluna, dimensionamento ajustável de colunas, navegação por teclado, edição inline e integração com objetos de banco de dados, arrays e recordsets ADO. TXBrowse é o sucessor moderno, mas TWBrowse permanece em uso ativo para cenários mais simples.

Exemplo: Browse de 3 Colunas Vinculado a DBF

#include "FiveWin.ch"

function Main()

   local oWnd, oBrw

   USE CUSTOMER NEW

   DEFINE WINDOW oWnd TITLE "Customers" SIZE 600, 400

   @ 10, 10 BROWSE oBrw ;
      HEADERS "Code", "Name", "City" ;
      SIZES 60, 200, 150 ;
      OF oWnd

   oBrw:SetOBJ( TDatabase():Open( nil, "CUSTOMER" ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TWBrowse suporta três modos de vinculação de dados: array (SetArray), objeto de banco de dados (SetOBJ) e recordset ADO (SetADO).
  • Para navegação simples de DBF sem um objeto TDatabase explícito, o browse usa automaticamente a área de trabalho atual (cAlias).
  • O bloco de código bLine permite a renderização personalizada de linhas. Ele recebe o objeto da linha e o array de valores de coluna como parâmetros.
  • Use bSkip para implementar lógica de navegação personalizada para fontes de dados não padronizadas.
  • Para novos projetos, considere usar TXBrowse, que oferece recursos mais avançados, incluindo cabeçalhos com bitmap, rodapés, grupos e estilização avançada.

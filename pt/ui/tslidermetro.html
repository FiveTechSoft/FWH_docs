TSliderMetro

Fonte: source/classes/sliderm.prg

Não herdada de TControl (classe independente)

TSliderMetro implementa uma tela de deslizar-para-desbloquear no estilo Windows Metro / Modern UI. Ela exibe uma sobreposição de bitmap em tela cheia com os textos "FiveWin touch" e "Slide to unlock", e responde a gestos de arraste vertical. Arrastar o bitmap para cima revela a janela subjacente. Foi projetada para aplicações de quiosque ou tablet com suporte a toque.

Principais Membros DATA

DATATipoDescrição
oBmpObjetoInstância de TBitmap que contém a imagem de fundo em tela cheia
oFont1ObjetoFonte grande ("Segoe UI Light" 90pt negrito) para o texto do título
oFont2ObjetoFonte média ("Segoe UI Light" 60pt negrito) para o texto de instrução
lDragLógicoIndica que uma operação de arraste está em andamento

Métodos

MétodoDescrição
New( cBmpFile, oWnd )Cria uma sobreposição de deslizar-para-desbloquear. Carrega o bitmap de fundo e cria as fontes do título
GoBottom()Anima o bitmap de volta à posição bloqueada (nTop = 0)
GoTop()Anima o bitmap para cima, para fora da tela, desbloqueando a janela
MouseMove( nRow, nCol )Rastreia a distância de arraste vertical e reposiciona o bitmap de acordo

Exemplo: Tela de Desbloqueio

#include "FiveWin.ch"

function Main()

   local oWnd, oLock

   DEFINE WINDOW oWnd TITLE "App" SIZE 800, 600

   oLock = TSliderMetro():New( "lock_bg.jpg", oWnd )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TSliderMetro não é descendente de TControl; ela gerencia um TBitmap diretamente através do handle da janela.
  • O bitmap de fundo deve corresponder às dimensões da janela para um efeito de tela cheia perfeito.
  • O texto é desenhado sobre o bitmap usando oBmp:Say() no codeblock bPainted com cor branca e fontes Segoe UI Light.
  • Arrastar o bitmap mais da metade para cima dispara GoTop(), que move o bitmap para fora da tela e habilita a janela subjacente.
  • Arrastar menos da metade ou soltar abaixo do ponto médio dispara GoBottom(), que encaixa o bloqueio de volta no lugar.
  • GoTop() desabilita a janela de origem durante a animação e a reabilita quando concluída.

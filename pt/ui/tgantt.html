TGantt

Fonte: source/classes/gantt.prg

Herda de: TControl

TGantt é o controle de gráfico de Gantt do FiveWin para agendamento de projetos e visualização de linhas do tempo. Ele exibe barras horizontais em uma grade baseada em tempo, onde cada barra representa uma tarefa com suas datas de início e fim. O controle suporta operações interativas com mouse, visualizações de grade mês-dia e recálculo dinâmico.

TGanttItem

Cada barra no gráfico de Gantt é representada por um objeto TGanttItem com as seguintes propriedades:

PropriedadeTipoDescrição
nRowNuméricoPosição da linha do item
nStartNuméricoColuna de início (normalmente o número do dia)
nEndNuméricoColuna de fim (normalmente o número do dia)
nClrBackNuméricoCor de fundo da barra

Exemplo: Gráfico de Gantt de Planejamento de Projeto

#include "FiveWin.ch"

function Main()

   local oWnd, oGantt

   DEFINE WINDOW oWnd TITLE "Project Plan" SIZE 800, 400

   @ 10, 10 GANTT oGantt SIZE 760, 340 OF oWnd ;
      CHANGE { |oItem| MsgInfo( "Item changed: Row " + Str( oItem:nRow ) ) }

   // Configure month-day grid for a 4-week view
   oGantt:SetGridMonth( 4 )
   oGantt:nCols := 28

   // Add tasks (row, start_day, end_day, color)
   oGantt:AddItem( 1, 1,  5, CLR_HRED )
   oGantt:AddItem( 2, 3,  10, CLR_HBLUE )
   oGantt:AddItem( 3, 6,  18, CLR_HGREEN )
   oGantt:AddItem( 4, 12, 22, RGB( 255, 165, 0 ) )
   oGantt:AddItem( 5, 15, 28, CLR_HMAGENTA )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use SetGridMonth( nRows ) para exibir cabeçalhos de dia da semana/mês. nRows determina quantas semanas são visíveis. Sem isso, a grade mostra um cabeçalho simples de número de coluna.
  • Os itens são armazenados em aItems como objetos TGanttItem. Use AtItem( nRow, nCol ) para localizar um item em uma coordenada específica da grade.
  • O bloco de código bChange é acionado quando um item é arrastado ou modificado via interação do mouse. O bloco de código recebe o TGanttItem afetado como parâmetro.
  • O controle recalcula as posições das células ao redimensionar via ReCalculate(), que é chamado automaticamente pelo método Resize.
  • As dimensões das células (nCellWidth, nCellHeight) podem ser ajustadas para se adequar a diferentes densidades de exibição ou durações de projeto.

TRbGroup / TRBtn / TRPanel — Elementos de Fita

Fontes: source/classes/trbgroup.prg, source/classes/trbtn.prg, source/classes/trpanel.prg

Herda de: TControl (todos os três)

TRbGroup, TRBtn e TRPanel são os blocos de construção do sistema de barra de fitas. TRbGroup representa um grupo nomeado de botões dentro de uma fita. TRBtn é um botão de fita individual suportando layouts normal, popup e split-popup. TRPanel é um painel leve usado como contêiner para controles de fita. Juntos fornecem a interface de usuário de fita estilo Office 2007/2010.

Exemplo: Grupo de Fita com Três Botões

#include "FiveWin.ch"

function Main()

   local oWnd, oRBar, oGrp, oBtn1, oBtn2, oBtn3

   DEFINE WINDOW oWnd TITLE "Ribbon Demo" SIZE 800, 500

   oRBar = TRibbonBar():New( oWnd )

   oGrp = TRbGroup():New( oWnd, 30, 10, 90, 180, 1, "Clipboard",;
                          {|| MsgInfo( "Group clicked" ) } )
   oGrp:aGradSel := { { 1, CLR_WHITE, CLR_HGRAY } }

   oBtn1 = TRBtn():New( 35, 20, 32, 32, "Paste", {|| MsgInfo( "Paste" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn1 )

   oBtn2 = TRBtn():New( 35, 60, 32, 32, "Copy", {|| MsgInfo( "Copy" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn2 )

   oBtn3 = TRBtn():New( 35, 100, 32, 32, "Cut", {|| MsgInfo( "Cut" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn3 )

   oRBar:AddGroup( oGrp )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TRbGroup atua como contêiner para instâncias de TRBtn e desenha a legenda e borda do grupo.
  • TRBtn suporta três tipos visuais: NORMAL (alvo de único clique), POPUP (clique mostra popup) e SPLITPOPUP (clique executa ação, seta mostra popup).
  • A propriedade nLayout controla a posição do texto em relação ao bitmap: TOP, LEFT, BOTTOM, RIGHT, MOSTLEFT, MOSTRIGHT ou CENTER.
  • TRPanel é o contêiner mais simples; desenha um retângulo preenchido usando o pincel da janela pai.
  • Arrays gradientes seguem o formato { { fraction, color1, color2 }, ... } usado em todo FWH.

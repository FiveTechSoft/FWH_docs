TRbGroup / TRBtn / TRPanel — Ribbon Elements

Fonte: source/classes/trbgroup.prg, source/classes/trbtn.prg, source/classes/trpanel.prg

Inherits from: TControl (all three)

TRbGroup, TRBtn and TRPanel are the building blocks of the ribbon bar system. TRbGroup represents a named group of buttons inside a ribbon. TRBtn is an individual ribbon button supporting normal, popup and split-popup layouts. TRPanel is a lightweight panel used as a container for ribbon controls. Together they provide the Office 2007/2010-style ribbon user interface.

Example: Ribbon Group with Three Buttons

#include "FiveWin.ch"

function Main()

   local oWnd, oRBar, oGrp, oBtn1, oBtn2, oBtn3

   DEFINE WINDOW oWnd TITLE "Ribbon Demo" SIZE 800, 500

   oRBar = TRibbonBar():New( oWnd )

   oGrp = TRbGroup():New( oWnd, 30, 10, 90, 180, 1, "Clipboard",;
                          {|| MsgInfo( "Group clicked" ) } )
   oGrp:aGradSel := { { 1, CLR_WHITE, CLR_HGRAY } }

   oBtn1 = TRBtn():New( 35, 20, 32, 32, "Paste", {|| MsgInfo( "Paste" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn1 )

   oBtn2 = TRBtn():New( 35, 60, 32, 32, "Copy", {|| MsgInfo( "Copy" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn2 )

   oBtn3 = TRBtn():New( 35, 100, 32, 32, "Cut", {|| MsgInfo( "Cut" ) },;
                        oWnd,,,, .T., .T., "TOP" )
   oGrp:AddButton( oBtn3 )

   oRBar:AddGroup( oGrp )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • TRbGroup acts as a container for TRBtn instances and draws the group caption and border.
  • TRBtn supports three visual types: NORMAL (single click target), POPUP (click shows popup), and SPLITPOPUP (click executes action, arrow shows popup).
  • The nLayout property controls text position relative to the bitmap: TOP, LEFT, BOTTOM, RIGHT, MOSTLEFT, MOSTRIGHT or CENTER.
  • TRPanel is the simplest container; it draws a filled rectangle using the parent window brush.
  • Gradient arrays follow the { { fraction, color1, color2 }, ... } format used throughout FWH.

TRadio

Fonte: source/classes/radio.prg

Herda de: TControl

TRadio implementa um botão de rádio individual (estilo de botão de rádio automático). Botões de rádio são usados em grupos onde apenas uma opção pode ser selecionada por vez. Eles são tipicamente gerenciados por um pai TRadMenu que lida com a exclusão mútua e navegação por teclado dentro do grupo.

Principais Membros DATA

DATATipoDescrição
lCheckedLogicalEstado marcado atual do botão de rádio
oRadMenuObjectTRadMenu pai que gerencia este grupo de botões de rádio
nPosNumericPosição/índice deste botão dentro do grupo

Métodos

MétodoDescrição
New( nRow, nCol, cPrompt, oWnd, bSetGet, lChecked, nPos, oRadMenu )Criar um botão de rádio; bSetGet é um bloco de código SETGET para o valor selecionado
Redefine( nId, lChecked, nPos, oDlg, oRadMenu )Redefinir a partir de um recurso de diálogo
SetCheck( lOnOff )Definir o estado marcado e atualizar o controle de botão do Windows
IsChecked()Consultar o estado marcado do botão no Windows
Check()Definir marcado como .T. (método de conveniência)
UnCheck()Definir marcado como .F. (método de conveniência)
Click()Gerenciar clique: seleciona este botão no TRadMenu pai e atualiza

Comandos

@ nRow, nCol RADIO oRad VAR nOpt PROMPT cText OF oDlg

Exemplo: Grupo de Rádio com TRadMenu

#include "FiveWin.ch"

function Main()

   local oWnd, oRadMenu, nOption := 1

   DEFINE WINDOW oWnd TITLE "Radio Demo" SIZE 300, 200

   @ 10, 10 RADIO oRadMenu VAR nOption ;
      ITEMS "Option &1", "Option &2", "Option &3" ;
      OF oWnd SIZE 120, 80

   @ 100, 10 BUTTON "Show" SIZE 60, 25 OF oWnd ;
      ACTION MsgInfo( "Selected: " + Str( nOption ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Cada TRadio é um controle Windows BS_AUTORADIOBUTTON. O primeiro botão em um grupo deve usar o parâmetro lGroup (estilo WS_GROUP) para definir os limites do grupo.
  • ACCESS lChanged compara o estado marcado atual com o valor original, útil para rastreamento de alterações.
  • Botões TRadio são tipicamente criados via comando RADIO, que configura automaticamente o TRadMenu e os objetos TRadio individuais.
  • A navegação por teclado (teclas de seta) dentro do grupo é gerenciada pelo TRadMenu pai.

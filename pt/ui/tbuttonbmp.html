TButtonBmp

Source: source/classes/buttonb.prg

Inherits from: TButton

TButtonBmp is a push button that displays a bitmap image alongside or instead of text. It supports multiple image formats, alpha-channel transparency, GDI+ rendering, color mapping, and flexible text positioning. TButtonBmp is commonly used inside TBar and TRibbonBar controls.

Command Syntax

@ nRow, nCol BTNBMP oBtn PROMPT cText FILE cBmp SIZE nW, nH ACTION bAct

Example: Button with Icon

#include "FiveWin.ch"

function Main()

   local oWnd, oBtn

   DEFINE WINDOW oWnd TITLE "Bitmap Button Demo" SIZE 400, 200

   @ 20, 20 BTNBMP oBtn ;
      PROMPT "Open File" ;
      FILE "open.bmp" ;
      SIZE 120, 40 ;
      ACTION MsgInfo( "Open clicked" ) ;
      OF oWnd

   oBtn:cPosText := "TEXTBOTTOM"

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • The BTNBMP command is the preferred way to create TButtonBmp controls. It supports FILE (file path) and RESOURCE (resource ID) bitmap sources.
  • Text position is controlled by cPosText: TEXTTOP, TEXTBOTTOM, TEXTLEFT, or TEXTRIGHT. The class default is set via cPosDefault.
  • Use bColorMap to dynamically recolor bitmap pixels, enabling hover/hot effects and theme adaptation.
  • GDI+ rendering (lGDIP) provides anti-aliased scaling and alpha blending for high-quality display.
  • Flat style is enabled with the lFlat parameter or NOBORDER clause.

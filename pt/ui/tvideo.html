TVideo

Fonte: source/classes/video.prg

Herda de: TControl

TVideo é um controle de reprodução de mídia que usa o Windows MCI (Media Control Interface) para reproduzir arquivos de vídeo. Ele suporta AVI e outros formatos de vídeo compatíveis com MCI. O controle exibe o vídeo em uma área retangular dentro de uma janela ou diálogo FiveWin, com renderização sem borda opcional.

Membros DATA Principais

DATATipoDescrição
oMciObjetoObjeto interno do dispositivo MCI que gerencia a reprodução
cAviFileCaractereCaminho para o arquivo AVI (ou outro vídeo)
cTypeCaractereString do tipo de dispositivo MCI (ex.: "AVIVideo")

Métodos

MétodoDescrição
New( nRow, nCol, nW, nH, cFile, oWnd, lNoBorder, cType )Cria um novo controle de reprodução de vídeo
Play( nFrom, nTo )Reproduz o vídeo do quadro nFrom até nTo. Se omitido, reproduz o vídeo inteiro.
PlayFull()Reproduz o vídeo em modo tela cheia
Position()Retorna a posição atual de reprodução em quadros
Length()Retorna o número total de quadros no vídeo
End()Para a reprodução e fecha o dispositivo MCI

Exemplo: Reproduzir Arquivo AVI

#include "FiveWin.ch"

function Main()

   local oWnd, oVideo

   DEFINE WINDOW oWnd TITLE "Reprodutor de Vídeo" SIZE 640, 520

   @ 10, 10 VIDEO oVideo FILE "sample.avi" ;
      SIZE 600, 450 OF oWnd

   oVideo:Play()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TVideo encapsula a API MCI do Windows (mciSendString) para reprodução de vídeo. Certifique-se de que os drivers MCI apropriados estejam instalados no sistema de destino.
  • Use o parâmetro lNoBorder em New() para remover a borda ao redor da área de exibição do vídeo.
  • O parâmetro cType especifica o tipo de dispositivo MCI. O padrão é "AVIVideo" para arquivos AVI.
  • Chame End() quando o vídeo não for mais necessário para liberar os recursos do dispositivo MCI.

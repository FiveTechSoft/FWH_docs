TExplorerBar

Fonte: source/classes/texplbar.prg

Herda de: TControl

TExplorerBar é um painel de tarefas vertical estilo Outlook com seções recolhíveis e cabeçalhos gradientes. Cada seção é representada por um objeto filho TTaskPanel que pode ser expandido ou recolhido clicando em sua barra de título. O painel suporta rolagem vertical quando o conteúdo excede a área visível. Each section is represented by a TTaskPanel child object that can be expanded or collapsed by clicking its title bar. The panel supports vertical scrolling when content exceeds the visible area, making it suitable for navigation menus, task lists, and property groups.

Sintaxe do Comando

@ nRow, nCol EXPLORERBAR oBar OF oWnd SIZE nW, nH

Exemplo: Barra Exploradora com Dois Painéis

#include "FiveWin.ch"

function Main()

   local oWnd, oBar, oPanel

   DEFINE WINDOW oWnd TITLE "Explorer Bar Demo" SIZE 300, 500

   @ 0, 0 EXPLORERBAR oBar OF oWnd SIZE 300, 500

   // "Documents" panel with 2 links
   oPanel = oBar:AddPanel( "Documents",, 60, 25 )
   oPanel:AddLink( "Open Recent", { || MsgInfo( "Recent docs" ) }, "fileopen.bmp" )
   oPanel:AddLink( "Browse Folders", { || MsgInfo( "Browse" ) }, "folders.bmp" )

   // "Tools" panel with 2 links
   oPanel = oBar:AddPanel( "Tools",, 60, 25 )
   oPanel:AddLink( "Settings", { || MsgInfo( "Settings" ) }, "settings.bmp" )
   oPanel:AddLink( "Help", { || MsgInfo( "Help" ) }, "help.bmp" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notes

  • Use a sintaxe do comando EXPLORERBAR para criar a barra; os painéis são adicionados programaticamente com AddPanel().
  • Clicar na barra de título de um painel alterna seu estado recolhido. O método CloseAll() recolhe todos os painéis exceto o especificado. The CloseAll() method collapses all panels except the specified one.
  • Each panel can display a bitmap in its header area (specified via cBmpName in AddPanel()).
  • Links inside panels are TUrlLink controls that support hover effects, tooltips, and custom colors.
  • The bar automatically manages vertical scrolling when panels extend beyond the visible area.
  • Visual styles (l2007, l2010, l2013, l2015) adjust the default appearance to match Windows version aesthetics.

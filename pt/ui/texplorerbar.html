TExplorerBar

Fonte: source/classes/texplbar.prg

Herda de: TControl

TExplorerBar é um painel de tarefas vertical estilo Outlook com seções recolhíveis e cabeçalhos gradientes. Cada seção é representada por um objeto filho TTaskPanel que pode ser expandido ou recolhido clicando em sua barra de título. O painel suporta rolagem vertical quando o conteúdo excede a área visível, tornando-o adequado para menus de navegação, listas de tarefas e grupos de propriedades.

Sintaxe do Comando

@ nRow, nCol EXPLORERBAR oBar OF oWnd SIZE nW, nH

Exemplo: Barra Exploradora com Dois Painéis

#include "FiveWin.ch"

function Main()

   local oWnd, oBar, oPanel

   DEFINE WINDOW oWnd TITLE "Explorer Bar Demo" SIZE 300, 500

   @ 0, 0 EXPLORERBAR oBar OF oWnd SIZE 300, 500

   // painel "Documents" com 2 links
   oPanel = oBar:AddPanel( "Documents",, 60, 25 )
   oPanel:AddLink( "Open Recent", { || MsgInfo( "Recent docs" ) }, "fileopen.bmp" )
   oPanel:AddLink( "Browse Folders", { || MsgInfo( "Browse" ) }, "folders.bmp" )

   // painel "Tools" com 2 links
   oPanel = oBar:AddPanel( "Tools",, 60, 25 )
   oPanel:AddLink( "Settings", { || MsgInfo( "Settings" ) }, "settings.bmp" )
   oPanel:AddLink( "Help", { || MsgInfo( "Help" ) }, "help.bmp" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use a sintaxe do comando EXPLORERBAR para criar a barra; os painéis são adicionados programaticamente com AddPanel().
  • Clicar na barra de título de um painel alterna seu estado recolhido. O método CloseAll() recolhe todos os painéis exceto o especificado.
  • Cada painel pode exibir um bitmap em sua área de cabeçalho (especificado via cBmpName em AddPanel()).
  • Os links dentro dos painéis são controles TUrlLink que suportam efeitos de hover, tooltips e cores personalizadas.
  • A barra gerencia automaticamente a rolagem vertical quando os painéis se estendem além da área visível.
  • Os estilos visuais (l2007, l2010, l2013, l2015) ajustam a aparência padrão para corresponder à estética da versão do Windows.

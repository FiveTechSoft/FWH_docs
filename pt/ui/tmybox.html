TMyBox

Fonte: source/classes/tmybox.prg

Herda de: TControl

TMyBox é um controle de caixa de grupo (group box) colorida com título personalizável. Diferente da caixa de grupo padrão, TMyBox suporta cores personalizadas para o texto do título, o fundo do título e a borda, além de alinhamento centralizado opcional do título e renderização com meia largura.

Membros DATA Principais

DATATipoDescrição
cTitleCaractereTexto do título exibido no cabeçalho da caixa
nClrTitleTextNuméricoCor do texto do título (valor RGB)
nClrTitleBackNuméricoCor de preenchimento do fundo do título (valor RGB)
nClrBorderNuméricoCor da linha da borda (valor RGB)
lTitleCenterLógicoCentraliza o texto do título horizontalmente na caixa
lHalfWidthLógicoRenderiza a caixa com metade da largura especificada

Métodos

MétodoDescrição
New( oWnd, nT, nL, nH, nW, cTitle, nClrTT, nClrTB, nClrB )Cria uma nova caixa de grupo colorida com valores de cor opcionais
ReDefine( nId, oWnd, cTitle )Redefine a partir de um recurso de diálogo pelo ID do controle
SetTitle( c )Altera o texto do título em tempo de execução
Paint()Desenha a borda da caixa, o fundo do título e o texto do título

Comandos

@ nRow, nCol MYBOX oBox TITLE cText SIZE nW, nH OF oDlg

Exemplo: Caixa com Título Azul

#include "FiveWin.ch"

function Main()

   local oWnd, oBox

   DEFINE WINDOW oWnd TITLE "TMyBox Demo" SIZE 400, 300

   @ 20, 20 MYBOX oBox TITLE "Customer Info" ;
      SIZE 360, 150 OF oWnd

   oBox:nClrTitleText := CLR_WHITE
   oBox:nClrTitleBack := CLR_BLUE
   oBox:nClrBorder    := CLR_BLUE
   oBox:lTitleCenter  := .T.

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TMyBox é puramente visual e não recorta (clip) controles filhos; ela desenha apenas um quadro decorativo e o título.
  • Defina os valores de cor como nil no construtor para usar as cores padrão do sistema para cada elemento.
  • O sinalizador lHalfWidth é útil quando a caixa é colocada em um diálogo redimensionável e deve adaptar-se ao espaço disponível.
  • Use SetTitle() para atualizar o título dinamicamente, por exemplo quando o idioma ou o contexto mudam.

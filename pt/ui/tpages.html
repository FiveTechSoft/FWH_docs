TPages

Fonte: source/classes/tpages.prg

Herda de: TControl, usa TPagesDialog

TPages é um contêiner de páginas com abas que gerencia uma coleção de páginas de diálogo dentro de uma única área de janela pai. Cada página é um diálogo hospedado dentro do contêiner, e o usuário alterna entre páginas programaticamente ou via controles de abas associados. Internamente funciona com TPagesDialog para renderizar cada superfície de página.

Principais Membros DATA

DATATipoDescrição
nOptionNumericÍndice da página atualmente selecionada (base 1)
aDialogsArrayArray de objetos de diálogo filho, um por página
aPagesArrayArray de definições de página { cTitle, nId, bInit }
bChangeBlockBloco de código executado quando a página ativa muda

Métodos

MétodoDescrição
New( nRow, nCol, nBottom, nRight, oWnd )Criar um novo contêiner TPages dentro de uma janela
Redefine( nId, oWnd, aDialogs, nOption, bChange )Recriar a partir de um controle de recurso de diálogo
AddPage( cPage )Adicionar uma nova página com o título fornecido
DelPage( nPage )Remover a página no índice especificado
SetOption( n )Alternar para a página no índice n
GoPrev()Alternar para a página anterior
GoNext()Alternar para a próxima página

Exemplo: Contêiner de Duas Páginas

#include "FiveWin.ch"

function Main()

   local oWnd, oPages

   DEFINE WINDOW oWnd TITLE "TPages Demo" SIZE 500, 400

   @ 10, 10 PAGES oPages SIZE 460, 340 OF oWnd

   oPages:AddPage( "General" )
   oPages:AddPage( "Advanced" )

   @ 20, 20 SAY "User Name" OF oPages:aDialogs[ 1 ] SIZE 60, 12
   @ 20, 100 GET ... OF oPages:aDialogs[ 1 ]

   @ 20, 20 SAY "Timeout" OF oPages:aDialogs[ 2 ] SIZE 60, 12
   @ 20, 100 GET ... OF oPages:aDialogs[ 2 ]

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Cada página é implementada como um diálogo filho não modal. Acesse os controles filhos através do objeto de diálogo correspondente em aDialogs.
  • Use bChange para realizar validação ou atualizar o estado da interface quando o usuário alternar páginas.
  • TPagesDialog é a classe de diálogo interna usada para cada superfície de página; normalmente não é instanciada diretamente.
  • O contêiner executa o bloco de código bChange com o novo índice de opção cada vez que a página é alternada.

TMsgBar / TMsgItem

Fontes: source/classes/msgbar.prg, source/classes/tmsgitem.prg

TMsgBar herda de TControl; TMsgItem é uma classe auxiliar

TMsgBar é uma substituição de barra de status com temas que suporta itens interativos incorporados (relógio, data, indicadores de teclado e botões de ação personalizados). Oferece estilos visuais Office 2007/2010/2015 e alinhamento centralizado de texto. TMsgItem define itens individuais incorporáveis dentro de um TMsgBar.

Exemplo: Barra de Mensagens com Relógio e Item Personalizado

#include "FiveWin.ch"

function Main()

   local oWnd, oMsgBar, oItem

   DEFINE WINDOW oWnd TITLE "TMsgBar Demo" SIZE 600, 400

   DEFINE MSGBAR oMsgBar OF oWnd PROMPT "Ready" ;
      2010 CLOCK DATE KEYBOARD

   // Adicionar um item personalizado clicavel
   oItem := TMsgItem():New( oMsgBar, "Records: 0", 120 )
   oItem:bAction := {|| MsgInfo( "Status clicked!" ) }
   oMsgBar:AddItem( oItem )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TMsgBar suporta temas visuais através dos indicadores l2007, l2010 e l2015. Apenas um tema deve estar habilitado por vez.
  • As cláusulas CLOCK, DATE e KEYBOARD (ou métodos correspondentes) adicionam indicadores de sistema padrão. Relógio e data são atualizados automaticamente via um temporizador interno.
  • TMsgItem suporta bitmaps de dois estados (hBitmap1 para "ligado", hBitmap2 para "desligado"), úteis para indicadores de alternância. Defina lActive para alternar entre eles.
  • Use ShowPopup() para anexar um menu popup a um item, permitindo ações sensíveis ao contexto quando o usuário clica no item.
  • TMsgBar é tipicamente usado como oWnd:oMsgBar e substitui o tradicional oWnd:oStatusBar em aplicações com temas.

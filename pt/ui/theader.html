THeader

Fonte: source/classes/theader.prg

Herda de: TControl

THeader is a wrapper for the Win32 SysHeader32 common control. It provides a clickable, resizable column header bar typically used above list views or custom grid controls. Each column can display a prompt, have a specific width, support click-to-sort arrows, and fire an action when clicked. The control supports hot-track highlighting and full-drag column resizing.

Principais Membros DATA

DATATipoDescrição

aSizesArrayMatriz de larguras de coluna em pixels
bActionBlockBloco de código executado ao clicar na coluna. Recebe o índice nItem e Self.

Exemplo: Cabeçalho de Três Colunas com Ação de Clique

#include "FiveWin.ch"

function Main()

   local oWnd, oHeader, aPrompts, aSizes

   aPrompts := { "Name", "Date", "Size" }
   aSizes   := { 150, 100, 80 }

   DEFINE WINDOW oWnd TITLE "Header Demo" SIZE 400, 200

   oHeader := THeader():New( oWnd, 10, 10, 380, 22, aPrompts, aSizes,,, ;
                             , { | nItem, oCtrl | MsgInfo( "Column " + Str( nItem ) ) } )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • O THeader encapsula o controle comum SysHeader32 (ou SysHeader no Clipper). Ele é registrado com a classe de janela WC_HEADER.
  • As colunas suportam realce de rastreamento (HDS_HOTTRACK) e redimensionamento com arrasto completo (HDS_FULLDRAG).
  • Quando o modo temático está ativo (IsAppThemed()), o controle aplica o estilo HDS_FLAT para uma aparência moderna.
  • O bloco de código bAction é disparado em notificações HDN_ITEMCLICK, recebendo o índice da coluna (base 1) e o objeto THeader como parâmetros.
  • Use SetItem() com o parâmetro nSort para exibir um indicador de seta de classificação (para cima ou para baixo) em uma coluna.
  • O alinhamento da coluna é controlado pelo parâmetro nAlign em InsertItem()/SetItem(), usando as constantes HDF_LEFT, HDF_CENTER ou HDF_RIGHT.

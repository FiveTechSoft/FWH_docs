TStatusBar

Fonte: source/classes/statusba.prg

Herda de: TControl

TStatusBar encapsula o controle comum de barra de status do Windows para exibir uma barra de status com múltiplos painéis na parte inferior de uma janela. Suporta um número arbitrário de painéis com larguras e textos individuais, um relógio integrado e exibição automática de mensagens com tempo de expiração configurável.

Principais Membros DATA

DATATipoDescrição
cMsgDefCaractereTexto padrão da mensagem da barra de status
oTimerObjetoTemporizador interno para expiração de mensagens e atualizações do relógio
nPartTimeNuméricoÍndice do painel reservado para a exibição do relógio

Métodos

MétodoDescrição
New( oWnd, cText, aWidths, aPrompts, lClock )Cria um novo controle TStatusBar
SetMsg( cText )Define o texto da barra de status (normalmente a partir de oWnd:SetMsg())
SetParts( aWidths )Define as larguras dos painéis como um array de valores numéricos
SetPartText( nPart, cText )Define o texto de um painel específico por índice
GetParts()Retorna as definições atuais de largura dos painéis
ClockOn()Ativa a exibição do relógio no último painel

Exemplo: Barra de Status de 3 Painéis com Relógio

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "StatusBar Demo" SIZE 600, 400

   DEFINE STATUSBAR oWnd PROMPT "Ready" ;
      CLOCK ;
      PARTS 150, 300

   // Define o texto em painéis individuais
   oWnd:oStatusBar:SetPartText( 2, "User: Admin" )
   oWnd:oStatusBar:SetPartText( 3, "Records: 42" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • A barra de status é criada automaticamente na parte inferior da janela. O comando DEFINE STATUSBAR fornece a sintaxe mais conveniente; TStatusBar():New() pode ser usado para criação programática.
  • As larguras dos painéis em SetParts() são especificadas como valores em pixels. O último painel sempre se estende para preencher o espaço restante, independentemente da largura especificada.
  • A cláusula CLOCK (ou ClockOn()) ativa um relógio em tempo real no painel mais à direita, atualizado a cada segundo por meio de um temporizador interno.
  • As mensagens definidas via SetMsg() são exibidas no primeiro painel (mais à esquerda). A mensagem reverte automaticamente para cMsgDef após o período de expiração definido por nPartTime.
  • TStatusBar usa o controle comum de barra de status do Windows (msctls_statusbar32), que fornece dimensionamento e posicionamento automáticos na parte inferior da janela pai.

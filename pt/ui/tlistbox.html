TListBox

Fonte: source/classes/listbox.prg

Herda de: TControl

TListBox encapsula o controle de caixa de listagem padrão do Windows (LISTBOX). Exibe uma lista rolável de itens da qual o usuário pode selecionar uma ou várias entradas. TListBox suporta itens desenhados pelo proprietário com bitmaps, reordenação por arrastar e soltar, modos de seleção múltipla, navegação por teclado e dicas de ferramentas por item. É o controle de lista padrão de coluna única no FiveWin.

Principais Membros DATA

DATATipoDescrição
aItemsArrayArray de strings de caracteres exibidas na caixa de listagem.
aBitmapsArrayArray de handles de bitmap ou nomes de recursos para itens de bitmap desenhados pelo proprietário. Cada entrada corresponde a um item em aItems.
bSetGetBlockBloco de vinculação de dados. Quando avaliado sem argumentos, retorna o valor do item selecionado; com um argumento, seleciona esse item.
lOwnerDrawLogicalSe .T., a caixa de listagem é desenhada pelo proprietário, permitindo a renderização personalizada de itens via bDrawItem.
bDrawItemBlockBloco de código de desenho personalizado para itens desenhados pelo proprietário: { |nItem, hDC, aRect, nState, oLbx| ... }.
lMultiSelectLogicalSe .T., vários itens podem ser selecionados de uma vez.
lDragLogicalHabilita a reordenação de itens da lista por arrastar e soltar com o mouse.
bChangeBlockAvaliado quando a seleção muda: { |nItem, oLbx| ... }.
bValidBlockBloco de validação avaliado quando a caixa de listagem perde o foco.
nAtNumericÍndice do item atualmente selecionado (baseado em 1). 0 significa nenhuma seleção.

Métodos

MétodoDescrição
New( nRow, nCol, bSetGet, aItems, nW, nH, oWnd, lMultiSel, lDrag, lOwner, oFont, bDraw, lPixel, lDesign, oIcon, cMsg, lUpdate, bChange, bValid, ... )Cria uma nova caixa de listagem. aItems é o array inicial de itens. bSetGet vincula o valor selecionado a uma variável.
Add( cItem, nAt )Adiciona um novo item. Se nAt for omitido, o item é anexado ao final. Se especificado, é inserido naquela posição.
Del( nAt )Exclui o item na posição nAt (baseado em 1).
Modify( cItem, nAt )Substitui o item na posição nAt pelo novo texto cItem.
Select( nItem )Seleciona programaticamente o item na posição nItem.
SetItems( aItems )Substitui todos os itens da caixa de listagem por um novo array de strings.
GetPos()Retorna o índice do item atualmente selecionado (baseado em 1). Retorna 0 se nenhum item estiver selecionado.
GetSel()Retorna o texto do item selecionado como uma string.
nCount()Retorna o número total de itens na caixa de listagem.
Clear()Remove todos os itens da caixa de listagem.
End()Destrói o controle.

Comandos: @ ... LISTBOX

@ nRow, nCol LISTBOX oLbx ;
   ITEMS aItems ;
   [ VAR uVar ] ;
   [ SIZE nW, nH ] ;
   [ OF oDlg ] ;
   [ MULTISELECT ] ;
   [ DRAG ] ;
   [ ON CHANGE bChange ] ;
   [ ON VALID bValid ] ;
   [ BITMAPS aBitmaps ] ;
   [ OWNERDRAW ]

Exemplo: Caixa de Listagem de 3 Itens

#include "FiveWin.ch"

function Main()

   local oWnd, oLbx, cChoice := ""

   DEFINE WINDOW oWnd TITLE "TListBox Demo" SIZE 400, 300

   @ 20, 20 LISTBOX oLbx ;
      ITEMS { "Apples", "Oranges", "Bananas" } ;
      SIZE 200, 150 OF oWnd ;
      ON CHANGE MsgInfo( "Selected: " + oLbx:GetSel() )

   @ 200, 20 BUTTON "Get Selection" SIZE 120, 30 OF oWnd ;
      ACTION MsgInfo( "Item " + Str( oLbx:GetPos() ) + ;
                      ": " + oLbx:GetSel() )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TListBox herda de TControl. Todos os métodos de controle padrão estão disponíveis.
  • Use lMultiSelect := .T. (ou a cláusula MULTISELECT) para permitir que o usuário selecione vários itens usando Ctrl+clique ou Shift+clique.
  • O bloco bDrawItem habilita a renderização personalizada. Quando lOwnerDraw é .T., a caixa de listagem passa a ser desenhada pelo proprietário e o bloco bDrawItem é chamado para cada item visível durante a pintura.
  • Os bitmaps de item (aBitmaps) fornecem um ícone simples ao lado de cada item sem a necessidade de desenho pelo proprietário. Cada elemento é um handle de bitmap ou nome de recurso.
  • A reordenação por arrastar e soltar é habilitada via a cláusula DRAG. Os itens podem ser arrastados para novas posições dentro da lista.
  • Para a navegação por teclado, a caixa de listagem trata as setas Cima/Baixo, PageUp/PageDown e as teclas Home/End automaticamente.

TToast

Fonte: source/classes/ttoast.prg

Herda de: TWindow

TToast fornece notificações toast na área de trabalho no estilo Windows 8/10. As notificações aparecem como janelas em camadas que se posicionam automaticamente no canto da tela, fecham automaticamente após um tempo configurável e suportam texto de cabeçalho, corpo e rodapé, junto com imagens bitmap opcionais. O controle usa mesclagem alfa para efeitos suaves de transparência e sombras.

Exemplo: Notificação Toast

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "Toast Demo" SIZE 400, 300

   @ 20, 20 BUTTON "Show Toast" SIZE 120, 30 OF oWnd ;
      ACTION ShowToast()

   ACTIVATE WINDOW oWnd CENTERED

return nil

function ShowToast()

   // Show a notification at the bottom-right corner
   // Auto-dismisses after 5000 ms (default)
   TToast():NewToast( ;
      1, ;                     // Notification type
      "System Update##"; + ;   // Header (separated by ##)
      "Your system has been updated successfully." + ;
      "##Please restart to apply changes.", ; // Body
      "..\bitmaps\info.bmp", ; // Optional icon
      320, 120, ;              // Width, Height
      , , , , 5000, .F. )      // 5 sec timeout, bottom position

return nil

Notas

  • TToast usa o método estático NewToast() como sua API principal. Ele cria, posiciona e exibe a janela de notificação em uma única chamada.
  • O formato de texto usa ## como separador: a primeira parte se torna o cabeçalho, a segunda parte o corpo e a terceira (opcional) o texto do rodapé.
  • No Windows 8 e posteriores, o estilo padrão é escuro com fonte Segoe MDL2 Assets. Em sistemas mais antigos, ele usa um tema claro com Tahoma.
  • A opacidade é controlada via nLevel (0-255). A janela usa WS_EX_LAYERED e LWA_ALPHA para mesclagem alfa.
  • Os toasts são empilhados automaticamente: cada novo toast se posiciona acima do anterior. O array de nível de classe aTToast rastreia todas as notificações ativas.
  • Clicar no toast invoca bReturn. O botão fechar (se habilitado) descarta a notificação imediatamente.

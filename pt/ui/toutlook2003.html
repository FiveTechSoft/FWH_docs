TOutLook2003 / TOutLook2010

Fontes: source/classes/outl2003.prg, source/classes/outl2010.prg

Herda de: TControl

TOutLook2003 e TOutLook2010 são controles de painel de navegação modelados segundo a barra lateral do Microsoft Outlook. Eles exibem um cabeçalho, grupos recolhíveis com ícones e uma área de cliente para diálogos filhos. Ambas as classes compartilham a mesma API; a diferença é o esquema de cores (azul do Outlook 2003 vs. cinza claro do Outlook 2010).

Exemplo: Painel de Navegação

#include "FiveWin.ch"

function Main()

   local oWnd, oOutlook
   local aPrompts := { "Mail", "Calendar", "Contacts" }
   local aBitmaps := { "mail.bmp", "cal.bmp", "cont.bmp" }

   DEFINE WINDOW oWnd TITLE "Outlook 2003 Pane" SIZE 700, 500

   @ 0, 0 OUTLOOK2003 oOutlook ;
      PROMPTS aPrompts BITMAPS aBitmaps ;
      SIZE 190, 500 OF oWnd

   // Para estilo Outlook 2010, use OUTLOOK2010
   // @ 0, 0 OUTLOOK2010 oOutlook ...

   ACTIVATE WINDOW oWnd CENTERED

return nil

Diferenças do TOutLook2010

TOutLook2010 usa a mesma API e assinaturas de métodos que TOutLook2003. As únicas diferenças são:

  • Cor de fundo: nRGB( 220, 223, 228 ) (cinza claro) vs. azul escuro do Outlook 2003.
  • As cores de gradiente dos botões de grupo usam tons laranja/ciam quentes em vez de tons azuis.

Notas

  • O painel tem 190 pixels de largura por padrão, posicionado no lado esquerdo da janela.
  • Cada grupo tem um diálogo filho associado criado como uma janela WS_CHILD; alterne grupos clicando no botão do grupo.
  • O bloco bChange é executado quando o usuário seleciona um grupo diferente via SetOption().
  • Um menu popup com clique direito permite que os usuários alternem entre grupos programaticamente.

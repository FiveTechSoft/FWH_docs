TMyTitle

Fonte: source/classes/tmytitle.prg

Herda de: TControl

O TMyTitle é um controle personalizado de barra de título gradiente que pode ser colocado no topo de uma janela ou diálogo. Ele renderiza um fundo preenchido com gradiente (horizontal ou vertical) com texto do título, um bitmap de cabeçalho opcional e um efeito tipo vidro. Ele suporta fontes personalizadas, cores de borda e atualizações em tempo de execução do texto do título e do bitmap.

Exemplo: Barra de Título Gradiente

#include "FiveWin.ch"

function Main()

   local oWnd, oTitle

   DEFINE WINDOW oWnd TITLE "Demo" SIZE 500, 300

   oTitle := TMyTitle():New( oWnd, 0, 0, 50, 500,;
              "My Custom Dialog", CLR_WHITE,;
              nRGB( 89, 135, 214 ), nRGB( 3, 56, 147 ),,,;
              .F., .T., CLR_BLACK, .F. )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • A fonte padrão é Tahoma, tamanho -18, negrito. Uma fonte personalizada pode ser fornecida através do parâmetro oFontTitle.
  • Quando lGlass está .T., a barra usa um gradiente horizontal de duas passagens que cria um efeito de reflexão tipo vidro.
  • Os bitmaps podem ser carregados de arquivo (caminho com extensão) ou de recurso (nome sem extensão). O bitmap é desenhado no deslocamento nOffSetX, nOffSetY a partir do canto superior esquerdo.
  • O escalonamento High-DPI é suportado via nScale, que é calculado automaticamente a partir do DPI lógico da janela ativa.

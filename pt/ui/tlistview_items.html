TListViewItem

Fonte: source/classes/tlistvie.prg

Classe independente (usada por TListView)

TListViewItem representa um item individual em um controle TListView. Cada item pode exibir texto, uma imagem de uma lista de imagens e ser atribuído a um grupo para visualizações categorizadas. Os itens suportam dicas de ferramentas, indentacão e estado marcado.

Principais Membros DATA

DATATipoDescrição
cTextCharacterTexto de exibição do item
nImageNumericÍndice na lista de imagens (0 = sem imagem)
nGroupNumericID do grupo ao qual este item pertence
nItemNumericÍndice do item dentro da visualização de lista

Métodos

MétodoDescrição
New( oParent )Criar um novo item associado a um TListView
Create( oParent )Inserir o item na visualização de lista
SetText( cText ) / GetText()Alterar ou obter o texto do item
SetImage( nImage ) / GetImage()Alterar ou obter o índice da imagem
SetGroup( nGroup )Atribuir o item a um grupo

TListViewGroup

Classe independente (usada por TListView)

Define um cabeçalho de agrupamento visual dentro de uma visualização de lista agrupada. Os grupos organizam itens em categorias recolhíveis.

DATATipoDescrição
cHeaderCharacterTexto do cabeçalho do grupo
nGroupIdNumericIdentificador único do grupo
nStateNumericEstado: normal (0), recolhido (1), oculto (2)
MétodoDescrição
New( oParent )Criar um grupo
Create( oParent )Inserir o grupo na visualização de lista
SetState( nState )Recolher, expandir ou ocultar o grupo

Exemplo: Lista em Grupo

#include "FiveWin.ch"
function Main()
   local oWnd, oList, oGrp1, oGrp2, oItem
   DEFINE WINDOW oWnd TITLE "Grouped ListView" SIZE 500, 400
   @ 10, 10 LISTBOX oList FIELDS "" OF oWnd SIZE 460, 350
   oList:EnableGroupView()
   oGrp1 := TListViewGroup():New( oList )
   oGrp1:cHeader := "Fruits"; oGrp1:Create()
   oGrp2 := TListViewGroup():New( oList )
   oGrp2:cHeader := "Vegetables"; oGrp2:Create()
   oItem := TListViewItem():New( oList )
   oItem:cText := "Apple"; oItem:nGroup := oGrp1:nGroupId; oItem:Create()
   ACTIVATE WINDOW oWnd CENTERED
return nil

Notas

  • Chame oList:EnableGroupView() antes de adicionar grupos.
  • Os itens são adicionados a oList:aItems após a criação. Os grupos vão para oList:aGroups.
  • A propriedade nGroup em um item deve corresponder ao nGroupId de um grupo.

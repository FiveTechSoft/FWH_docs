TListView

Controle comum ListView do Windows com icones, detalhes, grupos e visualizacao em blocos

Fonte: source/classes/tlistvie.prg  |  Pai: TControl

Visao Geral

TListView encapsula o controle comum SysListView32 do Windows. Diferente do TXBrowse (projetado para navegacao de registros de banco de dados), o TListView e projetado para exibir listas de itens com icones -- similar a listagem de arquivos do Windows Explorer. Suporta cinco modos de visualizacao, agrupamento de itens, listas de imagens e selecao de itens.

Modos de Visualizacao

Exemplos de Codigo

Exemplo 1: ListView Basico com Icones

#include "FiveWin.ch"

FUNCTION TestListView()
   LOCAL oWnd, oLvw, oImgList

   DEFINE WINDOW oWnd TITLE "ListView Demo"

   // Create a 32x32 image list
   oImgList := TImageList():New( 32, 32 )
   oImgList:AddMasked( TBitmap():Define( "FOLDER",, oWnd ), CLR_MAGENTA )
   oImgList:AddMasked( TBitmap():Define( "FILE",,   oWnd ), CLR_MAGENTA )

   @ 0, 0 LISTVIEW oLvw OF oWnd ;
      PROMPTS "Documents", "Pictures", "Music", "Videos" ;
      ON CHANGE { || MsgInfo( "Selected: " + Str( oLvw:nOption ) ) } ;
      SIZE 400, 300 PIXEL

   oLvw:SetImageList( oImgList, 0 )  // LVSIL_NORMAL

   ACTIVATE WINDOW oWnd
RETURN NIL

Exemplo 2: Visualizacao de Detalhes com Grupos

#include "FiveWin.ch"

FUNCTION TestListViewGroups()
   LOCAL oWnd, oLvw

   DEFINE WINDOW oWnd TITLE "ListView Groups"

   @ 0, 0 LISTVIEW oLvw OF oWnd SIZE 500, 400 PIXEL ;
      ON CHANGE { || ProcessItem( oLvw:nOption ) }

   // Switch to details view
   oLvw:SetStyle( 1 )   // LV_VIEW_DETAILS

   // Insert groups
   oLvw:InsertGroup( "Contacts" )
   oLvw:InsertGroup( "Suppliers" )

   // Enable group headers
   oLvw:EnableGroupView()

   // Insert items into groups
   oLvw:InsertItem( 0, "John Smith",     0 )  // Group 0 = default
   oLvw:InsertItem( 0, "Jane Doe",       1 )  // Group 1 = Contacts
   oLvw:InsertItem( 0, "Acme Corp",      2 )  // Group 2 = Suppliers
   oLvw:InsertItem( 0, "Widget Inc",     2 )

   ACTIVATE WINDOW oWnd
RETURN NIL

Exemplo 3: Alternando Modos de Visualizacao

// Add a combobox to switch view modes
@ 0, 0 COMBOBOX oCbx ITEMS { "Large Icons", "Details", ;
   "Small Icons", "List", "Tiles" } ;
   OF oWnd SIZE 150, 200 PIXEL ;
   ON CHANGE { || oLvw:SetStyle( oCbx:nAt - 1 ) }

Dicas

  • Para navegacao de banco de dados com ordenacao, filtragem e edicao, use TXBrowse.
  • TListView e mais adequado para selecao baseada em icones (navegadores de arquivos, galerias de imagens, listas de opcoes).
  • Chame EnableGroupView() apos inserir grupos para tornar os cabecalhos de grupo visiveis.
  • O parametro nImageIndex em InsertItem() e base 0 (correspondendo ao indice da lista de imagens).
  • Use SetIconSpacing() para controlar o espacamento entre itens no modo de visualizacao de icones.

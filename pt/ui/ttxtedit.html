TTxtEdit

Fonte: source/classes/ttxtedit.prg

Herda de: TControl

TTxtEdit é um controle de editor de texto para código-fonte com suporte a realce de sintaxe. Fornece edição orientada a linhas com modos de inserção/sobrescrita, operações de área de transferência, histórico de desfazer/refazer, diálogos de localizar e substituir, e comandos de manipulação de linhas. O colorido de sintaxe baseado em tokens pode ser personalizado para diferentes linguagens de programação.

Membros DATA Principais

DATATipoDescrição
aLinesArrayArray de strings de caracteres, uma por linha de texto
lInsertLógicoModo de inserção quando .T., modo de sobrescrita quando .F.
lChangedLógicoSinalizador que indica que o texto foi modificado
cFileNameCaractereNome do arquivo associado ao documento editado
cTokens1 / cTokens2 / cTokens3CaractereListas de tokens para três grupos de realce de sintaxe
nClrTok1 / nClrTok2 / nClrTok3NuméricoCores de texto para cada grupo de tokens
nClrNumberNuméricoCor para literais numéricos
nClrStringNuméricoCor para literais de string

Exemplo: Editor com Realce de Sintaxe

#include "FiveWin.ch"

function Main()

   local oWnd, oEdit

   DEFINE WINDOW oWnd TITLE "Source Editor" SIZE 600, 400

   oEdit := TTxtEdit():New( 0, 0, 600, 380, oWnd )

   // Tokens de sintaxe Harbour
   oEdit:cTokens1 := "function|procedure|local|if|else|endif|do|while|return"
   oEdit:nClrTok1 := CLR_BLUE

   oEdit:cTokens2 := "MAIN|NIL|TRUE|FALSE|.T.|.F."
   oEdit:nClrTok2 := CLR_RED

   oEdit:nClrNumber := CLR_PURPLE
   oEdit:nClrString := CLR_GREEN

   oEdit:Load( "source.prg" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O realce de sintaxe usa três grupos de tokens (cTokens1 até cTokens3) com cores configuráveis de forma independente.
  • Os tokens são strings delimitadas por barra vertical. Cada token é correspondido como palavra inteira no texto-fonte.
  • O sinalizador lChanged é mantido automaticamente; verifique-o antes de fechar para solicitar o salvamento.
  • Use DlgFind() e DlgGoLine() para fornecer ao usuário os diálogos padrão de Localizar e Ir para Linha.
  • O array aLines fornece acesso direto a linhas individuais para manipulação programática.

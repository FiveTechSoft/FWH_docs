TGraph

Fonte: source/classes/tgraph.prg

Herda de: TControl

TGraph é o controle de gráficos do FiveWin que suporta gráficos de barras, linhas, pontos, pizza e dispersão XY. Ele fornece um conjunto abrangente de capacidades gráficas diretamente em janelas e diálogos FiveWin, com suporte para múltiplas séries, renderização 3D, legendas, linhas de grade e exportação para imagem ou impressora.

Tipos de Gráfico

TGraph suporta os seguintes tipos de gráfico, definidos como constantes numéricas:

ConstanteValorDescrição
GRAPH_TYPE_BAR1Gráfico de barras vertical (padrão)
GRAPH_TYPE_LINE2Gráfico de linhas conectando pontos de dados
GRAPH_TYPE_POINT3Gráfico de dispersão/pontos
GRAPH_TYPE_PIE4Gráfico de pizza
GRAPH_TYPE_XY_LINES6Gráfico de dispersão XY com linhas de conexão
GRAPH_TYPE_XY_POINTS7Gráfico de dispersão XY apenas com pontos

Exemplo: Gráfico de Barras com Duas Séries

#include "FiveWin.ch"

function Main()

   local oWnd, oGraph

   DEFINE WINDOW oWnd TITLE "Quarterly Sales" SIZE 600, 400

   @ 10, 10 GRAPH oGraph SIZE 560, 340 OF oWnd TYPE GRAPH_TYPE_BAR ;
      TITLE "Sales by Quarter"

   oGraph:l3D      := .T.
   oGraph:lxGrid   := .T.
   oGraph:lyGrid   := .T.
   oGraph:lxVal    := .T.
   oGraph:lyVal    := .T.
   oGraph:lLegends := .T.
   oGraph:cPicture := "999,999.99"

   // Set category labels
   oGraph:SetYVals( { "Q1", "Q2", "Q3", "Q4" } )

   // Add two series
   oGraph:AddSerie( { 1200, 1500, 1100, 1800 }, "Product A", CLR_RED )
   oGraph:AddSerie( { 900, 1300, 1600, 1400 }, "Product B", CLR_BLUE )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TGraph é um mecanismo de gráficos totalmente autônomo que não depende de componentes ActiveX ou OCX externos. Toda a renderização é feita via GDI.
  • Use a sintaxe do comando GRAPH com TYPE nType para definir o tipo de gráfico no momento da criação.
  • As cores das séries são atribuídas automaticamente a partir de uma paleta interna se não forem especificadas. A paleta padrão alterna entre METRO_AMBER, METRO_OLIVE, CLR_HMAGENTA, CLR_HBLUE, CLR_HRED, CLR_HGREEN e cores padrão.
  • Gráficos XY (tipos 6 e 7) esperam dados como arrays de pares de coordenadas { x, y }. Use AddXYSerie() para adicionar séries XY.
  • A exportação para imagem usa Save2Bmp() internamente. O gráfico também pode ser copiado para a área de transferência para colagem em outros aplicativos.
  • O menu popup (habilitado via lPopUp) fornece acesso com clique direito para alternar o tipo de gráfico, ativar/desativar grade e opções de exportação em tempo de execução.

TMetro

Fonte: source/classes/tmetro.prg

Classe independente

TMetro cria uma tela inicial (estilo Metro) Modern UI em tela cheia com botões em mosaico, inspirada na linguagem de design Metro do Windows 8. Ela exibe uma imagem de fundo, um título, a data e a hora atuais e uma grade de botões em mosaico que podem ser normais ou grandes (largura dupla). Cada mosaico tem cores de texto e de fundo configuráveis e uma imagem de ícone opcional.

Membros DATA Principais

DATATipoDescrição
oWndObjetoA janela popup subjacente (estilo WS_POPUP)
cTitleCaractereTítulo exibido no topo da tela inicial
aButtonsArrayArray de objetos TButtonBmp criados por AddButton()
nBtnWidthNuméricoLargura do mosaico em pixels (padrão 132)
nBtnHeightNuméricoAltura do mosaico em pixels (padrão 132)
nOriginXNuméricoPosição X inicial da grade de mosaicos (padrão 200)
nOriginYNuméricoPosição Y inicial da grade de mosaicos (padrão 200)
hBitmapNuméricoHandle para o bitmap de fundo
oFontObjetoFonte Segoe UI Light para os elementos de exibição
oFontBObjetoFonte Segoe UI Light em negrito para exibição da hora
oTimerObjetoTimer para atualizar a exibição do relógio

Métodos

MétodoDescrição
New( cTitle, nBtnW, nBtnH, cBgFile )Cria uma nova tela inicial TMetro. cBgFile é um arquivo de bitmap de fundo ou recurso.
Activate()Exibe a tela inicial maximizada com fundo, título, data e hora
AddButton( cCaption, nClrText, nClrPane, lLarge, cImg, bAction )Adiciona um botão em mosaico com legenda, cores, imagem opcional e ação
End()Fecha a tela inicial e libera os recursos

Exemplo: Tela Metro com Mosaicos

#include "FiveWin.ch"

function Main()

   local oMetro

   oMetro := TMetro():New( "My Application", 132, 132, "bg.bmp" )

   oMetro:AddButton( "Customers", CLR_WHITE, CLR_HBLUE, .F., "cust.bmp",;
      { || MsgInfo( "Customers" ) } )

   oMetro:AddButton( "Products", CLR_WHITE, CLR_HGREEN, .F., "prod.bmp",;
      { || MsgInfo( "Products" ) } )

   oMetro:AddButton( "Reports", CLR_WHITE, CLR_HRED, .T., "rpt.bmp",;
      { || MsgInfo( "Reports" ) } )

   oMetro:Activate()

return nil

Notas

  • TMetro cria uma janela popup sem borda que preenche toda a tela. O estilo da janela usa WS_POPUP sem barra de título ou borda.
  • A imagem de fundo pode ser carregada de um arquivo ou de um recurso. Se o arquivo não for encontrado, recorre ao carregamento a partir do recurso.
  • Mosaicos grandes (lLarge := .T.) ocupam duas posições de mosaico em largura, dando ênfase visual às ações principais.
  • As posições dos mosaicos são calculadas automaticamente em um layout de grade. Quando uma linha excede a largura da tela, os mosaicos passam para a linha seguinte.
  • O relógio é atualizado por meio de um timer interno e exibido na área superior direita usando a fonte Segoe UI Light.
  • TMetro usa a fonte Segoe UI Light, que está disponível no Windows 8 e versões posteriores. Em sistemas mais antigos, recorre a uma fonte padrão.

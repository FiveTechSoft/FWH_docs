TComboBox

Controle de seleção suspensa com múltiplos estilos e vinculação de dados

Fonte: source/classes/combobox.prg  |  Classe pai: TControl

Visão Geral

TComboBox encapsula o controle ComboBox do Windows, fornecendo uma lista suspensa da qual o usuário seleciona um item. Suporta três estilos:

  • CBS_DROPDOWN (padrão) -- campo de texto editável com uma lista suspensa
  • CBS_DROPDOWNLIST -- não editável; o usuário só pode selecionar a partir da lista
  • CBS_SIMPLE -- campo de texto editável com uma lista sempre visível

O combo pode ser vinculado a uma variável de texto (o texto do item selecionado) ou a uma variável numérica (o índice do item selecionado). Ele suporta busca incremental, desenho personalizado e listas de itens orientadas a dados.

Principais Propriedades

PropriedadeTipoDescrição
aItemsArrayArray de strings exibidas na lista suspensa
bSetGetBlockBloco de vinculação de dados. Para combos de texto: lê/escreve o texto selecionado. Para combos numéricos: lê/escreve o índice selecionado.
bChangeBlockBloco de código executado quando a seleção muda
nAtNumericÍndice do item atualmente selecionado (começando em 1)

lOwnerDrawLogicalHabilita desenho personalizado de itens via bDrawItem
bDrawItemBlockBloco de desenho personalizado para o modo owner-draw
cCueTextStringTexto de espaço reservado quando nada está selecionado

Métodos Principais

MétodoDescrição
New( nRow, nCol, bSetGet, aItems, ... )Construtor. Cria um novo combo na posição indicada.
ReDefine( nId, bSetGet, aItems, oWnd, ... )Redefine a partir de um recurso de diálogo.
Set( cText )Define o item selecionado pelo seu texto.
Select( n )Define o item selecionado pelo seu índice.
Add( cItem )Adiciona um item à lista em tempo de execução.
Del( n )Remove o item no índice n.
Reset()Limpa todos os itens da lista.
Refresh()Repopula a lista a partir de aItems e restaura a seleção.

Sintaxe do Comando

ComboBox vinculado a texto

@ nRow, nCol COMBOBOX oCombo VAR cVar ;
   ITEMS aItems ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ] ;
   [ VALID bValid ] ;
   [ STYLE CBS_DROPDOWNLIST ] ;
   [ FONT oFont ]

ComboBox vinculado a número (índice)

@ nRow, nCol COMBOBOX oCombo VAR nIndex ;
   ITEMS aItems ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ]

Exemplos de Código

Exemplo 1: Seleções Simples de ComboBox

#include "FiveWin.ch"

FUNCTION ComboDemo()
   LOCAL oDlg, oFont
   LOCAL cCountry := "USA"
   LOCAL nPriority := 2
   LOCAL aCountries := { "USA", "Canada", "Mexico", "Brazil", "UK", "France", "Germany", "Spain" }
   LOCAL aPriority  := { "Low", "Medium", "High", "Critical" }

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14
   DEFINE DIALOG oDlg TITLE "ComboBox Demo" SIZE 400, 300 FONT oFont

   // Combo vinculado a texto -- cCountry guarda o texto selecionado
   @ 1.0, 1 SAY "Country:" OF oDlg
   @ 1.0, 6 COMBOBOX cCountry ;
      ITEMS aCountries ;
      OF oDlg SIZE 180, 200 ;
      STYLE CBS_DROPDOWNLIST

   // Combo vinculado a número -- nPriority guarda o índice selecionado
   @ 3.0, 1 SAY "Priority:" OF oDlg
   @ 3.0, 6 COMBOBOX nPriority ;
      ITEMS aPriority ;
      OF oDlg SIZE 140, 200 ;
      ON CHANGE ( MsgInfo( "Priority changed to: " + aPriority[ nPriority ] ) )

   @ 5.5, 6 BUTTON "&OK" OF oDlg SIZE 80, 25 ;
      ACTION ( MsgInfo( "Country: " + cCountry + CRLF + ;
                        "Priority: " + aPriority[ nPriority ] ), ;
               oDlg:End() ) DEFAULT

   @ 5.5, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   RELEASE FONT oFont
RETURN NIL

Exemplo 2: ComboBox Baseado em Banco de Dados

#include "FiveWin.ch"

FUNCTION DBCombo()
   LOCAL oDlg, oCmb
   LOCAL cCategory := ""
   LOCAL aCategories := {}

   // Constrói o array de itens a partir de uma tabela de banco de dados
   USE Categories VIA "DBFCDX" NEW
   Categories->( DbGoTop() )
   DO WHILE !Categories->( Eof() )
      AAdd( aCategories, AllTrim( Categories->CATNAME ) )
      Categories->( DbSkip() )
   ENDDO

   DEFINE DIALOG oDlg TITLE "Select Category" SIZE 400, 200

   @ 1.5, 1 SAY "Category:" OF oDlg
   @ 1.5, 6 COMBOBOX oCmb VAR cCategory ;
      ITEMS aCategories ;
      OF oDlg SIZE 200, 200 ;
      STYLE CBS_DROPDOWN ;
      VALID ( !Empty( cCategory ) ) ;
      CUETEXT "Type or select a category"

   @ 4.0, 6 BUTTON "&Select" OF oDlg SIZE 90, 25 ;
      ACTION ( MsgInfo( "Selected: " + cCategory ), oDlg:End() ) DEFAULT

   @ 4.0, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   CLOSE Categories
RETURN NIL

Exemplo 3: ComboBoxes Dependentes (País/Cidade)

#include "FiveWin.ch"

FUNCTION DependentCombos()
   LOCAL oDlg
   LOCAL cCountry := "USA"
   LOCAL cCity    := ""
   LOCAL oCmbCountry, oCmbCity
   LOCAL aCountries := { "USA", "Canada", "UK" }
   LOCAL aCities    := {}

   DEFINE DIALOG oDlg TITLE "Dependent Combos" SIZE 400, 250

   @ 1, 1 SAY "Country:" OF oDlg
   @ 1, 6 COMBOBOX oCmbCountry VAR cCountry ;
      ITEMS aCountries OF oDlg SIZE 160, 200 ;
      STYLE CBS_DROPDOWNLIST ;
      ON CHANGE ( UpdateCities( cCountry, @aCities, oCmbCity ) )

   @ 3, 1 SAY "City:" OF oDlg
   @ 3, 6 COMBOBOX oCmbCity VAR cCity ;
      ITEMS aCities OF oDlg SIZE 160, 200 ;
      STYLE CBS_DROPDOWNLIST

   // Inicializa as cidades para o país padrão
   UpdateCities( cCountry, @aCities, oCmbCity )

   @ 5.5, 6  BUTTON "&OK"     OF oDlg SIZE 80, 25 ACTION oDlg:End() DEFAULT
   @ 5.5, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

STATIC FUNCTION UpdateCities( cCountry, aCities, oCmbCity )
   DO CASE
   CASE cCountry == "USA"
      aCities := { "New York", "Los Angeles", "Chicago", "Houston" }
   CASE cCountry == "Canada"
      aCities := { "Toronto", "Montreal", "Vancouver", "Calgary" }
   CASE cCountry == "UK"
      aCities := { "London", "Manchester", "Birmingham", "Glasgow" }
   OTHERWISE
      aCities := {}
   ENDCASE

   IF oCmbCity != NIL
      oCmbCity:aItems := aCities
      oCmbCity:Reset()
      oCmbCity:Refresh()
      IF Len( aCities ) > 0
         oCmbCity:Select( 1 )
      ENDIF
   ENDIF
RETURN NIL

Dicas

  • Use CBS_DROPDOWNLIST quando o usuário deve escolher apenas a partir da lista. Use CBS_DROPDOWN quando a entrada de texto livre também for aceitável.
  • O parâmetro de altura do SIZE controla a altura da lista suspensa, não do controle em si. Torne-o grande o suficiente para mostrar vários itens.
  • Para listas grandes de itens, habilite lIncSearch para que os usuários possam digitar para filtrar.
  • Use bChange para combos em cascata (alterar um combo atualiza outro).
  • Para atualizar os itens de um combo em tempo de execução, atualize aItems, chame Reset() e depois Refresh().
  • Para combos vinculados a um campo DBF, use FieldWBlock() como o bSetGet.

TComboBox

Controle de selecao suspensa com multiplos estilos e vinculacao de dados

Fonte: source/classes/combobox.prg  |  Pai: TControl

Visao Geral

TComboBox encapsula o controle ComboBox do Windows, fornecendo uma lista suspensa na qual o usuario seleciona um item. Suporta tres estilos:

  • CBS_DROPDOWN (padrao) -- campo de texto editavel com lista suspensa
  • CBS_DROPDOWNLIST -- nao editavel; o usuario so pode selecionar da lista
  • CBS_SIMPLE -- campo de texto editavel com lista sempre visivel

O combo pode ser vinculado a uma variavel string (texto do item selecionado) ou a uma variavel numerica (indice do item selecionado). Suporta busca incremental, desenho personalizado e listas de itens orientadas a dados.

Sintaxe de Comandos

ComboBox vinculado a String

@ nRow, nCol COMBOBOX oCombo VAR cVar ;
   ITEMS aItems ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ] ;
   [ VALID bValid ] ;
   [ STYLE CBS_DROPDOWNLIST ] ;
   [ FONT oFont ]

ComboBox vinculado a Numerico (indice)

@ nRow, nCol COMBOBOX oCombo VAR nIndex ;
   ITEMS aItems ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ]

Exemplos de Codigo

Exemplo 1: Selecoes Simples com ComboBox

#include "FiveWin.ch"

FUNCTION ComboDemo()
   LOCAL oDlg, oFont
   LOCAL cCountry := "USA"
   LOCAL nPriority := 2
   LOCAL aCountries := { "USA", "Canada", "Mexico", "Brazil", "UK", "France", "Germany", "Spain" }
   LOCAL aPriority  := { "Low", "Medium", "High", "Critical" }

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14
   DEFINE DIALOG oDlg TITLE "ComboBox Demo" SIZE 400, 300 FONT oFont

   // Combo vinculado a string -- cCountry armazena o texto selecionado
   @ 1.0, 1 SAY "Country:" OF oDlg
   @ 1.0, 6 COMBOBOX cCountry ;
      ITEMS aCountries ;
      OF oDlg SIZE 180, 200 ;
      STYLE CBS_DROPDOWNLIST

   // Combo vinculado a numerico -- nPriority armazena o indice selecionado
   @ 3.0, 1 SAY "Priority:" OF oDlg
   @ 3.0, 6 COMBOBOX nPriority ;
      ITEMS aPriority ;
      OF oDlg SIZE 140, 200 ;
      ON CHANGE ( MsgInfo( "Priority changed to: " + aPriority[ nPriority ] ) )

   @ 5.5, 6 BUTTON "&OK" OF oDlg SIZE 80, 25 ;
      ACTION ( MsgInfo( "Country: " + cCountry + CRLF + ;
                        "Priority: " + aPriority[ nPriority ] ), ;
               oDlg:End() ) DEFAULT

   @ 5.5, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   RELEASE FONT oFont
RETURN NIL

Exemplo 2: ComboBox Orientado a Banco de Dados

#include "FiveWin.ch"

FUNCTION DBCombo()
   LOCAL oDlg, oCmb
   LOCAL cCategory := ""
   LOCAL aCategories := {}

   // Constroi o array de itens a partir de uma tabela de banco de dados
   USE Categories VIA "DBFCDX" NEW
   Categories->( DbGoTop() )
   DO WHILE !Categories->( Eof() )
      AAdd( aCategories, AllTrim( Categories->CATNAME ) )
      Categories->( DbSkip() )
   ENDDO

   DEFINE DIALOG oDlg TITLE "Select Category" SIZE 400, 200

   @ 1.5, 1 SAY "Category:" OF oDlg
   @ 1.5, 6 COMBOBOX oCmb VAR cCategory ;
      ITEMS aCategories ;
      OF oDlg SIZE 200, 200 ;
      STYLE CBS_DROPDOWN ;
      VALID ( !Empty( cCategory ) ) ;
      CUETEXT "Type or select a category"

   @ 4.0, 6 BUTTON "&Select" OF oDlg SIZE 90, 25 ;
      ACTION ( MsgInfo( "Selected: " + cCategory ), oDlg:End() ) DEFAULT

   @ 4.0, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   CLOSE Categories
RETURN NIL

Exemplo 3: ComboBoxes Dependentes (Pais/Cidade)

#include "FiveWin.ch"

FUNCTION DependentCombos()
   LOCAL oDlg
   LOCAL cCountry := "USA"
   LOCAL cCity    := ""
   LOCAL oCmbCountry, oCmbCity
   LOCAL aCountries := { "USA", "Canada", "UK" }
   LOCAL aCities    := {}

   DEFINE DIALOG oDlg TITLE "Dependent Combos" SIZE 400, 250

   @ 1, 1 SAY "Country:" OF oDlg
   @ 1, 6 COMBOBOX oCmbCountry VAR cCountry ;
      ITEMS aCountries OF oDlg SIZE 160, 200 ;
      STYLE CBS_DROPDOWNLIST ;
      ON CHANGE ( UpdateCities( cCountry, @aCities, oCmbCity ) )

   @ 3, 1 SAY "City:" OF oDlg
   @ 3, 6 COMBOBOX oCmbCity VAR cCity ;
      ITEMS aCities OF oDlg SIZE 160, 200 ;
      STYLE CBS_DROPDOWNLIST

   // Inicializa cidades para o pais padrao
   UpdateCities( cCountry, @aCities, oCmbCity )

   @ 5.5, 6  BUTTON "&OK"     OF oDlg SIZE 80, 25 ACTION oDlg:End() DEFAULT
   @ 5.5, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

STATIC FUNCTION UpdateCities( cCountry, aCities, oCmbCity )
   DO CASE
   CASE cCountry == "USA"
      aCities := { "New York", "Los Angeles", "Chicago", "Houston" }
   CASE cCountry == "Canada"
      aCities := { "Toronto", "Montreal", "Vancouver", "Calgary" }
   CASE cCountry == "UK"
      aCities := { "London", "Manchester", "Birmingham", "Glasgow" }
   OTHERWISE
      aCities := {}
   ENDCASE

   IF oCmbCity != NIL
      oCmbCity:aItems := aCities
      oCmbCity:Reset()
      oCmbCity:Refresh()
      IF Len( aCities ) > 0
         oCmbCity:Select( 1 )
      ENDIF
   ENDIF
RETURN NIL

Dicas

  • Use CBS_DROPDOWNLIST quando o usuario deve escolher somente da lista. Use CBS_DROPDOWN quando a entrada de texto livre tambem e aceitavel.
  • O parametro de altura em SIZE controla a altura da lista suspensa, nao do controle em si. Faca-o grande o suficiente para mostrar varios itens.
  • Para listas de itens grandes, habilite lIncSearch para que usuarios possam digitar para filtrar.
  • Use bChange para combos em cascata (alterar um combo atualiza outro).
  • Para atualizar os itens de um combo em tempo de execucao, atualize aItems, chame Reset() e depois Refresh().
  • Para combos vinculados a um campo DBF, use FieldWBlock() como bSetGet.

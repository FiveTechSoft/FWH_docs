TSysLink

Fonte: source/classes/tsyslink.prg

Herda de: TControl

TSysLink encapsula o controle comum SysLink do Windows (Vista+), fornecendo hyperlinks clicáveis dentro de diálogos. Vários links podem ser incorporados em uma única string de texto usando tags <a> no estilo HTML. Os links abrem URLs no navegador padrão ou disparam blocos de código Harbour.

Membros DATA Principais

DATATipoDescrição
cTextCharacterTexto exibido com tags <a> que definem as regiões de link
cUrlCharacterURL aberta quando um link é clicado
nLinkIdNumericÍndice do último link clicado

Métodos

MétodoDescrição
New( nRow, nCol, oWnd, cText, cUrl, nW, nH, lPixel, lDesign, cMsg, bWhen, bClick, lTransparent, ... )Cria um novo controle SysLink
ReDefine( nId, oWnd, cText, cUrl )Redefine a partir de um recurso de diálogo

HitTest( nX, nY )Testa qual link está nas coordenadas fornecidas
GetIdealHeight( nWidth )Retorna a altura ideal para uma dada largura
SetItem( nIndex, cUrl, nState ) / GetItem( nIndex )Modifica ou consulta itens de link individuais

Comandos

@ nRow, nCol SYSLINK oLink TEXT cText OF oWnd

Exemplo: Múltiplos Links

#include "FiveWin.ch"
function Main()
   local oWnd, oLink
   DEFINE WINDOW oWnd TITLE "TSysLink Demo" SIZE 400, 200
   @ 20, 20 SYSLINK oLink TEXT ;
      "Visit <a href=""https://www.fivetechsoft.com"">FiveTech</a> " + ;
      "and <a href=""https://github.com"">GitHub</a>" ;
      OF oWnd
   ACTIVATE WINDOW oWnd CENTERED
return nil

Notas

  • Requer Windows Vista ou posterior (o controle SysLink não está disponível em versões mais antigas).
  • As regiões de link são definidas com tags <a href="...">. Clicar abre a URL no navegador padrão.
  • Use lTransparent := .T. para fazer o fundo coincidir com o diálogo pai.

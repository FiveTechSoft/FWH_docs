TSlider

Fonte: source/classes/slider.prg

Herda de: TControl

TSlider provides a trackbar / slider control for selecting a numeric value by dragging a thumb along a track. It supports horizontal and vertical orientation, tick marks, snap-to-grid (exact) positioning, and a slim style with a colored thumb.

Sintaxe do Comando

@ nRow, nCol SLIDER oSld VAR nValue RANGE nMin, nMax SIZE nW, nH PIXEL OF oWnd ;
   HORIZONTAL MARKS nMarks EXACT ON CHANGE bBlock

Principais Membros DATA

DATATipoDescrição
lHorizontalLogicalOrientação horizontal (.T.) ou vertical (.F.)
nMinNumericValor mínimo do intervalo do deslizador
nMaxNumericValor máximo do intervalo do deslizador
nMarksNumericNúmero de marcas de graduação ao longo da trilha (0 = sem marcas)
lExactLogicalSnap do polegar para a marca de graduação mais próxima
nClrBtnNumericCor do botão do polegar do deslizador
lSlimStyleLogicalRenderizar com trilha fina e polegar colorido
nDirectionNumericDireção das marcas de graduação (1=topo, 2=esquerda, 3=fundo, 4=direita)

Exemplos

Deslizador de Volume (0-100)

#include "FiveWin.ch"

function Main()

   local oWnd, oSld, nVolume := 50

   DEFINE WINDOW oWnd TITLE "Volume Slider" SIZE 400, 150

   @ 40, 30 SLIDER oSld VAR nVolume RANGE 0, 100 ;
      SIZE 300, 30 PIXEL OF oWnd HORIZONTAL ;
      ON CHANGE oWnd:SetText( "Volume: " + Str( nVolume, 3 ) + "%" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Seletor com Marcas de Graduação

#include "FiveWin.ch"

function Main()

   local oWnd, oSld, nOption := 3, aOpts := { "Low", "Med", "Norm", "High", "Max" }

   DEFINE WINDOW oWnd TITLE "Speed Selector" SIZE 400, 150

   @ 40, 30 SLIDER oSld VAR nOption RANGE 1, 5 ;
      SIZE 300, 30 PIXEL OF oWnd HORIZONTAL ;
      MARKS 5 EXACT ;
      ON CHANGE oWnd:SetText( "Speed: " + aOpts[ nOption ] )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • O deslizador é um controle GDI autodesenhado, não a barra de controle comum do Windows. Isso garante uma aparência consistente em todas as versões do Windows e fornece a opção de estilo fino.
  • Quando MARKS nMarks é especificado junto com EXACT, o polegar snap para a posição da marca de graduação mais próxima, fornecendo um comportamento de passo discreto.
  • O estilo fino (lSlimStyle ou a cláusula SLIM) renderiza uma trilha mais fina com um polegar colorido (padrão CLR_BLUE) para uma aparência moderna.
  • Navegação pelo teclado: Esquerda/Cima decrementa o valor, Direita/Baixo incrementa. Page Up/Page Down saltam em passos maiores.
  • O controle suporta tanto arrastar com o mouse quanto interação de clicar-para-posicionar. Arrastar o polegar produz atualizações de valor em tempo real através do bloco de código bChange.

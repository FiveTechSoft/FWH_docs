TCheckBox / TRadio

Caixas de selecao booleanas e grupos de botoes de opcao mutuamente exclusivos

TCheckBox

Fonte: source/classes/checkbox.prg  |  Pai: TControl

TCheckBox encapsula o controle checkbox padrao do Windows. Vincula-se a uma variavel logica -- .T. quando marcado, .F. quando desmarcado. Checkboxes sao independentes; qualquer quantidade pode ser marcada simultaneamente.

Propriedades do TCheckBox

PropriedadeTipoDescricao
bSetGetBlockBloco de vinculacao de dados que le/escreve a variavel logica
cCaptionStringTexto exibido ao lado do checkbox
lCheckedLogicalEstado atual de marcacao

Metodos do TCheckBox

MetodoDescricao
New( nRow, nCol, cCaption, bSetGet, oWnd, ... )Construtor.
Click()Alterna o estado de marcacao e avalia bSetGet.
Check()Define o estado marcado como .T.
UnCheck()Define o estado marcado como .F.
SetCheck( lOnOff )Define o estado marcado para o valor fornecido.
lIsChecked()Retorna o estado visual de marcacao atual da API do Windows.
Refresh()Rele a variavel vinculada e atualiza o estado visual.

Comando TCheckBox

@ nRow, nCol CHECKBOX oChk VAR lVar ;
   PROMPT "Texto do rotulo" ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ ON CHANGE bChange ] ;
   [ WHEN bWhen ] ;
   [ FONT oFont ]

TRadio e TRadMenu

Fonte: source/classes/radio.prg  |  Pai: TControl

TRadio representa um unico botao de opcao. Botoes de opcao sao mutuamente exclusivos dentro de um grupo -- selecionar um desmarca todos os outros. O grupo e gerenciado por um objeto TRadMenu, que se vincula a uma variavel numerica indicando qual opcao esta selecionada (base 1).

Propriedades do TRadio

PropriedadeTipoDescricao
oRadMenuObjectReferencia ao TRadMenu que possui este botao de opcao
nPosNumericIndice de posicao dentro do grupo. Quando este radio e selecionado, TRadMenu:nOption e igual a nPos.
cCaptionStringTexto exibido ao lado do botao de opcao

Comando Radio

@ nRow, nCol RADIO oRad VAR nChoice ;
   PROMPT "Texto da opcao" ;
   [ OF oWnd ] ;
   [ WHEN bWhen ] ;
   [ ON CHANGE bChange ]

Quando multiplos comandos RADIO compartilham a mesma VAR, o FiveWin os agrupa automaticamente em um TRadMenu.

Exemplos de Codigo

Exemplo 1: Checkboxes para Opcoes

#include "FiveWin.ch"

FUNCTION PrintOptions()
   LOCAL oDlg
   LOCAL lLandscape  := .F.
   LOCAL lColor      := .T.
   LOCAL lDuplex     := .F.
   LOCAL lCollate    := .T.
   LOCAL lPreview    := .F.

   DEFINE DIALOG oDlg TITLE "Print Options" SIZE 350, 320

   @ 1.0, 2 SAY "Select print options:" OF oDlg

   @ 2.5, 2 CHECKBOX lLandscape PROMPT "&Landscape orientation" OF oDlg SIZE 200, 18
   @ 4.0, 2 CHECKBOX lColor     PROMPT "&Color printing"        OF oDlg SIZE 200, 18
   @ 5.5, 2 CHECKBOX lDuplex    PROMPT "&Duplex (two-sided)"    OF oDlg SIZE 200, 18
   @ 7.0, 2 CHECKBOX lCollate   PROMPT "Co&llate copies"        OF oDlg SIZE 200, 18
   @ 8.5, 2 CHECKBOX lPreview   PROMPT "Print Pre&view"         OF oDlg SIZE 200, 18

   @ 11, 5  BUTTON "&Print"  OF oDlg SIZE 80, 25 ;
      ACTION ( PrintDoc( lLandscape, lColor, lDuplex, lCollate, lPreview ), ;
               oDlg:End() ) DEFAULT
   @ 11, 15 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

Exemplo 2: Grupo de Botoes de Opcao

#include "FiveWin.ch"

FUNCTION ShippingMethod()
   LOCAL oDlg
   LOCAL nShipping := 1   // 1=Padrao, 2=Expresso, 3=Noturno

   DEFINE DIALOG oDlg TITLE "Shipping Method" SIZE 350, 280

   @ 1.0, 2 SAY "Select shipping method:" OF oDlg

   @ 2.5, 3 RADIO nShipping PROMPT "&Standard (5-7 days)"  OF oDlg
   @ 4.0, 3 RADIO nShipping PROMPT "&Express (2-3 days)"   OF oDlg
   @ 5.5, 3 RADIO nShipping PROMPT "&Overnight (1 day)"    OF oDlg

   @ 8, 5  BUTTON "&OK" OF oDlg SIZE 80, 25 ;
      ACTION ( ShowShippingCost( nShipping ), oDlg:End() ) DEFAULT
   @ 8, 15 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

STATIC FUNCTION ShowShippingCost( nMethod )
   LOCAL aCosts := { 4.99, 12.99, 29.99 }
   LOCAL aNames := { "Standard", "Express", "Overnight" }

   MsgInfo( aNames[ nMethod ] + " shipping: $" + ;
            LTrim( Str( aCosts[ nMethod ], 8, 2 ) ) )
RETURN NIL

Exemplo 3: Checkboxes e Radios Misturados em um Dialogo de Configuracoes

#include "FiveWin.ch"

FUNCTION AppSettings()
   LOCAL oDlg, oFld, oDlg1, oDlg2
   // Configuracoes de exibicao
   LOCAL lShowToolbar := .T.
   LOCAL lShowStatus  := .T.
   LOCAL lFullScreen  := .F.
   LOCAL nTheme       := 1    // 1=Claro, 2=Escuro, 3=Sistema
   // Configuracoes de comportamento
   LOCAL lAutoSave    := .T.
   LOCAL lConfirmDel  := .T.
   LOCAL lSounds      := .F.
   LOCAL nStartup     := 1    // 1=Ultimo arquivo, 2=Novo arquivo, 3=Nada

   DEFINE DIALOG oDlg TITLE "Application Settings" SIZE 450, 400

   @ 0.3, 0.3 FOLDER oFld OF oDlg ;
      PROMPTS "Display", "Behavior" ;
      DIALOGS oDlg1, oDlg2 ;
      SIZE 420, 280

   // --- Pagina de Exibicao ---
   @ 1.0, 2 CHECKBOX lShowToolbar PROMPT "Show &Toolbar"      OF oDlg1 SIZE 200, 18
   @ 2.5, 2 CHECKBOX lShowStatus  PROMPT "Show &Status Bar"   OF oDlg1 SIZE 200, 18
   @ 4.0, 2 CHECKBOX lFullScreen  PROMPT "&Full Screen Mode"  OF oDlg1 SIZE 200, 18

   @ 6.0, 2 SAY "Color Theme:" OF oDlg1
   @ 7.5, 3 RADIO nTheme PROMPT "&Light"  OF oDlg1
   @ 9.0, 3 RADIO nTheme PROMPT "&Dark"   OF oDlg1
   @ 10.5, 3 RADIO nTheme PROMPT "&System" OF oDlg1

   // --- Pagina de Comportamento ---
   @ 1.0, 2 CHECKBOX lAutoSave   PROMPT "&Auto-save every 5 minutes" OF oDlg2 SIZE 250, 18
   @ 2.5, 2 CHECKBOX lConfirmDel PROMPT "&Confirm before deleting"   OF oDlg2 SIZE 250, 18
   @ 4.0, 2 CHECKBOX lSounds    PROMPT "Enable &Sounds"             OF oDlg2 SIZE 250, 18

   @ 6.0, 2 SAY "On startup:" OF oDlg2
   @ 7.5, 3 RADIO nStartup PROMPT "Open &last file"    OF oDlg2
   @ 9.0, 3 RADIO nStartup PROMPT "Create &new file"   OF oDlg2
   @ 10.5, 3 RADIO nStartup PROMPT "Do ¬hing"        OF oDlg2

   // Botoes no dialogo pai
   @ 23, 8  BUTTON "&Save"   OF oDlg SIZE 80, 25 ;
      ACTION ( SaveSettings( lShowToolbar, lShowStatus, lFullScreen, nTheme, ;
                             lAutoSave, lConfirmDel, lSounds, nStartup ), ;
               oDlg:End() ) DEFAULT
   @ 23, 18 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED
RETURN NIL

Dicas

  • Checkbox vincula-se a uma variavel logica. Grupo Radio vincula-se a uma variavel numerica (o indice da opcao).
  • O FiveWin agrupa automaticamente comandos RADIO consecutivos que compartilham a mesma VAR em um TRadMenu.
  • Use & no PROMPT para definir um atalho Alt: "&Landscape" significa Alt+L para alternar.
  • Para um checkbox vinculado a um campo logico DBF, use FieldWBlock( "ACTIVE", Select() ) como bSetGet.
  • A clausula ON CHANGE dispara apos cada mudanca de estado, util para habilitar/desabilitar controles dependentes.
  • Botoes de opcao suportam navegacao por teclas de seta dentro do grupo automaticamente.
  • Para mais de 5-6 opcoes, considere usar um TComboBox em vez de um grupo radio longo.

Veja Também

  • TControl -- classe pai
  • TComboBox -- alternativa para selecionar um de muitos itens
  • TGet -- controles de entrada de texto
  • TFolder -- controle de abas frequentemente usado para organizar checkboxes e radios

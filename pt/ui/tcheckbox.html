Dicas

  • Checkbox vincula-se a uma variÃ¡vel lÃ³gica. Grupo de rádio vincula-se a uma variÃ¡vel numÃ©rica (o Ã­ndice da opÃ§Ã£o).
  • FiveWin agrupa automaticamente comandos RADIO consecutivos que compartilham o mesmo VAR em um TRadMenu.
  • Use & no PROMPT para definir um acelerador de tecla Alt: "&Landscape" significa que Alt+L o alterna.
  • Para uma caixa de seleção vinculada a um campo lógico DBF, use FieldWBlock( "ACTIVE", Select() ) como o bSetGet.
  • A cláusula ON CHANGE dispara após cada mudança de estado, útil para habilitar/desabilitar controles dependentes.
  • Os botões de rádio suportam navegação por teclas de seta dentro do grupo automaticamente.
  • Para mais de 5-6 opções, considere usar um TComboBox em vez de um longo grupo de rádio.

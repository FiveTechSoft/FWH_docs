TNavigator

Fonte: source/classes/navpanels.prg

Herda de: TControl

O TNavigator é um painel de navegação recolhível com barra de título gradiente, botão de alternância e reposicionamento automático de painéis irmãos. Quando recolhido, o painel encolhe para uma barra vertical estreita com título rotacionado; quando expandido, revela controles filhos. Múltiplas instâncias TNavigator podem ser vinculadas via aRelatedNavigators para que alternar um painel reposicione seus irmãos -- ideal para barras de navegação de encaixe lateral.

Exemplo: Painéis Navegadores Vinculados

#include "FiveWin.ch"

function Main()

   local oWnd, oNav1, oNav2

   DEFINE WINDOW oWnd TITLE "Navigator" SIZE 600, 400

   oNav1 := TNavigator():New( 0, 0, 400, 200, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Files" )

   oNav2 := TNavigator():New( 0, 202, 400, 402, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Search" )

   oNav1:aRelatedNavigators := { oNav2 }
   oNav2:aRelatedNavigators := { oNav1 }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • Os painéis irmãos são reposicionados automaticamente via aRelatedNavigators. A matriz é ordenada por nOriginalLeft para manter a ordenação da esquerda para a direita durante a alternância.
  • Quando recolhido, o texto do título é desenhado verticalmente usando a fonte oBoldVertical. Quando expandido, é desenhado horizontalmente no cabeçalho gradiente.
  • A imagem do botão de alternância padrão são bitmaps de seta embutidos (CreaArrowLeft / CreaArrowRight). Imagens de botão personalizadas podem ser fornecidas via cBtnImage1 e cBtnImage2.
  • Os controles filhos são automaticamente mostrados/ocultados conforme o painel expande e recolhe.

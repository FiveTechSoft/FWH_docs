TNavigator

Fonte: source/classes/navpanels.prg

Herda de: TControl

TNavigator é um painel de navegação recolhível com uma barra de título gradiente, botão de alternância e reposicionamento automático de paineis irmãos. Quando recolhido, o painel encolhe para uma barra vertical estreita com um título rotacionado; quando expandido, revela os controles filhos. Várias instâncias de TNavigator podem ser vinculadas via aRelatedNavigators para que alternar um painel reposicione seus irmãos -- ideal para barras de navegação acopladas lateralmente.

Exemplo: Paineis de Navegação Vinculados

#include "FiveWin.ch"

function Main()

   local oWnd, oNav1, oNav2

   DEFINE WINDOW oWnd TITLE "Navigator" SIZE 600, 400

   oNav1 := TNavigator():New( 0, 0, 400, 200, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Files" )

   oNav2 := TNavigator():New( 0, 202, 400, 402, oWnd,,,;
              RGB( 157, 188, 219 ), 50, "Search" )

   oNav1:aRelatedNavigators := { oNav2 }
   oNav2:aRelatedNavigators := { oNav1 }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Paineis irmãos são reposicionados automaticamente via aRelatedNavigators. O array é ordenado por nOriginalLeft para manter a ordem da esquerda para a direita durante a alternância.
  • Quando recolhido, o texto do título é desenhado verticalmente usando a fonte oBoldVertical. Quando expandido, é desenhado horizontalmente no cabeçalho gradiente.
  • A imagem do botão de alternância padrão são setas embutidas (CreaArrowLeft / CreaArrowRight). Imagens de botão personalizadas podem ser fornecidas via cBtnImage1 e cBtnImage2.
  • Controles filhos são automaticamente mostrados/ocultos conforme o painel expande e recolhe.

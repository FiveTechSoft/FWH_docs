TIPAddress

Fonte: source/classes/tipaddr.prg

Herda de: TControl

TIPAddress encapsula o controle comum de endereço IP do Win32, fornecendo um campo de entrada especializado para endereços IPv4 em notação decimal pontuada. Cada um dos quatro octetos é editado em um segmento de campo separado, com validação integrada e restrições de intervalo opcionais por campo.

Principais Membros DATA

DATATipoDescrição
cIPAddressCharacterO endereço IP atual como uma string (ex.: "192.168.1.1")
aFieldRangesArrayArray de arrays de intervalo { nMin, nMax } para cada um dos quatro campos de octeto

Métodos

MétodoDescrição
New( nRow, nCol, oWnd, cIP, nW, nH )Cria um novo controle de entrada de endereço IP
SetAddress( cIP )Define o endereço IP do controle a partir de uma string decimal pontuada
GetAddress()Retorna o endereço IP atual como uma string decimal pontuada (ex.: "192.168.1.1")
ClearAddress()Limpa os quatro campos de octeto, deixando-os em branco
IsBlank()Retorna .T. se todos os quatro octetos estiverem vazios
SetRange( nField, nMin, nMax )Define os valores mínimo e máximo para um campo de octeto específico (1-4)
SetFocus( nField )Define o foco do teclado para um campo de octeto específico (1-4)

Exemplo: Entrada de Endereço IP com Intervalos de Campo

#include "FiveWin.ch"

function Main()

   local oWnd, oIP

   DEFINE WINDOW oWnd TITLE "IP Address" SIZE 350, 150

   @ 40, 20 IPADDRESS oIP ;
      SIZE 120, 25 OF oWnd ;
      ADDRESS "192.168.1.1"

   // Restringe o primeiro octeto a intervalos privados válidos
   oIP:SetRange( 1, 10, 192 )
   oIP:SetRange( 4, 1, 254 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TIPAddress encapsula o controle comum SysIPAddress32 do Win32. Ele trata apenas endereços IPv4.
  • Use SetRange( nField, nMin, nMax ) para restringir octetos individuais. nField começa em 1 (1 = octeto mais à esquerda, 4 = mais à direita).
  • O método GetAddress() retorna uma string vazia se o controle estiver em branco; use IsBlank() para verificar antes de ler.
  • A navegação entre os campos de octeto é automática: pressionar . (ponto) ou → move para o próximo campo.
  • A cláusula ADDRESS no comando @ ... IPADDRESS define o valor IP inicial.

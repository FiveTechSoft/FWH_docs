TBar

Fonte: source/classes/bar.prg

Herda de: TControl

TBar é um contêiner de barra de botões que exibe uma faixa horizontal ou vertical de botões com bitmap e separadores de grupo opcionais. Suporta múltiplos estilos visuais, incluindo 3D plano, temas Office 2007/2010/2013/2015, renderização GDI+, tema escuro e barras de ferramentas flutuantes/encaixáveis.

Exemplo: Barra Superior com 3 Botões

#include "FiveWin.ch"

function Main()

   local oWnd, oBar

   DEFINE WINDOW oWnd TITLE "Button Bar Demo" SIZE 600, 400

   oBar := TBar():New( oWnd, 32, 32,, "TOP" )

   oBar:Add( TButtonBmp():New(,, "New", oWnd,, 32, 32,,, .F., .F.,,,,, "new.bmp" ) )
   oBar:Add( TButtonBmp():New(,, "Open", oWnd,, 32, 32,,, .F., .F.,,,,, "open.bmp" ) )
   oBar:Add( TButtonBmp():New(,, "Save", oWnd,, 32, 32,,, .F., .F.,,,,, "save.bmp" ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • A TBar ajusta seu tamanho automaticamente à largura (topo/baixo) ou altura (esquerda/direita) da janela pai.
  • Use o parâmetro cMode para definir o encaixe inicial: "TOP", "LEFT", "RIGHT", "BOTTOM" ou "FLOAT".
  • O membro de dados l97Look controla a aparência plana de botão compatível com versões anteriores. Mantenha-o como NIL para a renderização moderna de botões.
  • Os temas Office (l2007, l2010, l2013, l2015) são mutuamente exclusivos; ative apenas um.
  • A TBar suporta menus de contexto do botão direito para personalização em tempo de execução.

TRichEdit5

Fonte: source/classes/triched5.prg

Herda de: TControl

TRichEdit5 encapsula o controle RichEdit 5.0 do Windows (classe de janela RichEdit50W), fornecendo edição de texto rico avançada com suporte para formatação RTF, realce de sintaxe, inserção de tabelas, imagens em linha, verificação ortográfica, impressão e exportação para PDF. É adequado para construir editores de texto completos e editores de código em aplicações FiveWin.

Exemplo: Editor RTF

#include "FiveWin.ch"

function Main()

   local oWnd, oRE

   DEFINE WINDOW oWnd TITLE "RichEdit 5.0 Editor" SIZE 800, 600

   @ 10, 10 RICHEDIT5 oRE VAR "" ;
      OF oWnd ;
      SIZE 760, 540 ;
      HIGHLIGHT ;
      BAR ;
      FILE "document.rtf"

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TRichEdit5 usa o controle RichEdit 5.0 (MsftEdit 5.0), disponível no Windows Vista e posteriores. Ele fornece significativamente mais recursos que o controle RichEdit padrão.
  • O realce de sintaxe é controlado por lHighlight e configurado através dos arrays aKeywords1, aKeywords2 e dos valores de cor nClrNumber, nClrString, nClrComment, nClrKey1, nClrKey2.
  • O indicador lBar habilita uma barra de ferramentas de formatação integrada com botões de negrito, itálico, sublinhado, fonte, tamanho, cor, alinhamento e tabela.
  • Use cText (acesso SETGET) para obter ou definir o conteúdo de texto simples, ou LoadRTF()/SaveAsRTF() para conteúdo RTF.
  • A verificação ortográfica (lSpell) destaca palavras mal escritas com um sublinhado vermelho.
  • A exportação para PDF e a pré-visualização de impressão são integradas via SaveToPDF() e Preview().
  • O controle suporta arrastar e soltar arquivos via a notificação EN_DROPFILES.

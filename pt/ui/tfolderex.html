TFolderEx

Fonte: source/classes/tfoldex.prg

Herda de: TControl

TFolderEx é um controle de pasta com abas estendido que suporta múltiplos layouts de abas (superior, esquerda, inferior, direita), renderização com gradiente, bitmaps por aba, animação, reordenação por arraste, habilitar/desabilitar/ocultar por aba e abas em múltiplas linhas. É o principal controle de abas usado em aplicações FWH modernas, oferecendo uma alternativa rica ao TFolder padrão.

Principais Membros DATA

DATATipoDescrição
aDialogsArrayArray de objetos de diálogo filho para cada página de aba
aPromptsArrayArray de strings de legenda das abas

aBitmapsArrayArray de handles de bitmap para cada ícone de aba
aAlignArrayAlinhamento de texto por aba: AL_LEFT, AL_RIGHT, AL_CENTER
nLayOutNumericPosição da aba: TOP (1), LEFT (2), BOTTOM (3), RIGHT (4)
nOptionNumericÍndice da aba atualmente selecionada (base 1)
nOverNumericÍndice da aba sobre a qual o mouse está atualmente posicionado
nSeparatorNumericEspaçamento em pixels entre abas adjacentes
nRoundNumericRaio dos cantos para os fundos das abas
aGradSelArrayGradiente para a aba selecionada
aGradUnselArrayGradiente para abas não selecionadas
aGradOverArrayGradiente para a aba sob o cursor
aGradDisArrayGradiente para abas desabilitadas
lAnimationLogicalHabilita transição animada ao trocar de abas
lMultiLineLogicalPermite que as abas se distribuam em múltiplas linhas
lStretchLogicalEstica as abas para preencher a largura disponível

Exemplo: Pasta com 3 Abas e Ícones

#include "FiveWin.ch"

function Main()

   local oWnd, oFolder, oDlg1, oDlg2, oDlg3

   DEFINE WINDOW oWnd TITLE "TFolderEx Demo" SIZE 600, 400

   oDlg1 := TDlg():New( 0, 0, 300, 200, "General", , , , , , , oWnd )
   oDlg2 := TDlg():New( 0, 0, 300, 200, "Options", , , , , , , oWnd )
   oDlg3 := TDlg():New( 0, 0, 300, 200, "About",   , , , , , , oWnd )

   @ 20, 20 FOLDEREX oFolder ;
        PROMPTS "General", "Options", "About" ;
        DIALOGS oDlg1, oDlg2, oDlg3 ;
        SIZE 560, 360 OF oWnd ;
        LAYOUT TOP

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TFolderEx suporta quatro layouts de abas via nLayOut: TOP (1), LEFT (2), BOTTOM (3), RIGHT (4). A faixa de abas é desenhada de acordo e os diálogos filhos são posicionados para preencher a área restante.
  • Os arrays de estado por aba (aEnable, aVisible, aAlign, aBitmaps) são mantidos em paralelo com aPrompts.
  • Quando lAnimation é verdadeiro, a troca de abas dispara uma transição deslizante controlada por nSpeed.
  • A renderização das abas é dividida em dois métodos internos: PaintLR() para layouts esquerda/direita e PaintTB() para layouts superior/inferior.
  • O clique com o botão direito em uma aba dispara bPopup se atribuído, permitindo menus de contexto por aba.
  • A reordenação de abas é suportada via aOrder — defina o array com a sequência de índices de aba desejada e chame ChangeOrder().

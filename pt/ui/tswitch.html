TSwitch

Fonte: source/classes/tswitch.prg

Herda de: TControl

TSwitch is a toggle switch control with four rendering modes: standard toggle, oval, radio-style, and check-box. It provides a modern on/off switch with customizable colors, thumb size, and border appearance. The control supports mouse hover effects, keyboard navigation, and read-only mode.

Sintaxe do Comando

@ nRow, nCol SWITCH oSw VAR lVar SIZE nW, nH PIXEL OF oWnd ;
   COLORS nClrOn, nClrOff BORDER nClrBorder

Modos de Renderização

TSwitch supports four visual rendering modes determined by the aspect ratio and style flags:

ModoAtivaçãoDescrição
Alternância padrãoLargura maior que alturaTrilha retangular com polegar deslizante (padrão)
OvallOvalStyle := .T.Trilha arredondada em formato de pílula com polegar
Estilo rádiolRadStyle := .T.Indicador circular liga/desliga
Caixa de seleçãoLargura igual à alturaRenderização em estilo de caixa de seleção quadrada

Exemplo: Alternância com Cores

#include "FiveWin.ch"

function Main()

   local oWnd, oSw, lOn := .F.

   DEFINE WINDOW oWnd TITLE "Toggle Switch Demo" SIZE 300, 200

   @ 40, 30 SWITCH oSw VAR lOn SIZE 60, 22 PIXEL OF oWnd ;
      COLORS CLR_GREEN, CLR_GRAY BORDER CLR_HGRAY

   oSw:bChange := { | lValue | MsgInfo( If( lValue, "ON", "OFF" ), "Switch Changed" ) }

   @ 120, 30 BUTTON "Toggle" SIZE 60, 25 PIXEL OF oWnd ;
      ACTION oSw:Toggle()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • O TSwitch usa bSetGet para ler e escrever seu estado lógico. A cláusula VAR no comando SWITCH cria este bloco de código automaticamente.
  • A cláusula COLORS na sintaxe do comando espera duas cores: a primeira para a trilha do estado LIGADO e a segunda para a trilha do estado DESLIGADO.
  • Quando lReadOnly está definido como .T., cliques do mouse e entrada do teclado são ignorados, mas o interruptor ainda pode ser alterado programaticamente via SetCheck(), Check() ou UnCheck().
  • Os efeitos de passagem do mouse estão ativados por padrão. A trilha e o polegar mudam de aparência quando o mouse entra na área do controle.
  • O controle respeita a ordem de tabulação e responde à tecla Espaço para alternar quando está em foco.

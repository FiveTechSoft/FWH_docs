TSelex / TSelector

Fonte: source/classes/tselex.prg, source/classes/selector.prg

Herda de: TControl (ambos)

TSelex é um controle deslizante segmentado com um polegar arrastável que permite aos usuários escolher entre um conjunto discreto de opções. TSelector é um controle de dial circular/radial para selecionar um valor ao longo de um arco. Ambos fornecem seleção visual com renderização de gradiente e interação por teclado/mouse.

Exemplo: Deslizante Segmentado e Dial Radial

#include "FiveWin.ch"

function Main()

   local oWnd, oSelex, oSelector, nOpt := 1, nVal := 5

   DEFINE WINDOW oWnd TITLE "TSelex + TSelector Demo" SIZE 400, 300

   @ 20, 20 SELEX oSelex VAR nOpt OPTIONS { "Low", "Med", "High" } ;
        SIZE 200, 30 OF oWnd

   @ 80, 20 SELECTOR oSelector VAR nVal ;
        ANGLES 180, 540 MIN 0 MAX 10 ;
        MARKS 11 EXACT OF oWnd SIZE 120, 120

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • As trilhas do TSelex são renderizadas com duas camadas de gradiente (aGradOut = trilha externa, aGradIn = destaque interno).
  • O polegar é desenhado como um retângulo arredondado; seu tamanho é controlado por nWidthThumb / nHeightThumb.
  • TSelector usa um sistema de coordenadas angulares. Os ângulos são especificados em graus; o construtor os converte internamente para radianos.
  • Quando lExact é verdadeiro e há marcas definidas, o dial se ajusta à marca mais próxima ao soltar o mouse.
  • Ambos os controles suportam navegação por teclado (teclas de seta para TSelex, setas para TSelector).

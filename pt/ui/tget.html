TGet / TMGet

Controles de entrada de texto com formatação PICTURE, validação e edição multi-linha

Visão Geral do TGet

Fonte: source/classes/tget.prg  |  Pai: TControl

TGet é o equivalente FiveWin do comando clássico GET do Clipper -- um controle de entrada de texto de linha única que suporta máscaras PICTURE, blocos de validação e vinculação de dados via bSetGet. É o carro-chefe dos formulários de entrada de dados.

Visão Geral do TMGet

Fonte: source/classes/mget.prg  |  Pai: TControl

TMGet (também conhecido como memo GET) oferece edição de texto multi-linha. É usado para campos de texto livre como notas, comentários e descrições. Ele encapsula o controle EDIT do Windows com o estilo ES_MULTILINE.

Principais Propriedades do TGet

PropriedadeTipoDescrição
bSetGetBlockBloco de vinculação de dados. Eval( bSetGet ) lê o valor; Eval( bSetGet, x ) escreve.
cPictureStringMáscara PICTURE controlando a formatação de entrada (ex: "@E 999,999.99", "@!", "99/99/9999")
bValidBlockBloco de validação avaliado quando o usuário sai do GET. Deve retornar .T. para permitir a saída.
bWhenBlockBloco de condição avaliado quando o foco se aproxima. Se .F., o GET é pulado (somente leitura).
lReadOnlyLogicalQuando .T., o campo não é editável.
lPasswordLogicalQuando .T., a entrada é mascarada com caracteres de ponto.
cCueTextStringTexto de placeholder exibido quando o GET está vazio e sem foco (marca d'água).
lSpinnerLogicalQuando .T., adiciona setas de incremento/decremento para entrada numérica.
nMinNumericValor mínimo para o spinner.
nMaxNumericValor máximo para o spinner.
bChangeBlockBloco avaliado cada vez que o texto muda (atualização em tempo real).
lRightLogicalAlinhar o texto à direita (útil para campos numéricos).

Máscaras PICTURE Comuns

MáscaraEfeitoExemplo Entrada/Saída

"999,999.99"Numérico com separadores de milhar1234.50 → 1,234.50
"@E 999,999.99"Numérico europeu (ponto=milhares, vírgula=decimal)1234.50 → 1.234,50
"99/99/9999"Máscara de data03242026 → 03/24/2026

Sintaxe de Comandos

GET de Linha Única

@ nRow, nCol GET oGet VAR cVar ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ PICTURE cMask ] ;
   [ VALID bValid ] ;
   [ WHEN bWhen ] ;
   [ READONLY ] ;
   [ PASSWORD ] ;
   [ SPINNER [ MIN nMin ] [ MAX nMax ] ] ;
   [ CUETEXT cPlaceholder ] ;
   [ ON CHANGE bChange ] ;
   [ FONT oFont ] ;
   [ RIGHT ]

GET Memo Multi-Linha

@ nRow, nCol GET oMGet VAR cMemo MEMO ;
   [ OF oWnd ] ;
   [ SIZE nWidth, nHeight ] ;
   [ READONLY ] ;
   [ FONT oFont ] ;
   [ HSCROLL ] ;
   [ NO WORDWRAP ]

Exemplos de Código

Exemplo 1: Formulário de Entrada de Dados com Vários Tipos de GET

#include "FiveWin.ch"

FUNCTION CustomerForm()
   LOCAL oDlg, oFont
   LOCAL cName   := Space( 30 )
   LOCAL cPhone  := Space( 14 )
   LOCAL nAge    := 0
   LOCAL dBirth  := CToD( "" )
   LOCAL cPass   := Space( 12 )
   LOCAL nSalary := 0
   LOCAL cNotes  := Space( 500 )

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14
   DEFINE DIALOG oDlg TITLE "Customer Entry" SIZE 480, 520 FONT oFont

   // Text input with uppercase mask
   @ 1.0, 1 SAY "Name:" OF oDlg
   @ 1.0, 6 GET cName OF oDlg SIZE 200, 22 ;
      PICTURE "@!" ;
      VALID ( !Empty( cName ) ) ;
      CUETEXT "Enter full name"

   // Phone with template mask
   @ 2.5, 1 SAY "Phone:" OF oDlg
   @ 2.5, 6 GET cPhone OF oDlg SIZE 140, 22 ;
      PICTURE "(999)999-9999"

   // Numeric with spinner
   @ 4.0, 1 SAY "Age:" OF oDlg
   @ 4.0, 6 GET nAge OF oDlg SIZE 80, 22 ;
      PICTURE "999" ;
      SPINNER MIN 0 MAX 120

   // Date field
   @ 5.5, 1 SAY "Birth Date:" OF oDlg
   @ 5.5, 6 GET dBirth OF oDlg SIZE 100, 22 ;
      PICTURE "99/99/9999"

   // Password field
   @ 7.0, 1 SAY "Password:" OF oDlg
   @ 7.0, 6 GET cPass OF oDlg SIZE 160, 22 ;
      PASSWORD

   // Numeric with European formatting
   @ 8.5, 1 SAY "Salary:" OF oDlg
   @ 8.5, 6 GET nSalary OF oDlg SIZE 140, 22 ;
      PICTURE "@E 9,999,999.99" ;
      RIGHT

   // Multi-line memo
   @ 10.0, 1 SAY "Notes:" OF oDlg
   @ 10.5, 1 GET cNotes MEMO OF oDlg SIZE 400, 100

   // Buttons
   @ 17, 6  BUTTON "&Save"   OF oDlg SIZE 80, 25 ACTION oDlg:End() DEFAULT
   @ 17, 16 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   RELEASE FONT oFont
RETURN NIL

Exemplo 2: GET Validado com WHEN Dinâmico

#include "FiveWin.ch"

FUNCTION ValidatedForm()
   LOCAL oDlg
   LOCAL cCode    := Space( 5 )
   LOCAL cDesc    := Space( 40 )
   LOCAL nQty     := 0
   LOCAL nPrice   := 0
   LOCAL lApprove := .F.

   DEFINE DIALOG oDlg TITLE "Order Entry" SIZE 400, 300

   @ 1, 1 SAY "Code:" OF oDlg
   @ 1, 5 GET cCode OF oDlg SIZE 80, 22 ;
      PICTURE "@!" ;
      VALID ( ValidateCode( cCode, @cDesc ) )  // look up code, fill description

   @ 2.5, 1 SAY "Description:" OF oDlg
   @ 2.5, 5 GET cDesc OF oDlg SIZE 200, 22 READONLY

   @ 4.0, 1 SAY "Quantity:" OF oDlg
   @ 4.0, 5 GET nQty OF oDlg SIZE 80, 22 ;
      PICTURE "9999" ;
      SPINNER MIN 1 MAX 9999 ;
      VALID ( nQty > 0 )

   @ 5.5, 1 SAY "Price:" OF oDlg
   @ 5.5, 5 GET nPrice OF oDlg SIZE 100, 22 ;
      PICTURE "@E 99,999.99" ;
      WHEN ( !Empty( cCode ) )          // only enabled after valid code

   @ 7.5, 5 BUTTON "&OK" OF oDlg SIZE 80, 25 ;
      ACTION ( lApprove := .T., oDlg:End() ) DEFAULT

   @ 7.5, 14 BUTTON "&Cancel" OF oDlg SIZE 80, 25 ;
      ACTION oDlg:End() CANCEL

   ACTIVATE DIALOG oDlg CENTERED

   IF lApprove
      // process the order...
   ENDIF
RETURN NIL

STATIC FUNCTION ValidateCode( cCode, cDesc )
   IF Empty( cCode )
      MsgStop( "Code is required." )
      RETURN .F.
   ENDIF
   // Look up in database
   cDesc := GetDescForCode( AllTrim( cCode ) )
   IF Empty( cDesc )
      MsgStop( "Code not found." )
      RETURN .F.
   ENDIF
RETURN .T.

Dicas e Boas Práticas

  • O bloco bSetGet é criado automaticamente pelo comando GET var. Para vincular a um campo: GET FieldWBlock( "NAME", Select() ).
  • Use CUETEXT (placeholder) para dar ao usuário uma dica sobre o formato de entrada esperado.
  • O bloco bValid pode exibir uma mensagem e retornar .F. para impedir que o usuário saia do campo.
  • Para GETs numéricos, sempre forneça um PICTURE para controlar casas decimais e separadores de milhar.
  • A cláusula SPINNER adiciona setas de incremento/decremento; combine com MIN/MAX para restringir o intervalo.
  • TMGet suporta HSCROLL para adicionar uma barra de rolagem horizontal, e NO WORDWRAP para desabilitar a quebra de linha.
  • Ao usar GETs em um diálogo, o FiveWin gerencia a ordem de tabulação automaticamente com base na ordem de criação.

TScrollPanelEx

Fonte: source/classes/scrollex.prg

Herda de: TPanel

TScrollPanelEx é um painel rolável aprimorado que suporta rolagem horizontal de controles filhos com entrada via teclado, roda do mouse, barra de rolagem e gestos (toque/pan). Ele rastreia os controles filhos mais à esquerda e mais à direita para calcular a faixa de rolagem e fornece gerenciamento automático da barra de rolagem. O painel é comumente usado para barras de ferramentas, layouts estilo ribbon e contêineres de overflow.

Membros DATA Principais

DATATipoDescrição

nScrollRangeNuméricoFaixa de rolagem calculada com base nas posições dos controles filhos
oCtrlLeftObjetoControle filho mais à esquerda (usado como limite de rolagem)
oCtrlRightObjetoControle filho mais à direita
nRightMarginNuméricoMargem direita para redimensionamento automático
nBottomMarginNuméricoMargem inferior para redimensionamento automático
aPagesArrayPosições de páginas nomeadas para navegação GoToPage
lScrollDragLógicoSinalizador do modo arrastar-para-rolar

Métodos

MétodoDescrição

SetRange()Varre os controles filhos e define a faixa de rolagem

Exemplo: Painel de Rolagem Suave com Controles Filhos

#include "FiveWin.ch"

function Main()

   local oWnd, oPanel, oBtn

   DEFINE WINDOW oWnd TITLE "TScrollPanelEx Demo" SIZE 600, 150

   @ 20, 20 SCROLLPANEX oPanel SIZE 560, 60 OF oWnd

   for n := 1 to 15
      @ 10, ( n - 1 ) * 90 BUTTON "Btn " + Str( n ) ;
         SIZE 80, 30 OF oPanel PIXEL
   next

   oPanel:SetRange()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Chame SetRange() após adicionar todos os controles filhos para calcular os limites de rolagem e anexar o rastreamento de foco para rolagem automática até a visualização.
  • Use SetPage( cName, nCol ) com GoToPage( cName ) para navegação por seções nomeadas.
  • A rolagem por arraste é habilitada ao manter pressionado o botão esquerdo do mouse e arrastar horizontalmente sobre o fundo do painel.
  • Gestos de toque (pan) são suportados em dispositivos com entrada por toque através do método HandleGesture (GID_PAN).

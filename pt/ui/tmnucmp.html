TMnuComp

Fonte: source/classes/tmnucomp.prg

Herda de: TComponent

TMnuComp é um componente não visual que encapsula um objeto TMenu no framework TComponent para uso no designer de formulários VisualFW. Permite que menus sejam projetados, manipulados e persistidos no ambiente do designer visual junto com controles visuais. O componente cria um menu padrão com itens de exemplo e o registra na janela pai.

Principais Membros DATA

DATATipoDescrição
oMenuTMenuO objeto TMenu encapsulado
cResBmpCharacterNome opcional de recurso de bitmap para o menu
cVarNameCharacterNome da variável usado no designer (de CLASSDATA aProperties)

Métodos

MétodoDescrição
New( nRow, nCol, oWnd, lDesign, oObject, cResBmp )Criar um componente de menu, encapsular o TMenu e anexá-lo à janela
aItems( aNewItems )Método SETGET; substitui todos os itens do menu por um novo array de definições
Destroy()Encerrar o menu encapsulado, desanexar da janela e destruir o componente

Exemplo: Componente de Menu no Designer

#include "FiveWin.ch"

function Main()

   local oWnd, oMnuComp

   DEFINE WINDOW oWnd TITLE "VisualFW Designer" SIZE 800, 600

   // TMnuComp e tipicamente instanciado pelo designer VisualFW.
   // Aqui e mostrado explicitamente:

   oMnuComp := TMnuComp():New( 0, 0, oWnd, .T., , "mybmp" )

   // oMnuComp:oMenu agora e a barra de menu da janela
   // Substituir todos os itens em tempo de execucao:

   oMnuComp:aItems := { "&File", "&Edit", "&View", "&Help" }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TMnuComp deriva de TComponent, não de TControl, portanto não tem representação visual no formulário. Aparece como um componente não visual na lista de componentes do designer.
  • O construtor New() cria um menu padrão com três itens de nível superior (&One, &Two, T&hree) e um submenu. Isso serve como marcador de posição no designer.
  • O método SETGET aItems destrói o menu atual e o reconstrói a partir de um array de strings. Cada string se torna um item de menu de nível superior.
  • O parâmetro cResBmp é passado para TComponent:New() para exibição opcional do ícone no designer.
  • No ambiente VisualFW, o designer serializa as aProperties (aItems, cVarName) do componente para salvar/carregar definições de formulários.

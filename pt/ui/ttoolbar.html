TToolBar

Fonte: source/classes/toolbar.prg

Herda de: TControl

TToolBar é um controle de barra de ferramentas que hospeda botões com bitmap, com tooltips, imagens e estilos visuais modernos opcionais. Ele fornece uma faixa de botões acoplável, normalmente posicionada no topo de uma janela. TToolBar suporta estilos de botão planos e 3D, listas de imagens para os glifos dos botões e temas modernos (2007/2010/2013/2015).

Exemplo: Barra de Ferramentas com Três Botões

#include "FiveWin.ch"

function Main()

   local oWnd, oToolBar, oImgList

   DEFINE WINDOW oWnd TITLE "TToolBar Demo" SIZE 600, 400

   oImgList := TImageList():New( 24, 24 )

   oToolBar := TToolBar():New( oWnd, 32, 32, oImgList, , , .T., , , , , , , .T. )

   oToolBar:AddButton( { || MsgInfo( "New" ) }, "Create a new document", "New" )
   oToolBar:AddButton( { || MsgInfo( "Open" ) }, "Open an existing file", "Open" )
   oToolBar:AddSeparator()
   oToolBar:AddButton( { || MsgInfo( "Save" ) }, "Save current document", "Save" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TToolBar cria automaticamente objetos TButton filhos para cada chamada de AddButton. Os valores nBtnWidth e nBtnHeight controlam o tamanho de todos os botões de forma uniforme.
  • Use l2007, l2010, l2013 ou l2015 para aplicar temas modernos de botão plano. Apenas um flag de tema deve estar como .T. de cada vez.
  • Quando lTTBalloon é .T., os tooltips são renderizados no estilo balão, com cantos arredondados e uma ponta apontada.
  • Defina oImageList para fornecer as imagens de glifo dos botões. O índice de imagem de cada botão corresponde à sua posição no array interno de botões da barra de ferramentas.
  • A barra de ferramentas normalmente é acoplada ao topo da janela usando oWnd:oTop := oToolBar após a criação.

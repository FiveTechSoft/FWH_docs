TPanel

Fonte: source/classes/tpanel.prg

Herda de: TControl

TPanel é um controle contêiner que hospeda controles filhos com suporte para transparência, cor de fundo personalizada e uma borda opcional. É comumente usado para agrupar controles relacionados visualmente dentro de um diálogo ou janela. O painel pode ser projetado em tempo de execução ou vinculado a um recurso de diálogo.

Principais Membros DATA

DATATipoDescrição
aControlsArrayArray de controles filhos hospedados no painel
nOpacityNumericNível de opacidade de 0 (transparente) a 255 (opaco)
nClrPaneNumericCor de preenchimento de fundo (valor RGB)

Métodos

MétodoDescrição
New( nTop, nLeft, nBottom, nRight, oWnd, lDesign, cVar, lBorder )Criar um novo controle painel
Redefine( nId, oWnd )Redefinir a partir de um recurso de diálogo
Paint()Pintar o fundo e a borda do painel
GotFocus( hCtlLost )Gerenciar a chegada do foco; encaminhar para controles filhos

Exemplo: Painel com Controles Filhos

#include "FiveWin.ch"

function Main()

   local oWnd, oPanel

   DEFINE WINDOW oWnd TITLE "TPanel Demo" SIZE 500, 400

   @ 20, 20 PANEL oPanel SIZE 460, 200 OF oWnd ;
      TRANSPARENT COLOR CLR_BTNFACE

   @ 30, 40 SAY "Name:" OF oPanel SIZE 40, 12
   @ 30, 90 GET ... OF oPanel SIZE 120, 20

   @ 60, 40 SAY "Email:" OF oPanel SIZE 40, 12
   @ 60, 90 GET ... OF oPanel SIZE 180, 20

   @ 100, 40 BUTTON "Save" OF oPanel SIZE 60, 25

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use a cláusula TRANSPARENT para tornar o fundo do painel transparente. Quando transparente, os controles filhos desenham diretamente sobre o fundo da janela pai.
  • A cláusula COLOR define nClrPane para o preenchimento de fundo quando a transparência está desabilitada.
  • TPanel suporta edição em modo de design quando lDesign é verdadeiro, permitindo reposicionamento por arrastar e soltar de controles filhos em tempo de execução durante o desenvolvimento.
  • O painel gerencia o foco encaminhando eventos GotFocus para o primeiro controle filho.

TSplitter

Fonte: source/classes/splitter.prg

Herda de: TControl

TSplitter fornece uma barra divisória arrastável que permite aos usuários redimensionar painéis de controle adjacentes em tempo de execução. É comumente usada para criar layouts de painel dividido redimensionáveis (por exemplo, uma árvore à esquerda e uma área de edição à direita) onde o usuário pode arrastar o divisor para alocar mais ou menos espaço a cada painel.

Membros DATA Principais

DATATipoDescrição
lVerticalLógicoDivisor vertical (painéis esquerda/direita) vs horizontal (superior/inferior)
aPrevCtrolsArrayControles do lado anterior (esquerda/superior) a serem redimensionados
aHindCtrolsArrayControles do lado posterior (direita/inferior) a serem redimensionados
nFirstNuméricoPosição inicial do divisor em pixels

Métodos

MétodoDescrição
New( nRow, nCol, lVert, aPrev, lAdjPrev, aHind, lAdjHind, bMargin1, bMargin2, oWnd, bChange )Cria um novo controle TSplitter
SetPosition( n )Define a posição do divisor programaticamente
AdjClient()Ajusta a área cliente da janela pai considerando o divisor

Exemplo: Divisor Vertical Entre Árvore e Edição

#include "FiveWin.ch"

function Main()

   local oWnd, oTree, oEdit, oSplit

   DEFINE WINDOW oWnd TITLE "Demo de Splitter" SIZE 700, 500

   @ 0, 0 TREE oTree SIZE 200, 500 OF oWnd
   oTree:AddNode( "Node 1" )
   oTree:AddNode( "Node 2" )

   @ 0, 210 GET oEdit VAR cVar MEMO SIZE 480, 500 OF oWnd

   @ 0, 200 SPLITTER oSplit ;
      VERTICAL ;
      PREVIOUS oTree ;
      HIND oEdit ;
      SIZE 10, 500 OF oWnd

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TSplitter rastreia automaticamente o movimento do mouse e redimensiona os controles anteriores e posteriores conforme o usuário arrasta a barra do divisor.
  • O parâmetro lVert determina a orientação: .T. para vertical (painéis esquerda/direita), .F. para horizontal (painéis superior/inferior).
  • aPrevCtrols e aHindCtrols aceitam tanto um único objeto de controle quanto um array de controles a serem redimensionados juntos.
  • O bloco de código bChange é disparado cada vez que o usuário termina de arrastar para uma nova posição, permitindo que o código da aplicação responda à mudança de layout.
  • Use AdjClient() para fazer o divisor participar da lógica de redimensionamento da área cliente da janela, garantindo que ele se reposicione corretamente quando a janela for redimensionada.

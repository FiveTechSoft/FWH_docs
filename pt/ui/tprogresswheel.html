TProgressWheel

Fonte: source/classes/metrcirc.prg

Herda de: TControl

TProgressWheel é um indicador de progresso circular/anel baseado em GDI+ que exibe texto de porcentagem concluída no centro. Suporta cores de preenchimento gradiente tanto para os segmentos de arco concluídos quanto restantes, um diâmetro interno ajustável e um modo de giro indeterminado adequado para operações de duração desconhecida. As propriedades de cor aceitam valores RGB numéricos, arrays gradientes, caminhos de arquivo de imagem ou objetos TBrush.

Exemplo: Progresso de Anel a 35%

#include "FiveWin.ch"

function Main()

   local oWnd, oWheel

   DEFINE WINDOW oWnd TITLE "Progress Wheel" SIZE 300, 300

   oWheel := TProgressWheel():New( 20, 20, oWnd, 35,, 100, 100,;
                                   .T.,,, .F., CLR_HGRAY,;
                                   CLR_HRED, CLR_HGREEN, CLR_WHITE,;
                                   0, 100, 0.60 )

   oWheel:lPercentage := .T.

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TProgressWheel usa GDI+ para toda a renderização. A biblioteca FWH vincula suporte GDI+ por padrão em versões recentes.
  • As propriedades de cor nColorRemain e nColorDoneMin aceitam RGB numérico, arrays gradientes de dois elementos { nClr1, nClr2 }, caminhos de arquivo de imagem para pincéis de textura ou objetos TBrush.
  • No modo indeterminado (Indefinite( .T. )), um temporizador interno impulsiona a rotação contínua de dois arcos coloridos, adequado para operações de duração desconhecida.
  • O diâmetro interno controla a espessura do anel. Valores próximos de 0 produzem um disco sólido; valores próximos de 1 produzem um contorno de anel fino.

TProgressWheel

Fonte: source/classes/metrcirc.prg

Herda de: TControl

O TProgressWheel é um indicador de progresso circular/anular baseado em GDI+ que exibe texto de porcentagem concluída no centro. Ele suporta cores de preenchimento gradiente para os segmentos de arco concluído e restante, um diâmetro interno ajustável e um modo de giro indeterminado adequado para operações de duração desconhecida. As propriedades de cor aceitam valores RGB numéricos, matrizes de gradiente, caminhos de arquivo de imagem ou objetos TBrush.

Exemplo: Progresso Anular a 35%

#include "FiveWin.ch"

function Main()

   local oWnd, oWheel

   DEFINE WINDOW oWnd TITLE "Progress Wheel" SIZE 300, 300

   oWheel := TProgressWheel():New( 20, 20, oWnd, 35,, 100, 100,;
                                   .T.,,, .F., CLR_HGRAY,;
                                   CLR_HRED, CLR_HGREEN, CLR_WHITE,;
                                   0, 100, 0.60 )

   oWheel:lPercentage := .T.

   ACTIVATE WINDOW oWnd CENTERED

return nil

Observações

  • O TProgressWheel usa GDI+ para toda a renderização. A biblioteca FWH vincula o suporte GDI+ por padrão em versões recentes.
  • As propriedades de cor nColorRemain e nColorDoneMin aceitam RGB numérico, matrizes de gradiente de dois elementos { nClr1, nClr2 }, caminhos de arquivo de imagem para pincéis de textura ou objetos TBrush.
  • No modo indeterminado (Indefinite( .T. )), um temporizador interno conduz a rotação contínua de dois arcos coloridos, adequado para operações de duração desconhecida.
  • O diâmetro interno controla a espessura do anel. Valores próximos de 0 produzem um disco sólido; valores próximos de 1 produzem um contorno de anel fino.

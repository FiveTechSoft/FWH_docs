TRating

Fonte: source/classes/trating.prg

Herda de: TControl

TRating é um controle interativo de classificação por estrelas que permite aos usuários selecionar um valor de classificação clicando em imagens de estrela. Ele suporta visualização por hover, clique para definir, exibição de meia-estrela e valores máximos configuráveis. O controle usa três estados de imagem (vazio, metade, cheio) para renderizar a classificação visual.

Exemplo: Controle de Classificação de 5 Estrelas

#include "FiveWin.ch"

function Main()

   local oWnd, oRating, nRating := 0

   DEFINE WINDOW oWnd TITLE "Rate this App" SIZE 400, 250

   @ 60, 40 RATING oRating ;
      RATING 5 ;
      EMPTY   "star_empty.bmp" ;
      HALF    "star_half.bmp"  ;
      FULL    "star_full.bmp"  ;
      OF oWnd ;
      MAX 100 ;
      INITIAL 0 ;
      CHANGE ( nRating := oRating:nSelectedValue, ;
               oWnd:SetText( "Rating: " + Str( nRating ) ) )

   @ 140, 40 SAY "Click a star to rate" ;
      SIZE 200, 20 OF oWnd

   @ 180, 40 BUTTON "Reset" SIZE 60, 25 OF oWnd ;
      ACTION oRating:Reset()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O comando RATING requer três imagens bitmap para os três estados visuais: EMPTY (não selecionado), HALF (preenchido pela metade) e FULL (totalmente selecionado).
  • nRating especifica o número de imagens de estrela exibidas (ex.: 5 para uma classificação de 5 estrelas). MAX define o valor numérico máximo (padrão 100), e o controle mapeia a posição visual para um valor proporcional.
  • O bloco de código CHANGE não recebe parâmetro; leia oRating:nSelectedValue dentro do bloco para obter a classificação atual.
  • Use bSetGet para vincular a classificação a uma variável ou campo de banco de dados. O bloco de código é avaliado na criação para ler o valor inicial e ao clicar para escrever o novo valor.
  • O comportamento de hover é gerenciado automaticamente: MouseMove atualiza nCurrentValue para feedback visual em tempo real, e MouseLeave restaura a exibição para nSelectedValue.
  • O membro de dados nPercentual controla o fator de escala. Com o padrão de 100, clicar na última estrela define o valor para 100. Ajuste isso para diferentes escalas de classificação.

TFLine

Fonte: source/classes/fline.prg

Classe independente

TFLine (Linha Formatada) é uma classe utilitária para compor uma linha formatada a partir de múltiplos fragmentos de texto estilizados. Cada fragmento pode ter sua própria fonte, cor e alinhamento. TFLine é usada em conjunto com TSay:oLine para renderizar rótulos de texto rico e com a saída de linha formatada de TReport. A classe mantém um array de trios de texto, fonte e cor que são desenhados como uma única linha, com a quebra de linha controlada por lCrLf.

Membros DATA Principais

DATATipoDescrição
oUpObjetoObjeto ligado a montante (usado em cadeias de linhas)
oDownObjetoObjeto ligado a jusante
nalignNuméricoValor de alinhamento da linha (0 = padrão)
aTextArrayArray de strings de texto para cada fragmento
aFontsArrayArray de objetos de fonte ou índices para cada fragmento
aColorsArrayArray de valores de cor para cada fragmento
lCrLfLógicoInsere retorno de carro/avanço de linha após esta linha

Métodos

MétodoDescrição
New( nalign, aText, aFonts, aColors, lCrLf )Cria uma linha formatada com os fragmentos fornecidos. Padrões: {}, {}, {}, 0, .F.
End()Libera os objetos ligados (define oUp e oDown como NIL)

Exemplo: Fragmentos de Texto Estilizados

#include "FiveWin.ch"

function FormattedLabel()

   local oSay, oLine

   DEFINE FONT oFont1 NAME "Arial" SIZE 0, -24
   DEFINE FONT oFont2 NAME "Arial" SIZE 0, -18 BOLD

   oLine := TFLine():New( 0, ;
      { "Welcome ", "FiveWin ", "User" }, ;
      { oFont1, oFont2, oFont1 }, ;
      { CLR_BLUE, CLR_RED, CLR_BLACK } )

   // Usa oLine com TSay para exibição
   @ 10, 10 SAY oSay PROMPT "" OF oWnd SIZE 300, 50
   oSay:oLine := oLine
   oSay:lTransparent := .T.

return nil

Notas

  • TFLine é usada principalmente de forma interna por TSay e TReport para dar suporte à renderização de texto com múltiplos estilos em uma única linha.
  • Cada elemento de array em aText, aFonts e aColors corresponde a um fragmento estilizado. Os fragmentos são concatenados horizontalmente.
  • Defina lCrLf := .T. para forçar uma quebra de linha após esta linha formatada.
  • Os ponteiros oUp e oDown permitem encadear múltiplos objetos TFLine.

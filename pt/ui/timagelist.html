TImageList

Fonte: source/classes/timaglst.prg

Classe independente (não derivada de TControl)

TImageList é um wrapper independente em torno da API Win32 HIMAGELIST para gerenciar coleções de ícones e bitmaps de tamanho igual. As listas de imagens são amplamente utilizadas por tree views, list views, controles de abas, barras de ferramentas e outros controles comuns para gerenciar conjuntos de ícones de forma eficiente.

Principais Membros DATA

DATATipoDescrição
hImageListHandleHandle Win32 HIMAGELIST
aBitmapsArrayArray de objetos TBitmap adicionados à lista

Métodos

MétodoDescrição
New( nWidth, nHeight )Cria uma nova lista de imagens. O tamanho padrão é 16x16 pixels.
Add( oBmpImage, oBmpMask )Adiciona uma imagem com bitmap de máscara opcional à lista. Retorna o índice da imagem.
AddMasked( oBmpImage, nClrMask )Adiciona uma imagem usando uma cor transparente como máscara. Retorna o índice da imagem.
AddIcon( oIcon )Adiciona um ícone (objeto TIcon ou nome de arquivo/recurso de ícone) à lista. Retorna o índice da imagem.
AddImage( cFile )Carrega e adiciona uma imagem a partir de um caminho de arquivo. Retorna o índice da imagem.
ReadBitmap( cFile, nWidth, nImages, nClrTransparent )Carrega uma faixa de bitmaps de um arquivo, dividida em nImages quadros, usando nClrTransparent como a cor de máscara transparente.
SetBkColor( nColor )Define a cor de fundo usada ao renderizar imagens mascaradas. Use CLR_NONE para fundo transparente.
End()Destrói a lista de imagens e libera todos os recursos associados.

Exemplo: Criar uma Lista de Imagens para uma Barra de Ferramentas

#include "FiveWin.ch"

function Main()

   local oWnd, oImgList, oBar

   DEFINE WINDOW oWnd TITLE "ImageList Demo" SIZE 500, 300

   // Cria uma lista de imagens 24x24
   oImgList := TImageList():New( 24, 24 )

   // Adiciona bitmaps mascarados (usando magenta como cor transparente)
   oImgList:AddMasked( TBitmap():Load( "bitmaps\new.bmp"  ), CLR_MAGENTA )
   oImgList:AddMasked( TBitmap():Load( "bitmaps\open.bmp" ), CLR_MAGENTA )
   oImgList:AddMasked( TBitmap():Load( "bitmaps\save.bmp" ), CLR_MAGENTA )

   // Vincula a uma barra de botões de ferramentas
   oBar := TButtonBar():New( oWnd, , , oImgList )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TImageList é uma classe não visual e não herda de TControl. Ela gerencia o ciclo de vida de um handle Win32 HIMAGELIST que pode ser compartilhado entre múltiplos controles comuns.
  • Todas as imagens em uma única lista de imagens devem ter o mesmo tamanho (largura e altura), o qual é especificado no momento da criação em New().
  • O método AddMasked() é a forma mais comum de adicionar bitmaps, usando uma cor transparente (tipicamente CLR_MAGENTA ou CLR_WHITE) para criar a máscara automaticamente.
  • ReadBitmap() é útil para carregar faixas de bitmaps (várias imagens dispostas horizontalmente em um único arquivo de bitmap). Especifique o número de imagens e a cor transparente para dividi-las automaticamente.
  • Sempre chame End() quando a lista de imagens não for mais necessária para evitar vazamentos de handles GDI. A lista de imagens é frequentemente destruída automaticamente quando a janela pai é destruída.

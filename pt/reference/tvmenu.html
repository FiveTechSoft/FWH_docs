TVMenu

Fonte: source/classes/VMenu.prg

Hereda de: TControl

TVMenu e um painel estilo ExplorerBar que exibe uma lista de objetos TVItem. Suporta cabecalho colapsavel, animacao de abrir/fechar, multiplos estilos de selecao (SOLID, INSET, XBOX, BUMP, ETCHED, RAISED, UNDERLINE), fundos com degradê e renderizacao com temas. TVMenu e o container pai dos objetos TVItem, que sao automaticamente adicionados ao array aItems do menu ao serem criados.

Construtor New()

TVMenu():New( nTop, nLeft, nWidth, nHeight, oWnd, bAction, nClrText, nClrPane,;
              oFont, lBorder, nClrBorder, nHItem, cTextAlign, under, nMargen,;
              nClrPSel, nSpeed, selmode, bChange, nClrTSel, oAttach,;
              nClrTOver, nClrPOver, nClrPOver2, nClrPSel2,;
              lVGradSel, lMGradSel, nClrPane2, cWaterMark )
ParametroTipoDescricao
nTop, nLeftNumericoPosicao em pixels
nWidth, nHeightNumericoDimensoes em pixels
oWndTWindowJanela pai
bActionBlocoAcao padrao para os itens
nClrTextNumericoCor do texto (padrao: branco)
nClrPaneNumericoCor de fundo (padrao: cinza claro)
oFontTFontFonte para o texto dos itens
lBorderLogicoMostrar borda (padrao: .f.)
nHItemNumericoAltura minima do item em pixels
cTextAlignCaractere"LEFT", "CENTER", "RIGHT", "MULTILINE"
underCaractereEstilo de selecao: "SOLID", "INSET", "XBOX", etc.
selmodeCaractereModo de preenchimento: "FILLED", "NONE", "DOTS", etc.
bChangeBlocoExecutado ao mudar a selecao
cWaterMarkCaractereNome do arquivo bitmap para marca d'agua

Exemplo

local oMenu, oItem

oMenu := TVMenu():New( 0, 0, 220, 380, oWnd, ;
         {|| MsgInfo("Acao") }, ;
         RGB(55,65,80), RGB(245,246,248), ;
         oFont, .t., RGB(220,224,230), ;
         0, , "SOLID", 5, , 1, "FILLED" )

oMenu:SetTitle( "Explorador", 28, oFont, ;
                RGB(255,255,255), RGB(70,130,180), ;
                , 50, .f., , , , , , .t., 17 )

oItem := TVItem():New( oMenu, "Inicio" )
oItem:SetImage( hBmp )

oItem := TVItem():New( oMenu, "Documentos" )
oItem:SetImage( hBmp2 )

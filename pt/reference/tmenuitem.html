TMenuItem

Fonte: source/classes/menuitem.prg

Classe independente

TMenuItem representa uma única entrada dentro de um objeto TMenu. Cada item tem um texto (prompt), uma ação opcional (bloco de código), um estado marcado/desmarcado, um estado habilitado/desabilitado e uma condição WHEN para visibilidade dinâmica. Os itens também podem atuar como separadores ou abrir submenus.

Principais Membros DATA

DATATipoDescrição
cPromptCharacterTexto do item de menu, com & para o sublinhado do acelerador
nIdNumericID de comando do item de menu
bActionBlockBloco de código executado ao selecionar
bWhenBlockBloco de código avaliado para habilitar/desabilitar o item dinamicamente
lCheckedLogicalIndica se o item exibe uma marca de seleção
lActiveLogicalIndica se o item está habilitado (clicável)
lSeparatorLogical.T. para uma barra separadora
oMenuObjectObjeto TMenu pai que contém este item

Métodos Principais

MétodoDescrição
New( cPrompt, cMsg, lChecked, lActive, bAction, bWhen, ... )Cria um novo item de menu
ReDefine( cPrompt, ... )Redefine um item de menu a partir de um recurso
SetCheck( lOn )Alterna a marca de seleção (ligada/desligada)
Enable()Habilita o item de menu
Disable()Desabilita (esmaece) o item de menu
SetPrompt( cText )Altera o texto do item de menu em tempo de execução

Exemplo: Item de Menu com Ação e Marca de Seleção

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu, oItemStatus

   DEFINE WINDOW oWnd TITLE "TMenuItem Demo" ;
      MENU buildMenu( @oItemStatus )

   ACTIVATE WINDOW oWnd CENTERED

return nil

function buildMenu( oItemStatus )

   local oMenu

   MENU oMenu
      MENUITEM "&View"
      MENU oSub
         MENUITEM "&Toolbar" ACTION MsgInfo( "Toggle Toolbar" )
         MENUITEM "&Status Bar" ;
            ACTION MsgInfo( "Toggle Status Bar" ) ;
            CHECKED
         SEPARATOR
         MENUITEM "E&xit" ACTION oWnd:End()
      ENDMENU
   ENDMENU

return oMenu

Notas

  • Use a cláusula CHECKED no comando MENUITEM para criar um item que já vem marcado inicialmente.
  • O bloco bWhen é avaliado cada vez que o menu é aberto. Se retornar .F., o item é desabilitado.
  • SetPrompt() permite alterações dinâmicas do texto do menu, útil para listas de arquivos recentes ou indicadores de estado.
  • Itens separadores são criados com o comando SEPARATOR; eles não têm ação nem texto.
  • A cada item de menu é atribuído um nId único pelo menu pai, usado para o roteamento de comandos e o mapeamento de aceleradores.

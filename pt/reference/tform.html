TForm

Fonte: source/classes/tform.prg

Herda de: TWindow

TForm é um contêiner visual de formulário que carrega o layout de seus controles a partir de um recurso .ffm (Forms File Memory). É utilizado pela IDE Visual FiveWin para projetar e executar formulários em tempo de execução. O formulário serializa os controles filhos, suas propriedades e os vínculos com bancos de dados.

Principais Membros DATA

DATATipoDescrição
nBorderStyleNumericEstilo de borda da janela (padrão 3 = redimensionável)
nPositionNumericPosição inicial: 0=normal, 1=maximizada, 2=minimizada
cDescriptionCharacterDescrição visível no gerenciador de Projeto Visual
cClassNameCharacterNome da classe usado como nome de recurso padrão para carregar o .ffm
oInspectorObjectObjeto inspetor de propriedades para o modo de design
aPropertiesArrayArray DATA de classe que lista todas as propriedades serializáveis
lDesignLogicalAtiva o modo de design com arrastar e soltar para os controles filhos

Métodos Principais

MétodoDescrição
New()Cria um novo formulário com configurações padrão e carrega o recurso .ffm
LoadRes( cResName, cResType )Carrega a definição do formulário a partir de um recurso (tipo "FORMS" por padrão)
ShowModal()Exibe o formulário como um diálogo modal, respeitando nPosition
Initiate()Inicializa os controles: cria janelas filhas, resolve aliases e configura os vínculos com bancos de dados
Default()Define os valores padrão para estilo de borda, posição e barras de rolagem

Exemplo: Carregar e Exibir o Formulário

#include "FiveWin.ch"

function Main()

   local oForm := TForm():New()

   oForm:cTitle     := "Meu Formulário"
   oForm:nWidth     := 600
   oForm:nHeight    := 400
   oForm:nPosition  := 0   // normal

   oForm:ShowModal()

return nil

Notas

  • TForm carrega o layout de seus controles a partir de um recurso binário .ffm armazenado sob o tipo de recurso "FORMS", indexado pelo nome da classe.
  • Initiate() processa os componentes de banco de dados (TDataBaseComp) antes dos demais controles, de modo que os aliases estejam disponíveis para TXBrowse e controles semelhantes.
  • O modo de design é alternado por meio de lDesign, que permite reposicionar todos os controles filhos com arrastar e soltar.
  • Controles sem um hWnd existente são criados a partir de suas propriedades armazenadas; as coordenadas são normalizadas se forem negativas.

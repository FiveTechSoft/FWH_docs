TLex

Fonte: source/classes/tlex.prg

Herda de: TFile

TLex é um analisador léxico (tokenizador) que lê texto-fonte de um arquivo ou string e o divide em tokens. Suporta caracteres separadores configuráveis, modos de pular-em-branco e pular-em-CRLF, tabelas de identificadores e mapeamento de IDs de token. A classe retorna tokens sequencialmente via nGetToken(), que retorna um ID numérico de token correspondente às entradas no array aTokens.

Principais Membros DATA

DATATipoDescrição
aTokensArrayArray de definições de token (cada entrada: { cTokenString, nTokenId })
aIdsArrayArray de strings de identificadores reconhecidos
lSkipBlankLógicoPular caracteres de espaço em branco ao tokenizar
lSkipCRLFLógicoPular caracteres de retorno de carro e avanço de linha
cTokenCaractereO último texto de token extraído
cSeparatorsCaractereString de caracteres separadores usados para delimitar tokens
uValueQualquerValor opcional associado ao token atual
cTextCaractereO texto-fonte completo sendo tokenizado

Métodos Principais

MétodoDescrição
New( cFile, aTokens, aIds, cSeparators )Cria um TLex a partir de um arquivo, com tabela de tokens, tabela de identificadores e separadores
nGetToken()Extrai o próximo token e retorna seu ID numérico (0 = não reconhecido, -1 = fim)
lEoF()Retorna .T. quando o fim do texto-fonte for alcançado
SetText( c )Define o texto-fonte a ser tokenizado (alternativa ao construtor baseado em arquivo)
Add( cToken, nId )Adiciona uma nova string de token com seu ID numérico à tabela de tokens

Exemplo: Tokenizar Script IF-THEN-ELSE

#include "FiveWin.ch"

function Main()

   local oLex, nToken
   local cScript := "IF x > 10 THEN print 'Hello' ELSE stop"

   // Define os tokens: { string, id }
   local aTokens := { ;
      { "IF",    1 }, ;
      { "THEN",  2 }, ;
      { "ELSE",  3 }, ;
      { ">",     4 }, ;
      { "print", 5 }, ;
      { "stop",  6 }  }

   // Cria o lexer
   oLex := TLex():New( , aTokens )
   oLex:SetText( cScript )
   oLex:lSkipBlank := .T.

   // Tokeniza
   while ! oLex:lEoF()
      nToken := oLex:nGetToken()
      if nToken == 0
         ? "Unrecognized:", oLex:cToken
      elseif nToken > 0
         ? "Token ID:", nToken, "Text:", oLex:cToken
      endif
   enddo

return nil

Notas

  • TLex herda de TFile, permitindo texto-fonte baseado em arquivo. Use SetText() para tokenizar uma string em vez disso.
  • O array aTokens mapeia padrões de string para IDs numéricos. nGetToken() retorna o ID do token correspondente, 0 para uma sequência não reconhecida, ou -1 no fim da entrada.
  • cSeparators define quais caracteres delimitam tokens. Os separadores padrão incluem espaço, tabulação e pontuação comum se não forem especificados.
  • O membro DATA cToken sempre contém o último texto de token extraído, útil para mensagens de diagnóstico ou consultas à tabela de símbolos.

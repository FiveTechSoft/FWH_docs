TPen

Fonte: source/classes/pen.prg

Classe independente (sem herança)

TPen encapsula um objeto pen (caneta) GDI do Windows para desenhar linhas, bordas e contornos. As pens definem a cor, a largura e o estilo (sólido, tracejado, pontilhado, etc.) das linhas desenhadas em qualquer contexto de dispositivo. TPen é usada internamente por muitos controles do FiveWin e também está disponível para uso direto em rotinas de pintura personalizadas.

Principais Membros DATA

DATATipoDescrição
hPenNumérico (Handle)Handle da pen GDI do Windows
nStyleNuméricoEstilo da pen (PS_SOLID, PS_DASH, PS_DOT, PS_DASHDOT, etc.)
nWidthNuméricoLargura da pen em unidades lógicas (pixels)
nColorNuméricoCor da pen como valor RGB
oDeviceObjetoContexto de dispositivo proprietário opcional para escalonamento de largura ciente de DPI

Métodos Principais

MétodoDescrição
New( nStyle, nWidth, nColor, oDevice )Cria uma nova pen. Padrões: PS_SOLID, largura 1, CLR_BLACK. Quando oDevice é fornecido, a largura é escalonada pelo DPI.
End()Exclui o objeto pen GDI e libera os recursos. Apelido para Release().

Estilos de Pen

ConstanteValorDescrição
PS_SOLID0Linha sólida (padrão)
PS_DASH1Linha tracejada (válida apenas quando a largura é 1)
PS_DOT2Linha pontilhada (válida apenas quando a largura é 1)
PS_DASHDOT3Padrão alternado traço-ponto
PS_DASHDOTDOT4Padrão traço-ponto-ponto
PS_NULL5Pen invisível
PS_INSIDEFRAME6Pen sólida que desenha dentro do quadro delimitador

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oPen

   DEFINE WINDOW oWnd TITLE "TPen Demo" SIZE 400, 300

   oWnd:bPainted = {| hDC |
      // Cria uma pen vermelha com largura 2
      DEFINE PEN oPen WIDTH 2 COLOR CLR_RED

      // Desenha uma linha do canto superior esquerdo ao inferior direito
      MoveTo( hDC, 50, 50 )
      LineTo( hDC, 350, 250, oPen:hPen )

      oPen:End()
      }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Sempre chame End() ou Release() quando a pen não for mais necessária para evitar vazamentos de recursos GDI.
  • Ao especificar um oDevice (janela, impressora, etc.), a largura da pen é escalonada automaticamente com base nos pixels lógicos por polegada do dispositivo, tornando a largura visual consistente entre diferentes configurações de DPI.
  • O comando DEFINE PEN oferece uma alternativa de sintaxe conveniente em vez de chamar TPen():New() diretamente.
  • TPen é usada extensivamente pelos controles do FiveWin internamente. Uma vez que uma pen é selecionada em um contexto de dispositivo via SelectObject(), ela afeta todas as operações de desenho subsequentes até que outra pen seja selecionada.

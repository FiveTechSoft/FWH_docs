TGSelector / TChooseGradient / TInk

Fonte: source/classes/tgselect.prg

TGSelector de TControl, TChooseGradient diálogo autônomo, TInk autônomo

TGSelector é um controle editor de barra de gradiente que permite aos usuários criar e editar visualmente gradientes de cores adicionando, movendo e removendo paradas de cor ("inks") ao longo de uma barra de gradiente. TChooseGradient fornece um invólucro de diálogo completo em torno de TGSelector com controles deslizantes RGB para edição precisa de cores. TInk representa uma única parada de cor dentro do gradiente.

TGSelector

Uma subclasse de TControl que exibe uma barra de gradiente interativa com paradas de cor móveis.

TChooseGradient

Um diálogo modal completo para editar gradientes com feedback visual e controles RGB.

MétodoDescrição
New( aInit, bCode, bOnOK, bOnCancel )Abre o diálogo do editor de gradiente. aInit é o array de gradiente inicial. bCode é avaliado a cada alteração. bOnOK/bOnCancel são blocos de ação.

TInk

Representa uma única parada de cor no gradiente.

DATATipoDescrição
nPorcentClrNumericPosição percentual ao longo do gradiente (0.0 a 1.0)
nColorStartNumericCor inicial (lado esquerdo da parada)
nColorEndNumericCor final (lado direito da parada)
lSelectedLogicalIndica se esta ink está atualmente selecionada
lMoveLogicalIndica se a ink pode ser movida (falso para inks de limite)
lFirstLogicalIndica se esta é a primeira ink (mais à esquerda) no gradiente

Função Livre

FunçãoDescrição
ChooseGradient( aInit ) --> aGradOutAbre o diálogo seletor de gradiente e retorna o array de gradiente resultante. Esta é a maneira mais simples de usar o editor de gradiente.

Exemplo

#include "FiveWin.ch"

function Main()

   local aGrad

   // Gradiente inicial: preto para branco
   local aInit := { { 1, 0, nRGB( 255, 255, 255 ) } }

   // Abre o diálogo seletor de gradiente
   aGrad := ChooseGradient( aInit )

   if ! Empty( aGrad )
      // Usa o gradiente: por exemplo, preenche o fundo de uma janela
      MsgInfo( "Gradient created with " + Str( Len( aGrad ) ) + " stops" )
   endif

return nil

Notas

  • A função ChooseGradient() é o ponto de entrada mais simples -- ela abre um diálogo completo com controles deslizantes RGB, um painel de cor e botões OK/Cancelar, e então retorna o array de gradiente resultante.
  • O formato do array de gradiente de saída é { { nPercent, nColorStart, nColorEnd }, ... }, que é diretamente utilizável por GradientFill() e outras funções de desenho de gradiente.
  • Clicar com o botão direito em uma ink interior a remove (mescla seu espaço com os vizinhos).
  • Clicar duas vezes em uma ink abre o seletor de cores do Windows (ChooseColor()) para editar sua cor.
  • As inks podem ser arrastadas para a esquerda/direita para ajustar sua posição no gradiente.

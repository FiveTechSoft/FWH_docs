TXBrCode

Fonte: source/classes/xbrcode.prg

Inherits from: TXBrowse + TXBrColCode

TXBrCode is a code-generation tool that produces FiveWin PRG source code from a live TXBrowse configuration. It inspects the browse definition, including columns, data sources, headers, footers, and button bars, and outputs ready-to-compile Harbour code in multiple coding styles.

Methods

MethodDescription
PrgCode()Return an array of 4 strings representing the generated code segments: (1) main window/browse setup, (2) column definitions, (3) button bar, (4) activation code
PrgCodeMain()Generate the main window and browse definition code block
PrgCodeOpenData()Generate the data source opening code block
PrgCodeBtnBar()Generate the button bar definition code block
BrwDataCode( lOops )Generate browse column definitions with optional error-handling wrapper
RptCode()Generate a report definition based on the browse layout

TXBrColCode

TXBrColCode extends column code generation with multiple style options and the ability to reuse column definitions across different output formats.

MethodDescription
PrgCode( nStyle, lSameCols )Return a character string with column PRG code in the specified style (1=command syntax, 2=WITH_OBJECT syntax, 3=OOP syntax). Set lSameCols to reuse column definitions from a previous call

Example: Generate Browse PRG

#include "FiveWin.ch"

function Main()

   local oBrw, oCode
   local aCode

   // ... browse definition ...

   oCode := TXBrCode()      // Same object as oBrw
   // or create an independent code generator

   aCode := oCode:PrgCode()

   // aCode[1] = window/browse setup
   // aCode[2] = column definitions
   // aCode[3] = button bar
   // aCode[4] = activation

   // Preview the generated code
   MemoEdit( aCode[1] + aCode[2] + aCode[3] + aCode[4] )

return nil

Notes

  • TXBrCode shares the same object instance as the browse. After configuring the browse interactively, call PrgCode() to capture its structure as source code.
  • The BrwDataCode() method is useful for generating column code that includes error handling around data access (lOops parameter).
  • TXBrColCode provides three output styles: command-style (@ ... XBROWSE ...), WITH_OBJECT-style, and pure OOP-style for maximum flexibility.
  • Generated code includes all column headers, data blocks, widths, footers, and picture clauses as configured in the browse.

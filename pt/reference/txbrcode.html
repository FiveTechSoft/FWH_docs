TXBrCode

Fonte: source/classes/xbrcode.prg

Herda de: TXBrowse + TXBrColCode

TXBrCode é uma ferramenta de geração de código que produz código-fonte PRG do FiveWin a partir de uma configuração TXBrowse ativa. Ela inspeciona a definição do browse, incluindo colunas, fontes de dados, cabeçalhos, rodapés e barras de botões, e gera código Harbour pronto para compilar em múltiplos estilos de codificação.

Métodos Principais

MétodoDescrição
PrgCode()Retorna um array de 4 strings que representam os segmentos de código gerados: (1) configuração da janela/browse principal, (2) definições de colunas, (3) barra de botões, (4) código de ativação
PrgCodeMain()Gera o bloco de código da janela principal e da definição do browse
PrgCodeOpenData()Gera o bloco de código de abertura da fonte de dados
PrgCodeBtnBar()Gera o bloco de código de definição da barra de botões
BrwDataCode( lOops )Gera as definições de colunas do browse com um invólucro opcional de tratamento de erros
RptCode()Gera uma definição de relatório baseada no layout do browse

TXBrColCode

TXBrColCode estende a geração de código de colunas com múltiplas opções de estilo e a capacidade de reutilizar definições de colunas em diferentes formatos de saída.

MétodoDescrição
PrgCode( nStyle, lSameCols )Retorna uma string de caracteres com o código PRG das colunas no estilo especificado (1=sintaxe de comando, 2=sintaxe WITH_OBJECT, 3=sintaxe OOP). Defina lSameCols para reutilizar as definições de colunas de uma chamada anterior

Exemplo: Gerar PRG do Browse

#include "FiveWin.ch"

function Main()

   local oBrw, oCode
   local aCode

   // ... definição do browse ...

   oCode := TXBrCode()      // Mesmo objeto que oBrw
   // ou cria um gerador de código independente

   aCode := oCode:PrgCode()

   // aCode[1] = configuração da janela/browse
   // aCode[2] = definições de colunas
   // aCode[3] = barra de botões
   // aCode[4] = ativação

   // Pré-visualiza o código gerado
   MemoEdit( aCode[1] + aCode[2] + aCode[3] + aCode[4] )

return nil

Notas

  • TXBrCode compartilha a mesma instância de objeto que o browse. Após configurar o browse interativamente, chame PrgCode() para capturar sua estrutura como código-fonte.
  • O método BrwDataCode() é útil para gerar código de colunas que inclui tratamento de erros em torno do acesso aos dados (parâmetro lOops).
  • TXBrColCode fornece três estilos de saída: estilo de comando (@ ... XBROWSE ...), estilo WITH_OBJECT e estilo OOP puro para máxima flexibilidade.
  • O código gerado inclui todos os cabeçalhos de colunas, blocos de dados, larguras, rodapés e cláusulas picture conforme configurado no browse.

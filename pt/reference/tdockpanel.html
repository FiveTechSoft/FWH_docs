TDockPnel

Fonte: source/internal/tdockpnel.prg

Herda de: TControl

TDockPnel é um controle de painel acoplável (dockable) que fornece uma janela flutuante/de ferramentas com uma barra de título e uma área de conteúdo interna. Suporta múltiplos modos de conteúdo (nMode: 1=TPanel, 2=TScrollPanel, 9=TDialog) e vários tipos de controle (nType: 1=ButtonBar, 2=TTitle, 3=TRibbonBar, 4=TFolderEx, 5=TXBrowse). O painel pode ser acoplado a qualquer borda e suporta redimensionamento baseado em divisor (splitter).

Exemplo: Painel Acoplável com XBrowse

#include "FiveWin.ch"

function Main()

   local oWnd, oDock, oBrw

   DEFINE WINDOW oWnd TITLE "Dock Panel Demo" SIZE 800, 600

   // Cria um painel acoplável com conteúdo XBrowse
   oDock := TDockPnel():New( oWnd, 30, 10, 400, 600, "Data Browser", ;
                              1, CLR_BLACK, RGB(240,240,255), .F. )

   oDock:nType := 5   // conteúdo TXBrowse

   // Configura as colunas do XBrowse
   oBrw := TXBrowse():New( oDock:oPnelP )
   oBrw:AddCol( "Name" )
   oBrw:AddCol( "Value" )
   oBrw:lRecordSelector := .F.

   oDock:SetCtrlsPnel( oBrw )
   oDock:SetColors( CLR_BLACK, RGB(240,240,255), CLR_WHITE, RGB(50,100,200) )
   oDock:Activate()

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

Notas

  • A propriedade nMode determina o tipo de contêiner interno criado para hospedar controles. O modo 1 (TPanel) é o padrão para layouts simples; o modo 9 (TDialog) habilita o comportamento no estilo de diálogo com botões OK/Cancelar.
  • A propriedade nType seleciona qual tipo de controle integrado é renderizado dentro do painel. O tipo 5 (TXBrowse) é comumente usado para grades de dados.
  • Use SetSplitV() para adicionar um divisor vertical arrastável. O divisor permite que os usuários redimensionem o painel em tempo de execução.
  • Os 52 estilos predefinidos acessíveis via SetStyle() controlam a aparência visual, incluindo gradientes, bordas e renderização de fonte.

Funções Principais do FWH

O FiveWin fornece centenas de funções que estendem o Harbour com acesso à API do Windows, utilitários de GUI e auxiliares de conveniência. Esta página documenta as mais utilizadas.

Funções de Caixa de Mensagem

MsgInfo()

MsgInfo( cMessage [, cTitle ] ) --> nil

Exibe uma caixa de mensagem informativa com um ícone "i" e botão OK. O título padrão é "Information". 

MsgInfo( "Record saved successfully" )
MsgInfo( "Total: " + LTrim( Str( nTotal ) ), "Calculation Result" )

MsgAlert()

MsgAlert( cMessage [, cTitle ] ) --> nil

Exibe uma caixa de mensagem de aviso com um ícone de exclamação. Título padrão: "Alert". 

MsgAlert( "File not found: " + cFile )

MsgStop()

MsgStop( cMessage [, cTitle ] ) --> nil

Exibe uma caixa de mensagem de erro/parada com um ícone X vermelho. Título padrão: "Stop". 

MsgStop( "Invalid data entered", "Validation Error" )

MsgYesNo()

MsgYesNo( cMessage [, cTitle ] ) --> lYes

Exibe um diálogo de pergunta Sim/Não. Retorna .T. se o usuário clicar em Sim, .F. para Não. 

if MsgYesNo( "Are you sure you want to delete this record?" )
   oDb:Delete()
endif

MsgNoYes()

MsgNoYes( cMessage [, cTitle ] ) --> lYes

Igual ao MsgYesNo() mas com "Não" como botão padrão (focado).

MsgGet()

MsgGet( cTitle, cPrompt, @cValue [, cPicture ] ) --> lOk

Exibe um diálogo de entrada com um campo GET. Retorna .T. se o usuário clicar em OK. O valor é retornado por referência em cValue. 

local cName := Space( 40 )
if MsgGet( "Input", "Enter your name:", @cName )
   ? "Name:", Trim( cName )
endif

Alert()

Alert( cMessage [, aButtons ] ) --> nButton

Função alert padrão do Harbour, aprimorada pelo FiveWin para exibir um diálogo GUI em vez de um alerta de console. Retorna o número do botão clicado (base 1). 

local nChoice := Alert( "Choose an action", { "Save", "Discard", "Cancel" } )
do case
   case nChoice == 1 ; SaveData()
   case nChoice == 2 ; // discard
   case nChoice == 3 ; // cancel
endcase

Idioma e Localização

FWString()

FWString( cEnglishText ) --> cLocalizedText

Retorna a versão localizada de uma string com base na configuração de idioma atual. O FiveWin inclui traduções para espanhol, francês, alemão, português, italiano, holandês, russo e muitos outros idiomas. 

? FWString( "Save" )   // "Guardar" (if Spanish)
? FWString( "Cancel" ) // "Annuler" (if French)

FWSetLanguage()

FWSetLanguage( cLang [, hCustomStrings ] ) --> cPrevLang

Definir o idioma da aplicação. Os valores integrados incluem: "EN" (inglês), "ES" (espanhol), "FR" (francês), "DE" (alemão), "PT" (português), "IT" (italiano), "NL" (holandês), "RU" (russo), "PL" (polonês), "CZ" (tcheco), "SK" (eslovaco), "HR" (croata), "HU" (húngaro), "RO" (romeno), "BG" (búlgaro), "TR" (turco), "ZH" (chinês), "JA" (japonês), "KO" (coreano), "AR" (árabe). 

FWSetLanguage( "ES" )  // Switch to Spanish

Diálogos de Arquivo e Diretório

cGetFile()

cGetFile( cFilter, cTitle [, nFilterIndex [, cInitDir [, lMulti [, nFlags ] ] ] ] ) --> cFile

Exibe um diálogo de Abrir Arquivo. Retorna o caminho do arquivo selecionado, ou string vazia se cancelado. 

local cFile

cFile := cGetFile( "DBF Files (*.dbf)|*.dbf|All Files (*.*)|*.*", ;
                   "Select Database" )

if ! Empty( cFile )
   ? "Selected:", cFile
endif

// Multiple file selection
cFile := cGetFile( "Images|*.jpg;*.png;*.bmp", "Select Images",,,  .T. )
// Returns files separated by CRLF

cPutFile()

cPutFile( cFilter, cTitle [, nFilterIndex [, cInitDir [, cDefFile ] ] ] ) --> cFile

Exibe um diálogo de Salvar Arquivo. Retorna o caminho selecionado, ou string vazia se cancelado. 

local cFile := cPutFile( "PDF Files (*.pdf)|*.pdf", "Save Report As" )
if ! Empty( cFile )
   SaveReport( cFile )
endif

cGetDir()

cGetDir( [cTitle [, cInitDir ] ] ) --> cDir

Exibe um diálogo de seleção de pasta. Retorna o caminho do diretório selecionado. 

local cDir := cGetDir( "Select output folder" )
if ! Empty( cDir )
   SetErrorPath( cDir )
endif

Funções de Conversão

cValToChar()

cValToChar( uValue ) --> cString

Converte qualquer valor Harbour para sua representação em string de caracteres. Funciona com tipos numérico, data, lógico, array, hash, nil e objeto. 

? cValToChar( 42 )           // "42"
? cValToChar( .T. )          // ".T."
? cValToChar( Date() )       // "03/24/2026"
? cValToChar( nil )          // "NIL"
? cValToChar( { 1, 2, 3 } ) // "{ 1, 2, 3 }"

nLoWord() / nHiWord()

nLoWord( nDWord ) --> nWord
nHiWord( nDWord ) --> nWord

Extrair a palavra de 16 bits de ordem baixa ou alta de um valor de 32 bits. Essencial para processar mensagens do Windows onde wParam/lParam empacotam dois valores. 

// In a WM_SIZE handler:
local nWidth  := nLoWord( nLParam )
local nHeight := nHiWord( nLParam )

Funções de Data/Hora

FW_ADDMONTH()

FW_ADDMONTH( tDate, nMths ) --> tDateTime

Adiciona um número de meses a um valor de data ou datetime. Lida automaticamente com limites de ano e ajustes de fim de mês. 

? FW_ADDMONTH( CTOD( "01/15/2026" ), 3 )  // 04/15/2026
? FW_ADDMONTH( CTOD( "01/31/2026" ), 1 )  // 02/28/2026 (end-of-month adjusted)

FW_YMDLAPSED()

FW_YMDLAPSED( dFrom, dLast ) --> { nYears, nMonths, nDays }

Retorna o tempo decorrido entre duas datas como um array de anos, meses e dias. Útil para calcular idade ou tempo de serviço em formato legível. 

local aLapsed := FW_YMDLAPSED( CTOD( "03/15/2020" ), Date() )
? "Years:", aLapsed[ 1 ], "Months:", aLapsed[ 2 ], "Days:", aLapsed[ 3 ]

FW_MTHSLAPSED()

FW_MTHSLAPSED( dDate1, dDate2 ) --> nMonths

Retorna o número de meses civis completos entre duas datas. Diferente da divisão simples por contagem de dias, esta função respeita os limites dos meses do calendário. 

? FW_MTHSLAPSED( CTOD( "01/15/2026" ), CTOD( "04/20/2026" ) )  // 3

FW_AGE()

FW_AGE( dDob, dAsOn ) --> nAge

Calcula a idade em anos completos a partir de uma data de nascimento, em relação a uma data específica. 

local nAge := FW_AGE( CTOD( "04/15/1980" ), Date() )
? "Age:", nAge

FW_NEXTBIRTHDAY()

FW_NEXTBIRTHDAY( dDob, dToday, lIncludeToday ) --> dDate

Retorna a data do próximo aniversário a partir de uma data de nascimento, relativa a uma data específica. Se lIncludeToday for .T. e hoje for o aniversário, retorna a data de hoje. 

local dNext := FW_NEXTBIRTHDAY( CTOD( "04/15/1980" ), Date() )
? "Next birthday:", dNext

FW_ADDTIME()

FW_ADDTIME( tDate, cTimeStr ) --> tDateTime

Adiciona uma string de duração de tempo a um valor datetime. A string de tempo suporta o formato "HH:MM:SS" e pode abranger vários dias. 

local tStart := FW_ADDMONTH( Date(), 0 ) // today at midnight
local tEnd   := FW_ADDTIME( tStart, "02:30:00" )
? "Two and a half hours later:", tEnd

FW_DateToUnix()

FW_DateToUnix( tDateTime ) --> nMilliSecs

Converte um valor datetime para milissegundos desde a época Unix (1970-01-01 00:00:00 UTC). Essencial para comunicação com APIs e aritmética de timestamps. 

local nMs := FW_DateToUnix( DateTime() )
? "Current epoch ms:", nMs

FW_UnixToDate()

FW_UnixToDate( nMilliSecs ) --> tDateTime

Converte milissegundos desde a época Unix de volta para um valor datetime. O inverso de FW_DateToUnix(). 

local tDate := FW_UnixToDate( 1713129600000 )
? "Date from epoch:", tDate

UTC_TIMESTAMP()

UTC_TIMESTAMP( dDateTime ) --> tDateTime

Converte um datetime local para Tempo Universal Coordenado (UTC). Aplica o offset do fuso horário local para produzir o datetime UTC equivalente. 

local tUtc := UTC_TIMESTAMP( DateTime() )
? "UTC time:", tUtc

FW_UTCTOLOCAL()

FW_UTCTOLOCAL( tUtcTime ) --> tDateTime

Converte um datetime UTC de volta para a hora local. O inverso de UTC_TIMESTAMP(). 

local tLocal := FW_UTCTOLOCAL( tUtc )
? "Local time:", tLocal

FW_TIMEZONE()

FW_TIMEZONE() --> cTimezoneStr

Retorna o offset do fuso horário local como uma string formatada, ex. "+05:30" para a Índia ou "-05:00" para o Horário Padrão do Leste (EUA). 

? "Timezone offset:", FW_TIMEZONE()  // e.g. "+05:30"

FW_SToT()

FW_SToT( cDateTime ) --> tDateTime

Converte uma string datetime para um valor datetime do Harbour. Aceita vários formatos padrão, incluindo "YYYY-MM-DD HH:MM:SS" e "MM/DD/YYYY HH:MM:SS". 

local t := FW_SToT( "2026-05-28 14:30:00" )
? "Parsed datetime:", t

Informações de Versão e Sistema

FWVersion()

FWVersion() --> cVersion

Retorna a string de versão do FiveWin, ex. "FWH 26.05".

GetVersion()

GetVersion() --> aVersion

Retorna um array com informações de versão do Windows: { nMajor, nMinor, nBuild, cPlatform }.

hb_Compiler()

hb_Compiler() --> cCompiler

Retorna a string de versão do compilador Harbour.

IsExe64()

IsExe64() --> lIs64

Retorna .T. se a aplicação atual é um executável de 64 bits.

IsWinNT() / IsWin10() / IsWin11()

IsWinNT() --> lNT
IsWin10() --> lWin10

Detectar a versão do Windows.

Funções de Informação do Sistema

ScreenWidth()

ScreenWidth() --> nPixels

Retorna a largura total da tela em pixels. Útil para posicionar janelas e diálogos em relação aos limites da tela. 

local nW := ScreenWidth()
oWnd:SetSize( nW / 2, ScreenHeight() / 2 )

ScreenHeight()

ScreenHeight() --> nPixels

Retorna a altura total da tela em pixels. Combina com ScreenWidth() para cálculos de centralização e dimensionamento.

ScreenScaling()

ScreenScaling() --> nScale

Retorna o fator de escala DPI para o monitor principal. Retorna 1.0 para 96 DPI (100%), 1.25 para 120 DPI (125%), 1.5 para 144 DPI (150%), etc. 

local nScale := ScreenScaling()
if nScale > 1.0
   MsgInfo( "Monitor de alta-DPI detectado: " + Str( nScale * 100, 3, 0 ) + "%" )
endif

IsWindows11()

IsWindows11() --> lBoolean

Retorna .T. se a aplicação estiver sendo executada no Windows 11. Verifica o número de build do Windows (requer build 22000 ou superior). 

if IsWindows11()
   // Aplicar estilo específico do Windows 11
   oWnd:lWin11 := .T.
endif

IsWindows10()

IsWindows10() --> lBoolean

Retorna .T. se a aplicação estiver sendo executada no Windows 10.

IsWin64()

IsWin64() --> lBoolean

Retorna .T. se estiver sendo executado em uma versão de 64 bits do Windows, independentemente de a aplicação em si ser de 32 ou 64 bits. 

if IsWin64()
   ? "Executando no Windows 64 bits"
endif

IsDarkTheme()

IsDarkTheme() --> lBoolean

Detecta se o tema escuro do Windows (configuração de personalização) está ativo no momento. Útil para adaptar as cores da aplicação em tempo de execução. 

if IsDarkTheme()
   SetAppColors( CLR_BLACK, CLR_WHITE )
else
   SetAppColors( CLR_WHITE, CLR_BLACK )
endif

FW_IsTouchScreen()

FW_IsTouchScreen() --> lBoolean

Retorna .T. se o sistema tiver capacidade de entrada por toque. Útil para adaptar a IU fornecendo alvos de toque maiores e suporte a gestos. 

if FW_IsTouchScreen()
   oBtn:SetSize( 64, 48 )  // botões maiores para toque
endif

FW_IsMousePresent()

FW_IsMousePresent() --> lBoolean

Retorna .T. se pelo menos um mouse estiver conectado ao sistema. Útil para dispositivos somente toque onde efeitos de hover e clique direito podem não se aplicar. 

if ! FW_IsMousePresent()
   // Ativar navegação touch-friendly
   oWnd:SetTouchMode( .T. )
endif

GetCPUSpeed()

GetCPUSpeed() --> nMhz

Retorna a velocidade aproximada da CPU em MHz. Usa contadores de desempenho do Windows para estimar a frequência do clock do processador. 

? "Velocidade da CPU:", GetCPUSpeed(), "MHz"

FW_ActiveMonitors()

FW_ActiveMonitors() --> nCount

Retorna o número de monitores ativos conectados ao sistema. Útil para configuração de vários monitores e posicionamento de janelas. 

if FW_ActiveMonitors() > 1
   // Posicionar janela no monitor secundário
   oWnd:SetWindowPos(, 1920, 100, 800, 600 )
endif

cWinVersion()

cWinVersion() --> cVersion

Retorna uma string legível da versão do Windows, como "Windows 11 Pro" ou "Windows 10 Enterprise". Inclui informações de edição quando disponível. 

? "SO:", cWinVersion()

ScrResolution()

ScrResolution() --> { nWidth, nHeight }

Retorna a resolução da tela como um array de largura e altura em pixels. Similar a ScreenWidth()/ScreenHeight() mas retorna ambos em uma única chamada. 

local aRes := ScrResolution()
oWnd:SetSize( aRes[ 1 ] * 0.75, aRes[ 2 ] * 0.75 )

WndCenterEx()

WndCenterEx( hWnd, hParent ) --> nil

Centraliza uma janela no monitor onde a janela pai está atualmente exibida. Diferente da WndCenter() básica, esta função lida corretamente com configurações de vários monitores. 

WndCenterEx( hWnd, hParent )
// Centraliza a janela filha no mesmo monitor que sua janela pai

Funções de Shell e Processo

ShellExecute()

ShellExecute( nHwnd, cOperation, cFile [, cParams [, cDir [, nShowCmd ] ] ] ) --> nResult

Executar ou abrir um arquivo usando o shell do Windows. Operações comuns: "open", "print", "explore", "runas". 

// Open a file with its default application
ShellExecute( 0, "open", "report.pdf" )

// Open a URL in the default browser
ShellExecute( 0, "open", "https://www.fivetechsoft.com" )

// Open Windows Explorer at a folder
ShellExecute( 0, "explore", "C:\data\" )

// Print a document
ShellExecute( 0, "print", "document.docx" )

// Run as administrator
ShellExecute( 0, "runas", "myapp.exe" )

WinExec()

WinExec( cCommandLine [, nShowCmd ] ) --> nResult

Executar um programa. Alternativa simples ao ShellExecute para iniciar executáveis. 

WinExec( "notepad.exe C:\data\log.txt" )
WinExec( "calc.exe" )

Funções do Sistema de Arquivos

lIsDir()

lIsDir( cDirName ) --> lBoolean

Verifica se o caminho especificado é um diretório existente. Retorna .T. se o diretório existe e está acessível. 

if ! lIsDir( "C:\data\backup" )
   lMkDir( "C:\data\backup" )
endif

lMkDir()

lMkDir( cPath ) --> lSuccess

Cria um diretório. Retorna .T. em caso de sucesso. Cria diretórios intermediários se necessário (similar a mkdir -p). 

if lMkDir( "C:\data\reports\2026\may" )
   ? "Diretório criado com sucesso"
endif

cFilePath()

cFilePath( cPathMask ) --> cPath

Extrai a parte do caminho de um caminho de arquivo completo, excluindo o nome do arquivo. Inclui a barra invertida final. 

? cFilePath( "C:\data\app\myfile.txt" )  // "C:\data\app\"

cFileNoPath()

cFileNoPath( cPathMask ) --> cFileName

Extrai a parte do nome do arquivo de um caminho completo, excluindo o caminho do diretório. O inverso de cFilePath(). 

? cFileNoPath( "C:\data\app\myfile.txt" )  // "myfile.txt"

cFileNoExt()

cFileNoExt( cPathMask ) --> cName

Retorna o nome do arquivo sem sua extensão. Remove tudo após o último ponto. 

? cFileNoExt( "C:\data\app\myfile.txt" )  // "C:\data\app\myfile"

cFileExt()

cFileExt( cPathMask ) --> cExt

Retorna a extensão do arquivo sem o ponto. O inverso de cFileNoExt(). 

? cFileExt( "myfile.txt" )  // "txt"
? cFileExt( "C:\data\app\myfile.dbf" )  // "dbf"

cNewFileName()

cNewFileName( cRootName, cExt ) --> cFileName

Gera um nome de arquivo único anexando um sufixo numérico se o arquivo de destino já existir. Útil para rotinas de backup e exportação. 

local cName := cNewFileName( "backup", "zip" )
// Retorna "backup.zip" ou "backup_001.zip", "backup_002.zip", etc.

cTempFile()

cTempFile( cPath, cExtension ) --> cFileName

Cria um arquivo temporário com um nome único no diretório especificado. O arquivo é criado no disco, mas deixado vazio para o chamador escrever. 

local cTmp := cTempFile( "C:\temp", "tmp" )
? "Arquivo temporário:", cTmp

FSize()

FSize( cFile ) --> nFileSize

Retorna o tamanho de um arquivo em bytes. Retorna -1 se o arquivo não existir ou não puder ser acessado. 

local nBytes := FSize( "C:\data\largefile.dbf" )
? "Tamanho do arquivo:", nBytes, "bytes"
? "Em KB:", nBytes / 1024

FDate()

FDate( cFile ) --> dFileDate

Retorna a data da última modificação de um arquivo como um valor de data do Harbour. 

local d := FDate( "C:\data\customer.dbf" )
? "Última modificação:", d

FTime()

FTime( cFile ) --> cFileTime

Retorna a hora da última modificação de um arquivo como uma string no formato "HH:MM:SS". 

local cTime := FTime( "C:\data\customer.dbf" )
? "Última modificação às:", cTime

ADrives()

ADrives( nType ) --> aDrives

Retorna um array de letras de unidades disponíveis. O parâmetro nType filtra por tipo de unidade: 0 = todas, 1 = disquetes, 2 = discos rígidos, 3 = unidades de rede, 4 = unidades de CD/DVD, 5 = unidades RAM. 

local aHD := ADrives( 2 )  // apenas discos rígidos
? "Unidades fixas:"
AEval( aHD, { |c| QOut( c ) } )

FW_MEMOWRIT()

FW_MEMOWRIT( cFile, cText ) --> lSuccess

Escreve conteúdo de texto em um arquivo, sobrescrevendo qualquer conteúdo existente. Retorna .T. em caso de sucesso. Um wrapper simplificado em torno do MemoWrit() do Harbour. 

if FW_MEMOWRIT( "C:\log\output.txt", "Processo concluído às " + Time() )
   ? "Arquivo escrito com sucesso"
endif

aFindFile()

aFindFile( cFileName, cPath ) --> aFiles

Pesquisa recursivamente por arquivos correspondentes a um padrão no diretório especificado. Retorna um array de caminhos completos de arquivos. 

local aPrgs := aFindFile( "*.prg", "C:\fwteam\source" )
? "Encontrados " + LTrim( Str( Len( aPrgs ) ) ) + " arquivos PRG"

Funções de Cor

GetSysColor()

GetSysColor( nIndex ) --> nRGBColor

Obter uma cor do sistema Windows. Índices comuns: COLOR_WINDOW (5), COLOR_WINDOWTEXT (8), COLOR_BTNFACE (15), COLOR_HIGHLIGHT (13), COLOR_HIGHLIGHTTEXT (14). 

local nBgColor := GetSysColor( 5 )  // Window background color

nRGB()

nRGB( nRed, nGreen, nBlue ) --> nRGBColor

Criar um valor de cor RGB a partir de componentes individuais (0-255 cada).

local nRed   := nRGB( 255, 0, 0 )
local nGreen := nRGB( 0, 128, 0 )
local nBlue  := nRGB( 0, 0, 255 )
local nCustom := nRGB( 45, 52, 64 )  // dark gray-blue

Funções de Imagem e Desenho

FW_ReadImage()

FW_ReadImage( oWnd, uSource, aResize ) --> aImageInfo

Carrega uma imagem de um caminho de arquivo, URL, identificador de recurso ou buffer de memória. Retorna um array: { hBitmap, hPalette, nWidth, nHeight, lAlpha, cName }. Suporta BMP, PNG, JPG, GIF e TIFF via GDI+. 

local aImg := FW_ReadImage( oWnd, "logo.png" )
if aImg[ 5 ]  // has alpha channel
   oBmp:SetBitmap( aImg[ 1 ] )
endif

FW_DrawImage()

FW_DrawImage( oWnd, hBmp, aRect, lTransp, nResize, nAlpha, lGray, cAlign )

Desenha uma imagem em uma janela ou contexto de dispositivo com redimensionamento opcional, mesclagem alfa, conversão para escala de cinza e alinhamento (C = centro, T = topo, B = fundo, L = esquerda, R = direita). 

// Draw image centered and semi-transparent
FW_DrawImage( oWnd, hBmp, { 10, 10, 210, 210 }, .F., 0, 128, .F., "C" )

FW_SaveImage()

FW_SaveImage( uImage, cFile, nJpegQuality )

Salva uma imagem (handle ou array de imagem) em um arquivo. O formato de saída é determinado pela extensão do arquivo: BMP, PNG, JPG, GIF ou TIFF. O parâmetro nJpegQuality (1-100) controla a qualidade da compressão JPEG. 

FW_SaveImage( hBitmap, "thumbnail.jpg", 85 )

FW_SaveThumbNail()

FW_SaveThumbNail( cImage, cThumb, nWidth, nHeight ) --> lSuccess

Cria uma miniatura a partir de um arquivo de imagem de origem, salvando-a no caminho especificado. Mantém a proporção enquanto ajusta às dimensões fornecidas. 

FW_SaveThumbNail( "photo.jpg", "thumb.jpg", 150, 150 )

FW_ImageToBLOB()

FW_ImageToBLOB( uImage, cType, nQuality ) --> cBuffer

Converte uma imagem em um BLOB binário (buffer de memória) adequado para armazenar em um campo de banco de dados. O parâmetro cType especifica o formato de saída ("JPG", "PNG", "BMP", "GIF"). 

local cBlob := FW_ImageToBLOB( hBmp, "JPG", 80 )
oRs:Fields( "photo" ):Value := cBlob

FW_TextToBitmap()

FW_TextToBitmap( cText, oFont, nClrText, nClrBack ) --> hBitmap

Renderiza texto em um handle de bitmap usando a fonte e cores especificadas. Útil para criar rótulos baseados em imagem, marcas d'água ou sobreposições de texto. 

local hBmp := FW_TextToBitmap( "Hello World", oFont, nRGB( 255,0,0 ), CLR_WHITE )

FW_BarCodeBmp()

FW_BarCodeBmp( cText, cType, nWidth, nHeight ) --> hBitmap

Gera um bitmap de código de barras a partir de dados de texto. Os tipos de código de barras suportados incluem "EAN13", "CODE128", "CODE39", "UPCA", "QR" e mais. 

local hBmp := FW_BarCodeBmp( "123456789012", "EAN13", 200, 60 )
oImage:SetBitmap( hBmp )

FW_DrawShadow()

FW_DrawShadow( hDC, aRect, nSize, nAlpha )

Desenha um efeito de sombra projetada ao redor de um retângulo no contexto de dispositivo fornecido. O parâmetro nSize controla a largura da sombra e nAlpha (0-255) controla a opacidade. 

FW_DrawShadow( hDC, { 10, 10, 300, 200 }, 8, 80 )

DrawProgressBar()

DrawProgressBar( hDC, aRect, nValue, nTotal, aColors )

Desenha uma barra de progresso personalizada no contexto de dispositivo especificado. O array aColors pode especificar as cores da barra e do fundo. 

DrawProgressBar( hDC, { 10, 10, 310, 30 }, 65, 100, { CLR_GREEN, CLR_GRAY } )

FW_PieChart()

FW_PieChart( oWnd, aRect, aValues, aColors )

Desenha um gráfico de pizza ou rosca na janela especificada dentro do retângulo fornecido. O array aValues contém os dados numéricos e aColors fornece as cores dos segmentos. 

FW_PieChart( oWnd, { 10, 10, 310, 310 }, { 30, 50, 20 }, ;
             { CLR_RED, CLR_BLUE, CLR_GREEN } )

GradientFill()

GradientFill( hDC, nTop, nLeft, nBottom, nRight, aGradInfo, lVert )

Funções de Formato e Conversão de Dados

cValToStr()

cValToStr( uVal, cPic ) --> cString

Converte qualquer valor Harbour para uma string formatada. O parâmetro cPic aceita máscaras de data/hora como "dd/mm/yyyy hh:mi:ss" e "dddd, mmmm dd, yyyy", tornando-o mais flexível que cValToChar(). 

? cValToStr( Date(), "dddd, mmmm dd, yyyy" )  // "Thursday, May 28, 2026"
? cValToStr( 1234.56, "999,999.99" )            // "  1,234.56"
? cValToStr( .T., "Yes/No" )                    // "Yes"

FW_TRANSFORM()

FW_TRANSFORM( uVal, cPic ) --> cString

Versão aprimorada de Transform() que suporta tokens de data (dd, mmm, yyyy, hh, mi, ss) na string de picture. Converte automaticamente valores de data e numéricos para suas strings formatadas apropriadas. 

? FW_TRANSFORM( Date(), "dd/mm/yyyy" )  // "28/05/2026"
? FW_TRANSFORM( DateTime(), "dd-mm-yyyy hh:mi:ss" )

uCharToVal()

uCharToVal( cText, cType ) --> uVal

Converte uma string para um valor tipado com base no tipo especificado ("N", "D", "L", "C"). Quando cType é omitido, detecta automaticamente o tipo a partir do conteúdo da string. 

? uCharToVal( "123.45", "N" ) + 1        // 124.45
? uCharToVal( "20260324", "D" )           // 03/24/2026 (Sett format)
? uCharToVal( ".T.", "L" )                // .T.
? uCharToVal( "123.45" )                  // auto-detected as numeric

nStrToNum()

nStrToNum( cNum, lEuropean ) --> nValue

Analisa uma string numérica contendo separadores de milhar e marcadores decimais. Quando lEuropean é .T., trata a vírgula como separador decimal e o ponto como separador de milhar. Quando .F. (padrão), usa a convenção americana. 

? nStrToNum( "1,234.56", .F. )   // 1234.56 (Americano)
? nStrToNum( "1.234,56", .T. )   // 1234.56 (Europeu)

FWNumFormat()

FWNumFormat( cFormat, lThouSep ) --> aPrev

Define ou recupera o formato numérico atual para exibição. O parâmetro cFormat aceita "A" (Americano: 1,234.56), "E" (Europeu: 1.234,56), "B" (Britânico: 1,234.56), "I" (Indiano: 12,34,56.78). Retorna as configurações de formato anteriores. 

FWNumFormat( "E", .T. )       // Mudar para formato Europeu
? Str( 1234567.89, 12, 2 )    // "1.234.567,89"

FW_ValToCSV()

FW_ValToCSV( uVal ) --> cCSV

Converte um único valor para sua representação CSV. Lida com aspas e escape automaticamente com base no tipo de valor. 

? FW_ValToCSV( "Smith, John" )  // '"Smith, John"' (entre aspas devido à vírgula)
? FW_ValToCSV( 1234 )            // "1234"

FW_ArrayToCSV()

FW_ArrayToCSV( aData, aHead ) --> cCSV

Converte um array (tipicamente de um browse ou consulta) para o formato CSV. O parâmetro opcional aHead fornece cabeçalhos de coluna. Retorna o texto CSV completo. 

local aData := { { "John", 30 }, { "Jane", 25 } }
local aHead := { "Name", "Age" }
local cCSV  := FW_ArrayToCSV( aData, aHead )
FW_MEMOWRIT( "export.csv", cCSV )

FW_ValToJSON / FW_JsonDecode()

FW_ValToJSON( uVal [, lPretty ] ) --> cJson
FW_JsonDecode( cJson ) --> uVal

Converte um valor Harbour (array, hash ou tipo simples) para string JSON e vice-versa. O parâmetro lPretty ativa a saída indentada legível. Lida com estruturas aninhadas, datas e valores nil. 

local hData := { "name" => "John", "age" => 30 }
local cJson := FW_ValToJSON( hData, .T. )
// {
//   "name": "John",
//   "age": 30

local hParsed := FW_JsonDecode( cJson )

Converte um array 2D em uma tabela HTML com cabeçalhos e legenda opcionais. Retorna uma string completa de elemento <table> pronta para exibição web ou email.

FW_ProperCase()

FW_ProperCase( cText ) --> cString

Converte uma string para formato de título, capitalizando a primeira letra de cada palavra e convertendo o restante para minúsculas. Lida com casos especiais como prefixos Mc- e O'-.

FW_UTF8LEFT / FW_UTF8RIGHT / FW_UTF8SUBSTR()

FW_UTF8LEFT( cText, nCount ) --> cText
FW_UTF8RIGHT( cText, nCount ) --> cText
FW_UTF8SUBSTR( cText, nStart [, nCount ] ) --> cText

Versões seguras para UTF-8 de Left(), Right() e SubStr(). Estas funções contam caracteres (não bytes), tornando-as seguras para uso com texto UTF-8 multibyte, incluindo caracteres acentuados, ideogramas CJK e emoji. 

? FW_UTF8LEFT( "Café", 3 )               // "Caf"

Junta um array de strings em uma única string delimitada, similar ao implode() do PHP. Cada elemento é convertido para sua representação em string.

FW_ListAsArray()

Divide uma string delimitada em um array, o inverso de FW_ArrayAsList(). Remove espaços em branco de cada elemento.

nRandom()

Retorna um inteiro aleatório entre nMin e nMax, inclusive. Usa um gerador criptograficamente seguro quando disponível, recorrendo ao RNG padrão do Harbour.

Converte um valor numérico para sua representação hexadecimal em string. Preenchido com pelo menos dois dígitos hexadecimais.

Funções de Array e Dados

FW_DbfToArray()

FW_DbfToArray( cAlias, bFor, bWhile, nNext, nRecNo, lRest ) --> aData

Copia registros de uma área de trabalho DBF para um array 2D. Suporta filtragem de escopo via condições FOR/WHILE, NEXT n, número de registro ou escopo REST (compatível com SET FILTER). Retorna um array vazio se nenhum registro corresponder. 

use customer alias cust shared
local aData := FW_DbfToArray( "cust", { || Cust->State = "CA" } )
? "Clientes da Califórnia:", Len( aData )

FW_ArrayToDBF()

FW_ArrayToDBF( aData, cAlias, lOverWrite )

Escreve dados de um array 2D em um arquivo DBF. O parâmetro cAlias especifica o alias e arquivo de destino. Quando lOverWrite é .T., substitui os dados existentes; caso contrário, adiciona. 

local aData := { { "John", "Doe", 30 }, { "Jane", "Smith", 25 } }
FW_ArrayToDBF( aData, "newcust", .T. )

FW_DbfToHash()

FW_DbfToHash( cAlias ) --> hHash

Converte o registro atual de um DBF aberto para um hash/array associativo, onde os nomes dos campos se tornam chaves e os valores dos campos se tornam valores. Útil para serialização JSON e transferência de registros. 

use customer alias cust shared
go top
local hRec := FW_DbfToHash( "cust" )
? hRec[ "FIRST" ], hRec[ "LAST" ]

FW_HashToRec()

FW_HashToRec( hHash )

Escreve pares chave/valor de um hash no registro atual de um DBF aberto. Os nomes das chaves no hash devem corresponder aos nomes dos campos do DBF. Mapeamento hash-para-registro, o inverso de FW_DbfToHash(). 

local hData := { "FIRST" => "Alice", "LAST" => "Brown", "AGE" => 28 }
FW_HashToRec( hData )

FW_RecToJson()

FW_RecToJson( cAlias ) --> cJson

Converte o registro atual de um DBF para uma string JSON, combinando a funcionalidade de FW_DbfToHash() e FW_ValToJSON() em uma única chamada. 

use customer alias cust shared

// {"FIRST":"John","LAST":"Doe","AGE":30,"SALARY":50000.00}

ArrTranspose()

ArrTranspose( aArray ) --> aArray

Transpõe um array 2D, trocando linhas por colunas. Útil para converter dados orientados por linhas para o formato orientado por colunas (ex., para gráficos ou exibição de tabela cruzada). 

local aData := { { "Name", "John", "Jane" }, { "Age", 30, 25 } }

Calcula a soma de uma coluna específica em um array 2D. Trata valores não numéricos como zero.

FW_ArrGroupSum()

FW_ArrGroupSum( aArray, nGrpCol, nValCol ) --> aResult

Agrupa linhas em um array 2D por uma coluna chave e soma uma coluna de valor dentro de cada grupo. Retorna um array de pares { chave, soma }.

ASHUFLE()

ASHUFLE( aArray ) --> aArray

Embaralha aleatoriamente os elementos de um array in-place usando o algoritmo Fisher-Yates. Retorna a mesma referência de array, agora reordenada. 

local aCards := { "Ace", "King", "Queen", "Jack", "Ten" }

FW_AReverse()

FW_AReverse( aArray, nStart, nCount ) --> aArray

Inverte a ordem dos elementos em um subconjunto de um array. Quando nStart e nCount são omitidos, inverte o array inteiro. Retorna a mesma referência de array.

TC5Tooltip

Source: source/classes/c5tooltp.prg

Inherits from: TWindow

TC5Tooltip is a rich popup tooltip window with support for multi-line body text, header, footer, an optional left-side image, and custom border/background colors. It renders as a rounded window with drop shadow, auto-sizes to content, and includes a self-dismissing timer. The tooltip is designed for C5-style (CA-Visual Objects) themed tooltips.

Example: Rich Tooltip with Icon

#include "FiveWin.ch"

function Main()

   local oTip := TC5Tooltip():New( 100, 100, 250, 80, , , CLR_WHITE, CLR_YELLOW )

   oTip:cHeader := "Information"
   oTip:cBody   := "This is a rich tooltip with multi-line body text."
   oTip:cFoot   := "Tip: hover for details"
   oTip:cBmpLeft := "help.ico"
   oTip:lLineHeader := .T.
   oTip:Show()

return nil

Notes

  • The tooltip auto-dismisses after nTimer milliseconds (default 5000). Set lShowAgain to .F. to prevent re-show.
  • Uses CreateRoundRectRgn for rounded corners and registers with CS_DROPSHADOW class style for the drop-shadow effect.
  • Body text uses DT_WORDBREAK for automatic word wrapping within the available width.
  • All three sections (header, body, footer) are optional -- omit them by leaving the corresponding c* DATA empty.

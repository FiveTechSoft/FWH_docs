TC5Tooltip

Fonte: source/classes/c5tooltp.prg

Herda de: TWindow

TC5Tooltip é uma janela de tooltip (dica) popup rica, com suporte a texto de corpo em várias linhas, cabeçalho, rodapé, uma imagem opcional do lado esquerdo e cores personalizadas de borda/fundo. É renderizada como uma janela arredondada com sombra projetada, dimensiona-se automaticamente ao conteúdo e inclui um temporizador de auto-fechamento. O tooltip foi projetado para dicas com tema no estilo C5 (CA-Visual Objects).

Exemplo: Tooltip Rico com Ícone

#include "FiveWin.ch"

function Main()

   local oTip := TC5Tooltip():New( 100, 100, 250, 80, , , CLR_WHITE, CLR_YELLOW )

   oTip:cHeader := "Information"
   oTip:cBody   := "This is a rich tooltip with multi-line body text."
   oTip:cFoot   := "Tip: hover for details"
   oTip:cBmpLeft := "help.ico"
   oTip:lLineHeader := .T.
   oTip:Show()

return nil

Notas

  • O tooltip fecha-se automaticamente após nTimer milissegundos (padrão 5000). Defina lShowAgain como .F. para impedir que seja exibido novamente.
  • Usa CreateRoundRectRgn para os cantos arredondados e registra-se com o estilo de classe CS_DROPSHADOW para o efeito de sombra projetada.
  • O texto do corpo usa DT_WORDBREAK para a quebra automática de linha dentro da largura disponível.
  • Todas as três seções (cabeçalho, corpo, rodapé) são opcionais -- omita-as deixando o DATA c* correspondente vazio.

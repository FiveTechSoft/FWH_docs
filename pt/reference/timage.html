TImage

Fonte: source/classes/image.prg

Herda de: TControl

TImage é um controle de imagem estendido que exibe bitmaps, ícones e metafiles dentro de uma janela ou diálogo. Ele estende TBitmap com capacidades adicionais: carregamento a partir de arquivos, recursos, buffers de memória e URLs; salvamento de imagens em vários formatos (BMP, PNG, JPG, GIF, TIFF); rotação; e um indicador de progresso integrado. TImage é o controle recomendado para exibir imagens estáticas em aplicações FiveWin.

Principais Membros DATA

DATATipoDescrição
nProgressNumericPorcentagem de progresso (0-100). Quando definido, uma barra de progresso é sobreposta à imagem.
nFormatNumericIdentificador do formato de imagem usado ao salvar. Valores: 0=BMP, 1=JPG, 2=PNG, 3=GIF, 4=TIFF.
cBmpFileCharacterCaminho do arquivo de origem da imagem exibida.
cBmpResCharacterNome do recurso da imagem exibida (se carregada a partir de recursos).
hBitmapNumeric (Handle)Handle do bitmap atualmente exibido.
lStretchLogicalSe .T., a imagem é esticada para preencher as dimensões do controle.
lAdjustLogicalSe .T., o tamanho do controle é ajustado para coincidir com as dimensões da imagem.
nAngleNumericÂngulo de rotação atual em graus.

Métodos Principais

MétodoDescrição
New( nRow, nCol, nW, nH, cRes, cFile, oWnd, lNoBorder, lStretch, lAdjust, oFont, bClrGrad, ... )Cria um novo controle de imagem. Aceita um nome de recurso (cRes) ou um caminho de arquivo (cFile). Parâmetros adicionais controlam a borda, o comportamento de esticamento e a cor de gradiente.
Define( cRes, cFile, oWnd )Construtor alternativo para criar o controle após a instanciação.
LoadImage( cRes, cFile )Carrega uma imagem a partir de um nome de recurso ou caminho de arquivo, substituindo a imagem atual.
SaveImage( cFile, nFmt, nQuality )Salva a imagem atual em um arquivo. nFmt especifica o formato (0=BMP, 1=JPG, 2=PNG, 3=GIF, 4=TIFF). nQuality aplica-se a JPG (0-100).
LoadFromMemory( cBuf, nW, nH )Carrega uma imagem a partir de um buffer de memória contendo dados de bitmap brutos.
LoadFromURL( cUrl )Baixa e exibe uma imagem a partir de uma URL. Os dados da imagem são obtidos por meio de uma requisição HTTP interna.
RotateImage( nAngle )Rotaciona a imagem exibida pelo ângulo especificado em graus. Cria um novo bitmap rotacionado.
Progress( lOn )Mostra ou oculta um indicador de progresso sobreposto à imagem. Sem argumentos, alterna a visibilidade.
SetImage( hBmp )Substitui a imagem exibida por um handle de bitmap. O bitmap anterior não é destruído (chame DeleteObject() se necessário).
End()Destrói o controle e libera o handle do bitmap.

Comandos: @ ... IMAGE

@ nRow, nCol IMAGE oImg ;
   [ FILENAME cFile ] ;
   [ RESOURCE cRes ] ;
   [ SIZE nW, nH ] ;
   [ OF oWnd ] ;
   [ NOBORDER ] ;
   [ STRETCH ] ;
   [ ADJUST ] ;
   [ TRANSPARENT ]

Exemplo: Carregar Imagem de Arquivo e Salvar como PNG

#include "FiveWin.ch"

function Main()

   local oWnd, oImg

   DEFINE WINDOW oWnd TITLE "TImage Demo" SIZE 600, 500

   @ 20, 20 IMAGE oImg FILENAME "photo.bmp" ;
      SIZE 560, 400 OF oWnd STRETCH

   @ 440, 20 BUTTON "Salvar como PNG" SIZE 120, 30 OF oWnd ;
      ACTION oImg:SaveImage( "photo.png", 2 )   // 2 = PNG

   @ 440, 160 BUTTON "Rotacionar 90" SIZE 120, 30 OF oWnd ;
      ACTION oImg:RotateImage( 90 )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TImage herda de TControl, que herda de TWindow. Todos os métodos padrão de controle (Move(), Refresh(), SetFocus(), etc.) estão disponíveis.
  • A cláusula STRETCH dimensiona a imagem para preencher as dimensões do controle. Sem ela, a imagem é desenhada em seu tamanho natural.
  • A cláusula ADJUST redimensiona o controle para coincidir automaticamente com as dimensões da imagem carregada.
  • Os formatos de imagem suportados para carregamento dependem das bibliotecas GDI+ disponíveis no sistema. BMP, PNG, JPG, GIF e TIFF são universalmente suportados no Windows moderno.
  • SaveImage() usa GDI+ para a conversão de formato. O parâmetro nQuality (1-100) controla o nível de compressão JPG; valores mais altos produzem melhor qualidade, mas arquivos maiores.
  • LoadFromURL() realiza um download HTTP bloqueante. Para carregamento de imagens de rede sem bloqueio, considere usar TWebClient ou FW_CurlHttp() para baixar os dados primeiro e, em seguida, SetImage().
  • A sobreposição de progresso é útil ao carregar imagens grandes ou durante o processamento em lote. Chame oImg:Progress( .T. ) para ativar e, em seguida, defina oImg:nProgress para atualizar a porcentagem.

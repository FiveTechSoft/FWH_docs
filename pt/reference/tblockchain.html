TBlockChain

Fonte: source/internal/TBlockChain.prg

Classe independente

TBlockChain é uma implementação de blockchain em Harbour puro com hashing SHA-256, mineração proof-of-work e validação de blocos. Ela usa um hash CLASSDATA (aBlocks) para que todas as instâncias compartilhem a mesma cadeia, permitindo que aplicações multi-janela operem sobre os mesmos dados. A cadeia armazena um array de blocos com hash, cada um contendo um timestamp, uma carga de dados, um once (nonce) e o hash do bloco anterior. A mineração itera pelos valores de nonce até que o hash coincida com o prefixo de dificuldade.

Principais Membros DATA

DATATipoDescrição
aBlocksHash (CLASSDATA)Todos os blocos da cadeia, compartilhados entre todas as instâncias
cJsonCharacterRepresentação JSON de toda a cadeia
uDifficultyCharacterPrefixo de dificuldade de mineração (padrão: "0000")
nIterationsNumericTotal de iterações de mineração realizadas
cPrivateKeyCharacterChave privada para assinar blocos
cPublicKeyCharacterChave pública para verificação de assinatura
cSignatureCharacterString de assinatura do bloco

Métodos Principais

MétodoDescrição
New( cKey )Cria uma nova blockchain com bloco gênesis, indexada por cKey
AddNewBlock( uOnce, cData )Adiciona um novo bloco com nonce e string de dados opcionais
BlockToHash( nIdx, uOnce, cData )Calcula o hash para um determinado índice de bloco e dados
MineBlock( nIdx )Minera o bloco nIdx iterando os nonces até o hash coincidir com a dificuldade
IsValidHash( nIdx )Verifica se o bloco nIdx tem um hash válido que coincide com a dificuldade
IsValidBlock( nIdx, cHash )Valida o bloco nIdx contra o hash fornecido
CountBlocks()Retorna o número total de blocos na cadeia
UpdateAllBlocks()Recalcula os hashes de todos os blocos da cadeia

Exemplo: Criando uma Cadeia

#include "FiveWin.ch"

function Main()

   local oChain := TBlockChain():New( "myapp" )

   // Adiciona blocos com dados
   oChain:AddNewBlock( , "Genesis: Base record" )
   oChain:AddNewBlock( , "Block 2: Transaction data" )
   oChain:AddNewBlock( , "Block 3: Verification record" )

   // Minera o segundo bloco
   oChain:MineBlock( 2 )

   // Valida
   if oChain:IsValidHash( 2 )
      MsgInfo( "Block 2 is valid. Total blocks: " + ;
               Str( oChain:CountBlocks() ) )
   endif

   // Exporta a cadeia como JSON
   if ! Empty( oChain:cJson )
      MemoWrit( "chain.json", oChain:cJson )
   endif

   oChain:End()

return nil

Notas

  • O membro de dados aBlocks é marcado como CLASSDATA e armazenado como um hash indexado pelo parâmetro cKey passado a New(). Todas as instâncias que usam a mesma chave compartilham os mesmos dados da cadeia.
  • A dificuldade padrão (uDifficulty) é "0000", exigindo que os quatro primeiros dígitos hexadecimais do hash SHA-256 sejam zero. Aumente o comprimento da string (por exemplo, "000000") para tornar a mineração exponencialmente mais difícil.
  • MineBlock() incrementa o nonce e refaz o hash até que ele coincida com o prefixo de dificuldade. O número de iterações é acumulado em nIterations.

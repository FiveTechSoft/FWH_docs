TIcon

Fonte: source/classes/icon.prg

Herda de: TControl

TIcon é um controle para exibir ícones do Windows (.ico) a partir de arquivos ou recursos do programa. Ele suporta ações de clique, troca dinâmica de ícones, exibição de borda e liberação adequada de recursos. TIcon é comumente usado para indicadores de barra de ferramentas, ícones de status e elementos decorativos em janelas e diálogos.

Principais Membros DATA

DATATipoDescrição
hIconNumérico (Handle)Handle do ícone do Windows (HICON)
cIcoFileCaractereCaminho para o arquivo .ico
cResNameCaractereNome do recurso de ícone no executável

Métodos Principais

MétodoDescrição
New( nRow, nCol, cRes, cFile, lBorder, bClick, oWnd )Cria um controle de ícone. Forneça cRes (nome do recurso) ou cFile (caminho do arquivo .ico).
ReDefine( nId, cRes, cFile, bClick, lUpdate, oDlg )Redefine a partir de um template de recurso de diálogo
SetName( cResName )Troca para um recurso de ícone diferente pelo nome. Destrói o handle do ícone antigo.
SetFile( cIcoFile )Troca para um arquivo .ico diferente. Destrói o handle do ícone antigo.
End()Destrói o handle do ícone e chama o End() da superclasse

Comando ICON

@ nRow, nCol ICON oIcon OF oWnd FILE cFile

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oIcon

   DEFINE WINDOW oWnd TITLE "Icon Demo" SIZE 300, 200

   // Exibe um ícone a partir de um arquivo
   @ 10, 10 ICON oIcon OF oWnd FILE "myapp.ico"

   // Torna o ícone clicável
   oIcon:bLClicked := {|| MsgInfo( "Icon clicked!" ) }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O ícone é carregado a partir de um arquivo (cIcoFile via ExtractIcon()) ou de um recurso do programa (cResName via LoadIcon()). Um dos dois deve ser fornecido.
  • O tamanho padrão do ícone é 32x32 pixels, determinado pelas constantes da classe ICO_CHARPIX_H (14) e ICO_CHARPIX_W (8) multiplicadas pelas coordenadas de linha/coluna.
  • Use SetName() e SetFile() para alterar o ícone exibido em tempo de execução. Ambos os métodos destroem corretamente o handle do ícone anterior para evitar vazamentos de recursos.
  • Atribua um bloco de código a bLClicked para tratar eventos de clique no ícone.
  • O método Destroy() garante que o handle do ícone seja liberado via DestroyIcon() quando o controle é destruído.

TDDEMLClient / TDDEMLServer

Sources: source/classes/tddemlcl.prg, source/classes/tddemlsv.prg

Classes independentes

As classes da DDE Management Library (DDEML) fornecem uma interface de alto nível para o Dynamic Data Exchange do Windows usando a API DDEML. TDDEMLClient conecta-se a servidores DDE e executa comandos ou solicita dados; TDDEMLServer registra um servidor DDE que responde às solicitações dos clientes. Ambas as classes gerenciam conversas, registro de serviço/tópico e transferência de dados através do protocolo DDEML.

TDDEMLServer"] A -->|Execute cCmd| B A -->|Request cReq| B B -->|_Return cData| A B -->|bOnConnect / bOnRequest| B

TDDEMLClient

TDDEMLClient conecta-se a um servidor DDE existente, envia comandos e solicita dados.

Principais DATA

DATATipoDescrição
hInstNuméricoHandle da instância DDEML
hConvNuméricoHandle da conversa após conexão bem-sucedida
cServiceCaractereString com o nome do serviço
hServiceNuméricoHandle do serviço
cTopicCaractereString com o nome do tópico
hTopicNuméricoHandle do tópico
nTimeOutNuméricoTempo limite em milissegundos para operações DDE

Principais METHODs

MétodoDescrição
New()Cria o cliente DDE e inicializa a DDEML
Connect( cSvc, cTopic )Conecta-se a um servidor DDE no serviço/tópico informado
Disconnect()Encerra a conversa DDE
Execute( cCmd )Envia uma string de comando ao servidor para execução
Request( cReq )Solicita dados ao servidor; retorna a string de resultado
NetConnect( cSvr, cApp )Conecta-se a um servidor DDE em uma máquina remota da rede

TDDEMLServer

TDDEMLServer registra-se como um servidor DDE, aguardando conexões de clientes e respondendo a operações de execução/solicitação.

Principais DATA

DATATipoDescrição
hInstNuméricoHandle da instância DDEML
aClientsArrayArray de handles de conversa dos clientes conectados
bOnConnectBlockCodeblock avaliado quando um cliente se conecta
bOnRequestBlockCodeblock avaliado quando um cliente solicita dados; retorna o resultado
bOnDisconnectBlockCodeblock avaliado quando um cliente se desconecta
bOnExecuteBlockCodeblock avaliado quando um cliente envia um comando

Principais METHODs

MétodoDescrição
New()Cria o servidor DDE e inicializa a DDEML
Connect()Registra o nome do serviço do servidor e começa a aguardar conexões
ConnectConfirm( hConv )Aceita e confirma a conversa de um cliente
Disconnect( hConv )Encerra a conversa de um cliente
Execute( cCmd )Processa um comando enviado por um cliente
Request( cReq, cTopic )Trata uma solicitação de dados de um cliente; retorna a string de resultado
SetNetDDE( lOn )Ativa ou desativa o suporte a DDE em rede
_Return( cData )Retorna dados a uma solicitação do cliente; retorna o handle hData

Exemplo: Servidor e Cliente DDE

#include "FiveWin.ch"

// Lado servidor
function DdeServer()

   local oServer := TDDEMLServer():New()

   oServer:bOnConnect := { |hConv| ;
      QOut( "Client connected: " + Str( hConv ) ) }

   oServer:bOnRequest := { |cReq, cTopic| ;
      "Server received: " + cReq }

   oServer:bOnExecute := { |cCmd| ;
      QOut( "Executing: " + cCmd ) }

   oServer:Connect()

return oServer

// Lado cliente
function DdeClient()

   local oClient := TDDEMLClient():New()

   if oClient:Connect( "MyService", "MyTopic" )
      oClient:Execute( "[SAVE]" )
      ? oClient:Request( "GetData" )
      oClient:Disconnect()
   endif

   oClient:End()

return nil

Notas

  • Ambas as classes requerem a biblioteca DDEML do Windows (USER32.DLL). Inicialize com DdeInitialize() e libere os recursos com DdeUninitialize().
  • O método Request() no lado cliente retorna uma string de caracteres. No lado servidor, Request() deve retornar os dados a serem enviados, e _Return() os empacota em um handle de dados DDEML.
  • Use NetConnect() no cliente para conectar entre máquinas via Network DDE (requer que o Network DDE esteja ativado em ambos os sistemas).
  • Os blocos de callback do servidor recebem o handle da conversa como parâmetro, permitindo o gerenciamento de múltiplos clientes através do array aClients.

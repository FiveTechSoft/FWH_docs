TDde / TDdeClient / TDdeServer

Fontes: source/classes/dde.prg, source/classes/ddeclien.prg, source/classes/ddeserv.prg

Classes autônomas (não baseadas em controle)

Estas três classes implementam a comunicação Dynamic Data Exchange (DDE) entre aplicações Windows. TDde é um wrapper DDE simplificado, enquanto TDdeClient e TDdeServer fornecem uma implementação cliente-servidor mais completa, com suporte para Execute, Request, Poke e tratamento de confirmação (acknowledgment).

TDde (Simple DDE)

Principais Membros DATA

DATATipoDescrição
nServiceNumericÁtomo global para o nome do serviço
nTopicNumericÁtomo global para o nome do tópico
oWndServerObjectObjeto da janela do servidor após a conexão
lActiveLogical.T. quando a conversação DDE está ativa

Métodos Principais

MétodoDescrição
New( cService, cTopic, cItem, bAction, bEnd )Cria um objeto DDE com os átomos de serviço, tópico, item e os code blocks de ação/finalização
Activate()Difunde WM_DDE_INITIATE para todas as janelas de nível superior
Execute( cCommand )Envia um comando de execução DDE ao servidor
End()Encerra a conversação DDE e exclui os átomos

TDdeClient (Full Client)

Principais Membros DATA

DATATipoDescrição
oWndObjectObjeto da janela principal para o tratamento de mensagens
cServiceCharacterNome do serviço (convertido em átomo)
cTopicCharacterNome do tópico (convertido em átomo)
lActiveLogical.T. quando a conversação DDE está ativa
nAckNumericStatus do ACK: 0=OK, 1=Ocupado, 2=Não Suportado, 3=Timeout
cDataCharacterArmazena os dados recebidos de uma chamada Request

Métodos Principais

MétodoDescrição
New( oWnd, cService, cTopic )Cria o cliente; conecta bDDE_ACK e bDDE_DATA à janela
Activate( nWait )Envia WM_DDE_INITIATE; opcionalmente aguarda nWait segundos pelo ACK
Execute( cCommand, nWaitOK )Envia uma string de comando e opcionalmente aguarda a confirmação
Request( nType, cCommand, nWaitOK )Solicita dados ao servidor (CF_TEXT por padrão); resultado em ::cData
Poke( nType, cItem, cData, nWaitOK )Envia dados ao servidor identificados por cItem
End()Encerra a conversação e exclui os átomos

TDdeServer (Full Server)

Principais Membros DATA

DATATipoDescrição
oWndObjectObjeto da janela principal para o tratamento de mensagens
cServiceCharacterNome do serviço ao qual responder
cTopicCharacterNome do tópico ao qual responder
bInitBlockCode block executado na inicialização DDE (retorne .F. para rejeitar)
bExecuteBlockCode block executado em DDE_EXECUTE
bRequestBlockCode block executado em DDE_REQUEST (retorna uma string de dados)
bPokeBlockCode block executado em DDE_POKE

Métodos Principais

MétodoDescrição
New( oWnd, cService, cTopic, bInit, bExecute, bRequest, bPoke, bTerminate )Cria o servidor e conecta os tratadores de mensagens DDE à janela
End()Remove os tratadores de mensagens e marca como inativo

Exemplo: Cliente DDE

#include "FiveWin.ch"

function DDEClientDemo()

   local oClient := TDdeClient():New( oWnd, "MyService", "MyTopic" )

   // Ativa com timeout de 5 segundos
   if oClient:Activate( 5 )
      // Executa um comando
      oClient:Execute( "OPEN_FILE|C:\data.txt" )
      // Solicita dados
      oClient:Request( 1, "GET_STATUS" )
      MsgInfo( oClient:cData )
      oClient:End()
   endif

return nil

Exemplo: Servidor DDE

#include "FiveWin.ch"

function DDEServerDemo( oWnd )

   local oServer := TDdeServer():New( oWnd, "MyService", "MyTopic",;
      {|cSrv,cTop| MsgInfo( "Client connected: "+cSrv ), .T. },;
      {|cCmd|   MsgInfo( "Exec: " + cCmd ), .T. },;
      {|cItem|  If( cItem == "TIME", Time(), "" ) },;
      {|cItem,cData| MsgInfo( "Poked: "+cItem+"="+cData ), .T. } )

return nil

Notas

  • O DDE utiliza mensagens do Windows (WM_DDE_*) e átomos globais para a identificação de serviço/tópico.
  • A janela do servidor deve permanecer ativa para que a conversação continue ativa. A ativação do servidor ocorre automaticamente quando New() conecta os tratadores.
  • Os códigos de ACK são: 0=OK, 1=Ocupado, 2=Não Suportado, 3=Timeout. Verifique ::nAck após cada operação.
  • Para Request(), os dados retornados são armazenados em ::cData. Apenas CF_TEXT é suportado.

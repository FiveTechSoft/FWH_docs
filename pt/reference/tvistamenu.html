TVistaMenu

Fonte: source/classes/vistamnu.prg

Herda de: TControl

TVistaMenu fornece um painel de menu vertical moderno com renderização visual no estilo Vista. Cada item exibe texto e um ícone opcional, com cores de destaque configuráveis para a seleção sob o cursor. O controle é adequado para painéis de navegação e menus laterais.

Principais Membros DATA

DATATipoDescrição
aItemsArrayArray com as definições dos itens de menu
oOverNuméricoÍndice do item atualmente sob o mouse
nOptionFocusNuméricoÍndice do item atualmente em foco (navegação por teclado)
nClrPaneOverNuméricoCor de fundo do item sob o cursor
nClrTextOverNuméricoCor do texto do item sob o cursor
nClrBorderOverNuméricoCor da borda do item sob o cursor

Métodos Principais

MétodoDescrição
New( nRow, nCol, nW, nH, oWnd, oFont, oFont2 )Cria um novo controle de menu vista
Redefine( nId, oWnd, oFont, oFont2 )Redefine a partir de um recurso de diálogo
AddItem( cText, cImage, bAction )Adiciona um item de menu com texto, caminho da imagem e ação
InsertItem( n, cText, cImage, bAction )Insere um item de menu na posição especificada
DelItem( n )Exclui um item de menu na posição indicada
GoUp()Move o foco do teclado para o item anterior
GoDown()Move o foco do teclado para o próximo item

Exemplo: Menu Vertical com Ícones

#include "FiveWin.ch"

function Main()

   local oWnd, oVMenu

   DEFINE WINDOW oWnd TITLE "TVistaMenu Demo" SIZE 400, 400

   @ 10, 10 VISTAMENU oVMenu ;
      OF oWnd ;
      SIZE 180, 300 ;
      FONT oWnd:oFont

   oVMenu:AddItem( "&Dashboard",   "images/dash.bmp",  { || MsgInfo( "Dashboard" ) } )
   oVMenu:AddItem( "&Customers",  "images/cust.bmp",  { || MsgInfo( "Customers" ) } )
   oVMenu:AddItem( "&Orders",     "images/ord.bmp",   { || MsgInfo( "Orders" ) } )
   oVMenu:AddItem( "&Reports",    "images/rpt.bmp",   { || MsgInfo( "Reports" ) } )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O parâmetro cImage em AddItem() aceita um caminho de arquivo para um bitmap ou recurso de ícone. Se a imagem não puder ser carregada, o item exibe apenas o texto.
  • Use nClrPaneOver, nClrTextOver e nClrBorderOver para personalizar a aparência do destaque sob o cursor.
  • A navegação por teclado é tratada via GoUp() e GoDown(), normalmente mapeadas para as teclas de seta PARA CIMA e PARA BAIXO na janela pai.
  • O caractere & no texto do item define aceleradores de teclado (por exemplo, "&Dashboard" é ativado com Alt+D).
  • TVistaMenu herda de TControl, portanto suporta todo o posicionamento, dimensionamento e tratamento de eventos padrão de controles.

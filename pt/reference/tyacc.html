TYacc + TLex

Fontes: source/classes/tyacc.prg, source/classes/tlex.prg

Classes independentes (TYacc, TLex)

TYacc e TLex implementam um gerador de parser LALR(1) completo e um analisador léxico em Harbour puro. TYacc realiza a análise shift-reduce usando uma máquina de estados gerada, enquanto TLex trata a tokenização comparando a entrada com um conjunto de padrões de tokens. Juntos, eles permitem a análise de linguagens estruturadas, expressões e arquivos de configuração.

Métodos de TYacc

MétodoDescrição
New( oLex )Cria um parser associado ao objeto lexer fornecido
Parse( cText )Analisa o texto de entrada e retorna o valor do resultado
Shift( n )Empilha o próximo estado na pilha do parser
Reduce( n )Reduz pela regra gramatical de número n
Accept()Sinaliza a conclusão bem-sucedida da análise
ProdValue( n )Obtém o valor semântico de um símbolo de produção na posição n

TLex

TLex herda de TFile e fornece serviços de tokenização: lê o texto de entrada e retorna um fluxo de tokens com os valores semânticos associados.

DATATipoDescrição
aTokensArrayArray de strings de padrões de tokens
aIdsArrayArray de IDs numéricos de tokens correspondentes a cada padrão
cTokenCaractereTexto do token correspondente atual
uValueVariadoValor semântico associado ao token atual
MétodoDescrição
New( cFile, aTokens, aIds, cSeparators )Cria um lexer com padrões de tokens, IDs e caracteres separadores
nGetToken()Obtém o próximo token da entrada; retorna o ID do token
SetText( c )Define o texto de entrada a ser tokenizado
Add( cToken, nId )Adiciona um novo padrão de token com seu ID numérico

Exemplo: Parser de Expressão Simples

#include "FiveWin.ch"

function Main()

   local oLex, oYacc
   local aTokens := { "\d+", "\+", "\-", "\*", "/", "\(", "\)" }
   local aIds    := { 1, 2, 3, 4, 5, 6, 7 }  // NUM, PLUS, MINUS, MUL, DIV, LPAR, RPAR

   oLex := TLex():New( , aTokens, aIds, " " )
   oLex:SetText( "12 + 34 * ( 56 - 7 )" )

   oYacc := TYacc():New( oLex )
   oYacc:lDebug := .T.

   // Analisa a expressão
   oYacc:Parse( oLex:cToken )

return nil

Notas

  • TYacc usa um algoritmo de análise LALR(1) orientado a tabelas. As regras gramaticais e as transições de estado devem ser definidas por meio de subclasses ou configurando as tabelas de ações programaticamente.
  • Os code blocks bShift e bReduce permitem que ações semânticas personalizadas sejam executadas durante a análise.
  • TLex tenta os padrões de tokens em ordem; o primeiro padrão correspondente determina o token. Coloque os padrões mais específicos antes dos mais gerais.
  • ProdValue( n ) acessa os valores semânticos do lado direito de uma regra gramatical, onde n é a posição do símbolo (com base em 1) na produção.
  • Habilite lDebug para rastrear as transições de estado do parser e as decisões de shift/reduce ao depurar definições de gramática.

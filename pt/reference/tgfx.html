Funções de Renderização Gráfica

Fonte: source/function/imgtxtio.prg, source/winapi/gdipfwh.cpp

As funções de renderização gráfica do FiveWin fornecem as primitivas de desenho fundamentais para toda saída visual em janelas, diálogos, impressoras e documentos PDF. Elas abstraem as operações Windows GDI e GDI+, tratando da conversão de recursos, mesclagem alfa, preenchimentos com gradiente e transformações de coordenadas. A camada intermediária em imgtxtio.prg converte tipos de dados Harbour (cores, arrays, objetos) em handles GDI de baixo nível.

FW_Box() - Renderização de Formas

FW_Box( hDC, aRect, uPen, uBrush, aText, nShape )

Desenha retângulos, retângulos arredondados ou elipses com canetas e pincéis personalizáveis. Suporta preenchimentos com gradiente, mesclagem alfa e texto opcional dentro da forma.

ParâmetroTipoDescrição
hDCHandle / ObjetoHandle do contexto de dispositivo, objeto TWindow, TDialog ou TPrinter
aRectArray{ nTop, nLeft, nBottom, nRight } em pixels
uPenVáriosCor da caneta (numérica), array { color, nWidth }, objeto TPen ou handle
uBrushVáriosCor do pincel, array de gradiente, objeto TBrush ou handle de imagem
aTextArray / NilOpcional { cText, oFont, nClrText, cAlign } para desenhar dentro da forma
nShapeNuméricoConstante de forma: 0 = Retângulo, 1 = RoundRect, 2 = Elipse

FW_SayText() - Renderização de Texto

FW_SayText( oWnd, cText, aRect, cAlign, oFont, nClrText, nClrBack, lBorder, nAddStyle )

Desenha texto com controle total de alinhamento, quebra de linha e preenchimento de fundo opcional. Suporta renderização GDI+ para cores alfa e formatação RTF básica.

FlagSignificado
CCentralizar horizontalmente
LAlinhar à esquerda
RAlinhar à direita
TAlinhar ao topo verticalmente
BAlinhar à base verticalmente
WQuebra de linha

Os flags de alinhamento combinam livremente: "CR" = centro-direita, "TL" = topo-esquerda, "CB" = centro-base.

Variantes de Texto

  • FW_SayHollow( hDC, cText, aRect, cAlign, oFont, nClrText, nClrBack ) - Renderiza o texto como vazado (apenas contorno) usando GDI ou GDI+.
  • FW_SayTextHilite( oWnd, cText, aRect, cAlign, oFont, nClrText, nClrBack, aHilite, aFonts, aClrs ) - Renderiza o texto com palavras específicas destacadas em diferentes fontes e cores.
  • FW_SayTextSpread( hDC, cText, aRect, oFont, nClrText, nClrBack, nAngle ) - Distribui os caracteres uniformemente por toda a largura do retângulo de destino.

FW_DrawImage() - Renderização de Imagem

FW_DrawImage( oWnd, hBmp, aRect, lTransp, nResize, nAlpha, lGray, cAlign, aColorMap )

Desenha um bitmap em uma janela ou contexto de dispositivo com suporte a modos de redimensionamento, mesclagem alfa, escala de cinza e mapeamento de cores.

nResizeConstanteComportamento
0FIT_CENTERCentraliza no tamanho original, sem escalonamento
1FIT_WIDTHEscala para corresponder à largura do retângulo, mantendo a proporção
2FIT_HEIGHTEscala para corresponder à altura do retângulo, mantendo a proporção
3FIT_RECTEstica para preencher o retângulo de destino (pode distorcer)
4FIT_ORGLExibe no tamanho original em pixels, recortado se maior

Defina nAlpha com um valor entre 0 (invisível) e 255 (opaco) para renderização semitransparente. Defina lGray como .T. para conversão em escala de cinza. aColorMap é um array opcional de substituições de cor { nFrom, nTo }.

FW_DrawShadow()

FW_DrawShadow( hDC, aRect, nSize, nAlpha )

Desenha um efeito de sombra projetada ao redor de um retângulo. nSize controla a largura da sombra em pixels (tipicamente 4-12), e nAlpha (0-255) controla a opacidade. A sombra esmaece de opaca na borda até transparente para fora.

GradientFill()

GradientFill( hDC, nTop, nLeft, nBottom, nRight, aGradInfo, lVert )

Preenche uma região retangular com um gradiente de múltiplas paradas. aGradInfo é um array de paradas { nColor }; duas paradas produzem uma mesclagem simples, três ou mais criam transições em múltiplas etapas. Defina lVert como .T. para um gradiente vertical (de cima para baixo) ou .F. para horizontal (da esquerda para a direita).

Funções de Desenho Adicionais

  • FW_DrawShapes( oWnd, aShapes, aRect ) - Desenha em lote múltiplas formas (retângulo, retângulo arredondado, elipse, linha, polígono) a partir de um array de descritores { nShape, aRect, uPen, uBrush }.
  • FW_PieChart( oWnd, aRect, aValues, aColors ) - Desenha um gráfico de pizza/rosca a partir de arrays de dados numéricos e cores.
  • FillRectEx( hDC, aRect, nClr ) - Preenchimento de retângulo com cor sólida sem o custo de criação de um pincel.
  • RingGradientFill( hDC, nTop, nLeft, nBottom, nRight, aGradInfo, nAngle ) - Preenchimento com gradiente radial/anular para efeitos brilhantes e fundos personalizados.

Exemplo: Caixa com Texto e Sombra

#include "FiveWin.ch"

function DrawSample( hDC, oWnd )

   local aRect := { 50, 50, 350, 250 }
   local oFont := TFont():New( "Segoe UI", 0, -18 )

   // Desenha primeiro a sombra projetada
   FW_DrawShadow( hDC, aRect, 8, 80 )

   // Desenha um retângulo arredondado com preenchimento em gradiente
   FW_Box( hDC, aRect, CLR_BLUE, ;
           { CLR_WHITE, CLR_HBLUE }, ;
           { "Hello FWH Graphics", oFont, CLR_BLACK, "CR" }, ;
           1 ) // RoundRect

   oFont:End()

return nil

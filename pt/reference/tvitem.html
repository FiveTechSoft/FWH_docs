TVItem

Fonte: source/classes/vitem.prg

Classe independente (nao herda de TControl)

TVItem representa um item individual dentro de um painel TVMenu. Cada TVItem contem um caption de texto, bitmap/icone opcional, bloco de acao e propriedades de exibicao. Ao ser criado, um TVItem automaticamente se adiciona ao array aItems do TVMenu pai. TVItem suporta estilos de separador, titulos de grupo, menus popup, clausulas when e cores personalizadas.

Construtor New()

TVItem():New( oParent, cText, cBmp1, cBmp2, lGroup, nClrText, nClrPane,;
              nTextAlign, nImgAlign, nHeight, nLeft, separator, nWidth,;
              lUnder, nLeftImg, nClrPane2, lVGrad, bAction, oPopup,;
              nClrPSel, nClrTSel, lMirGrad, nSteps, cToolTip,;
              nColorSep, lIcon, nTop, bWhen, nClrPSel2 )
ParametroTipoDescricao
oParentTVMenuMenu pai (obrigatorio)
cTextCaractereTexto do caption
cBmp1Caractere/NumericoCaminho do bitmap, nome do recurso ou handle
lGroupLogicoE titulo de grupo (padrao: .f.)
nClrTextNumericoCor do texto personalizada
nClrPaneNumericoCor de fundo personalizada
separatorCaractere"LINE", "SEPARADOR", "INSET", "DOTDOT"
bActionBlocoBloco de acao do item
bWhenBlocoClausula when (retorna .t. para habilitar)

Metodos

MetodoRetornaDescricao
SetImage(cBmp, lIcon)nilDefinir imagem de arquivo, recurso ou handle numerico
SetBold(lBold)LogicoAlternar texto em negrito
SetDialog(cResName)nilAssociar recurso de dialogo
lOption()LogicoE o item selecionado atualmente

Exemplo

local oItem

oItem := TVItem():New( oMenu, "Documentos" )

oItem := TVItem():New( oMenu, "Inicio" )
oItem:SetImage( hMeuBitmap )

oItem := TVItem():New( oMenu, "" )
oItem:nSeparator := 2

TBrush

Fonte: source/classes/brush.prg

Classe independente (sem herança)

TBrush gerencia objetos de pincel (brush) GDI do Windows usados para preencher áreas com cores sólidas, padrões de hachura ou imagens bitmap. Um pincel é necessário sempre que você precisa pintar um fundo (painel de janela, face de controle, formas desenhadas manualmente). TBrush suporta pincéis de cor sólida, estilos de hachura predefinidos, padrões de gradiente (através de um bitmap interno), pincéis baseados em imagem a partir de arquivos ou recursos, e pincéis NULL que suprimem o preenchimento. Todo TBrush deve ser liberado com End() para evitar vazamentos de recursos GDI.

Principais Membros DATA

DATATipoDescrição
hBrushNumérico (Handle)Handle do pincel GDI do Windows. Criado por New().
hBitmapNumérico (Handle)Handle do bitmap que dá suporte aos pincéis baseados em imagem e gradiente. nil para pincéis sólidos e de hachura.
cStyleCaractereNome do estilo de hachura: "HORIZONTAL", "VERTICAL", "CROSS", "DIAGCROSS", "BORLAND", "BRICKS", "TILED", "TABS" ou "NULL".
nRGBColorNuméricoValor de cor RGB para pincéis sólidos e de hachura.
aGradArrayArray de definição de gradiente para pincéis de gradiente: { { nPercent, nRGB1, nRGB2 }, ... }.
cBmpFileCaractereCaminho do arquivo do bitmap usado para pincéis baseados em imagem.
cBmpResCaractereNome do recurso do bitmap usado para pincéis baseados em recurso.
nBmpHandleNuméricoHandle direto do bitmap usado para pincéis baseados em imagem (alternativa a arquivo/recurso).
cResizeModeCaractereModo de redimensionamento para pincéis de bitmap: "T" = lado a lado (tile), "S" = esticar (stretch).
lVerticalLógicoSe .T., o gradiente é vertical; se .F., horizontal.
CargoQualquerSlot de dados de uso geral do usuário.

Estilos de Pincel

EstiloDescrição
"HORIZONTAL"Linhas de hachura horizontais
"VERTICAL"Linhas de hachura verticais
"CROSS"Hachura cruzada (horizontal + vertical)
"DIAGCROSS"Hachura cruzada diagonal
"BORLAND"Padrão diagonal estilo Borland
"BRICKS"Padrão de parede de tijolos
"TILED"Bitmap repetido lado a lado pela área de preenchimento
"TABS"Padrão semelhante a abas
"NULL"Pincel NULL (sem preenchimento). Usado para impedir que o GDI preencha uma região.

Métodos Principais

MétodoDescrição
New( cStyle, nRGB, cBmpFile, cBmpRes, nBmpHandle, cResizeMode )Cria um pincel. Sem argumentos, cria um pincel sólido COLOR_BTNFACE. cStyle seleciona o estilo de hachura ou NULL. Quando cBmpFile ou cBmpRes é fornecido, cria um pincel baseado em imagem.
End()Exclui o pincel GDI (e o bitmap de suporte, se presente) via DeleteObject(). Deve ser chamado quando o pincel não for mais necessário.
Resized( x, y, nMode )Cria uma versão redimensionada de um pincel de bitmap. x e y são as novas dimensões; nMode é o modo de esticamento (padrão: COLORONCOLOR).
Cropped( oWnd, oRect )Recorta o bitmap do pincel para um retângulo especificado. Útil para criar pincéis específicos de região.
Resize( oWnd )Redimensiona o bitmap do pincel para corresponder às dimensões de uma janela. O pincel é recriado com o bitmap escalado.
Copy()Cria uma cópia independente do pincel com um novo handle GDI.
GdiBrush()Retorna o handle do pincel GDI (hBrush). Usado internamente ao selecionar pincéis em DCs.
SameAs( oB )Compara dois pincéis por seus atributos (estilo, cor, bitmap). Retorna .T. se forem equivalentes.
SetColor( nRGB )Altera a cor do pincel. Recria o handle do pincel GDI com a nova cor.
SetStyle( cStyle )Altera o estilo do pincel. Recria o handle do pincel GDI com o novo estilo.

Comandos: DEFINE BRUSH

DEFINE BRUSH oBrush ;
   [ COLOR nRGBColor ] ;
   [ STYLE cStyle ] ;
   [ FILE cBmpFile ] ;
   [ RESOURCE cBmpRes ] ;
   [ RESIZE nWidth, nHeight ]

Exemplo: Pincéis Sólido, Hachura, Gradiente e Bitmap

#include "FiveWin.ch"

function Main()

   local oWnd, oBrush1, oBrush2, oBrush3

   DEFINE WINDOW oWnd TITLE "TBrush Demo" SIZE 600, 400

   // Pincel azul sólido
   DEFINE BRUSH oBrush1 COLOR CLR_BLUE

   // Pincel vermelho de hachura cruzada
   DEFINE BRUSH oBrush2 COLOR CLR_RED STYLE "CROSS"

   // Pincel de gradiente (vertical)
   oBrush3 := TBrush():New( , , , , , , .T. )
   oBrush3:aGrad := { { 1.0, nRGB( 40, 80, 140 ), nRGB( 20, 40, 70 ) } }

   oWnd:oBrush := oBrush1

   ACTIVATE WINDOW oWnd CENTERED

   oBrush1:End()
   oBrush2:End()
   oBrush3:End()

return nil

Notas

  • TBrush é uma classe independente — não herda de TWindow ou TControl.
  • Todo TBrush deve ser acompanhado de uma chamada End(). Os pincéis GDI são um recurso limitado; vazá-los degrada o desempenho do sistema.
  • Para atribuir um pincel ao fundo de uma janela, use oWnd:SetBrush( oBrush ) ou oWnd:oBrush := oBrush. A janela assume a propriedade: defina oWnd:lTransparent := .F. para que o pincel tenha efeito.
  • Os pincéis de gradiente geram um bitmap temporário internamente. O array aGrad especifica segmentos: cada entrada é { nPercent, nColorTopLeft, nColorBottomRight }.
  • Os pincéis de bitmap podem ser repetidos lado a lado (padrão) ou esticados definindo cResizeMode como "S".
  • O estilo "NULL" cria um pincel oco que não preenche. Use-o quando precisar do contorno de uma forma sem preencher o interior.

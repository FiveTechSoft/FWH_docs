TMenu

Fonte: source/classes/menu.prg

Classe independente (não baseada em controle)

TMenu é o sistema de menus do FiveWin. Ele gerencia tanto menus popup quanto menus de sistema, suportando temas modernos do Office (2007/2010/2013/2015), aceleradores de teclado e mesclagem de menus MDI. Os menus podem ser criados programaticamente via comandos ou a partir de recursos de diálogo.

Principais Membros DATA

DATATipoDescrição
hMenuHandleHandle do menu do Windows (HMENU)
aItemsArrayArray de objetos TMenuItem neste menu
oWndObjectJanela proprietária do menu
lPopupLogical.T. para menus popup (contexto), .F. para a barra de menu de nível superior
lSysMenuLogical.T. se este for o menu de sistema
l2007LogicalTema visual Office 2007
l2010LogicalTema visual Office 2010
l2013LogicalTema visual Office 2013
l2015LogicalTema visual Office 2015
oAccTableObjectTabela de aceleradores de teclado
oFontObjectFonte usada para o texto do menu

Métodos Principais

MétodoDescrição
New( lPopup, oWnd, nClrT, nClrP, oFont, l2007, l2010, l2013, l2015 )Cria um novo menu; lPopup=.T. para menus de contexto
ReDefine( cRes, ... )Cria um menu a partir de uma definição de recurso de diálogo
NewSys( oWnd )Cria ou recupera o menu de sistema de uma janela

Command( nCmd )Executa a ação associada a um ID de comando

Comandos de Menu

Os menus são mais comumente definidos usando a sintaxe de comando MENU / MENUITEM: 

MENU oMenu
   MENUITEM "&File"
      MENU oSub
         MENUITEM "&Open"   ACTION oWnd:Open()
         MENUITEM "&Save"   ACTION oWnd:Save()
         SEPARATOR
         MENUITEM "E&xit"   ACTION oWnd:End()
      ENDMENU
   MENUITEM "&Help"
      MENU oSub
         MENUITEM "&About"  ACTION MsgInfo( "My App v1.0" )
      ENDMENU
ENDMENU

Exemplo: Menu Popup

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu

   DEFINE WINDOW oWnd TITLE "TMenu Demo"

   // Cria um menu de contexto popup
   MENU oMenu POPUP
      MENUITEM "Cut"    ACTION MsgInfo( "Cut" )
      MENUITEM "Copy"   ACTION MsgInfo( "Copy" )
      MENUITEM "Paste"  ACTION MsgInfo( "Paste" )
      SEPARATOR
      MENUITEM "Delete" ACTION MsgInfo( "Delete" )
   ENDMENU

   // Atribui à janela como popup no clique direito
   oWnd:bRClicked := { |nRow, nCol| oMenu:Activate( nRow, nCol, oWnd ) }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Os menus popup são posicionados nas coordenadas de tela usando Activate( nRow, nCol, oWnd ). Os valores de linha e coluna vêm do bloco de evento bRClicked.
  • Os flags l2007, l2010, l2013 e l2015 habilitam a renderização de menu com tema. Apenas um deve estar ativo por vez.
  • Use oAccTable para definir aceleradores de teclado (teclas de atalho) para os itens de menu.
  • Para aplicações MDI, AddMdi() trata da mesclagem automática de menus quando as janelas filhas são ativadas.

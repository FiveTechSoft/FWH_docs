TMeterEx

Fonte: source/classes/tmeterex.prg

Herda de: TControl

TMeterEx é um controle de barra de progresso estendido com renderização de gradiente duplo. Ele exibe uma barra de progresso preenchida sobre uma trilha de fundo, suportando definições de gradiente personalizadas, cantos arredondados, sobreposição opcional de bitmap, orientação vertical e direção de preenchimento invertida. O valor do medidor é gerenciado por meio de um bloco de código bSetGet.

Exemplo: Medidor de Valor Duplo

#include "FiveWin.ch"

function Main()

   local oWnd, oMeter, nVal := 50

   DEFINE WINDOW oWnd TITLE "TMeterEx Demo" SIZE 400, 150

   @ 30, 30 METEREX oMeter VAR nVal TOTAL 100 ;
      SIZE 340, 28 OF oWnd ;
      GRADIENTS { { 1, CLR_GRAY, CLR_WHITE } }, ;
                 { { 1, CLR_GREEN, CLR_YELLOW } } ;
      ROUND

   @ 80, 30 BUTTON "Update" SIZE 60, 25 ;
      ACTION ( nVal += 10, oMeter:Set( nVal ) )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Use a cláusula GRADIENTS para definir aGrad (fundo da trilha) e aGradMet (preenchimento do progresso). Cada um é um array de entradas { fração, corDe, corPara }.
  • A cláusula ROUND habilita cantos arredondados com raio padrão 3; passe nRound para um raio personalizado.
  • lVertical desenha o medidor de baixo para cima; lInverted inverte a direção do preenchimento (da direita para a esquerda ou de cima para baixo).
  • Uma sobreposição de bitmap pode ser especificada via cBitmap -- o bitmap é redimensionado e desenhado sobre a área preenchida.

TEnhMetaFile

Fonte: source/classes/tenhmeta.prg

Herda de: TControl

TEnhMetaFile exibe Enhanced Metafiles (EMF) do Windows dentro de janelas e diálogos FiveWin. É uma subclasse completa de TControl com suporte a dimensionamento, posicionamento, zoom para aproximar/afastar, efeitos de sombra e liberação de recursos. Os arquivos EMF contêm gráficos vetoriais que escalam sem perda de qualidade, tornando-os ideais para diagramas, logotipos e conteúdo de pré-visualização de impressão.

Principais Membros DATA

DATATipoDescrição
hMetaNumérico (Handle)Handle do enhanced metafile (HENHMETAFILE)
nWidthNuméricoLargura lógica do metafile
nHeightNuméricoAltura lógica do metafile
nXZoomNuméricoFator de zoom no eixo X (padrão 2)
nYZoomNuméricoFator de zoom no eixo Y (padrão 4)
nXorigNuméricoDeslocamento da origem de rolagem no eixo X
nYorigNuméricoDeslocamento da origem de rolagem no eixo Y
lZoomLógicoIndica se o modo de zoom está atualmente ativo
lShadowLógicoExibe o efeito de sombra ao redor do controle (padrão .T.)

Métodos Principais

MétodoDescrição
New( nTop, nLeft, nW, nH, cFile, oWnd )Cria um novo controle TEnhMetaFile que carrega e exibe um arquivo EMF
Redefine( nId, cFile, oWnd )Redefine a partir de um template de recurso de diálogo
SetFile( cFile )Carrega um novo arquivo EMF, substituindo o atual
ZoomIn()Aproxima o zoom no metafile (divide nWidth/nHeight por nXZoom/nYZoom)
ZoomOut()Afasta o zoom do metafile (restaura as dimensões originais)
SetZoomFactor( nX, nY )Altera o fator de zoom e ajusta o estado de zoom atual
SetOrg( nX, nY )Define a origem de rolagem para deslocar a visualização do metafile
End()Libera o handle do metafile e chama o End() da superclasse

Comando EMF

TEnhMetaFile pode ser criado diretamente usando a sintaxe do comando EMF:

@ nRow, nCol EMF oEmf FILE cFile OF oWnd SIZE nW, nH

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oEmf

   DEFINE WINDOW oWnd TITLE "Visualizador EMF" SIZE 600, 500

   @ 10, 10 EMF oEmf FILE "diagram.emf" OF oWnd SIZE 560, 400

   oEmf:lShadow := .T.

   // Botão para aproximar o zoom
   @ 420, 10 BUTTON "Zoom In" OF oWnd SIZE 80, 25 ;
      ACTION oEmf:ZoomIn()

   @ 420, 100 BUTTON "Zoom Out" OF oWnd SIZE 80, 25 ;
      ACTION oEmf:ZoomOut()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TEnhMetaFile manipula apenas Enhanced Metafiles (.emf). Para arquivos WMF com conversão automática, use TMetaFile.
  • Os métodos ZoomIn/ZoomOut alternam entre os estados com e sem zoom. O fator de zoom é definido via nXZoom (padrão 2) e nYZoom (padrão 4).
  • O efeito de sombra desenha uma borda com sombra estilo 3D usando um TPen. Desative definindo lShadow := .F..
  • Os metafiles são carregados do arquivo na primeira pintura. Use SetFile() para alterar o arquivo exibido em tempo de execução, o que libera o handle do metafile anterior.

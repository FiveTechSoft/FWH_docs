TTreeItem / TTVItem

Fonte: source/classes/treeitem.prg, source/classes/ttvitem.prg

TTreeItem implementa um nó de árvore em lista encadeada para widgets de árvore personalizados. Cada nó armazena um texto (prompt), nível, bitmaps, bloco de código de ação e dados de carga (cargo), e mantém ponteiros anterior/próximo/filho por meio de um objeto TTree associado. TTVItem encapsula um item TreeView nativo do Win32 (HTREEITEM) para uso com o controle de árvore padrão do Windows, fornecendo operações de inserção, expansão, edição, caixa de seleção e persistência.

TTreeItem — Nó de Árvore em Lista Encadeada

Principais Membros DATA

DATATipoDescrição
cPromptCharacterTexto de exibição do nó
oTreeObjectReferência ao objeto TTree filho (filhos), nil se for folha
lOpenedLogicalO nó está expandido (filhos visíveis)
nLevelNumericNível de indentação (0 = raiz)
hBmpOpenHandleHandle do bitmap para o estado expandido
hBmpCloseHandleHandle do bitmap para o estado recolhido
bActionCodeblockBloco de código executado quando o nó é ativado

Métodos Principais

MétodoDescrição
New( cPrompt, nLevel, hBmpOpen, hBmpClose, bAction, uCargo, uValue )Cria um novo nó de árvore no nível especificado
Open()Expande o nó para mostrar os filhos
Close()Recolhe o nó para ocultar os filhos
Toggle()Alterna entre o estado aberto e fechado
Add( cPrompt )Adiciona um nó irmão após este (inserção em lista encadeada)
AddChild( cPrompt, lFirst )Adiciona um nó filho (cria ou usa um TTree existente)
Delete( oRoot )Remove este nó da lista
MoveUp( oRoot )Move o nó para cima na lista
MoveDown( oRoot )Move o nó para baixo na lista
Sort( oRoot, lAsc, lRecurs )Ordena os irmãos pelo texto, opcionalmente de forma recursiva
Promote()Diminui o nível de indentação em um
Demote()Aumenta o nível de indentação em um
Parent( nParent )Localiza o ancestral em um determinado nível

Exemplo: Construção da Árvore

#include "FiveWin.ch"

function Main()

   local oTreeView, oRoot, oItem1, oItem2

   // exemplo de TTVItem com TreeView nativo
   DEFINE WINDOW oWnd TITLE "Tree Demo" SIZE 400, 300

   oTreeView = TTreeView():New( 10, 10, 380, 280, oWnd )

   oRoot = TTVItem():New( TVInsertItem( oTreeView:hWnd, "Root", 0, 0 ),;
                          oTreeView, NIL, "Root", 0, NIL )

   oItem1 = oRoot:Add( "Child 1", 1, "data1" )
   oItem2 = oRoot:Add( "Child 2", 1, "data2" )

   oItem1:Add( "Grandchild", 2, "deep" )

   oRoot:Expand()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TTreeItem foi projetado para uma árvore em lista encadeada personalizada, onde cada nó pode opcionalmente conter um TTree filho (via oTree). A lista encadeada é duplamente encadeada via oPrev/oNext.
  • TTVItem encapsula um handle de item de árvore nativo do Windows e delega todas as operações de exibição/estrutura ao common control via SendMessage.
  • O Save() / Load() de TTVItem serializam as propriedades cPrompt, nImage, Cargo e lBold.
  • GetCheck() / SetCheck() exigem que a árvore tenha o estilo TVS_CHECKBOXES.
  • O acessor/atribuição Value em TTreeItem delega a um bloco de código bSetGet, permitindo que o nó atue como uma variável SET/GET.

TFont

Fonte: source/classes/font.prg

Classe independente (sem herança)

TFont gerencia objetos de fonte GDI do Windows. Ela encapsula a criação, seleção e destruição de fontes lógicas, fornecendo uma interface de alto nível para nome da família tipográfica, tamanho, peso, estilo (negrito, itálico, sublinhado, tachado), conjunto de caracteres, inclinação (escapement) e orientação. TFont é usada por todo o framework FiveWin por cada controle e janela que renderiza texto. As fontes devem ser explicitamente liberadas com End() quando não forem mais necessárias, para evitar vazamentos de recursos GDI.

Principais Membros DATA

DATATipoDescrição
hFontNumérico (Handle)Handle da fonte GDI do Windows. Criado por New(), usado ao ativar em um DC.
cFaceNameCaractereNome da família tipográfica (ex.: "Arial", "Segoe UI", "Courier New").
nInpHeightNuméricoAltura nominal da fonte em unidades lógicas. Valores negativos indicam a altura do caractere (em-height); valores positivos indicam a altura da célula.
nInpWidthNuméricoLargura média do caractere. Zero deixa o Windows escolher uma largura proporcional.
nWeightNuméricoPeso da fonte: 0=padrão, 400=normal, 700=negrito. Definido automaticamente quando lBold é .T..
nEscapementNuméricoÂngulo da linha base do texto em décimos de grau (0 = horizontal, 900 = vertical para cima).
nOrientationNuméricoÂngulo de cada caractere em décimos de grau.
nCharSetNuméricoIdentificador do conjunto de caracteres: 0=ANSI, 1=DEFAULT, 204=RUSSIAN, 238=EASTEUROPE, 255=OEM.
lBoldLógicoSe .T., a fonte é criada com peso negrito (700).
lItalicLógicoSe .T., a fonte é criada com estilo itálico.
lUnderlineLógicoSe .T., a fonte é criada com sublinhado.
lStrikeOutLógicoSe .T., a fonte é criada com tachado.
lSubstituteLógicoSe .T., o nome da fonte é substituído através da tabela de substituição de fontes (FWFontSubst()).
lQualityLógicoSe .T., a qualidade suavizada (CLEARTYPE) é solicitada quando disponível.
CargoQualquerSlot de dados do usuário de uso geral.

Métodos Principais

MétodoDescrição
New( cFace, nW, nH, lBold, lItalic, lUnder, lStrike, nEscap, nOrient, nWeight, nCharSet, lQuality, lSubst )Cria um novo objeto de fonte. nH negativo especifica a altura do caractere; positivo especifica a altura da célula. nW igual a 0 seleciona largura proporcional. O handle da fonte hFont é criado imediatamente.
End()Libera o handle da fonte GDI (DeleteObject( ::hFont )) e libera o objeto. Deve ser chamado quando a fonte não for mais necessária.
Activate( hDC )Seleciona a fonte em um contexto de dispositivo. Retorna o handle da fonte anterior. Use DeActivate() para restaurar.
DeActivate( hDC, hOldFont )Restaura o handle da fonte anterior no contexto de dispositivo. Chame após Activate() para limpar.
Modify( nH, lBold, lItalic, lUnder, lStrike, cFace, nW, nEscap, nOrient, nWeight, nCharSet, lQuality )Altera os atributos da fonte e recria o handle da fonte GDI. O handle antigo é destruído.
Choose( nRGB )Abre o diálogo padrão de seleção de fontes do Windows. O parâmetro opcional nRGB predefine a cor. Retorna a cor RGB escolhida ou nil se cancelado. O objeto de fonte é atualizado com a seleção.
Clone()Cria uma cópia independente da fonte com um novo handle GDI. Útil quando a mesma fonte lógica é necessária por proprietários diferentes.
nSize()Retorna a altura da fonte como um valor negativo (convenção de altura do caractere).
Rotate( nDeg )Cria uma versão rotacionada da fonte. nDeg é o ângulo de rotação em graus (não em décimos). Define tanto a inclinação (escapement) quanto a orientação.
Release()Alias para End(). Libera o handle da fonte GDI.
lChanged()Retorna .T. se os atributos da fonte foram modificados desde a criação.

Comandos: DEFINE FONT

O FiveWin fornece um comando de pré-processador para criação conveniente de fontes:

DEFINE FONT oFont ;
   NAME cFaceName ;
   SIZE nWidth, nHeight ;
   [ BOLD ] [ ITALIC ] [ UNDERLINE ] [ STRIKEOUT ] ;
   [ CHARSET nCharSet ] ;
   [ ESCAPEMENT nDeg ] ;
   [ ORIENTATION nDeg ] ;
   [ WEIGHT nWeight ] ;
   [ QUALITY ]

A cláusula SIZE recebe largura e altura. Usar uma altura negativa (ex.: 0, -14) especifica a altura do caractere em pontos; positiva especifica a altura da célula em unidades lógicas. Largura igual a 0 deixa o Windows escolher proporcionalmente.

Exemplo: Criar Fonte e Usar em um Contexto de Dispositivo

#include "FiveWin.ch"

function Main()

   local oWnd, oFont, hOldFont, hDC

   DEFINE WINDOW oWnd TITLE "TFont Demo" SIZE 500, 300

   // Cria uma fonte negrito itálico
   DEFINE FONT oFont NAME "Arial" SIZE 0, -24 BOLD ITALIC

   ACTIVATE WINDOW oWnd CENTERED ;
      ON PAINT ( hDC := oWnd:GetDC(), ;
                 hOldFont := oFont:Activate( hDC ), ;
                 SayText( hDC, "Hello FiveWin!", 50, 50,, oFont:nInpHeight ), ;
                 oFont:DeActivate( hDC, hOldFont ), ;
                 oWnd:ReleaseDC( hDC ) )

   oFont:End()

return nil

Notas

  • TFont é uma classe independente — não herda de TWindow nem de TControl.
  • Cada objeto TFont deve ser acompanhado de uma chamada a End(). Handles de fonte GDI são um recurso limitado do sistema; deixar de liberá-los causa degradação visível em todos os aplicativos em execução.
  • O par Activate() / DeActivate() deve delimitar qualquer desenho personalizado que use a fonte. Nunca deixe uma fonte selecionada em um DC após concluir o desenho.
  • Use o método Choose() para permitir que os usuários escolham fontes interativamente. O diálogo de fontes mostra todas as fontes instaladas no sistema.
  • A substituição de fontes (controlada por lSubstitute) permite mapear nomes de fontes indisponíveis para alternativas através da tabela FWFontSubst().
  • Para usar uma fonte com um controle, atribua-a via a DATA oFont (ex.: oSay:oFont := oFont) em vez de ativá-la manualmente em um DC.
  • Para reconhecimento de alto DPI, especifique tamanhos de fonte em pontos usando valores de altura negativos (ex.: -14 para texto de 10 pontos).

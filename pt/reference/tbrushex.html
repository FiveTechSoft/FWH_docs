TBrushEx

Fonte: source/classes/brushex.prg

Classe independente (sem herança)

TBrushEx cria objetos de pincel GDI estendidos com padrões de gradiente. Ao contrário de um pincel padrão de cor sólida, TBrushEx gera um bitmap preenchido com um gradiente suave entre duas (ou quatro) cores e, em seguida, cria um pincel de padrão a partir desse bitmap. Isso permite que janelas e controles sejam pintados com fundos em gradiente sem código manual de desenho de gradiente.

Principais Membros DATA

DATATipoDescrição
hBrushNumérico (Handle)Handle do pincel GDI do Windows criado a partir do bitmap de gradiente
hBitmapNumérico (Handle)Handle do bitmap de gradiente que sustenta o pincel

Métodos Principais

MétodoDescrição
New( nWidth, nHeight, nColor, nColor2, lVGrad )Cria um pincel de gradiente de duas cores. lVGrad é .T. para gradiente vertical, .F. (padrão) para horizontal.
NewEx( nWidth, nHeight, nC1, nC2, nC3, nC4, lVGrad )Cria um pincel de gradiente de quatro cores com duas cores de canto adicionais para padrões mais complexos.
End()Exclui tanto o pincel quanto o bitmap, liberando todos os recursos GDI.

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oBrush

   DEFINE WINDOW oWnd TITLE "TBrushEx Demo" SIZE 400, 300

   // Cria um pincel de gradiente horizontal de vermelho para azul
   oBrush := TBrushEx():New( 400, 300, CLR_RED, CLR_BLUE, .F. )

   oWnd:SetBrush( oBrush )
   oWnd:lTransparent := .F.

   ACTIVATE WINDOW oWnd CENTERED

   oBrush:End()

return nil

Notas

  • As dimensões do bitmap (nWidth, nHeight) devem corresponder ou exceder a área a ser preenchida para evitar artefatos de mosaico (tiling).
  • Definir lVGrad como .T. cria um gradiente vertical (de cima para baixo); .F. cria horizontal (da esquerda para a direita).
  • End() deve ser chamado quando o pincel não for mais necessário para evitar vazamentos de recursos GDI. Tanto o handle do pincel quanto o handle do bitmap são excluídos internamente.
  • TBrushEx não deriva de nenhuma classe base do FiveWin; é um wrapper leve em torno das funções GDI CreaBitmapEx() e CreatePatternBrush().

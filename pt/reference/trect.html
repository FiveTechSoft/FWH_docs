TRect / TPoint

Fonte: source/classes/rect.prg

Classes independentes (sem herança)

TRect e TPoint são classes utilitárias para operações de geometria 2D. TRect representa um retângulo definido pelas suas bordas superior, esquerda, inferior e direita. TPoint representa um único ponto com coordenadas de linha e coluna (ou Y e X). Ambas as classes suportam operadores aritméticos e transformações geométricas comumente necessárias em código de layout de interface e desenho.

TRect

Principais Membros DATA

DATATipoDescrição
aRectArrayDados principais: { nTop, nLeft, nBottom, nRight }
nTopNumericBorda superior (acessor para aRect[1])
nLeftNumericBorda esquerda (acessor para aRect[2])
nBottomNumericBorda inferior (acessor para aRect[3])
nRightNumericBorda direita (acessor para aRect[4])
nWidthNumericLargura calculada
nHeightNumericAltura calculada
cRectCharacterEstrutura RECT binária (8 bytes) para chamadas à API Win32
CenterPtArrayPonto central como { nTop, nLeft }
lWinRectLogicalRetângulo no estilo Windows (direita/inferior exclusivas). Padrão .T.

Métodos TRect

MétodoDescrição
New( nTop, nLeft, nBottom, nRight [, nWidth, nHeight] )Cria um novo retângulo. Aceita array, string binária ou quatro coordenadas. nWidth/nHeight substituem nRight/nBottom.
MoveBy( nRows, nCols )Desloca todo o retângulo pelos deltas informados
MoveTo( nNewTop, nNewLeft )Move o retângulo de modo que seu canto superior esquerdo fique na posição informada
Contains( aPoint )Verifica se um ponto { row, col } ou outro retângulo está dentro deste
Resize( nRatio [, aPoint] )Redimensiona por uma proporção relativa ao centro (ou ao ponto de ancoragem especificado)
FitInside( oRect, nType, cAlign )Encaixa este retângulo dentro de outro, opcionalmente ampliando. nType: 1=exato, 2=preencher externo, 3=encaixar dentro.
AsSquare( lOuter, cAlign )Ajusta para formar um quadrado expandindo ou contraindo a maior dimensão
Modify( ... )Retorna um novo TRect com bordas modificadas; suporta alterações absolutas, fracionárias e relativas

Operadores TRect

OperadorDescrição
==Comparação de igualdade (todas as quatro bordas coincidem)
+, -, *, /, %Aritmética em todas as quatro bordas por um valor ou array
+=, -=, *=, /=, %=Operadores aritméticos no próprio objeto
[]Acesso indexado: oRect[1] = nTop, oRect[2] = nLeft, etc.

TPoint

Principais Membros DATA de TPoint

DATATipoDescrição
nRowNumericCoordenada de linha (Y)
nColNumericCoordenada de coluna (X)
XNumericAlias para nCol
YNumericAlias para nRow
aPtArray{ nRow, nCol }

Métodos TPoint

MétodoDescrição
New( nRow, nCol )Cria a partir de linha/coluna; também aceita um array {row,col}
NewXY( x, y )Cria a partir de coordenadas X/Y (armazenadas como nCol/nRow)
Rect( nRadius [, yRadius] )Retorna um TRect centrado neste ponto com o raio informado
Distance( oPt )Distância euclidiana a outro ponto
Plus( r, c [, lNew] )Adiciona deltas e retorna um novo ponto (ou modifica Self se lNew for .F.)

Operadores TPoint

OperadorDescrição
+Cria um novo ponto deslocado pelo delta informado
+=Deslocamento no próprio objeto
-Retorna a distância entre dois pontos

Exemplo

#include "FiveWin.ch"

function Main()

   local oRect, oPt, oInner

   // Cria um retângulo 200x100 na posição (10,10)
   oRect := TRect():New( 10, 10, 110, 210 )

   // Testa se um ponto está dentro
   oPt := TPoint():New( 50, 100 )
   if oRect:Contains( oPt:aPt )
      MsgInfo( "Point is inside the rectangle" )
   endif

   // Cria um quadrado e o encaixa dentro do retângulo
   oInner := TRect():New( 0, 0, 100, 100 )
   oInner:FitInside( oRect, 3, "C" )  // Encaixar dentro, centrado

   // Move o retângulo 10 pixels em cada direção
   oRect:MoveBy( 10, 10 )

return nil

Notas

  • TRect pode ser construído a partir de um array, de uma estrutura RECT binária ou de quatro coordenadas numéricas.
  • O flag lWinRect controla se os cálculos de largura/altura usam a convenção do Windows (bordas inferior/direita exclusivas, padrão .T.) ou a convenção inclusiva (.F.).
  • O operador - de TPoint retorna a distância euclidiana (um valor numérico), não um novo ponto.
  • Ambas as classes fornecem sobrecarga de OPERATOR para sintaxe natural de aritmética e indexação.
  • As funções auxiliares PointXY( x, y ) e PointRowCol( r, c ) criam objetos TPoint de forma inline.

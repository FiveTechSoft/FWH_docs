TTitle / TTitleText / TTitleImg

Fonte: source/classes/ttitle.prg

Herda de: TControl

TTitle é um controle decorativo de título / cabeçalho que combina fundos com gradiente, elementos de texto e imagens bitmap em um único cabeçalho visual. Ele suporta sombras, bordas, cantos arredondados, animação de imagem, mesclagem alfa (alpha blending) e efeitos de reflexo (espelho). Texto e imagens podem ser adicionados independentemente via AddText() e LoadBitmaps().

Principais Membros DATA

DATATipoDescrição
aImgsArrayArray de descritores de imagem com 10 posições: row, col, hBitmap, hPalette, hasAlpha, alphaLevel, reflex, transparent, anima, action
aTextArrayArray de descritores de texto: row, col, text, justify, brush, pen, shadow, font, textColor
aGrdBaseArrayArray de gradiente para a área base (cabeçalho)
aGrdBackArrayArray de gradiente para o fundo
hBackBrushHandleHandle interno do pincel (brush) do padrão de fundo
nShadowNumericDireção da sombra: TOPLEFT, TOPRIGHT, BOTTOMLEFT, BOTTOMRIGHT
nShadowIntensityNumericPorcentagem de opacidade da sombra (0-100)
nShadowSizeNumericDistância de espalhamento da sombra em pixels
lBaseLogicalPintar a área base no estilo dock do Mac
lBorderLogicalDesenhar uma borda ao redor do cabeçalho
lRoundLogicalUsar cantos arredondados
lVerticalLogicalAplicar o gradiente verticalmente (padrão: true)
nClrLine1NumericCor da linha 1 da borda
nClrLine2NumericCor da linha 2 da borda

Métodos Principais

MétodoDescrição
New( oWnd, nRow, nCol, nW, nH, cText, lBorder, lRound, lBase, lVertical, ... )Criar um cabeçalho de título decorativo com gradiente, sombra e texto
AddText( nRow, nCol, cText, lBold, lStrike, lShadow, cAlign, oFont, nClr )Adicionar um elemento de texto ao cabeçalho nas coordenadas indicadas
LoadBitmaps( cFile, nRow, nCol, nW, nH, nAlpha, lReflex, lTransparent, lAnima, bAction, nAt )Carregar um bitmap no array de imagens na posição especificada
AnimaImage()Animar imagens (efeito de deslizamento para cima/rolagem para cabeçalhos com múltiplas imagens)
ChangeImg( cBitmap, nImg )Substituir o bitmap em um índice de imagem específico
LButtonDown( nRow, nCol, nFlags )Tratar o clique do mouse; disparar qualquer ação associada à imagem sob o cursor

Exemplo: Cabeçalho com Gradiente, Logo e Sombra

#include "FiveWin.ch"

function Main()

   local oWnd, oTitle

   DEFINE WINDOW oWnd TITLE "Main" SIZE 600, 400

   oTitle = TTitle():New( oWnd, 0, 0, 600, 60, "My Application",;
                          .T., .F., .F., .T.,,, "BOTTOMRIGHT", 8 )

   oTitle:AddText( 15, 40, "My Application", .T., .F., .T., "LEFT",;
                   oFont(), CLR_WHITE )

   oTitle:LoadBitmaps( "logo.png", 10, 540, 40, 40,,,, {|| MsgInfo( "Logo clicked" ) } )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O cabeçalho é composto por até três camadas visuais: gradiente de fundo (aGrdBack), gradiente base (aGrdBase, efeito opcional semelhante a um dock) e texto e imagens sobrepostos.
  • A sombra é implementada deslocando uma cópia semitransparente do conteúdo do cabeçalho. A constante de direção nShadow controla em qual quadrante a sombra incide.
  • As imagens armazenadas em aImgs podem ter níveis alfa individuais, efeitos de reflexo (espelho) e transições animadas.
  • Quando lBase é true, uma faixa de gradiente mais escura adicional é pintada na parte inferior do cabeçalho (semelhante ao Dock do macOS).
  • As bordas são desenhadas com duas cores (nClrLine1 e nClrLine2) para criar um efeito de chanfro 3D.

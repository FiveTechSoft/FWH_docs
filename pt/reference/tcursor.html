TCursor

Fonte: source/classes/cursor.prg

Classe independente (sem herança)

TCursor carrega, cria e gerencia recursos de cursor do mouse. Suporta cursores predefinidos do sistema Windows, cursores personalizados a partir de arquivos .cur/.ico, cursores de recursos do programa e cursores criados programaticamente a partir de imagens bitmap. TCursor é usado pelo framework FiveWin para funções de gerenciamento de cursor como CursorHand(), CursorArrow(), CursorWait(), etc.

Principais Membros DATA

DATATipoDescrição
hCursorNumérico (Handle)Handle do cursor do Windows
lPredefLógicoIndica se o cursor é um cursor predefinido do sistema (não destruído no End)
SourceCaractereString de descrição da origem (ex.: "PREDEF:HAND" ou caminho do arquivo)

Tipos de Cursor Predefinidos

NomeDescrição
ARROWPonteiro de seta padrão (IDC_ARROW)
IBEAMCursor de texto em I (IDC_IBEAM)
WAITCursor de ampulheta/espera (IDC_WAIT)
CROSSCursor de mira (IDC_CROSS)
UPARROWCursor de seta vertical (IDC_UPARROW)
SIZECursor de redimensionar/mover de quatro pontas (IDC_SIZEALL)
HANDPonteiro de mão (link clicável)
STOPCursor de parar/entrada proibida
DRAGCursor de arrastar
SEARCHCursor de pesquisa/zoom
SIZENWSERedimensionamento diagonal NO-SE
SIZENESWRedimensionamento diagonal NE-SO
SIZEWERedimensionamento horizontal (oeste-leste)
SIZENSRedimensionamento vertical (norte-sul)

Métodos Principais

MétodoDescrição
New( cResOrFile, cPredef )Cria um cursor a partir de um nome de recurso, arquivo .cur/.ico ou tipo predefinido
NewBmp( oBitmap, nHotRow, nHotCol )Cria um cursor a partir de um objeto TBitmap ou TBtnBmp com coordenadas de ponto de ativação
NewFromBitmap( oBitmap, nHotRow, nHotCol, hMaskBitmap )Cria um cursor a partir de um bitmap com um bitmap de máscara separado
SetSource( cSource, cPredef )Define ou altera a origem do cursor e recarrega o handle do cursor
End()Libera o handle do cursor (cursores predefinidos não são destruídos)

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oCursor

   DEFINE WINDOW oWnd TITLE "TCursor Demo" SIZE 400, 300

   // Carrega um cursor de mão a partir de um arquivo
   oCursor := TCursor():New( "hand.cur" )
   // Alternativa: cursor de mão predefinido
   // oCursor := TCursor():New( , "HAND" )

   oWnd:SetCursor( oCursor:hCursor )

   ACTIVATE WINDOW oWnd CENTERED

   oCursor:End()

return nil

Notas

  • Cursores predefinidos (ARROW, IBEAM, WAIT, etc.) são carregados a partir dos recursos do sistema Windows e não devem ser destruídos. TCursor rastreia isso por meio da flag lPredef e ignora DestroyCursor() para cursores do sistema.
  • Use Source (protegido) para ler de volta a descrição de origem do cursor atualmente carregado.
  • O método NewBmp() cria um cursor a partir de qualquer objeto TBitmap, tratando automaticamente a paleta e a transparência.
  • Cursores de recursos (compilados no .exe) são carregados via LoadCursor( GetResources(), cResName ).

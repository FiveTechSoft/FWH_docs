GDI+ Classes

Fonte: source/classes/tgdiplus.prg

Classes independentes: Graphics, Pen, Brush, GDIBmp, Path, Region

O FiveWin fornece um conjunto abrangente de classes wrapper do GDI+ para renderização 2D de alta qualidade com anti-aliasing, transparência alfa, pincéis de gradiente, desenho baseado em caminhos (paths) e processamento de imagens. Essas classes encapsulam a API flat do GDI+ do Windows e não requerem componentes ActiveX externos. O GDI+ é inicializado automaticamente quando a primeira classe é instanciada.

Classe Graphics

A superfície de desenho principal. Todas as operações de desenho começam com um objeto Graphics.

MétodoDescrição
New( hDC [, lNoHighQuality] )Cria a partir de um handle de contexto de dispositivo
NewWnd( hWnd [, lNoHighQuality] )Cria para desenho em janela
NewFromWnd( oWnd [, lNoHighQuality] )Cria a partir de um objeto TWindow
NewImg( hImg [, lNoHighQuality] )Cria para renderização de imagem fora da tela
SetHighQuality()Ativa a renderização com anti-aliasing
SetNormalQuality()Desativa o anti-aliasing para ganhar velocidade
DrawLine( oPen, nLeft, nTop, nRight, nBottom )Desenha uma linha
DrawRect( oPen, oBrush, nLeft, nTop, nWidth, nHeight )Desenha um retângulo
DrawEllipse( oPen, oBrush, nLeft, nTop, nWidth, nHeight )Desenha uma elipse
DrawArc( oPen, nLeft, nTop, nW, nH, nStartAngle, nSweepAngle )Desenha um arco
DrawRoundRect( oPen, oBrush, nLeft, nTop, nW, nH, nRadius )Desenha um retângulo arredondado
DrawPath( oPen, oPath )Desenha o contorno de um caminho gráfico
FillPath( oBrush, oPath )Preenche um caminho gráfico
DrawImage( oImage, nTop, nLeft [, nW, nH] )Desenha uma imagem
Clear( nTrans, nRed, nGreen, nBlue )Limpa a superfície com uma cor ARGB
Translate( nRow, nCol )Translada o sistema de coordenadas
Rotate( nAngle )Rotaciona o sistema de coordenadas
Scale( nX, nY )Escala o sistema de coordenadas
Destroy()Libera o objeto graphics do GDI+

Classe Pen do GDI+

Caneta (pen) do GDI+ para desenhar linhas com cor, largura e estilo.

MétodoDescrição
New( nAlpha, nR, nG, nB, nSize )Cria uma caneta com cor ARGB e tamanho. Alfa 0..255.
SetColor( nAlpha, nR, nG, nB )Altera a cor da caneta
SetSize( nSize )Altera a largura da caneta
SetStyle( nStyle )Define o estilo da caneta (ex.: GDI_PEN_ROUND para extremidades arredondadas)
SetLineJoin( nJoin )Define o estilo de junção de linhas
Destroy()Libera a caneta do GDI+

Classe Brush do GDI+

Pincel (brush) do GDI+ para preencher formas com cores sólidas ou gradientes.

MétodoDescrição
NewSolidBrush( nAlpha, nR, nG, nB )Cria um pincel ARGB sólido
NewGradientBrush( nTop, nLeft, nW, nH, nType, nA1, nR1, nG1, nB1, nA2, nR2, nG2, nB2 )Cria um pincel de gradiente linear. nType: 0=horizontal, 1=vertical, 2=diagonal-direita, 3=diagonal-esquerda.
AngleGradientBrush( ... nAngle, lScala )Cria um gradiente em um ângulo arbitrário
Destroy()Libera o pincel do GDI+

Classe GDIBmp

Bitmap do GDI+ para carregar, manipular e salvar imagens.

MétodoDescrição
New( cFile )Carrega uma imagem de arquivo (BMP, JPG, GIF, TIF, PNG, EMF, WMF, ICO)
Resize( nWidth, nHeight )Redimensiona a imagem (mantém a proporção se uma dimensão for omitida)
Rotate( nRotate )Rotaciona/inverte a imagem
ImageRotate( nDegrees )Rotaciona em um ângulo arbitrário
Save( cFile [, nQuality] )Salva em arquivo. nQuality aplica-se a JPEG (0-100).
GetWidth() / GetHeight()Retorna as dimensões da imagem
CreateThumbnail( nW, nH )Cria uma miniatura GDIBmp
Conver24to32Alpha()Converte de 24 bits para 32 bits com transparência alfa
GetGDIHbitmap()Extrai um handle de bitmap GDI para uso com funções GDI
End() / Destroy()Libera a imagem do GDI+

Classe Path

Caminho gráfico (path) do GDI+ para construção de formas complexas.

MétodoDescrição
New()Cria um caminho vazio
AddLine( nLeft, nTop, nRight, nBottom )Adiciona um segmento de linha
AddArc( nLeft, nTop, nW, nH, nStartAngle, nSweepAngle )Adiciona um arco
AddRectangle( nLeft, nTop, nRight, nBottom )Adiciona um retângulo
AddRoundRect( x, y, nW, nH, nRadius )Adiciona um retângulo arredondado
AddElipse( nTop, nLeft, nW, nH )Adiciona uma elipse
AddString( cText, cFont, nStyle, eMSize, ... )Adiciona texto como contorno de um caminho
StarFigure() / CloseFigure()Inicia/fecha uma figura dentro do caminho
Translate() / Rotate() / Scale()Transforma o caminho
Destroy()Libera o caminho

Classe Region

MétodoDescrição

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oGraphics, oPen, oBrush

   DEFINE WINDOW oWnd TITLE "GDI+ Demo" SIZE 500, 400

   oWnd:bPainted = {| hDC |
      local oGraphics := Graphics():New( hDC )
      local oPen      := Pen():New( 255, 255, 0, 0, 3 )   // Caneta vermelha, 3px
      local oBrush    := Brush():NewSolidBrush( 128, 0, 0, 255 ) // Azul semitransparente

      // Desenha o contorno de uma elipse vermelha
      oGraphics:DrawEllipse( oPen, oBrush, 50, 50, 200, 150 )

      // O preenchimento azul semitransparente é aplicado automaticamente por DrawEllipse

      oPen:Destroy()
      oBrush:Destroy()
      oGraphics:Destroy()
      }

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O GDI+ é inicializado automaticamente por meio de uma init procedure GdiPlusStart() e encerrado por meio de uma exit procedure GdiPlusEnd(). Nenhuma inicialização/encerramento manual é necessário.
  • Todas as classes do GDI+ são independentes, no sentido de que não derivam de TControl nem de qualquer outra classe base do FiveWin.
  • O GDIBmp suporta o carregamento a partir de arquivo, de recurso (PNG ou bitmap) e de string em memória. Formatos de entrada suportados: BMP, JPG, GIF, TIF, PNG, EMF, WMF, ICO. Formatos de saída: BMP, JPG, GIF, TIF, PNG.
  • A classe Graphics define a unidade de página como pixels por padrão e ativa a renderização de alta qualidade (com anti-aliasing), a menos que lNoHighQuality seja .T.

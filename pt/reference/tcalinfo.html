TCalInfo

Fonte: source/classes/calinfo.prg

Herda de: TControl

TCalInfo representa um compromisso ou item de calendário exibido dentro de um controle de calendário TCalex. Gerencia a aparência visual, o intervalo temporal e o estado de seleção de entradas individuais do calendário, suportando itens com cores em gradiente nas visualizações de dia, semana e mês.

Principais Membros DATA

DATATipoDescrição
nStart / nEndNuméricoDeslocamentos de hora inicial e final dentro do dia (em minutos)
dStart / dEndDataDatas inicial e final para compromissos de vários dias
cTextCaractereTexto exibido para o item de compromisso
cSubjectCaractereAssunto ou título do compromisso
aGradColorArrayArray de cores em gradiente para o fundo do item
aGradColorND / aGradColorAp / aGradColorBTArrayCores em gradiente para os estados não exibido, compromisso e horário comercial
lSelectedLógicoEstado de seleção do compromisso
oCalexObjetoControle de calendário TCalex pai

Métodos Principais

MétodoDescrição
New( oCalex, nStart, nEnd, dStart, dEnd, cText, cSubject )Cria um novo item de calendário com limites temporais e texto de exibição
BuildDates( nTop, nLeft, nW, nH )Calcula o retângulo visual do item dentro da grade do calendário
Move()Reposiciona o item em resposta à rolagem ou redimensionamento do calendário
Paint()Desenha o item na visualização padrão do calendário
PaintOnMonth()Desenha o item dentro da grade de visão geral do mês
PaintOnWeek()Desenha o item dentro da visualização de semana/dia
Show() / Hide()Exibe ou oculta o item de calendário

Exemplo: Criar Compromisso

#include "FiveWin.ch"

function Main()

   local oCalex, oAppt

   DEFINE WINDOW oWnd TITLE "Calendar Demo" SIZE 800, 600

   oCalex := TCalex():New( oWnd )

   oAppt := TCalInfo():New( oCalex, ;
      540, 600, ;              // 9:00 às 10:00
      dDate(), dDate(), ;      // Apenas hoje
      "Team Meeting", "Weekly sync" )

   oAppt:aGradColor := { CLR_BLUE, CLR_CYAN }
   oAppt:Show()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Os valores de hora (nStart, nEnd) são expressos em minutos a partir da meia-noite (0 a 1439).
  • Compromissos de vários dias usam os valores de data dStart e dEnd abrangendo a duração do evento.
  • Os arrays de gradiente contêm dois valores numéricos de cor para os pontos de gradiente inicial e final.
  • O controle TCalex pai despacha as chamadas de desenho para o método de visualização apropriado (PaintOnMonth, PaintOnWeek ou Paint) com base no modo de exibição atual.

TSymbol / TSymTable

Fontes: source/classes/tsymbol.prg, source/classes/tsymtabl.prg

Classes independentes

TSymbol e TSymTable fornecem introspecção em tempo de execução da tabela de símbolos do Harbour. TSymbol encapsula um único handle de símbolo (hSymbol) e expõe seu nome e visibilidade. TSymTable fornece a iteração sobre toda a tabela de símbolos, retornando objetos TSymbol. Essas classes são úteis para depuradores, profilers e ferramentas que precisam enumerar todos os símbolos públicos/estáticos da aplicação atual.

TSymbol

TSymbol representa uma única entrada de símbolo na tabela de símbolos do Harbour.

Membros DATA Principais

DATATipoDescrição
hSymbolNumericHandle para a entrada de símbolo interna do Harbour

METHODs Principais

MétodoDescrição
Name()Retorna o nome do símbolo como uma string de caracteres
IsStatic()Retorna .T. se o símbolo for estático (escopo de módulo)

TSymTable

TSymTable fornece acesso indexado a todos os símbolos da tabela de símbolos.

METHODs Principais

MétodoDescrição
Get( n )Retorna o TSymbol na posição n (começando em 1)
Len()Retorna o número total de símbolos na tabela
Size()Retorna o tamanho total (o mesmo que Len())
GetFirst()Retorna o primeiro TSymbol da tabela
GetLast()Retorna o último TSymbol da tabela

Exemplo: Iterar Todos os Símbolos

#include "FiveWin.ch"

function Main()

   local oSymTable := TSymTable():New()
   local oSym, n

   ? "Total symbols:", oSymTable:Len()
   ? "---"

   // Imprime os primeiros 20 símbolos
   for n := 1 to Min( 20, oSymTable:Len() )
      oSym := oSymTable:Get( n )
      if oSym != nil
         ? oSym:Name(), ;
           if( oSym:IsStatic(), "(static)", "(public)" )
      endif
   next

   // Obtém o primeiro e o último símbolo
   oSym := oSymTable:GetFirst()
   if oSym != nil
      ? "First symbol:", oSym:Name()
   endif

   oSym := oSymTable:GetLast()
   if oSym != nil
      ? "Last symbol:", oSym:Name()
   endif

return nil

Notas

  • A tabela de símbolos contém todos os símbolos de nível Harbour da aplicação, incluindo símbolos FUNCTION, PROCEDURE, STATIC e PUBLIC.
  • Get() retorna nil se o índice estiver fora do intervalo. Sempre verifique nil antes de acessar o objeto retornado.
  • Os símbolos são indexados na ordem em que são definidos na aplicação. Os símbolos do primeiro módulo aparecem primeiro, seguidos pelos módulos subsequentes.
  • Essas classes dependem da API interna da tabela de símbolos do Harbour (funções hb_sym*) e são específicas do runtime do Harbour.

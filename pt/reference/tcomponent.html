TComponent FROM TControl; TDataBaseComp FROM TComponent; TDbfComp FROM TComponent

As classes de componentes fornecem um modelo de composição orientado a objetos para o FiveWin. TComponent encapsula um objeto Harbour arbitrário (oObject) e delega mensagens a ele, atuando como inspetor/contêiner. TDataBaseComp estende isso para tabelas de banco de dados com eventos CRUD, e TDbfComp adiciona suporte a índices e relações específicos de DBF. Todos os três suportam inspeção de propriedades/eventos por meio dos arrays aProperties e aEvents.

TComponent

TComponent herda de TControl e encapsula um objeto alvo (oObject). Seu manipulador de erros (Error()) delega automaticamente mensagens desconhecidas ao oObject, de modo que você pode interagir com o objeto encapsulado de forma transparente através do componente.

Principais DATA

DATATipoDescrição
oObjectObjectO objeto Harbour encapsulado
aPropertiesArrayArray de descritores de propriedades para o inspetor
aEventsArrayArray de descritores de eventos (pares de codeblock)
bInspectBlockCodeblock avaliado quando a inspeção é solicitada

Principais METHODs

MétodoDescrição
New( oWnd, nId, oObject )Cria um componente encapsulando oObject
Error( ... )Manipulador de erros que delega automaticamente para oObject

TDataBaseComp

TDataBaseComp estende TComponent para acesso a tabelas de banco de dados. Fornece navegação e edição orientadas a eventos com callbacks OnOpen, OnSkip e OnSave.

Principais DATA

DATATipoDescrição
cFileCharacterCaminho do arquivo de banco de dados
cAliasCharacterAlias da área de trabalho
cDriverCharacterNome do driver RDD (ex.: "DBFCDX")
OnOpenBlockCodeblock avaliado quando a tabela é aberta
OnSkipBlockCodeblock avaliado na navegação de registros
OnSaveBlockCodeblock avaliado quando um registro é salvo

Principais METHODs

MétodoDescrição
CreateFromCode()Cria o componente programaticamente a partir de código
Skip( n )Move n registros para frente/para trás
Append()Adiciona um registro em branco
Delete()Marca o registro atual como excluído
Save()Grava as alterações pendentes em disco

TDbfComp

TDbfComp estende TComponent para operações específicas de DBF, incluindo gerenciamento de índices e relações.

Principais DATA (propriedades SETGET)

DATATipoDescrição
cIndexNameCharacterNome do arquivo de índice
cTagNameCharacterNome da tag do índice
aRelationsArrayArray de definições de relação com tabelas filhas
lOpenedLogical (SETGET).T. se a tabela estiver aberta
lSelectedLogical (SETGET).T. se a área de trabalho estiver selecionada
cAliasCharacter (SETGET)Nome do alias da área de trabalho
cFileNameCharacter (SETGET)Caminho do arquivo DBF
nWorkAreaNumeric (SETGET)Número da área de trabalho

Exemplo: Componente de Banco de Dados

#include "FiveWin.ch"

function Main()

   local oComp, oWnd

   DEFINE WINDOW oWnd TITLE "Component Demo" SIZE 600, 400

   // Cria um TDataBaseComp encapsulando uma tabela de clientes
   oComp := TDataBaseComp():New( oWnd, 101 )
   oComp:cFile   := "customers.dbf"
   oComp:cDriver := "DBFCDX"

   oComp:OnOpen := { || MsgInfo( "Table opened!" ) }
   oComp:OnSkip := { || oWnd:SetText( "Rec: " + Str( oComp:RecNo() ) ) }

   oComp:CreateFromCode()
   oComp:GoTop()

   ACTIVATE WINDOW oWnd

return nil

Notas

  • O manipulador de erros do TComponent intercepta qualquer acesso a método ou dado não definido no próprio componente e o encaminha para oObject. Isso faz com que o objeto encapsulado pareça fazer parte do componente.
  • Os arrays aProperties e aEvents foram projetados para uso com o inspetor de propriedades do FiveWin, permitindo a edição visual em tempo de design das propriedades do componente.
  • Os blocos de evento do TDataBaseComp (OnOpen, OnSkip, OnSave) são disparados automaticamente durante operações de navegação e edição, permitindo que você se conecte ao ciclo de vida dos dados sem sobrescrever métodos.
  • As propriedades SETGET do TDbfComp fornecem validação em tempo de execução ao obter ou definir o estado da área de trabalho.

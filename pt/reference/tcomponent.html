TComponent / TDataBaseComp / TDbfComp

Sources: source/classes/tcompone.prg, source/classes/tdbasecomp.prg, source/classes/tdbfcomp.prg

TComponent FROM TControl; TDataBaseComp FROM TComponent; TDbfComp FROM TComponent

The component classes provide an object-oriented composition model for FiveWin. TComponent wraps an arbitrary Harbour object (oObject) and delegates messages to it, acting as an inspector/container. TDataBaseComp extends this for database tables with CRUD events, and TDbfComp adds DBF-specific index and relation support. All three support property/event inspection via aProperties and aEvents arrays.

classDiagram class TControl { } class TComponent { oObject, aProperties, aEvents bInspect } class TDataBaseComp { cFile, cAlias, cDriver OnOpen, OnSkip, OnSave CreateFromCode(), Skip(), Append() } class TDbfComp { cIndexName, cTagName, aRelations cAlias (SETGET), cFileName (SETGET) } TControl <|-- TComponent TComponent <|-- TDataBaseComp TComponent <|-- TDbfComp

TComponent

TComponent inherits from TControl and wraps a target object (oObject). Its error handler (Error()) automatically delegates unknown messages to oObject, so you can interact with the wrapped object transparently through the component.

Key DATA

DATATypeDescription
oObjectObjectThe wrapped Harbour object
aPropertiesArrayArray of property descriptors for the inspector
aEventsArrayArray of event descriptors (codeblock pairs)
bInspectBlockCodeblock evaluated when inspection is requested

Key METHODs

MethodDescription
New( oWnd, nId, oObject )Create a component wrapping oObject
Error( ... )Error handler auto-delegates to oObject

TDataBaseComp

TDataBaseComp extends TComponent for database table access. It provides event-driven navigation and editing with OnOpen, OnSkip, and OnSave callbacks.

Key DATA

DATATypeDescription
cFileCharacterDatabase file path
cAliasCharacterWork area alias
cDriverCharacterRDD driver name (e.g. "DBFCDX")
OnOpenBlockCodeblock evaluated when the table is opened
OnSkipBlockCodeblock evaluated on record navigation
OnSaveBlockCodeblock evaluated when a record is saved

Key METHODs

MethodDescription
CreateFromCode()Programmatically create the component from code
Skip( n )Move n records forward/backward
Append()Append a blank record
Delete()Mark the current record as deleted
Save()Commit pending changes to disk

TDbfComp

TDbfComp extends TComponent for DBF-specific operations, including index management and relations.

Key DATA (SETGET properties)

DATATypeDescription
cIndexNameCharacterIndex file name
cTagNameCharacterIndex tag name
aRelationsArrayArray of relation definitions to child tables
lOpenedLogical (SETGET).T. if the table is open
lSelectedLogical (SETGET).T. if the work area is selected
cAliasCharacter (SETGET)Work area alias name
cFileNameCharacter (SETGET)DBF file path
nWorkAreaNumeric (SETGET)Work area number

Example: Database Component

#include "FiveWin.ch"

function Main()

   local oComp, oWnd

   DEFINE WINDOW oWnd TITLE "Component Demo" SIZE 600, 400

   // Create a TDataBaseComp wrapping a customer table
   oComp := TDataBaseComp():New( oWnd, 101 )
   oComp:cFile   := "customers.dbf"
   oComp:cDriver := "DBFCDX"

   oComp:OnOpen := { || MsgInfo( "Table opened!" ) }
   oComp:OnSkip := { || oWnd:SetText( "Rec: " + Str( oComp:RecNo() ) ) }

   oComp:CreateFromCode()
   oComp:GoTop()

   ACTIVATE WINDOW oWnd

return nil

Notes

  • TComponent's error handler intercepts any method or data access not defined on the component itself and forwards it to oObject. This makes the wrapped object appear as if it were part of the component.
  • The aProperties and aEvents arrays are designed for use with the FiveWin property inspector, enabling visual design-time editing of component properties.
  • TDataBaseComp event blocks (OnOpen, OnSkip, OnSave) fire automatically during navigation and editing operations, allowing you to hook into the data lifecycle without overriding methods.
  • TDbfComp SETGET properties provide runtime validation when getting or setting work area state.

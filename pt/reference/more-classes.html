TXmlDocument — Parsing e Criação de XML

TXmlDocument é fornecido pela biblioteca contrib hbxml do Harbour e é amplamente usado nos exemplos do FiveWin (mais de 23 exemplos). Fornece parsing XML no estilo DOM a partir de arquivos ou strings, com iteração via TXmlIterator.

Principais DATA

DATATipoDescrição
oRootTXmlNodeNó raiz do documento XML analisado
nStatusNuméricoStatus do parsing (0 = sucesso)
nErrorNuméricoCódigo de erro se o parsing falhou
nLineNuméricoNúmero da linha onde o erro ocorreu

Principais METHODs

METHODDescrição
New( hFile | cString )Analisa XML a partir de um handle de arquivo ou string
Read( hFile )Lê e analisa a partir de um handle de arquivo aberto
ToString()Serializa o documento de volta para uma string XML
Write( hFile )Grava o documento em um handle de arquivo

TXmlNode (nós filhos)

DATA/METHODDescrição
cNameNome da tag do nó
cDataConteúdo de texto do nó
aAttributesHash de pares nome/valor de atributos
oChildPrimeiro nó filho
oNextPróximo nó irmão
AddBelow( oNode )Adiciona um nó filho

Exemplo

#include "FiveWin.ch"

function Main()

   local hFile    := FOpen( "config.xml" )
   local oXmlDoc  := TXmlDocument():New( hFile )
   local oXmlIter := TXmlIterator():New( oXmlDoc:oRoot )
   local oTag

   while ( oTag := oXmlIter:Next() ) != nil
      MsgInfo( oTag:cName + ": " + oTag:cData )
      // Acessar atributos:
      // HEval( oTag:aAttributes, { |k,v| QOut( k, v ) } )
   end

   FClose( hFile )

return nil

TWorkBook / TWorkSheet — Geração de Excel XLSX

Crie arquivos nativos do Excel .xlsx sem precisar do Microsoft Office. Construído sobre a biblioteca C xlsxwriter (de John McNamara), encapsulada para o Harbour por Arturo Tamayo. Suporta formatação, fórmulas, imagens, células mescladas e mais.

Fonte: source/function/fwxlsxlb.prg

TWorkSheet — Principais DATA/METHODs

DATA/METHODDescrição
Say( nRow, nCol, uValue, oFormat )Grava um valor em uma célula (detecta o tipo automaticamente)
SayRow( nRow, aValues, aFormat )Grava uma linha inteira de valores
SayImage( nRow, nCol, cImage )Incorpora uma imagem em uma célula
SayFormula( nRow, nCol, cFormula )Grava uma fórmula do Excel
MergeRange( r1, c1, r2, c2, cValue )Mescla um intervalo de células

Freeze( nRow, nCol )Congela os painéis na posição informada
CreateFrom( uSource )Popula a partir de um DBF, array ou recordset
SetArrayData( aData, aStruct )Grava um array 2D como dados de tabela

Exemplo

#include "FiveWin.ch"

function Main()

   local oBook, oSheet, oFmtBold

   oBook := TWorkBook():New( "report.xlsx" )
   oSheet := oBook:AddSheet( "Sales" )

   // Cria um formato em negrito
   oFmtBold := oBook:Format( , "B" )   // "B" = Negrito

   // Grava os cabeçalhos
   oSheet:Say( 0, 0, "Product",  oFmtBold )
   oSheet:Say( 0, 1, "Quantity", oFmtBold )
   oSheet:Say( 0, 2, "Price",    oFmtBold )

   // Grava as linhas de dados
   oSheet:SayRow( 1, { "Widget A", 150, 29.99 } )
   oSheet:SayRow( 2, { "Widget B",  75, 49.99 } )
   oSheet:SayRow( 3, { "Widget C", 200, 14.99 } )

   // Adiciona uma fórmula SUM
   oSheet:SayFormula( 4, 1, "=SUM(B2:B4)" )

   oSheet:SetColumnSize( 0, 0, 20 )   // Alarga a coluna A
   oSheet:Freeze( 1, 0 )              // Congela a linha de cabeçalho

   oBook:Close()
   MsgInfo( "report.xlsx criado!" )

return nil

function Main()

   local oChain := TBlockChain():New( "mychain" )

   // Adiciona blocos com dados

   oChain:AddNewBlock( , "Second transaction: Bob pays Carol 5" )

      MsgInfo( "Block 2 is valid! Blocks: " + ;
               Str( oChain:CountBlocks() ) )

Modo Escuro

O FiveWin oferece suporte integrado a modo escuro através da função FW_SetDarkMode(). Quando habilitado, todos os novos diálogos recebem automaticamente o tema com cores escuras em TDialog:Initiate(), e as janelas já abertas também recebem o tema imediatamente.

Fonte: source/classes/dialog.prg (linha ~1462)

flowchart LR A["FW_SetDarkMode(.T.)"] --> B["Define lDarkMode = .T."] B --> C["Aplica tema a todas as janelas existentes"] B --> D["Novos diálogos com tema automático
em TDialog:Initiate()"] C --> E["SetDarkMode() em cada janela"] D --> E E --> F["Fundo escuro + texto claro
em todos os controles"]

API

ChamadaDescrição
FW_SetDarkMode( .T. )Habilita o modo escuro com cores padrão (texto: RGB(220,220,220), fundo: RGB(30,30,30))
FW_SetDarkMode( .T., nClrText, nClrBack )Habilita com cores personalizadas
FW_SetDarkMode( .F. )Desabilita o modo escuro (restaura as cores do sistema)
FW_SetDarkMode()Consulta o estado atual (retorna .T. ou .F.)

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oDlg

   // Habilita o modo escuro para toda a aplicação
   FW_SetDarkMode( .T. )

   DEFINE WINDOW oWnd TITLE "Dark Mode App" SIZE 600, 400

   // Todos os diálogos criados a partir deste ponto são automaticamente escuros
   DEFINE DIALOG oDlg TITLE "Settings" SIZE 400, 300 PIXEL TRUEPIXEL OF oWnd
   @ 30, 20 SAY "This dialog is automatically dark!" OF oDlg SIZE 350, 24 PIXEL
   @ 70, 20 GET oGet VAR cName OF oDlg SIZE 350, 24 PIXEL
   @ 120, 160 BUTTON "OK" OF oDlg SIZE 80, 30 PIXEL ACTION oDlg:End()
   ACTIVATE DIALOG oDlg CENTERED

   ACTIVATE WINDOW oWnd

return nil

// Alterna o modo escuro em tempo de execução:
// FW_SetDarkMode( ! FW_SetDarkMode() )

Classes de Gráficos GDI+

O FiveWin encapsula a API GDI+ do Windows através de um conjunto de classes para gráficos 2D de alta qualidade: linhas com anti-aliasing, imagens com mesclagem alfa, preenchimentos em gradiente, desenho baseado em caminhos e mais. Todas as classes ficam em source/classes/tgdiplus.prg.

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "GDI+ Drawing" SIZE 600, 400

   ACTIVATE WINDOW oWnd ;
      ON PAINT DrawGdiPlus( oWnd:hDC )

return nil

function DrawGdiPlus( hDC )

   local oGfx    := Graphics():New( hDC )
   local oPen    := Pen():New( 255, 255, 0, 0, 3 )    // Caneta vermelha, 3px de largura
   local oBrush  := Brush():NewSolidBrush( 128, 0, 0, 255 )  // Azul semitransparente
   local oPenGrn := Pen():New( 255, 0, 180, 0, 2 )    // Caneta verde

   // Desenha um retângulo preenchido com borda
   oGfx:DrawRect( oPen, oBrush, 50, 50, 200, 150 )

   // Desenha uma elipse
   oGfx:DrawEllipse( oPenGrn, , 300, 80, 180, 120 )

   // Desenha uma linha
   oGfx:DrawLine( oPen, 50, 250, 500, 350 )

   // Desenha texto com anti-aliasing
   oGfx:DrawText( 20, 50, "GDI+ in FiveWin!", "Segoe UI", 24, ;
                  Brush():NewSolidBrush( 255, 0, 0, 0 ) )

   oPenGrn:Destroy()

IDE Visual do FiveWin

A IDE Visual do FiveWin (visual/visualfw.exe) é um designer visual de formulários que permite projetar diálogos arrastando e soltando controles, e então gera o código-fonte .prg correspondente. Também suporta edição de arquivos de recursos.

Características Principais

  • Design de diálogos com arrastar e soltar e prévia ao vivo
  • Inspetor de propriedades para todas as propriedades dos controles
  • Geração automática de código .prg
  • Importação e exportação de arquivos de recursos (.rc)
  • Suporte a todos os controles do FiveWin (TGet, TButton, TXBrowse, TFolder, etc.)
  • Ferramentas de alinhamento: encaixar na grade, centralizar, distribuir
  • Edição de múltiplos diálogos em abas

Primeiros Passos

  1. Execute visual/visualfw.exe a partir do diretório do FiveWin
  2. Crie um novo formulário ou abra um arquivo .prg existente
  3. Arraste controles da caixa de ferramentas para a superfície do diálogo
  4. Defina as propriedades no painel inspetor à direita
  5. Clique em "Gerar Código" para produzir o código-fonte .prg
  6. Compile o código gerado com o compilador de sua preferência

Consulte o diretório samples/FiveUI/ para ver 17 formulários de exemplo criados com o designer visual.

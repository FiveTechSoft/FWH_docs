TProgress

Fonte: source/classes/tprogres.prg

Herda de: TControl

TProgress encapsula a barra de progresso do controle comum do Windows (msctls_progress32). Ela suporta indicação de progresso padrão com intervalo e posição configuráveis, incrementos de passo, orientação vertical e modo marquee (indeterminado). TProgress é adequada para mostrar o progresso de operações em janelas, diálogos e barras de status.

Principais Membros DATA

DATATipoDescrição
nMinNumericValor mínimo do intervalo (padrão 0)
nMaxNumericValor máximo do intervalo (padrão determinado pelo sistema)
nPosNumericPosição atual
nStepNumericValor de incremento do passo

Métodos Principais

MétodoDescrição
New( nTop, nLeft, oWnd, nPos, nClrF, nClrB, lPixel, lDesign, nW, nH, cMsg, lVert, lMarquee )Cria uma barra de progresso. Suporta modos vertical e marquee via lVert e lMarquee.
ReDefine( nId, oWnd )Redefine a partir de um modelo de recurso de diálogo
SetPos( nPos )Define a posição atual (alias _nPosition, nPosition)
GetPos()Retorna a posição atual
SetRange( nMin, nMax )Define os valores mínimo e máximo do intervalo
SetStep( nStepInc )Define o valor de incremento do passo
StepIt()Avança a posição pelo valor de passo atual
DeltaPos( nIncrement )Altera a posição por um valor relativo (positivo ou negativo)
SetMarquee( lOnOff )Ativa ou desativa o modo marquee (indeterminado)

Comandos

// Barra de progresso padrão
DEFINE PROGRESS oProg OF oDlg

// Barra de progresso marquee (indeterminada)
DEFINE PROGRESS oProg OF oDlg MARQUEE

Exemplo

#include "FiveWin.ch"

function Main()

   local oWnd, oProg, n

   DEFINE WINDOW oWnd TITLE "Progress Demo" SIZE 400, 150

   @ 30, 30 PROGRESS oProg OF oWnd SIZE 340, 25

   oProg:SetRange( 0, 100 )
   oProg:SetStep( 1 )

   @ 80, 30 BUTTON "Start" OF oWnd SIZE 80, 25 ;
      ACTION ( oProg:SetPos( 0 ), ;
               For n := 1 To 100,;
                   oProg:SetPos( n ),;
                   SysRefresh(),;
                   Sleep( 10 ),;
               Next )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • A barra de progresso usa a classe de controle comum do Windows msctls_progress32.
  • O modo marquee (indeterminado) mostra uma barra de rolagem animada quando a duração da operação é desconhecida. Ative via lMarquee := .T. na criação ou chame SetMarquee( .T. ) em tempo de execução.
  • Barras de progresso verticais são criadas definindo lVertical := .T. (estilo PBS_VERTICAL).
  • O método StepIt() avança a posição pelo valor definido via SetStep(). O passo padrão é 1.
  • Use DeltaPos() para alterações de posição relativas sem modificar o valor do passo.

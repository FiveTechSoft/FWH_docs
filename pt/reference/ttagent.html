TAgent / TOLlama

Fonte: source/classes/tollama.prg

TOLlama: Autônoma | TAgent: Usa TOLlama internamente

TOLlama fornece integração com modelos LLM do Ollama executados localmente através da API REST do Ollama. Suporta prompts de texto, respostas em streaming e análise de imagens (para modelos multimodais). TAgent baseia-se em TOLlama para criar um agente de IA capaz de invocar funções Harbour como ferramentas, permitindo automação dirigida por LLM.

Principais Membros DATA

DATATipoDescrição
cModelCharacterNome do modelo Ollama (padrão "deepseek-r1:14b")
cUrlCharacterURL da API (padrão "http://localhost:11434/api/chat")
cSystemPromptCharacterPrompt de sistema que define o comportamento do agente
aToolsArrayArray de definições de ferramentas para o agente

Métodos Principais

MétodoDescrição
New( cModel )Cria um cliente Ollama com o modelo especificado
Send( cPrompt )Envia um prompt; retorna a resposta completa
SendStream( cPrompt, bWriteFunction )Envia com callback de streaming para saída de tokens em tempo real
SendImage( cImageFile, cPrompt )Envia imagem + prompt para modelos multimodais
GetValue()Analisa a resposta JSON e extrai o texto do conteúdo
End()Libera o handle do libcurl
SetSystemPrompt( c )Define o prompt de sistema do agente
AddTool( cName, cDesc, bAction )Registra uma função Harbour como ferramenta invocável
Run( cPrompt )Executa um prompt através do agente; retorna o resultado

Exemplo: Agente com Ferramenta de Calculadora

#include "FiveWin.ch"
function Main()
   local oAgent
   oAgent := TAgent():New( "deepseek-r1:14b" )
   oAgent:SetSystemPrompt( "You are a helpful assistant." )
   oAgent:AddTool( "calculator", "Add two numbers", { |a,b| a + b } )
   ? oAgent:Run( "What is 123 + 456?" )
return nil

Notas

  • TOLlama requer um servidor Ollama local em execução na porta 11434.
  • Usa libcurl (hbcurl.ch) para comunicação HTTP com a API do Ollama.
  • SendStream permite a exibição incremental dos tokens gerados à medida que chegam.
  • SendImage funciona com modelos multimodais como LLaVA ou bakllava.
  • TAgent organiza as ferramentas por categoria, fornecendo um framework extensível de uso de ferramentas por LLM.

TImageBase64

Fonte: source/classes/imageb64.prg

Classe utilitária independente

TImageBase64 é uma classe utilitária que codifica imagens em Base64 para uso em páginas web (tags HTML <img> com data URIs). Ela também pode extrair e salvar imagens a partir de HTML codificado em Base64. A classe detecta automaticamente se a origem de entrada é um caminho de arquivo, uma URL ou texto simples.

Principais Membros DATA

DATATipoDescrição
aImageArrayArray interno da imagem proveniente de FW_ReadImage
cFileCharacterCaminho do arquivo de origem ou URL (se aplicável)
cBase64CharacterString da imagem codificada em Base64
lTagLogicalIncluir tags <img> na saída
lHtmlLogicalGerar documento HTML completo na saída
lUrlEncodeLogicalCodificar a data URI em URL em vez de base64 simples
nImgWidthNumericLargura da imagem em pixels (ACCESS somente leitura)
nImgHeightNumericAltura da imagem em pixels (ACCESS somente leitura)

Métodos Principais

MétodoDescrição
New( cSource )Cria o objeto; opcionalmente carrega a origem imediatamente
SetSource( cSource )Define a origem: detecta automaticamente arquivo, URL ou texto base64
ChooseFile()Abre o diálogo de seleção de arquivo para escolher uma imagem
Paste()Carrega a imagem da área de transferência
MakeText( lUrlEncode, lTag, lHtml, cTitle )Gera o texto de saída (data URI ou HTML)
SaveText( cFile, lUrlEncode, lTag, lHtml )Salva o texto de saída em arquivo; retorna o nome do arquivo ou nil
CopyText( lUrlEncode, lTag, lHtml )Copia o texto de saída para a área de transferência; retorna o texto
SaveImage()Salva a imagem decodificada em um arquivo (.jpg ou .png)
TestHTML()Gera um arquivo HTML de teste e o abre no navegador

Exemplo: Imagem para Tag HTML Base64

#include "FiveWin.ch"

function Main()

   local oImg := TImageBase64():New( "c:\images\photo.jpg" )

   // Gera uma tag HTML img com dados base64 embutidos
   oImg:lTag := .T.
   oImg:CopyText()   // copia para a área de transferência

   // Ou salva como um arquivo HTML completo
   oImg:lHtml := .T.
   oImg:SaveText( "preview.html" )

   // Abre no navegador para testar
   oImg:TestHTML()

return nil

Notas

  • A detecção automática da origem verifica: caminho de arquivo (<=255 caracteres, existente em disco), URL HTTP/HTTPS ou texto codificado em base64.
  • Use Paste() para capturar uma imagem diretamente da área de transferência do Windows (formato bitmap, lista de arquivos ou PNG).
  • A data de classe nLineWidth (padrão 1024) controla a quebra de linha na saída base64.
  • Formatos de saída suportados: URIs data:image/..., tags <img> ou documentos HTML completos.

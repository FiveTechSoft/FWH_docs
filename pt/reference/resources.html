Recursos GDI

O FiveWin encapsula os objetos GDI (Graphics Device Interface) do Windows em classes Harbour. Esses objetos representam fontes, pincéis, cursores, ícones, bitmaps e imagens. Todos os recursos GDI devem ser liberados quando não forem mais necessários chamando :End() para evitar vazamento de recursos. Esta página também aborda TIni (gerenciamento de arquivos INI) e TReg32 (acesso ao Registro do Windows).

TFont

Fonte: source/classes/font.prg

Membros DATA Principais

DATATipoDescrição
cFaceNameCharacterNome da fonte (ex. "Arial", "Segoe UI")
hFontNumericHandle HFONT do Windows
lBoldLogicalPeso negrito
lItalicLogicalEstilo itálico
lUnderlineLogicalDecoração sublinhado
lStrikeOutLogicalDecoração tachado
nWeightNumericPeso da fonte (400=normal, 700=negrito)
nCharSetNumericConjunto de caracteres (0=ANSI, 1=DEFAULT, 255=OEM)
nEscapementNumericÂngulo do texto em décimos de grau
nOrientationNumericÂngulo de orientação dos caracteres
nInpHeightNumericAltura solicitada (negativo = tamanho em pontos)

Métodos Principais

MétodoDescrição
New( cFaceName, nWidth, nHeight, lFromUser, lBold, ... )Cria uma fonte (ou retorna uma instância em cache)
Choose( @nRGBColor )Exibe o diálogo de seleção de fonte, retorna a fonte selecionada
nSize()Obtém o tamanho da fonte em pontos
Bold( lBold )Cria uma nova fonte com negrito alternado
Italic( lItalic )Cria uma nova fonte com itálico alternado
Modify( nHeight, lBold, lItalic, lUnderline, lStrikeOut, nEsc )Cria uma cópia modificada
Rotate( nRotateBy )Cria uma cópia rotacionada
Clone()Compartilha o mesmo handle (contagem de referências)
Activate( hDC )Seleciona a fonte em um contexto de dispositivo
DeActivate( hDC )Restaura a fonte anterior
End()Libera o handle da fonte

Exemplo

#include "FiveWin.ch"

function Main()

   local oFont, oFontBig, oFontItalic

   // Definição padrão via comando
   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14

   // Variante negrito
   DEFINE FONT oFontBig NAME "Segoe UI" SIZE 0, -20 BOLD

   // Itálico via método
   oFontItalic := oFont:Italic( .T. )

   // Usar em um diálogo
   DEFINE DIALOG oDlg TITLE "Font Demo" SIZE 400, 200 FONT oFont
   @ 1, 1 SAY "Normal text" OF oDlg
   @ 2, 1 SAY "Bold text" OF oDlg FONT oFontBig
   @ 3, 1 SAY "Italic text" OF oDlg FONT oFontItalic
   ACTIVATE DIALOG oDlg CENTER

   // Seletor de fonte
   // local oChosen := oFont:Choose()

   oFont:End()
   oFontBig:End()
   oFontItalic:End()

return nil

   DEFINE WINDOW oWnd TITLE "Icon Demo" ICON oIcon

return nil

TBitmap é um controle que exibe imagens bitmap (BMP, PNG, JPG, GIF, ICO). Herda de TControl, podendo ser colocado em janelas e diálogos. Suporta rolagem, esticamento, transparência e mistura alfa.

lScrollLogicalHabilitar rolagem
lTransparentLogicalFundo transparente
lHasAlphaLogicalA imagem possui canal alfa
nZoomNumericNível de zoom (1 = 100%)
nImgWidthNumericLargura original da imagem
nImgHeightNumericAltura original da imagem

Métodos Principais

MétodoDescrição
LoadFromClipboard( oWnd )Carregar bitmap da área de transferência
CopyToClipboard()Copiar bitmap para a área de transferência
LoadFromString( cString )Carregar bitmap de uma string binária
Zoom( nZoom )Definir nível de zoom

Exemplo

#include "FiveWin.ch"

function Main()

   local oDlg, oBmp

   DEFINE DIALOG oDlg TITLE "Bitmap Demo" SIZE 600, 400

   @ 1, 1 BITMAP oBmp FILE "photo.bmp" OF oDlg SIZE 250, 180 STRETCH

   // ou a partir de recurso:
   // @ 1, 1 BITMAP oBmp RESOURCE "LOGO" OF oDlg SIZE 250, 180

   ACTIVATE DIALOG oDlg CENTER

return nil

TImage

Fonte: source/classes/image.prg

TImage estende TBitmap com suporte à biblioteca FreeImage, permitindo carregar e salvar muitos formatos de imagem: BMP, PNG, JPEG, GIF, TIFF, WebP, ICO, PSD, RAW, e mais. Também pode carregar imagens a partir de URLs.

Métodos Adicionais (além de TBitmap)

MétodoDescrição
LoadImage( cResName, cBmpFile, cResFile )Carregar qualquer formato via FreeImage
SaveImage( cFile, nFormat, nQuality )Salvar em qualquer formato suportado
LoadFromURL( cUrl )Baixar e exibir uma imagem a partir de uma URL
LoadFromMemory( cBuffer, nWidth, nHeight )Carregar de um buffer de memória
RotateImage( nAngle )Rotacionar a imagem em n graus
Progress( lProgress )Mostrar/ocultar progresso de carregamento

DLL FreeImage

TImage requer freeimage.dll (32-bit) ou freeimage64.dll (64-bit) no diretório da aplicação ou no PATH do sistema.

Exemplo

#include "FiveWin.ch"

function Main()

   local oDlg, oImg

   DEFINE DIALOG oDlg TITLE "Image Demo" SIZE 800, 600

   // Carregar qualquer formato (PNG, JPG, GIF, WebP, etc.)
   @ 1, 1 IMAGE oImg FILE "photo.png" OF oDlg SIZE 350, 250 STRETCH

   // Carregar de URL (após iniciar o diálogo)
   // oImg:LoadFromURL( "https://example.com/image.jpg" )

   // Salvar em formato diferente
   // oImg:SaveImage( "output.jpg", FIF_JPEG, 85 )

   // Rotacionar
   // oImg:RotateImage( 90 )

   ACTIVATE DIALOG oDlg CENTER

return nil

TIni

Fonte: source/classes/ini.prg

TIni gerencia arquivos de configuração INI do Windows. Utiliza as funções da API do Windows GetPrivateProfileString() e WritePrivateProfileString() para acesso confiável a arquivos INI.

Membros DATA Principais

DATATipoDescrição
cIniFileCharacterCaminho do arquivo INI
lAutoSetLogicalAuto-salvar no Get (escrever valor padrão se ausente)

Métodos

MétodoDescrição
New( cIniFile )Criar gerenciador INI (adiciona extensão ".ini" se ausente)
Get( cSection, cEntry, uDefault, @uVar )Ler um valor (auto-detecta tipo a partir do padrão)
Set( cSection, cEntry, uValue )Escrever um valor
Sections()Obter array com todos os nomes de seção
DelSection( cSection )Excluir uma seção inteira
DelEntry( cSection, cEntry )Excluir uma entrada individual

Exemplo

#include "FiveWin.ch"

function Main()

   local oIni, cUser, nPort, lDebug

   oIni := TIni():New( "myapp.ini" )

   // Ler configurações (com valores padrão)
   oIni:Get( "Database", "Server",   "localhost", @cServer )
   oIni:Get( "Database", "Port",     3306,        @nPort )
   oIni:Get( "App",      "Debug",    "N",         @cDebug )

   lDebug := ( cDebug == "Y" )

   // Escrever configurações
   oIni:Set( "App", "LastRun", DToC( Date() ) + " " + Time() )
   oIni:Set( "App", "Version", FWVersion() )

   // Excluir
   oIni:DelEntry( "Temp", "CacheFile" )

   ? "Server:", cServer, "Port:", nPort

return nil

Isso cria/lê um arquivo INI como:

[Database]
Server=localhost
Port=3306

[App]
Debug=N
LastRun=03/24/2026 14:30:45
Version=FWH 26.05

TReg32

Fonte: source/classes/reg32.prg

TReg32 fornece acesso de leitura/escrita ao Registro do Windows. Encapsula as funções da API do Registro do Windows (RegOpenKeyEx, RegQueryValueEx, RegSetValueEx, etc.).

Membros DATA Principais

DATATipoDescrição
cRegKeyCharacterCaminho da chave do registro
nKeyNumericChave raiz (HKEY_CURRENT_USER, HKEY_LOCAL_MACHINE, etc.)
nHandleNumericHandle da chave aberta
nErrorNumericÚltimo código de erro (0 = sucesso)
lErrorLogicalIndicador de erro

Métodos

MétodoDescrição
New( nKey, cRegKey )Abrir uma chave de registro existente
Create( nKey, cRegKey )Criar uma nova chave de registro (ou abrir se existir)
Get( cSubKey, @uVar )Ler um valor
GetBinary( cSubKey )Ler dados binários
Set( cSubKey, uVar, nType )Escrever um valor (REG_SZ, REG_DWORD, REG_BINARY)
Delete( cSubKey )Excluir uma subchave
Close()Fechar o handle da chave do registro

Constantes de Chave Raiz

ConstanteDescrição
HKEY_CLASSES_ROOTAssociações de arquivos e classes COM
HKEY_CURRENT_USERConfigurações do usuário atual
HKEY_LOCAL_MACHINEConfigurações de toda a máquina (requer admin)
HKEY_USERSTodos os perfis de usuário
HKEY_CURRENT_CONFIGConfiguração de hardware atual

Exemplo

#include "FiveWin.ch"

#define HKEY_CURRENT_USER  2147483649

function Main()

   local oReg, cValue := ""

   // Ler um valor do registro
   oReg := TReg32():New( HKEY_CURRENT_USER, ;
      "Software\Microsoft\Windows\CurrentVersion\Themes\Personalize" )

   if oReg:nError == 0
      oReg:Get( "AppsUseLightTheme", @cValue )
      ? "Dark mode:", iif( cValue == Chr(0), "Yes", "No" )
      oReg:Close()
   endif

   // Criar e escrever um valor
   oReg := TReg32():Create( HKEY_CURRENT_USER, "Software\MyApp" )
   if oReg:nError == 0
      oReg:Set( "LastRun", DToC( Date() ) + " " + Time() )
      oReg:Set( "Version", FWVersion() )
      oReg:Close()
   endif

   // Ler de volta
   oReg := TReg32():New( HKEY_CURRENT_USER, "Software\MyApp" )
   if oReg:nError == 0
      oReg:Get( "LastRun", @cValue )
      ? "Last run:", cValue
      oReg:Close()
   endif

return nil

Melhores Práticas de Gerenciamento de Recursos

  • Sempre chame :End() nos recursos GDI (TFont, TBrush, TIcon, TBitmap, TImage) quando terminar de usá-los. O Windows tem um conjunto limitado de handles GDI.
  • Cache de fontes: TFont armazena fontes em cache internamente. Criar a mesma fonte duas vezes retorna o mesmo objeto com uma contagem de referências incrementada. Chamar :End() decrementa a contagem e só libera o handle quando chega a zero.
  • Pincel para janelas: Ao atribuir um pincel a uma janela, a janela assume a propriedade. O pincel é liberado quando a janela é destruída.
  • TIni e TReg32 não usam handles GDI, mas TReg32:Close() deve ser chamado para liberar o handle da chave do registro.
  • Use GDI_GetObjectCount() durante o desenvolvimento para monitorar o uso de handles GDI e detectar vazamentos.

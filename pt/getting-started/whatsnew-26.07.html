TWebView2 — Fixed Version Runtime

TWebView2():New() aceita um terceiro parâmetro opcional cBrowserExecutableFolder (o browserExecutableFolder da Microsoft). Quando definido, o WebView2 carrega um Runtime Fixed Version / standalone dessa pasta em vez do Runtime Evergreen instalado no sistema.

  • Útil em SO antigos (p. ex. Windows Server 2012 R2) onde o Evergreen atual não funciona
  • Útil quando o Runtime não pode ser instalado na máquina
  • Caminho = raiz do Fixed Version (pasta com msedgewebview2.exe)
  • Deve ser passado no construtor (o ambiente é criado em New())
  • Código existente sem o parâmetro permanece igual
oWeb := TWebView2():New( oWnd, , "C:\MeuApp\WebView2Runtime" )

Também corrigido: o segundo parâmetro cUserDataFolder era sobrescrito com um caminho padrão em AppData; agora é respeitado.

Referência: TWebView2.

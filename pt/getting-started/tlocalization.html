Localização e Suporte Multi-idioma

Fonte: source/function/strings.prg

O sistema de localização do FiveWin fornece suporte multi-idioma centralizado através de FWString() e FWSetLanguage(). Centenas de traduções predefinidas são armazenadas em um array estático dentro de strings.prg, abrangendo inglês, espanhol, francês, português, alemão e italiano. Todos os componentes do framework -- janelas, menus, diálogos, relatórios, pré-visualizações de impressão e tratadores de erro -- obtêm o texto da interface através deste sistema unificado. As aplicações podem alternar de idioma em tempo de execução ou adicionar novos idiomas com tabelas de tradução personalizadas.

Funções Principais

FWString()

FWString( cEnglishText ) --> cLocalized

A interface principal para obter texto localizado. Procura no array aStrings pela chave em inglês e retorna a tradução para o idioma atualmente selecionado. Retorna o texto original caso nenhuma tradução seja encontrada.

? FWString( "Save" )     // "Guardar" (se idioma = Espanhol)
? FWString( "Cancel" )    // "Annuler" (se idioma = Francês)

FWSetLanguage()

FWSetLanguage( nLang [, cLang ] ) --> nPrevLang

Define o idioma ativo pelo seu ID numérico (1-6). Um nome de string opcional ("ES", "FR", etc.) pode ser passado para melhor legibilidade. Retorna o ID do idioma anterior. Todas as chamadas subsequentes a FWString() usam o novo idioma.

FWSetLanguage( 2 )    // Alterna para Espanhol
FWSetLanguage( 4 )    // Alterna para Português

FWAddLanguage()

FWAddLanguage( cLang, hStrings ) --> lSuccess

Adiciona um novo idioma com um hash de tradução personalizado. cLang é um código de duas letras e hStrings é um hash que mapeia cada string em inglês para sua tradução. Isso permite módulos de tradução incluíveis sem modificar o próprio strings.prg.

FWMissingStrings()

FWMissingStrings( lWriteToFile ) --> nCount

Informa o número de strings usadas pela aplicação que não possuem tradução para o idioma atual. Quando lWriteToFile é .T., grava as strings ausentes em um arquivo de texto como referência para o tradutor.

FWAddString()

FWAddString( cEnglish, cTranslated ) --> nil

Adiciona um único par de strings à tabela de tradução do idioma atual em tempo de execução. Útil para strings específicas da aplicação que não estão no conjunto predefinido.

FWSetString()

FWSetString( nLang, cEnglish, cTranslated ) --> nil

Define ou substitui a tradução de uma chave em inglês para um idioma específico. Permite corrigir entradas individuais sem recarregar a tabela inteira.

FWLanguageID()

FWLanguageID() --> nLang

Retorna o ID numérico do idioma atualmente ativo (1-6). Útil para lógica condicional que depende do idioma ativo (por exemplo, tratamento de pontuação inicial em espanhol).

if FWLanguageID() == 2  // Espanhol
   cPrompt := FWString( "Open" ) + " " + FWString( "file" )
endif

FWLoadStrings() / FWSaveStrings()

FWLoadStrings( cFile ) --> lSuccess
FWSaveStrings( cFile ) --> lSuccess

Carrega ou salva a tabela de tradução completa de/para um arquivo de texto. Útil para distribuir pacotes de idiomas separados ou permitir a personalização de traduções pelo usuário final.

Codificação do Arquivo

O arquivo de origem strings.prg deve ser codificado como CP1252 (Europa Ocidental), não UTF-8. Os caracteres acentuados são armazenados como bytes únicos (por exemplo, n=0xF1, a=0xE4, u=0xFC). O compilador Harbour preserva os bytes dos literais de string como estão, portanto a codificação deve corresponder à codepage esperada em tempo de compilação.

Suporte a Unicode e Codepage

O FiveWin suporta aplicações Unicode através de FW_SetUnicode(.T.), que deve ser chamada antes de qualquer janela ser criada. Quando o modo Unicode está ativo:

  • Todas as strings são codificadas internamente em UTF-8
  • Os controles do Windows recebem UTF-16 através de conversão automática em fwunicode.c
  • hb_cdpSelect("UTF8") é usado como a codepage do Harbour
  • Os literais de string nos arquivos de origem .prg devem ser salvos como UTF-8

Habilitando Unicode

#include "FiveWin.ch"

function Main()
   FW_SetUnicode( .T. )  // Deve ser chamada antes de qualquer UI
   // ... resto da aplicação
return nil

Detalhes de FW_SetUnicode()

Quando FW_SetUnicode(.T.) está ativo:

  • fwunicode.c: hbcdp_to_wincdp() converte codepages OEM (<1250) para CP_ACP quando bAnsiOnly é TRUE, evitando a dupla codificação de texto CP1252 com CP437
  • Templates de diálogo: dlg2chr.c e ctrl2chr.c usam CP_ACP (não CP_OEMCP) para a conversão MultiByteToWideChar
  • Controles comuns: aplicações com manifesto do Windows XP criam controles comuns Unicode; fwunicode.c faz a ponte de codificação
  • GET/MultiGet: a flag lWideChar usa KeyWChar() para entrada de caracteres Unicode

Tabelas de Idioma Personalizadas (Além das 6 Embutidas)

A função FWAddLanguage() suporta a adição de idiomas além dos 6 embutidos. O sistema suporta até Len(aStrings[1]) idiomas (atualmente 10 posições disponíveis). Use FWSetLanguage(n) com um ID > 6 após adicionar o idioma:

// Adiciona a tabela de tradução do Chinês (ID 7)
FWAddLanguage( "ZH", { "Save" => "保存", "Cancel" => "取消", ;
   "File" => "文件", "Open" => "打开" } )
FWSetLanguage( 7 )

Exemplo: Aplicação Multi-idioma

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu

   DEFINE WINDOW oWnd TITLE "Localization Demo" ;
      MENU BuildMenu( oWnd ) ;
      SIZE 600, 400

   ACTIVATE WINDOW oWnd

return nil

function BuildMenu( oWnd )

   local oMenu

   MENU oMenu
      MENUITEM FWString( "&File" )
      MENU
         MENUITEM FWString( "&Open" ) ACTION MsgInfo( FWString( "Open file" ) )
         MENUITEM FWString( "E&xit" )  ACTION oWnd:End()
      ENDMENU
      MENUITEM "Language"
      MENU
         MENUITEM "English"   ACTION ( FWSetLanguage( 1 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Espanol"   ACTION ( FWSetLanguage( 2 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Francais"  ACTION ( FWSetLanguage( 3 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Deutsch"   ACTION ( FWSetLanguage( 5 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
         MENUITEM "Italiano"  ACTION ( FWSetLanguage( 6 ), oWnd:SetMenu( BuildMenu( oWnd ) ) )
      ENDMENU
   ENDMENU

return oMenu

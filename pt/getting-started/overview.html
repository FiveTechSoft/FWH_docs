Visão Geral

FiveWin for Harbour (FWH) é um framework abrangente para desenvolvimento de aplicações Windows que traz o poder da API Win32 para as linguagens de programação Harbour e xHarbour. Ele permite construir aplicações nativas Windows profissionais utilizando uma linguagem de alto nível com sintaxe xBase, acessando toda a API do Windows por baixo.

O Que é o FiveWin?

O FiveWin fornece uma biblioteca de classes orientada a objetos completa, um rico conjunto de comandos xBase e integração transparente com múltiplos compiladores C. Em vez de lidar diretamente com chamadas brutas da API Win32, você escreve código Harbour limpo com comandos FiveWin:

  • Controles nativos do Windows — botões, campos de edição, listboxes, treeviews, grids e muito mais
  • Acesso a dados — DBF/CDX, ADO RecordSets, ODBC, MariaDB/MySQL, SQLite
  • Impressão e relatórios — TPrinter, TReport com pré-visualização
  • Internet e IA — WebView2, cliente/servidor HTTP, integração com OpenAI
  • Interface multi-idioma — troca de idioma em tempo de execução via FWString()

Arquitetura

O FWH fica entre o código da sua aplicação Harbour e o sistema operacional Windows. O compilador Harbour traduz o código-fonte .prg em C, que é então compilado pelo compilador C escolhido e linkado com as bibliotecas do FiveWin.

Compiladores Suportados

O FWH é distribuído com bibliotecas pré-compiladas para todos os principais compiladores C compatíveis com o Harbour. Escolha o compilador que melhor se adequa aos requisitos do seu projeto:

Hierarquia de Classes

Todos os objetos visuais do FiveWin herdam de TWindow. Os controles herdam através de TControl, enquanto os diálogos e frames MDI herdam diretamente de TWindow.

Início Rápido: Hello World

A aplicação FiveWin mais simples cria uma janela e a exibe. Os comandos DEFINE WINDOW e ACTIVATE WINDOW tratam toda a parte burocrática do Win32 para você: 

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "Hello World!" ;
      SIZE 600, 400

   ACTIVATE WINDOW oWnd CENTERED ;
      ON INIT MsgInfo( "Welcome to FiveWin!" )

return nil

Salve este código como hello.prg, compile-o com qualquer compilador suportado (veja Sistema de Build), e você terá uma aplicação nativa do Windows.

Exemplo Simples de Diálogo

Diálogos são a principal forma de coletar dados do usuário. Os diálogos do FiveWin suportam tanto coordenadas baseadas em texto quanto em pixels. Aqui está um diálogo típico de entrada de dados: 

#include "FiveWin.ch"

function CustomerDialog()

   local oDlg, oGet1, oGet2, oBtnOk, oBtnCancel
   local cName := Space( 40 )
   local cCity := Space( 30 )

   DEFINE DIALOG oDlg TITLE "Customer Entry" ;
      SIZE 420, 220 PIXEL TRUEPIXEL

   @ 20, 20 SAY "Name:" OF oDlg SIZE 60, 22 PIXEL
   @ 20, 90 GET oGet1 VAR cName OF oDlg SIZE 300, 24 PIXEL

   @ 55, 20 SAY "City:" OF oDlg SIZE 60, 22 PIXEL
   @ 55, 90 GET oGet2 VAR cCity OF oDlg SIZE 300, 24 PIXEL

   @ 100, 200 BUTTON oBtnOk PROMPT "&OK" OF oDlg ;
      SIZE 80, 28 PIXEL ;
      ACTION ( MsgInfo( "Name: " + AllTrim( cName ) ), oDlg:End() )

   @ 100, 290 BUTTON oBtnCancel PROMPT "&Cancel" OF oDlg ;
      SIZE 80, 28 PIXEL CANCEL ;
      ACTION oDlg:End()

   ACTIVATE DIALOG oDlg CENTERED

return nil

Suporte Multi-Idioma

O FiveWin oferece internacionalização integrada através da função FWString(). Você define tabelas de strings para cada idioma e troca em tempo de execução sem precisar recompilar: 

#include "FiveWin.ch"

function Main()

   local oDlg

   // Load language strings from resource or define inline
   // English is the default; switch to Spanish:
   FW_SetLanguage( "ES" )

   DEFINE DIALOG oDlg TITLE FWString( "Customer Entry" ) ;
      SIZE 400, 200 PIXEL TRUEPIXEL

   @ 20, 20 SAY FWString( "Name" ) + ":" OF oDlg SIZE 80, 22 PIXEL
   @ 20, 100 GET oGet VAR cName OF oDlg SIZE 260, 24 PIXEL

   @ 70, 150 BUTTON oBtnOk PROMPT FWString( "Accept" ) OF oDlg ;
      SIZE 80, 28 PIXEL ACTION oDlg:End()

   ACTIVATE DIALOG oDlg CENTERED

return nil

Os idiomas suportados incluem inglês, espanhol, francês, alemão, italiano, português, basco, catalão, holandês, russo e muitos outros. Você também pode adicionar tabelas de idiomas personalizadas em tempo de execução.

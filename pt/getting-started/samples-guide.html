Primeiros Passos: Seus 5 Primeiros Exemplos

Se você é completamente novo no FiveWin, trabalhe estes cinco exemplos na ordem. Cada um se baseia no que você aprendeu no anterior:

#ArquivoO Que Você Aprende
1 start/tutor01.prg Olá Mundo — MsgInfo(), o programa FWH mais simples
2 start/tutor02.prg Janelas — DEFINE WINDOW, ACTIVATE WINDOW
3 start/tutor03.prg Diálogos — DEFINE DIALOG, controles SAY/GET
4 start/tutor04.prg Botões e Ações — criação de botões, cláusulas ACTION, tratamento de eventos
5 start/tutor05.prg Menus — DEFINE MENU, MENUITEM, teclas de atalho

Após estes cinco, continue com tutor06.prg (bancos de dados), tutor07.prg (diálogos avançados) e tutor08.prg (juntando tudo).

Como Compilar os Exemplos

O diretório samples/ contém diversos scripts de build. A abordagem recomendada para novos projetos: 

cd c:\fwteam\samples

REM Build a sample with Borland C++ (32-bit, most common):
buildh.bat start\tutor01

REM Build with MSVC 64-bit:
buildh64.bat start\tutor01

REM The universal build script (auto-detects compiler):
build_new.bat start\tutor01

Cada script de build compila o arquivo .prg com o Harbour, depois compila e linka o código C resultante com o compilador escolhido. Veja a página Sistema de Build para detalhes completos.

Exemplos Intermediários

database/ (19 exemplos)

Operações de banco de dados incluindo navegação em DBF, busca indexada, consultas SQL via ADO/ODBC e integração com grid TXBrowse. Comece com os exemplos básicos de DBF antes de ir para SQL.

Arquivos-ChaveDescrição
dbfbrowse.prgNavegação básica em DBF com TXBrowse
sql*.prgConexões e consultas a bancos de dados SQL
xbrowse*.prgXBrowse avançado com fontes de dados

data/ (16 exemplos)

As classes TDatabase e TDataRow oferecem uma abstração de nível mais alto sobre operações brutas de DBF. Vinculação de dados, campos calculados e navegação de registros.

menus/ (14 exemplos)

Todos os tipos de menu: menus suspensos, menus popup/contexto, barras ribbon, menus da bandeja do sistema. Abrange criação dinâmica de menus, menus com bitmap e menus owner-draw.

report/ (41 exemplos)

Impressão e geração de relatórios com TPrinter e TReport. Inclui exportação para PDF, layouts multi-coluna, códigos de barras, gráficos em relatórios e pré-visualização de impressão.

graphics/ (28 exemplos)

Desenho com GDI+, criação de gráficos, manipulação de bitmaps, carregamento/salvamento de imagens, alpha blending e preenchimentos gradientes. Demonstra as classes Graphics, Pen, Brush e GDIBmp.

mail/ (5 exemplos)

Envio de e-mail via SMTP, recebimento via POP3 e integração com Outlook através de OLE Automation.

ole/ (8 exemplos)

Exemplos de OLE Automation para Microsoft Word, Excel e outros aplicativos COM. Crie documentos, preencha planilhas e controle aplicativos Office programaticamente.

trees/ (5 exemplos)

Exemplos do controle TTreeView: construção de estruturas em árvore, arrastar e soltar entre árvores, carregamento de árvore baseado em XML e renderização personalizada de nós.

comm/ (10 exemplos)

Comunicações por porta serial, controle de modem, integração com leitor de código de barras e comunicação com dispositivos de hardware.

unicode/ (2 exemplos)

Manipulação de strings Unicode, exibição de texto multi-script e conversão UTF-8/UTF-16. Use FW_SetUnicode( .T. ) para habilitar o modo Unicode globalmente.

A maior coleção, cobrindo praticamente todas as funcionalidades do FiveWin. Quando precisar ver como uma classe ou função específica funciona, procure aqui primeiro. Sub-tópicos notáveis:

  • Arrastar e soltar, área de transferência, bandeja do sistema
  • Barras divisoras, painéis de encaixe
  • Visualizadores de imagem, reprodução de vídeo
  • Criptografia, hashing, codificação
  • Operações com arquivos, compressão ZIP/GZIP
  • Pintura personalizada de controles, owner-draw

test/ (317 exemplos)

A suíte de testes do FiveWin e exemplos adicionais. Muitos destes são testes de regressão que também servem como documentação para casos extremos e comportamentos específicos de funcionalidades.

  • vmenu_test.prg — TVMenu + TVItem com ícones 32x32 (TC5ImgList). Compila no FWH64: build_new.bat vmenu_test hb64. Ver Novidades 26.08.
  • testblur.prg — box-blur em imagem (slider 0–100) via Blur() da biblioteca FWH (ribbon.c). Carrega BMP/JPG/PNG com FW_ReadImage; use DEFINE DIALOG … PIXEL TRUEPIXEL para o slider horizontal ficar visível. Build: build_new.bat testblur hb32. Ver Novidades 26.08.

test/fwunit/ — suíte de regressão automatizada

samples/test/fwunit/ é um harness de testes unitários autocontido para a biblioteca FWH (142 asserções). Cobre Unicode, strings CP1252, tradução de codepage, formatação, métricas do sistema, recursos PalBmp, postagem de mensagens WinAPI e controles de UI. Os resultados são gravados em fwunit_results.log via LogFile().

Compilar e executar:

cd samples\test\fwunit
run_all.bat

Ou apenas a suíte: C:\fwteam\samples\build_new.bat run_fwunit hm32 e depois run_fwunit.exe. Execute uma única instância por vez.

bigexe/ (16 exemplos)

Exemplos de aplicações completas e maiores que combinam múltiplas funcionalidades do FiveWin em programas do mundo real. Estude-os para entender como estruturar uma aplicação FWH completa com menus, barras de ferramentas, múltiplos diálogos, acesso a banco de dados e relatórios.

Dicas para Aprender com os Exemplos

  • Leia o código-fonte. Cada arquivo .prg é texto puro. Abra em qualquer editor. O código é a documentação.
  • Modifique e experimente. Altere uma cor, adicione um botão, troque um banco de dados. Recompile e veja o que acontece. O FiveWin compila rápido.
  • Use MsgInfo() para depuração. Insira MsgInfo( cVariable ) em qualquer lugar para inspecionar valores em tempo de execução. É o melhor amigo do desenvolvedor FiveWin.
  • Pesquise em misc/ quando travar. Com 467 exemplos, quase certamente existe um exemplo do que você precisa. Use o recurso "pesquisar em arquivos" do seu editor.
  • Examine os arquivos .ch de inclusão. Comandos como DEFINE WINDOW são traduzidos pelo preprocessador. Verifique FiveWin.ch para ver como se expandem.
  • Faça referência cruzada com a documentação. Quando um exemplo usa uma classe como TXBrowse, abra a documentação do TXBrowse junto com o código.
  • Participe da comunidade. Os fóruns da FiveTech são ativos e acolhedores. Poste suas dúvidas com seu código de exemplo.

Anatomia de um Exemplo FiveWin

Todo exemplo segue a mesma estrutura básica: 

#include "FiveWin.ch"     // Required: loads all FWH commands

function Main()           // Entry point

   local oWnd             // Declare local variables

   DEFINE WINDOW oWnd ... // Create UI objects using commands
   ACTIVATE WINDOW oWnd   // Start the event loop

return nil

A linha #include "FiveWin.ch" é essencial — ela carrega os comandos do preprocessador que traduzem a sintaxe de alto nível como DEFINE WINDOW em chamadas de métodos de classe.

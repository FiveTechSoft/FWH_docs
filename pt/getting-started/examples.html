Índice de Exemplos

O FWH inclui mais de 500 programas de exemplo organizados no diretório samples\. Cada subdiretório aborda uma área específica: Primeiros Passos, Controles UI, Acesso a Dados, impressão, internet, IA, utilitários legados e muito mais. Todos os exemplos podem ser compilados com build_new.bat <name> <variant>.

Compilando os Exemplos

Todos os exemplos são compilados a partir do diretório samples usando o script de compilação unificado:

cd \fwteam\samples
build_new.bat <program> <variant>

// Exemplos:
build_new.bat tutor01 hb32       // Harbour + BCC32
build_new.bat tutor01 hm64       // Harbour + MSVC 64
build_new.bat xbrwedit hb32      // edição inline do TXBrowse
build_new.bat qrcode2 hb32       // códigos QR

Variantes: hb32, hm32, hm64, hg32, hg64, hb64, xb32, xb64, xm64.

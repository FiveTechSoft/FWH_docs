Novidades no FWH 26.05

Esta página resume as mudanças e adições no FiveWin para Harbour/xHarbour versão 26.05 (Maio 2026), em relação à versão anterior 26.03 (Março 2026).

Documentação HTML Abrangente

A mudança mais visível: um site completo de documentação HTML cobrindo mais de 200 classes em três idiomas (inglês, espanhol, português). A documentação inclui diagramas de hierarquia de classes, tabelas de DADOS/Métodos, exemplos de código e um mapa mental interativo de funcionalidades. Disponível em fivetechsoft.github.io/FWH_docs e sincronizado automaticamente a partir do repositório principal via GitHub Actions.

Novas Classes

HFTokenizer — Tokenizador BPE da HuggingFace (IA)

O objetivo das classes de IA do FWH é oferecer a potência dos transformers nas suas aplicações FiveWin — e fazer isso reutilizando, o máximo possível, os recursos do ecossistema da HuggingFace. HFTokenizer é o primeiro marco desse esforço: uma implementação em Harbour puro do tokenizador BPE em nível de bytes da HuggingFace usado pelo GPT-2. Ele carrega um tokenizer.json padrão do Hub da HuggingFace e reproduz a tokenização do GPT-2 bit a bit (p.ex. "hello world" → { 31373, 995 }, com ciclos exatos Decode(Encode(texto))).

Uma ponte tokenizador → Transformer tokeniza texto real, constrói um vocabulário compacto apenas com os tokens que aparecem, treina o Transformer autorregressivo e decodifica os ids gerados de volta para texto — de modo que um modelo pode ser treinado e executado sobre linguagem real em vez de ids de brinquedo. Veja HFTokenizer para o pipeline completo e o roteiro de integração. Exemplos: samples/ai/hftoktest.prg, samples/ai/hflmtest.prg.

TGroupEx — Grupo Tipo Acordeão

Contribuição de Silvio Falconi (Itália). Um grupo recolhível tipo acordeão com um cabeçalho arredondado pintado, ícone opcional e botão de expandir/recolher. Múltiplos painéis TGroupEx podem ser vinculados com LINK GROUPS para se comportar como um acordeão vertical onde abrir um redistribui os demais. O último painel pode opcionalmente esticar para preencher a altura restante. Três temas visuais disponíveis. Exemplo: samples/test/ui/testgrpex.prg.

BWCC 64-bit dll/bwcc64.dll

Uma reimplementação limpa em 64 bits dos Controles Personalizados do Windows da Borland (BWCC) para aplicações de 64 bits. Exporta todas as 45 funções da DLL original de 32 bits:

  • Controles: BorBtn (com glifos predefinidos OK/Cancelar/Sim/Não/Ajuda), BorCheck, BorRadio, BorStatic, BorShade
  • Classes de diálogo: BorDlg, BorDlg_Gray, BorDlg_Std com pincel de padrão cinza pontilhado e manipulação de modelos
  • Glifos BorBtn: resolvidos dos recursos do módulo por ID inteiro, nome decimal ou texto do botão
  • BWCCMessageBox: caixa de mensagem com estilo Borland com ícone BWCC e botões BorBtn

Modo Escuro Nativo

A Visualização Prévia de Impressão (TPreview) agora suporta o modo escuro nativo via FW_SetDarkMode(.T.). O fundo da janela, a barra de ferramentas, a barra de status e o painel de miniaturas escurecem automaticamente sem alterações no código da aplicação. A barra de menu horizontal é escurecida usando uma nova função C FW_DarkMenuBar() que subclassifica a janela de visualização prévia e desenha os itens do menu de nível superior em cores escuras. Os submenus usam o estilo 2013 para menus pop-up escuros.

Correções Notáveis

TTrayIcon no Windows 11

Corrigido o problema do menu pop-up que não aparecia no Windows 11. O Windows 11 se recusa a exibir TrackPopupMenu pertencente a uma janela oculta/desabilitada. Um novo DATA oWndParent armazena a janela principal e Command() a ativa em vez de a janela oculta interna. A posição do cursor retornada por GetCursorPos agora é convertida corretamente para coordenadas de cliente.

Correções de Bugs no Modo Escuro

  • TMenu:SetDarkMode não mais faz recursão infinita. O método agora faz recursão no submenu real via oItem:bAction em vez de oItem:oMenu, que apontava de volta ao pai.
  • TBar:SetDarkMode corrigida a falha em bClrGrad não inicializado quando chamado antes de pintar a barra.

TXBrowse:SetColFromMySQL

Corrigido o erro do método que descartava um argumento de cabeçalho explícito na chamada clássica de dois parâmetros. O analisador de especificação de colunas agora verifica ValType(cHeader) != 'C' antes de sobrescrever, então os cabeçalhos fornecidos pelo usuário são preservados.

Resolução de Glifos de Botão BWCC

Os botões BorBtn genéricos agora exibem bitmaps dos recursos do módulo proprietário, testando três convenções: RT_BITMAP correspondendo ao ID do controle, IDs de bitmap baseados em estado e nome de bitmap correspondendo ao texto do botão. São correspondidos tanto IDs inteiros como nomes decimais, cobrindo as ferramentas de recursos da Borland.

Resumo

FWH 26.05 representa um grande esforço de documentação com mais de 200 novas páginas HTML de referência de classes, combinado com o controle acordeão TGroupEx, suporte completo a BWCC 64 bits, modo escuro nativo para Visualização Prévia de Impressão e múltiplas correções de bugs. A nova documentação é publicada em fivetechsoft.github.io/FWH_docs e é atualizada automaticamente a cada commit.

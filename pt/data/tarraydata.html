TArrayData

Fonte: source/classes/tarrdata.prg

TArrayData fornece uma interface de fonte de dados uniforme sobre arrays Harbour, tabelas DBF e consultas MariaDB/MySQL. Atua como uma ponte entre dados e XBrowse, permitindo que qualquer fonte de dados seja navegada, ordenada, filtrada e editada usando a mesma API. Internamente, os dados são armazenados como um array de linhas com uma definição de estrutura de campos correspondente.

Exemplo: Array para XBrowse com Ordenação

#include "FiveWin.ch"

function Main()

   local aData, aStruct, oWnd, oBrw

   // Define structure
   aStruct := { { "NAME", "C", 20, 0 }, ;
                { "AGE",  "N",  3, 0 }, ;
                { "CITY", "C", 15, 0 } }

   // Sample data
   aData := { { "Alice",   30, "New York" }, ;
              { "Bob",     25, "Boston"   }, ;
              { "Charlie", 35, "Chicago"  } }

   DEFINE WINDOW oWnd TITLE "Array Data Browser" SIZE 500, 300

   @ 0, 0 XBROWSE oBrw OF oWnd AUTOSORT
   oBrw:SetArrayData( aData, aStruct )
   oBrw:CreateFromCode()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TArrayData é a fonte de dados padrão usada por XBrowse quando oBrw:SetArrayData() é chamado. É criado internamente por XBrowse a partir de qualquer array de dados.
  • Quando carregado de DBF, os dados são uma captura instantânea. As alterações não são escritas de volta a menos que SaveData() seja chamado, que atualiza os registos DBF originais.
  • Os construtores fromMYSQL() e fromQuery() requerem um objeto FWMariaConnection e mantêm uma ligação ativa para escrever alterações de volta.
  • A ordenação cria um índice ordenado internamente; a ordem original de aData é preservada em aNatural.

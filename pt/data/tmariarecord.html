FWMariaRecord

Fonte: source/classes/mariarec.prg

Herda de: TDataRow

FWMariaRecord fornece acesso de registro único no estilo ORM a tabelas MariaDB/MySQL. Estende TDataRow para detectar automaticamente a estrutura da tabela, as chaves primárias e as colunas de incremento automático. A classe gerencia o ciclo de vida CRUD completo: carregar um registro do banco de dados, editar valores de campos através do acesso a propriedades do TDataRow, e salvar alterações com upsert automático (INSERT ou UPDATE conforme apropriado).

Métodos

MétodoDescrição
New( oCn, cTable, cWhere )Cria e carrega um registro. Se cWhere for nil ou vazio, cria um registro em branco para nova entrada.
Read( cWhere )Carrega um registro específico identificado pela cláusula WHERE
Blank()Redefine o registro para um modelo em branco para inserir uma nova linha
Load( lBlank )Carrega o registro do servidor (ou modelo em branco se lBlank for .T.)
Save()Salva as alterações usando upsert automático: INSERT se novo, UPDATE se existente
MakePrimaryWhere()Constrói uma cláusula WHERE a partir dos valores atuais dos campos de chave primária

Acesso a Campos

Como FWMariaRecord herda de TDataRow, os valores dos campos são acessíveis através dos métodos FieldGet() e FieldPut() usando nomes de campos ou posições numéricas: 

oRec:FieldGet( "name" )     // pelo nome do campo
oRec:FieldGet( 2 )           // pela posição numérica
oRec:FieldPut( "phone", "555-1234" )  // define pelo nome do campo

Exemplo: Carregar e Atualizar Registro

#include "FiveWin.ch"

function Main()

   local oCn, oRec

   // Conecta ao banco de dados
   oCn := FWMariaConnection():New( "localhost", "mydb", "root", "password" )
   if oCn:nError != 0
      MsgStop( "Connection failed" )
      return nil
   endif

   // --- LER registro existente ---
   oRec := FWMariaRecord():New( oCn, "customers", "id = 1" )
   if oRec:lValidData
      ? "Customer:", oRec:FieldGet( "name" )
      ? "Email:",    oRec:FieldGet( "email" )
      ? "Phone:",    oRec:FieldGet( "phone" )
   endif

   // --- ATUALIZAR registro ---
   oRec:FieldPut( "phone", "555-9999" )
   oRec:FieldPut( "city",  "Madrid" )
   if oRec:Save()
      MsgInfo( "Record updated successfully" )
   endif

   // --- CRIAR novo registro ---
   oRec := FWMariaRecord():New( oCn, "customers" )  // registro em branco
   oRec:FieldPut( "name",  "Jane Smith" )
   oRec:FieldPut( "email", "jane@example.com" )
   oRec:FieldPut( "phone", "555-4321" )
   if oRec:Save()
      MsgInfo( "New customer ID: " + Str( oRec:FieldGet( "id" ) ) )
   endif

   // --- Carrega um registro diferente ---
   oRec:Read( "email = 'jane@example.com'" )
   if oRec:lValidData
      MsgInfo( "Found: " + oRec:FieldGet( "name" ) )
   endif

   oCn:Close()

return nil

Notas

  • FWMariaRecord detecta automaticamente a estrutura da tabela, as chaves primárias e as colunas de incremento automático no primeiro carregamento. Isso habilita o comportamento de upsert inteligente sem configuração manual.
  • O método Save() usa oCn:Upsert() internamente, o que gera uma instrução INSERT ... ON DUPLICATE KEY UPDATE. A detecção da chave primária garante o comportamento correto.
  • Após inserir um novo registro com uma chave primária de incremento automático, o novo ID é recuperado automaticamente e armazenado nos dados do registro.
  • Os campos de caractere são preenchidos até o tamanho definido quando o modo Unicode está ativo (controlado por oCn:lUnicode).

TSqlError

Fonte: source/classes/sqlerror.prg

Classe independente

TSqlError encapsula informações de erro SQL do ODBC. Captura detalhes do erro nos níveis dos handles de ambiente, conexão e statement, fornecendo acesso estruturado aos códigos nativos de estado SQL, mensagens de erro e tipos de erro. É utilizada internamente pela classe TODBC e pode ser usada diretamente para tratamento de erros personalizado.

Membros DATA Principais

DATATipoDescrição
hErrEnvHandleHandle de ambiente ODBC onde o erro ocorreu
hErrDbcHandleHandle de conexão ODBC onde o erro ocorreu
hErrStmtHandleHandle de statement ODBC onde o erro ocorreu
cClassErrorCaractereCódigo de classe do estado SQL (ex.: "42S02" para tabela não encontrada)
nTypeNuméricoCódigo numérico do tipo de erro
cMsgErrorCaractereMensagem de erro legível por humanos

Métodos

MétodoDescrição
New( hEnv, hDbc )Cria um novo objeto TSqlError; captura erros dos handles de ambiente e conexão
Init()Inicializa o objeto de erro e recupera os registros de diagnóstico
GenerateError( hStmt )Captura detalhes do erro a partir de um handle de statement após uma operação SQL falha
CreateError( cClass, nType, cMsg )Cria um erro sintético com classe, tipo e mensagem explícitos
ClassError()Retorna o código de classe do estado SQL
Type()Retorna o código numérico do tipo de erro
MsgError()Retorna a mensagem de erro legível por humanos

Exemplo: Detectar e Exibir Erro SQL

#include "FiveWin.ch"

function Main()

   local oOdbc, oErr

   oOdbc := TODBC():New( "MyDSN", "user", "pass" )

   if ! oOdbc:lSuccess
      // Cria e exibe o erro
      oErr := TSqlError():New( oOdbc:hEnv, oOdbc:hDbc )
      oErr:Init()

      ? "SQL Error:"
      ? "  Class:", oErr:ClassError()
      ? "  Type:",  oErr:Type()
      ? "  Message:", oErr:MsgError()

      MsgStop( oErr:MsgError(), "ODBC Error: " + oErr:ClassError() )
   endif

return nil

Notas

  • TSqlError utiliza as chamadas de API ODBC SQLError() / SQLGetDiagRec() para recuperar informações de diagnóstico dos diversos handles envolvidos em uma operação que falhou.
  • O cClassError contém o código SQLSTATE padrão (string de 5 caracteres) definido pelos padrões ODBC e SQL.
  • GenerateError( hStmt ) deve ser chamado imediatamente após a falha do statement SQL, antes de quaisquer outras chamadas ODBC que possam sobrescrever as informações de diagnóstico.
  • Use CreateError() para gerar objetos TSqlError personalizados com mensagens de erro definidas pela aplicação para cenários de erro não-ODBC.

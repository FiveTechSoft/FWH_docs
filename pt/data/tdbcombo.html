TDBCombo

Fonte: source/classes/dbcombo.prg

Herda de: TComboBox

TDBCombo é um ComboBox com reconhecimento de banco de dados que exibe valores de um campo DBF e pode retornar um valor diferente para a variável vinculada. Ele suporta busca incremental conforme o usuário digita e pode preencher automaticamente seus itens a partir do banco de dados quando nenhum array explícito é fornecido.

Membros DATA Principais

DATATipoDescrição
cAliasCharacterAlias da área de trabalho para a tabela do banco de dados (padrão: alias atual)
cFldListCharacterNome do campo cujos valores são exibidos no combo
cFldItemCharacterNome do campo cujo valor é retornado para a variável vinculada
aListArrayArray de strings de exibição mostradas na lista suspensa
aItemsArrayArray de valores de retorno correspondentes às entradas de aList
cSearchKeyCharacterBuffer de busca incremental para navegação pelo teclado

Exemplo: Combo Vinculado ao Campo Cidade do Cliente

#include "FiveWin.ch"

function Main()

   local oWnd, oCombo, cCity := Space( 20 )

   use Customer shared new
   index on field->city to tmpCity

   DEFINE WINDOW oWnd TITLE "Demo TDBCombo" SIZE 400, 150

   @ 30, 30 DBCOMBO oCombo VAR cCity ;
      ITEMS FIELD->city ;
      OF oWnd ;
      SIZE 150, 120

   ACTIVATE WINDOW oWnd CENTERED

   use

return nil

Notas

  • TDBCombo pode exibir o valor de um campo enquanto retorna um valor diferente. Por exemplo, mostrar nomes de departamentos (cFldList) mas retornar os IDs dos departamentos (cFldItem).
  • A busca incremental é suportada: digitar caracteres filtra a lista. Pressionar Espaço reinicia o buffer de busca.
  • Quando nem aItems nem aList são fornecidos, o construtor chama Fill() para preencher automaticamente a partir dos campos do banco de dados.
  • Os dados do combo podem ser atualizados manualmente com Refill() quando os registros do banco de dados subjacente mudam.

TTable / TAccTable

Fonte: source/classes/ttable.prg, source/classes/tacctbl.prg

TTable fornece o gerenciamento de metadados de tabelas DBF — armazena o nome da tabela, o alias, as definições de campos e a lista de índices, e pode criar ou importar estruturas DBF. TAccTable gerencia tabelas de aceleradores do Windows, permitindo que atalhos de teclado (tecla virtual + estado de modificadores) sejam associados a IDs de controles.

TTable — Metadados de Tabela DBF

Membros DATA Principais

DATATipoDescrição
cNameCharacterNome do arquivo da tabela (sem extensão)
cAliasCharacterAlias usado ao abrir a tabela
lSharedLogicalAbrir a tabela em modo compartilhado
aFieldsArrayArray de objetos TField que definem a estrutura
aIndexesArrayArray de definições de índices

Métodos

MétodoDescrição
New( cName, cAlias, lShared, cComments )Cria um novo descritor de metadados de tabela
Import( cDbfFile )Importa a estrutura de campos a partir de um arquivo DBF existente
Create( cPath )Cria fisicamente o arquivo DBF no disco a partir das definições de campos armazenadas

TAccTable — Tabela de Aceleradores

Membros DATA Principais

DATATipoDescrição
nHandleNumericHandle da tabela de aceleradores do Windows (retornado por SetAccTable)
aItemsArrayArray de itens, cada um é { nVirtKey, nVKState, nId }

Métodos

MétodoDescrição
New()Cria uma tabela de aceleradores vazia
Add( nVK, nState, nId )Adiciona uma entrada de acelerador (tecla virtual + estado de modificadores + ID de comando)
Del( nVK, nState )Remove uma entrada de acelerador pela tecla virtual e estado
Activate()Define esta tabela de aceleradores como ativa para a thread chamadora
DeActivate()Restaura a tabela de aceleradores anterior (passa nil para SetAccTable)
End()Destrói a tabela de aceleradores e a desativa se estiver ativa no momento

Exemplo: Criar Tabela e Acelerador

#include "FiveWin.ch"

function Main()

   local oTable, oAccel

   // TTable: define e cria um DBF
   oTable := TTable():New( "customers", "CUST", .F. )
   AAdd( oTable:aFields, TField():New( "customers", 1, .F., "NAME", "C", 40, 0 ) )
   AAdd( oTable:aFields, TField():New( "customers", 2, .F., "CITY", "C", 30, 0 ) )
   oTable:Create( "c:\data" )

   // TAccTable: define atalhos de teclado
   oAccel := TAccTable():New()
   oAccel:Add( VK_F2, 0, 101 )
   oAccel:Add( VK_F3, 0, 102 )
   oAccel:Add( VK_S, MOD_CONTROL, 103 )
   oAccel:Activate()

return nil

Notas

  • TTable não gerencia operações em nível de registro; serve exclusivamente para a definição de estrutura e a criação física do DBF.
  • O método Import() lê o cabeçalho de um DBF existente e preenche aFields com instâncias de TField.
  • TAccTable encapsula a API SetAccTable() do Windows. O estado de modificadores (nVKState) pode ser uma combinação de MOD_CONTROL, MOD_ALT, MOD_SHIFT, etc.
  • Chame Activate() para registrar a tabela; o handle é armazenado em nHandle para posterior desativação.
  • Apenas uma tabela de aceleradores pode estar ativa por vez em cada thread.

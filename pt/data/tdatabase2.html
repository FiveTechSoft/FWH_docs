TDBase

Fonte: source/classes/tdbase.prg

Classe autônoma

TDBase representa metadados de um banco de dados SQL, armazenando o nome do banco e até oito definições de relação com suas cláusulas INTO correspondentes. É utilizada pelo motor de consultas e relatórios SQL para resolver os relacionamentos entre tabelas em instruções SELECT.

Membros DATA Principais

DATATipoDescrição
cDatabaseCharacterNome do banco de dados SQL
aRelationsArrayArray de definições de relação (até 8)
aIntosArrayArray de definições de cláusula INTO (até 8)

Métodos

MétodoDescrição
New( cDb, cRel01, cRel02, cRel03, cRel04, cRel05, cRel06, cRel07, cRel08, cInto01, cInto02, cInto03, cInto04, cInto05, cInto06, cInto07, cInto08 )Cria um novo objeto de metadados do banco de dados com até 8 pares relação/INTO

Exemplo: Definir Relações do Banco de Dados

#include "FiveWin.ch"

function Main()

   local oDb

   // Define um banco de dados "sales" com duas relações
   oDb := TDBase():New( "sales", ;
      "CUSTOMER.ID = ORDERS.CUSTID", "ORDERS.ID = ITEMS.ORDERID", , , , , , , ;
      "CUSTOMERS", "ORDER_ITEMS" )

   ? "Database:", oDb:cDatabase
   ? "Relation 1:", oDb:aRelations[ 1 ]
   ? "Into 1:", oDb:aIntos[ 1 ]
   ? "Relation 2:", oDb:aRelations[ 2 ]
   ? "Into 2:", oDb:aIntos[ 2 ]

return nil

Notas

  • TDBase é um contêiner leve de metadados, usado principalmente para configurar o gerador de consultas SQL com os relacionamentos entre tabelas.
  • Podem ser definidos até oito pares relação/INTO. As posições não utilizadas devem ser deixadas vazias (omitidas).
  • O array aRelations armazena strings de condição JOIN (ex.: "TABLE1.COL = TABLE2.COL"), enquanto aIntos armazena os apelidos (aliases) ou nomes das tabelas de destino.
  • Esta classe é normalmente usada internamente pelo motor de relatórios, e não diretamente no código da aplicação.

TDict - Dicionário de Dados

Fonte: source/classes/tdict.prg

Classe independente

TDict implementa um sistema de dicionário de dados que gerencia uma coleção de tabelas de banco de dados (DBFs), menus e relatórios. Ele armazena metadados em mais de 15 tabelas de sistema (oTables) que abrangem definições de tabelas, definições de campos, índices, relações, menus, relatórios, usuários e segurança. O dicionário pode construir automaticamente as tabelas de sistema ausentes (lAutoBuild) e fornece métodos para criar tabelas, abrir bancos de dados, carregar menus, executar relatórios e importar arquivos.

Principais Membros DATA

DATATipoDescrição
cPathCharacterCaminho base onde os arquivos do dicionário são armazenados
lAutoBuildLogical.T. para criar automaticamente as tabelas de sistema ausentes
oTablesArrayArray de mais de 15 objetos TDatabase para as tabelas de sistema

Métodos

MétodoDescrição
New( cPath )Cria um novo dicionário de dados no caminho indicado
Activate()Abre todas as tabelas de sistema e ativa o dicionário
CreateTable( cTbl )Cria uma nova tabela de usuário definida no dicionário
OpenDataBase( cDbName )Abre um banco de dados nomeado e todas as suas tabelas
OpenTable( cTbl )Abre uma tabela específica pelo nome
LoadMenu( cMenu )Carrega uma definição de menu do dicionário; retorna TMenu
Report( cReport )Executa um relatório definido no dicionário
Import( cMask )Importa arquivos que correspondem a uma máscara de arquivo para o dicionário
LoadWebBrowse( cTbl )Carrega a configuração de navegação web para uma tabela
LoadWebRecord( cTbl )Carrega a configuração do formulário de registro web para uma tabela
WebRecSave( cTbl )Salva a configuração de registro web para uma tabela

Exemplo: Criar e Usar um Dicionário

#include "FiveWin.ch"

function Main()

   local oDict

   // Cria um dicionário de dados no diretório de dados
   oDict := TDict():New( ".\data\" )
   oDict:lAutoBuild := .T.
   oDict:Activate()

   // Cria uma nova tabela de usuário
   oDict:CreateTable( "INVOICES" )

   // Abre um banco de dados
   oDict:OpenDataBase( "SALES" )

   // Carrega um menu
   DEFINE WINDOW oWnd TITLE "Dictionary Demo" SIZE 800, 600
   oDict:LoadMenu( "MAIN" ):Activate( oWnd )

   // Executa um relatório
   oDict:Report( "CUSTOMER_LIST" )

   ACTIVATE WINDOW oWnd

return nil

Notas

  • O dicionário mantém tabelas de sistema para definições de tabelas (_TABLES.DBF), definições de campos (_FIELDS.DBF), índices (_INDEXES.DBF), relações, menus, relatórios, usuários, grupos e permissões.
  • Quando lAutoBuild é .T., qualquer tabela de sistema ausente é criada automaticamente quando Activate() é chamado.
  • Use CreateTable() para materializar uma tabela definida pelo usuário com base nos metadados do dicionário. A estrutura da tabela é lida da tabela de sistema _FIELDS.
  • LoadMenu() lê as definições de menu do dicionário e retorna um objeto TMenu totalmente construído e pronto para ativação.

TDbOdbc / TDbOdbcDirect

Fonte: source/classes/tdbodbc.prg / source/classes/tdbodbcd.prg

TDbOdbc fornece acesso ODBC compatível com RDD a bases de dados SQL. Encapsula handles de instruções ODBC e apresenta uma interface semelhante a DBF (GoTop, Skip, FieldGet, etc.), tornando possível navegar em tabelas SQL usando os mesmos padrões de navegação que ficheiros DBF. TDbOdbcDirect é uma alternativa mais leve que funciona diretamente com ligações ODBC compatíveis com TDatabase sem a camada completa de emulação RDD.

Exemplo: Navegação em Tabela ODBC

#include "FiveWin.ch"

function Main()

   local oOdbc, oTable, oWnd, oBrw

   oOdbc := TODBC():New( "MyDB" )  // ODBC data source name

   if oOdbc == nil
      MsgStop( "Cannot connect to ODBC source" )
      return nil
   endif

   oTable := TDbOdbc():New( "Employees", oOdbc )

   if oTable:lError
      MsgStop( "Cannot open table" )
      return nil
   endif

   DEFINE WINDOW oWnd TITLE "Employees from ODBC"

   @ 0, 0 XBROWSE oBrw OF oWnd AUTOSORT
   oBrw:SetRdd()
   oBrw:SetADO( oTable )     // link TDbOdbc to XBrowse
   oBrw:CreateFromCode()

   ACTIVATE WINDOW oWnd MAXIMIZED

   oTable:End()

return nil

Notas

  • TDbOdbc emula a interface RDD DBF sobre ODBC, suportando navegação, edição, filtragem e ordenação usando construções SQL de forma transparente.
  • As chaves primárias são auto-detetadas via SQLPrimaryKeys() e usadas para instruções UPDATE/DELETE.
  • O método GenDbf() permite exportar qualquer conjunto de resultados ODBC para um ficheiro DBF para uso offline.
  • TDbOdbcDirect é mais leve e adequado para padrões de acesso SQL diretos só de leitura ou simples, sem emulação RDD completa.
  • Ambas as classes funcionam com o objeto de ligação TODBC para gestão de fontes de dados ODBC.

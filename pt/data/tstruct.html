TStruct / TField / TIndex

Fonte: source/classes/tstruct.prg, source/classes/tfield.prg, source/classes/tindex.prg

Estas três classes utilitárias fornecem representações orientadas a objetos para estruturas de memória ao estilo C (TStruct), definições de campos DBF (TField) e definições de índices DBF (TIndex). São usadas ao trabalhar com estruturas de dados de baixo nível, definir esquemas DBF programaticamente ou criar ficheiros de índice a partir de código Harbour.

TStruct - Construtor de Estruturas C

TStruct modela uma estrutura da linguagem C na memória Harbour. Mantém um buffer binário e uma lista de definições de membros, permitindo que membros sejam adicionados e acedidos por nome ou posição.

Membros DATA

DATATipoDescrição
cBufferCaractereBuffer de memória binário bruto
aMembersArrayArray de { cName, nType, nLen, nOffset }

Constantes de Tipo

ConstanteDescrição
BYTE / CHARInteiro sem sinal de 1 byte
WORD / INT / BOOLInteiro com sinal de 2 bytes
LONG / DWORD / PTR / LPSTRInteiro com sinal de 4 bytes ou ponteiro
LONGLONGInteiro com sinal de 8 bytes

Métodos

MétodoDescrição
New()Criar estrutura vazia
AddMember( cName, nType, nLen )Adicionar um membro com tipo e comprimento opcional
SetMember( nMember, uData )Definir valor do membro por índice
GetMember( nMember )Obter valor do membro por índice
SizeOf()Retornar comprimento total do buffer em bytes

Exemplo: Definir e Usar uma Estrutura C

#include "FiveWin.ch"
#include "Struct.ch"

function Main()

   local oStru := TStruct():New()

   // Add members: name, type, length
   oStru:AddMember( "nId",   LONG,    4 )
   oStru:AddMember( "cName", CHAR,   20 )
   oStru:AddMember( "nAge",  BYTE      )   // defaults to 1 byte

   ? "Size:", oStru:SizeOf()               // 25

   // Set values
   oStru:SetMember( 1, 12345 )
   oStru:SetMember( 2, "John Smith" )

   // Read them back
   ? oStru:GetMember( 1 )                  // 12345
   ? oStru:GetMember( 2 )                  // "John Smith"

return nil

TField - Definição de Campo DBF

TField é um contentor de dados simples que representa um único campo DBF. Armazena todas as propriedades necessárias para definir um campo na estrutura de um ficheiro DBF.

Membros DATA

DATATipoDescrição
cDbfNameCaractereNome do ficheiro DBF
nOrderNuméricoPosição do campo (base 1)
lIndexedLógicoSe o campo é indexado
cNameCaractereNome do campo
cTypeCaractereTipo de campo (C, N, D, L, M)
nWidthNuméricoLargura do campo
nDecimalNuméricoCasas decimais para campos numéricos
cCommentsCaractereDescrição opcional do campo

Método

MétodoDescrição
New( cDbfName, nOrder, lIndexed, cName, cType, nWidth, nDecimal, cComments )Criar uma definição de campo

Exemplo: Definir um Campo DBF

#include "FiveWin.ch"

function Main()

   local oFld

   oFld := TField():New( "CUSTOMER.DBF", 1, .F., "CODE", "C", 5, 0, "Customer code" )

   ? oFld:cName     // "CODE"
   ? oFld:cType     // "C"
   ? oFld:nWidth    // 5

return nil

TIndex - Definição de Índice DBF

TIndex representa uma definição de índice para um ficheiro DBF. Pode criar o ficheiro de índice real em disco (formato CDX ou NTX) a partir das propriedades da definição.

Membros DATA

DATATipoDescrição
cDbfNameCaractereNome do ficheiro DBF a indexar
cNameCaractereNome do ficheiro de índice (sem extensão)
cTagCaractereNome da tag para índices CDX
cExpressionCaractereExpressão da chave de índice
lUniqueLógicoFlag de índice único
lDescendingLógicoFlag de ordem descendente
cCommentsCaractereComentários opcionais
cTypeCaractereTipo de índice ("CDX" padrão, ou "NTX")

Métodos

MétodoDescrição
New( cDbfName, cName, cTag, cExpression, lUnique, lDescending, cComments )Criar uma definição de índice
Create( cPath )Criar o ficheiro de índice em disco no caminho dado

Exemplo: Criar um Índice

#include "FiveWin.ch"

function Main()

   local oIdx

   // Define an index on CUSTOMER.DBF by the CODE field
   oIdx := TIndex():New( "CUSTOMER.DBF", "CODE_IDX", "CODE", "CODE", .F., .F., "Index by code" )

   // Create the index file
   oIdx:Create( "C:\data\" )

return nil

Notas

  • TStruct usa NumToBin() / BinToNum() do Harbour internamente para serialização do buffer. Suporta acesso a membros por índice numérico e por nome (via manipulador de erros).
  • TField é principalmente um contentor de dados e não modifica o ficheiro DBF em si. É útil para construção programática de esquemas e gestão de metadados.
  • TIndex:Create() abre o DBF, executa o comando INDEX e fecha o ficheiro. Suporta formatos CDX (padrão) e NTX com base no membro cType.

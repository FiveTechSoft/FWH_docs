FWMariaConnection + FRecSet

Fonte: source/internal/fwmaria.prg

FWMariaConnection fornece uma conexão nativa abrangente com servidores MariaDB e MySQL através da biblioteca cliente C libmariadb.dll. A classe complementar FRecSet encapsula conjuntos de resultados SQL com recursos de navegação, paginação, ordenação e edição. Juntas, elas formam a espinha dorsal da camada de acesso a dados MariaDB/MySQL do FiveWin.

FWMariaConnection

A classe de conexão gerencia conexões TCP/IP com servidores MariaDB/MySQL. Ela suporta pool de conexões, reconexão automática, prepared statements, transações, backup/restore e execução completa de DDL/DML.

FRecSet - Conjunto de Resultados MariaDB

FRecSet fornece navegação orientada a registros sobre um conjunto de resultados MariaDB/MySQL. Ele suporta paginação (controlada por nPageSize), acesso a nível de campo, ordenação, edição e integração com o XBrowse para exibição em grade.

Exemplo: Conectar e Navegar

#include "FiveWin.ch"

function Main()

   local oCn, oRs, oWnd, oBrw

   // Conectar ao MariaDB
   oCn := FWMariaConnection():New( ;
      "localhost", ;     // servidor
      "mydb", ;          // banco de dados
      "root", ;          // usuário
      "password", ;      // senha
      3306 )             // porta

   if oCn:nError != 0
      MsgStop( "Connection failed: " + oCn:cError )
      return nil
   endif

   // Abrir um conjunto de resultados
   oRs := oCn:RowSet( "SELECT id, name, email, city FROM customers ORDER BY name" )

   // Navegar pelos registros
   oRs:GoTop()
   while !oRs:Eof()
      ? oRs:FieldGet( "id" ), oRs:FieldGet( "name" ), oRs:FieldGet( "email" )
      oRs:Skip( 1 )
   end

   // Exibir no XBrowse
   DEFINE WINDOW oWnd TITLE "Customers"

   @ 0, 0 XBROWSE oBrw OF oWnd
   oRs:SetXBrowse( oBrw )
   oBrw:CreateFromCode()

   ACTIVATE WINDOW oWnd MAXIMIZED

   oRs:Close()
   oCn:Close()

return nil

Notas

  • FWMariaConnection usa a biblioteca nativa MariaDB Connector/C (libmariadb.dll ou libmariadb64.dll). A DLL deve estar disponível no caminho da aplicação ou no PATH do sistema.
  • FRecSet usa paginação automática com tamanho de página padrão de 1000 linhas. Defina nPageSize para ajustar o uso de memória em conjuntos de resultados grandes.
  • O método SetOrder() reemite a consulta com uma cláusula ORDER BY, preservando as condições WHERE e a paginação.
  • Use oCn:ValToSQL() para escapar valores com segurança em strings SQL dinâmicas, prevenindo injeção de SQL.
  • O suporte a transações requer tabelas InnoDB (ou outras transacionais). Use BeginTransaction(), CommitTransaction() e RollBack().

FWMariaConnection + FRecSet

Source: source/internal/fwmaria.prg

FWMariaConnection provides a comprehensive native connection to MariaDB and MySQL servers through the libmariadb.dll C client library. The companion FRecSet class wraps SQL result sets with navigation, paging, sorting, and editing capabilities. Together they form the backbone of FiveWin's MariaDB/MySQL data access layer.

FWMariaConnection

The connection class manages TCP/IP connections to MariaDB/MySQL servers. It supports connection pooling, automatic reconnection, prepared statements, transactions, backup/restore, and full DDL/DML execution.

FRecSet - MariaDB Result Set

FRecSet provides record-oriented navigation over a MariaDB/MySQL result set. It supports paging (controlled by nPageSize), field-level access, sorting, editing, and integration with XBrowse for grid display.

Example: Connect and Browse

#include "FiveWin.ch"

function Main()

   local oCn, oRs, oWnd, oBrw

   // Connect to MariaDB
   oCn := FWMariaConnection():New( ;
      "localhost", ;     // server
      "mydb", ;          // database
      "root", ;          // user
      "password", ;      // password
      3306 )             // port

   if oCn:nError != 0
      MsgStop( "Connection failed: " + oCn:cError )
      return nil
   endif

   // Open a result set
   oRs := oCn:RowSet( "SELECT id, name, email, city FROM customers ORDER BY name" )

   // Navigate records
   oRs:GoTop()
   while !oRs:Eof()
      ? oRs:FieldGet( "id" ), oRs:FieldGet( "name" ), oRs:FieldGet( "email" )
      oRs:Skip( 1 )
   end

   // Display in XBrowse
   DEFINE WINDOW oWnd TITLE "Customers"

   @ 0, 0 XBROWSE oBrw OF oWnd
   oRs:SetXBrowse( oBrw )
   oBrw:CreateFromCode()

   ACTIVATE WINDOW oWnd MAXIMIZED

   oRs:Close()
   oCn:Close()

return nil

Notes

  • FWMariaConnection uses the MariaDB Connector/C native library (libmariadb.dll or libmariadb64.dll). The DLL must be available in the application path or system PATH.
  • FRecSet uses automatic paging with the default page size of 1000 rows. Set nPageSize to adjust memory usage for large result sets.
  • The SetOrder() method re-issues the query with an ORDER BY clause, preserving the WHERE conditions and pagination.
  • Use oCn:ValToSQL() to safely escape values in dynamic SQL strings, preventing SQL injection.
  • Transaction support requires InnoDB (or other transactional) tables. Use BeginTransaction(), CommitTransaction(), and RollBack().

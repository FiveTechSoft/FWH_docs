TDataRow

Fonte: source/classes/datarow.prg

Classe independente

TDataRow é um editor de registros de dados que fornece uma interface conveniente para visualizar e editar registros individuais de uma fonte de dados. Funciona com áreas de trabalho DBF, recordsets ADO, arrays e hashes, tornando-se uma ferramenta versátil para operações em nível de registro. TDataRow mantém uma cópia original dos dados e pode detectar modificações.

Membros DATA Principais

DATATipoDescrição
aDataArrayArray dos valores atuais dos campos
aOrgArrayArray dos valores originais dos campos (para detecção de alterações)
aPromptsArrayArray das strings de prompt/rótulo dos campos
uSourceVariantFonte de dados: alias (N), recordset ADO, array ou hash
cSrcTypeCharacterString do tipo de fonte: "DBF", "ADO", "ARR" ou "HSH"
bSaveBlockBloco de código avaliado ao salvar com sucesso
bValidBlockBloco de código para validação do registro antes de salvar
bEditBlockBloco de código avaliado quando a edição começa

Métodos

MétodoDescrição
New( uSource, cFieldList, lBlank, aInitVals )Cria uma linha de dados a partir de uma fonte e lista de campos opcional
Load( lBlank )Carrega os valores atuais da fonte para aData
Save( lCheck, lSilent )Grava as alterações de volta na fonte; validação opcional
Edit( lReadOnly, lNavigate, cTitle, cMsg )Abre um diálogo para edição interativa do registro
Undo( fld )Reverte um campo ao seu valor original
Copy()Cria uma cópia dos dados do registro atual
Paste( hRec )Cola um registro copiado anteriormente no buffer
Modified( fld )Verifica se um campo (ou qualquer campo) foi modificado
FieldGet( fld )Obtém o valor de um campo por nome ou posição
FieldPut( fld, uVal )Define o valor de um campo por nome ou posição

Exemplo: Editar o Registro DBF Atual

#include "FiveWin.ch"

function Main()

   local oDb, oRow

   DATABASE oDb FILE "customers.dbf" DRIVER "DBFCDX" SHARED

   oDb:GoTop()

   // Cria uma linha de dados para o registro atual
   oRow := TDataRow():New( oDb:nArea )

   // Abre o diálogo de edição
   if oRow:Edit( , , "Edit Customer" )
      // Usuário pressionou OK -- as alterações são salvas automaticamente
      MsgInfo( "Record saved" )
   else
      MsgInfo( "Edit cancelled" )
   endif

   oDb:Close()

return nil

Notas

  • TDataRow adapta-se ao tipo de fonte automaticamente. Para fontes DBF, passe o número ou alias da área de trabalho; para ADO, passe o objeto recordset; para arrays ou hashes, passe a referência diretamente.
  • O método Edit() cria um diálogo padrão com controles TGet para cada campo. Quando lReadOnly é .T., o diálogo exibe os dados sem permitir edições.
  • Use bSave para executar lógica personalizada após salvar com sucesso, como registro de log ou atualização de controles relacionados.
  • O método Modified() sem argumentos verifica se algum campo foi alterado; com um argumento de campo, verifica um campo específico.
  • Usar lNavigate=.T. em Edit() adiciona botões de navegação (Próximo/Anterior) para mover-se entre registros.

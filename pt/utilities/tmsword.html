FWMSWordDoc

Fonte: source/classes/fwmsword.prg

FWMSWordDoc gera documentos do Microsoft Word de forma programática via OLE Automation. Ele encapsula o modelo de objetos do Word para criar, formatar e salvar documentos com texto, tabelas, imagens, formas e controle de layout de página. A classe fornece uma superfície de API compatível com TPrinter, permitindo que código orientado a impressão produza saída no Word com alterações mínimas.

Exemplo: Gerar Documento do Word com Tabela

#include "FiveWin.ch"

function Main()

   local oWord

   oWord := FWMSWordDoc():New( "report.docx" )
   if oWord == nil
      MsgStop( "Microsoft Word is not available" )
      return nil
   endif

   oWord:Say( 1, 1, "Sales Report", oWord:oWord:Selection:Font,;
              nil, 0, nil, TA_CENTER )

   oWord:Line( 2, 1, 2, 100, 1, "CM" )

   oWord:Box( 4, 1, 8, 100, 1, RGB( 200, 200, 255 ), , "CM" )

   oWord:PrintImage( 10, 1, "logo.bmp", 40, 20, .T., , , , "MM" )

   oWord:End()

return nil

Notas

  • FWMSWordDoc requer que o Microsoft Word esteja instalado na máquina de destino. O construtor New() retorna nil se o objeto OLE não puder ser criado.
  • A classe é projetada com uma API compatível com TPrinter: Say(), Line(), Box(), PrintImage() e os métodos de conversão de unidades espelham a interface do TPrinter para facilitar a migração.
  • As unidades de coordenadas são gerenciadas via Units2Pix() / Pix2Units(), que aceitam "PIXEL", "INCH", "CM" ou "MM".
  • O método Save() pode exportar para o formato PDF quando o Word 2007 ou posterior (versão 12.0+) é utilizado.
  • Quando lPreview é .T. (o padrão), a janela do Word torna-se visível após End(), permitindo que o usuário revise o documento.

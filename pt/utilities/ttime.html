TTime

Fonte: source/classes/time.prg

TTime representa um valor de tempo como segundos desde a meia-noite. Fornece aritmética de tempo (somar/subtrair horas, minutos, segundos), formatação para "HH:MM:SS" e a capacidade de ler o relógio do sistema ou gravar o tempo de volta no relógio do sistema. Internamente, o tempo é armazenado como um único valor numérico (nTime) módulo 86400.

Principais Membros DATA

DATATipoDescrição
nTimeNumericSegundos desde a meia-noite (0-86399)

Métodos Principais

MétodoDescrição
New( nHours, nMinutes, nSeconds )Cria um TTime a partir de valores de hora/minuto/segundo. Todos têm padrão 0
System()Inicializa a partir da hora atual do relógio do sistema
AddHours( n )Adiciona n horas ao tempo armazenado
AddMinutes( n )Adiciona n minutos ao tempo armazenado
AddSeconds( n )Adiciona n segundos ao tempo armazenado
cAdd( nH, nM, nS )Adiciona uma duração de tempo e retorna o resultado como uma string formatada "HH:MM:SS"
cSub( nH, nM, nS )Subtrai uma duração de tempo (ou outro objeto TTime) e retorna o resultado formatado
cGetTime()Retorna o tempo armazenado formatado como "HH:MM:SS"
SysChange()Define o relógio do sistema com o valor de tempo armazenado

Exemplo: Aritmética de Tempo

#include "FiveWin.ch"

function Main()

   local oTime, cResult

   // Cria um tempo: 09:30:00
   oTime := TTime():New( 9, 30, 0 )

   // Adiciona 2 horas e 15 minutos
   cResult := oTime:cAdd( 2, 15, 0 )
   MsgInfo( cResult )   // --> "11:45:00"

   // Subtrai 45 minutos
   cResult := oTime:cSub( 0, 45, 0 )
   MsgInfo( cResult )   // --> "11:00:00"

   // Obtém a hora atual do sistema
   oTime:System()
   MsgInfo( "Current time: " + oTime:cGetTime() )

return nil

Notas

  • Todas as operações aritméticas aplicam módulo 86400 (segundos em um dia). Valores que excedem 24 horas dão a volta.
  • cAdd() e cSub() modificam o nTime interno e retornam a nova string formatada.
  • cSub() pode aceitar valores numéricos de hora/minuto/segundo ou outro objeto TTime como seu primeiro parâmetro.
  • SysChange() chama SysTime( ::nTime ) para gravar o tempo no relógio do sistema; isso pode exigir privilégios apropriados.

TBackup + TRestore

Fontes: source/classes/tbackup.prg, source/classes/trestore.prg

Classes independentes

TBackup e TRestore fornecem funcionalidade de backup e restauração de dados, suportando três tipos de armazenamento: cópia normal de arquivos, compressão ZIP e Windows Backup (NTBackup). TBackup cuida da criação do backup enquanto TRestore gerencia o processo de restauração, incluindo pontos de restauração do sistema.

TBackup Principais Membros DATA

DATATipoDescrição
nTypeNuméricoTipo de backup: BK_NORMAL (cópia de arquivo), BK_ZIP (comprimido), BK_WIN (Windows Backup)
cSourceCaractereCaminho de origem ou especificação de arquivo
cTargetDirCaractereDiretório de destino do backup
aFilesArrayArray de nomes de arquivos a incluir

Métodos de TBackup

MétodoDescrição
New( nType, cSrc, cDst, nLang, cZip, aFiles )Cria um novo objeto de backup com tipo, origem, destino, idioma, nome do ZIP e lista de arquivos
Execute()Executa a operação de backup conforme o tipo selecionado
MakeZip()Cria um arquivo de backup no formato ZIP
ExecuteWinBackup()Executa a operação do Windows NTBackup

TRestore Principais Membros DATA

DATATipoDescrição
nTypeNuméricoTipo de restauração: RES_NORMAL, RES_ZIP, RES_WIN
lOverwriteLógicoSobrescrever arquivos existentes durante a restauração

Métodos de TRestore

MétodoDescrição
New( nType, cSrc, cDst, nLang, aFiles, lOver )Cria um novo objeto de restauração com tipo, caminhos, idioma, lista de arquivos e flag de sobrescrita
Execute()Executa a operação de restauração
MakeCopy()Restaura arquivos por cópia direta de arquivo
UnZipData()Extrai arquivos de um arquivo de backup ZIP
CreateRestorePoint( cDesc )Cria um ponto de Restauração do Sistema do Windows com a descrição fornecida

Comandos

DEFINE BACKUP oZip TYPE BK_ZIP ;
   SOURCE cSrc TARGET cDst ZIPNAME cZip FILES aFiles

Exemplo: Backup e Restauração ZIP

#include "FiveWin.ch"

function Main()

   local oBackup, oRestore
   local aFiles := { "data1.dbf", "data2.dbf", "data3.dbf" }

   DEFINE BACKUP oBackup TYPE BK_ZIP ;
      SOURCE "C:\Data" TARGET "D:\Backup" ;
      ZIPNAME "backup.zip" FILES aFiles

   if oBackup:Execute()
      MsgInfo( "Backup completed successfully" )
   else
      MsgStop( "Backup failed" )
   endif

   oRestore := TRestore():New( RES_ZIP, "D:\Backup\backup.zip", ;
      "C:\Data\Restored", , aFiles, .T. )

   if oRestore:Execute()
      MsgInfo( "Restore completed successfully" )
   endif

return nil

Notas

  • BK_NORMAL realiza uma cópia simples de arquivos da origem para o diretório de destino.
  • BK_ZIP comprime os arquivos de origem em um único arquivo ZIP usando o nome de arquivo ZIP especificado.
  • BK_WIN delega ao utilitário Windows NTBackup para backups em nível de sistema.
  • Use CreateRestorePoint() antes de operações destrutivas para permitir a reversão do sistema.
  • O array aFiles pode conter nomes de arquivos individuais ou especificações com curingas.

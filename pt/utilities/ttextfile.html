TTxtFile - Arquivo de Texto Orientado a Linhas

Fonte: source/classes/ttxtfile.prg

TTxtFile herda de TFile e fornece leitura e escrita de arquivos de texto orientados a linhas com suporte a seções no estilo INI. Ele armazena o arquivo inteiro em memória e oferece navegação baseada em cursor (Advance, Rewind, Skip, GoTo), operações em nível de linha (ReadLine, Add, AppendLn, DelLine, InsLine, RepLine) e acesso a chave/valor de seções INI (GetValue, SetValue).

DATA Members

DATATipoDescrição

Métodos Principais

MétodoDescrição
Advance()Move para a próxima linha. Retorna .T. se bem-sucedido, .F. se estiver no EOF
Rewind()Move para a linha anterior. Retorna .T. se bem-sucedido, .F. se estiver no BOF
Skip( n )Move para frente (positivo) ou para trás (negativo) n linhas
ReadLine()Retorna o conteúdo da linha atual como uma string
Add( c )Acrescenta a linha c no final do arquivo
AppendLn( c )Insere a linha c após a linha atual
DelLine()Exclui a linha atual
InsLine( c )Insere a linha c antes da linha atual
RepLine( c )Substitui a linha atual por c
GoTop()Move o cursor para a primeira linha
GoBottom()Move o cursor para a última linha
GoTo( n )Move o cursor para o número de linha absoluto n
GetValue( cSec, cKey, xDef )Retorna o valor de uma chave em uma seção no estilo INI, ou xDef se ausente
SetValue( cSec, cKey, xVal )Define o valor de uma chave em uma seção no estilo INI (cria a seção/chave se necessário)

Exemplo: Leitor de Arquivo de Configuração

#include "FiveWin.ch"

function Main()

   local oTxt := TTxtFile():New( "config.ini", 2 )

   if oTxt:hFile != nil
      // Lê valores de seções no estilo INI
      ? "Server:",  oTxt:GetValue( "Database", "Server",  "localhost" )
      ? "Port:",    oTxt:GetValue( "Database", "Port",    3306 )
      ? "User:",    oTxt:GetValue( "Database", "User",    "admin" )

      // Atualiza ou adiciona um valor
      oTxt:SetValue( "Database", "LastAccess", DToC( Date() ) )

      // Navega pelas linhas manualmente
      oTxt:GoTop()
      while ! oTxt:lEof()
         ? oTxt:ReadLine()
         oTxt:Advance()
      endwhile

      oTxt:Close()
   else
      ? "Arquivo não encontrado"
   endif

return nil

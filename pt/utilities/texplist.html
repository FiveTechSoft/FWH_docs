TExplorerList / TItemListbar

Fonte: source/classes/texplist.prg

TExplorerList herda de: TControl. TItemListbar é uma classe de colaboração interna para itens individuais.

TExplorerList é um controle de lista de navegação vertical com itens expansíveis/recolhíveis, semelhante à árvore de pastas do Windows Explorer ou à barra do Outlook. Cada item pode exibir um bitmap, texto e itens filhos opcionais com indentação. O controle suporta navegação por teclado, efeitos de hover do mouse, realce de seleção com gradiente e rolagem vertical para conteúdo que excede a área visível.

Principais Membros DATA (TExplorerList)

DATATipoDescrição

bChangeBlockBloco de código executado quando o item selecionado muda

nSeparationNumericEspaçamento vertical entre itens de nível superior (padrão 15)

nVirtualTopNumericDeslocamento atual de rolagem em pixels virtuais

TItemListbar (Objetos de Item)

DATATipoDescrição

TItemListbar suporta AddItem() para criar itens filhos, OpenClose() para expandir/recolher filhos e Click() para disparar ações.

Exemplo: Lista de Navegação com Grupos

#include "FiveWin.ch"

function Main()

   local oWnd, oList, oInbox, oSent

   DEFINE WINDOW oWnd TITLE "TExplorerList Demo" SIZE 300, 400

   @ 10, 10 EXPLORERLIST oList SIZE 280, 380 OF oWnd

   oInbox := oList:AddItem( "Inbox", "inbox.bmp" )
   oInbox:AddItem( "Today", "mail.bmp" )
   oInbox:AddItem( "Yesterday", "mail.bmp" )

   oSent := oList:AddItem( "Sent Items", "sent.bmp" )
   oSent:AddItem( "This Week", "mail.bmp" )

   oList:AddItem( "Deleted Items", "trash.bmp" )

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • Adicione itens filhos chamando AddItem() em um objeto TItemListbar pai. Os itens filhos são indentados em 10 pixels por nível.
  • Os itens são renderizados com fundos em gradiente e cantos arredondados em três estados: normal, hover e selecionado+hover.
  • Navegação por teclado: setas Cima/Baixo, +/- para expandir/recolher, Enter para disparar a ação, Home/End para o primeiro/último item.
  • A animação de fade (FadeOn/FadeOff) fornece feedback visual nos eventos de entrada/saída do mouse.

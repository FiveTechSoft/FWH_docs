Classes de Arquivo, Texto e Dados

O FiveWin fornece um rico conjunto de classes para E/S de arquivos, edição de texto, configuração INI, acesso ao registro do Windows, operações de área de transferência, interoperabilidade com estruturas C e gerenciamento de dicionário de dados. Essas classes encapsulam recursos de baixo nível do sistema operacional em interfaces orientadas a objetos limpas.

TFile - Operações com Arquivos Binários

TFile é a classe base para manipulação de arquivos binários. Ela encapsula as funções de baixo nível do Harbour FOpen/FCreate/FRead/FWrite em um objeto que rastreia o handle do arquivo, o comprimento e a posição atual. TTxtFile herda de TFile para adicionar acesso baseado em linhas.

Membros DATA

DATATipoDescrição
cNameCaractereNome do arquivo (caminho) passado ao construtor
hFileNuméricoHandle do arquivo do SO retornado por FOpen/FCreate
nLenNuméricoComprimento total do arquivo em bytes
nBufferLenNuméricoTamanho do buffer de leitura (padrão 2048)
nModeNuméricoModo de abertura (FO_READWRITE, FC_NORMAL, etc.)

Referência de MÉTODOS

MétodoDescrição
New( cFileName, nMode )Abre um arquivo existente ou cria um novo. Se o arquivo existir, abre com nMode (padrão FO_READWRITE). Caso contrário, cria com FC_NORMAL.
Create( cFileName, nMode )Apaga o arquivo existente e então chama New() para criar um arquivo novo.
Open()Retorna .T. se o handle do arquivo for válido (hFile > 0).
Close()Fecha o handle do arquivo via FClose().
End()Alias para Close().
GoTop()Posiciona no byte 0 (início do arquivo).
GoBottom()Posiciona no fim do arquivo, atualiza nLen.
GoTo( nRecno )Posiciona na posição absoluta de byte nRecno.
Skip( nBytes )Move o ponteiro do arquivo para frente/trás em nBytes relativo à posição atual.
nRecNo()Retorna a posição de byte atual no arquivo.
lEoF()Retorna .T. se a posição atual >= nLen.
lBoF()Retorna .T. se a posição atual == 0.
nGetByte()Lê e retorna um byte como numérico (valor Asc), ou -1 em caso de falha.
nGetWord()Lê e retorna uma palavra de 16 bits (2 bytes) via Bin2I(), ou -1 em caso de falha.
cGetStr( nLen )Lê nLen bytes e retorna como string.
PutByte( nByte )Escreve um byte na posição atual.
PutWord( nWord )Escreve uma palavra de 16 bits na posição atual via I2Bin().
PutStr( cStr )Escreve uma string na posição atual via FWrite().
AppByte( nByte )Acrescenta um byte ao fim do arquivo, incrementa nLen.
AppWord( nWord )Acrescenta uma palavra de 16 bits ao fim do arquivo.
AppStr( cStr )Acrescenta uma string ao fim do arquivo.
Count( cStr )Conta ocorrências de cStr no arquivo inteiro (padrão CRLF).
Seek( cStr, nDirection, nCase )Procura por cStr a partir da posição atual. nDirection: 0=para frente, 1=para trás. nCase: 0=ignora maiúsc/minúsc, 1=maiúsculas, 2=minúsculas.
DelBytes( nLen )Exclui nLen bytes na posição atual.
InsBytes( nLen )Insere nLen bytes vazios na posição atual.

Exemplo: Lendo um Arquivo Binário

local oFile := TFile():New( "data.bin" )

if oFile:Open()
   oFile:GoTop()
   ? "File size:", oFile:nLen, "bytes"

   // Lê o cabeçalho: assinatura de 2 bytes + comprimento de 4 bytes
   local nSig  := oFile:nGetWord()
   local cData := oFile:cGetStr( 256 )

   ? "Signature:", nSig
   ? "First 256 bytes:", cData

   // Procura por um padrão
   oFile:GoTop()
   if oFile:Seek( "MARKER" )
      ? "Found MARKER at position:", oFile:nRecNo()
   endif

   oFile:Close()
endif

Exemplo: Criando e Gravando um Arquivo Binário

local oFile := TFile():Create( "output.dat" )

oFile:PutWord( 0x4657 )           // assinatura de 2 bytes "FW"
oFile:PutStr( "Hello World" )     // dados de string
oFile:AppStr( CRLF + "Line 2" )  // acrescenta no fim

? "Bytes written:", oFile:nLen
oFile:Close()

TTxtFile - Acesso por Linha a Arquivos de Texto

TTxtFile herda de TFile e adiciona navegação linha a linha. Ela conta os terminadores de linha CRLF na abertura e fornece os métodos Skip/GoTo/ReadLine que trabalham com números de linha em vez de deslocamentos de byte. Ideal para ler arquivos de log, dados CSV ou arquivos de configuração.

DATATipoDescrição
cLineCaractereConteúdo da linha atual após ReadLine()
nLineNuméricoNúmero da linha atual (começando em 1)
nTLinesNuméricoNúmero total de linhas no arquivo
nMaxLineLengthNuméricoComprimento máximo esperado da linha (padrão 1024)
nOffsetNuméricoDeslocamento de byte do início da linha atual

ReadLn()Alias para ReadLine() (compatibilidade com versões anteriores).

GoBottom()Vai para a última linha.

Advance()Move para a próxima linha (busca o próximo CRLF). Retorna .F. no EOF.

Exemplo: Processando um Arquivo de Texto Linha a Linha

local oTxt := TTxtFile():New( "logfile.txt", FO_READ )

if oTxt:Open()
   ? "Total lines:", oTxt:RecCount()

   oTxt:GoTop()
   while ! oTxt:Eof()
      if "ERROR" $ Upper( oTxt:cLine )
         ? "Line", oTxt:nLine, ":", oTxt:cLine
      endif
      oTxt:Skip( 1 )
   end

   oTxt:Close()
endif

Exemplo: Construindo um Arquivo de Texto

local oTxt := TTxtFile():New( "report.csv" )

oTxt:Add( "Name,Age,City" )
oTxt:Add( "John,30,New York" )
oTxt:Add( "Maria,25,Madrid" )
oTxt:Add( "Hans,40,Berlin" )

? "Written", oTxt:RecCount(), "lines"
oTxt:Close()

TTxtEdit - Controle Editor de Texto Multilinha

TTxtEdit é um controle editor de texto completo com realce de sintaxe, desfazer/refazer, seleção de blocos, localizar/substituir, numeração de linhas e suporte à área de transferência. Ele herda de TControl e pode ser colocado em qualquer janela ou diálogo. É usado internamente pelo editor de código do FiveWin e é adequado para construir interfaces semelhantes a uma IDE.

TIni - Acesso a Arquivos INI

TIni fornece acesso de leitura/escrita a arquivos INI no estilo do Windows. Ela encapsula as funções da API do Windows GetPrivateProfileString/WritePrivateProfileString. Quando nenhum arquivo é especificado, lê de/escreve em WIN.INI. O flag lAutoSet (padrão .T.) escreve automaticamente os valores padrão se uma chave não for encontrada.

Membros DATA

DATATipoDescrição
cIniFileCaractereCaminho para o arquivo INI. String vazia significa WIN.INI.
lAutoSetLógicoSe .T. (padrão), escreve os valores padrão quando a chave não é encontrada em Get().

Referência de MÉTODOS

MétodoDescrição
New( cIniFile )Cria o objeto TIni. Acrescenta a extensão ".ini" se não houver ponto no nome do arquivo.
Get( cSection, cEntry, uDefault, uVar )Lê um valor. O tipo é determinado por uDefault: numérico retorna inteiro, data retorna CToD(), lógico retorna comparação .T./.F., caso contrário string.
Set( cSection, cEntry, uValue )Escreve um valor (convertido para string via cValToChar).
Sections()Retorna um array com todos os nomes de seção no arquivo INI.
DelSection( cSection )Exclui uma seção inteira do arquivo INI.
DelEntry( cSection, cEntry )Exclui uma única entrada de uma seção.

Sintaxe de Comando

// O FiveWin fornece comandos wrappers para INI:
INI oIni FILENAME "myapp.ini"

   GET cServer  SECTION "Database" ENTRY "Server"  DEFAULT "localhost" OF oIni
   GET nPort    SECTION "Database" ENTRY "Port"    DEFAULT 3306        OF oIni
   GET lDebug   SECTION "App"      ENTRY "Debug"   DEFAULT .F.         OF oIni

   SET SECTION "App" ENTRY "LastRun" TO DToC( Date() ) OF oIni

ENDINI

Exemplo: Configurações da Aplicação

function LoadSettings()
   local oIni := TIni():New( "myapp.ini" )
   local cServer, nPort, cUser

   cServer := oIni:Get( "Database", "Server", "localhost" )
   nPort   := oIni:Get( "Database", "Port",   3306 )
   cUser   := oIni:Get( "Database", "User",   "admin" )

   // Lista todas as seções
   local aSections := oIni:Sections()
   AEval( aSections, {|c| QOut( "Section:", c ) } )

return nil

function SaveSettings( cServer, nPort )
   local oIni := TIni():New( "myapp.ini" )

   oIni:Set( "Database", "Server", cServer )
   oIni:Set( "Database", "Port",   nPort )
   oIni:Set( "App",      "LastRun", DToC( Date() ) )

return nil

TReg32 - Acesso ao Registro do Windows

TReg32 fornece acesso orientado a objetos ao Registro do Windows. Ela suporta a leitura e escrita de valores string (REG_SZ), numéricos (REG_DWORD) e binários (REG_BINARY) sob qualquer ramo (hive) do registro. Em aplicações de 32 bits executando em Windows de 64 bits, ela adiciona automaticamente KEY_WOW64_64KEY para o acesso correto à visão do registro.

Constantes HKEY

ConstanteValorDescrição
HKEY_CLASSES_ROOT0x80000000Associações de tipos de arquivo e registros COM
HKEY_CURRENT_USER0x80000001Preferências e configurações do usuário atual
HKEY_LOCAL_MACHINE0x80000002Dados de configuração de toda a máquina
HKEY_USERS0x80000003Todos os perfis de usuário na máquina
HKEY_CURRENT_CONFIG0x80000005Perfil de hardware atual

Membros DATA

DATATipoDescrição
cRegKeyCaractereCaminho da chave do registro (ex. "Software\\MyApp")
nKeyNuméricoConstante raiz HKEY
nHandleNuméricoHandle para a chave do registro aberta
nErrorNuméricoÚltimo código de erro (0 = ERROR_SUCCESS)
lErrorLógicoFlag de erro

Referência de MÉTODOS

MétodoDescrição
New( nKey, cRegKey )Abre uma chave de registro existente. Tenta primeiro KEY_ALL_ACCESS, recorrendo a KEY_READ.
Create( nKey, cRegKey )Cria uma nova chave de registro (ou abre se ela já existir).
Get( cSubKey, uVar )Lê um valor. Retorna string para REG_SZ, numérico para REG_DWORD.
GetBinary( cSubKey )Lê um valor binário como string bruta.
Set( cSubKey, uVar, nType )Escreve um valor. nType assume por padrão REG_SZ para strings, REG_DWORD para numéricos.
Delete( cSubKey )Exclui uma subchave.
Close()Fecha o handle da chave de registro.

Exemplo: Lendo e Gravando Valores do Registro

#define HKEY_CURRENT_USER  2147483649

function ReadAppSettings()
   local oReg, cValue := "", nValue := 0

   oReg := TReg32():New( HKEY_CURRENT_USER, "Software\MyCompany\MyApp" )

   if oReg:nError == 0
      oReg:Get( "InstallPath", @cValue )
      ? "Install path:", cValue

      oReg:Get( "RunCount", @nValue )
      ? "Run count:", nValue

      // Incrementa o contador de execuções
      oReg:Set( "RunCount", nValue + 1 )
   endif

   oReg:Close()
return nil

function CreateAppKey()
   local oReg

   oReg := TReg32():Create( HKEY_CURRENT_USER, "Software\MyCompany\MyApp" )
   oReg:Set( "Version", "26.05" )
   oReg:Set( "InstallDate", DToC( Date() ) )
   oReg:Set( "RunCount", 0 )
   oReg:Close()
return nil

TStruct - Interoperabilidade com Estruturas C

TStruct permite definir e manipular estruturas da linguagem C a partir de código Harbour/xHarbour. Os membros são definidos com nome, tipo e comprimento opcional. Uma vez definidos, os membros podem ser acessados como propriedades usando o mecanismo de tratamento de erros do Harbour. O buffer interno (cBuffer) é uma string binária compatível com os parâmetros STRUCT da API do Windows.

Constantes de Tipo Suportadas

TipoTamanho (bytes)Descrição
BYTE / CHAR1Valor de 8 bits
WORD / _INT / BOOL2Valor de 16 bits
LONG / DWORD / PTR / LPSTR4Valor ou ponteiro de 32 bits
LONGLONG8Valor de 64 bits

Membros DATA

DATATipoDescrição
cBufferCaractereBuffer binário bruto que contém os dados da estrutura
aMembersArrayArray de { cName, nType, nLen, nOffset } para cada membro

Referência de MÉTODOS

MétodoDescrição
New()Cria uma estrutura vazia com buffer em branco.
AddMember( cName, nType, nLen )Adiciona um membro nomeado. nLen é determinado automaticamente a partir de nType se omitido.
SetMember( nMember, uData )Define o valor de um membro pelo índice.
GetMember( nMember )Obtém o valor de um membro pelo índice.
SizeOf()Retorna o tamanho total da estrutura em bytes (Len de cBuffer).

Exemplo: Definindo e Usando uma Estrutura POINT

#include "Struct.ch"

local oPoint := TStruct():New()
oPoint:AddMember( "x", LONG )
oPoint:AddMember( "y", LONG )

// Define via acesso a propriedade (usa o tratador OnError)

oPoint:y := 200

? "Point:", oPoint:x, oPoint:y
? "Size:", oPoint:SizeOf(), "bytes"    // 8 bytes

// Passa cBuffer para funções da API do Windows que esperam LPPOINT
// GetCursorPos( oPoint:cBuffer )

Exemplo: Estrutura RECT para Chamadas de API

oRect:AddMember( "top",    LONG )

oRect:top    := 20
oRect:right  := 300

? "Height:", oRect:bottom - oRect:top    // 180

TDict - Dicionário de Dados da Aplicação

TDict é um gerenciador de dicionário de dados para aplicações FiveWin. Ele cria e gerencia um conjunto de tabelas DBF (em uma pasta "system" por padrão) que descrevem a estrutura da sua aplicação: scripts, bancos de dados, tabelas, browses, colunas, formulários, menus, textos de ajuda e traduções de idioma. Ele fornece métodos para construir a interface automaticamente a partir de metadados, carregar menus dinamicamente e gerar visualizações de browse/edição baseadas na web.

LoadWebEdit( cParams )Gera um formulário de edição HTML a partir dos metadados do dicionário.

Exemplo: Usando o Dicionário de Dados

local oDict := TDict():New( "c:\myapp\system" )

oDict:Activate()

// Abre um banco de dados registrado
oDict:OpenDataBase( "customers" )

// Carrega um menu do dicionário
oDict:LoadMenu( "MainMenu" )

// Gera um relatório
oDict:Report( "CustomerList" )

oDict:End()

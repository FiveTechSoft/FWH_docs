TDbg - FiveWin Debugger

Fonte: source/classes/fwdbg.prg

Classe independente

O TDbg é um depurador completo de nível de código-fonte para aplicações FiveWin. Ele fornece uma janela gráfica de depuração (oDlg) contendo até nove painéis XBrowse para inspecionar o código-fonte, a pilha de chamadas, variáveis locais/privadas, arrays, objetos, breakpoints, áreas de trabalho, comandos SET e dados do profiler. O depurador é ativado compilando com #pragma /b+ ou passando a flag de linha de comando /b.

Principais Membros DATA

DATATipoDescrição
oDlgTDialogA janela de diálogo do depurador
oBrwTXBrowseArray ou objeto para 9 painéis de browse (código-fonte, pilha, variáveis, arrays, objetos, breakpoints, áreas, SETs, profiler)
aStackArrayEntradas atuais da pilha de chamadas
aModulesArrayMódulos de código-fonte carregados
aBreakArrayDefinições de breakpoints
aTraceArrayEntradas do log de trace

Métodos Principais

MétodoDescrição
New()Cria a instância do depurador
Activate()Abre e exibe a janela de diálogo do depurador
Exec()Executa o loop principal do depurador
DbgNext()Avança para a próxima linha de código-fonte
DbgGo()Continua a execução até o próximo breakpoint
DbgNextRoutine()Passa por cima (executa chamadas de sub-rotina sem entrar nelas)
DbgSetBreak( cMod, nLine )Define um breakpoint em um módulo e linha específicos
DbgSetTrace( lOn )Ativa ou desativa o registro de trace
DbgEditVar( cVarName )Abre um editor para modificar o valor de uma variável
DbgEditObj( oObj )Abre um inspetor de objeto para um determinado objeto

Exemplo: Sessão de Depuração

// Adicione este pragma aos módulos que deseja depurar:
#pragma /b+

#include "FiveWin.ch"

function Main()

   local cName := "FiveWin"
   local nCount := 0

   // O depurador abre automaticamente quando o programa
   // é compilado com /b+ e a FWDbg.lib é vinculada.

   // Use F5 para continuar, F8 para avançar passo a passo, F9 para breakpoints
   for nCount := 1 to 5
      ? "Iteration:", nCount
      ProcessItem( cName )
   next

return nil

function ProcessItem( cItem )

   ? "Processing:", cItem

return nil

Notas

  • Para habilitar a depuração, adicione #pragma /b+ no topo de cada módulo de código-fonte que deseja depurar e vincule a FWDbg.lib (ou garanta que ela faça parte do seu conjunto de bibliotecas FWH).
  • O depurador também pode ser acionado em tempo de execução passando a flag /b na linha de comando ao iniciar sua aplicação.
  • Os nove painéis de browse exibem: código-fonte (com destaque da linha atual), pilha de chamadas, variáveis locais/privadas, arrays, objetos, breakpoints, áreas de trabalho de banco de dados, estados dos comandos SET e estatísticas do profiler.

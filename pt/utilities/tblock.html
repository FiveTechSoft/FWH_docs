TBlock - Bloco de Código a Partir de String de Expressão

Fonte: source/classes/block.prg

TBlock cria blocos de código Harbour (bBlock) a partir de strings de expressão de caracteres em tempo de execução. Isso permite a avaliação dinâmica de expressões inseridas pelo usuário ou lidas de arquivos de configuração. A classe compila a string de expressão usando o operador & (macro) do Harbour e armazena o bloco de código resultante. O método Eval() avalia o bloco com parâmetros opcionais, enquanto Exec() o executa para efeitos colaterais.

DATA Members

DATATipoDescrição
cExpressionCharacterA string de expressão a partir da qual o bloco de código foi compilado
bBlockCodeblockO bloco de código compilado pronto para avaliação

Métodos Principais

MétodoDescrição
New( cExpr )Cria um objeto TBlock a partir da string de expressão cExpr. Compila-a em bBlock
Eval( uPar1 .. uPar5 )Avalia o bloco de código com até cinco parâmetros e retorna o resultado
Exec( uPar1 .. uPar5 )Avalia o bloco de código para efeitos colaterais (o valor de retorno é descartado)

Exemplo: Avaliação de Expressão em Tempo de Execução

#include "FiveWin.ch"

function Main()

   local cExpr, oBlock, nResult

   // Obtém a expressão da entrada do usuário
   cExpr := "2 + 3 * 4"

   oBlock := TBlock():New( cExpr )
   if oBlock:bBlock != nil
      nResult := oBlock:Eval()
      ? cExpr + " = " + Str( nResult )    // 14
   endif

   // Expressão com parâmetros
   oBlock := TBlock():New( "x + y" )
   if oBlock:bBlock != nil
      nResult := oBlock:Eval( 10, 20 )
      ? "x + y = " + Str( nResult )       // 30
   endif

   // Expressão de arquivo de configuração
   local cConfigExpr := "Year( Date() ) - 2000"
   oBlock := TBlock():New( cConfigExpr )
   ? "Year offset:", oBlock:Eval()

   // Exec com efeitos colaterais
   oBlock := TBlock():New( "MsgInfo( 'Hello from TBlock!' )" )
   oBlock:Exec()

return nil

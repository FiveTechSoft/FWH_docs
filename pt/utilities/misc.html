Classes Diversas

O FiveWin inclui uma ampla variedade de classes utilitárias que cobrem temporizadores, manipulação de tempo, retângulos, canetas GDI, gerenciamento de layout, protocolos de internet (FTP, SMTP, POP3), e-mail, análise de expressões e gráficos. Esta página documenta cada uma dessas classes com seus membros DATA, métodos e exemplos práticos.

TTimer - Ações de Temporizador Periódicas

TTimer encapsula a API SetTimer/KillTimer do Windows para executar um code block em intervalos regulares. Os temporizadores são gerenciados em um array estático e despachados através da função TimerEvent(). Múltiplos temporizadores podem estar ativos simultaneamente, cada um com intervalos e ações diferentes.

Membros DATA

DATATipoDescrição
nIntervalNuméricoIntervalo do temporizador em milissegundos (padrão 18)
bActionCode blockCode block a executar em cada disparo
lActiveLógico.T. quando o temporizador está em execução
nIdNuméricoID único do temporizador (atribuído automaticamente)
hWndOwnerNuméricoHandle da janela proprietária
CargoQualquerDados de carga definidos pelo usuário

Referência de MÉTODOS

MétodoDescrição
New( nInterval, bAction, oWnd )Cria um novo temporizador. NÃO o inicia -- chame Activate() para iniciar.
Activate()Inicia o temporizador via SetTimer() do Windows. Define lActive como .T.
DeActivate()Para o temporizador via KillTimer(). Define lActive como .F.
End()Desativa e remove o temporizador do array interno de temporizadores.

Sintaxe de Comando

// Comando FiveWin:
DEFINE TIMER oTimer INTERVAL 1000 ACTION UpdateClock() OF oWnd
ACTIVATE TIMER oTimer

// Desativar depois:
DEACTIVATE TIMER oTimer
// ou
oTimer:End()

Exemplo: Exibição de Relógio com Atualização Automática

local oWnd, oTimer, oSay

DEFINE WINDOW oWnd TITLE "Timer Demo"

@ 2, 2 SAY oSay PROMPT Time() OF oWnd SIZE 200, 30

// Atualiza o relógio a cada segundo (1000 ms)
DEFINE TIMER oTimer INTERVAL 1000 ;
   ACTION ( oSay:SetText( Time() ) ) OF oWnd
ACTIVATE TIMER oTimer

ACTIVATE WINDOW oWnd ;
   VALID ( oTimer:End(), .T. )

Exemplo: Salvamento Automático com Temporizador

// Salva os dados a cada 5 minutos
local oAutoSave := TTimer():New( 300000, {|| SaveAllData() }, oWnd )
oAutoSave:Activate()

// Pausa temporariamente o salvamento automático
oAutoSave:DeActivate()

// Retoma
oAutoSave:Activate()

// Limpeza ao sair
oAutoSave:End()

TTime - Manipulação de Tempo

TTime armazena o tempo como o total de segundos desde a meia-noite (0-86399) e fornece métodos para aritmética e formatação. Pode ser construída a partir de horas/minutos/segundos ou inicializada a partir do relógio do sistema.

Membros DATA

DATATipoDescrição
nTimeNuméricoTempo armazenado como total de segundos desde a meia-noite (0-86399)

Referência de MÉTODOS

MétodoDescrição
New( nHours, nMinutes, nSeconds )Cria TTime a partir de componentes. Reinicia em 86400 (24 horas).
System()Construtor: cria TTime a partir da hora atual do sistema.
AddHours( nHours )Adiciona horas ao tempo atual.
AddMinutes( nMinutes )Adiciona minutos ao tempo atual.
AddSeconds( nSeconds )Adiciona segundos ao tempo atual.
cAdd( nHours, nMinutes, nSeconds )Adiciona componentes de tempo e retorna a string formatada "HH:MM:SS".
cSub( nHours, nMinutes, nSeconds )Subtrai o tempo e retorna a string formatada. Também pode aceitar um objeto TTime.
cGetTime()Retorna a string de tempo formatada "HH:MM:SS".
SysChange()Define a hora do sistema com o valor armazenado em nTime.

Exemplo: Cálculos de Tempo

// Cria a partir de componentes
local oStart := TTime():New( 9, 30, 0 )    // 09:30:00
local oEnd   := TTime():New( 17, 45, 0 )    // 17:45:00

? "Start:", oStart:cGetTime()   // "09:30:00"
? "End:",   oEnd:cGetTime()     // "17:45:00"

// Calcula a duração
local oDuration := TTime():New( 0, 0, oEnd:nTime - oStart:nTime )
? "Duration:", oDuration:cGetTime()  // "08:15:00"

// Adiciona 1,5 horas ao início
oStart:AddHours( 1 )
oStart:AddMinutes( 30 )
? "Break ends:", oStart:cGetTime()   // "11:00:00"

// A partir do relógio do sistema
local oNow := TTime():System()
? "Current time:", oNow:cGetTime()

TRect - Objeto Retângulo

TRect representa um retângulo com as coordenadas nTop, nLeft, nBottom, nRight. Suporta ACCESS/ASSIGN para propriedades calculadas (nWidth, nHeight, CenterPt), sobrecarga de operadores para aritmética (+, -, *, /) e métodos utilitários para mover, redimensionar e ajustar retângulos. Também pode converter de/para o formato de estrutura binária RECT do Windows.

Membros DATA

DATATipoDescrição
aRectArray{ nTop, nLeft, nBottom, nRight }
lWinRectLógicoSe .T. (padrão), usa a convenção do Windows para o cálculo de largura/altura

Propriedades ACCESS/ASSIGN

PropriedadeDescrição
nTopCoordenada superior (leitura/escrita)
nLeftCoordenada esquerda (leitura/escrita)
nBottomCoordenada inferior (leitura/escrita)
nRightCoordenada direita (leitura/escrita)
nWidthLargura calculada (leitura/escrita -- ao definir, ajusta nRight)
nHeightAltura calculada (leitura/escrita -- ao definir, ajusta nBottom)
CenterPtPonto central como { nRow, nCol } (leitura/escrita -- ao definir, move o retângulo)
cRectEstrutura binária RECT para a API do Windows (leitura/escrita)

Referência de MÉTODOS

MétodoDescrição
New( nTop, nLeft, nBottom, nRight )Cria a partir de coordenadas. Também aceita um array ou uma string binária RECT.
MoveBy( nRows, nCols )Move o retângulo por um deslocamento (preservando o tamanho).
MoveTo( nNewTop, nNewLeft )Move o retângulo para uma posição absoluta (preservando o tamanho).
Contains( aRect )Retorna .T. se aRect estiver totalmente dentro deste retângulo.
Resize( nRatio, aPoint )Redimensiona o retângulo por uma proporção em torno de um ponto.
FitInside( oRect, nResizeType, cAlign, nEnlarge )Ajusta este retângulo dentro de oRect mantendo a proporção.
AsSquare( lOuter, cAlign )Converte o retângulo em um quadrado (interno ou externo).
Modify( ... )Modifica várias propriedades de uma só vez.

Sobrecarga de Operadores

local oRect1 := TRect():New( 10, 20, 100, 200 )
local oRect2 := oRect1 + { 5, 5, 5, 5 }    // expande 5 em todos os lados
local oRect3 := oRect1 * 2                   // dobra todas as coordenadas

? oRect1 == oRect2    // .F. (operador de comparação)

Exemplo: Trabalhando com Retângulos

local oRect := TRect():New( 10, 20, 110, 220 )

? "Position:", oRect:nTop, oRect:nLeft
? "Size:", oRect:nWidth, "x", oRect:nHeight
? "Center:", oRect:CenterPt[ 1 ], oRect:CenterPt[ 2 ]

// Move para uma nova posição
oRect:MoveTo( 50, 100 )
? "New position:", oRect:nTop, oRect:nLeft    // 50, 100
? "Size unchanged:", oRect:nWidth, "x", oRect:nHeight

// Ajusta dentro de outro retângulo
local oContainer := TRect():New( 0, 0, 400, 600 )
oRect:FitInside( oContainer )

TPen - Objeto Caneta GDI

TPen encapsula uma caneta GDI do Windows para desenhar linhas e bordas. Encapsula o estilo, a largura e a cor da caneta e gerencia o ciclo de vida do handle GDI. Quando associada a um dispositivo de impressora, ela escala automaticamente a largura da caneta com base no DPI do dispositivo.

Constantes de Estilo de Caneta

ConstanteDescrição
PS_SOLIDLinha sólida (padrão)
PS_DASHLinha tracejada
PS_DOTLinha pontilhada
PS_DASHDOTTraço-ponto alternados
PS_DASHDOTDOTPadrão traço-ponto-ponto
PS_NULLCaneta invisível (sem desenho)

Membros DATA

DATATipoDescrição
hPenNuméricoHandle da caneta GDI (HPEN)
nStyleNuméricoEstilo da caneta (PS_SOLID, PS_DASH, etc.)
nWidthNuméricoLargura da caneta em pixels (escalada para o DPI do dispositivo)
nInpWidthNuméricoLargura de entrada original antes da escala de DPI
nColorNuméricoCor da caneta (valor RGB)
oDeviceObjetoDispositivo associado (impressora) para escala de DPI

Referência de MÉTODOS

MétodoDescrição
New( nStyle, nWidth, nColor, oDevice )Cria a caneta. Padrões: PS_SOLID, largura 1, CLR_BLACK. Escala automaticamente a largura para o DPI da impressora.
Release()Exclui o handle da caneta GDI.
End()Alias para Release().

Exemplo: Desenhando com Canetas

local oPenRed, oPenBlue, oPenDash

// Cria canetas diferentes
oPenRed  := TPen():New( PS_SOLID, 2, CLR_RED )
oPenBlue := TPen():New( PS_SOLID, 3, CLR_BLUE )
oPenDash := TPen():New( PS_DASH,  1, CLR_BLACK )

// Usa em um manipulador de Paint
oWnd:bPainted := {| hDC |  ;
   local hOldPen := SelectObject( hDC, oPenRed:hPen ), ;
   LineTo( hDC, 100, 100 ), ;
   SelectObject( hDC, oPenBlue:hPen ), ;
   LineTo( hDC, 200, 100 ), ;
   SelectObject( hDC, hOldPen ) ;
}

// Para impressão (escala automaticamente para o DPI da impressora)
local oPrnPen := TPen():New( PS_SOLID, 1, CLR_BLACK, oPrinter )

// Sempre libere ao terminar
oPenRed:End()
oPenBlue:End()
oPenDash:End()

TLayout - Gerenciador de Layout

TLayout herda de TPanel e fornece o arranjo automático de controles filhos quando a janela pai é redimensionada. Suporta layouts horizontais e verticais com dimensionamento fixo ou proporcional. Os layouts podem ser aninhados para criar arranjos complexos.

Tipos de Layout

ConstanteValorDescrição
LAYOUT_TYPE_MAIN0Layout de nível superior (anexado à janela)
LAYOUT_TYPE_HORIZONTAL1Subdivisão horizontal
LAYOUT_TYPE_VERTICAL2Subdivisão vertical

Membros DATA

DATATipoDescrição
aHLayoutArrayArray de layouts filhos horizontais
aVLayoutArrayArray de layouts filhos verticais
nTypeNuméricoTipo de layout (MAIN, HORIZONTAL, VERTICAL)
lFixedLógicoSe .T., este painel tem tamanho fixo; se .F., ele se estende proporcionalmente
bOnResizeCode blockManipulador de redimensionamento anterior (encadeado)

Referência de MÉTODOS

MétodoDescrição
New( oWnd )Cria o layout principal anexado a oWnd. Captura bResized para layout automático.
AddHLayout( nWidth )Adiciona um painel filho horizontal. nWidth > 0 = pixels fixos; 0 = proporcional.
AddVLayout( nHeight )Adiciona um painel filho vertical. nHeight > 0 = pixels fixos; 0 = proporcional.
onResized( nType, nWidth, nHeight )Interno: recalcula todas as posições dos painéis filhos ao redimensionar.

Exemplo: Layout de Dois Painéis com Barra Lateral Fixa

local oWnd, oLayout, oLeft, oRight

DEFINE WINDOW oWnd TITLE "Layout Demo" SIZE 800, 600

oLayout := TLayout():New( oWnd )

// Painel esquerdo: barra lateral fixa de 250px de largura
oLeft := oLayout:AddHLayout( 250 )

// Painel direito: preenche o espaço restante
oRight := oLayout:AddHLayout( 0 )

// Adiciona controles a cada painel
@ 1, 1 LISTBOX oLbx VAR cItem ITEMS { "Option 1", "Option 2", "Option 3" } ;
   OF oLeft SIZE oLeft:nWidth - 10, oLeft:nHeight - 20

@ 1, 1 SAY "Content area" OF oRight

ACTIVATE WINDOW oWnd

Exemplo: Layout Aninhado Vertical + Horizontal

local oWnd, oLayout, oTop, oBottom, oBottomLeft, oBottomRight

DEFINE WINDOW oWnd TITLE "Nested Layout" SIZE 800, 600

oLayout := TLayout():New( oWnd )

// Topo: área de barra de ferramentas fixa de 40px
oTop := oLayout:AddVLayout( 40 )

// Base: preenche o espaço restante
oBottom := oLayout:AddVLayout( 0 )

// Divide a base em esquerda/direita
oBottomLeft  := oBottom:AddHLayout( 0 )   // 50% cada
oBottomRight := oBottom:AddHLayout( 0 )

ACTIVATE WINDOW oWnd

TFTP / TFtpClient - Transferência de Arquivos FTP

O FiveWin fornece duas classes FTP: TFTP usa a API WinINet para operações FTP simples e de alto nível, enquanto TFtpClient usa sockets brutos para controle de baixo nível do protocolo FTP. TFTP é recomendada para a maioria dos casos de uso.

Membros DATA de TFTP (baseada em WinINet)

DATATipoDescrição
oInternetObjetoObjeto contêiner TInternet
cSiteCaractereURL/nome do host do servidor FTP
hFTPNuméricoHandle da conexão FTP
cUserNameCaractereNome de usuário de login
cPasswordCaractereSenha de login

Referência de MÉTODOS de TFTP

MétodoDescrição
New( cFTPSite, oInternet, cUserName, cPassword )Conecta ao servidor FTP via InternetConnect() do WinINet.
End()Fecha o handle da conexão FTP.
DeleteFile( cFileName )Exclui um arquivo remoto.
Directory( cMask )Lista o diretório remoto (como a função Directory() do Clipper).
RenameFile( cOldName, cNewName )Renomeia um arquivo remoto.
SetCurrentDirectory( cDirName )Altera o diretório de trabalho remoto.
CreateDirectory( cDirName )Cria um diretório remoto.

Referência de MÉTODOS de TFtpClient (baseada em Socket)

MétodoDescrição
New( cIPServer, nPort, User, Pass )Cria uma conexão de socket com o servidor FTP (porta padrão 21).
PWD()Retorna o caminho do diretório remoto atual.
CWD( cDirName )Altera o diretório remoto.
MKD( cDirName )Cria um diretório remoto.
DELE( cFileName )Exclui um arquivo remoto.
STOR( cFileName, bBlock )Faz upload de um arquivo. bBlock recebe atualizações de progresso.
RETR( cFileName )Faz download de um arquivo.
TYPE( cType )Define o tipo de transferência: "A" para ASCII, "I" para binário.
QUIT()Desconecta do servidor FTP.

Exemplo: Upload FTP com WinINet

local oInternet, oFtp

oInternet := TInternet():New()
oFtp := TFTP():New( "ftp.myserver.com", oInternet, "user", "password" )

if oFtp:hFTP != nil
   // Faz upload de um arquivo
   FtpPutFile( oFtp:hFTP, "c:\local\report.pdf", "/remote/report.pdf", 0, 0 )

   // Lista o diretório remoto
   local aFiles := oFtp:Directory( "*.pdf" )
   AEval( aFiles, {|a| QOut( a[ 1 ], a[ 2 ] ) } )

   // Cria o diretório e navega até ele
   oFtp:CreateDirectory( "/remote/backup" )
   oFtp:SetCurrentDirectory( "/remote/backup" )

   oFtp:End()
endif

oInternet:End()

TSmtp - Enviar E-mail via SMTP

TSmtp envia e-mail através do protocolo SMTP usando a classe TSocket do FiveWin. Suporta autenticação (método LOGIN), conteúdo HTML, anexos de arquivos, destinatários CC/BCC, confirmações de entrega e configurações de prioridade. A comunicação é assíncrona através de callbacks de eventos de socket.

Membros DATA

DATATipoDescrição
oSocketObjetoTSocket usado para a sessão SMTP
cIPServerCaractereIP ou nome do host do servidor SMTP
cFromCaractereEndereço de e-mail do remetente
aToArrayArray de endereços de e-mail dos destinatários
aCCArrayDestinatários CC
aBCCArrayDestinatários BCC
cReplyToCaractereEndereço de resposta (reply-to)
cSubjectCaractereAssunto do e-mail
cMsgCaractereCorpo da mensagem em texto puro
cHTMLCaractereCorpo da mensagem em HTML
aFilesArrayArray de caminhos de arquivos a anexar
cPriorityCaracterePrioridade da mensagem: "normal", "high", "low"
lReceiptLógicoSolicita confirmação de entrega
cUserCaractereNome de usuário de autenticação SMTP
cPasswordCaractereSenha de autenticação SMTP
lDoAuthLógicoHabilita a autenticação SMTP
bConnectingCode blockAção durante a conexão
bConnectedCode blockAção quando conectado
bDoneCode blockAção quando o e-mail é enviado com sucesso
bFailureCode blockAção em caso de falha
cErrorCaractereÚltima mensagem de erro

Exemplo: Enviar E-mail

function SendEmail()
   local oSmtp

   oSmtp := TSmtp():New( "smtp.myserver.com", 25, .T., "user@myserver.com", "password" )

   oSmtp:cFrom    := "sender@myserver.com"
   oSmtp:aTo      := { "recipient@example.com" }
   oSmtp:aCC      := { "cc@example.com" }
   oSmtp:cSubject := "Test Email from FiveWin"
   oSmtp:cMsg     := "This is a plain text email."
   oSmtp:cHTML    := "<h1>Hello!</h1><p>This is an <b>HTML</b> email.</p>"
   oSmtp:aFiles   := { "c:\docs\report.pdf" }
   oSmtp:cPriority := "high"

   oSmtp:bDone    := {|| MsgInfo( "Email sent successfully!" ) }
   oSmtp:bFailure := {|| MsgAlert( "Failed: " + oSmtp:cError ) }

   oSmtp:SendMail()

return nil

TPop3 - Receber E-mail via POP3

TPop3 recupera mensagens de e-mail de um servidor de correio POP3 usando a classe TSocket do FiveWin. Ele conecta, autentica e baixa as mensagens em um array de objetos compatíveis com TMail. Suporta a recuperação apenas de cabeçalhos e a exclusão de mensagens.

Membros DATA

DATATipoDescrição
oSocketObjetoTSocket para comunicação POP3
cIPServerCaractereNome do host do servidor POP3
nPortNuméricoNúmero da porta (padrão 110)
UserCaractereNome de usuário POP3
PassCaractereSenha POP3
aMsgsArrayArray de mensagens recuperadas
lDelMsgsLógicoExclui mensagens após a recuperação (padrão .T.)
lHeaderOnlyLógicoRecupera apenas os cabeçalhos (padrão .F.)
bConnectingCode blockAção durante a conexão
bConnectedCode blockAção quando conectado
bDoneCode blockAção quando todas as mensagens são recuperadas

Exemplo: Recuperar E-mail

function CheckMail()
   local oPop3

   oPop3 := TPop3():New( "pop3.myserver.com", 110, "user@myserver.com", "password" )
   oPop3:lDelMsgs    := .F.   // Não exclui após o download
   oPop3:lHeaderOnly := .F.   // Obtém as mensagens completas

   oPop3:bDone := {|| ShowMessages( oPop3:aMsgs ) }
   oPop3:GetMail()

return nil

function ShowMessages( aMsgs )
   local n
   for n := 1 to Len( aMsgs )
      ? "Subject:", aMsgs[ n ]:cSubject
      ? "From:",    aMsgs[ n ]:cFrom
      ? "Date:",    aMsgs[ n ]:dDate
      ? "---"
   next
return nil

TMail - Mensagem de E-mail MAPI

TMail usa a MAPI (Messaging Application Programming Interface) do Windows para compor e enviar e-mail através do cliente de correio padrão (normalmente o Outlook). Fornece uma abordagem mais simples que TSmtp quando o usuário tem um cliente compatível com MAPI instalado.

Membros DATA

DATATipoDescrição
cSubjectCaractereAssunto do e-mail
cNoteTextCaractereTexto do corpo do e-mail
cMsgTypeCaractereTipo da mensagem
dDateDataData da mensagem
cTimeCaractereHora da mensagem
lReceiptLógicoSolicita confirmação de leitura
lFromUserLógicoMostra o diálogo de composição para edição do usuário (padrão .T.)
aOriginArrayInformações do remetente
aRecipientsArrayArray de arrays de destinatários: { cName, cAddress }
aFilesArrayArray de caminhos de arquivos a anexar
nRetCodeNuméricoCódigo de retorno MAPI (0 = SUCCESS_SUCCESS)

Exemplo: Enviar pelo Cliente de Correio Padrão

local oMail := TMail():New( ;
   "Monthly Report",  ;                   // Assunto
   "Please find the report attached.",  ;  // Corpo
   ,, ;                                    // MsgType, ConversationID
   Date(), Time(),  ;                      // Data, Hora
   .F., .T.,  ;                            // Receipt, FromUser
   {},  ;                                  // Origem
   { { "John Doe", "john@example.com" } },  ; // Destinatários
   { "c:\reports\monthly.pdf" } )           // Anexos

oMail:Activate()   // Abre o cliente de correio padrão com os campos preenchidos

if oMail:nRetCode == 0
   ? "Email sent or queued successfully"
endif

oMail:End()

TParser - Análise de Expressões

TParser fornece um mecanismo de análise simples baseado em regras. Você define regras gramaticais como símbolos não-terminais com sequências de tokens e code blocks de ação associados. Ele mantém estados do analisador para construir gramáticas mais complexas.

Membros DATA

DATATipoDescrição
aRulesArrayArray de regras de análise: { cNonTerminal, aTokens, bAction }
aStatesArrayEstados da máquina de estados do analisador

Referência de MÉTODOS

MétodoDescrição
New()Cria um analisador vazio.
Add( cNonTerminal, aTokens, bAction )Adiciona uma regra gramatical. cNonTerminal é o nome da regra, aTokens define a sequência de tokens esperada, bAction é executado quando a regra corresponde.

Exemplo: Analisador de Expressões Simples

local oParser := TParser():New()

// Define regras: expressão -> número operador número
oParser:Add( "expr", { "number", "operator", "number" }, ;
   {|aTokens| Eval( aTokens ) } )

oParser:Add( "number", { "digit" }, ;
   {|aTokens| Val( aTokens[ 1 ] ) } )

TGraph - Gráficos e Diagramas

TGraph herda de TControl e renderiza gráficos de barras, gráficos de linhas, gráficos de pontos, gráficos de pizza e diagramas de dispersão XY diretamente em uma janela ou diálogo. SetFonts( aFonts )Define as fontes: { oTitleFont, oXFont, oYFont, oLegendFont }.
SaveAsImage( cFile )Salva o gráfico como arquivo de imagem BMP.
Save2Bmp( cFile )Salva o gráfico como BMP (alias para SaveAsImage).
Copy2ClipBoard( lMsg )Copia o gráfico para a área de transferência como bitmap.
End()Destrói o controle de gráfico.

Exemplo: Gráfico de Barras

local oDlg, oGraph

DEFINE DIALOG oDlg TITLE "Sales Report" SIZE 700, 500

oGraph := TGraph():New( 10, 10, oDlg, 680, 450, "Quarterly Sales" )
oGraph:nType   := GRAPH_TYPE_BAR
oGraph:l3D     := .T.
oGraph:lxGrid  := .T.
oGraph:lyGrid  := .T.
oGraph:lxVal   := .T.
oGraph:lyVal   := .T.
oGraph:lLegends := .T.

// Rótulos dos períodos
oGraph:aSeries := { "Q1", "Q2", "Q3", "Q4" }

// Séries de dados (um array por produto)
oGraph:AddSerie( { 15000, 22000, 18000, 25000 }, "Product A", CLR_BLUE )
oGraph:AddSerie( { 12000, 19000, 24000, 21000 }, "Product B", CLR_RED )
oGraph:AddSerie( {  8000, 11000, 13000, 17000 }, "Product C", CLR_GREEN )

ACTIVATE DIALOG oDlg CENTER

Exemplo: Gráfico de Linhas com Exportação

local oDlg, oGraph

DEFINE DIALOG oDlg TITLE "Temperature Trends" SIZE 700, 400

oGraph := TGraph():New( 10, 10, oDlg, 680, 350, "Monthly Temperatures" )
oGraph:nType     := GRAPH_TYPE_LINE
oGraph:lxGrid    := .T.
oGraph:lyGrid    := .T.
oGraph:nPenWidth := 2
oGraph:cTitX     := "Month"
oGraph:cTitY     := "Degrees C"

oGraph:aSeries := { "Jan","Feb","Mar","Apr","May","Jun", ;
                     "Jul","Aug","Sep","Oct","Nov","Dec" }

oGraph:AddSerie( { 5, 7, 12, 18, 23, 28, 31, 30, 25, 18, 11, 6 }, ;
                 "Madrid", CLR_RED, GRAPH_TYPE_LINE )
oGraph:AddSerie( { 2, 3, 8, 14, 19, 24, 27, 26, 21, 14, 8, 3 }, ;
                 "Berlin", CLR_BLUE, GRAPH_TYPE_LINE )

ACTIVATE DIALOG oDlg CENTER ;
   ON INIT ( oGraph:SaveAsImage( "c:\temp\temperatures.bmp" ) )

Miscellaneous Classes

FiveWin includes a wide variety of utility classes covering timers, time manipulation, rectangles, GDI pens, layout management, internet protocols (FTP, SMTP, POP3), email, expression parsing, and charting. This page documents each of these classes with their DATA members, methods, and practical examples.

TTimer - Periodic Timer Actions

TTimer wraps the Windows SetTimer/KillTimer API to execute a codeblock at regular intervals. Timers are managed in a static array and dispatched through the TimerEvent() function. Multiple timers can be active simultaneously, each with different intervals and actions.

DATA Members

DATATypeDescription
nIntervalNumericTimer interval in milliseconds (default 18)
bActionCodeblockCodeblock to execute on each tick
lActiveLogical.T. when timer is running
nIdNumericUnique timer ID (auto-assigned)
hWndOwnerNumericHandle of owner window
CargoAnyUser-defined cargo data

METHOD Reference

MethodDescription
New( nInterval, bAction, oWnd )Creates a new timer. Does NOT start it -- call Activate() to start.
Activate()Starts the timer via Windows SetTimer(). Sets lActive to .T.
DeActivate()Stops the timer via KillTimer(). Sets lActive to .F.
End()Deactivates and removes the timer from the internal timer array.

Command Syntax

// FiveWin command:
DEFINE TIMER oTimer INTERVAL 1000 ACTION UpdateClock() OF oWnd
ACTIVATE TIMER oTimer

// Deactivate later:
DEACTIVATE TIMER oTimer
// or
oTimer:End()

Example: Clock Display with Auto-Refresh

local oWnd, oTimer, oSay

DEFINE WINDOW oWnd TITLE "Timer Demo"

@ 2, 2 SAY oSay PROMPT Time() OF oWnd SIZE 200, 30

// Update the clock every second (1000 ms)
DEFINE TIMER oTimer INTERVAL 1000 ;
   ACTION ( oSay:SetText( Time() ) ) OF oWnd
ACTIVATE TIMER oTimer

ACTIVATE WINDOW oWnd ;
   VALID ( oTimer:End(), .T. )

Example: Auto-Save with Timer

// Save data every 5 minutes
local oAutoSave := TTimer():New( 300000, {|| SaveAllData() }, oWnd )
oAutoSave:Activate()

// Temporarily pause auto-save
oAutoSave:DeActivate()

// Resume
oAutoSave:Activate()

// Cleanup on exit
oAutoSave:End()

TTime - Time Manipulation

TTime stores time as total seconds since midnight (0-86399) and provides methods for arithmetic and formatting. It can be constructed from hours/minutes/seconds or initialized from the system clock.

DATA Members

DATATypeDescription
nTimeNumericTime stored as total seconds since midnight (0-86399)

METHOD Reference

MethodDescription
New( nHours, nMinutes, nSeconds )Creates TTime from components. Wraps at 86400 (24 hours).
System()Constructor: creates TTime from current system time.
AddHours( nHours )Adds hours to current time.
AddMinutes( nMinutes )Adds minutes to current time.
AddSeconds( nSeconds )Adds seconds to current time.
cAdd( nHours, nMinutes, nSeconds )Adds time components and returns formatted string "HH:MM:SS".
cSub( nHours, nMinutes, nSeconds )Subtracts time and returns formatted string. Can also accept a TTime object.
cGetTime()Returns formatted time string "HH:MM:SS".
SysChange()Sets the system time to the stored nTime value.

Example: Time Calculations

// Create from components
local oStart := TTime():New( 9, 30, 0 )    // 09:30:00
local oEnd   := TTime():New( 17, 45, 0 )    // 17:45:00

? "Start:", oStart:cGetTime()   // "09:30:00"
? "End:",   oEnd:cGetTime()     // "17:45:00"

// Calculate duration
local oDuration := TTime():New( 0, 0, oEnd:nTime - oStart:nTime )
? "Duration:", oDuration:cGetTime()  // "08:15:00"

// Add 1.5 hours to start
oStart:AddHours( 1 )
oStart:AddMinutes( 30 )
? "Break ends:", oStart:cGetTime()   // "11:00:00"

// From system clock
local oNow := TTime():System()
? "Current time:", oNow:cGetTime()

TRect - Rectangle Object

TRect represents a rectangle with nTop, nLeft, nBottom, nRight coordinates. It supports ACCESS/ASSIGN for computed properties (nWidth, nHeight, CenterPt), operator overloading for arithmetic (+, -, *, /), and utility methods for moving, resizing, and fitting rectangles. It can also convert to/from the Windows RECT binary structure format.

DATA Members

DATATypeDescription
aRectArray{ nTop, nLeft, nBottom, nRight }
lWinRectLogicalIf .T. (default), uses Windows convention for width/height calculation

ACCESS/ASSIGN Properties

PropertyDescription
nTopTop coordinate (read/write)
nLeftLeft coordinate (read/write)
nBottomBottom coordinate (read/write)
nRightRight coordinate (read/write)
nWidthComputed width (read/write -- setting adjusts nRight)
nHeightComputed height (read/write -- setting adjusts nBottom)
CenterPtCenter point as { nRow, nCol } (read/write -- setting moves the rect)
cRectBinary RECT structure for Windows API (read/write)

METHOD Reference

MethodDescription
New( nTop, nLeft, nBottom, nRight )Creates from coordinates. Also accepts an array or binary RECT string.
MoveBy( nRows, nCols )Moves rectangle by offset (preserving size).
MoveTo( nNewTop, nNewLeft )Moves rectangle to absolute position (preserving size).
Contains( aRect )Returns .T. if aRect is fully inside this rectangle.
Resize( nRatio, aPoint )Resizes rectangle by ratio around a point.
FitInside( oRect, nResizeType, cAlign, nEnlarge )Fits this rectangle inside oRect maintaining aspect ratio.
AsSquare( lOuter, cAlign )Converts rectangle to a square (inner or outer).
Modify( ... )Modifies multiple properties at once.

Operator Overloading

local oRect1 := TRect():New( 10, 20, 100, 200 )
local oRect2 := oRect1 + { 5, 5, 5, 5 }    // expand by 5 on all sides
local oRect3 := oRect1 * 2                   // double all coordinates

? oRect1 == oRect2    // .F. (comparison operator)

Example: Working with Rectangles

local oRect := TRect():New( 10, 20, 110, 220 )

? "Position:", oRect:nTop, oRect:nLeft
? "Size:", oRect:nWidth, "x", oRect:nHeight
? "Center:", oRect:CenterPt[ 1 ], oRect:CenterPt[ 2 ]

// Move to a new position
oRect:MoveTo( 50, 100 )
? "New position:", oRect:nTop, oRect:nLeft    // 50, 100
? "Size unchanged:", oRect:nWidth, "x", oRect:nHeight

// Fit inside another rectangle
local oContainer := TRect():New( 0, 0, 400, 600 )
oRect:FitInside( oContainer )

TPen - GDI Pen Object

TPen wraps a Windows GDI pen for drawing lines and borders. It encapsulates the pen style, width, and color, and manages the GDI handle lifecycle. When associated with a printer device, it automatically scales the pen width based on the device's DPI.

Pen Style Constants

ConstantDescription
PS_SOLIDSolid line (default)
PS_DASHDashed line
PS_DOTDotted line
PS_DASHDOTDash-dot alternating
PS_DASHDOTDOTDash-dot-dot pattern
PS_NULLInvisible pen (no drawing)

DATA Members

DATATypeDescription
hPenNumericGDI pen handle (HPEN)
nStyleNumericPen style (PS_SOLID, PS_DASH, etc.)
nWidthNumericPen width in pixels (scaled for device DPI)
nInpWidthNumericOriginal input width before DPI scaling
nColorNumericPen color (RGB value)
oDeviceObjectAssociated device (printer) for DPI scaling

METHOD Reference

MethodDescription
New( nStyle, nWidth, nColor, oDevice )Creates pen. Defaults: PS_SOLID, width 1, CLR_BLACK. Auto-scales width for printer DPI.
Release()Deletes the GDI pen handle.
End()Alias for Release().

Example: Drawing with Pens

local oPenRed, oPenBlue, oPenDash

// Create different pens
oPenRed  := TPen():New( PS_SOLID, 2, CLR_RED )
oPenBlue := TPen():New( PS_SOLID, 3, CLR_BLUE )
oPenDash := TPen():New( PS_DASH,  1, CLR_BLACK )

// Use in a Paint handler
oWnd:bPainted := {| hDC |  ;
   local hOldPen := SelectObject( hDC, oPenRed:hPen ), ;
   LineTo( hDC, 100, 100 ), ;
   SelectObject( hDC, oPenBlue:hPen ), ;
   LineTo( hDC, 200, 100 ), ;
   SelectObject( hDC, hOldPen ) ;
}

// For printing (auto-scales to printer DPI)
local oPrnPen := TPen():New( PS_SOLID, 1, CLR_BLACK, oPrinter )

// Always release when done
oPenRed:End()
oPenBlue:End()
oPenDash:End()

TLayout - Layout Manager

TLayout inherits from TPanel and provides automatic arrangement of child controls when the parent window is resized. It supports horizontal and vertical layouts with fixed or proportional sizing. Layouts can be nested to create complex arrangements.

Layout Types

ConstantValueDescription
LAYOUT_TYPE_MAIN0Top-level layout (attached to window)
LAYOUT_TYPE_HORIZONTAL1Horizontal subdivision
LAYOUT_TYPE_VERTICAL2Vertical subdivision

DATA Members

DATATypeDescription
aHLayoutArrayArray of horizontal child layouts
aVLayoutArrayArray of vertical child layouts
nTypeNumericLayout type (MAIN, HORIZONTAL, VERTICAL)
lFixedLogicalIf .T., this pane has fixed size; if .F., it stretches proportionally
bOnResizeCodeblockPrevious resize handler (chained)

METHOD Reference

MethodDescription
New( oWnd )Creates main layout attached to oWnd. Captures bResized for auto-layout.
AddHLayout( nWidth )Adds a horizontal child pane. nWidth > 0 = fixed pixels; 0 = proportional.
AddVLayout( nHeight )Adds a vertical child pane. nHeight > 0 = fixed pixels; 0 = proportional.
onResized( nType, nWidth, nHeight )Internal: recalculates all child pane positions on resize.

Example: Two-Panel Layout with Fixed Sidebar

local oWnd, oLayout, oLeft, oRight

DEFINE WINDOW oWnd TITLE "Layout Demo" SIZE 800, 600

oLayout := TLayout():New( oWnd )

// Left panel: fixed 250px wide sidebar
oLeft := oLayout:AddHLayout( 250 )

// Right panel: fills remaining space
oRight := oLayout:AddHLayout( 0 )

// Add controls to each panel
@ 1, 1 LISTBOX oLbx VAR cItem ITEMS { "Option 1", "Option 2", "Option 3" } ;
   OF oLeft SIZE oLeft:nWidth - 10, oLeft:nHeight - 20

@ 1, 1 SAY "Content area" OF oRight

ACTIVATE WINDOW oWnd

Example: Nested Vertical + Horizontal Layout

local oWnd, oLayout, oTop, oBottom, oBottomLeft, oBottomRight

DEFINE WINDOW oWnd TITLE "Nested Layout" SIZE 800, 600

oLayout := TLayout():New( oWnd )

// Top: fixed 40px toolbar area
oTop := oLayout:AddVLayout( 40 )

// Bottom: fills remaining space
oBottom := oLayout:AddVLayout( 0 )

// Split bottom into left/right
oBottomLeft  := oBottom:AddHLayout( 0 )   // 50% each
oBottomRight := oBottom:AddHLayout( 0 )

ACTIVATE WINDOW oWnd

TFTP / TFtpClient - FTP File Transfer

FiveWin provides two FTP classes: TFTP uses the WinINet API for simple, high-level FTP operations, while TFtpClient uses raw sockets for low-level FTP protocol control. TFTP is recommended for most use cases.

TFTP DATA Members (WinINet-based)

DATATypeDescription
oInternetObjectTInternet container object
cSiteCharacterFTP server URL/hostname
hFTPNumericFTP connection handle
cUserNameCharacterLogin username
cPasswordCharacterLogin password

TFTP METHOD Reference

MethodDescription
New( cFTPSite, oInternet, cUserName, cPassword )Connects to FTP server via WinINet InternetConnect().
End()Closes the FTP connection handle.
DeleteFile( cFileName )Deletes a remote file.
Directory( cMask )Lists remote directory (like Clipper's Directory() function).
RenameFile( cOldName, cNewName )Renames a remote file.
SetCurrentDirectory( cDirName )Changes the remote working directory.
CreateDirectory( cDirName )Creates a remote directory.

TFtpClient METHOD Reference (Socket-based)

MethodDescription
New( cIPServer, nPort, User, Pass )Creates socket connection to FTP server (default port 21).
PWD()Returns current remote directory path.
CWD( cDirName )Changes remote directory.
MKD( cDirName )Creates remote directory.
DELE( cFileName )Deletes remote file.
STOR( cFileName, bBlock )Uploads a file. bBlock receives progress updates.
RETR( cFileName )Downloads a file.
TYPE( cType )Sets transfer type: "A" for ASCII, "I" for binary.
QUIT()Disconnects from FTP server.

Example: FTP Upload with WinINet

local oInternet, oFtp

oInternet := TInternet():New()
oFtp := TFTP():New( "ftp.myserver.com", oInternet, "user", "password" )

if oFtp:hFTP != nil
   // Upload a file
   FtpPutFile( oFtp:hFTP, "c:\local\report.pdf", "/remote/report.pdf", 0, 0 )

   // List remote directory
   local aFiles := oFtp:Directory( "*.pdf" )
   AEval( aFiles, {|a| QOut( a[ 1 ], a[ 2 ] ) } )

   // Create directory and navigate
   oFtp:CreateDirectory( "/remote/backup" )
   oFtp:SetCurrentDirectory( "/remote/backup" )

   oFtp:End()
endif

oInternet:End()

TSmtp - Send Email via SMTP

TSmtp sends email via the SMTP protocol using FiveWin's TSocket class. It supports authentication (LOGIN method), HTML content, file attachments, CC/BCC recipients, delivery receipts, and priority settings. Communication is asynchronous through socket event callbacks.

DATA Members

DATATypeDescription
oSocketObjectTSocket used for the SMTP session
cIPServerCharacterSMTP server IP or hostname
cFromCharacterSender email address
aToArrayArray of recipient email addresses
aCCArrayCC recipients
aBCCArrayBCC recipients
cReplyToCharacterReply-to address
cSubjectCharacterEmail subject
cMsgCharacterPlain text message body
cHTMLCharacterHTML message body
aFilesArrayArray of file paths to attach
cPriorityCharacterMessage priority: "normal", "high", "low"
lReceiptLogicalRequest delivery receipt
cUserCharacterSMTP authentication username
cPasswordCharacterSMTP authentication password
lDoAuthLogicalEnable SMTP authentication
bConnectingCodeblockAction while connecting
bConnectedCodeblockAction when connected
bDoneCodeblockAction when email sent successfully
bFailureCodeblockAction on failure
cErrorCharacterLast error message

Example: Send Email

function SendEmail()
   local oSmtp

   oSmtp := TSmtp():New( "smtp.myserver.com", 25, .T., "user@myserver.com", "password" )

   oSmtp:cFrom    := "sender@myserver.com"
   oSmtp:aTo      := { "recipient@example.com" }
   oSmtp:aCC      := { "cc@example.com" }
   oSmtp:cSubject := "Test Email from FiveWin"
   oSmtp:cMsg     := "This is a plain text email."
   oSmtp:cHTML    := "<h1>Hello!</h1><p>This is an <b>HTML</b> email.</p>"
   oSmtp:aFiles   := { "c:\docs\report.pdf" }
   oSmtp:cPriority := "high"

   oSmtp:bDone    := {|| MsgInfo( "Email sent successfully!" ) }
   oSmtp:bFailure := {|| MsgAlert( "Failed: " + oSmtp:cError ) }

   oSmtp:SendMail()

return nil

TPop3 - Receive Email via POP3

TPop3 retrieves email messages from a POP3 mail server using FiveWin's TSocket class. It connects, authenticates, and downloads messages into an array of TMail-compatible objects. Supports header-only retrieval and message deletion.

DATA Members

DATATypeDescription
oSocketObjectTSocket for POP3 communication
cIPServerCharacterPOP3 server hostname
nPortNumericPort number (default 110)
UserCharacterPOP3 username
PassCharacterPOP3 password
aMsgsArrayArray of retrieved messages
lDelMsgsLogicalDelete messages after retrieval (default .T.)
lHeaderOnlyLogicalRetrieve headers only (default .F.)
bConnectingCodeblockAction while connecting
bConnectedCodeblockAction when connected
bDoneCodeblockAction when all messages retrieved

Example: Retrieve Email

function CheckMail()
   local oPop3

   oPop3 := TPop3():New( "pop3.myserver.com", 110, "user@myserver.com", "password" )
   oPop3:lDelMsgs    := .F.   // Don't delete after download
   oPop3:lHeaderOnly := .F.   // Get full messages

   oPop3:bDone := {|| ShowMessages( oPop3:aMsgs ) }
   oPop3:GetMail()

return nil

function ShowMessages( aMsgs )
   local n
   for n := 1 to Len( aMsgs )
      ? "Subject:", aMsgs[ n ]:cSubject
      ? "From:",    aMsgs[ n ]:cFrom
      ? "Date:",    aMsgs[ n ]:dDate
      ? "---"
   next
return nil

TMail - MAPI Email Message

TMail uses the Windows MAPI (Messaging Application Programming Interface) to compose and send email through the default mail client (typically Outlook). It provides a simpler approach than TSmtp when the user has a MAPI-compatible client installed.

DATA Members

DATATypeDescription
cSubjectCharacterEmail subject
cNoteTextCharacterEmail body text
cMsgTypeCharacterMessage type
dDateDateMessage date
cTimeCharacterMessage time
lReceiptLogicalRequest read receipt
lFromUserLogicalShow compose dialog for user editing (default .T.)
aOriginArraySender information
aRecipientsArrayArray of recipient arrays: { cName, cAddress }
aFilesArrayArray of file paths to attach
nRetCodeNumericMAPI return code (0 = SUCCESS_SUCCESS)

Example: Send via Default Mail Client

local oMail := TMail():New( ;
   "Monthly Report",  ;                   // Subject
   "Please find the report attached.",  ;  // Body
   ,, ;                                    // MsgType, ConversationID
   Date(), Time(),  ;                      // Date, Time
   .F., .T.,  ;                            // Receipt, FromUser
   {},  ;                                  // Origin
   { { "John Doe", "john@example.com" } },  ; // Recipients
   { "c:\reports\monthly.pdf" } )           // Attachments

oMail:Activate()   // Opens default mail client with pre-filled fields

if oMail:nRetCode == 0
   ? "Email sent or queued successfully"
endif

oMail:End()

TParser - Expression Parsing

TParser provides a simple rule-based parser engine. You define grammar rules as non-terminal symbols with token sequences and associated action codeblocks. It maintains parser states for building more complex grammars.

DATA Members

DATATypeDescription
aRulesArrayArray of parsing rules: { cNonTerminal, aTokens, bAction }
aStatesArrayParser state machine states

METHOD Reference

MethodDescription
New()Creates an empty parser.
Add( cNonTerminal, aTokens, bAction )Adds a grammar rule. cNonTerminal is the rule name, aTokens defines the expected token sequence, bAction is executed when the rule matches.

Example: Simple Expression Parser

local oParser := TParser():New()

// Define rules: expression -> number operator number
oParser:Add( "expr", { "number", "operator", "number" }, ;
   {|aTokens| Eval( aTokens ) } )

oParser:Add( "number", { "digit" }, ;
   {|aTokens| Val( aTokens[ 1 ] ) } )

TGraph - Charts and Graphs

TGraph inherits from TControl and renders bar charts, line charts, point charts, pie charts, and XY scatter plots directly in a window or dialog. It supports 3D effects, grid lines, legends, multiple series, value display, custom fonts, colors, and can export to BMP or clipboard.

Graph Type Constants

ConstantValueDescription
GRAPH_TYPE_BAR1Bar chart
GRAPH_TYPE_LINE2Line chart
GRAPH_TYPE_POINT3Point/scatter chart
GRAPH_TYPE_PIE4Pie chart
GRAPH_TYPE_ALL5Combined bar + line + point
GRAPH_TYPE_XY_LINES6XY scatter with lines
GRAPH_TYPE_XY_POINTS7XY scatter with points only

Key DATA Members

nTypeNumericGraph type (see constants above)
cTitleCharacterGraph title text
cSubTitCharacterSubtitle text
cTitX, cTitYCharacterX-axis and Y-axis titles
l3DLogicalEnable 3D rendering
lxGrid, lyGridLogicalShow X/Y grid lines
lxVal, lyValLogicalShow X/Y axis values
lLegendsLogicalShow legend
lTitleLogicalShow title
lDottedLogicalUse dotted grid lines
lPopUpLogicalEnable right-click popup menu
aSeriesArraySeries labels
aDataArrayData values array
nBarDNumeric3D bar depth in pixels
nBarSepNumericBar separator width
nPenWidthNumericLine chart pen width
nClrGridNumericGrid color
nClrBackNumericBackground color
nLanguageNumericLanguage for labels (1=English, 2=Spanish, etc.)
cPictureCharacterNumber format mask for values
lFlatLogicalFlat style (no 3D effects, default .F.)

METHOD Reference

Example: Bar Chart

local oDlg, oGraph

// Data series (one array per product)
oGraph:AddSerie( { 15000, 22000, 18000, 25000 }, "Product A", CLR_BLUE )

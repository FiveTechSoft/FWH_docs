TBtnClr / TPickerColor

Fonte: source/classes/tbtnclr.prg

TBtnClr herda de: TControl. TPickerColor é uma classe auxiliar autônoma.

TBtnClr é um controle de botão seletor de cor que exibe uma amostra da cor selecionada e, opcionalmente, um bitmap de seta suspensa. Clicar no botão dispara uma ação (normalmente exibindo o diálogo TPickerColor). TPickerColor fornece um diálogo de seleção de cor com tema, com uma grade de cores padrão, uma linha de cores base/de tema e uma opção "Mais Cores" usando o diálogo ChooseColor do sistema.

TPickerColor

MétodoDescrição
New( nColor, oControl, cTitle1, cTitle2, cTitle3 )Cria o diálogo seletor com títulos de seção personalizáveis
Dialog( nColor )Constrói o diálogo com grade de cores, cores base e botão Mais Cores
Activate()Exibe o diálogo de forma modal; retorna .T. se uma cor foi escolhida

A função livre ChooseColor( nInitClr ) abre o seletor de cores padrão do Windows e retorna a cor RGB selecionada.

Exemplo: Botão de Cor

#include "FiveWin.ch"

function Main()

   local oWnd, oBtnClr, nColor := CLR_RED

   DEFINE WINDOW oWnd TITLE "Color Picker Demo" SIZE 300, 150

   @ 30, 30 BTNBMP oBtnClr PROMPT "Color" ;
      SIZE 40, 25 OF oWnd ;
      ACTION ( nColor := ChooseColor( nColor ), ;
               oBtnClr:SetColor( nColor ), ;
               oBtnClr:Refresh() )

   @ 80, 30 SAY "Selected color shown on button" OF oWnd SIZE 200, 20

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • TBtnClr suporta temas do Windows via C5_DrawThemeBackground com estados de hover e pressionado.
  • A amostra de cor é renderizada como um retângulo preenchido dentro do botão usando nColorSel.
  • nTypeClr controla o posicionamento da amostra: 1 preenche a face do botão, 2 deixa espaço para a seta do popup.
  • TPickerColor exibe uma grade 6x10 de cores padrão mais uma linha de 10 cores de tema/base. O botão "Mais Cores" invoca o diálogo ChooseColor do sistema.

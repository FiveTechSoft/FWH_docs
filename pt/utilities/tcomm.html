TComm

Fonte: source/classes/tcomm.prg

Classe independente

TComm provides serial port (RS-232) communication capabilities for interfacing with modems, serial printers, barcode scanners, and other legacy serial devices. It wraps the Windows COM API with methods for port configuration, data transmission, and flow control.

Principais Membros DATA

DATATipoDescrição
nDeviceNumericCOM port number (1-based: COM1, COM2, etc.)
nIdNumericWindows file handle of the opened COM port
nBaudNumericBaud rate (e.g., 9600, 19200, 115200)
cParityCharacterParity setting: "N" (none), "E" (even), "O" (odd)
nStopNumericStop bits: 1, 1.5, or 2
nDataNumericData bits: 5, 6, 7, or 8
nInQueue / nOutQueueNumericInput and output buffer sizes in bytes

Métodos Principais

MétodoDescrição
New( nDev, nInQ, nOutQ, cStyle, nBaud, cParity, nStop, nData )Open a COM port with the specified parameters
SetUp()Apply port configuration (baud, parity, stop bits, data bits)
Write( cStr )Write a string to the serial port
Close()Close the serial port connection
Break() / UnBreak()Set or clear the serial break signal
Flush()Flush the input and output buffers
Error()Return the last error code

Example: COM1 at 9600 Baud

#include "FiveWin.ch"

function Main()

   local oComm
   local cData

   oComm := TComm():New( 1, 4096, 4096, , 9600, "N", 1, 8 )

   if oComm:nId != 0
      oComm:Write( "AT" + Chr( 13 ) )   // Send AT command to modem
      cData := oComm:Read()
      MsgInfo( cData )
   else
      MsgStop( "Cannot open COM1" )
   endif

   oComm:Close()

return nil

Notas

  • The cStyle parameter in the constructor accepts an extended mode string not commonly used; pass nil for default style.
  • Buffer sizes (nInQueue, nOutQueue) are set at port open time and cannot be changed without reopening.
  • Use Error() after a failed operation to obtain the system error code for diagnostics.
  • The class handles DCB (Device Control Block) configuration internally through the SetUp() method, called automatically from New().

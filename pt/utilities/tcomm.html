TComm

Fonte: source/classes/tcomm.prg

Classe independente

TComm fornece recursos de comunicação por porta serial (RS-232) para interagir com modems, impressoras seriais, leitores de código de barras e outros dispositivos seriais legados. Ela encapsula a API COM do Windows com métodos para configuração de porta, transmissão de dados e controle de fluxo.

Principais Membros DATA

DATATipoDescrição
nDeviceNumericNúmero da porta COM (base 1: COM1, COM2, etc.)
nIdNumericHandle de arquivo do Windows da porta COM aberta
nBaudNumericTaxa de transmissão (ex.: 9600, 19200, 115200)
cParityCharacterConfiguração de paridade: "N" (nenhuma), "E" (par), "O" (ímpar)
nStopNumericBits de parada: 1, 1.5 ou 2
nDataNumericBits de dados: 5, 6, 7 ou 8
nInQueue / nOutQueueNumericTamanhos dos buffers de entrada e saída em bytes

Métodos Principais

MétodoDescrição
New( nDev, nInQ, nOutQ, cStyle, nBaud, cParity, nStop, nData )Abre uma porta COM com os parâmetros especificados
SetUp()Aplica a configuração da porta (baud, paridade, bits de parada, bits de dados)
Write( cStr )Escreve uma string na porta serial
Close()Fecha a conexão da porta serial
Break() / UnBreak()Define ou limpa o sinal de break serial
Flush()Esvazia os buffers de entrada e saída
Error()Retorna o último código de erro

Exemplo: COM1 a 9600 Baud

#include "FiveWin.ch"

function Main()

   local oComm
   local cData

   oComm := TComm():New( 1, 4096, 4096, , 9600, "N", 1, 8 )

   if oComm:nId != 0
      oComm:Write( "AT" + Chr( 13 ) )   // Envia comando AT para o modem
      cData := oComm:Read()
      MsgInfo( cData )
   else
      MsgStop( "Cannot open COM1" )
   endif

   oComm:Close()

return nil

Notas

  • O parâmetro cStyle no construtor aceita uma string de modo estendido pouco usada; passe nil para o estilo padrão.
  • Os tamanhos dos buffers (nInQueue, nOutQueue) são definidos no momento da abertura da porta e não podem ser alterados sem reabri-la.
  • Use Error() após uma operação malsucedida para obter o código de erro do sistema para diagnóstico.
  • A classe trata a configuração do DCB (Device Control Block) internamente através do método SetUp(), chamado automaticamente a partir de New().

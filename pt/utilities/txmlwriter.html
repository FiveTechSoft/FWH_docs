TXmlWriter

Fonte: source/classes/TXmlWriter.prg

TXmlWriter é um escritor de XML mínimo e em fluxo (streaming) que grava diretamente em disco. Ele suporta o padrão clássico OpenTag / Element / CloseTag e produz XML bem-formado com indentação automática e escape de caracteres. Cada método retorna Self, permitindo uma API fluente (encadeável). O escritor usa a E/S de arquivo de baixo nível do Harbour (FCreate / FWrite), de modo que permanece eficiente em memória mesmo para documentos grandes.

Principais Membros DATA

DATATipoDescrição
cFileCharacterCaminho do arquivo de saída
hFileNumericHandle do arquivo obtido de FCreate ( -1 se a criação falhar )
nIndentNumericNível de indentação atual (base 0)
aStackArrayPilha de nomes de tags para aninhamento; garante que CloseTag saiba qual tag fechar
lOpenLogicalO arquivo está aberto e gravável

Métodos Principais

MétodoDescrição
New( cFile )Cria um escritor e abre o arquivo de saída. Retorna Self
Start( cVersion, cEncoding )Escreve a declaração XML <?xml ... ?>. Padrões: "1.0", "UTF-8". Retorna Self
OpenTag( cTag, hAttribs )Abre uma tag nomeada com um hash opcional de atributos. Aumenta a indentação. Retorna Self
CloseTag( cTag )Fecha a tag mais recente (ou a nomeada). Diminui a indentação. Retorna Self
Element( cTag, cValue, hAttribs )Escreve uma tag auto-fechável ou um elemento completo com conteúdo de texto escapado. Retorna Self
Comment( cText )Escreve um comentário XML <!-- ... -->. Retorna Self
CData( cText )Escreve uma seção CDATA <![CDATA[...]]>. Retorna Self
End()Fecha quaisquer tags ainda abertas para garantir uma saída bem-formada. Retorna Self
Destroy()Fecha o handle do arquivo se ainda estiver aberto

Exemplo: Gerar XML

#include "FiveWin.ch"

function Main()

   local oXml := TXmlWriter():New( "catalog.xml" )

   oXml:Start()
   oXml:OpenTag( "catalog", { "version" -> "1.0" } )
   oXml:OpenTag( "book",    { "id" -> "101" } )
   oXml:Element( "title",   "FiveWin Programming" )
   oXml:Element( "author",  "Antonio Linares" )
   oXml:Element( "price",   "49.95", { "currency" -> "USD" } )
   oXml:CloseTag( "book" )
   oXml:CloseTag( "catalog" )
   oXml:End()
   oXml:Destroy()

return nil

Notas

  • Todos os métodos públicos (exceto New e Destroy) retornam Self, o que permite encadear chamadas de método: oXml:Start():OpenTag(...):Element(...):CloseTag():End().
  • Os hashes de atributos usam a sintaxe key -> value (hashes do Harbour). Os valores são automaticamente escapados para XML.
  • O método Escape() trata as cinco entidades XML predefinidas: &, <, >, " e '.
  • End() fecha automaticamente quaisquer tags que ainda restem na pilha, garantindo uma saída bem-formada mesmo que o chamador tenha omitido chamadas explícitas de fechamento.
  • O escritor usa indentação de dois espaços por nível de aninhamento, controlada por cIndStr.

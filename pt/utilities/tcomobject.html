TComObject

Fonte: source/classes/tcomobj.prg

Classe independente

TComObject fornece um wrapper genérico em torno de objetos COM (Component Object Model) do Windows através da interface IDispatch. Ela armazena o ponteiro nIDispatch e expõe métodos para invocar métodos COM, obter/definir propriedades e encapsular automaticamente ponteiros IDispatch retornados. A classe suporta chamadas COM encadeadas através de seu manipulador de erros: nomes de propriedades prefixados com _ definem valores, nomes de propriedades simples obtêm valores, e valores de retorno IDispatch são automaticamente encapsulados em novas instâncias de TComObject.

Principais Membros DATA

DATATipoDescrição
nIDispatchNumericPonteiro para a interface COM IDispatch

Métodos Principais

MétodoDescrição
New( cProgID )Cria um objeto COM a partir de uma string ProgID (ex.: "Word.Application")
Invoke( cMethod, u1, u2, u3 )Invoca um método COM com até três parâmetros opcionais
End()Libera o objeto COM e libera o ponteiro IDispatch
ClassName()Retorna o nome da classe Harbour ("TComObject")

Exemplo: Automação do Word

#include "FiveWin.ch"

function Main()

   local oWord, oDoc

   // Cria o objeto COM Word Application
   oWord := TComObject():New( "Word.Application" )

   // Define propriedade (prefixo com _)
   oWord:_Visible := .T.

   // Acessa a coleção de documentos (retorna TComObject encapsulado automaticamente)
   oDoc := oWord:Documents

   // Adiciona um novo documento
   oDoc:Add()

   // Invoca métodos
   oWord:Invoke( "Activate" )

   // Define o conteúdo
   oWord:Selection:TypeText( "Hello from FiveWin!" )

   MsgInfo( "Word is running. Press OK to close." )

   // Limpeza
   oWord:Quit()
   oWord:End()

return nil

Notas

  • O manipulador de erros (Error()) é o núcleo da conveniência do TComObject. Quando você acessa uma propriedade sem o prefixo de underscore, ele chama IDispatch::GetIDsOfNames e Invoke com DISPATCH_PROPERTYGET. Se o valor de retorno for outro ponteiro IDispatch, ele é encapsulado automaticamente em um novo TComObject, permitindo navegação encadeada como oWord:Selection:Text.
  • Definir uma propriedade requer o prefixo de underscore (ex.: oWord:_Visible := .T.), que aciona DISPATCH_PROPERTYPUT.
  • Use Invoke() para métodos que precisam de controle explícito sobre os parâmetros, ou quando o comportamento de encapsulamento automático não se aplica.
  • Sempre chame End() para liberar o ponteiro da interface COM e evitar vazamentos de recursos.
  • Requer o subsistema COM do Windows (OLE32.dll). Funciona em todas as plataformas Windows de 32 e 64 bits.

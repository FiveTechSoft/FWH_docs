TRtfFile - Gerador de Documentos de Ajuda RTF/HPJ

Fonte: source/classes/rtffile.prg

TRtfFile gera arquivos no formato Rich Text Format (.RTF) adequados para compilação em arquivos de Ajuda do Windows (.HLP) com o Microsoft Help Workshop (HCW.EXE). Ele produz entradas de tópicos curtos e longos, links de salto (jump) e pop-up, referências a bitmaps, IDs de tópicos, listas de "veja também" e quebras de página, tudo em sintaxe RTF válida que o Compilador de Ajuda compreende.

Métodos Principais

MétodoDescrição
New( cFile )Cria um novo arquivo RTF com o cabeçalho de ajuda padrão (formatação de notas de rodapé)
WriteShort( cText, cJump, lPopup, cBmp )Escreve um tópico curto. cText é exibido; cJump é a string de contexto; lPopup especifica pop-up vs. salto; cBmp opcionalmente incorpora um bitmap
WriteLong( cText )Escreve um parágrafo de tópico longo com texto do corpo
WriteId( cId )Escreve uma nota de rodapé # com a string de ID do tópico (usada como nome de contexto para os saltos)
WriteSeeAlso( cList )Escreve uma nota de rodapé $ com uma lista "Veja Também" de títulos de tópicos relacionados
NewPage()Insere uma quebra de página (form-feed) para separar tópicos no RTF
End()Finaliza o arquivo RTF com as chaves de fechamento e o fecha

Exemplo: Gerar um Arquivo de Tópicos de Ajuda

#include "FiveWin.ch"

function Main()

   local oRtf := TRtfFile():New( "help.rtf" )

   // Primeiro tópico: Introdução
   oRtf:WriteId( "INTRO" )
   oRtf:WriteShort( "Bem-vindo ao MyApp", "INTRO", .F., "" )
   oRtf:WriteLong( "Esta é a introdução ao MyApp." )
   oRtf:WriteLong( "Clique abaixo para mais informações." )
   oRtf:WriteSeeAlso( "Instalação|Configuração" )
   oRtf:NewPage()

   // Segundo tópico: Instalação
   oRtf:WriteId( "INSTALL" )
   oRtf:WriteShort( "Guia de Instalação", "INSTALL", .F., "" )
   oRtf:WriteLong( "Siga estes passos para instalar o MyApp." )
   oRtf:WriteSeeAlso( "Introdução" )
   oRtf:NewPage()

   oRtf:End()
   MsgInfo( "Arquivo de ajuda help.rtf gerado" )

return nil

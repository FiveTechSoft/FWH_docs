FWStack

Fonte: source/classes/fwstack.prg

FWStack implementa uma estrutura de dados de pilha LIFO (Last-In, First-Out) clássica. Ela armazena itens em um array interno e fornece operações push, pop e peek. O construtor e o método Push() aceitam listas de argumentos de comprimento variável, permitindo adicionar múltiplos itens em uma única chamada. FWStack é útil para operações de desfazer/refazer, avaliação de expressões e qualquer cenário que exija gerenciamento de dados no estilo último a entrar, primeiro a sair.

Principais Membros DATA

DATATipoDescrição
aStackArrayArray interno que contém os itens da pilha

Métodos Principais

MétodoDescrição
New( item1, item2, ... )Cria uma pilha inicializada com os itens fornecidos (da base ao topo)
Push( item1, item2, ... )Empilha um ou mais itens no topo da pilha. Retorna Self para encadeamento.
Pop()Remove e retorna o item do topo da pilha. Retorna nil se a pilha estiver vazia.
Peek( n )Retorna o n-ésimo item a partir do topo sem removê-lo. n assume 1 por padrão (o topo). Um n negativo indexa a partir da base (por exemplo, -1 é a base). Retorna nil se o índice estiver fora do intervalo.
Size()Retorna o número de itens na pilha
Clear()Remove todos os itens da pilha. Retorna Self para encadeamento.

Exemplo: Empilhar/Desempilhar Valores

#include "FiveWin.ch"

function Main()

   local oStack := FWStack():New()

   // Empilha vários itens
   oStack:Push( 10, 20, 30, 40, 50 )

   ? "Stack size:", oStack:Size()       // 5

   // Espia o item do topo sem removê-lo
   ? "Top item:", oStack:Peek()         // 50

   // Espia o item 2 a partir do topo
   ? "Second from top:", oStack:Peek( 2 )  // 40

   // Desempilha os itens
   while oStack:Size() > 0
      ? "Popped:", oStack:Pop()
   end

   ? "Stack is empty:", oStack:Size() == 0  // .T.

   // Inicializa com itens
   oStack := FWStack():New( "apple", "banana", "cherry" )
   ? oStack:Pop()   // "cherry"
   ? oStack:Pop()   // "banana"
   ? oStack:Pop()   // "apple"
   ? oStack:Pop()   // nil (vazia)

return nil

Notas

  • Os métodos de FWStack que aceitam argumentos variáveis (New, Push) funcionam tanto com Harbour quanto com xHarbour. No xHarbour, eles aceitam um parâmetro de array em vez de varargs.
  • O método Peek() sem argumento retorna o item do topo sem removê-lo. Com um argumento positivo n, ele busca n posições a partir do topo (1 = topo). Com um argumento negativo, ele conta a partir da base (-1 = base).
  • Push() e Clear() retornam Self, possibilitando o encadeamento de métodos: oStack:Clear():Push( 1, 2, 3 ):Push( 4 ).
  • Pop() retorna nil quando a pilha está vazia -- teste com oStack:Size() > 0 antes de desempilhar.

TClipBoard - Área de Transferência do Windows

Fonte: source/classes/clipbrd.prg

TClipBoard encapsula a API da Área de Transferência do Windows (OpenClipboard, GetClipboardData, SetClipboardData, CloseClipboard, etc.) em uma interface orientada a objetos. Ela suporta texto ANSI e Unicode, imagens bitmap, metafiles e listas de arquivos (a partir da cópia/colagem do Explorer). A classe gerencia automaticamente a posse da área de transferência e a sequência de abrir/esvaziar/fechar.

Membros DATA

DATATipoDescrição
nFormatNuméricoFormato padrão da área de transferência para operações de texto (CF_TEXT)
oWndObjetoJanela proprietária para operações da área de transferência

Métodos Principais

MétodoDescrição
New( nFormat )Cria o objeto da área de transferência com formato opcional (padrão CF_TEXT)
SetText( c )Copia texto ANSI para a área de transferência
GetText()Recupera texto ANSI da área de transferência
SetWideText( c )Copia texto Unicode (wide) para a área de transferência
GetUnicodeText()Recupera texto Unicode da área de transferência
SetBitmap( oBmp )Copia um bitmap para a área de transferência
GetBitmap()Recupera um bitmap da área de transferência
SetMetaFile( o )Copia um metafile para a área de transferência
GetMetaFile()Recupera um metafile da área de transferência
GetFiles()Retorna um array de nomes de arquivos de uma área de transferência CF_HDROP (copiados do Explorer)
Clear()Limpa todo o conteúdo da área de transferência
Open()Abre a área de transferência para múltiplas operações (deve chamar Empty() e Close() em seguida)
Empty()Esvazia o conteúdo da área de transferência (deve ser chamado após Open() antes de definir dados)
Close()Fecha a área de transferência (deve ser chamado após Open())

Exemplo: Copiar/Colar Texto e Arquivos

#include "FiveWin.ch"

function Main()

   local oClip := TClipBoard():New()

   // Copia texto para a area de transferencia
   oClip:SetText( "Hello from FiveWin!" )
   ? "Text copied to clipboard"

   // Cola texto da area de transferencia
   ? "Clipboard content:", oClip:GetText()

   // Copia uma lista de arquivos (como se viesse do Explorer)
   oClip:Open()
   oClip:Empty()
   // ... define dados CF_HDROP via API do Windows
   oClip:Close()

   // Le arquivos copiados do Explorer
   local aFiles := oClip:GetFiles()
   if ValType( aFiles ) == "A"
      AEval( aFiles, {|c| ? "File: " + c } )
   endif

return nil

Exemplo: Copiar um Bitmap

function CopyBitmap()

   local oClip := TClipBoard():New()
   local oBmp  := TBitmap():New( "logo.bmp" )

   oClip:SetBitmap( oBmp )
   MsgInfo( "Bitmap copied to clipboard" )

return nil

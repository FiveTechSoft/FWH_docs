RRW (Rave Reports Wrapper)

Fonte: source/classes/rrw.prg

Classe independente

RRW é uma classe wrapper para o motor de execução do Rave Reports (RRW). Ela gerencia a execução de relatórios através de um arquivo de controle (registro de relatórios baseado em DBF), gera um arquivo de controle .CNT temporário, inicia o motor RRWRUN.EXE como um processo externo e coleta os resultados da execução. Os relatórios são definidos em um DBF de controle (padrão RREPORTS.DBF) e executados pelo nome.

Principais Membros DATA

DATATipoDescrição
cRi_ReportCharacterNome do relatório a executar
cRi_OutFileCharacterCaminho do arquivo de saída para os resultados
cRi_PrinterCharacterModo de impressão: "P"=impressora, "D"=pré-visualização
cRi_FilterCharacterExpressão de filtro opcional
cRi_QueryCharacterModo de consulta: "S"=silencioso, "?"=solicitar, "O"=filtro
nRi_CopiesNumericNúmero de cópias a imprimir
lActiveLogicalIndica se o objeto de relatório está ativo e pronto
cDataDirectoryCharacterDiretório dos arquivos de dados
cLibDirectoryCharacterDiretório da biblioteca de relatórios
cControlFileCharacterCaminho do arquivo de controle .CNT gerado
cOutFileCharacterCaminho do arquivo de resultados .OUT
aResultsArrayResultados da execução: { ecode, emsg, nReports, nPages, nRecNo }

Métodos Principais

MétodoDescrição
New( cControlFile, cReport, lQuery, lPreview, nBegPage, nEndPage, cDataDirectory, cLibDirectory, cTempDir, cOutFile )Inicializa uma execução de relatório: abre o DBF de controle, localiza o relatório, gera o arquivo de controle .CNT
End()Fecha as áreas de banco de dados e marca como inativo
Print()Executa o relatório via RRWRUN.EXE e coleta os resultados
Activate()Sinônimo de Print()
SetFilter( cVar )Define uma expressão de filtro e alterna para o modo de consulta por filtro
SetPrinter( cVar )Define o nome da impressora no arquivo de controle
Results()Lê o arquivo de resultados .OUT; retorna um array com código de erro, mensagem, quantidade de relatórios, quantidade de páginas, número do registro
ShowError()Exibe uma caixa de mensagem com os detalhes do erro de execução

Exemplo: Executar um Relatório Rave

#include "FiveWin.ch"

function Main()

   local oReport

   oReport := RRW():New( "RREPORTS.DBF", "Invoice", .F., .T., 1, 99999, ;
                         "\data", "\reports" )

   if oReport != nil
      oReport:Print()
      if oReport:aResults[ 1 ] != "0"
         oReport:ShowError()
      else
         MsgInfo( "Relatório gerado com sucesso" )
      endif
      oReport:End()
   endif

return nil

Notas

  • O DBF de controle (RREPORTS.DBF) deve conter ao menos um campo RI_REPORT para o nome do relatório, RI_LIBRARY para o arquivo da biblioteca de relatórios, RI_WTITLE para o título da janela e RI_WPTR para o nome da impressora.
  • A classe invoca RRWRUN.EXE (o runtime do Rave Reports) como um processo externo via WaitRun().
  • Os resultados são gravados em um arquivo .OUT no formato INI e relidos via TIni.

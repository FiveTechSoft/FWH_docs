TMci

Fonte: source/classes/tmci.prg

Classe independente

TMci oferece controle de reprodução multimídia através da API do Windows Media Control Interface (MCI). Suporta a reprodução de arquivos de áudio e vídeo, incluindo vídeo AVI, áudio de CD, WAV, MIDI e outros dispositivos compatíveis com MCI. A classe pode reproduzir mídia em uma janela ou em tela cheia.

Principais Membros DATA

DATATipoDescrição
nErrorNumericÚltimo código de erro MCI; zero indica sucesso
nIdNumericIdentificador do dispositivo MCI atribuído na abertura
cTypeCharacterTipo de dispositivo: "AVIVideo", "CDAudio", "WaveAudio", "Sequencer", etc.
cFileNameCharacterCaminho para o arquivo multimídia sendo reproduzido
oWndObjectJanela pai para a reprodução de vídeo

Métodos Principais

MétodoDescrição
New( cDev, cFile )Cria um novo objeto MCI para o tipo de dispositivo e arquivo de mídia informados
lOpen()Abre o dispositivo MCI; retorna .T. em caso de sucesso
Play( nFrom, nTo, hWnd )Reproduz um segmento de nFrom até nTo, opcionalmente em um handle de janela
PlayFull()Reproduz a mídia em modo de tela cheia
SetWindow( oWnd )Define a janela pai para a saída de vídeo
Position()Retorna a posição de reprodução atual
Length()Retorna a duração total da mídia
SendStr( cMci )Envia uma string de comando MCI bruta diretamente ao dispositivo
cGetError()Retorna uma descrição legível do último erro
End()Fecha o dispositivo MCI e libera os recursos

Exemplo: Reproduzir Arquivo AVI

#include "FiveWin.ch"

function Main()

   local oMci, oWnd

   DEFINE WINDOW oWnd TITLE "MCI Video Player" SIZE 640, 480

   oMci := TMci():New( "AVIVideo", "sample.avi" )

   if oMci:lOpen()
      oMci:SetWindow( oWnd )
      oMci:Play()
      MsgInfo( "Playing: " + oMci:cFileName )
   else
      MsgStop( "Cannot open: " + oMci:cGetError() )
   endif

   ACTIVATE WINDOW oWnd CENTERED

   oMci:End()

return nil

Notas

  • O parâmetro cType determina qual driver MCI é carregado. Tipos comuns incluem "AVIVideo", "WaveAudio", "CDAudio" e "Sequencer" (MIDI).
  • Chame lOpen() antes de qualquer operação de reprodução. Verifique o valor de retorno para confirmar que o dispositivo foi aberto com sucesso.
  • Use Play() com um handle de janela para incorporar o vídeo na interface da sua aplicação, ou PlayFull() para reprodução em tela cheia.
  • O método SendStr() fornece acesso de baixo nível a qualquer string de comando MCI para operações avançadas não cobertas pelos métodos da classe.
  • Sempre chame End() ao terminar para liberar o dispositivo MCI e evitar vazamentos de recursos.

Interoperabilidade OLE, COM, ActiveX & .NET

O FiveWin oferece suporte abrangente para automação COM/OLE do Windows, incorporação de ActiveX e APIs modernas de e-mail baseadas em nuvem. Essas classes permitem automatizar aplicações do Microsoft Office, incorporar controles ActiveX em diálogos, interagir com assemblies .NET e enviar e-mail através das APIs do Gmail e Outlook.

TOleAuto - Automação OLE

TOleAuto é a classe principal do FiveWin para automação OLE/COM. Ela encapsula a funcionalidade win_oleAuto do Harbour, permitindo criar e controlar objetos OLE como Microsoft Word, Excel, Outlook, Internet Explorer e qualquer outro servidor de automação. Propriedades e métodos do objeto OLE são acessados de forma transparente através do manipulador de erros do Harbour -- você os chama como se fossem membros nativos da classe.

Como Funciona

Quando você chama TOleAuto():New("Word.Application"), o FiveWin chama CreateOleObject() que invoca CoCreateInstance() internamente para criar o objeto COM. O ponteiro IDispatch retornado é armazenado no DATA hObj. Qualquer acesso a método ou propriedade que não esteja definido na classe é interceptado pelo manipulador OnError, que o encaminha através de OleInvoke() ou OleGetProperty()/OleSetProperty().

Membros DATA

DATATipoDescrição
hObjPointer/NumericPonteiro IDispatch para o objeto de automação OLE

Referência de METHODs

MétodoDescrição
New( cClassName )Cria um objeto de automação OLE pelo ProgID (ex.: "Excel.Application", "Word.Application").
End()Libera o objeto COM e chama OleUninitialize().
(qualquer propriedade)Obtém/Define qualquer propriedade OLE via manipulador OnError. Ex.: oExcel:Visible := .T.
(qualquer método)Invoca qualquer método OLE de forma transparente. Ex.: oWord:Documents:Add()

Exemplo: Criar um Documento Word

function CreateWordDoc()
   local oWord, oDoc, oSelection

   // Create Word application
   oWord := TOleAuto():New( "Word.Application" )
   oWord:Visible := .T.

   // Add a new document
   oDoc := oWord:Documents:Add()

   // Get the selection (cursor) and type text
   oSelection := oWord:Selection
   oSelection:Font:Name := "Arial"
   oSelection:Font:Size := 14
   oSelection:Font:Bold := .T.
   oSelection:TypeText( "FiveWin Report" )
   oSelection:TypeParagraph()

   oSelection:Font:Size := 11
   oSelection:Font:Bold := .F.
   oSelection:TypeText( "Generated on " + DToC( Date() ) + " at " + Time() )
   oSelection:TypeParagraph()
   oSelection:TypeParagraph()
   oSelection:TypeText( "This document was created from a Harbour/FiveWin application." )

   // Save and close
   oDoc:SaveAs( "c:\temp\report.docx" )

   MsgInfo( "Word document created successfully!" )

   // Don't quit Word - let user review the document
   // oWord:Quit()

return nil

Exemplo: Criar uma Planilha Excel

function CreateExcel()
   local oExcel, oBook, oSheet, n

   oExcel := TOleAuto():New( "Excel.Application" )
   oExcel:Visible := .T.

   oBook  := oExcel:WorkBooks:Add()
   oSheet := oExcel:ActiveSheet

   // Column headers
   oSheet:Cells( 1, 1 ):Value := "Product"
   oSheet:Cells( 1, 2 ):Value := "Quantity"
   oSheet:Cells( 1, 3 ):Value := "Price"
   oSheet:Cells( 1, 4 ):Value := "Total"

   // Bold headers
   oSheet:Range( "A1:D1" ):Font:Bold := .T.
   oSheet:Range( "A1:D1" ):Interior:Color := RGB( 200, 220, 255 )

   // Data rows
   local aData := { ;
      { "Widget A", 100, 9.99 }, ;
      { "Widget B",  50, 19.99 }, ;
      { "Widget C", 200, 4.99 }, ;
      { "Widget D",  75, 29.99 } }

   for n := 1 to Len( aData )
      oSheet:Cells( n + 1, 1 ):Value := aData[ n ][ 1 ]
      oSheet:Cells( n + 1, 2 ):Value := aData[ n ][ 2 ]
      oSheet:Cells( n + 1, 3 ):Value := aData[ n ][ 3 ]
      oSheet:Cells( n + 1, 4 ):Formula := "=B" + AllTrim( Str( n + 1 ) ) + ;
                                            "*C" + AllTrim( Str( n + 1 ) )
   next

   // Total formula
   oSheet:Cells( 6, 3 ):Value := "Grand Total:"
   oSheet:Cells( 6, 3 ):Font:Bold := .T.
   oSheet:Cells( 6, 4 ):Formula := "=SUM(D2:D5)"
   oSheet:Cells( 6, 4 ):Font:Bold := .T.

   // Auto-fit columns
   oSheet:Columns( "A:D" ):AutoFit()

   oBook:SaveAs( "c:\temp\products.xlsx" )
   MsgInfo( "Excel file created!" )

return nil

Exemplo: Enviar E-mail via Outlook

function SendOutlookEmail()
   local oOutlook, oMail

   oOutlook := TOleAuto():New( "Outlook.Application" )

   // Create a new mail item (olMailItem = 0)
   oMail := oOutlook:CreateItem( 0 )

   oMail:To      := "customer@example.com"
   oMail:CC      := "manager@example.com"
   oMail:Subject := "Monthly Report - " + CMonth( Date() )
   oMail:Body    := "Dear Customer," + CRLF + CRLF + ;
                     "Please find attached the monthly report." + CRLF + CRLF + ;
                     "Best regards," + CRLF + "Support Team"

   // Attach a file
   oMail:Attachments:Add( "c:\reports\monthly.pdf" )

   // Display for review (use :Send() to send directly)
   oMail:Display()

   MsgInfo( "Email composed in Outlook" )

return nil

TComObject - Interface COM de Baixo Nível

TComObject é uma alternativa de mais baixo nível ao TOleAuto para interoperabilidade COM. Ele armazena o ponteiro IDispatch como valor numérico e fornece chamadas Invoke() explícitas. Propriedades são acessadas via manipulador OnError, que encaminha através de OleGetProperty/OleSetProperty. Quando um método retorna outro objeto COM, TComObject automaticamente o encapsula.

Membros DATA

DATATipoDescrição
nIDispatchNumericPonteiro IDispatch bruto para o objeto COM

Referência de METHODs

MétodoDescrição
New( cClassName )Cria objeto COM pela string ProgID, ou encapsula um IDispatch existente se um valor numérico for passado.
Invoke( cMethodName, uParam1, uParam2, uParam3 )Invoca explicitamente um método. Retorna um novo TComObject se o resultado for um IDispatch.
ClassName()Retorna o nome da classe do objeto COM via OleGetProperty.
End()Chama OleUninitialize() para liberar o objeto COM.

Exemplo: Usando TComObject

local oCom := TComObject():New( "Scripting.FileSystemObject" )

if oCom:nIDispatch != 0
   ? "Drives available:"

   local oDrives := oCom:Drives
   ? "Total drives:", oDrives:Count

   // Check if C: drive exists
   if oCom:DriveExists( "C:" )
      local oDrive := oCom:GetDrive( "C:" )
      ? "C: Drive - Total:", oDrive:TotalSize, "Free:", oDrive:FreeSpace
   endif

   oCom:End()
endif

TActiveX - Controles ActiveX Incorporados

TActiveX herda de TControl e permite incorporar qualquer controle ActiveX/OCX dentro de uma janela ou diálogo do FiveWin. Ele cria o contêiner ActiveX usando incorporação OLE do Windows, e então expõe os métodos e propriedades do controle através de um objeto TOleAuto interno. Eventos do controle ActiveX podem ser capturados via o codeblock bOnEvent.

Membros DATA

DATATipoDescrição
hActiveXNumericHandle para o contêiner ActiveX
cProgIDCharacterProgID do controle ActiveX (ex.: "Shell.Explorer.2")
cStringCharacterString de exibição para o controle ActiveX
oOleAutoObjectWrapper TOleAuto interno para o IDispatch do controle
aPropertiesArrayPropriedades disponíveis (preenchido por ReadTypes)
aMethodsArrayMétodos disponíveis (preenchido por ReadTypes)
aEventsArrayEventos disponíveis (preenchido por ReadTypes)
bOnEventCodeblockManipulador de eventos: {|nEvent, aParams, pParams| ... }

Referência de METHODs

MétodoDescrição
New( oWnd, cProgID, nRow, nCol, nWidth, nHeight )Cria controle ActiveX em oWnd na posição informada.
ReDefine( nId, oWnd, cProgID )Redefine a partir de um ID de controle de recurso de diálogo.
Do( ... )Invoca um método no objeto OLE subjacente. Passe o nome do método e os parâmetros.
GetProp( cPropName )Obtém o valor de uma propriedade do controle ActiveX.
SetProp( cPropName, uValue )Define o valor de uma propriedade do controle ActiveX.
ReadTypes()Lê informações de tipo (propriedades, métodos, eventos) do controle.
OnEvent( nEvent, aParams, pParams )Despachante de eventos interno. Sobrescreva bOnEvent para tratamento personalizado.
Destroy()Destrói o contêiner ActiveX e libera os recursos.

Exemplo: Incorporar um Navegador Web

function EmbedBrowser()
   local oDlg, oActiveX

   DEFINE DIALOG oDlg TITLE "Embedded Browser" SIZE 800, 600

   // Shell.Explorer.2 is Internet Explorer's ActiveX ProgID
   oActiveX := TActiveX():New( oDlg, "Shell.Explorer.2", 0, 0, 800, 600 )

   // Handle navigation events
   oActiveX:bOnEvent := {| nEvent, aParams |  ;
      If( nEvent == 252, ( MsgInfo( "Navigating to: " + aParams[ 2 ] ) ), ) }

   ACTIVATE DIALOG oDlg CENTER ;
      ON INIT ( oActiveX:Navigate( "https://www.fivetechsoft.com" ) )

return nil

Exemplo: Incorporar um Visualizador de PDF

function ShowPDF( cPdfFile )
   local oDlg, oActiveX

   DEFINE DIALOG oDlg TITLE "PDF Viewer" SIZE 800, 600

   // Adobe Acrobat Reader ActiveX
   oActiveX := TActiveX():New( oDlg, "AcroPDF.PDF.1", 0, 0, 800, 600 )

   ACTIVATE DIALOG oDlg CENTER ;
      ON INIT ( oActiveX:LoadFile( cPdfFile ), ;
                oActiveX:SetView( "FitH" ) )

return nil

Exemplo: Incorporar o Windows Media Player

function PlayMedia( cMediaFile )
   local oDlg, oWMP

   DEFINE DIALOG oDlg TITLE "Media Player" SIZE 640, 480

   oWMP := TActiveX():New( oDlg, "WMPlayer.OCX", 0, 0, 640, 480 )

   ACTIVATE DIALOG oDlg CENTER ;
      ON INIT ( oWMP:URL := cMediaFile )

return nil

TDotNet - Interoperabilidade com .NET

O FiveWin suporta a chamada de assemblies .NET a partir do Harbour através de interoperabilidade COM. Embora não exista uma classe TDotNet dedicada no código-fonte, componentes .NET que expõem interfaces COM podem ser instanciados via TOleAuto. Para assemblies .NET personalizados, você pode registrá-los para interoperabilidade COM usando regasm e então criá-los como qualquer outro objeto COM.

Abordagem: Usando .NET via Interoperabilidade COM

sequenceDiagram participant Harbour as Harbour/FiveWin participant COM as Runtime COM participant CLR as .NET CLR participant Assembly as Assembly .NET Harbour->>COM: CreateOleObject("MyLib.MyClass") COM->>CLR: Carregar Host CLR CLR->>Assembly: Instanciar classe Assembly-->>COM: Ponteiro IDispatch COM-->>Harbour: Objeto TOleAuto Harbour->>COM: Chamadas de Propriedade/Método COM->>Assembly: Invocar via IDispatch

Exemplo: Chamando .NET via COM

// Step 1: Register .NET assembly for COM interop (run once from command line):
//   regasm MyLibrary.dll /tlb:MyLibrary.tlb /codebase

// Step 2: Use from Harbour/FiveWin
function UseDotNet()
   local oDotNet

   TRY
      oDotNet := TOleAuto():New( "MyLibrary.MyClass" )
      ? oDotNet:MyMethod( "Hello from Harbour!" )
      ? oDotNet:MyProperty
      oDotNet:End()
   CATCH
      MsgAlert( ".NET component not registered or not available" )
   END

return nil

Exemplo: Usando Bibliotecas do Sistema .NET

// The .NET mscorlib types exposed via COM can be accessed directly
function DotNetExample()
   local oNet

   // Create a .NET StringBuilder via COM
   TRY
      oNet := TOleAuto():New( "System.Text.StringBuilder" )
      oNet:Append( "Hello" )
      oNet:Append( " World" )
      ? oNet:ToString()
   CATCH
      // .NET COM interop may not be available on all systems
      MsgAlert( "Requires .NET COM registration" )
   END

return nil

TGmail - Integração com a API do Gmail

TGmail herda de TOAuth e fornece acesso autenticado via OAuth2 à API do Gmail. Utiliza libcurl para comunicação HTTP e suporta envio de e-mails com conteúdo HTML e anexos de arquivo. A autenticação é tratada através do fluxo OAuth2 do Google com tokens de atualização (refresh tokens).

Membros DATA

DATATipoDescrição
cTokenCharacterToken de atualização OAuth2 (refresh token)
hTokenHashResposta de token parseada (access_token, etc.)
hConfigHashConfiguração OAuth: client_id, client_secret, redirect_uri

Referência de METHODs

MétodoDescrição
New( cToken )Cria instância TGmail com refresh token opcional.
SetConfig( hConfig )Define o hash de configuração OAuth2 com client_id, client_secret, redirect_uri.
SetToken( cToken )Define o refresh token.
Auth()Inicia o fluxo de autorização OAuth2. Abre o navegador para consentimento do usuário.
IsAuth()Verifica se o token atual é válido (valida contra o endpoint de informações de token do Google).
GetToken( cCode )Troca o código de autorização por um token de acesso.
Me()Retorna as informações de perfil do usuário autenticado.
Send( cTo, cSubject, cMessage, lHTML, aAttachment )Envia um e-mail. lHTML: .T. para corpo HTML. aAttachment: array de caminhos de arquivo.
Revoke()Revoga o token OAuth2.

Exemplo: Enviar E-mail via Gmail

function SendGmail()
   local oGmail := TGmail():New()

   // Configure OAuth2 credentials (from Google Cloud Console)
   oGmail:SetConfig( { ;
      "client_id"     => "your-client-id.apps.googleusercontent.com", ;
      "client_secret" => "your-client-secret", ;
      "redirect_uri"  => "http://localhost:8888" ;
   } )

   // First-time authentication (opens browser)
   if ! oGmail:IsAuth()
      oGmail:Auth()
   endif

   if oGmail:IsAuth()
      // Send a plain text email
      oGmail:Send( "recipient@example.com", ;
                   "Hello from FiveWin", ;
                   "This email was sent using TGmail class.", ;
                   .F. )   // .F. = plain text

      // Send HTML email with attachment
      oGmail:Send( "recipient@example.com", ;
                   "Monthly Report", ;
                   "<h1>Report</h1><p>Please see attached.</p>", ;
                   .T., ;   // .T. = HTML
                   { "c:\reports\monthly.pdf" } )

      MsgInfo( "Emails sent successfully!" )
   else
      MsgAlert( "Gmail authentication failed" )
   endif

return nil

TOutlookMail - API de E-mail do Outlook

TOutlookMail herda de TOAuth e fornece acesso autenticado via OAuth2 à API do Microsoft Graph para envio de e-mail através do Outlook/Office 365. Assim como TGmail, utiliza libcurl e suporta conteúdo HTML, anexos de arquivo, destinatários CC e BCC. Trata automaticamente a rotação de refresh tokens quando a Microsoft os rotaciona.

Membros DATA

DATATipoDescrição
cTokenCharacterToken de atualização OAuth2 (refresh token)
hTokenHashResposta de token parseada (access_token, refresh_token, etc.)
hConfigHashConfiguração OAuth: client_id, client_secret, redirect_uri, tenant
hUserHashInformações do perfil do usuário autenticado

Referência de METHODs

MétodoDescrição
New( cToken )Cria instância com refresh token opcional.
SetConfig( hConfig )Define configuração OAuth2: client_id, client_secret, redirect_uri (com porta para servidor local).
SetToken( cToken )Define o refresh token.
Auth()Inicia o fluxo de autorização OAuth2 da Microsoft.
IsAuth()Valida o token, atualiza automaticamente se expirado. Atualiza o refresh_token se rotacionado.
GetToken( cCode )Troca o código de autorização por tokens de acesso/atualização.
Me( cPhoto )Retorna perfil do usuário. Opcionalmente salva foto do perfil no caminho cPhoto.
Send( aTo, cSubject, cMessage, lHTML, aAttachment, aBCC, aCC )Envia e-mail. aTo/aBCC/aCC são arrays de endereços de e-mail.
Revoke()Revoga o token OAuth2.

Exemplo: Enviar E-mail via Outlook/Office 365

function SendOutlookAPI()
   local oMail := TOutlookMail():New()

   // Configure Azure AD app credentials
   oMail:SetConfig( { ;
      "client_id"     => "your-azure-app-client-id", ;
      "client_secret" => "your-azure-client-secret", ;
      "redirect_uri"  => "http://localhost:9090", ;
      "tenant"        => "common" ;
   } )

   // Authenticate (opens browser for Microsoft login)
   if ! oMail:IsAuth()
      oMail:Auth()
   endif

   if oMail:IsAuth()
      // Get user info
      local hUser := oMail:Me()
      ? "Sending as:", hUser[ "displayName" ], hUser[ "mail" ]

      // Send email with CC and BCC
      oMail:Send( ;
         { "recipient@example.com", "another@example.com" }, ;  // To
         "Project Update", ;                                      // Subject
         "<h2>Weekly Update</h2><p>All tasks completed.</p>", ; // Body
         .T., ;                                                   // HTML
         { "c:\docs\status.pdf" }, ;                             // Attachments
         { "boss@example.com" }, ;                                // BCC
         { "team@example.com" } )                                 // CC

      MsgInfo( "Email sent via Outlook API!" )
   endif

return nil

Dicas e Boas Práticas

Tratamento de Erros OLE

// Always wrap OLE calls in TRY/CATCH
TRY
   local oExcel := TOleAuto():New( "Excel.Application" )
   // ... work with Excel
   oExcel:Quit()
CATCH oErr
   MsgAlert( "OLE Error: " + oErr:Description + CRLF + ;
             "Make sure the application is installed." )
END

Padrão de Tratamento de Eventos ActiveX

// The bOnEvent codeblock receives:
//   nEvent  - numeric event ID
//   aParams - array of event parameters
//   pParams - raw parameter pointers

oActiveX:bOnEvent := {| nEvent, aParams, pParams |  ;
   do case ;
   case nEvent == 250 ;   // BeforeNavigate2
      ? "Navigating to:", aParams[ 2 ] ;
   case nEvent == 252 ;   // DocumentComplete
      ? "Page loaded" ;
   case nEvent == 259 ;   // NewWindow3
      ? "Popup blocked" ;
   endcase ;
}

Liberando Objetos COM

Sempre libere os objetos COM quando terminar. Para aplicações do Office, chame Quit() antes de liberar, ou o processo pode permanecer na memória:

// Correct cleanup order for Excel:
oSheet := nil
oBook:Close( .F. )    // .F. = don't save
oBook  := nil
oExcel:Quit()
oExcel := nil
SysRefresh()           // Allow COM cleanup

Integração com Excel

Fonte: source/function/fwxlsxlb.prg, source/function/drxl.prg, source/function/readxlsx.prg

O FiveWin fornece três estratégias complementares para a integração com arquivos Excel, que vão desde a geração nativa de alta velocidade usando a biblioteca C xlsxlibhb (baseada em libxlsxwriter), passando pela automação OLE via TOleAuto para controle COM completo do Excel, até a análise direta de XML para ler arquivos .xlsx sem o Excel.

Visão Geral das Estratégias

EstratégiaFonteCaso de Uso
XLSX Nativo (TWorkBook/TWorkSheet)fwxlsxlb.prgCriação de alta performance, não requer Excel, suporta formatação e imagens
Automação OLE (FWDrXLSX)drxl.prgModelo de objetos COM completo do Excel para formatação legada e recursos avançados
Leitor XML (TXlsxReader)readxlsx.prgLeitura de arquivos .xlsx via análise ZIP/XML, não requer Excel

TWorkBook / TWorkSheet - Geração Nativa de XLSX

As classes TWorkBook e TWorkSheet fornecem uma interface orientada a objetos para a biblioteca C xlsxlibhb. Este é o método preferido para gerar planilhas grandes rapidamente sem qualquer dependência do Microsoft Excel.

TXlsxReader - Leitura Baseada em XML

A classe TXlsxReader lê arquivos .xlsx tratando o arquivo como um arquivo ZIP e analisando os componentes OpenXML internos. Nenhuma instalação do Excel é necessária.

MétodoDescrição
New( cXlsx, cSheet )Abre um arquivo .xlsx para leitura. Opcionalmente especifica o nome de uma planilha. Retorna nil se o arquivo não for encontrado ou for inválido.
ReadData()Lê todos os dados para aData (array 2D). Detecta automaticamente os tipos (N, D, T, L, C, M) e calcula a estrutura.
ShowData()Exibe a planilha em um diálogo XBrowse com detecção automática de tipos.
Range( cRange )Lê um intervalo específico (ex.: "A1:C10") como um array 2D.
Cells( nRow, nCol )Lê uma única célula ou um conjunto de colunas de uma linha específica.
SaveAs( cSave )Salva os dados carregados em um novo arquivo .xlsx usando a biblioteca XLSX nativa.
Close()Libera os recursos internos.

Exemplo: Criar uma Pasta de Trabalho e Escrever Células

#include "FiveWin.ch"

function Main()

   local oBook, oSheet, oFmt, nRow := 1

   // Cria uma nova pasta de trabalho
   oBook := TWorkBook():New( "c:\temp\example.xlsx" )

   if oBook == nil
      MsgStop( "Cannot create workbook" )
      return nil
   endif

   // Adiciona uma planilha
   oSheet := oBook:AddSheet( "Employees" )

   // Cria um formato de cabeçalho em negrito
   oFmt := oBook:Format()
   oFmt:Bold():Align( 2, 10 ):SetBottom( 2 )

   // Escreve os cabeçalhos
   oSheet:Say( nRow, 0, "ID",   oFmt )
   oSheet:Say( nRow, 1, "Name",     oFmt )
   oSheet:Say( nRow, 2, "Hired",    oFmt )
   oSheet:Say( nRow, 3, "Salary",   oFmt )

   // Escreve as linhas de dados (auto-tipagem: N, C, D, N)
   oSheet:Say( ++nRow, 0, 1001 )
   oSheet:Say( nRow, 1, "John Smith" )
   oSheet:Say( nRow, 2, STOD( "20240315" ) )
   oSheet:Say( nRow, 3, 75000.00 )

   oSheet:Say( ++nRow, 0, 1002 )
   oSheet:Say( nRow, 1, "Maria Garcia" )
   oSheet:Say( nRow, 2, STOD( "20240110" ) )
   oSheet:Say( nRow, 3, 82000.00 )

   // Congela a linha de cabeçalho
   oSheet:Freeze( 1, 0 )

   // Finaliza e salva
   oBook:Close()

   // Exibe o resultado
   FW_ShowXlsx( "c:\temp\example.xlsx" )

return nil

Exemplo: Ler um Arquivo XLSX

#include "FiveWin.ch"

function ReadXlsx()

   local oXlsx := FW_OpenXlsx( "c:\temp\example.xlsx" )

   if oXlsx == nil
      MsgStop( "Cannot open file" )
      return nil
   endif

   ? "Rows:", oXlsx:nRows, "Cols:", oXlsx:nCols
   ? "Header:", oXlsx:aHead[ 1 ], oXlsx:aHead[ 2 ], oXlsx:aHead[ 3 ]

   // Acessa uma célula específica
   MsgInfo( oXlsx:Cells( 2, 2 ), "Cell B2" )

   // Lê um intervalo
   XBROWSER oXlsx:Range( "A1:D3" ) TITLE "Range A1:D3"

   oXlsx:Close()

return nil

Notas

  • XLSX Nativo (TWorkBook) é a abordagem recomendada para criar planilhas. Não possui dependências externas, suporta arquivos grandes e oferece controle total de formatação através da classe TFormat.
  • Automação OLE (FWDrXLSX) requer que o Microsoft Excel esteja instalado na máquina de destino. É adequada para código legado ou quando recursos específicos do Excel (macros, tabelas dinâmicas) são necessários.
  • TXlsxReader detecta automaticamente os tipos de dados a partir dos metadados XML do Excel, tratando strings (tabela de strings compartilhadas), números, datas, datetimes, booleanos e imagens.
  • As funções cTempXlsx() e cGetFileXlsx() tratam o gerenciamento de arquivos temporários e a detecção de conflitos (arquivos atualmente abertos no Excel não podem ser sobrescritos).
  • Quando ambas as bibliotecas nativa e OLE estão disponíveis, UseXLSXLIB() e UseDrXlsx() controlam qual estratégia é preferida. Por padrão, a biblioteca nativa é escolhida quando o Excel não está instalado.
  • Os valores de string no XLSX nativo são automaticamente convertidos de ANSI para UTF-8 para a codificação adequada no XML do .xlsx. Dados de memo binários são detectados e substituídos por "<binary data>".

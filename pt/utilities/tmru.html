TMRU - Lista de Arquivos Usados Recentemente

Fonte: source/classes/mru.prg

TMRU gerencia uma lista de arquivos usados recentemente (MRU - Most Recently Used), normalmente exibida no menu Arquivo das aplicações. Ela persiste a lista em um arquivo INI (via TIni) e atualiza automaticamente um menu popup. Quando um usuário abre um arquivo, a lista MRU é atualizada com a nova entrada no topo, e as entradas mais antigas descem ou são removidas se a lista exceder o tamanho máximo. Selecionar um item de menu MRU dispara o codeblock bAction associado.

DATA Members

DATATipoDescrição
aItemsArrayArray de strings de caminhos de arquivo em ordem MRU (mais recente primeiro)
nMaxItemsNumericNúmero máximo de itens na lista MRU (padrão 4)
cIniFileCharacterCaminho do arquivo INI para persistir a lista MRU
cSectionCharacterNome da seção INI onde as entradas MRU são armazenadas
oMenuObjectObjeto de menu popup que exibe as entradas MRU
bActionCodeblockCodeblock executado quando um item MRU é selecionado, recebe o caminho do arquivo

Métodos Principais

MétodoDescrição
New( cIni, cSec, nMax, cMsg, bAction, oMenu, nPos )Cria a lista MRU. Carrega do INI, cria os itens de menu popup e os anexa a oMenu na posição nPos
Save( uNew )Adiciona um novo arquivo ao topo da lista MRU. Se já existir, move-o para o topo. Persiste no INI. uNew pode ser um único arquivo ou um array de arquivos
Clear()Limpa a lista MRU, remove todos os itens de menu e exclui a seção INI

Exemplo: Menu MRU no Menu Arquivo

#include "FiveWin.ch"

function Main()

   local oWnd, oMenu, oMru

   DEFINE WINDOW oWnd TITLE "MRU Demo"

   MENU oMenu
      MENUITEM "~File"
      POPUP
         MENUITEM "~Open..."   ACTION OpenFile( oWnd, oMru )
         MENUITEM "~Save"      ACTION MsgInfo( "Save" )
         SEPARATOR
         // A lista MRU será inserida aqui na posição 4
      ENDPOPUP
   ENDMENU

   oWnd:oMenu := oMenu

   // Cria o MRU com no máximo 5 itens, anexado ao menu Arquivo na posição 4
   oMru := TMRU():New( "C:\MyApp\settings.ini", "MRU", 5, ;
                       "Open recent file", {|cFile| OpenRecent( cFile ) }, ;
                       oMenu, 4 )

   ACTIVATE WINDOW oWnd

return nil

function OpenFile( oWnd, oMru )

   local cFile := cGetFile( "All files (*.*)|*.*" )

   if ! Empty( cFile )
      oMru:Save( cFile )   // Adiciona ao MRU e atualiza o menu
      // ... abre o arquivo
   endif

return nil

function OpenRecent( cFile )

   MsgInfo( "Opening recent: " + cFile )
   // ... abre o arquivo

return nil

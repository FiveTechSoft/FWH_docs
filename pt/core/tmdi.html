TMDI* (MDI Classes)

Fontes: source/classes/mdiframe.prg, mdiclien.prg, mdichild.prg

Todas as três herdam de: TWindow

O sistema MDI (Multiple Document Interface) consiste em três classes coordenadas: TMDIFrame (a janela de moldura principal), TMDIClient (a área cliente que gerencia as janelas filhas) e TMDIChild (janelas filhas de documentos individuais). Juntas, elas proporcionam a experiência clássica de MDI do Windows com lado a lado, em cascata, organização de ícones e mesclagem de menus.

Exemplo: Moldura MDI com Duas Janelas Filhas

#include "FiveWin.ch"

function Main()

   local oWnd, oChild1, oChild2

   DEFINE MDIFRAME oWnd TITLE "MDI Demo"

   DEFINE MDICHILD oChild1 TITLE "Document 1" OF oWnd
   @ 10, 10 SAY "First document" OF oChild1

   DEFINE MDICHILD oChild2 TITLE "Document 2" OF oWnd
   @ 10, 10 SAY "Second document" OF oChild2

   ACTIVATE MDIFRAME oWnd MAXIMIZED

return nil

Notas

  • Use DEFINE MDIFRAME ... TITLE cTitle para criar a moldura. A moldura cria automaticamente um TMDIClient e adiciona um submenu "Janela" para gerenciamento das filhas, caso nenhum seja fornecido.
  • Use DEFINE MDICHILD oChild OF oWnd TITLE cTitle para criar janelas filhas. Elas são registradas automaticamente no TMDIClient via Add().
  • TMDIFrame encaminha as operações de área de transferência (Copy, Cut, Paste, Undo, Redo, Find, SelectAll) para o controle ativo da filha ativa.
  • Mesclagem de menus: quando a moldura é criada com um menu, o parâmetro nMenuInfo especifica qual posição de submenu se torna a lista de janelas.
  • O sinalizador lChildAutoSize em TMDIFrame faz com que novas filhas abram maximizadas.

TWindow

Classe Base Classe Raiz source/classes/window.prg

TWindow é a classe raiz de toda a hierarquia de classes do FiveWin. Todo elemento visível em uma aplicação FiveWin — diálogos, controles, frames MDI, filhos MDI — herda de TWindow. Ela encapsula um HWND do Win32 e fornece a API fundamental para criação de janelas, tratamento de eventos, pintura, gerenciamento de coordenadas, arrastar e soltar, tooltips e muito mais.

Hierarquia de Herança

TWindow está no topo da hierarquia. Todas as principais classes do FiveWin derivam dela direta ou indiretamente:

classDiagram class TWindow { +hWnd +cCaption +oMenu +oMsgBar +aControls +Activate() +End() +Center() } TWindow <|-- TMDIFrame TWindow <|-- TMDIChild TWindow <|-- TDialog TWindow <|-- TControl TControl <|-- TButton TControl <|-- TGet TControl <|-- TXBrowse TControl <|-- TSay TControl <|-- TFolder TMDIFrame : +oWndClient TMDIChild : +oWndParent TDialog : +lModal TDialog : +lTruePixel

Blocos de Código de Eventos

TWindow expõe um rico conjunto de blocos de código que disparam em eventos Win32. Atribua um bloco para interceptar qualquer evento:

Bloco de CódigoParâmetrosDescrição
bInit|Self|Dispara após a criação da janela, antes do loop de mensagens.
bPainted|hDC, cPS, Self|Pintura personalizada dentro do WM_PAINT.
bLClicked|nRow, nCol, nFlags|Clique do botão esquerdo do mouse.
bRClicked|nRow, nCol, nFlags|Clique do botão direito do mouse.
bKeyDown|nKey, nFlags, Self|Tecla pressionada.
bResized|nSizeType, nWidth, nHeight|Janela redimensionada.
bMoved|Self|Janela movida.
bValid|Self|Deve retornar .T. para permitir o fechamento.
bGotFocus|Self, hFrom|Janela recebeu o foco.
bLostFocus|Self, hTo|Janela perdeu o foco.
bDropFiles|hDrop, Self|Arquivos soltos sobre a janela.
bMouseWheel|nDelta, nKeys|Roda do mouse rolada.

Principais Métodos

New() — Construtor

METHOD New( nTop, nLeft, nBottom, nRight, cTitle, nStyle, oMenu,
      oBrush, oIcon, oWnd, lVScroll, lHScroll, nClrFore, nClrBack,
      oCursor, cBorder, lSysMenu, lCaption, lMin, lMax, lPixel,
      nExStyle, cVarName, nHelpId, lUnicode, nWidth, nHeight )

Cria uma nova instância de TWindow mas não a exibe. O handle da janela hWnd ainda não foi criado; isso acontece durante Activate().

Activate()

METHOD Activate( cShow, bLClicked, bRClicked, bMoved, bResized,
      bPainted, bKeyDown, bInit, bUp, bDown, bPgUp, bPgDown,
      bLeft, bRight, bPgLeft, bPgRight, bValid, bDropFiles,
      bLButtonUp, lCentered, oMonitor )

Cria a janela Win32, exibe-a e entra no loop de mensagens. O parâmetro cShow pode ser "MAXIMIZED", "ICONIZED" ou "NORMAL" (padrão). O método não retorna até que a janela seja fechada.

End()

Envia WM_CLOSE para a janela. Se bValid estiver definido, ele é avaliado primeiro; o fechamento é cancelado quando bValid retorna .F..

Comandos: DEFINE WINDOW / ACTIVATE WINDOW

O FiveWin fornece comandos de preprocessador que se traduzem em chamadas de métodos de TWindow. Esta é a forma recomendada de criar janelas:

DEFINE WINDOW

DEFINE WINDOW oWnd ;
   [ FROM nTop, nLeft TO nBottom, nRight ] ;
   [ TITLE cTitle ] ;
   [ STYLE nStyle ] ;
   [ MENU oMenu ] ;
   [ BRUSH oBrush ] ;
   [ ICON oIcon ] ;
   [ OF oParent ] ;
   [ VSCROLL ] [ HSCROLL ] ;
   [ COLOR nClrText, nClrBack ] ;
   [ CURSOR oCursor ] ;
   [ BORDER cBorder ] ;   // "NONE", "SINGLE"
   [ NOSYSMENU ] ;
   [ NOCAPTION ] ;
   [ NOMINIMIZE ] ;
   [ NOMAXIMIZE ] ;
   [ PIXEL ] ;
   [ HELPID nHelpId ] ;
   [ UNICODE ]

ACTIVATE WINDOW

ACTIVATE WINDOW oWnd ;
   [ MAXIMIZED | ICONIZED | NORMAL ] ;
   [ ON LEFT CLICK bLClicked ] ;
   [ ON RIGHT CLICK bRClicked ] ;
   [ ON MOVE bMoved ] ;
   [ ON RESIZE bResized ] ;
   [ ON PAINT bPainted ] ;
   [ ON KEYDOWN bKeyDown ] ;
   [ ON INIT bInit ] ;
   [ ON UP bUp ] [ ON DOWN bDown ] ;
   [ ON PAGEUP bPgUp ] [ ON PAGEDOWN bPgDown ] ;
   [ ON LEFT bLeft ] [ ON RIGHT bRight ] ;
   [ VALID bValid ] ;
   [ ON DROP bDropFiles ] ;
   [ CENTERED ]

Ciclo de Vida da Janela

flowchart LR A["DEFINE WINDOW
(TWindow:New)"] --> B["Build Menu,
Toolbar, StatusBar"] B --> C["ACTIVATE WINDOW
(TWindow:Activate)"] C --> D["Win32 CreateWindow"] D --> E["ON INIT
bInit block"] E --> F["Message Loop
(user interaction)"] F --> G{"User closes
or End()"} G -->|"bValid returns .T."| H["WM_CLOSE /
DestroyWindow"] G -->|"bValid returns .F."| F H --> I["Activate() returns"]

O ponto-chave é que Activate() é uma chamada bloqueante que executa o loop de mensagens do Windows. O código colocado após ACTIVATE WINDOW só executa depois que a janela é fechada.

Exemplo: Janela Principal com Menu, Barra de Ferramentas e Barra de Status

#include "FiveWin.ch"

function Main()

   local oWnd, oBar, oFont

   DEFINE FONT oFont NAME "Segoe UI" SIZE 0, -14

   DEFINE WINDOW oWnd TITLE "My Application" ;
      COLOR CLR_BLACK, CLR_WHITE

   DEFINE BUTTONBAR oBar OF oWnd SIZE 56, 56 2007

   DEFINE BUTTON OF oBar RESOURCE "NEW"  ;
      ACTION MsgInfo( "New document" )    ;
      TOOLTIP "New"

   DEFINE BUTTON OF oBar RESOURCE "OPEN" ;
      ACTION MsgInfo( "Open file" )       ;
      TOOLTIP "Open"

   DEFINE BUTTON OF oBar RESOURCE "SAVE" ;
      ACTION MsgInfo( "Save file" )       ;
      TOOLTIP "Save"

   SET MESSAGE OF oWnd TO "Ready" ;
      CENTERED CLOCK DATE KEYBOARD

   MENU oMenu
      MENUITEM "&File"
      MENU
         MENUITEM "&New"    ACTION MsgInfo( "New" )    MESSAGE "Create new document"
         MENUITEM "&Open"   ACTION MsgInfo( "Open" )   MESSAGE "Open existing file"
         MENUITEM "&Save"   ACTION MsgInfo( "Save" )   MESSAGE "Save current file"
         SEPARATOR
         MENUITEM "E&xit"   ACTION oWnd:End()          MESSAGE "Exit application"
      ENDMENU
      MENUITEM "&Help"
      MENU
         MENUITEM "&About"  ACTION MsgAbout()
      ENDMENU
   ENDMENU

   oWnd:SetMenu( oMenu )
   oWnd:SetFont( oFont )

   ACTIVATE WINDOW oWnd MAXIMIZED ;
      ON INIT ( oWnd:SetFocus() ) ;
      VALID ( MsgYesNo( "Exit application?" ) )

   oFont:End()

return nil

Exemplo: Aplicação MDI

MDI (Interface de Múltiplos Documentos) permite que uma janela frame principal hospede múltiplas janelas filhas. O FiveWin fornece TMDIFrame e TMDIChild, ambos derivados de TWindow:

#include "FiveWin.ch"

static oWnd

function Main()

   local oBar

   DEFINE WINDOW oWnd TITLE "MDI Application" MDI ;
      COLOR CLR_BLACK, GetSysColor( COLOR_APPWORKSPACE )

   DEFINE BUTTONBAR oBar OF oWnd SIZE 56, 56 2007

   DEFINE BUTTON OF oBar RESOURCE "NEW" ;
      ACTION NewChild() TOOLTIP "New Document"

   SET MESSAGE OF oWnd TO "Ready" CENTERED CLOCK DATE

   MENU oMenu
      MENUITEM "&File"
      MENU
         MENUITEM "&New Child"  ACTION NewChild()
         SEPARATOR
         MENUITEM "E&xit"       ACTION oWnd:End()
      ENDMENU
      MENUITEM "&Window"
      MENU
         MENUITEM "&Tile"       ACTION oWnd:Tile()
         MENUITEM "Ca&scade"    ACTION oWnd:Cascade()
         MENUITEM "Arrange &Icons" ACTION oWnd:IconArrange()
         SEPARATOR
         MENUITEM "Close &All"  ACTION oWnd:CloseAll()
      ENDMENU
   ENDMENU

   oWnd:SetMenu( oMenu )

   ACTIVATE WINDOW oWnd MAXIMIZED

return nil

//--------------------------------------------------------------------//

static function NewChild()

   local oChild
   static nCount := 0

   nCount++

   DEFINE WINDOW oChild TITLE "Document " + LTrim( Str( nCount ) ) ;
      MDICHILD OF oWnd

   ACTIVATE WINDOW oChild

return nil

Dicas de Uso

  • Pintura com buffer duplo — Envolva a pintura personalizada dentro de DispBegin() / DispEnd() para eliminar tremulação.
  • Persistência da posição da janela — Salve nTop, nLeft, nBottom, nRight em um arquivo INI no bValid e restaure-os no New().
  • Fundos gradientes — Defina aGradColors como um array de pares de cores: oWnd:SetGradient( { { 0.5, nRGB(40,40,50), nRGB(20,20,30) }, { 0.5, nRGB(20,20,30), nRGB(10,10,15) } } ).
  • Unicode — Passe UNICODE no comando DEFINE WINDOW, ou chame FW_SetUnicode( .T. ) globalmente, para usar as APIs Win32 de caracteres largos.
  • aControls — Itere os controles filhos via AEval( oWnd:aControls, {|o| o:Refresh() } ) ou o método mais recente ForEachControl().
  • Suporte a múltiplos monitores — Passe oMonitor para Activate() para abrir a janela em um monitor específico em configurações com múltiplas telas.

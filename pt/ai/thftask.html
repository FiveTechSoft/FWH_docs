THFTask e TChatAgent - utilidades FWAI

Fonte: source/classes/thftask.prg, source/classes/tchatagent.prg

Duas classes utilitárias "FWAI" que trazem tarefas de IA do dia a dia às apps FiveWin em poucas linhas — veja o roteiro PyTorch-lite.

THFTask — tarefas NLP da HuggingFace

Uma classe fina sobre a Inference API da HuggingFace para as tarefas NLP comuns. Cada método faz POST ao endpoint do modelo e retorna valores Harbour normais.

MétodoRetorna
Classify( cText [,cModel] ){ {label,score}, ... } decrescente
ZeroShot( cText, aLabels [,cModel] ){ {label,score}, ... } com seus próprios rótulos
NER( cText [,cModel] ){ {entity,word,score}, ... }
Summarize( cText [,cModel] )string de resumo
Translate( cText [,cModel] )string de tradução (en→es por padrão)
Sentiment( cText [,cModel] ){ label, score } (top)
 
oT := THFTask():New()                            // usa HF_API_KEY
aCls := oT:Classify( "win a free prize now" )    // -> { {"spam",0.91}, {"ham",0.09} }
? oT:Summarize( cRelatorioLongo )
? oT:Translate( "Hello world" )                  // "Hola mundo"
aEnt := oT:NER( "John lives in Madrid" )         // PER John, LOC Madrid
aZ   := oT:ZeroShot( "minha fatura está errada", { "faturamento", "suporte" } )

O transporte é injetável via ::bSender { |cUrl, cJson| -> cResponseJson } — deixe NIL para usar libcurl, ou defina para simular respostas (o teste samples/ai/thftasktest.prg verifica o parsing offline) ou rotear por outra camada HTTP / um servidor local.

TChatAgent — chat sobre os dados da sua app

Um agente mínimo com tool-calling: o LLM responde, ou pede à app que execute uma consulta; a app devolve linhas e o laço continua até o LLM responder. Agnóstico de backend via dois codeblocks.

flowchart LR U[Pergunta do usuário] --> A[TChatAgent] A -->|prompt| L[LLM bChat] L -->|TOOL consulta| A A -->|executa consulta| T[bTool → linhas] T --> A L -->|ANSWER texto| R[Resposta]
MétodoDescrição
New( bChat, bTool [,cSystem] )bChat = { |cPrompt| -> cReply } (LLM, p.ex. TOLlama ou uma classe API); bTool = { |cQuery| -> cResultText } (você executa a consulta DBF/SQL).
Ask( cQuestion )Executa o laço e retorna o texto da resposta final.
 
oLlm   := TOLlama():New( "llama3" )
oAgent := TChatAgent():New( ;
   { |cPrompt| oLlm:Send( cPrompt ), oLlm:GetValue() }, ;     // backend LLM
   { |cQuery|  RunMyQuery( cQuery ) } )                       // seu tool de dados
? oAgent:Ask( "quantas faturas vencidas há neste mês?" )

O LLM é instruído a responder TOOL <consulta> ou ANSWER <texto>; os resultados são reinjetados como RESULT: <linhas> até ele responder (ou nMaxSteps). Combine com TSemanticIndex para o agente recuperar registros relevantes. Teste: samples/ai/chatagenttest.prg.

GPT2Model - Inferência de GPT-2 pré-treinado no FWH

Fonte: source/classes/gpt2model.prg (sobre FW_Tensor, source/function/fwtensor.c)

GPT2Model roda GPT-2 pré-treinado real inteiramente em FWH/Harbour na CPU. Carrega os pesos reais do GPT-2 de um model.safetensors da HuggingFace e executa o forward pass completo — embeddings de token + posição, pre-norm, atenção causal multi-cabeça, MLP GELU, residuais, norm final e cabeça de saída com pesos atados — tudo sobre o backend plano FW_Tensor. É a Fase 3 do roteiro PyTorch-lite, verificada numericamente contra uma referência ("The capital of France is" → " the", token 262).

Obter os pesos

Baixe o GPT-2 small do Hub da HuggingFace (não é distribuído com o FWH): https://huggingface.co/gpt2/resolve/main/model.safetensors (~500 MB, 124M params) mais tokenizer.json para HFTokenizer. Os pesos são lidos um tensor de cada vez via FWT_LoadSafe (sem carregar o arquivo inteiro), então o pico de memória são os pesos float32 (~500 MB), que cabem num processo de 32 bits.

Métodos

MétodoDescrição
New( n_layer, n_head, n_embd, vocab, n_ctx )Configura a arquitetura. Padrão GPT-2 small (12, 12, 768, 50257, 1024).
LoadSafetensors( cFile )Parseia o cabeçalho safetensors e carrega cada tensor de pesos em FW_Tensors.
Forward( aTok )Executa o forward para uma sequência de tokens (ids de gather base 1). Retorna logits [seq, vocab].
Generate( aTok, nNew, nTemp, nTopK )Geração autorregressiva (greedy / temperatura / top-k). Retorna a sequência completa de ids base 1.

Os ids são base 1 para o gather (id base 0 da HuggingFace + 1); reconverta com id - 1 antes de decodificar.

Exemplo

oTok := HFTokenizer():New( "gpt2.tokenizer.json" )
oM   := GPT2Model():New()                       // padrão GPT-2 small
oM:LoadSafetensors( "model.safetensors" )

aIds := oTok:Encode( "The capital of France is" )   // ids HF base 0
aTok := {} ; AEval( aIds, { |n| AAdd( aTok, n + 1 ) } )

aOut := oM:Generate( aTok, 8, 0.0001, 1 )            // greedy, 8 tokens
aHF  := {} ; AEval( aOut, { |n| AAdd( aHF, n - 1 ) } )
? oTok:Decode( aHF )    // "The capital of France is the capital of the French Republic, and"

Notas

  • Apenas inferência (sem treinamento) — não precisa de autograd.
  • A velocidade é limitada pelo matmul ingênuo; um backend BLAS (Fase 2 do roteiro) tornaria rápidas as gerações longas. Ainda não há KV cache, então cada passo recomputa a janela (O(n²)).
  • Para modelos maiores/quantizados, a via pragmática é vincular o llama.cpp (Trilha C do roteiro) em vez de escalar este caminho do zero.
  • Teste/demo: samples/ai/gpt2test.prg.

Rede Neural Transformer

Fonte: source/classes/transformer.prg, source/function/matrixes.c, source/function/matrices.prg

O FiveWin fornece uma implementação em puro Harbour/C da arquitetura Transformer apenas-codificador para classificação de sequências e modelagem de linguagem. A implementação inclui auto-atenção multi-cabeça, redes feed-forward, normalização de camada e otimizadores Adam/SGD. Toda a álgebra linear pesada é acelerada via extensões C em matrixes.c.

Arquitetura

flowchart LR Input[Tokens de Entrada] --> Embed[Busca de Embedding] Embed --> Pos[Codificação Posicional] Pos --> MHA[Atenção Multi-Cabeça] MHA --> Add1[+ Residual] Add1 --> LN1[Layer Norm] LN1 --> FF[Feed Forward] FF --> Add2[+ Residual] Add2 --> LN2[Layer Norm] LN2 --> Pool[Avg Pooling] Pool --> Proj[Projeção W_vocab] Proj --> SM[Softmax] SM --> Output[Probabilidades de Saída]

Classes

Transformer

A classe de nível superior que orquestra embeddings, codificação posicional, camadas empilhadas e projeção de saída.

MétodoDescrição
New( num_layers, d_model, n_heads, vocab_size, max_seq_len, hEmbeddings, aVocab )Cria um Transformer com a arquitetura informada. Inicializa todas as subcamadas e embeddings.
Forward( src_indices, pos_indices )Executa uma passagem direta: busca de embedding, codificação posicional, N blocos transformer, average pooling e softmax sobre o vocabulário.
Backward( d_output, targets, src_indices, pos_indices )Retropropaga os gradientes por todas as camadas e acumula os gradientes dos pesos.
zero_grad()Redefine para zero todos os gradientes acumulados.

MultiHeadAttention

Calcula a atenção por produto escalar escalonado sobre múltiplas cabeças. Projeta as entradas nos espaços Query, Key e Value via matrizes aprendidas, calcula os escores de atenção e concatena as saídas das cabeças.

FeedForward

Um MLP de duas camadas por posição com ativação ReLU que opera em cada posição de forma independente: FF(x) = W2 * ReLU(W1 * x + b1) + b2.

LayerNorm

Aplica a normalização de camada ao longo da dimensão de características: y = (x - mean) / sqrt(var + eps) * gamma + beta.

Optimizer_Adam

Otimizador de Estimativa Adaptativa de Momento (Adaptive Moment Estimation). Mantém estimativas de primeiro (m) e segundo (v) momentos com correção de viés. Usa a função acelerada em C hb_AdamUpdate() para atualizações eficientes de parâmetros.

Optimizer_SGD

Gradiente Descendente Estocástico com momento opcional, para cenários de treinamento mais simples.

Operações de Matriz (Extensões C)

O arquivo matrixes.c fornece álgebra linear de alto desempenho exposta ao Harbour como wrappers HB_FUNC:

FunçãoDescrição
hb_MatrixMultiply( A, B )Multiplicação de matrizes padrão (MxN * NxP = MxP)
hb_Softmax( logits )Softmax por linha com estabilidade numérica (subtração do máximo)
hb_ReLU( M )Unidade Linear Retificada: max(0, x) elemento a elemento
hb_AdamUpdate( W, dW, m, v, t, lr, beta1, beta2, eps )Passo de atualização de parâmetros do otimizador Adam com correção de viés
hb_MatrixTranspose( M )Transpõe a matriz (troca linhas e colunas)
hb_Matrix3DAdd( A, B )Adição elemento a elemento para tensores 3D (batch x seq x dim)
hb_Matrix3DAvg( X )Average pooling sobre a dimensão da sequência
hb_Matrix3DExpand( M, n )Expande o gradiente 2D para 3D para retropropagação ao longo da sequência

Classe FW_Matrix

A classe FW_Matrix em matrices.prg fornece um wrapper de alto nível para manipulação de matrizes com sobrecarga de operadores do Harbour: 

oM1 := FW_Matrix():New( { { 1, 2 }, { 3, 4 } } )
oM2 := FW_Matrix():New( { { 5, 6 }, { 7, 8 } } )
oResult := oM1 * oM2   // sobrecarga de operador via palavra-chave OPERATOR
oResult:View()         // exibe na grade TXBrowse

Pipeline de Treinamento

Um laço de treinamento típico segue estes passos:

  1. Passagem direta: chame oTransformer:Forward( src_indices, pos_indices ) para obter as distribuições de probabilidade.
  2. Cálculo da perda: calcule a perda de entropia cruzada entre as previsões e os tokens alvo.
  3. Passagem reversa: chame oTransformer:Backward( d_output, targets, src_indices, pos_indices ) para propagar os gradientes.
  4. Passo do otimizador: use Optimizer_Adam:Step( oTransformer ) ou Optimizer_SGD:Step( oTransformer ) para atualizar os pesos.
  5. Zerar gradientes: chame oTransformer:zero_grad() antes da próxima iteração.

Exemplo: Classificação de Sentimento

O exemplo samples/ai/transf2.prg estende o Transformer com uma cabeça de classificação para análise binária de sentimento (Positivo/Negativo): 

#include "FiveWin.ch"

CLASS CustomTransformer INHERIT Transformer
   DATA W_proj, b_class, dW_proj, db_class, last_probs

   METHOD New( num_layers, d_model, n_heads, vocab_size, max_seq_len, ;
               hEmbeddings, aVocab, num_classes )
   METHOD ForwardClassification( src_indices, pos_indices )
   METHOD BackwardClassification( d_loss, train_src, train_pos )
   METHOD UpdateWeights( learningRate )
ENDCLASS

METHOD New( ... ) CLASS CustomTransformer
   ::Super:New( num_layers, d_model, n_heads, vocab_size, max_seq_len, ;
                hEmbeddings, aVocab )
   ::W_proj   := hb_MatrixRandom( vocab_size, num_classes )
   ::b_class  := hb_MatrixZero( 1, num_classes )
   ::dW_proj  := hb_MatrixZero( vocab_size, num_classes )
   ::db_class := hb_MatrixZero( 1, num_classes )
RETURN Self

// Forward de classificacao: forward do pai + projecao W_proj + softmax
METHOD ForwardClassification( src_indices, pos_indices ) CLASS CustomTransformer
   LOCAL probs := ::Forward( src_indices, pos_indices )
   ::last_probs := probs
   LOCAL logits := hb_MatrixMultiply( probs, ::W_proj )
   // Adiciona o vies
   AEval( logits, { |row, i| row[ 1 ] += ::b_class[ 1 ][ 1 ] } )
   AEval( logits, { |row, i| row[ 2 ] += ::b_class[ 1 ][ 2 ] } )
RETURN hb_Softmax( logits )

// Laco de treinamento
oTransformer := CustomTransformer():New( 1, 6, 2, 8, 5, NIL, vocab, 2 )
FOR e := 1 TO 50
   FOR i := 1 TO Len( trainSrc )
      pred := oTransformer:ForwardClassification( { trainSrc[ i ] }, ;
                                                   { trainPos[ i ] } )
      loss := CrossEntropyLoss( pred, { trainLabels[ i ] } )
      oTransformer:BackwardClassification( loss[ 2 ], ;
                                           { trainSrc[ i ] }, { trainPos[ i ] } )
      oTransformer:UpdateWeights( 0.01 )
   NEXT
NEXT

Treine com frases como "buen dia" (Positivo) e "malo trabajo" (Negativo) usando um vocabulário de 8 tokens e 50 épocas de treinamento.

Notas

  • A codificação posicional senoidal é pré-calculada na inicialização por questão de eficiência.
  • As conexões residuais usam hb_Matrix3DAdd (acelerado em C) para evitar a sobrecarga de laços do Harbour.
  • O Softmax em C subtrai o máximo da linha antes da exponenciação para evitar estouro de ponto flutuante.
  • Demos visuais de treinamento: samples/ai/transformer.prg (GUI) e samples/ai/transf1.prg (interativo).

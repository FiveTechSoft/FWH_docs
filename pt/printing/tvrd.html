VRD - Motor do Designer Visual de Relatórios

Fonte: source/classes/vrd.prg

Classe independente (motor de relatórios)

VRD é o motor em tempo de execução para o Designer Visual de Relatórios. Carrega e processa definições de relatórios armazenadas em ficheiros .rpt (formato INI), gere áreas de dados, processa consultas de base de dados e conduz a impressão ou pré-visualização de relatórios complexos. Não é um designer visual em si, mas o motor de execução que lê a saída do designer.

Exemplo: Carregar e Pré-visualizar um Relatório

#include "FiveWin.ch"

function Main()

   local oRpt

   // Load a report definition and open in preview mode
   oRpt := VRD():New( "C:\reports\invoice.rpt", .T. )
   oRpt:OpenDatabases()
   oRpt:AreaStart( 1 )
   oRpt:PrintArea( 1 )
   oRpt:End()

return nil

Notas

  • VRD lê definições de relatórios de ficheiros .rpt em formato INI criados pela aplicação Designer Visual de Relatórios. Estes ficheiros definem áreas, itens, fontes, cores, ligações de base de dados e expressões.
  • As áreas do relatório são secções lógicas (ex.: cabeçalho de página, detalhe, rodapé de página). Cada área tem o seu próprio conjunto de itens (texto, campos, linhas, caixas) posicionados em coordenadas de tempo de design.
  • O motor suporta expressões calculadas, sumários de base de dados, impressão condicional e gestão de quebras de página.
  • Múltiplas bases de dados podem ser abertas simultaneamente via aDBAlias, suportando estruturas de relatório mestre-detalhe.

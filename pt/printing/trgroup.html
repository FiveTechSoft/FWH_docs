TRGroup

Fonte: source/classes/rgroup.prg

Classe independente

TRGroup define uma quebra de grupo dentro de um TReport. Os grupos permitem relatórios hierárquicos com cabeçalhos de grupo, rodapés e subtotais automáticos. Quando ocorre uma quebra de grupo (detectada por uma mudança no valor da expressão do grupo), o rodapé do grupo é impresso, os totais são reiniciados, e o cabeçalho do grupo para o novo grupo é impresso na próxima página ou na linha seguinte.

Membros DATA Principais

DATATipoDescrição
oReportObjetoObjeto TReport pai
aTotalArrayArray de valores de subtotal acumulados por coluna
bGroupCodeblockExpressão do grupo; avaliada a cada linha para detectar quebras
bHeaderCodeblockCodeblock do texto do cabeçalho, impresso quando um novo grupo começa
bFooterCodeblockCodeblock do texto do rodapé, impresso quando um grupo termina
cValueCaractereValor atual do grupo
cOldValueCaractereValor anterior do grupo, usado para detecção de quebra
nCounterNuméricoContagem de linhas dentro do grupo atual
lEjectLógicoEjeta a página quando o grupo quebra
lHeaderLógicoTem um cabeçalho para imprimir
lFooterLógicoTem um rodapé para imprimir

Métodos

MétodoDescrição
New( bGroup, bHeader, bFooter, bFont, lEject, oReport )Cria uma nova definição de TRGroup
Header( nRow )Renderiza o cabeçalho do grupo na linha especificada
Footer( nRow )Renderiza o rodapé do grupo na linha especificada
Total( nRow )Renderiza os subtotais das colunas na linha especificada
Check()Retorna .T. se o valor do grupo mudou (ocorreu uma quebra)
Evaluate()Incrementa o contador de linhas do grupo
Reset()Reinicia os totais, o contador e os valores atual/anterior
Stabilize( nOrder )Calcula as dimensões do cabeçalho/rodapé

Exemplo: Agrupar por Estado com Subtotais

#include "FiveWin.ch"
#include "report.ch"

function GroupedReport()

   local oReport

   REPORT oReport TITLE "Sales by State" PREVIEW

   GROUPS oReport

   GROUP ON { || oSale:State } ;
          HEADER { || "State: " + oSale:State } ;
          FOOTER { || "Subtotal for " + oSale:State }

   COLUMN TITLE "Customer" DATA { || oSale:Customer }
   COLUMN TITLE "Amount"   DATA { || oSale:Amount } ;
          PICTURE "9,999.99" TOTAL

   END REPORT

   ACTIVATE REPORT oReport

return nil

Notas

  • Use o comando GROUP ON dentro de um bloco REPORT para definir quebras de grupo de forma declarativa.
  • As quebras de grupo são detectadas automaticamente comparando a avaliação atual de bGroup com o valor anterior.
  • Defina lEject := .T. para forçar uma quebra de página sempre que o valor do grupo mudar.
  • O array aTotal acumula subtotais para colunas que têm lTotal := .T..
  • Vários níveis de grupo podem ser aninhados definindo múltiplos objetos TRGroup em sequência.

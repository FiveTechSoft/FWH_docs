TRColumn

Fonte: source/classes/rcolumn.prg

Classe independente

TRColumn representa uma única coluna dentro de um TReport. Define como os dados são obtidos, formatados e exibidos para cada coluna em um relatório impresso. As colunas suportam totais, totais acumulados, campos memo, imagens, barras de progresso e gráficos embutidos.

Exemplo: Coluna com Total

#include "FiveWin.ch"
#include "report.ch"

function BuildReport()

   local oReport, oCol

   REPORT oReport TITLE "Sales Report" PREVIEW

   COLUMN oCol TITLE "Product" DATA { || oSale:Product }
   COLUMN oCol TITLE "Amount" ;
          DATA { || oSale:Amount } ;
          PICTURE "999,999.99" ;
          TOTAL

   END REPORT

   ACTIVATE REPORT oReport

return nil

Notas

  • TRColumn é criada implicitamente ao usar o comando COLUMN dentro de um bloco REPORT.
  • Defina lTotal := .T. para habilitar a totalização automática para colunas numéricas.
  • A flag lCumTotal acumula totais entre os grupos em vez de reiniciar a cada grupo.
  • Colunas memo (lMemo := .T.) suportam quebra de texto em múltiplas linhas dentro da largura da coluna.
  • Colunas de imagem (lImage := .T.) exibem bitmaps obtidos pelo codeblock de dados.
  • As colunas suportam gráficos de barras embutidos através dos membros DATA cChartStyle e chartdata.

TEReport (Designer EasyReport)

Fonte: source/classes/tereport.prg

TEReport é o designer visual interativo para arquivos de relatório EasyReport (.vrd / .erd). Ele encapsula o TEasyReport e fornece um editor MDI completo com barra de menus, barra de botões, superfície de design da área do relatório, inserção de itens (texto, imagem, gráfico, código de barras), desfazer/refazer, gerenciamento de banco de dados, configuração de fonte/cor e recursos de pré-visualização/impressão. É a principal ferramenta para projetar layouts de relatório visualmente.

Principais Membros DATA

DATATipoDescrição
oERTEasyReportInstância subjacente do motor EasyReport
cFileReportCharacterCaminho do arquivo de relatório atual
oGenVarTExStructContêiner de variáveis gerais (cores, pincéis, fontes, configurações)
aFontsArrayArray de objetos TFont (até 20) definidos para o relatório
aAreasArrayÁreas (faixas) do relatório acessadas via :oER:aAreaIni
aItemsArrayItens do relatório por área, acessados via :oER:aItems[nArea, nItem]
oBarTButtonBarBarra de botões principal do designer
lVRDSaveLogicalIndica se existem alterações não salvas

Métodos

MétodoDescrição
New( oP )Cria e executa o designer como filho MDI de uma janela existente, ou como janela MDI independente
Activate( ... )Ativa o designer como uma aplicação MDI independente com suporte a arquivo por linha de comando
OpenFile( cFile, lChange, lAddDelNew )Abre um arquivo de relatório .vrd ou .erd no designer
SaveFile()Salva o estado atual do relatório (todas as áreas, configurações gerais)
SaveAs( cFile )Salva o relatório em um novo caminho de arquivo
SaveAsNewFormat()Converte e salva no novo formato .erd
Undo()Desfaz a última ação do designer
Redo()Refaz uma ação previamente desfeita
BuildMenu()Constrói toda a estrutura de menus do designer
BarMenu()Constrói a barra de botões do designer com todas as ferramentas
SetGeneralSettings()Carrega e aplica as configurações gerais do relatório (medida, grade, bancos de dados)
ClientWindows()Cria todas as janelas filhas MDI para cada área do relatório, carregando os dados da área
DefineFonts()Carrega as definições de fonte do arquivo de relatório em objetos TFont
OpenDatabases()Abre e carrega as definições de banco de dados a partir da configuração do relatório

Exemplo: Executar o Designer EasyReport a partir do Código

#include "FiveWin.ch"

function Main()

   local oER

   oER := TEReport():New()  // Designer independente

return nil

Exemplo: Abrir um Arquivo de Relatório no Designer

#include "FiveWin.ch"

function Main()

   local oER

   oER := TEReport():New()
   oER:OpenFile( "myreport.vrd" )

return nil

Notas

  • TEReport é uma aplicação completa de design visual, não um encapsulamento de execução de relatórios. Ele hospeda o motor TEasyReport e apresenta uma interface gráfica baseada em MDI para projetar layouts de relatório.
  • Os arquivos de relatório vêm em dois formatos: o legado .vrd (formato VRD) e o novo .erd (formato EasyReport). O designer lida com ambos de forma transparente.
  • Cada área (faixa) do relatório é exibida como uma janela filha MDI dentro da janela principal do designer, com suporte ao posicionamento de itens por arrastar e soltar.
  • Os tipos de itens incluem TEXT, IMAGE, GRAPHIC e BARCODE. Cada item pode ser posicionado, dimensionado e estilizado através do diálogo de propriedades.
  • O desfazer/refazer é implementado usando arquivos DBF temporários que armazenam as alterações em nível de entrada e em nível de área.
  • O designer inclui um sistema multi-idioma com suporte a inglês, alemão, italiano, espanhol, português e francês.

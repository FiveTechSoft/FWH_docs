TRFile

Fonte: source/classes/rfile.prg

Classe independente

TRFile é um dispositivo de saída de relatório em arquivo de texto que implementa a mesma interface da TPrinter, permitindo que relatórios sejam gravados em um arquivo de texto simples em vez de uma impressora. Ele substitui o driver de dispositivo da TReport, fornecendo os métodos Say(), StartPage(), EndPage() e métodos de medição que operam sobre células de caractere em vez de pixels.

Membros DATA Principais

DATATipoDescrição
hDCNuméricoHandle do arquivo de texto de saída
aRowsArrayArray de strings de caracteres, uma por linha da página atual
cDocumentCaractereNome do documento
nHeightNuméricoAltura da página em linhas de caractere
nWidthNuméricoLargura da página em colunas de caractere
lPrintLógicoHabilita a saída (padrão .T.)

Métodos

MétodoDescrição
New( cFile )Abre cFile para gravação e cria um dispositivo TRFile
Say( nRow, nCol, cText, oFont, nMaxSize, u6, u7, nPad )Grava texto na linha e coluna especificadas no buffer de caracteres
StartPage()Inicia uma nova página; limpa o buffer de linhas
EndPage()Descarrega o buffer da página atual para o arquivo
End()Fecha o arquivo de saída
SetHeight( nHeight )Define a altura da página em linhas de caractere e reinicializa o buffer
SetSize( nWidth, nHeight )Define as dimensões da página em células de caractere
GetTextWidth( cText )Retorna Len( cText ) (largura baseada em caracteres)
GetTextHeight()Sempre retorna 1 (altura de uma única linha de caractere)

Exemplo: Gravar Relatório de Texto em Arquivo

#include "FiveWin.ch"

function WriteTextReport()

   local oFile := TRFile():New( "report.txt" )

   oFile:SetSize( 80, 66 )

   oFile:StartPage()
   oFile:Say( 1, 30, "Relatório Mensal" )
   oFile:Say( 3, 1,  Replicate( "-", 80 ) )
   oFile:Say( 5, 1,  "Item" )
   oFile:Say( 5, 40, "Amount" )
   oFile:Say( 6, 1,  Replicate( "-", 80 ) )
   oFile:Say( 8, 1,  "Widget A" )
   oFile:Say( 8, 40, "  150.00" )
   oFile:Say( 9, 1,  "Widget B" )
   oFile:Say( 9, 40, "  275.00" )
   oFile:EndPage()

   oFile:End()

return nil

Notas

  • TRFile pode ser usada como substituta direta da TPrinter na TReport definindo oReport:oDevice := TRFile():New( "out.txt" ).
  • O posicionamento do texto é baseado em caracteres: linha 1, coluna 1 é o canto superior esquerdo.
  • Fontes, bitmaps, linhas e caixas não são suportados (os métodos são VIRTUAL).
  • Cada página é armazenada em buffer em aRows e descarregada em disco em EndPage().

Geração de Códigos de Barras (FWER_BarCode)

Fonte: source/classes/fwbarcod.prg, source/function/fwzebra.prg

FWER_BarCode é o motor de renderização de códigos de barras integrado do FiveWin. Ele suporta 17 simbologias de códigos de barras através de um motor GDI nativo, com fallback opcional para a biblioteca hbzebra para códigos 2D (QR, DataMatrix, PDF417). Os códigos de barras podem ser renderizados em janelas, diálogos, impressoras e saída em PDF.

Funções Livres

FW_SayBarCode()

Renderização direta de código de barras sem criar uma instância de objeto:

FW_SayBarCode( oWnd, cText, aRect, cType, nClrT, nClrB, lVert, lTransp )

Parâmetros: oWnd (janela/diálogo/impressora), cText (dados a codificar), aRect (array { nTop, nLeft, nBottom, nRight }), cType (string da simbologia), nClrT/nClrB (cores de frente/fundo), lVert (orientação vertical), lTransp (fundo transparente).

FW_BarCodeBmp()

Gera um handle de bitmap independente do código de barras para uso em relatórios ou controles de imagem.

Exemplo: EAN-13 na Impressora

#include "FiveWin.ch"

FUNCTION PrintBarcode()
   LOCAL oPrn, nRow := 2.0  // cm a partir do topo

   PRINT oPrn NAME "Barcode Test"
   PAGE
      oPrn:Say( nRow, 1.0, "Product Barcode:" )
      nRow += 0.8

      // Metodo 1: Usando FWER_BarCode diretamente
      FWER_BarCode():New( oPrn:hDC, "5901234567890", ;
                          oPrn:CmToPix( nRow ),        // nTop
                          oPrn:CmToPix( 1.0 ),         // nLeft
                          oPrn:CmToPix( 5.0 ),         // nWidth
                          oPrn:CmToPix( 2.5 ),         // nHeight
                          8, 0, 16777215, .T., .F. ):ShowBarcode()

      // Metodo 2: Usando a funcao de conveniencia FW_SayBarCode
      nRow += 3.0
      FW_SayBarCode( oPrn, "5901234567890", ;
                     { oPrn:CmToPix( nRow ), oPrn:CmToPix( 1.0 ), ;
                       oPrn:CmToPix( nRow + 2.5 ), oPrn:CmToPix( 6.0 ) }, ;
                     "EAN13", 0, 16777215 )
   ENDPAGE
   ENDPRINT
RETURN NIL

Notas

  • Os nomes de tipo em string não diferenciam maiúsculas de minúsculas e são normalizados removendo o prefixo "CODE", espaços, sublinhados e hífens. Exemplo: "CODE128", "code 128" e "128" resolvem todos para Code 128 auto.
  • Quando a biblioteca hbzebra está vinculada, as simbologias 2D (QR, DataMatrix, PDF417) são automaticamente roteadas pelo motor Zebra, que também suporta saída direta em PDF via detecção do objeto TPDF.
  • Use FWER_BarCode:lUseZebraLib := .T. no nível da classe para forçar o motor Zebra para todas as simbologias suportadas.
  • A saída para impressora usa GDI FillRect para as barras e FillRectEx para o fundo, garantindo o dimensionamento correto em dispositivos de alta DPI.

FWPdf

Fonte: source/classes/fwpdf.prg

Herda de: TPdf

FWPdf é uma classe aprimorada de geração de PDF que estende TPdf com funcionalidades adicionais como suporte a Unicode, renderização de texto RTF, gráficos de pizza, preenchimentos gradientes, códigos de barras, impressão de imagens, hiperligações e suporte a múltiplas unidades de coordenadas (pontos, polegadas, centímetros, milímetros). Fornece uma API completa de alto nível para criar documentos PDF profissionais.

Exemplo: PDF Rico com Imagem, Gráfico e Gradiente

#include "FiveWin.ch"

function Main()

   local oPdf, oFont

   oPdf := FWPdf():New( "rich_doc.pdf" )
   oPdf:cAuthor  := "FWH User"
   oPdf:cTitle   := "Rich Document"
   oPdf:cSubject := "Demonstrates FWPdf features"

   oPdf:SetPage( HPDF_PAGE_SIZE_A4 )
   oPdf:StartPage()

   oFont := oPdf:DefineFont( "Arial", 16, .T., .T. )

   // Title text
   oPdf:Say( 2, 2, "FWPdf Rich Document", oFont, , , , , "CM" )

   // Gradient fill
   oPdf:GradientFill( { 2, 2, 19, 5 }, { { CLR_HRED, 0.5 }, { CLR_HBLUE, 0.5 } }, .F., "CM" )

   // Draw a line separator
   oPdf:Line( 2, 6, 19, 6, , "CM" )

   // Barcode
   oPdf:PrintBarcode( "FWH-12345", 2, 7, 6, 2, "CM" )

   oPdf:EndPage()
   oPdf:Save()

return nil

Notas

  • FWPdf herda todos os métodos de TPdf e os estende com sobrecargas conscientes de unidades. O parâmetro cUnits aceita "P" (pontos), "I" (polegadas), "C" (centímetros) ou "M" (milímetros).
  • Unicode está ativo por padrão baseado em FW_SetUnicode(). Quando ativo, a codificação UTF-8 é usada para todo o texto PDF.
  • Metadados (autor, título, assunto, criador) são incorporados no PDF e visíveis nas propriedades do documento.
  • Preenchimentos gradientes suportam gradientes lineares com múltiplas paragens de cor e rácios.
  • Os tipos de código de barras incluem Code 128, Code 39, EAN-13 e outros.

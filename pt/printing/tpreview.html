TPreview

Fonte: source/classes/rpreview.prg

Classe independente (não herdada de TControl)

TPreview é o motor de janela de pré-visualização de impressão do FiveWin. É invocado automaticamente ao usar a cláusula PREVIEW com o comando PRINTER, e fornece um ambiente de pré-visualização completo com zoom, navegação de páginas, visualização de duas páginas, impressão e capacidades de exportação. Também é usado internamente por TReport para pré-visualização de relatórios.

Exemplo: Pré-visualização de Impressão com Comando PRINTER

#include "FiveWin.ch"

function Main()

   local oWnd

   DEFINE WINDOW oWnd TITLE "Print Preview Demo" SIZE 600, 400

   @ 20, 20 BUTTON "&Print Preview" SIZE 120, 30 OF oWnd ;
      ACTION DoPreview()

   ACTIVATE WINDOW oWnd CENTERED

return nil

function DoPreview()

   PRINTER oPrn PREVIEW
      PAGE
         @ 10, 10 SAY "Hello from FiveWin!" FONT oPrn:oFont
         @ 30, 10 SAY "Page: " + Str( oPrn:nPageCount )
      ENDPAGE
      PAGE
         @ 10, 10 SAY "This is page 2"
      ENDPAGE
   ENDPRINTER

return nil

Notas

  • TPreview é usado automaticamente quando PRINTER ... PREVIEW é especificado. Também pode ser instanciado diretamente passando um dispositivo TPrinter e um objeto TReport opcional.
  • A janela de pré-visualização suporta navegação por teclado: teclas de seta para rolagem, Page Up/Down para navegação de páginas, e +/- para aumentar/diminuir zoom.
  • O modo escuro é detectado e aplicado automaticamente no Windows 11 quando o tema do sistema está configurado para escuro.
  • As capacidades de exportação (PDF, Word, Excel) dependem do dispositivo de impressão e do relatório terem os blocos de código apropriados atribuídos.
  • O oLvw (miniaturas em lista) fornece um seletor visual de páginas lateral. Pode ser ocultado via o class data lListViewHide.

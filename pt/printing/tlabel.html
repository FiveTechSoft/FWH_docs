Impressão de Etiquetas

Fontes: samples/labels/source/LABEL.PRG, LITEM.PRG, PDLABEL.PRG — por Manuel Calero Solis (1995)

A FWH inclui um sistema completo de impressão de etiquetas em samples/labels/ com 17 programas de exemplo e código-fonte completo. Ele imprime etiquetas em um layout de grade (por exemplo, 2 na horizontal, 7 na vertical) com quebras de página automáticas, posicionamento e suporte a bitmaps. As etiquetas podem ser enviadas para impressora, janela de pré-visualização ou arquivo de texto.

Arquitetura

graph LR A["Comando LABEL"] --> B["Motor TLabel"] B --> C["TPrinter"] B --> D["TRFile (texto)"] B --> E["Diálogo de Pré-visualização"] F["TLItem"] --> B G["Comando LBLITEM"] --> F

Comandos (include/label.ch)

LABEL

LABEL oLabel ;
   SIZE nWidth, nHeight ;          // mm
   SEPARATORS nH, nV ;              // espaçamento horizontal, vertical em mm
   ON LINE nCount ;                 // etiquetas por linha
   FONT aFonts PEN aPens ;         // arrays opcionais de fonte/caneta
   TO PRINTER | PREVIEW | FILE cFile | DEVICE oDevice ;
   CAPTION cTitle

LBLITEM

LBLITEM DATA bData1, bData2, ... ;
   AT nCol ;                        // deslocamento da coluna
   SIZE nChars ;                    // largura em caracteres
   PICTURE cPict1, cPict2, ... ;
   FONT uFont ;                     // índice ou nome da fonte
   LEFT | CENTER | RIGHT ;
   SHADOW ;                         // fundo cinza
   GRID nPen                        // linha de grade inferior

ACTIVATE LABEL

ACTIVATE LABEL oLabel ;
   FOR bFor WHILE bWhile ;
   ON INIT bInit ;
   ON STARTPAGE bStartPage ON ENDPAGE bEndPage ;
   ON STARTLINE bStartLine ON ENDLINE bEndLine ;
   ON STARTLABEL bStartLabel ON ENDLABEL bEndLabel ;
   ON CHANGE bChange

Classe TLabel

Motor principal de etiquetas. Gerencia o layout de grade das etiquetas, quebras de página, fontes e dispositivo de saída.

DATADescrição
oDeviceDispositivo de saída (TPrinter, TRFile ou tela)
nLblWidth / nLblHeightDimensões da etiqueta em pixels
nHSeparator / nVSeparatorEspaçamento horizontal/vertical entre etiquetas
nLblOnLineEtiquetas por linha ao longo da página
aoItemsArray de objetos TLItem (campos da etiqueta)
aFont / aPenArrays de fonte e caneta (escalados para o dispositivo)
nLeftMargin / nRightMargin / nTopMargin / nDnMarginMargens da página em pixels
MétodoDescrição
New(nW,nH,hSep,vSep,nPerLine,aFont,aPen,...)Construtor, cria o dispositivo, escala as unidades
AddItem(oItem)Adiciona um TLItem à etiqueta
Activate(bFor,bWhile,bInit,...)Define os hooks e inicia o loop de impressão
Say(nRow,nCol,xText,nFont,nPad)Imprime texto com alinhamento à esquerda/centro/direita
SayBitmap(nRow,nCol,cBmp,nW,nH)Renderiza bitmap na posição
Box(nRow,nCol,nBottom,nRight,nPen)Desenha retângulo
Line(nTop,nLeft,nBottom,nRight,nPen)Desenha linha
Shadow(nH,nItem,nLine)Preenchimento de fundo cinza atrás de uma etiqueta
Grid(nH,nItem,nLine)Linha de grade horizontal ao longo da etiqueta
Margin(nVal,nType)Define margens individuais

Classe TLItem

Representa um campo de dados dentro de uma etiqueta. Criado pelo comando LBLITEM.

DATADescrição
aDataArray de blocos de código que retornam valores a imprimir
aPictureCláusulas PICTURE por bloco de dados
bDataFontBloco de código que retorna o índice da fonte
nWidth / nDataHeightDimensões do campo em pixels
nColDeslocamento opcional da coluna a partir da borda esquerda
nPadAlinhamento: RPT_LEFT(1), RPT_RIGHT(2), RPT_CENTER(3)
lShadow / lGridHabilita fundo sombreado / linha de grade inferior

Exemplo: Etiqueta de Endereço Simples

#include "FiveWin.ch"
#include "label.ch"

FUNCTION Label01()
   local oLabel
   USE TEST NEW SHARED ALIAS "TEST"

   // etiquetas de 89x23mm, 2 por linha, pré-visualização
   LABEL oLabel SIZE 89, 23 ;
      SEPARATORS 5, 2 ;
      ON LINE 2 ;
      PREVIEW ;
      CAPTION "Address Labels"

   LBLITEM DATA "N.: " + Str( TEST->( RECNO() ), 0 )
   LBLITEM DATA TEST->FIRST
   LBLITEM DATA TEST->LAST
   LBLITEM DATA TEST->STREET

   END LABEL oLabel
   ACTIVATE LABEL oLabel
   CLOSE TEST
RETURN NIL

Etiquetas com Códigos QR

Combine a impressão de etiquetas com códigos QR usando FW_BarCodeBmp() + SayBitmap():

REQUEST FWZEBRA

LABEL oLabel SIZE 100, 60 ;
   SEPARATORS 3, 3 ;
   ON LINE 2 ;
   PREVIEW

LBLITEM DATA CUSTOMER->FIRST
LBLITEM DATA CUSTOMER->LAST
LBLITEM DATA CUSTOMER->CITY

ACTIVATE LABEL oLabel ;
   ON STARTLABEL { || ;
      oLabel:SayBitmap( 1, 3.5, ;
         FW_BarCodeBmp( ;
            "https://example.com/" + CUSTOMER->ID, ;
            "QR", 150, 150 ), ;
         0.5, 0.5 ) }

END LABEL oLabel

Programas de Exemplo

O diretório samples/labels/ contém 17 exemplos prontos para executar:

  • LABEL01.PRG até LABEL17.PRG — exemplos progressivos abrangendo etiquetas de endereço, etiquetas de produto, códigos de barras, múltiplas páginas, saída para arquivo e pré-visualização
  • DEMO.PRG — demonstração combinada
  • source/LABEL.PRG — classe do motor TLabel
  • source/LITEM.PRG — classe de campo de dados TLItem
  • source/PDLABEL.PRG — funções auxiliares de comando
  • include/LABEL.CH — definições #xcommand
  • ilabel/ — subsistema de etiquetas italiano (ILABELS.PRG, MLABEL.PRG)

Dicas

  • As etiquetas são medidas em milímetros por padrão. Use TO PRINTER para impressão direta ou PREVIEW para pré-visualização na tela.
  • Os hooks ON STARTLABEL e ON ENDLABEL são o melhor lugar para adicionar desenhos personalizados (imagens, códigos de barras, códigos QR).
  • Para códigos QR nas etiquetas, gere um bitmap com FW_BarCodeBmp() e renderize-o via oLabel:SayBitmap() dentro de um hook STARTLABEL.
  • Para impressão de etiquetas autônoma sem o sistema TLabel, use TPrinter diretamente: defina o tamanho do papel, percorra os registros, chame Say() para cada campo e gerencie as posições manualmente.

TSmtp

Fonte: source/classes/tsmtp.prg

TSmtp é a classe de envio de e-mail do FiveWin. Ela implementa o protocolo SMTP para enviar mensagens através de um servidor de correio, com suporte para autenticação (AUTH LOGIN), conteúdo HTML, anexos de arquivos, destinatários CC/BCC e confirmações de recebimento. É construída sobre TSocket e usa o modelo de eventos assíncronos para comunicação.

Métodos

MétodoDescrição
New( cIPServer, nPort, lAuth, cUser, cPassword )Criar uma nova sessão SMTP. nPort padrão é 25. Resolve hostname para IP se necessário.
SendMail( cFrom, aTo, cMsg, cSubject, aFiles, aCC, aBCC, lReceipt, cHTML )Compor e enviar um e-mail. Todos os parâmetros após aTo são opcionais.
End()Fechar o socket subjacente e limpar
Priority()Retornar prioridade numérica: 1=High, 3=Normal, 5=Low

Exemplo: Enviar um E-mail Simples

#include "FiveWin.ch"

function Main()

   local oSmtp

   oSmtp := TSmtp():New( "mail.example.com" )

   oSmtp:SendMail( "sender@example.com", ;
                   { "recipient@example.com" }, ;
                   "Hello, this is a test message.", ;
                   "Test Subject" )

return nil

Exemplo: SMTP Autenticado com Anexo

#include "FiveWin.ch"

function Main()

   local oSmtp

   // Gmail SMTP with authentication
   oSmtp := TSmtp():New( "smtp.gmail.com", 587, .T., ;
                         "user@gmail.com", "password" )

   oSmtp:bConnecting := { || MsgInfo( "Connecting to SMTP server..." ) }
   oSmtp:bDone       := { || MsgInfo( "Email sent successfully!" ) }
   oSmtp:bFailure    := { |o,n,c| MsgStop( "Error: " + oSmtp:cError ) }

   oSmtp:SendMail( "user@gmail.com", ;
                   { "recipient@example.com" }, ;
                   "Please find the attached report.", ;
                   "Monthly Report", ;
                   { "C:\reports\report.pdf" } )

return nil

Exemplo: E-mail HTML com CC

#include "FiveWin.ch"

function Main()

   local oSmtp, cHtml

   TEXT INTO cHtml
   <html>
   <body style="font-family: Arial; color: #333;">
      <h1>Welcome!</h1>
      <p>This is an <b>HTML email</b> sent from FiveWin.</p>
      <hr>
      <p>Regards,<br>The FiveWin Team</p>
   </body>
   </html>
   ENDTEXT

   oSmtp := TSmtp():New( "mail.example.com" )

   oSmtp:SendMail( "sender@example.com", ;
                   { "alice@example.com" }, ;
                   "Plain text fallback message.", ;
                   "HTML Email Test", , ;
                   { "bob@example.com" }, ;   // CC
                   .F., cHtml )

return nil

Notas

  • TSmtp suporta o método de autenticação AUTH LOGIN. Para servidores que exigem PLAIN ou MD5, é necessária implementação adicional.
  • O hostname do servidor (cIPServer) pode ser um nome amigável (ex.: "smtp.gmail.com") ou um endereço IP. TSmtp resolve automaticamente.
  • Anexos são codificados como base64 para arquivos binários ou quoted-printable para arquivos de texto. Os nomes dos arquivos preservam suas maiúsculas/minúsculas originais.
  • E-mails HTML incluem uma estrutura multipart/alternative: um fallback de texto simples é enviado junto com o conteúdo HTML.
  • Se o servidor expirar após enviar anexos grandes, incremente o membro DATA nDelay em um para adicionar atraso entre os envios.

TFtpClient / TFtpSession

Fonte: source/classes/tftpcli.prg (TFtpClient), source/classes/tftpsess.prg (TFtpSession)

FiveWin fornece capacidades de cliente FTP através de TFtpClient, que implementa o protocolo FTP para operações de transferência de arquivos. Suporta upload (STOR), download (RETR), navegação de diretórios (CWD, PWD), criação de diretórios (MKD), exclusão de arquivos (DELE) e modos de transferência binário/texto (TYPE). TFtpSession é uma classe leve usada pelo servidor FTP interno para rastrear sessões de cliente conectadas.

Classe TFtpClient

Membros DATA

DATATipoDescrição
cIPServerCharacterNome do servidor FTP ou endereço IP
nPortNumericPorta do servidor FTP (padrão 21)
UserCharacterNome de usuário FTP
PassCharacterSenha FTP
oSocketTSocketSocket da conexão de controle
oDataSocketTSocketSocket da conexão de dados para transferências de arquivos
nStatusNumericEstado da sessão (CONNECTING, IDENTIFY1, IDENTIFY2)
AllOkLogicalDefinido como .T. após login bem-sucedido
SrvLastMsgCharacterÚltima mensagem de resposta do servidor
lWaitingLogicalFlag de ocupado durante execução síncrona de comandos
lTimeOutLogicalDefinido como .T. se um comando expirar (30 segundos)
nSendedNumericContador de bytes enviados
bConnectingBlockCallback durante a conexão
bConnectedBlockCallback quando conectado
bDoneBlockCallback quando a operação é concluída

Métodos

MétodoDescrição
New( cIPServer, nPort, User, Pass )Criar cliente FTP e conectar ao servidor. nPort padrão é 21.
PWD()Imprimir diretório de trabalho. Retorna a resposta do servidor.
CWD( cDirName )Alterar diretório de trabalho no servidor
MKD( cDirName )Criar um diretório no servidor
DELE( cFileName )Excluir um arquivo do servidor
TYPE( cType )Definir modo de transferência: "I" (binário/imagem) ou "A" (ASCII)
STOR( cFileName, bBlock )Enviar um arquivo (STORE). Usa modo ativo PORT.
RETR( cFileName )Baixar um arquivo (RETRIEVE). Retorna .T. em sucesso, .F. se arquivo não encontrado (550).
PORT( oTransSocket )Gerar string do comando PORT para conexão de dados ativa
QUIT()Desconectar do servidor
DoWait()Aguardar sincronamente a resposta do servidor (timeout de 30 segundos)

Classe TFtpSession

TFtpSession é uma classe de dados simples usada internamente para representar uma sessão de cliente FTP conectada no lado do servidor:

DATATipoDescrição
cUserNameCharacterNome de usuário autenticado
cPasswordCharacterSenha autenticada
cCurDirCharacterDiretório de trabalho atual da sessão
cIPCharacterEndereço IP do cliente do comando PORT
nPortNumericPorta do cliente do comando PORT
oSocketTSocketSocket de resposta para a sessão

Exemplo: Enviar um Arquivo

#include "FiveWin.ch"

function Main()

   local oFtp

   oFtp := TFtpClient():New( "ftp.example.com", 21, ;
                             "username", "password" )

   if oFtp:AllOk
      oFtp:CWD( "/public_html" )
      oFtp:STOR( "C:\files\index.html" )
      oFtp:QUIT()
      MsgInfo( "Upload complete" )
   else
      MsgStop( "FTP connection failed" )
   endif

return nil

Exemplo: Baixar um Arquivo

#include "FiveWin.ch"

function Main()

   local oFtp, lResult

   oFtp := TFtpClient():New( "ftp.example.com", 21, ;
                             "username", "password" )

   if oFtp:AllOk
      oFtp:CWD( "/backups" )
      lResult := oFtp:RETR( "data_2026.zip" )
      if lResult
         MsgInfo( "Download successful" )
      else
         MsgAlert( "File not found on server" )
      endif
      oFtp:QUIT()
   endif

return nil

Exemplo: Operações de Diretório

#include "FiveWin.ch"

function Main()

   local oFtp, cCurrentDir

   oFtp := TFtpClient():New( "ftp.example.com", 21, ;
                             "username", "password" )

   if oFtp:AllOk
      // Get current directory
      cCurrentDir := oFtp:PWD()

      // Create a directory
      oFtp:MKD( "new_folder" )

      // Change into it
      oFtp:CWD( "new_folder" )

      // List current directory
      ? oFtp:PWD()

      oFtp:QUIT()
   endif

return nil

Notas

  • TFtpClient usa modo FTP ativo (comando PORT) para transferências de dados. O cliente abre um socket de escuta e envia o comando PORT com informações de IP e porta para o servidor.
  • Após chamar New(), verifique AllOk para confirmar que o login foi bem-sucedido antes de tentar operações de arquivo.
  • O método DoWait() implementa execução síncrona de comandos com timeout de 30 segundos. Se o servidor não responder a tempo, lTimeOut é definido como .T..
  • Para downloads, RETR() retorna .F. se o servidor responder com código de erro 550 (arquivo não encontrado).
  • TFtpSession é projetada para uso com a classe interna de servidor FTP e normalmente não é instanciada diretamente pelo código da aplicação.

TOLlama (Ollama / Local LLM)

Fonte: source/classes/tollama.prg

TOLlama é o cliente do FiveWin para a API Ollama, permitindo a interação com LLMs hospedados localmente através da API REST do Ollama (padrão: http://localhost:11434). Suporta chat de texto, respostas em streaming e análise de imagens para modelos com capacidade de visão. A classe usa a biblioteca hb_curl do Harbour e conecta-se ao seu servidor Ollama local, não exigindo chaves de API nem conectividade com a internet. A classe complementar TAgent fornece um contêiner de dados para definições de ferramentas/agentes.

Métodos

MétodoDescrição
New( cModel )Cria uma instância de TOLlama. Define o nome do modelo e inicializa o handle do libcurl. O endpoint padrão é http://localhost:11434/api/chat.
Send( cPrompt )Envia um prompt de texto para a API de chat do Ollama. Armazena a resposta JSON bruta em cResponse e a retorna.
SendStream( cPrompt, bWriteFunction )Envia um prompt com streaming ativado. O codeblock bWriteFunction recebe cada fragmento JSON à medida que chega do servidor.
SendImage( cImageFileName, cPrompt )Envia um arquivo de imagem local com um prompt de texto para análise de visão. Codifica a imagem em base64. Suportado por modelos de visão como o LLaVA.
GetValue()Extrai o texto da resposta do JSON em cResponse. Retorna message.content ou a mensagem de erro.
End()Libera o handle do libcurl. Chamado automaticamente pelo destrutor.

Classe TAgent

DATATipoDescrição
cCategoryCaractereCategoria ou identificador do agente

TAgent é um contêiner de dados para definir agentes e seus conjuntos de ferramentas associados. Funciona em conjunto com o array aAgents do TOLlama para organizar múltiplas configurações de agentes.

MétodoDescrição
New( cCategory, aTools )Cria uma instância de TAgent com um nome de categoria e um array de definições de ferramentas.

Exemplo: Chat com LLM Local

#include "FiveWin.ch"

function Main()

   local oAI := TOLlama():New( "llama3.2" )

   oAI:Send( "What is the capital of France?" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      MsgInfo( oAI:GetValue() )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Exemplo: Resposta em Streaming

#include "FiveWin.ch"

function Main()

   local oAI := TOLlama():New( "llama3.2" )
   local cBuffer := ""

   oAI:SendStream( "Tell me a joke.", ;
      { |cChunk| cBuffer += cChunk, QOut( cChunk ) } )

   if oAI:nError == 0
      MsgInfo( "Complete response:" + CRLF + cBuffer )
   endif

   oAI:End()

return nil

Exemplo: Análise de Imagem

#include "FiveWin.ch"

function Main()

   local oAI := TOLlama():New( "llava" )  // modelo com capacidade de visão

   oAI:SendImage( "C:\photos\photo.jpg", "What objects do you see?" )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Notas

  • TOLlama conecta-se a um servidor Ollama em execução local. Nenhuma chave de API ou acesso à internet é necessário.
  • O modelo padrão é "deepseek-r1:14b" (definido na classe), mas você deve passar o nome do modelo que baixou localmente (por exemplo, "llama3.2", "llava", "mistral").
  • Para análise de imagem, use um modelo com capacidade de visão como "llava" ou "bakllava".
  • GetValue() extrai o campo message.content da resposta JSON do Ollama. Em caso de erro, retorna o campo error.message.
  • O método Send() define stream: false e temperature: 0.5 na requisição. SendStream() define stream: true.
  • Requer a biblioteca hb_curl. Inclua #include "hbcurl.ch" para as constantes do curl.

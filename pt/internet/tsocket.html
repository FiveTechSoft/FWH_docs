TSocket

Fonte: source/classes/tsocket.prg

TSocket é a classe de sockets TCP/IP de baixo nível do FiveWin, encapsulando a API Winsock do Windows. Ela fornece funcionalidade de socket tanto para cliente quanto para servidor através de um modelo assíncrono orientado a eventos que se integra naturalmente ao loop de mensagens do FiveWin. TSocket é a base para TWebServer, TSmtp, TPop3, TFtpClient e TWebClient.

Métodos

MétodoDescrição
New( nPort, oWnd, cIp )Criar um socket e vincular a uma porta. Chama WSAStartup no primeiro socket. Registra com oWnd para eventos assíncronos.
Listen()Iniciar escuta por conexões recebidas na porta vinculada
Accept( nSocket, oWnd )Aceitar uma conexão recebida. Retorna um novo TSocket para a sessão do cliente.
Connect( cIPAddr, nPort )Conectar a um servidor remoto como cliente
GetData()Ler dados disponíveis do socket. Retorna uma string de caracteres.
SendData( cData )Enviar dados de caractere. Armazena em buffer se um envio anterior estiver em andamento.
SendFile( cFileName, nBlockSize )Enviar um arquivo em blocos. O tamanho padrão do bloco é 30.000 bytes.
SendChunk( nBlockSize )Enviar o próximo bloco de um handle de arquivo aberto (usado internamente por SendFile)
ClientIP()Obter o endereço IP do par remoto conectado
Refresh()Forçar o socket a se registrar novamente para eventos assíncronos
Close()Fechar o handle do socket. Aguarda a conclusão de envios pendentes.
End()Fechar o socket e remover da lista de sockets da classe. Chama WSACleanup quando for o último socket.

Callbacks de Evento

TSocket usa WSAAsyncSelect para registrar eventos de socket do Windows. Quando um evento ocorre, o loop de mensagens do FiveWin o roteia para HandleEvent(), que despacha para o método de callback apropriado. Defina o codeblock correspondente para manipular o evento:

CodeblockEventoMétodo Callback
bAcceptConexão recebidaOnAccept()
bReadDados disponíveisOnRead()
bWritePronto para enviarOnWrite()
bCloseRemoto fechouOnClose()
bConnectResultado da conexãoOnConnect( nErrorCode )
bOOBDados OOBOnOOB()

Exemplo: Cliente TCP

#include "FiveWin.ch"

function Main()

   local oWnd, oSocket, cResponse := ""

   DEFINE WINDOW oWnd TITLE "TCP Client"

   oSocket := TSocket():New( 0, oWnd )

   oSocket:bRead := { |oSock|
      cResponse += oSock:GetData()
      oWnd:SetText( "Received: " + cResponse )
   }

   oSocket:bClose := { |oSock|
      MsgInfo( "Connection closed" )
      oSock:End()
   }

   // Connect to a remote server
   oSocket:Connect( "93.184.216.34", 80 )

   // Send HTTP request
   oSocket:SendData( "GET / HTTP/1.1" + CRLF + ;
                     "Host: example.com" + CRLF + ;
                     "Connection: close" + CRLF + CRLF )

   ACTIVATE WINDOW oWnd ;
      ON INIT SysRefresh() ;
      VALID ( oSocket:End(), .T. )

return nil

Exemplo: Servidor de Chat

#include "FiveWin.ch"

static aClients := {}

function Main()

   local oWnd, oSocket

   DEFINE WINDOW oWnd TITLE "Chat Server - Port 9000"

   oSocket := TSocket():New( 9000, oWnd )
   oSocket:Listen()

   oSocket:bAccept := { ||
      local oClient := TSocket():Accept( oSocket:nSocket, oWnd )
      AAdd( aClients, oClient )

      oClient:bRead := { |oSock|
         local cMsg := oSock:GetData()
         AEval( aClients, { |o| o:SendData( cMsg ) } )
      }

      oClient:bClose := { |oSock|
         local nAt := AScan( aClients, ;
            { |o| o:nSocket == oSock:nSocket } )
         if nAt > 0
            ADel( aClients, nAt, .T. )
         endif
         oSock:End()
      }
   }

   ACTIVATE WINDOW oWnd VALID ( oSocket:End(), .T. )

return nil

Notas

  • TSocket requer uma janela FiveWin (ou diálogo) para seu modelo de eventos assíncronos. O loop de mensagens da janela despacha eventos Winsock via WSAAsyncSelect.
  • O array de classe aSockets rastreia todos os sockets ativos. HandleEvent() pesquisa neste array pelo handle do socket para despachar eventos ao objeto correto.
  • WSAStartup() é chamado quando o primeiro TSocket é criado. WSACleanup() é chamado quando o último socket é destruído.
  • O método SendData() lida com envios parciais e armazena dados em buffer automaticamente. Envios grandes são transparentemente divididos em vários segmentos TCP.
  • Use ShowIP() (uma função utilitária em tsocket.prg) para obter rapidamente o endereço IP da máquina local.

TWebClient

Fonte: source/classes/twebclie.prg

TWebClient é a classe de cliente HTTP leve do FiveWin, construída diretamente sobre TSocket. Ela fornece uma interface simples para conectar a servidores web, buscar páginas e processar respostas HTTP. Para funcionalidades HTTP mais avançadas (HTTPS, POST com JSON, cabeçalhos personalizados), considere usar a biblioteca hb_curl diretamente ou as classes TOpenAI/AI como referência.

Membros DATA Principais

DATATipoDescrição
oSocketTSocketSocket TCP subjacente para a conexão HTTP
bOnConnectBlockCallback executado quando a conexão com o servidor é estabelecida
bOnReadBlockCallback executado quando dados chegam do servidor

Métodos

MétodoDescrição
New()Criar um novo TWebClient. Cria e configura o TSocket subjacente com handlers padrão de leitura/conexão/fechamento.
Connect( cIPAddress )Conectar a um servidor web. Aceita hostname (ex.: "example.com") ou endereço IP. Resolve hostnames automaticamente.
GetPage( cPageName )Enviar uma solicitação HTTP GET para o caminho de página especificado. Suporta tanto URLs completas (http://...) quanto caminhos relativos.
OnConnect()Chamado internamente quando a conexão é estabelecida. Dispara o callback bOnConnect se definido.
OnRead( cData )Chamado internamente quando dados são recebidos. Dispara o callback bOnRead com os dados recebidos.

Exemplo: Buscar uma Página Web

#include "FiveWin.ch"

function Main()

   local oClient, cResponse := ""

   oClient := TWebClient():New()

   oClient:bOnConnect := { ||
      oClient:GetPage( "/" )
   }

   oClient:bOnRead := { |cData|
      cResponse += cData
   }

   oClient:Connect( "www.example.com" )

   // Wait for response
   SysRefresh()
   Inkey( 3 )

   // Display the HTTP response
   ? "Response received:", Len( cResponse ), "bytes"
   ? SubStr( cResponse, 1, 500 )

return nil

Exemplo: Chamada de API REST

#include "FiveWin.ch"

function Main()

   local oClient, cResponse := ""
   local cApiHost := "api.github.com"
   local cEndpoint := "/repos/FiveTechSoft/FWH"

   oClient := TWebClient():New()

   oClient:bOnConnect := { ||
      // Send a GET request to the GitHub API
      oClient:GetPage( cEndpoint + ;
        " HTTP/1.1" + CRLF + ;
        "Host: " + cApiHost + CRLF + ;
        "User-Agent: FWH-WebClient" + CRLF + ;
        "Accept: application/vnd.github.v3+json" + CRLF + ;
        "Connection: close" )
   }

   oClient:bOnRead := { |cData|
      cResponse += cData
   }

   oClient:Connect( cApiHost )

   // Wait for the async operation
   SysRefresh()
   Inkey( 5 )

   // Display the response
   if ! Empty( cResponse )
      MemoWrit( "github_response.txt", cResponse )
      ? "Response saved to github_response.txt"
   endif

return nil

Notas

  • TWebClient é um encapsulamento mínimo em torno de TSocket. Ele não analisa respostas HTTP nem lida com redirecionamentos automaticamente.
  • O método GetPage() envia uma solicitação HTTP GET bruta. Quando uma URL completa começando com "http://" é fornecida, ele analisa o hostname e o caminho da URL e usa HTTP/1.1 com um cabeçalho Host. Caso contrário, envia uma solicitação HTTP/1.0 simples apenas com o caminho.
  • Para conexões HTTPS, use a biblioteca hb_curl diretamente em vez de TWebClient, pois TSocket não suporta TLS/SSL nativamente.
  • A classe reinicializa automaticamente o socket após uma conexão ser fechada (o handler bClose recria o socket).
  • Como TWebClient usa eventos de socket assíncronos, SysRefresh() deve ser chamado para processar dados recebidos em aplicações modo console.

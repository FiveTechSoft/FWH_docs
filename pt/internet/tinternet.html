TInternet

Fonte: source/classes/internet.prg

Herda de: nenhuma (classe base)

TInternet é a classe base para acesso à Internet baseado em WinInet no FWH. Gerencia um manipulador de sessão WinInet global e fornece um método fábrica para criar conexões TFTP. A classe usa um padrão singleton com contagem de referências para o manipulador de sessão WinINet.

Principais Membros DATA

DATATipoDescrição
hWinINetManipulador(Dado de classe) Manipulador do WinINet.dll aberto
hSessionManipulador(Dado de classe) Manipulador da sessão WinINet atual (InternetOpen)
nCountNumérico(Dado de classe) Contagem de referência de objetos TInternet ativos
aFTPsArray(Dado de classe) Array de todos os objetos TFTP atualmente em uso

Métodos Principais

MétodoDescrição
New()Cria um novo objeto TInternet; incrementa a contagem de referência da sessão e abre a sessão WinINet no primeiro uso
End()Libera o objeto internet; decrementa a contagem de referência e fecha a sessão WinINet quando a contagem chega a zero
FTP( cFTPSite, cUserName, cPassword )Cria e retorna um novo objeto TFTP conectado ao site FTP especificado

Exemplo: Upload de Arquivo FTP via WinInet

#include "FiveWin.ch"

function Main()

   local oInet := TInternet():New()
   local oFtp  := oInet:FTP( "ftp.example.com", "user", "pass" )

   if oFtp:hFTP != nil
      oFtp:SetCurrentDirectory( "/uploads" )
      FtpPutFile( oFtp:hFTP, "c:\data\report.txt", "report.txt" )
      MsgInfo( "File uploaded successfully" )
   else
      MsgAlert( "FTP connection failed" )
   endif

   oFtp:End()
   oInet:End()

return nil

Notas

  • TInternet usa um padrão singleton com dados de classe: o manipulador hSession é compartilhado entre todas as instâncias de TInternet. A sessão é aberta no primeiro New() e fechada no último End().
  • O método FTP() cria um objeto TFTP (definido em tftp.prg) que usa InternetConnect com INTERNET_SERVICE_FTP na porta 21.
  • Todas as conexões TFTP ativas são rastreadas em aFTPs e fechadas adequadamente quando a contagem de referência do TInternet chega a zero.
  • As chamadas diretas à API WinINet (InternetOpen, InternetConnect, InternetCloseHandle, FtpPutFile, etc.) estão disponíveis para uso avançado além dos métodos wrapper.

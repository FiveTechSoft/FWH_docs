TGrok (xAI)

Fonte: source/classes/tgrok.prg

TGrok é o cliente FiveWin para a API xAI Grok. Fornece acesso aos modelos de linguagem Grok com suporte para chat de texto, respostas em stream e análise de imagens (incluindo upload de ficheiros locais e URLs de imagens). A classe usa a biblioteca hb_curl do Harbour para comunicação HTTPS com o endpoint da API xAI. As chaves de API podem ser passadas explicitamente ou lidas da variável de ambiente XAI_API_KEY.

Métodos Principais

MétodoDescrição
New( cKey, cModel )Criar uma instância TGrok. Se cKey estiver vazio, lê XAI_API_KEY do ambiente. Inicializa o handle libcurl.
Send( cPrompt )Enviar um prompt de texto para a API Grok. Armazena a resposta JSON bruta em cResponse.
SendStream( cPrompt, bCallback )Enviar um prompt com streaming ativado. O bloco de código bCallback recebe cada bloco de dados à medida que chega.
SendImage( cImageFile, cPrompt )Enviar um ficheiro de imagem local com um prompt de texto para análise de visão. Codifica a imagem como base64.
SendImageURL( cImageUrl, cPrompt )Enviar um URL de imagem com um prompt de texto para análise de visão.
GetValue()Extrair a resposta de texto do JSON em cResponse. Retorna o conteúdo da mensagem ou informação de erro.
End()Limpar o handle libcurl. Chamado automaticamente pelo destrutor.

Exemplo: Chat de Texto

#include "FiveWin.ch"

function Main()

   local oAI := TGrok():New( "your-xai-key-here" )

   oAI:Send( "What are the key features of the Harbour language?" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      MsgInfo( oAI:GetValue() )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Exemplo: Resposta em Stream

#include "FiveWin.ch"

function Main()

   local oAI := TGrok():New( "your-xai-key-here" )
   local cBuffer := ""

   oAI:SendStream( "Write a short story about AI.", ;
      { |cChunk| cBuffer += cChunk, QOut( cChunk ) } )

   if oAI:nError == 0
      MsgInfo( "Complete response:" + CRLF + cBuffer )
   endif

   oAI:End()

return nil

Exemplo: Análise de Imagem

#include "FiveWin.ch"

function Main()

   local oAI := TGrok():New( "your-xai-key-here", "grok-3-latest" )

   // Analyze a local image
   oAI:SendImage( "C:\photos\chart.png", "Describe this chart in detail." )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   // Analyze an image by URL
   oAI:SendImageURL( "https://example.com/photo.jpg", ;
      "What objects are in this photo?" )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Notas

  • TGrok requer a biblioteca hb_curl. Inclua #include "hbcurl.ch" para constantes curl.
  • A verificação SSL está desativada por padrão (HB_CURLOPT_SSL_VERIFYPEER = .F.) para compatibilidade.
  • A chave da API pode ser lida da variável de ambiente XAI_API_KEY passando uma chave vazia para New().
  • GetValue() navega pelo caminho JSON choices[1].message.content para extrair o texto. Se ocorreu um erro, retorna o objeto de erro.
  • O método SendImage() lê o ficheiro do disco, codifica-o como base64 e envia-o inline com o pedido.

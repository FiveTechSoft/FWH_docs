TPop3

Fonte: source/classes/tpop3.prg

TPop3 é a classe de recuperação de e-mail do FiveWin, implementando o protocolo POP3 para receber mensagens de um servidor de correio. Ela gerencia todo o ciclo de vida da sessão POP3: conectar, autenticar, listar mensagens, recuperar conteúdo, opcionalmente excluir mensagens do servidor e sair. Assim como TSmtp, é construída sobre TSocket.

Fluxo do Protocolo

sequenceDiagram participant App as FiveWin App participant POP3 as TPop3 participant Server as POP3 Server App->>POP3: GetMail() POP3->>Server: USER username Server-->>POP3: +OK POP3->>Server: PASS password Server-->>POP3: +OK POP3->>Server: STAT Server-->>POP3: +OK count size loop For each message POP3->>Server: RETR n Server-->>POP3: [message content] POP3->>Server: DELE n (if lDelMsgs=.T.) Server-->>POP3: +OK end POP3->>Server: QUIT Server-->>POP3: +OK

Membros DATA Principais

Métodos

MétodoDescrição
New( cIPServer, nPort, User, Pass )Criar uma nova sessão POP3. nPort padrão é 110.
GetMail()Conectar ao servidor e iniciar a sequência de recuperação de e-mail. As mensagens são armazenadas em aMsgs[].

Exemplo: Verificar Caixa de Entrada

#include "FiveWin.ch"

function Main()

   local oPop3, n

   oPop3 := TPop3():New( "mail.example.com", 110, ;
                         "user@example.com", "password" )

   oPop3:bConnected := { || MsgInfo( "Connected! Messages: " + ;
                                     LTrim( Str( Len( oPop3:aMsgs ) ) ) ) }

   oPop3:bDone := { ||
      MsgInfo( "Retrieved " + LTrim( Str( Len( oPop3:aMsgs ) ) ) + ;
               " messages." )
   }

   oPop3:GetMail()

   // Wait for async operation to complete
   while ! oPop3:AllOk
      SysRefresh()
   end

   // Display messages
   for n := 1 to Len( oPop3:aMsgs )
      ? "Message", n, ":", SubStr( oPop3:aMsgs[ n ], 1, 200 )
   next

return nil

Exemplo: Recuperar Apenas Cabeçalhos

#include "FiveWin.ch"

function Main()

   local oPop3, n

   oPop3 := TPop3():New( "mail.example.com", 110, ;
                         "user@example.com", "password" )

   // Only retrieve headers (faster, less bandwidth)
   oPop3:lHeaderOnly := .T.

   // Keep messages on the server
   oPop3:lDelMsgs := .F.

   oPop3:GetMail()

   while ! oPop3:AllOk
      SysRefresh()
   end

   // Display headers
   for n := 1 to Len( oPop3:aMsgs )
      ? "--- Message", n, "---"
      ? SubStr( oPop3:aMsgs[ n ], 1, 500 )
   next

return nil

Notas

  • TPop3 usa o modelo de socket assíncrono. Após chamar GetMail(), a recuperação acontece através do loop de mensagens do FiveWin. Chame SysRefresh() em um loop se estiver usando uma aplicação estilo console sem janela.
  • Por padrão, as mensagens são excluídas do servidor após a recuperação (lDelMsgs := .T.). Defina como .F. para deixar as mensagens no servidor.
  • Defina lHeaderOnly := .T. para recuperar apenas os cabeçalhos do e-mail usando o comando POP3 TOP. Isso é útil para escanear rapidamente o conteúdo da caixa de entrada sem baixar mensagens completas.
  • As mensagens em aMsgs[] são armazenadas em formato POP3 bruto, incluindo todos os cabeçalhos. Analisá-las para assunto, remetente, data, etc., requer extração de string do conteúdo bruto.
  • Detalhes de erro são registrados em MailErr.log no diretório da aplicação quando ocorre um erro POP3.

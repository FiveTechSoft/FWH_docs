TProxy

Fonte: source/classes/tproxy.prg

TProxy é o servidor proxy TCP multi-protocolo do FiveWin. Escuta numa porta local, aceita ligações de entrada e encaminha tráfego para um servidor backend remoto. O proxy funciona de forma transparente para qualquer protocolo baseado em TCP (HTTP, POP3, SMTP, FTP, etc.) criando ligações de socket emparelhadas entre o cliente e o servidor backend e retransmitindo dados bidirecionalmente.

Métodos Principais

MétodoDescrição
New( nPort, cServerIP )Criar uma instância do proxy. Cria o TSocket de escuta e configura o callback de aceitação. Padrão para porto 110 (POP3). Resolve nomes de anfitrião para endereços IP automaticamente.
Activate()Iniciar escuta por ligações de entrada. Delega para oSocket:Listen().
End()Parar o proxy e liberar o socket de escuta. Delega para oSocket:End().
OnAccept()Interno: Chamado quando um novo cliente se liga. Cria um socket de cliente emparelhado e socket backend, configura retransmissão bidirecional de dados com callbacks de leitura/fecho.
OnRead( oSocket, oServer )Interno: Chamado quando dados chegam do cliente. Encaminha os dados para o servidor backend.

Exemplo: Proxy POP3

#include "FiveWin.ch"

function Main()

   local oProxy, oWnd

   DEFINE WINDOW oWnd TITLE "POP3 Proxy - Port 8080"

   // Proxy on port 8080, forwarding to the mail server
   oProxy := TProxy():New( 8080, "mail.example.com" )
   oProxy:lDebug := .T.
   oProxy:Activate()

   ACTIVATE WINDOW oWnd VALID ( oProxy:End(), .T. )

return nil

Quando um cliente se liga ao porto 8080, TProxy cria uma ligação backend para mail.example.com:8080 (mesmo porto) e retransmite todos os dados bidirecionalmente. Com lDebug := .T., todo o tráfego é registado em proxy.log.

Notas

  • TProxy é agnóstico quanto a protocolo — funciona com qualquer protocolo baseado em TCP, pois simplesmente retransmite bytes brutos entre cliente e servidor.
  • O método New() aceita nomes de anfitrião e resolve-os para IPs usando GetHostByName().
  • Cada ligação de entrada cria dois objetos TSocket: um para o cliente e um para o backend. Ambos são limpos quando a ligação fecha.
  • Definir lDebug := .T. regista todos os dados do cliente e servidor no ficheiro especificado por cLogFile.
  • O porto do proxy padroniza para 110 (POP3) se não for especificado.

TFtpServer

Fonte: source/classes/tftpserv.prg

Classe independente

TFtpServer implementa um servidor FTP básico usando TSocket. Escuta na porta 21 e lida com comandos FTP padrão (USER, PASS, STOR, RETR, LIST, CWD, PWD, QUIT). Suporta acesso anônimo e serve arquivos de um diretório raiz configurável.

Principais Membros DATA

DATATipoDescrição
oSocketObjetoTSocket de escuta principal
cRootDirCaractereDiretório FTP padrão (padrão "ftp")
nPortNuméricoPorta de escuta (padrão 21)
lDebugLógicoHabilita registro de depuração em cLogFile

Métodos Principais

MétodoDescrição
New( nPort )Cria o servidor; cria o diretório raiz se ausente
Activate()Inicia a escuta de clientes
End()Para o servidor
OnAccept()Lida com novas conexões de clientes
OnRead( oSocket )Processa comandos FTP de um cliente

TFTP

Fonte: source/classes/tftp.prg

Cliente FTP via WinINet. Suporta listagem de diretórios, exclusão de arquivos, renomeação e gerenciamento de diretórios.

MétodoDescrição
New( cFTPSite, oInternet, cUser, cPass )Conecta a um site FTP
Directory( cMask )Retorna um array de registros de arquivos remotos
DeleteFile( cFile )Exclui um arquivo remoto
RenameFile( cOld, cNew )Renomeia um arquivo remoto

TFTPFile

Fonte: source/classes/tftpfile.prg

Gerencia transferências individuais de arquivos remotos. Suporta modos ASCII e binário.

MétodoDescrição
New( cFileName, oFTP )Cria um objeto de arquivo
OpenRead() / OpenWrite()Abre para leitura ou escrita
Read( nBytes ) / Write( cData )Lê ou escreve dados
Seek( nBytes, nFrom )Posiciona em uma localização
End()Fecha o manipulador do arquivo

Exemplo: Iniciar Servidor FTP

#include "FiveWin.ch"
function Main()
   local oServer
   oServer := TFtpServer():New( 21 )
   oServer:cRootDir = "c:\ftproot"
   oServer:lDebug   = .T.
   oServer:Activate()
return nil

Notas

  • TFtpServer suporta apenas login anônimo; nenhuma autenticação por senha é exigida.
  • Comandos manipulados: NOOP, USER, PASS, QUIT, CWD, CDUP, PWD, PORT, TYPE, RETR, STOR, LIST, SYST.
  • O cliente TFTP usa WinINet, exigindo componentes do Internet Explorer.
  • TFTPFile suporta modos de transferência binário (lBinary := .T.) e ASCII.

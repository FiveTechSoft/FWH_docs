TNeuralNetwork

Fonte: source/classes/tneuralnet.prg

TNeuralNetwork é a rede neural feedforward do FiveWin implementada em Harbour puro. Fornece um perceptrão multi-camada (MLP) com treino por retropropagação. A rede consiste em três tipos de camadas: uma camada de entrada, uma ou mais camadas ocultas e uma camada de saída. Cada neurónio usa a função de ativação sigmoide. A classe é ideal para tarefas simples de reconhecimento de padrões, como o problema XOR.

Métodos Principais

MétodoDescrição
New( nInputs, aHiddenLayers, nOutputs )Criar uma rede neural com nInputs neurónios de entrada, um array de tamanhos de camadas ocultas (ex.: { 4, 3 } para duas camadas ocultas) e nOutputs neurónios de saída.
Learn( aInputs, aOutputs, lDebug )Treinar a rede numa amostra: executa propagação direta, depois retropropagação para ajustar pesos e viéses.
Propagation( aInputs )Executar propagação direta: calcular valores de ativação da entrada através das camadas ocultas até à saída. Usa a função de ativação sigmoide.
BackPropagation( aInputs, aOutputs )Executar propagação inversa: calcular gradientes de erro e atualizar todos os pesos e viéses com base na taxa de aprendizagem.

Exemplo: Treino XOR

#include "FiveWin.ch"

function Main()

   local oNN, n

   // Network: 2 inputs, hidden layer with 2 neurons, 1 output
   oNN := TNeuralNetwork():New( 2, { 2 }, 1 )

   // Train for 10000 iterations
   for n = 1 to 10000
      oNN:Learn( { 0, 0 }, { 0 } )
      oNN:Learn( { 1, 0 }, { 1 } )
      oNN:Learn( { 0, 1 }, { 1 } )
      oNN:Learn( { 1, 1 }, { 0 } )
   next

   // Test the trained network
   ? "XOR Truth Table:"
   ? "0 XOR 0 =", oNN:Propagation( { 0, 0 } )[ 1 ]  // ~0.0
   ? "1 XOR 0 =", oNN:Propagation( { 1, 0 } )[ 1 ]  // ~1.0
   ? "0 XOR 1 =", oNN:Propagation( { 0, 1 } )[ 1 ]  // ~1.0
   ? "1 XOR 1 =", oNN:Propagation( { 1, 1 } )[ 1 ]  // ~0.0

return nil

#include "FiveWin.ch"

function Main()

   // Debug mode prints inputs, outputs, expected values, and errors
   oNN:Learn( { 1, 0 }, { 1 }, .T. )

return nil

Notas

  • Pesos e viéses são inicializados com valores aleatórios usando hb_Random().
  • A função de ativação sigmoide mapeia valores para o intervalo (0, 1). A derivada é usada durante a retropropagação para cálculo do gradiente.
  • O nLearningRate controla quanto os pesos mudam durante cada atualização. Valores mais baixos (ex.: 0.01 - 0.1) fornecem treino mais estável, enquanto valores mais altos podem convergir mais rapidamente mas arriscam oscilação.
  • Múltiplas camadas ocultas podem ser criadas passando um array com vários valores: { 4, 3 } cria duas camadas ocultas com 4 e 3 neurónios respetivamente.
  • Esta é uma implementação Harbour pura sem dependências externas. A função Math_E() é implementada via API de extensão C do Harbour.
  • Para capacidades de rede neural mais avançadas, consulte a classe Transformer em source/classes/transformer.prg.

TGemini (Google Gemini)

Fonte: source/classes/tgemini.prg

TGemini é o cliente do FiveWin para a API Google Gemini. Ele fornece acesso à família de modelos Gemini do Google com suporte a chat de texto, respostas em streaming, análise de imagens e arquivos (PNG, JPEG, PDF, TXT, CSV, PRG) e upload de arquivos para o serviço de arquivos do Google. A classe usa a biblioteca hb_curl do Harbour para a comunicação HTTPS. As chaves de API podem ser passadas explicitamente ou lidas da variável de ambiente GEMINI_API_KEY.

Métodos

MétodoDescrição
New( cKey, cModel )Cria uma instância de TGemini. Lê GEMINI_API_KEY do ambiente se cKey estiver vazia. Inicializa o handle do libcurl.
Send( uContent, [cPrompt], [bCallback] )Método principal que aceita entrada flexível. uContent pode ser uma string de texto, um caminho de arquivo ou um array de caminhos de arquivos. cPrompt fornece texto opcional junto com os arquivos. bCallback habilita o streaming via codeblock. Retorna JSON bruto.
GetValue()Extrai o texto da resposta do JSON em cResponse. Navega pelo caminho candidates[1].content.parts[1].text. Retorna informações de erro em caso de falha.
GetTokens( cBuffer )Analisa um trecho (chunk) de resposta em streaming e extrai o token de texto. Trata tanto chunks JSON no estilo array quanto no estilo objeto.
UploadFile( cFileName, lDeleteAfter )Faz o upload de um arquivo para a API de arquivos do Google. Retorna a string com o URI do arquivo. Opcionalmente exclui cFileName quando lDeleteAfter é .T..
End()Libera o handle do libcurl. Chamado automaticamente pelo destrutor.

Exemplo: Chat de Texto

#include "FiveWin.ch"

function Main()

   local oAI := TGemini():New( "your-gemini-api-key" )

   oAI:Send( "What are the key features of the Harbour language?" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      MsgInfo( oAI:GetValue() )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Exemplo: Análise de Imagem / Arquivo

#include "FiveWin.ch"

function Main()

   local oAI := TGemini():New( "your-gemini-api-key" )

   // Imagem única
   oAI:Send( "C:\photos\chart.png", "Describe this chart." )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   // Análise de múltiplos arquivos
   oAI:Send( { "C:\docs\invoice.pdf", "C:\docs\photo.jpg" }, ;
      "Compare and summarize." )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Exemplo: Resposta em Streaming

#include "FiveWin.ch"

function Main()

   local oAI := TGemini():New( "your-gemini-api-key" )
   local cFull := ""

   // Passe um codeblock como 3º parâmetro para ativar o streaming
   oAI:Send( "Write a short story about AI.", , ;
      { |cChunk| cFull += cChunk, QOut( cChunk ) } )

   if oAI:nError == 0
      MsgInfo( "Complete:" + CRLF + cFull )
   endif

   oAI:End()

return nil

Notas

  • Requer a biblioteca hb_curl. Inclua #include "hbcurl.ch" para as constantes do curl.
  • A verificação SSL está desabilitada por padrão (HB_CURLOPT_SSL_VERIFYPEER = .F.).
  • Send() detecta automaticamente os arquivos pela extensão e os codifica em base64 para submissão inline. Tipos suportados: PNG, JPEG, PDF, TXT, CSV, PRG, CH.
  • O streaming é habilitado ao passar um codeblock como terceiro parâmetro para Send(). O endpoint muda de :generateContent para :streamGenerateContent.
  • UploadFile() usa o serviço dedicado de upload de arquivos do Google e retorna um URI para referência posterior em conversas de múltiplos turnos.

TKimi (Moonshot)

Fonte: source/classes/tkimi.prg

TKimi é o cliente FiveWin para a API Moonshot Kimi. Apresenta um método Send() unificado que deteta automaticamente o tipo de entrada: texto simples, ficheiro de imagem local, URL de imagem ou pedido de streaming. Este design simplifica a integração eliminando a necessidade de chamar métodos diferentes para diferentes tipos de entrada. Os modelos Kimi oferecem fortes capacidades multilingues com janelas de contexto de 8K a 128K tokens.

Métodos Principais

MétodoDescrição
New( cKey, cModel )Criar uma instância TKimi. Se cKey estiver vazio, lê KIMI_API_KEY do ambiente.
Send( xInput, uOptional )Método de envio unificado. Deteta automaticamente o tipo de entrada: string de texto simples, caminho de ficheiro local (envia como imagem), URL HTTP (envia como URL de imagem), ou se o segundo parâmetro for um bloco de código (streaming).
GetValue()Extrair a resposta de texto do JSON em cResponse. Navega choices[1].message.content.
End()Limpar o handle libcurl.

Exemplo: Prompt de Texto Simples

#include "FiveWin.ch"

function Main()

   local oKimi := TKimi():New( "your-moonshot-key" )

   // Simple text prompt
   oKimi:Send( "What is the capital of France?" )

   if oKimi:nError == 0
      MsgInfo( oKimi:GetValue() )
   endif

   oKimi:End()

return nil

Exemplo: Análise de URL de Imagem

#include "FiveWin.ch"

function Main()

   local oKimi := TKimi():New( "your-moonshot-key" )

   // Image URL - auto-detected by the "http" prefix
   oKimi:Send( "https://example.com/photo.jpg", ;
               "What do you see in this image?" )

   if oKimi:nError == 0
      MsgInfo( oKimi:GetValue() )
   endif

   oKimi:End()

return nil

Exemplo: Resposta em Stream

#include "FiveWin.ch"

function Main()

   local oKimi := TKimi():New( "your-moonshot-key" )
   local cBuffer := ""

   // Pass a codeblock as the second parameter for streaming
   oKimi:Send( "Tell me a joke", { |c| cBuffer += c, QOut( c ) } )

   if oKimi:nError == 0
      MsgInfo( "Complete:" + CRLF + cBuffer )
   endif

   oKimi:End()

return nil

Notas

  • O método Send() deteta tipos de entrada automaticamente: um caminho de ficheiro existente ativa upload de imagem, um URL começando com "http" ativa modo de URL de imagem, um bloco de código como segundo parâmetro ativa streaming, e texto simples envia um pedido de chat normal.
  • TKimi requer a biblioteca hb_curl. Inclua #include "hbcurl.ch" para constantes curl.
  • A chave da API pode ser lida da variável de ambiente KIMI_API_KEY passando uma chave vazia para New().
  • Modelos Kimi: moonshot-v1-8k (contexto 8K), moonshot-v1-32k (contexto 32K) e moonshot-v1-128k (contexto 128K).
  • A verificação SSL está desativada por padrão para ampla compatibilidade.

TNewsServer / TNewsInstance

Fontes: source/classes/tnewssrv.prg, source/classes/tnewsins.prg

TNewsServer independente | TNewsInstance auxiliar

TNewsServer implementa um servidor de notícias NNTP (Network News Transfer Protocol) na porta 119. É construído sobre TSocket e usa arquivos DBF/CDX para armazenar grupos de notícias e artigos. TNewsInstance lida com cada sessão de cliente conectada, analisando comandos NNTP e servindo dados de artigos.

Exemplo: Iniciar Servidor de Notícias

#include "FiveWin.ch"

function Main()

   local oWnd, oServer

   DEFINE WINDOW oWnd TITLE "NNTP News Server" SIZE 600, 400

   oServer := TNewsServer():New( oWnd, "c:\newsserver\data" )
   oServer:Activate()

   ACTIVATE WINDOW oWnd CENTERED

return nil

Notas

  • O servidor escuta na porta TCP 119 (porta NNTP padrão). Cada conexão de cliente cria um TNewsInstance.
  • Os grupos de notícias e artigos são armazenados em arquivos DBF com índices CDX, organizados por ID de grupo.
  • O temporizador (intervalo de 10ms) processa tarefas pendentes do cliente (p.ex., enviar resultados LIST em fragmentos).
  • A análise de comandos não difere maiúsculas/minúsculas. Comandos não reconhecidos recebem "500 Command not implemented."

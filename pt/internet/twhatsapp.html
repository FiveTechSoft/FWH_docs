TWhatsApp

Fonte: source/classes/twhatsapp.prg

Hierarquia: TWhatsApp (classe independente, sem herança)

TWhatsApp é um cliente da API WhatsApp Cloud que se comunica com a Plataforma de Negócios da Meta via requisições HTTPS usando a biblioteca cURL. Requer uma Conta de Negócios Meta, um ID de número de telefone registrado e um token de acesso permanente do sistema gerado a partir do Painel de Aplicativos Meta. Todos os tipos de mensagem são enviados como payloads JSON através da Graph API.

Principais Membros DATA

DATATipoPadrãoDescrição
cTokenCaractereToken de acesso Bearer para autenticação da API
cPhoneIdCaractereID do número de telefone do remetente (ID numérico Meta, não o número de telefone)
cVersionCaractere"v18.0"String de versão da Graph API
cBaseUrlCaractere"https://graph.facebook.com"URL base para todas as chamadas da API
cResponseCaractereResposta JSON bruta da última chamada da API
nErrorNumérico0Código de erro cURL da última operação
nHttpCodeNumérico0Código de status HTTP da última resposta

Métodos Principais

MétodoDescrição
New( cToken, cPhoneId, cVersion )Construtor. Inicializa o identificador cURL e armazena as credenciais. Opcionalmente define a versão da API.
End()Limpar o identificador cURL. Chamar quando terminar de usar o objeto.
SendText( cTo, cMsg, lPreviewUrl )Enviar uma mensagem de texto simples. lPreviewUrl habilita a geração de pré-visualização de link.
SendTemplate( cTo, cName, cLang, aBodyParams )Enviar um modelo de mensagem pré-aprovado com valores opcionais de parâmetros de corpo.
SendImage( cTo, cLinkOrId, cCaption )Enviar uma imagem por URL ou ID de mídia previamente enviada.
SendDocument( cTo, cLinkOrId, cFilename, cCaption )Enviar um documento por URL ou ID de mídia com nome de arquivo e legenda opcionais.
SendAudio( cTo, cLinkOrId )Enviar um arquivo de áudio por URL ou ID de mídia.
SendVideo( cTo, cLinkOrId, cCaption )Enviar um vídeo por URL ou ID de mídia com legenda opcional.
SendLocation( cTo, nLat, nLong, cName, cAddress )Enviar um marcador de localização com latitude, longitude e nome/endereço opcionais.
UploadMedia( cFileName, cMimeType )Enviar um arquivo de mídia para os servidores do WhatsApp. Retorna a string do ID da mídia ou nil em caso de falha.
DownloadMedia( cMediaId, cTargetFile )Baixar um arquivo de mídia dos servidores do WhatsApp e salvar no disco. Retorna .T. em caso de sucesso.
GetMessageId()Extrair o ID da mensagem da última resposta da API. Retorna string vazia em caso de falha.
GetError()Extrair a mensagem de erro da última resposta da API. Retorna string vazia se não houver erro.

Exemplo: Enviar Mensagem de Texto

#include "FiveWin.ch"

function Main()

   local oWA := TWhatsApp():New( "EAAx...token", "123456789", "v18.0" )
   local cResp, cMsgId

   // Send a simple text message
   cResp := oWA:SendText( "5215512345678", "Hello from FiveWin!" )

   cMsgId := oWA:GetMessageId()
   if ! Empty( cMsgId )
      MsgInfo( "Message sent. ID: " + cMsgId )
   else
      MsgInfo( "Error: " + oWA:GetError() )
   endif

   oWA:End()

return nil

Exemplo: Mensagem de Modelo

#include "FiveWin.ch"

function SendTemplate()

   local oWA  := TWhatsApp():New( "EAAx...token", "123456789" )
   local aParams := { "John", "FWH 26.05", "Monday" }

   // "welcome_message" must be pre-approved by Meta
   oWA:SendTemplate( "5215512345678", "welcome_message", "en_US", aParams )
   oWA:End()

return nil

Notas

  • Uma Conta de Negócios Meta e um número de telefone registrado são necessários. O ID do número de telefone é um identificador numérico atribuído pela Meta, não o número de telefone em si.
  • Use um token de acesso permanente do sistema do Painel de Aplicativos Meta. Tokens de usuário temporários expiram.
  • SendImage, SendDocument, SendAudio e SendVideo aceitam uma URL pública ou um ID de mídia previamente enviado. URLs devem começar com http (case-insensitive).
  • Os nomes dos modelos devem corresponder a modelos pré-aprovados na conta de Negócios Meta. Os parâmetros de corpo são inseridos posicionalmente.
  • Todos os métodos de envio retornam a resposta JSON bruta em cResponse. Chame GetMessageId() ou GetError() para analisar o resultado.
  • A classe usa hbcurl.ch e requer a biblioteca cURL vinculada à aplicação.

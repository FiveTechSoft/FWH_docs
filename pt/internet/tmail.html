TMail

Fonte: source/classes/tmail.prg

TMail é a classe de email MAPI (Messaging API) do FiveWin. Usa a interface Simple MAPI do Windows para enviar emails através do cliente de email padrão (como Microsoft Outlook, Windows Mail ou qualquer aplicação de email compatível com MAPI). TMail suporta assunto, corpo de texto, múltiplos destinatários, anexos de ficheiros, confirmações de leitura e informações do remetente.

Métodos Principais

MétodoDescrição
New( cSubject, cNoteText, cMsgType, cConversationID, dDate, cTime, lReceipt, lFromUser, aOrigin, aRecipients, aFiles )Criar uma nova mensagem de email com todos os parâmetros opcionais. Padrões: assunto vazio, corpo vazio, data de hoje, hora atual, sem confirmação de leitura, pedir confirmação ao utilizador.
Activate()Enviar o email via MAPI. Chama MAPISendMail() com todas as propriedades configuradas. Armazena o código de retorno em nRetCode.
End()Terminar sessão MAPI. Chama MAPILogOff().

Exemplo: Enviar Email com Anexos

#include "FiveWin.ch"

function Main()

   local oMail

   // Configure the email
   oMail := TMail():New( "Report for May 2026", ;
                         "Please find the attached report.",,,, .T. )

   // Add recipients
   oMail:aRecipients := { "user@example.com", "manager@example.com" }

   // Attach files
   oMail:aFiles := { "C:\reports\may2026.xlsx", "C:\reports\summary.pdf" }

   // Request read receipt
   oMail:lReceipt := .T.

   // Send without prompting the user
   oMail:lFromUser := .F.

   // Activate sends the email
   oMail:Activate()

   if oMail:nRetCode == 0
      MsgInfo( "Email sent successfully!" )
   else
      MsgStop( "Failed to send email. Error code: " + Str( oMail:nRetCode ) )
   endif

   oMail:End()

return nil

Notas

  • TMail usa o cliente MAPI padrão instalado no sistema. Outlook, Windows Mail, Thunderbird (com plugin MAPI) e a maioria dos clientes de email suportam MAPI.
  • Quando lFromUser é .T. (padrão), a janela de composição do cliente de email abre para o utilizador rever e enviar. Quando .F., o email é enviado silenciosamente.
  • O array aFiles aceita caminhos completos para ficheiros. Os anexos podem ser de qualquer tipo de ficheiro suportado pelo cliente de email do destinatário.
  • Os destinatários em aRecipients podem ser strings simples de endereço de email ou estruturas MAPI de destinatário com campos de nome e endereço.
  • Verifique nRetCode após Activate() para determinar se o envio foi bem-sucedido.

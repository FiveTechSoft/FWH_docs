AI Classes

Fontes: source/classes/topenai.prg, source/classes/tdeepseek.prg, source/classes/tgemini.prg, source/classes/tollama.prg

FiveWin fornece um conjunto unificado de classes de IA/LLM que se integram com provedores populares de IA na nuvem e modelos locais. Todas as classes seguem o mesmo padrão básico: instanciar com uma chave de API (ou nome do modelo para local), enviar um prompt e extrair a resposta. Elas usam a biblioteca hb_curl do Harbour para comunicação HTTPS com os respectivos endpoints da API.

Para a documentação completa de IA incluindo todos os membros das classes e exemplos estendidos, consulte TOpenAI / TChatGPT — essa página documenta cada classe de IA com tabelas de referência completas, exemplos de código e um guia de comparação.

Padrão Comum

Todas as classes de IA compartilham este fluxo de trabalho básico: 

// 1. Create instance with API key (or model name for local)
oAI := TSomeAI():New( cApiKey )

// 2. Send a prompt
oAI:Send( "Your question here" )

// 3. Extract the response text
cAnswer := oAI:GetValue()

// 4. Clean up
oAI:End()

TOLlama (IA Local)

Fonte: source/classes/tollama.prg

Integração com LLM local via Ollama. Nenhuma chave de API necessária — executa modelos na sua própria máquina. Modelo padrão: deepseek-r1:14b.

DATAPadrãoDescrição
cModeldeepseek-r1:14bNome do modelo Ollama
cUrlhttp://localhost:11434/api/chatEndpoint do servidor Ollama
MétodoParâmetrosDescrição
New()cModelConstrutor. Modelo padrão: deepseek-r1:14b.
Send()cPromptEnviar prompt, retorna JSON bruto
SendStream()cPrompt, bCallbackResposta em streaming via callback
SendImage()cImageFile, cPromptVisão para modelos multimodais (ex.: llava)
GetValue()Extrair conteúdo da mensagem do JSON
 
// Local AI - no API key needed
local oAI := TOLlama():New( "llama3" )
oAI:Send( "What is FiveWin?" )
MsgInfo( oAI:GetValue() )

// Streaming response
oAI:SendStream( "Write a poem", {|c| QOut(c)} )

// Image analysis (vision model)
oAI:SendImage( "photo.jpg", "What do you see?" )

oAI:End()

Dicas

  • Todas as classes de IA requerem a biblioteca hb_curl. Vincule com #include "hbcurl.ch" para constantes curl.
  • A verificação SSL está desativada por padrão (HB_CURLOPT_SSL_VERIFYPEER = .F.) para ampla compatibilidade.
  • Use GetValue() para extrair a resposta de texto do JSON bruto armazenado em cResponse.
  • O membro DATA cResponse sempre contém o JSON bruto. Acesse-o diretamente para depuração ou análise personalizada.
  • Para documentação completa incluindo todos os métodos, codeblocks de callback e uso avançado, consulte a página TOpenAI / TChatGPT.

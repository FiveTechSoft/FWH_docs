TDeepSeek

Fonte: source/classes/tdeepseek.prg

TDeepSeek é o cliente FiveWin para a API DeepSeek. DeepSeek é conhecido pelas suas fortes capacidades de programação e raciocínio, tornando-o uma excelente escolha para geração de código, análise e tarefas de lógica. A classe fornece uma interface simples de chat completion usando a biblioteca hb_curl do Harbour. Suporta os modelos deepseek-chat e deepseek-reasoner.

Métodos Principais

MétodoDescrição
New( cKey, cModel )Criar uma instância TDeepSeek. Se cKey estiver vazio, lê DEEPSEEK_API_KEY do ambiente. Define o endpoint da API e inicializa um handle libcurl.
Send( cPrompt )Enviar um prompt de texto para a API DeepSeek. Armazena a resposta JSON bruta em cResponse.
GetValue()Extrair a resposta de texto do JSON em cResponse. Navega choices[1].message.content em caso de sucesso, ou retorna a mensagem de erro em caso de falha.
End()Limpar o handle libcurl.

Exemplo: Chat Completions

#include "FiveWin.ch"

function Main()

   local oAI := TDeepSeek():New( "sk-deepseek-key" )
   local cAnswer

   // Send a prompt
   oAI:Send( "Write a Harbour function to calculate the Fibonacci sequence" )

   if oAI:nError == 0 .and. oAI:nHttpCode == 200
      cAnswer := oAI:GetValue()
      MsgInfo( cAnswer )
   else
      MsgStop( "Error: " + oAI:cResponse )
   endif

   oAI:End()

return nil

Exemplo: Usar o Modelo Reasoner

#include "FiveWin.ch"

function Main()

   local oAI := TDeepSeek():New( "sk-deepseek-key", "deepseek-reasoner" )

   oAI:Send( "Solve this logic puzzle: A man pushes his car to a hotel " + ;
             "and tells the owner he is bankrupt. What happened?" )

   if oAI:nError == 0
      MsgInfo( oAI:GetValue() )
   endif

   oAI:End()

return nil

Notas

  • TDeepSeek requer a biblioteca hb_curl. Inclua #include "hbcurl.ch" para constantes curl.
  • A chave da API pode ser lida da variável de ambiente DEEPSEEK_API_KEY passando uma chave vazia para New().
  • A verificação SSL está desativada por padrão (HB_CURLOPT_SSL_VERIFYPEER = .F.) para ampla compatibilidade.
  • O modelo deepseek-reasoner fornece raciocínio chain-of-thought antes de responder, tornando-o adequado para tarefas complexas de lógica e análise.
  • GetValue() navega pelo caminho JSON choices[1].message.content e retorna o texto. Se a API retornar um erro, navega por error.message.
  • A classe não mantém estado para prompts — cada chamada Send() é independente. Para conversas de múltiplas trocas, mantenha o seu próprio histórico de mensagens e envie o contexto completo.

TCtrlSocket

Fonte: source/classes/tctrsock.prg

Classe independente

TCtrlSocket implementa um servidor de sockets multiplexado que gerencia múltiplas conexões de clientes através de uma fila de requisições. Em vez de dedicar uma thread por cliente, mantém um array de requisições pendentes (aRequests) e as atende em sequência. Cada entrada de requisição armazena o objeto socket e blocos de callback opcionais para fim de conexão (abEnd) e oportunidade de processamento (abChance). A classe rastreia contagens de bytes enviados (anSended) e o estado de execução do servidor (lServerWorking).

Principais Membros DATA

DATATipoDescrição
aRequestsArrayArray de objetos de requisição pendente (socket + callbacks)
abEndArrayArray de codeblocks avaliados quando cada conexão de requisição termina
abChanceArrayArray de codeblocks avaliados quando cada requisição recebe tempo de processamento
anSendedArrayArray de contagens de bytes enviados para cada requisição
lServerWorkingLógico.T. quando o servidor está ativamente servindo requisições

Métodos Principais

MétodoDescrição
New()Cria um novo controlador de sockets multiplexado
AddRequest( oSocket, bEnd, bChance )Enfileira um socket com callbacks opcionais de fim e oportunidade
ServeClients()Processa todas as requisições pendentes em modo round-robin

Exemplo: Servidor Multiplexado de 2 Sockets

#include "FiveWin.ch"

function Main()

   local oCtrl, oSocket1, oSocket2

   // Create the multiplexed socket controller
   oCtrl := TCtrlSocket():New()

   // Create two client sockets
   oSocket1 := TSocket():New()
   oSocket2 := TSocket():New()

   // Add requests with callbacks
   oCtrl:AddRequest( oSocket1, ;
      { || QOut( "Socket 1 ended" ) }, ;
      { || QOut( "Socket 1 processing" ) } )

   oCtrl:AddRequest( oSocket2, ;
      { || QOut( "Socket 2 ended" ) }, ;
      { || QOut( "Socket 2 processing" ) } )

   // Serve clients in a loop
   do while oCtrl:lServerWorking
      oCtrl:ServeClients()
      // Yield to Windows message queue
      SysRefresh()
   enddo

return nil

Notas

  • TCtrlSocket é projetado para multitarefa cooperativa dentro de uma única thread. Chame ServeClients() periodicamente para dar a cada socket na fila uma oportunidade de ler/escrever dados.
  • Use o callback abChance para manipular o processamento de dados de cada socket. Este callback recebe o objeto socket e pode chamar Recv()/Send() para se comunicar.
  • O callback abEnd é disparado quando uma conexão termina, permitindo a limpeza de recursos por socket.
  • anSended rastreia bytes cumulativos enviados por requisição, útil para monitoramento de progresso.

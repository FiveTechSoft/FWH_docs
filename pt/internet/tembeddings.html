TEmbeddings

Fonte: source/classes/tembeddings.prg

TEmbeddings é a classe FiveWin para gerar e comparar embeddings de texto (representações vetoriais de texto). Suporta tanto a HuggingFace (via pipeline de extração de características da Inference API) como a OpenAI embeddings API. Embeddings convertem texto em vetores de alta dimensão que capturam significado semântico, permitindo operações como pesquisa de similaridade semântica, clustering e classificação.

Métodos Principais

MétodoDescrição
New( cModel, cKey )Criar uma instância TEmbeddings. Padrão para modelo HuggingFace MiniLM. Lê a chave da API das variáveis de ambiente HF_API_KEY e depois OPENAI_API_KEY se não for fornecida.
GetEmbeddings( cText )Gerar embeddings para o texto dado. Armazena o vetor em aEmbeddings. Retorna o array do vetor bruto.
Distance( aVector, lCosine )Calcular distância entre aEmbeddings e outro vetor. Padrão usa distância cosseno. Defina lCosine := .F. para distância euclidiana.
DistanceFrom( oEmbeddings )Calcular distância para outro objeto TEmbeddings comparando os vetores aEmbeddings.
End()Limpar o handle libcurl.

Exemplo: Similaridade Semântica

#include "FiveWin.ch"

function Main()

   local oE1 := TEmbeddings():New()
   local oE2 := TEmbeddings():New()
   local oE3 := TEmbeddings():New()
   local nSimilarity1, nSimilarity2

   // Generate embeddings for three phrases
   oE1:GetEmbeddings( "I feel very well" )
   oE2:GetEmbeddings( "How are you?" )
   oE3:GetEmbeddings( "I saw Peter" )

   // Cosine distance: lower = more similar
   nSimilarity1 := oE1:DistanceFrom( oE2 )  // Low distance (similar topic)
   nSimilarity2 := oE1:DistanceFrom( oE3 )  // High distance (different topic)

   QOut( "Similarity between 'feel well' and 'How are you':", nSimilarity1 )
   QOut( "Similarity between 'feel well' and 'saw Peter':", nSimilarity2 )

   // Using the OPERATOR "-" syntax (equivalent to DistanceFrom)
   ? oE1 - oE2   // Same as oE1:DistanceFrom( oE2 )
   ? oE1 - oE3   // Same as oE1:DistanceFrom( oE3 )

   oE1:End()
   oE2:End()
   oE3:End()

return nil

Exemplo: Distância Euclidiana

#include "FiveWin.ch"

function Main()

   local oE1 := TEmbeddings():New()
   local oE2 := TEmbeddings():New()

   oE1:GetEmbeddings( "Machine learning is fascinating" )
   oE2:GetEmbeddings( "Deep learning and AI are interesting" )

   // Euclidean distance instead of cosine
   ? "Euclidean distance:", oE1:Distance( oE2:aEmbeddings, .F. )

   oE1:End()
   oE2:End()

return nil

Notas

  • O modelo padrão é sentence-transformers/all-MiniLM-L6-v2 da HuggingFace. Mudar o nome do modelo alterna automaticamente entre fornecedores: se o nome do modelo contiver "openai" ou "text-embedding-", usa o endpoint OpenAI; caso contrário, usa HuggingFace.
  • Ao usar HuggingFace, defina a variável de ambiente HF_API_KEY. Ao usar OpenAI, defina OPENAI_API_KEY.
  • O método Distance() suporta duas métricas: distância cosseno (padrão) varia de 0 (idêntico) a 1 (completamente diferente); distância euclidiana mede a distância em linha reta entre vetores.
  • O OPERATOR "-" permite sintaxe intuitiva: oE1 - oE2 calcula a distância entre dois objetos TEmbeddings. É equivalente a chamar oE1:DistanceFrom( oE2 ).
  • Ambos os vetores devem ter o mesmo comprimento. O método Distance() retorna -1 em caso de erro.

Email OAuth2: TOAuth, TGmail, TOutlookMail

Fontes: source/classes/oauth.prg, source/classes/gmail.prg, source/classes/outlookmail.prg

O FiveWin fornece suporte de email OAuth2 para Gmail (TGmail) e Outlook/Office 365 (TOutlookMail) através de uma hierarquia de classes comum. TOAuth lida com autenticação, gerenciamento de tokens e construção de mensagens MIME. TGmail implementa a API REST do Gmail, TOutlookMail usa o Microsoft Graph. Toda comunicação de rede usa libcurl; o login interativo usa TWebView2.

Fluxo de Autenticação OAuth2

TOAuth: Classe Base

TOAuth fornece o fluxo de trabalho OAuth2 principal e a construção multiparte MIME. Gerencia as credenciais do cliente, o servidor HTTP local para captura de redirecionamento e o ciclo de vida do token incluindo a atualização automática.

cAccessTokenCaractereToken de acesso atual
cRefreshTokenCaractereToken de atualização persistente
MétodoDescrição
GetAuthCode()Abre WebView2, navega para URL de autenticação do provedor, captura código de autorização via THttpServer local
GetToken()Troca código de autorização por tokens de acesso e atualização via POST para o endpoint /token
RefreshToken()Usa refresh_token para obter um novo access_token quando o atual expira

getFileMime(cPath)Retorna a string de tipo MIME para uma extensão de arquivo (tabela de consulta para jpg, png, pdf, etc.)

TGmail: API do Google Gmail

MétodoDescrição
New(cClientId,cClientSecret,cUser)Cria uma instância TGmail para o usuário especificado. Ativa o fluxo de autenticação OAuth2 se nenhum token estiver em cache.
Send(cTo,cSubj,cBody,aAttach)Envia um email via endpoint da API do Gmail. aAttach é um array de caminhos de arquivos.
GetToken()Obtém um token de acesso novo, verificando validade via endpoint tokeninfo primeiro.
RefreshToken()Força a atualização do token de acesso a partir do token de atualização armazenado.

TGmail envia via https://gmail.googleapis.com/gmail/v1/users/me/messages/send?uploadType=multipart e requer um ID de cliente "Aplicação Web" do Google Cloud Console com URI de redirecionamento configurado para http://localhost:2025.

TOutlookMail: API do Microsoft Graph

MétodoDescrição
New(cClientId,cTenantId,cUser)Cria uma instância TOutlookMail. cTenantId identifica o inquilino do Azure AD.
Send(cTo,cSubj,cBody,aAttach)Envia email via endpoint do Microsoft Graph /users/{user}/sendMail. Suporta corpo HTML e anexos.
me()Recupera o perfil do usuário autenticado de https://graph.microsoft.com/v1.0/me

Escopos OAuth2 necessários: Mail.Send, offline_access, openid, profile, SMTP.Send, User.Read. A Microsoft pode rotacionar tokens de atualização; a classe detecta novos tokens de atualização nas respostas e atualiza o armazenamento local automaticamente.

Exemplo: Envio Gmail OAuth2

#include "FiveWin.ch"

function Main()

   local oGmail := TGmail():New( ;
      "your-client-id.apps.googleusercontent.com", ;
      "your-client-secret", ;
      "user@gmail.com" )

   // The OAuth2 browser window opens automatically
   // if no cached token is found

   if ! Empty( oGmail:cAccessToken )
      oGmail:Send( "recipient@example.com", ;
                   "Test from FWH", ;
                   "<h1>Hello!</h1><p>Sent via Gmail API.</p>", ;
                   { "C:\docs\invoice.pdf" } )
      MsgInfo( "Email sent successfully!" )
   else
      MsgStop( "Authentication failed" )
   endif

return nil

Notas

  • Requer libcurl.dll, libssl-3-x64.dll, zlib1.dll para compilações de 64 bits; o runtime do TWebView2 deve estar instalado.
  • Os tokens são armazenados em cache local; a rotação do token de atualização garante acesso de longa duração sem solicitações de login repetidas.
  • O THttpServer local escuta na porta 2025 (padrão) para capturar o redirecionamento com o código de autorização.
  • As mensagens MIME usam delimitadores adequados, cabeçalhos Content-Type e codificação base64 de anexos conforme RFC 2822.

TWebView2

Fonte: source/classes/twebview2.prg

Overview

TWebView2 incorpora Microsoft Edge WebView2 numa janela ou diálogo FiveWin. Serve para alojar UIs HTML/CSS/JS modernas junto de controlos FWH nativos. Requer o Runtime WebView2.

Desktop + Web com uma única UI

O sample samples/DesktopWeb/login.prg mostra o padrão em que desktop e browser partilham o mesmo HTML/CSS/JS:

  • Um servidor HTTP multi-thread na porta 8080 serve login e dashboard gerados em Harbour.
  • O shell desktop cria TWebView2 e faz Navigate("http://localhost:8080/").
  • Qualquer browser abre a mesma URL com a mesma UI e API.
  • A validação de credenciais está em PRG (ValidateLogin); sessão com cookie DWSESS.

Compilar com VM multi-thread: samples\DesktopWeb\build.bat ou build_new.bat login hm64 -mt. Demo: admin/1234, demo/demo.

FWH 26.09

A API ampliada, incluindo bOnConsole e EnableConsole, está disponível desde FWH 26.09, dia 12 (12 de setembro de 2026). São recursos da biblioteca FWH; atualizar apenas o Runtime da Microsoft não basta. Bibliotecas anteriores podem não ter o setter DATA _BONCONSOLE nem o método EnableConsole.

Blocos de eventos

Atribua blocos com estes argumentos. hWebView é o ponteiro da vista nativa, não o objeto FWH; bOnBind recebe oWebView como segundo argumento. Retornos afetam o comportamento apenas quando indicado.

AssinaturaComportamento
bOnBind( uParams, oWebView )Recebe argumentos comuns de SendToFWH; retorno ignorado. Arrays de um elemento são desempacotados; console/limpeza usam eventos separados.
bOnEval( cJson, hWebView )Resultado JavaScript codificado em JSON; retorno ignorado.
bOnConsole( cJson, hWebView )JSON de console descrito abaixo; retorno ignorado.
bOnNavigationCompleted( cUrl, hWebView )Navegação principal concluída. Retorno ignorado.
bOnSourceChanged( cUrl, hWebView )URL de origem alterada. Retorno ignorado.
bOnDocumentTitleChanged( cTitle, hWebView )Título do documento alterado. Retorno ignorado.
bOnHistoryChanged( lCanBack, lCanFwd, hWebView )Disponibilidade do histórico alterada. Retorno ignorado.
bOnFrameNavCompleted( cUrl, hWebView )Navegação do frame concluída. Retorno ignorado.
bOnCapturePreview( lOk, cPath, hWebView )Resultado final da captura/gravação PNG. Retorno ignorado.
bOnPrintToPdf( lOk, cPath, hWebView )Resultado final da exportação PDF. Retorno ignorado.
bOnClearBrowsingData( lOk, cWhat, hWebView )Confirmação JS: .T., "javascript"; não comprova remoção completa do perfil. Retorno ignorado.
bOnZoomFactorChanged( nZoom, hWebView )Zoom do navegador alterado. Retorno ignorado.
bOnProcessFailed( nKind, hWebView )Falha do processo do navegador; tipo WV_FAIL_*. Retorno ignorado.
bOnFullScreen( lFull, hWebView )Estado HTML de tela cheia alterado. Retorno ignorado.
bOnNavigationStarting( cUrl, hWebView )Retorne .T. para cancelar; outros valores, ou valores não lógicos, não cancelam.
bOnFrameNavStarting( cUrl, hWebView )Retorne .T. para cancelar; outros valores, ou valores não lógicos, não cancelam.
bOnNewWindow( cUrl, hWebView )Apenas notificação: a vista nativa navega à URL e marca a requisição como atendida; o retorno não seleciona outra janela.
bOnPermission( cUrl, nKind, hWebView )Retorne WV_PERM_ALLOW (1), WV_PERM_DENY (2), ou 0 para padrão; nKind é o tipo de permissão do runtime.
bOnWebResource( cUrl, nContext, hWebView )Retorne .T. ou número diferente de zero para bloquear com HTTP 403 vazio; caso contrário permite. Instale os filtros antes.
bOnScriptDialog( cUri, nKind, cMsg, cDefault, hWebView )Retorne .T. para Accept; .F. mantém a gestão padrão (ou sem diálogo se desativada). Um bloco instalado com retorno não lógico é tratado como .T. Tipos WV_DIALOG_*. Não é exposta a troca da resposta de prompt.
bOnHostObject( cObjName, cMethod, cArg, hWebView )Hook reservado com retorno C; o registro nativo de objetos host não está implementado.

Console JavaScript

EnableConsole(.T.) intercepta console.log/warn/error/info sem remover a saída original do console e adiciona um listener de erros JavaScript. Envia um envelope interno por SendToFWH; bOnConsole recebe a string JSON interna, não o envelope externo. args contém strings: objetos são convertidos com JSON.stringify. line consta nos erros de window, não nas chamadas comuns a console.

Chame EnableConsole(.T.) após cada navegação principal: a interceptação é instalada uma vez por documento. EnableConsole(.F.) interrompe a entrega pelo despachante do console, mas não desfaz a interceptação JavaScript já instalada. Seu retorno lógico é o indicador armazenado, não prova de injeção correta. O console é separado das mensagens comuns de bOnBind.

Exemplos de JSON recebido

{
  "type": "log",
  "args": [
    "ready",
    "{\"count\":2}"
  ],
  "url": "https://example.com/"
}

{
  "type": "error",
  "args": [
    "Uncaught ReferenceError: x is not defined"
  ],
  "url": "https://example.com/",
  "line": 12
}

Exemplo de console

oWeb := TWebView2():New( oWnd )
IF ! Empty( oWeb:hWebView )
   oWeb:bOnConsole := { | cJson, hWebView | LogConsole( cJson ) }
   oWeb:bOnNavigationCompleted := { | cUrl, hWebView | oWeb:EnableConsole( .T. ) }
   oWeb:Navigate( "https://example.com/" )
ENDIF

STATIC FUNCTION LogConsole( cJson )
   LOCAL hData
   hb_jsonDecode( cJson, @hData )
   IF ValType( hData ) == "H"
      // hData[ "type" ], hData[ "args" ], hData[ "url" ]
      // hData[ "line" ]: only for a window error
      OutputDebugString( cJson )
   ENDIF
RETURN NIL

Compatibilidade de bibliotecas

Para aceitar bibliotecas FWH anteriores, verifique a atribuição do DATA e a chamada a EnableConsole. Use a mesma verificação ao ativar o rastreamento após navegar. Apenas o diagnóstico do console é omitido; o tráfego comum SendToFWH/bOnBind não muda.

IF __objHasMsg( oWeb, "_BONCONSOLE" ) .AND. ;
   __objHasMsg( oWeb, "ENABLECONSOLE" )
   oWeb:bOnConsole := { | cJson, hWebView | LogConsole( cJson ) }
   oWeb:EnableConsole( .T. )
ENDIF

Limites e requisitos do runtime

AddHostObject não está implementado. SetContextMenuExclude armazena a lista mas não filtra itens do menu. A limpeza usa JavaScript, não apaga todo o perfil nem cookies HttpOnly. Verifique o resultado PNG/PDF assíncrono nos eventos. As interfaces disponíveis do runtime podem limitar PDF, downloads e requisições HTTP. Consulte samples/webview2/wvdemo.prg + pulse.html e as constantes WV_CONTEXT_*, WV_DIALOG_*, WV_PERM_* e WV_FAIL_* em include/WebView2.ch.

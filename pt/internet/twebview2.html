TWebView2

Fonte: source/classes/twebview2.prg

Overview

TWebView2 incorpora Microsoft Edge WebView2 numa janela ou diálogo FiveWin. Serve para alojar UIs HTML/CSS/JS modernas junto de controlos FWH nativos. Requer o Runtime WebView2.

Desktop + Web com uma única UI

O sample samples/DesktopWeb/login.prg mostra o padrão em que desktop e browser partilham o mesmo HTML/CSS/JS:

  • Um servidor HTTP multi-thread na porta 8080 serve login e dashboard gerados em Harbour.
  • O shell desktop cria TWebView2 e faz Navigate("http://localhost:8080/").
  • Qualquer browser abre a mesma URL com a mesma UI e API.
  • A validação de credenciais está em PRG (ValidateLogin); sessão com cookie DWSESS.

Compilar com VM multi-thread: samples\DesktopWeb\build.bat ou build_new.bat login hm64 -mt. Demo: admin/1234, demo/demo.

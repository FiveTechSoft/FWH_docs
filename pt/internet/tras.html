TRas

Fonte: source/classes/tras.prg

TRas é a classe de Serviço de Acesso Remoto (RAS) do FiveWin para gerir ligações dial-up no Windows. Encapsula a API RAS do Windows para iniciar ligações telefónicas, monitorizar o estado da ligação e desligar. TRas suporta modos de ligação manual e automático (bloqueante) com salvaguardas baseadas em timeout.

Métodos Principais

MétodoDescrição
New( oWnd, cPhone, cUser, cPass )Criar uma instância RAS. Requer um handle de janela válido, número de telefone, nome de utilizador e palavra-passe. Valida todos os parâmetros na construção.
Call( lMode, bStatus )Iniciar a ligação dial-up. Se lMode for .T. (espera automática), bloqueia até ligar ou timeout. Opcionalmente define o callback bStatus.
Status()Consultar o estado atual da ligação e atualizar todos os membros DATA de estado. Invoca o callback bStatus se definido.
HangUp()Terminar a ligação RAS. Chama RaHangUp() com o handle armazenado.

Exemplo: Dial-up com Espera Automática

#include "FiveWin.ch"

function Main()

   local oWnd, oRas

   DEFINE WINDOW oWnd TITLE "RAS Dial-up"

   oRas := TRas():New( oWnd, "555-1234", "myuser", "mypass" )

   if oRas:lOperation
      // Auto-wait mode: blocks until connected (or timeout)
      if oRas:Call( .T. )
         MsgInfo( "Connected! Status: " + oRas:cStatus )
         // ... use the connection ...
         oRas:HangUp()
      else
         MsgStop( "Connection failed: " + oRas:cError )
      endif
   else
      MsgStop( "RAS initialization failed" )
   endif

return nil

Notas

  • TRas requer um handle de janela ou diálogo FiveWin válido (oWnd:hWnd) para a API RAS publicar notificações de estado da ligação.
  • No modo de espera automática (Call( .T. )), o método consulta o estado da ligação num ciclo até ligar, o timeout expirar ou lPanic ser definido como .T..
  • O bloco de código de callback bStatus é invocado em cada mudança de estado, permitindo atualizações da interface durante o processo de ligação.
  • Verifique sempre lOperation após a construção e Call() para confirmar o sucesso.

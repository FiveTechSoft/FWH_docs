Claude Code

Claude Code é a ferramenta CLI oficial da Anthropic e um agente de codificação com IA que opera diretamente no terminal. Lê todo o código do projeto, executa comandos, edita arquivos e orquestra tarefas complexas.

FiveWin para Harbour integra-se com Claude Code através de CLAUDE.md, memória persistente, skills especializados e fluxos multi-agente.

O que é Claude Code?

  • Nativo do terminal — PowerShell, cmd, bash
  • Conhecimento total do código — lê todo o projeto
  • Agente com ferramentas — edita, compila, executa, usa git
  • Multi-agente — sub-agentes em paralelo
  • Memória persistente — lembra preferências e convenções
  • Hooks — automação por eventos
  • MCP — extensível por Model Context Protocol

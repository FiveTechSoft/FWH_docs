Instalação e Configuração

Pré-requisitos

  • Node.js 18+
  • Chave API Anthropic ou assinatura Claude
  • Git

Instalar Claude Code

npm install -g @anthropic-ai/claude-code

Autenticar

claude login

Ou com chave API: $env:ANTHROPIC_API_KEY = "sk-..."

Configuração do Projeto FWH

git clone https://github.com/FiveTechSoft/fwh.git
cd fwh
claude

Claude lê CLAUDE.md automaticamente. O projeto FWH inclui:

  • CLAUDE.md — Regras de compilação, caminhos, bibliotecas
  • .claude/settings.local.json — Hooks e permissões
  • .claude/projects/c--fwteam/memory/ — Memória persistente
